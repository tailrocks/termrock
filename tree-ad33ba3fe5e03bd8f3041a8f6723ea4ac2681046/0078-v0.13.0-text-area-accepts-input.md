# 0078 — TextArea accepts_input + editor premium chrome

## Removed / renamed

| Removed | Replacement |
|---------|-------------|
| `TextAreaState::set_focused` (primary) | `set_accepts_input` (deprecated alias kept) |
| `TextAreaState::is_focused` (primary) | `accepts_input` |
| Wheel always `Changed` | `TextAreaOutcome::Scrolled` when viewport-only |

## Added

| API | Role |
|-----|------|
| `set_read_only` / `is_read_only` | Scroll ok, edits blocked |
| `handle_intent` | Nav / cancel |
| `default_text_area_intent` | Home/End/Page/Left/Right/Esc |
| `TextArea::{ascii, colorless}` | Scroll glyphs + caret |
| PromptComposer propagates accepts_input to editor | Fix latent key-gate bug |

## Consumer edits

```rust
// Before
state.set_focused(true);

// After
state.set_accepts_input(true);
// Optional
state.set_read_only(false);
TextArea::new(&system).title("Edit").ascii(false).placeholder("…");
```
