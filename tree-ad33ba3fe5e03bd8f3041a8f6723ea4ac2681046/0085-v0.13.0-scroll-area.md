# 0085 — ScrollArea canonical scrolling primitive

## Mission

One scroll engine for logs, transcripts, lists, dialogs, nested panes: axes,
wheel, page, bars, follow/pause/unseen, anchors, nesting policy, visible ranges.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `scroll::{max_offset, apply_delta_u16, render_scrollbar, …}` | **Preserve** paint/math helpers |
| `scroll::TailScroll` / `DialogScroll` | **Preserve** specialized helpers (LogPane buffer, dialog dual-axis) |
| `perf::{FollowMode, ScrollAnchor, NewContentIndicator}` | **Wire into** `ScrollAreaState` (sole policy for streams that use it) |
| `widgets::ScrollAreaState` | **Expand** to canonical model |
| Dual `LogStreamState.follow` bool | **Delete** — use `scroll.is_following()` |
| Widget-local offset pairs without state | **Migrate** reps to `ScrollAreaState` |

## Added

| API | Module | Role |
|-----|--------|------|
| `ScrollChain` | `widgets` | Capture / Parent / NestedPreferChild wheel policy |
| `ScrollOutcome` | `widgets` | Ignored / Scrolled / FollowChanged / ChainToParent |
| `VisibleRange` | `widgets` | Half-open `[start, end)` for virt + a11y |
| `ScrollAreaState::{axes, chain, wheel_steps, …}` | `widgets` | Dual axis + policy builders |
| `follow` / `pause_follow` / `jump_to_new_content` | `widgets` | Follow-tail lifecycle |
| `apply_anchor` / `capture_*_anchor` | `widgets` | Stable anchors across resize/stream |
| `visible_range_y` / `visible_range_x` | `widgets` | Virtualization window |
| `handle_intent` | `widgets` | `UiIntent` Move/Page → scroll |
| `set_offset_y_quiet` | `widgets` | Programmatic reveal without pause |
| `ScrollArea::render_new_content` | `widgets` | Non-color `↓ N new` strip |
| `ScrollOutcome::{is_scrolled, consumed, chains}` | `widgets` | Test/host helpers |

## Breaking

| Surface | Change |
|---------|--------|
| `handle_key` / `handle_mouse` | Return `ScrollOutcome` (was `bool`) |
| `set_content_size` / `set_viewport` | No longer `const`; growth runs follow/indicator |
| `follow_tail` field | Internal `FollowMode` (use `is_following` / `follow_mode`) |
| `LogStreamState` | No parallel `follow` field; `scroll()` accessor |

## Consumer edits

```rust
use termrock::widgets::{
    ScrollArea, ScrollAreaState, ScrollBarVisibility, ScrollChain, ScrollOutcome,
};
use termrock::perf::ScrollAnchor;

let mut s = ScrollAreaState::new()
    .axes(true, true)
    .chain(ScrollChain::NestedPreferChild)
    .wheel_steps(3, 4);
s.set_content_size(80, 1000);
s.set_viewport(40, 20);
s.follow_tail();

// was: if state.handle_key(key) { … }
if state.handle_key(key).is_scrolled() { /* … */ }

// Nested wheel: host chains when child returns ChainToParent
match child.handle_mouse(ev) {
    ScrollOutcome::ChainToParent => { let _ = parent.handle_mouse(ev); }
    o if o.consumed() => {}
    _ => {}
}

// Anchors after reflow
s.apply_anchor(&ScrollAnchor::content_id("msg-42"), |id| map.get(id).copied());
let window = s.visible_range_y(); // virt slice [start, end)

// Paint chrome
let sa = ScrollArea::new(&system).bar(ScrollBarVisibility::Auto);
let body = sa.body_area(area, &s);
// … paint body …
sa.render_bars(area, buf, &s);
sa.render_new_content(area, buf, &s);
```

### LogStream

- Follow/pause/unseen sole path: `ScrollAreaState` inside `LogStreamState`.
- `is_following()` reads scroll policy.
- Paused appends accumulate `new_content().unseen`; chip shows `↓ N new`.

### ObjectInspector / DiffReview

- Cursor/hunk reveal uses `set_offset_y_quiet` (no accidental follow pause).
- User wheel/keys still pause via `set_offset_y` / `scroll_by`.

## Laws

1. One offset + follow authority per surface (`ScrollAreaState`).
2. User scroll pauses follow; append while paused notes unseen (glyph/count, not color alone).
3. Nested wheel policy is explicit (`ScrollChain`), never implicit dual capture.
4. Visible ranges are half-open for virtualization and semantic inspection.
5. Anchors prefer `ContentId` when host can resolve; else Index / FromEnd.
