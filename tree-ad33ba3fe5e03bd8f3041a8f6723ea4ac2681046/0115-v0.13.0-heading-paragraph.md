# 0115 — Heading & Paragraph editorial recipes

## Mission

Editorial heading and prose for documentation, dialogs, plans, help, and empty
states: heading levels via weight, rules, and ASCII `#` prefixes; paragraph
wrap, indentation, hanging prefixes, quotes, lists, compact/reading recipes;
Markdown paint reuses the same layout (no duplicated wrap/prefix logic).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Text` / `TextSpan` | **Preserve** — paint primitive under Heading/Paragraph |
| `Heading` / `HeadingLevel` | **Migrated** — recipes, rule, prefix, parts, measure |
| `Paragraph` | **Migrated** — kinds (body/quote/list/ordered), hanging wrap, recipes |
| `HeadingRecipe`, `ParagraphKind`, `ParagraphRecipe`, `*Parts` | **Added** |
| `MarkdownBlock` | **Migrated** — adds `heading_level`; use `MarkdownBlock::new` / `::heading` |
| `MarkdownView` | **Migrated** — paints via Heading/Paragraph/Text |
| `Callout` / `Alert` | **Preserve** |
| `crate::text` wrap/truncate | **Preserve** — shared measurement |

## API sketch

```rust
use termrock::widgets::{
    Heading, HeadingLevel, HeadingRecipe,
    Paragraph, ParagraphKind, ParagraphRecipe,
};

// Heading: levels + recipes
Heading::new("Title", &system).h1().reading().paint(area, buf);
Heading::new("Section", &system).h2().compact(); // ## prefix for ASCII/no-color
Heading::new("Note", &system).h3().rule(false);

// Paragraph: body / quote / list
Paragraph::new("Body wrap…", &system).reading().paint(area, buf);
Paragraph::quote("Cited line…", &system).paint(area, buf);
Paragraph::list_item("Bullet…", &system).paint(area, buf);
Paragraph::ordered_item("Step…", &system, 2).hanging(true);

// Measure before layout
let h = heading.measure_height();
let rows = paragraph.measure_height(width);
```

## Markdown

```rust
// Before
MarkdownBlock { kind: MarkdownBlockKind::Heading, text: "Plan" }

// After
MarkdownBlock::heading("Plan", HeadingLevel::H1)
// or
MarkdownBlock::new(MarkdownBlockKind::Paragraph, "body")

// project_plain_lines("# A\n## B") sets heading_level from hash depth
```

`MarkdownView` single-row viewport forces `rule(false)` on headings (multi-row
rules need multi-row block windows — host can paint `Heading::reading()` in a
taller rect).

## Hierarchy without color

| Level | Compact prefix | Reading rule |
|-------|----------------|--------------|
| H1 | `# ` | `═` / `=` under title |
| H2 | `## ` | `─` / `-` under title |
| H3 | `### ` | none by default |
