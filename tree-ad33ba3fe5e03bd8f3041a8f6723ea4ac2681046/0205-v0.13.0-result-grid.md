# 0205 — ResultGrid query result component

## Mission

Database / query result grid built on DataTable with typed cells, nulls, binary,
large text, row numbers, copy/export, column statistics, editable cells,
pagination/streaming, and query status. Cell detail and object inspection for
structured values. Very wide schemas and unknown row counts. Safe display /
redaction for secrets and binary. Integrates with QueryEditor results slot and
schema context.

Research: database clients, VisiData, TablePlus, SQL terminal tools.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DataTable` / `DataTableState` / `ColumnModel` / `VirtualWindow` / `LoadState` / `CopyPayload` | **Preserved** — ResultGrid embeds and paints through DataTable |
| `ObjectInspector` / `InspectorField` | **Preserved** — `result_row_to_inspector_fields` bridge |
| `QueryEditor` / `QueryResultSummary` | **Preserved** — `ResultQueryStatus::to_query_summary` / `ResultGridState::query_summary` |
| Host SQL drivers / clipboard / file export IO | **Never in TermRock** — outcomes only |
| `ResultGrid*` domain model | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    ResultGrid, ResultGridState, ResultColumn, ResultRow, ResultCell,
    ResultQueryStatus, ResultRedaction, ResultGridOutcome, DataColumnWidth,
    ObjectInspector, result_row_to_inspector_fields,
};

let schema = vec![
    ResultColumn::new("id", "ID").type_name("int8").not_null().pin_start(),
    ResultColumn::new("name", "Name").editable(),
    ResultColumn::new("token", "Token").secret(),
    ResultColumn::new("blob", "Blob").binary(),
];
let rows = [
    ResultRow::new(1, 1, &[
        ResultCell::integer("1"),
        ResultCell::text("alpha"),
        ResultCell::secret_value("…"),
        ResultCell::binary(128),
    ]),
];
let mut state = ResultGridState::with_schema(schema.clone());
state.set_status(ResultQueryStatus::Ready { total: Some(1), duration_ms: Some(5) }, 1);

// Inside QueryEditor results slot:
ResultGrid::new(&system, &schema, &rows)
    .title("results")
    .render(query_state.slots.results, buf, &mut state);
// Optional: query_state.set_results(state.query_summary());

// Input
let model = state.column_model();
let ids: Vec<u64> = rows.iter().map(|r| r.id).collect();
match state.handle_key(key, &model, &ids) {
    ResultGridOutcome::ExportRequested { format, .. } => { /* host export */ }
    ResultGridOutcome::InspectRequested { row, column } => {
        // ObjectInspector::new(&result_row_to_inspector_fields(...), &system)
    }
    ResultGridOutcome::PageNext => { /* host fetch next page */ }
    ResultGridOutcome::EditCommitted { row, column, text } => { /* write-back */ }
    _ => {}
}
```

### Keys (on top of DataTable)

| Key | Action |
|-----|--------|
| Ctrl+E / Ctrl+Shift+E | Export TSV / CSV (window) |
| Ctrl+J | Export JSON request |
| Ctrl+I | Inspect cell/row |
| Ctrl+D | Cell detail (large text) |
| Ctrl+Shift+U | Toggle secret reveal (host-gated) |
| Ctrl+G | Toggle stats strip |
| Ctrl+N / `]` · Ctrl+P / `[` | Page next / prev |
| Ctrl+R | Refresh projection |
