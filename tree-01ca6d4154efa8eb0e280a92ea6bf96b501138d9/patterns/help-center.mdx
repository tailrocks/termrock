## Classification and composition

Composed public building blocks: `CommandEntry`, `HelpEntry`, `KeyboardHelp`, `List`, `ListRow`, `MarkdownBlock`, `MarkdownView`, `Panel`, `SearchInput`, `StatefulWidget`, `StatusBar`, `StatusRegion`, `StatusSlot`, `Widget`.

## Workflow

- `↑↓ select`: move visible focus, selection, pane, or hierarchy state for the next action.
- `Enter open`: invoke the focused public state-machine action and inspect its typed request.
- `/ filter`: focus the real field and edit its persistent Unicode-safe draft.
- `Tab panes`: move visible focus, selection, pane, or hierarchy state for the next action.
- `D diagnostics`: forward this normalized action to the mounted public pattern state.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.
