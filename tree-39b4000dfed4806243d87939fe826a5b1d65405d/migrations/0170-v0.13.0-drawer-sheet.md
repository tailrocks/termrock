# 0170 — Drawer and Sheet redesign

## Mission

Edge-mounted secondary surfaces for responsive inspectors, task rails, filters,
and details — left/right/top/bottom, modal/non-modal, resizable depth, focus
trap, opener restoration, nested overlays, compact handles, no-motion fallback,
fullscreen promotion on tiny terminals. Hosts preserve underlying view selection
and scroll.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DRAWER_OVERLAY_ID` | **Preserved** |
| `place_drawer`, `open_drawer_overlay`, `dismiss_drawer_overlay` | **Preserved** (default right/modal) |
| `Drawer::new(title, system)` + `Widget` | **Preserved** (richer chrome + slots) |
| Thin `Drawer` / `DrawerState` in `menu_nav` | **Deleted** → `widgets/drawer.rs` |
| `DrawerState::{open,is_open,handle_key Esc}` | **Preserved** (expanded outcomes) |
| `DrawerEdge`, modality, presentation, resize, slots | **Added** |
| `Sheet` / `SheetState` (bottom default) | **Added** |
| `PlacementPrefer::{DrawerTop,DrawerBottom}` | **Added** (overlay_stack) |
| Sidebar `open_drawer_overlay` / AppShell drawers | **Unchanged** (still `OverlaySpec::drawer`) |

## Consumer edits

```diff
  use termrock::widgets::{Drawer, DrawerState, open_drawer_overlay, DRAWER_OVERLAY_ID};
+ use termrock::widgets::{
+     Drawer, DrawerState, DrawerEdge, DrawerModality, DrawerPresentation, Sheet,
+     place_drawer_on_edge, open_drawer_configured, open_drawer_nested_overlay,
+ };

  let mut state = DrawerState::new();
  state.open();
+ state.set_edge(DrawerEdge::Right); // Left | Right | Top | Bottom
+ state.set_modality(DrawerModality::NonModal); // keep main selection interactive
+ state.set_depth(36);
+ state.set_motion(Motion::Off); // ASCII handle / no-motion chrome

- Widget::render(&Drawer::new("Settings", &system), area, buf);
+ Drawer::new("Inspector", &system)
+     .footer(Some("esc · [ ] resize"))
+     .paint(area, buf, &mut state);
+ // Host content: state.body_area() — do NOT clear main list selection/scroll

+ // Sheet (bottom):
+ let mut sheet = DrawerState::sheet();
+ Sheet::new("Actions", &system).paint(area, buf, &mut sheet);

+ // Nested under drawer:
+ open_drawer_nested_overlay(&mut stack, bounds, size, DrawerEdge::Right, Some("main"));
```

### Edges & placement

| Edge | Overlay prefer |
|------|----------------|
| Left | `DrawerStart` |
| Right | `DrawerEnd` (default) |
| Top | `DrawerTop` |
| Bottom | `DrawerBottom` (Sheet default) |

### Modality

| Mode | Trap | Backdrop | Outside |
|------|------|----------|---------|
| Modal (default) | yes | Dim | dismiss |
| NonModal | no | none | dismiss |

### Resize

- Keyboard: `[` / `]` ±2 depth (horizontal edges)
- Mouse: drag handle band
- Host re-opens / reflows stack with new `overlay_size`

### Stories

- `drawer/basic`, `left`, `sheet`, `non-modal`, `narrow`, `unicode`
