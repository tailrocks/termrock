# 0070 — ObjectInspector cursor vs scene focus

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `ObjectInspectorOutcome::FocusChanged` | `ObjectInspectorOutcome::CursorMoved` |
| `ObjectInspectorState::focus` (primary) | `cursor` / `cursor()` (`focus()` deprecated) |
| Ungated keys | `accepts_input` / `set_accepts_input` |
| `ObjectInspector::new(…, tokens)` paint-only | `system` + `focused` / `ascii` / `colorless` |
| Immutable `render(..., &state)` | `render(..., &mut state)` (hit geometry + scroll) |

## Added

| API | Role |
|-----|------|
| `ObjectInspectorOutcome::Scrolled` | Reserved / scroll feedback path |
| `ObjectInspector::focused` / `ascii` / `colorless` | Surface chrome + a11y |
| `handle_intent` / `default_inspector_intent` | Intent-first nav |
| `handle_mouse` | Click / wheel |
| `set_cursor` / `offset_y` / `accepts_input` | Host integration |
| Non-color cursor / empty marks | Accessibility |
| `ScrollAreaState::set_offset_y` | Cursor-follow (shared) |

## Consumer edits

```rust
// Before
ObjectInspectorOutcome::FocusChanged { index } => …
let i = /* private focus */;
ObjectInspector::new(&fields, &tokens).render(area, buf, &state);

// After
ObjectInspectorOutcome::CursorMoved { index } => …
let i = state.cursor();
state.set_accepts_input(scene.is_focused(INSPECTOR_ID));
ObjectInspector::new(&fields, &system)
    .focused(true)
    .ascii(false)
    .render(area, buf, &mut state);
```

```rust
// Intent path (optional)
if let Some(intent) = default_inspector_intent(key) {
    let _ = state.handle_intent(intent, fields.len());
}
```
