# Full-row diff semantic tints

Added and removed diff lines now paint their semantic background across the
complete available row, including unused trailing cells. Content, navigation,
folding, line-number, split/unified, ASCII, and colorless contracts are
unchanged. Remove consumer-owned per-glyph background patches; configure
`Role::DiffAdded` and `Role::DiffRemoved` instead.

Validate with `cargo nextest run -p termrock diff quantize` and `mise run gate`.
