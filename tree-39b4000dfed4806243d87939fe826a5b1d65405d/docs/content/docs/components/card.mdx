## Usage

The Code view above and this source excerpt use the exact paint setup registered for `card/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn card_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::widgets::Card;
    let body = Card::new(system)
        .title("Latency")
        .description("p99 over last hour")
        .footer("dashboard")
        .paint(area, frame.buffer_mut(), None);
    if body.width > 2 {
        frame.buffer_mut().set_stringn(
            body.x,
            body.y,
            "42ms",
            usize::from(body.width),
            system.style(Role::TextStrong),
        );
    }
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
