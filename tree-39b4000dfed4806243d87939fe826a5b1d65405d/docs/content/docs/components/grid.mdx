## Usage

The Code view above and this source excerpt use the exact paint setup registered for `grid/columns`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn grid_columns_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::layout::{Grid, GridAutoFlow};
    use termrock::widgets::Panel;
    let layout = Grid::columns(3)
        .gaps(1, 1)
        .auto_row(termrock::layout::TrackSize::Fixed(4))
        .layout_flow(area, 6, GridAutoFlow::Row);
    for (i, r) in layout.cells.iter().enumerate() {
        if r.width == 0 {
            continue;
        }
        let labels = ["A", "B", "C", "D", "E", "F"];
        let _ = Panel::new(system)
            .title(labels.get(i).copied().unwrap_or("x"))
            .paint(*r, frame.buffer_mut(), None);
    }
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
