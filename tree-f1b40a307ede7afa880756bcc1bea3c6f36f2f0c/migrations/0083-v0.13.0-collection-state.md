# 0083 — CollectionState headless collection model

## Mission

Reusable headless collection state for lists, menus, pickers, radios (and later
trees/tables): stable IDs, disabled skip, virtualization metadata, reconcile,
optional hierarchy, no long-lived borrowed display data.

## Added

| API | Role |
|-----|------|
| `CollectionState<Id>` | Active cursor + offset/viewport/total |
| `CollectionItem` | Frame projection (id, enabled, label, parent) |
| `CollectionOutcome` | ActiveChanged / Scrolled / Ignored |

Composes `RovingFocusGroup` for movement/typeahead.

## Migrated (prove reuse ×3+)

| Component | Change |
|-----------|--------|
| `ListState` | Embeds `CollectionState`; `selected`/`offset` via collection |
| `MenuState` | `CollectionState<usize>` instead of bare roving |
| `RadioState` | `CollectionState` for active descendant |
| `PickerState` | Via `ListState.collection` |

## Consumer notes

```rust
use termrock::interaction::{CollectionItem, CollectionState};

let mut c = CollectionState::new();
let items = vec![
    CollectionItem::new("a", "Alpha"),
    CollectionItem::new("b", "Beta").enabled(false),
];
let _ = c.reconcile(&items);
let _ = c.move_next(&items);
assert_eq!(c.active(), Some(&"a")); // skipped disabled on next from a if starting a
```

### ListState

```rust
state.collection() // headless model
state.selected()   // == collection.active()
state.offset()     // viewport start
// ListState::new is no longer const
```

Labels are never stored in state — only ids + numbers.
