# 0108 — Separator semantic rules

## Mission

Semantic horizontal and vertical separators with optional labels: quiet / strong /
section-break / labeled / focus-zone recipes, ASCII + no-color glyphs, spacing
recipes for bands, no fake interactive semantics.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `SeparatorLine::horizontal/vertical` | **Preserve** as alias of `Separator` |
| `type Separator = SeparatorLine` | **Flipped** — `Separator` is canonical; `SeparatorLine` is alias |
| Hardcoded `"─"` / `"│"` without GlyphSet | **Deleted** in Separator paint path |
| `SeparatorVariant`, `SeparatorOrientation`, `SeparatorThickness` | **Added** |
| `Separator::label`, `section_break`, `focus_zone`, `preferred_cross_size` | **Added** |
| `register_semantic_if_labeled` | **Added** (labeled only, non-focusable) |
| HintBar / list `RowRole::Separator` | **Preserve** — different domains |

## API sketch

```rust
use termrock::widgets::{Separator, SeparatorVariant};
use termrock::style::DesignSystem;

let system = DesignSystem::default();

// Quiet horizontal (legacy)
Widget::render(&Separator::horizontal(&system), area, buf);
// same: SeparatorLine::horizontal(&system)

// Strong / section break / focus zone
Separator::horizontal(&system).strong().paint(area, buf);
Separator::horizontal(&system)
    .section_break()
    .with_density(system.density) // or Density::Compact
    .paint(band_area, buf); // prefer height 3

// Labeled
Separator::horizontal(&system).label("OR").paint(area, buf);

// Vertical
Separator::vertical(&system).focus_zone().paint(area, buf);

// Host layout: reserve cross size from recipe
let h = Separator::horizontal(&system).section_break().preferred_cross_size(); // 3
```

## Variants

| Variant | Glyph intent (Unicode / ASCII) | Role |
|---------|--------------------------------|------|
| Quiet | `─` / `-` · `│` / `|` | Border |
| Strong | `━` / `=` · `┃` / `|` | TextMuted |
| SectionBreak | same as Strong, band pad via spacing | TextMuted |
| Labeled | rule + centered label | Border + TextMuted label |
| FocusZone | `═` / `=` · `║` / `:` | Border (**not** BorderFocused) |

## Semantics

- Default: **no** semantic registration
- Labeled only: optional `register_semantic_if_labeled` → non-focusable Chrome landmark

## Consumer edits

```diff
- SeparatorLine::horizontal(&tokens)
+ Separator::horizontal(&system) // SeparatorLine still works (alias)
```
