# 0249 — AuthEntry login blocks + email-only path

## Mission

Close shadcn **login** blocks (login-01…05) on the existing AuthEntry peer:
document coverage, harden sign-in paths, and add **email-only / passwordless**
submit (`AuthEntryMode::EmailOnly`) for magic-link request UIs. Host owns
delivery and OAuth.

Matrix: `docs/design/shadcn-login-blocks-coverage.md`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `AuthEntry` SignUp / SignIn (0248) | **Preserved** — extended |
| Dual `LoginForm` paint fork | **Forbidden** — same composition |
| `AuthEntryMode::EmailOnly` · `email_only()` · `set_email_only()` · `passwordless` on `Submitted` | **Added** |
| Cover-image chrome | **N/A** — aside text only |

## Consumer API

```rust
use termrock::patterns::{AuthEntryState, AuthEntryOutcome, AuthEntryMode};

// Password login (login-01/03)
let mut st = AuthEntryState::sign_in();
// Ctrl+F → SecondaryAction { id: "forgot-password" }
// Ctrl+O → SecondaryAction { id: "oauth:default" }
// Ctrl+E → EmailOnly

// Email-only / magic-link request (login-05)
let mut st = AuthEntryState::email_only();
match st.handle_key(key) {
    AuthEntryOutcome::Submitted {
        mode: AuthEntryMode::EmailOnly,
        identity,
        passwordless: true,
        ..
    } => { /* host send magic link to identity */ }
    _ => {}
}
```

### Breaking note

`AuthEntryOutcome::Submitted` gains `passwordless: bool`. Update match arms.
