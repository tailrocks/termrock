# 0042 — Capability-aware preview host lifecycle

## Canonical addition

`CapabilityPreviewHost` owns generation-safe placement planning:

- `bump_generation` / `complete_async` (reject stale)
- `place_image` / `place_resource_preview`
- `session_commands` → `MediaSessionCommand::{Replace, Delete, Clear}`
- `PreviewPresentation::{CellFallback, Kitty, ITerm2, Sixel}`

`patterns::wire_resource_preview` links `ResourceBrowserSlots` → host.

`ImageSurface` / `ImageMeta` paint cell fallback with `pending` / `stale` /
`generation` lifecycle flags. `ImageProtocol::from_presentation` bridges host
plans. `protocol_emission_hint` is documentation only — never emit from render.

TermRock never emits terminal protocol bytes.

## Consumer edits

```rust
let mut host = CapabilityPreviewHost::truecolor(system).protocols(true, false, false);
host.bump_generation();
host.begin_frame();
host.place_image(area, "img.png", true);
// async done:
if host.complete_async(gen, "img.png") {
    for cmd in host.session_commands() { /* emit OSC */ }
}
```

Resource browser:

```rust
let slots = layout_resource_browser(area, config);
wire_resource_preview(&mut host, &slots, Some(id), pending, selection_changed);
```
