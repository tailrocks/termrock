# 0141 — NumberInput numeric field

## Mission

Numeric field for forms and settings: integer/decimal kinds, locale-independent
`f64` storage, draft text separate from committed value, min/max/step, units,
empty and intermediate invalid states, steppers and wheel, overflow clamp, and
SliderBounds composition.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` / `TextInputState` | **Preserved** — draft buffer composition |
| `Slider` / `SliderBounds` | **Preserved** — shared snap via `NumberConstraints::from_slider` |
| `Field` / `Form` | **Preserved** — host projects NumberInput into field body |
| `NumberInput*` | **Added** |
| `NumberKind` / `NumberConstraints` / `NumberParse` / `NumberValidity` | **Added** |

## Consumer edits

```rust
use termrock::widgets::{
    NumberConstraints, NumberInput, NumberInputOutcome, NumberInputState, NumberKind,
    SliderBounds,
};

let mut state = NumberInputState::new()
    .with_kind(NumberKind::decimal2())
    .with_constraints(NumberConstraints::bounded(0.0, 100.0, 0.5))
    .with_value(12.5);
state.set_focused(true);

match state.handle_key(key) {
    NumberInputOutcome::ValueChanged { value } => { /* live bind */ let _ = value; }
    NumberInputOutcome::Submitted { value } => { /* form submit */ let _ = value; }
    NumberInputOutcome::Changed => { /* draft only */ }
    NumberInputOutcome::ClipboardPasteRequest => {
        let _ = state.insert_str(&host.paste());
    }
    _ => {}
}

// Slider dual-control
let bounds = SliderBounds::new(0.0, 100.0, 0.5);
state.set_from_slider(bounds, slider_value);
let slider_value = state.to_slider_value(bounds);

NumberInput::new("Opacity", &system)
    .unit("%")
    .show_steppers(true)
    .ascii(true);
```

### Draft vs committed

| Phase | Draft text | `value()` |
|-------|------------|-----------|
| Idle | mirrors value | committed |
| Typing | user edit | unchanged until commit |
| Enter / blur / step | reformatted | updated (clamped/snapped) |
| Esc | restored from value | unchanged |

### Keys

| Chord | Action |
|-------|--------|
| Up / Down | ± step |
| PageUp / PageDown | ± 10 steps |
| Enter | commit + Submitted |
| Esc | cancel draft |
| +/- steppers / wheel | step |
