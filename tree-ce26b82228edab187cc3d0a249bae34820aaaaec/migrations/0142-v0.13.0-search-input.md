# 0142 — SearchInput specialized search field

## Mission

Standalone search field for tables, logs, quick-open, palettes, and inspectors:
query editing, clear, history, leading filter metadata, status projection,
command/filter/goto syntax detection, and **debounced application messages
without embedding async work**.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` / draft editing | **Preserved** — composed as query buffer |
| `Picker` / `CommandPalette` query | **Preserved** — full list composition; may embed SearchInput later |
| `SettingsShellState::search: String` | **Preserved** — hosts may migrate to SearchInput |
| `SearchInput*` / `SearchStatus` / `SearchSyntax` / `SearchFilterChip` | **Added** |
| Debounce via `poll(FrameTick)` | **Added** — no threads/timers in widget |

## Consumer edits

```rust
use std::time::Duration;
use termrock::runtime::FrameTick;
use termrock::widgets::{
    SearchFilterChip, SearchInput, SearchInputOutcome, SearchInputState, SearchStatus,
};

let mut state = SearchInputState::new()
    .with_debounce(Duration::from_millis(150))
    .with_history_limit(32);
state.set_focused(true);

// keys
match state.handle_key(key) {
    SearchInputOutcome::Changed => { /* optional live hint */ }
    SearchInputOutcome::Submitted { query } => { /* enter */ let _ = query; }
    SearchInputOutcome::Cleared => { /* esc nonempty / × */ }
    SearchInputOutcome::Cancelled => { /* esc empty — dismiss */ }
    SearchInputOutcome::CompletionRequested => { /* open candidates */ }
    SearchInputOutcome::HistoryRecalled { query } => { let _ = query; }
    SearchInputOutcome::FilterChipActivated { id } => { let _ = id; }
    SearchInputOutcome::ClipboardPasteRequest => {
        let _ = state.insert_str(&host.paste());
    }
    _ => {}
}

// each frame — host owns async filter work
match state.poll(frame_tick) {
    SearchInputOutcome::DebouncedQuery { query } => host.start_search(query),
    _ => {}
}

// project status after host search completes
SearchInput::new(&system)
    .filters(&[SearchFilterChip::new("ext", "rs")])
    .status(SearchStatus::Results { count: 12 })
    .placeholder("Search…");
```

### Escape semantics

1. Non-empty query → clear → `Cleared`
2. Empty query → `Cancelled` (dismiss host surface)

### Syntax

| Prefix | `SearchSyntax` |
|--------|----------------|
| (none) | `Plain` |
| `>` | `Command` |
| `/` | `Filter` |
| `:` | `Goto` |

Payload via `state.syntax_payload()`.
