# WorkingStateCard

Non-invasive “what is the agent doing now” card. Host supplies a **public
summary** only — never private chain-of-thought.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

<TerminalPreview story="working-state-card/basic" interactive caption="WorkingStateCard · working-state-card/basic — Ghostty truecolor focus surface" />

## When to use / when not

| Use WorkingStateCard | Prefer |
|----------------------|--------|
| Current turn work status | — |
| Multi concurrent ops strip | [ActivityShelf](/docs/handbook) |
| Raw reasoning chrome | ThinkingBlock (host policy) |
| Session-level chrome | [AgentStatusHeader](/docs/handbook/agent-status-header) |

## Phases

Planning · Searching · Editing · Running · Waiting · Reviewing

## Presentation

| Form | Role |
|------|------|
| Expanded | Card with summary, files, inspect/cancel |
| Collapsed | One line + `to_activity_item()` for ActivityShelf |
