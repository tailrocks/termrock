# LogStream

O(visible) paint over a **consumer-owned** line projection. TermRock owns scroll
offset, follow/detach chrome, search/level filters, selection/bookmarks, and
line recipes — not the history buffer.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use LogStream | Prefer |
|---------------|--------|
| Live/tail logs (stern/k9s-class) | — |
| Multi-source projected windows | — |
| Single local append+evict buffer | [LogPane](/docs/components/log-pane) (project via `log_lines_from_plain`) |
| Structured k8s/agent events | [EventStream](/docs/handbook/event-stream) |
| Chat/agent turns | [Transcript](/docs/handbook/transcript) |
| Chronological recipes | [Timeline](/docs/handbook/timeline) |

## Outcomes

- `Ignored`
- `Scrolled { offset }` — moved while already pinned
- `Detach` / `Follow` — left or re-attached to the tail
- `SelectionChanged { ids }` — multi-select
- `Copy { text }` / `Export { text }` — host owns clipboard/file I/O
- `BookmarkToggled { id, on }`
- `SearchChanged` / `LevelFilter` / `HScrolled` / `Cancelled` / `AckDropped`

## Focus law

| Concern | Owner |
|---------|--------|
| Surface focus | Host / InteractionScene |
| Scroll + follow + unread | `LogStreamState` → `ScrollAreaState` |
| Line buffer / history bound | Consumer (or LogPane) |
| Copy / export side effects | Consumer |

## Recipes and wrap

| Recipe | Layout |
|--------|--------|
| `Detailed` (default) | timestamp · source · severity · body |
| `Compact` | severity + body |

| Wrap | Behavior |
|------|----------|
| `Clip` (default) | h-scroll with `h`/`l` |
| `Wrap` | soft-wrap (toggle `w`) |

## Non-color

- Levels: `i`/`!`/`x` or ASCII `I`/`W`/`E` / letters `TDIWE`
- Follow chip: `↓ follow` / `v follow`; unread `N new`
- Dropped / batch / reconnect on chip or banner
- Empty: `∅` / `[ ]`
- Bookmark: `★` / `*`
- Cursor gutter: `›` / `>`

## Intents and product chords

`default_log_stream_intent` — j/k, arrows, Home/End, page (no Space).

| Chord | Action |
|-------|--------|
| `f` | Toggle follow |
| Space | Multi-select |
| `/` | Search |
| `[` | Level floor |
| `m` | Bookmark |
| `c` | Copy |
| `C-e` | Export filtered |
| `b` | Ack drop/reconnect |
| `w` / `d` | Wrap / recipe |

## Responsive

| Width | Layout |
|-------|--------|
| ≥ 36 | detailed timestamp + source |
| 16–35 | compact severity + body |
| &lt; 16 | body only |
| height ≥ 2 | follow / unread / filter chip |

## Basic example

```rust
use termrock::{
    style::DesignSystem,
    widgets::{LogLevel, LogLine, LogStream, LogStreamState},
};

let system = DesignSystem::default();
let lines = [
    LogLine::new("1", LogLevel::Info, "ready")
        .timestamp("12:00:00")
        .source("main"),
];
let mut state = LogStreamState::new();
state.on_append(1, 8);
// LogStream::new(&lines, &system).title("app.log").focused(true)
//     .render(area, buf, &mut state);
let _ = (system, lines, state);
```
