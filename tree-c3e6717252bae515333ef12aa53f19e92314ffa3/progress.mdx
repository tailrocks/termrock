## Usage

```rust
use termrock::widgets::{Progress, ProgressBar, ProgressBarState, ProgressKind, ProgressRecipe};

Progress::new(ProgressKind::Determinate { fraction: 0.72 }, &system)
    .label("Indexing")
    .paint(area, buf);

let mut state = ProgressBarState::transfer(12_000_000, 30_000_000);
state.set_label("Download");
state.set_rate(Some(2_000_000.0));
state.recompute_eta();
state.set_recipe(ProgressRecipe::Detailed);
ProgressBar::paint_state(&system, area, buf, &mut state, tick, motion);
```

## State and typed outcomes

The widget owns deterministic paint and layout. The host owns all surrounding state and effects; this demo intentionally exposes no fake cursor, click, or keyboard behavior.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.

## Test recipe
