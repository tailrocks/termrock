# QueryEditor

Multiline query workbench for SQL, logs, search DSLs, and structured queries.
TermRock owns draft editing, focus zones, run/stop chrome, parameters, and
typed **requests**. Host owns language services, execution, formatting, and
result grids.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use QueryEditor | Prefer |
|-----------------|--------|
| DB / log / metrics query pane | — |
| Agent chat prompt | [PromptComposer](/docs/handbook/prompt-composer) |
| Plain notes / forms | [TextArea](/docs/handbook/text-area) |
| Result table only | [DataTable](/docs/handbook/data-table) (future ResultGrid) |

## Ownership

| Concern | Owner |
|---------|--------|
| Draft, cursor, selection, undo | `TextAreaState` inside `QueryEditorState` |
| Completer, parser, formatter, executor | Host |
| Result rows / types / paging | Host DataTable (or ResultGrid) in `slots.results` |
| Persist history / saved queries | Host via outcomes |

## Draft survival

Moving focus to **Results** / **Diagnostics** / **Parameters** never clears
the draft or cursor. Only `accepts_input` and `focus` change. Same rule for
completion overlays and help modals.

## Outcomes (requests)

- `RunRequested` · `StopRequested`
- `FormatRequested` · `SaveQueryRequested` · `OpenSavedQueries`
- `OpenHistory` · `HistoryApplied`
- `CompletionRequested` · `CompletionCommitted` · `CompletionClosed`
- `JumpToDiagnostic` · `ParameterEditRequested`
- `OpenKeyboardHelp` · `FocusChanged` · `ModeChanged` · fullscreen

## Integrate

| Piece | How |
|-------|-----|
| CompletionMenu | On `CompletionRequested`, host opens menu; commit → insert |
| CodeFrame / Diagnostic | Pass diagnostics to paint; jump via labels |
| KeyboardHelp | Seed with `query_editor_help_entries()` + live keymap |
| HistoryPicker | `OpenHistory` / `saved_queries_to_history` |
| DataTable | Paint into `state.slots.results` after workbench render |

## Keys

| Key | Action |
|-----|--------|
| Ctrl+R / Ctrl+Enter | Run |
| Ctrl+Shift+S | Stop |
| Ctrl+F · Ctrl+S · Ctrl+H | Format · save · history |
| Ctrl+Space | Completion |
| Ctrl+J · Ctrl+1..4 | Focus zones |
| Ctrl+M · Ctrl+Shift+F | Mode · fullscreen |
| Ctrl+? | Help |
