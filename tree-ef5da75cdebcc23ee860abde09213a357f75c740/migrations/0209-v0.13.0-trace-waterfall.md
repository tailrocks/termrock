# 0209 — TraceWaterfall span latency visualization

## Mission

Hierarchical span and latency visualization for distributed traces and
agent/tool execution: nested spans, duration bars, critical path, status,
service/actor, search, filters, zoom, selection, details. Readable ASCII
fallback and exact time labels. Virtualize large traces; preserve horizontal
time navigation. Hierarchy navigation distinct from timeline scrolling.
Compose with ObjectInspector and Timeline.

Research: trace viewers, Chrome DevTools waterfall, agent activity timelines.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Timeline` / `TimelineEvent` / `TimelineStatus` | **Preserved** — chronological list; `span_to_timeline_event` bridge |
| `ObjectInspector` / `InspectorField` | **Preserved** — `span_to_inspector_fields` |
| `Tree` | **Preserved** — generic hierarchy; waterfall owns time axis |
| Trace collectors / OTLP | **Never in TermRock** — host projects spans |
| `TraceWaterfall*` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    TraceWaterfall, TraceWaterfallState, TraceSpan, TraceSpanStatus,
    span_to_inspector_fields, format_trace_duration_ms, ObjectInspector,
};

let spans = [
    TraceSpan::new("root", "HTTP GET /api", 0, 420).service("gateway").branch().expanded().critical(),
    TraceSpan::new("db", "SELECT users", 50, 180).parent("root").service("postgres").depth(1).critical(),
    TraceSpan::new("tool", "tool:fetch", 240, 150).parent("root").service("agent").depth(1).error("timeout"),
];
let mut state = TraceWaterfallState::with_selected("db");
TraceWaterfall::new(&spans, &system).title("req").render(area, buf, &mut state);

// Details side panel:
// ObjectInspector::new(&span_to_inspector_fields(span), &system)
```

### Keys

| Key | Action |
|-----|--------|
| j/k · page · home/end | Hierarchy selection |
| h/l | Hierarchy: collapse/expand · Timeline mode: pan time |
| Ctrl+\ | Toggle Hierarchy / Timeline nav |
| [ ] | Pan time window |
| Ctrl+= / Ctrl+- / Ctrl+0 | Zoom in / out / fit |
| / | Filter (ancestor retention) |
| Ctrl+P | Critical-path only |
| Enter · i | Expand branch / details |
| c | Center selected in time window |
| Ctrl+T | Timeline export request |
| Shift+wheel | Pan time |
