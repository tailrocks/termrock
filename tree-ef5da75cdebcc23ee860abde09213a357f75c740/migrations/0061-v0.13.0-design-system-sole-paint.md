# 0061 — DesignSystem sole paint authority (pre-1.0 Break B)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `style::Theme` | `style::RolePalette` |
| `style::DesignTokens` | `style::DesignSystem` |
| `widgets::PanelEmphasis` | `style::PanelChrome` (re-exported from `widgets`) |
| Widget constructors taking `&Theme` and/or `&DesignTokens` | `&DesignSystem` only |
| `PromptComposer::new(tokens, theme)` dual paint args | `PromptComposer::new(system)` |
| `quantize_theme` | `quantize_palette` |
| `theme_for_appearance` | `palette_for_appearance` |
| Nested `DesignSystem { tokens: DesignTokens }` | Flat `DesignSystem` fields |

No deprecated aliases are provided. This is a hard break.

## Canonical replacement

`DesignSystem` is the **sole paint authority** passed down the widget tree:

```rust
pub struct DesignSystem {
    pub palette: RolePalette,       // was Theme
    pub density: Density,
    pub motion: Motion,
    pub glyphs: GlyphSet,
    pub spacing: SpacingScale,
    pub selection: SelectionChrome,
    pub capability: ColorCapability,
}

impl DesignSystem {
    pub fn phosphor() -> Self { /* … */ }
    pub fn from_palette(palette: RolePalette) -> Self { /* … */ }
    pub fn density(self, d: Density) -> Self { /* … */ }
    pub fn style(&self, role: Role) -> Style { /* … */ }
    pub fn panel_recipe(&self, chrome: PanelChrome) -> PanelRecipe { /* … */ }
    pub fn list_row_recipe(&self, selected: bool, focused: bool, enabled: bool) -> ListRowRecipe { /* … */ }
    pub fn quantize(self, cap: ColorCapability) -> Self { /* … */ }
}
```

`RolePalette` is only the Role → Style map (construct with `RolePalette::tailrocks_phosphor()`, `slate()`, `with_role`, …).

## Consumer edits

### Before

```rust
use termrock::style::{Density, DesignTokens, Theme};
use termrock::widgets::{List, Panel, PanelEmphasis, PromptComposer};

let theme = Theme::default();
let tokens = DesignTokens::new(theme.clone(), Density::Comfortable);
Panel::new(&tokens).emphasis(PanelEmphasis::Focused);
List::new(&rows, &tokens);
PromptComposer::new(&tokens, &theme);
```

### After

```rust
use termrock::style::{Density, DesignSystem, PanelChrome};
use termrock::widgets::{List, Panel, PromptComposer};

let system = DesignSystem::phosphor().density(Density::Comfortable);
Panel::new(&system).chrome(PanelChrome::Focused); // or .emphasis(PanelChrome::Focused)
List::new(&rows, &system);
PromptComposer::new(&system);
```

Brand themes: build `RolePalette`, then `DesignSystem::from_palette(palette)`.

Monochrome / capability: `system.quantize(ColorCapability::Monochrome)`.

## Removed concepts

- Nested Theme ⊂ DesignTokens ⊂ DesignSystem dual/triple paint roots.
- Dual chrome enums (`PanelEmphasis` vs `PanelChrome`).
- Widget dual constructors that took both tokens and theme.

## Ownership changes

Paint recipes (panel, list row) live only on `DesignSystem`. Widgets must not hardcode phosphor RGB on public paint paths; brands retheme via `RolePalette` + `DesignSystem`.
