# 0255 — SegmentedMeter pie peers (selection, center, separators)

## Mission

Close shadcn **pie** chart TUI gaps on the existing part-to-whole meter:
honest width allocation (no zero-weight mass), selection highlight, optional
separators, and center caption for donut-text. Matrix:
`docs/design/shadcn-pie-charts-coverage.md`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `SegmentedMeter` continuous paint | **Preserved** — default no separators |
| `MeterSegment` | **Preserved** + `effective_weight` |
| Last-segment-gets-remaining inventing mass for zero-weight tail | **Fixed** via `allocate_segment_widths` |
| `allocate_segment_widths` · `selected` highlight · `center` · `separators` | **Added** |

## Consumer API

```rust
use termrock::widgets::{SegmentedMeter, MeterSegment, allocate_segment_widths};

let segs = [
    MeterSegment::new("a", 2.0, Role::Success),
    MeterSegment::new("b", 1.0, Role::Danger),
    MeterSegment::new("skip", 0.0, Role::Accent),
];
SegmentedMeter::new(&segs, &system)
    .selected(1)
    .center("33%")
    .show_labels(true)
    .render(area, buf);

// Pure width helper
let cols = allocate_segment_widths(&[2.0, 0.0, 1.0], 12);
assert_eq!(cols[1], 0);
```
