# 0117 — Icon & semantic Glyph catalog

## Mission

Replace scattered Unicode literals with a semantic glyph system: named
[`Glyph`] values resolve under [`GlyphSet`] profiles (Unicode / ASCII /
Enhanced), with width guarantees, accessible meanings, and an [`Icon`] paint
primitive. Glyphs must never be the only representation of critical meaning.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `GlyphSet::{Unicode,Ascii}` | **Preserved** (+ **`Enhanced`**) |
| `GlyphSet::disclosure_*` / `rule` / `check_*` / `loading` | **Preserved** — now resolve via catalog |
| `GlyphSet::{rule_strong,rule_v,ellipsis,bullet,disabled_mark,resolve}` | **Added** |
| `Glyph`, `GlyphGroup`, `GlyphResolved`, `glyph_by_id` | **Added** (style) |
| `Icon`, `IconParts` | **Added** (widgets) |
| StatusBar / Panel / Toolbar / Separator / Paragraph prefixes | **Migrated** — use catalog helpers |
| Ad-hoc `"▸"` / `"…"` literals in chrome | **Migrate** → `Glyph` / `GlyphSet` helpers |

## API sketch

```rust
use termrock::style::{Glyph, GlyphGroup, GlyphSet, DesignSystem};
use termrock::widgets::Icon;

let system = DesignSystem::default().glyphs(GlyphSet::Ascii);

// Resolve
let r = Glyph::DisclosureClosed.resolve(system.glyphs);
assert_eq!(r.text, ">");
assert_eq!(r.meaning, "collapsed"); // always non-empty
assert_eq!(r.cols, 1);

// Paint with optional label (critical meaning not glyph-only)
Icon::new(Glyph::Success, &system)
    .role(Role::Success)
    .label("ready")
    .min_width(2)
    .paint(area, buf);

// Browser
for g in Glyph::in_group(GlyphGroup::Status) {
    let _ = (g.id(), g.meaning(), g.resolve(system.glyphs));
}
```

## Profiles

| Profile | Use |
|---------|-----|
| Unicode | Default box / status glyphs |
| Ascii | Capability-safe (`>`, `[x]`, `...`) |
| Enhanced | Richer file/status cells (may be 2 cols) |

## Width

`GlyphResolved::cols` is the nominal alignment budget; `display_width()` measures
actual cells. `Icon::min_width` pads glyph columns for tables/toolbars.
ASCII checks are 3 columns (`[x]` / `[ ]`).

## Critical meaning rule

Every `Glyph::meaning()` is non-empty English. Prefer `Icon::label(...)` for
status/action icons. Hosts must not key policy solely on painted codepoints.
