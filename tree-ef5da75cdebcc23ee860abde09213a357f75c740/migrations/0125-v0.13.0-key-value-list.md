# 0125 — KeyValueList

## Mission

Compact metadata presentation for settings, object summaries, dialogs, and
detail panes: aligned keys, wrapped values, nested groups, copyable values,
status tones, links, secret redaction, two-column → stacked contraction, dense
and reading recipes.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DetailTable` / `DetailRow` / `DetailCapability` | **Preserved** — selection-heavy dialog details |
| `ObjectInspector` | **Preserved** — tree/object projection |
| `KeyValueList`, `KvEntry`, density/layout recipes | **Added** — canonical DescriptionList-style list |
| Dialog `DetailTable` embedding | **Preserved** — migrate to KeyValueList when no multi-select scroll needed |

## API sketch

```rust
use termrock::widgets::{
    KeyValueList, KeyValueListState, KvEntry, KvStatus, KvLayout, KeyValueListOutcome,
};

let entries = [
    KvEntry::group_header("id", "Identity"),
    KvEntry::pair("name", "Name", "termrock").copyable().annotation("crate"),
    KvEntry::pair("status", "Status", "active").status(KvStatus::Success),
    KvEntry::pair("token", "Token", secret).secret().copyable(),
    KvEntry::pair("docs", "Docs", "handbook").href("https://example.invalid"),
];

let mut state = KeyValueListState::new();
state.set_focused(true);

KeyValueList::reading(&entries, &system) // or ::dense
    .layout(KvLayout::Auto)
    .paint(area, buf, &mut state);

match list.handle_key(&mut state, key) {
    KeyValueListOutcome::Copy { text, .. } => { /* clipboard */ }
    KeyValueListOutcome::ActivateLink { href, .. } => { /* open */ }
    KeyValueListOutcome::SecretRevealed(id) => {}
    _ => {}
}
```

## Layout

| Mode | Behavior |
|------|----------|
| `Auto` | Columns when width ≥ density threshold; else stacked |
| `Columns` | Key + separator + wrapped value; annotation dropped when tight |
| `Stacked` | Key row, then value wrap, then annotation |

Primary value is always preferred over secondary annotation under contraction.
