# 0151 — FormWizard

## Mission

Multi-step setup/onboarding/connection/migration flows with validation gates,
optional steps, review, async checks, failure/retry, and saved progress.
Domain field values stay host-owned; FormWizard owns chrome, gates, and typed
outcomes only.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `blocks::FormWizard` / `FormWizardState { step, step_count, step_valid }` | **Deleted** from `blocks.rs` |
| `FormWizardOutcome::{Ignored, StepChanged { index }, BlockedInvalid, SubmitRequested, Cancelled}` | **Migrated** — expanded outcomes |
| `Form` / `Field` / `Fieldset` | **Preserved** — host paints into `body_area` |
| Inline stepper paint | **Added** (future Stepper may extract) |
| `FormWizard` module API | **Added** / redesigned |

## Consumer edits

```diff
- let mut state = FormWizardState::new(3);
- state.set_step_valid(false);
- match state.handle_key(key) {
-     FormWizardOutcome::StepChanged { index } => {}
-     FormWizardOutcome::BlockedInvalid => {}
-     FormWizardOutcome::SubmitRequested => {}
-     FormWizardOutcome::Cancelled => {}
-     _ => {}
- }
- FormWizard::new(&system, "Setup").render(area, buf, &state);

+ let mut state = FormWizardState::with_steps([
+     WizardStep::new("account", "Account"),
+     WizardStep::new("region", "Region").optional(true),
+     WizardStep::new("confirm", "Confirm"),
+ ])
+ .with_review(true);
+ // quick start still: FormWizardState::new(3)
+ state.set_focused(true);
+ state.set_step_valid(valid); // or set_gate(WizardGate::…)
+
+ match state.handle_key(key) {
+     FormWizardOutcome::StepChanged { to, reason, .. } => {
+         let _ = state.request_focus_field(); // first relevant field
+         let _ = (to, reason);
+     }
+     FormWizardOutcome::BlockedInvalid { message, .. } => {}
+     FormWizardOutcome::BlockedPending { .. } => {}
+     FormWizardOutcome::AsyncCheckRequested { step, generation } => {
+         host.check(step, generation);
+     }
+     FormWizardOutcome::ReviewOpened => {}
+     FormWizardOutcome::SubmitRequested => host.submit(),
+     FormWizardOutcome::Failed { message } => {}
+     FormWizardOutcome::RetryRequested { step } => {}
+     FormWizardOutcome::ProgressSaved { progress } => host.persist(progress),
+     FormWizardOutcome::Cancelled => host.close(),
+     _ => {}
+ }
+
+ // when async returns:
+ state.apply_async_result(generation, WizardGate::Valid);
+
+ FormWizard::new(&system)
+     .title("Setup")
+     .paint(area, buf, &mut state);
+ // host paints fields into state.body_area()
```

### Keys

| Key | Behavior |
|-----|----------|
| Enter / n / → | Next / review / finish |
| p / ← | Back (data preserved) |
| s | Skip optional |
| Ctrl+S | `ProgressSaved` snapshot |
| Esc | Cancel |
| r / Enter | Retry when failed |
