# 0200 — HexViewer virtualized binary inspector

## Mission

Virtualized binary inspector: offsets, configurable bytes per row, hex +
ASCII/Unicode interpretation, selection, search, bookmarks, endian-aware
value inspector, copy/export outcomes. Massive files via host-provided paging
([`HexWindow`]). Active byte and selection without color alone. Tiny-terminal
compact mode. Property tests for offsets and widths.

Research: hex editors, xxd, binary-analysis tools.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `CodeBlock` / `FullscreenViewer` | **Preserved** — text/source viewers |
| `VirtualList` / `Virtualizer` | **Preserved** — list virtualization (not byte pages) |
| `HexViewer` / `HexWindow` / `HexViewerState` | **Added** |
| Layout helpers (`row_for_offset`, …) | **Added** (public for hosts/tests) |
| `hex_viewer_bench` | **Added** |
| File I/O | **Never in TermRock** — host pages |

## Consumer API sketch

```rust
use termrock::widgets::{
    HexViewer, HexViewerState, HexWindow, HexEndian, hex_viewer_bench,
};

// Host maps file [page_start, page_start+len) into `data`
let window = HexWindow::new(page_start, &data, file_len);
let mut state = HexViewerState::new();
state.bytes_per_row = 0; // auto from width
// On HexViewerOutcome::PageNeeded { offset } → re-project window around offset

HexViewer::new(window, &system)
    .title("blob.bin")
    .render(area, buf, &mut state);
```

### Keys

| Key | Action |
|-----|--------|
| h/l j/k · arrows | Byte / row motion |
| Shift+motion / Space | Selection |
| / n N | Search hex or text · next/prev |
| b | Bookmark |
| e | Toggle endian |
| a | Cycle ASCII mode |
| w | Cycle bytes/row (8/16/32/auto) |
| i | Inspector strip |
| c / x / y | Copy hex · copy ASCII · export dump |
| g / G · Home/End · PgUp/Dn | File/row extremes |
