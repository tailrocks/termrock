# 0252 — Chart area fill (shadcn area charts peer)

## Mission

Close the primary TUI gap for [shadcn charts/area](https://ui.shadcn.com/charts/area):
**filled area under series** and **stacked area**, without dual paint paths.
Document full first-party chart demo coverage in
`docs/design/shadcn-charts-coverage.md`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Chart` line multi-series | **Preserved** — default `ChartFill::None` |
| `Sparkline` / `BarSeries` / `Histogram` / `Gauge` / `SegmentedMeter` | **Preserved** |
| `ChartFill` · `Chart::area` · `Chart::area_stacked` · `Chart::fill` | **Added** |
| Continuous gradient / polar radar / DOM tooltips | **N/A** or host |

## Consumer API

```rust
use termrock::widgets::{Chart, ChartSeries, ChartFill};

let series = [ChartSeries::new("cpu", &samples)];
// Area chart (fill under outline)
Chart::new(&series, &system).area().title("cpu").render(area, buf);

// Stacked area
let series = [
    ChartSeries::new("a", &a),
    ChartSeries::new("b", &b),
];
Chart::new(&series, &system)
    .fill(ChartFill::AreaStacked)
    .show_legend(true)
    .render(area, buf);
```
