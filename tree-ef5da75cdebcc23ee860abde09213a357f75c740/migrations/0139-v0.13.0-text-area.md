# 0139 — TextArea production multi-line editor

## Mission

Multi-line editor for forms, notes, prompts, and comments: grapheme-safe
editing, selection, undo/redo, word movement, indent, configurable soft wrap,
horizontal scroll, line numbers, ScrollArea dual-axis viewport, host clipboard
and external-editor / fullscreen outcomes, read-only and review variants,
cursor/scroll preservation through resize and reflow.

## Consumer edits

```diff
  match state.handle_key(key) {
      TextAreaOutcome::Changed => { /* repaint */ }
+     TextAreaOutcome::ClipboardCopy { text } => host.copy(text),
+     TextAreaOutcome::ClipboardCut { text } => host.copy(text),
+     TextAreaOutcome::ClipboardPasteRequest => {
+         let _ = state.insert_text(&host.paste());
+     }
+     TextAreaOutcome::ExternalEditorRequested => host.open_external_editor(state.text()),
+     TextAreaOutcome::FullscreenRequested => host.promote_fullscreen(),
      TextAreaOutcome::Cancelled => { /* dismiss */ }
      _ => {}
  }
```

```rust
// Soft wrap + line numbers + review chrome
TextArea::new(&system)
    .title("Notes")
    .line_numbers(true)
    .soft_wrap()
    .review()
    .placeholder("Write…");

state.set_wrap(TextWrap::Soft);
state.set_indent("    ");
state.select_all();
let _ = state.undo();
```

## Default key adapter (Emacs-style)

| Chord | Action |
|-------|--------|
| ←→↑↓ / Home/End / Page | Move (±Shift select) |
| Ctrl/Alt+←→ | Word move |
| Ctrl+A / C / X / V | Select all / copy / cut / paste request |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | Undo / redo |
| Tab / Shift+Tab | Indent / outdent line |
| Ctrl+E | External editor request |
| Ctrl+Shift+F | Fullscreen request |
| Enter | Newline |
| Esc | Clear selection, else Cancelled |

`PromptComposer` intercepts many Ctrl chords before TextArea and keeps a
separate undo/selection layer; standalone hosts use TextArea's stack.
