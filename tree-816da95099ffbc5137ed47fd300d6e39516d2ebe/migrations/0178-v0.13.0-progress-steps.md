# 0178 — ProgressSteps

## Mission

Pipeline and phase progress for builds, imports, migrations, and agent plans.
Statuses: queued, running, waiting, complete, skipped, warning, failed, retrying,
cancelled. Durations, verbs, details, retry actions. Interactive navigation is
explicit (vs passive live progress). Narrow terminals contract to a summary
line. Compose with Timeline and TaskRail via projections.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Stepper` / `StepStatus` / FormWizard | **Preserved** (form navigation chrome) |
| `Timeline` / `TaskRail` / `PlanReview` | **Preserved** (composition targets) |
| Prior ProgressSteps | **None** (greenfield) |
| `ProgressSteps`, `ProgressStep`, statuses, modes | **Added** |
| `progress_steps_as_timeline_events` / `as_list_rows` | **Added** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     ProgressSteps, ProgressStepsState, ProgressStep, ProgressStepStatus,
+     ProgressStepsMode, ProgressStepsPresentation, example_build_pipeline,
+     paint_progress_steps_as_timeline, progress_steps_as_list_rows,
+ };

+ let steps = example_build_pipeline(); // or host-owned Vec<ProgressStep>
+ let mut state = ProgressStepsState::new(); // passive
+ // Interactive recovery:
+ // let mut state = ProgressStepsState::interactive();
+ ProgressSteps::new(&steps, &system)
+     .title("Build")
+     .paint(area, buf, &mut state);

+ // Narrow auto-summary via width; or force:
+ state.set_presentation(Some(ProgressStepsPresentation::Summary));

+ // Compose:
+ paint_progress_steps_as_timeline(&steps, area, buf, &system);
+ let rows = progress_steps_as_list_rows(&steps);
+ // TaskRail::new(&rows, &system, "Tasks") …
```
