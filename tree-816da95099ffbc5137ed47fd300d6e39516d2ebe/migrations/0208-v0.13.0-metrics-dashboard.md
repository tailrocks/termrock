# 0208 — MetricsDashboard observability block

## Mission

Reusable dashboard composed from metric cards, charts (Sparkline/Gauge), alerts,
and time controls. Time range, refresh, comparison, thresholds, drill-down,
loading, partial failure, responsive grid. Trend/exception readability over
decoration. Keyboard spatial navigation and command palette actions. Narrow
terminals contract to vertical summary. **Public component APIs only.**

Research: btop, Grafana concepts, observability TUIs, operating dashboards.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Sparkline` / `Gauge` / `Chart` / `ScaleMode` / `VizGlyphSet` | **Preserved** — MetricsDashboard paints through them |
| `OpsDashboardState` / `layout_ops_dashboard` | **Preserved** — region router for table+log ops; different mission |
| `Card` / `Callout` | **Preserved** — optional host chrome; dashboard paints compact tiles |
| `CommandPalette` / `CommandEntry` | **Preserved** — `metrics_dashboard_commands` bridge |
| Scrape / PromQL / agents | **Never in TermRock** — outcomes only |
| `MetricsDashboard*` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    MetricsDashboard, MetricsDashboardState, MetricTile, MetricAlert,
    MetricAlertSeverity, MetricTileHealth, metrics_dashboard_commands,
    apply_metrics_command, CommandPalette,
};

static S: &[f64] = &[/* samples */];
static THR: &[f64] = &[70.0, 90.0];
let tiles = [
    MetricTile::new("cpu", "CPU", "42%").samples(S).thresholds(THR).delta("+2%", true),
    MetricTile::new("mem", "Memory", "71%").gauge(71.0).thresholds(THR)
        .health(MetricTileHealth::Warning),
    MetricTile::new("disk", "Disk", "—").failed("timeout"),
];
let alerts = [
    MetricAlert::new("a1", MetricAlertSeverity::Warning, "mem > 70%").metric("mem"),
];
let mut state = MetricsDashboardState::new();
MetricsDashboard::new(&tiles, &alerts, &system).title("ops").render(area, buf, &mut state);

// Ctrl+K → open palette with metrics_dashboard_commands()
// apply_metrics_command(&mut state, commands::REFRESH, &tiles)
```

### Keys

| Key | Action |
|-----|--------|
| Tab / Shift+Tab | Tiles ↔ Alerts ↔ Toolbar |
| hjkl / arrows | Spatial tile nav (grid-aware) |
| Enter | Drill-down focused tile / activate alert |
| Ctrl+R | Refresh |
| Ctrl+T / Ctrl+Shift+T | Time range next/prev |
| Ctrl+D | Cycle comparison |
| Ctrl+P | Pause auto-refresh |
| Ctrl+F | Retry failed tiles |
| Ctrl+K | Command palette request |
