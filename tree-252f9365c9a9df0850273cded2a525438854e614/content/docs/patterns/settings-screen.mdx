## Workflow

- `Tab cycle regions`: move visible focus, selection, pane, or hierarchy state for the next action.
- `↑↓ select/edit`: focus the real field and edit its persistent Unicode-safe draft.
- `/ search`: focus the real field and edit its persistent Unicode-safe draft.
- `Ctrl+B drawer`: forward this normalized action to the mounted public pattern state.
- `Ctrl+S save`: forward this normalized action to the mounted public pattern state.
- `? help`: forward this normalized action to the mounted public pattern state.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.

## When to use

| Use SettingsScreen | Prefer |
|--------------------|--------|
| Multi-category settings with search | Standalone Form / Sidebar |
| Theme + keybinding surfaces in one shell | ThemePicker / KeybindingRecorder alone |
| App settings with dirty / restart banners | Custom Workspace layout |

| Concern | Type |

## Minimal host loop

```rust
use termrock::patterns::{
    SettingsScreenState, SettingsScreenSurfaces, render_settings_screen,
    example_settings_categories, example_settings_appearance_fields,
};
use termrock::widgets::{Fieldset, BUILTIN_THEME_PRESETS};

let mut state = SettingsScreenState::new();
let nav = example_settings_categories();
let fields = example_settings_appearance_fields();
let fieldsets = [Fieldset::new("Appearance", &fields)];

render_settings_screen(buf, area, SettingsScreenSurfaces {
    system: &system,
    state: &mut state,
    nav: &nav,
    fieldsets: &fieldsets,
    theme_presets: BUILTIN_THEME_PRESETS,
    theme_paint: Some(&system),
    status_slots: &[],
    status_state: &mut status,
    section_title: "Appearance",
});
```
