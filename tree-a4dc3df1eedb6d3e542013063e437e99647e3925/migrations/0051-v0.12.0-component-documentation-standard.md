# 0051 — Component documentation standard

## Removed surface

None. Generated thin pages under `docs/content/docs/components/` remain the
API inventory view.

## Canonical addition

- **Standard:** `docs/design/component-documentation-standard.md`  
  Mandatory section order (purpose → install → examples → anatomy → ownership →
  outcomes → interaction → responsive → a11y → composition → mistakes → perf →
  testing → migration → related → app sketch).

- **Handbook (shadcn-depth pages):** `docs/content/docs/handbook/`  
  Applied to Button (ActionBar pattern), List, DataTable, Dialog,
  CommandPalette, PromptComposer, PermissionPrompt.

- **CI examples:** `crates/termrock/tests/documentation_examples.rs` mirrors
  handbook snippets with public APIs only.

### Writing rules

Explain *why* and *when*; never restate field names alone. Examples must compile.
