# 0162 — HistoryPicker

## Mission

Reusable recent-history selector for commands, prompts, searches, sessions, and
values: recency + pin, search, delete, metadata, groups, preview, redaction
hooks, draft preservation, and popover/fullscreen placement.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Picker` | **Preserved** — generic query+list |
| `SessionPicker` / `SessionItem` | **Preserved** — thin agent façade |
| PathInput / SearchInput / PromptComposer local history | **Preserved** — field-local Up/Down |
| CommandPalette query history | **Preserved** — palette-specific |
| `HistoryPicker*` | **Added** (greenfield) |

## Consumer edits

```diff
+ use termrock::widgets::{
+     HistoryEntry, HistoryKind, HistoryPicker, HistoryPickerOutcome, HistoryPickerState,
+     filter_history_entries, history_redaction_secret, open_history_picker_overlay,
+ };

+ let mut state = HistoryPickerState::new();
+ state.set_redaction(history_redaction_secret());
+ // open from composer:
+ let _ = state.open(Some(composer_draft.clone()));
+ let visible = filter_history_entries(&host_store, state.query_text());
+ match state.handle_key(key, &visible) {
+     HistoryPickerOutcome::Selected { value, .. } => {
+         composer_draft = value; // apply
+     }
+     HistoryPickerOutcome::Cancelled => {
+         if let Some(d) = state.take_draft() {
+             composer_draft = d; // restore
+         }
+     }
+     HistoryPickerOutcome::Deleted { id } => host.delete(id),
+     HistoryPickerOutcome::PinToggled { id, pinned } => host.set_pin(id, pinned),
+     HistoryPickerOutcome::QueryChanged { query } => {
+         // refilter / async
+     }
+     _ => {}
+ }
+ HistoryPicker::new(&visible, &system).paint(area, buf, &mut state);
```

### Privacy

- Mark entries `sensitive(true)`.
- Set `state.set_redaction(history_redaction_secret())` (or `MaskAll` / host display).
- List/preview paint uses redacted display; `Selected.value` remains full (host choice).

### Stories

- `history-picker/basic`, `search`, `redacted`, `draft`, `empty`, `ascii`
