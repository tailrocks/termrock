Database / query result component built on [DataTable](/docs/components/data-table).
Host projects a **visible window** of typed cells; TermRock paints safe display,
status/stats chrome, and emits export / inspect / page / edit **requests**.

## When to use / when not

| Use ResultGrid | Prefer |
|----------------|--------|
| SQL / analytics query results | — |
| Generic interactive grid | [DataTable](/docs/components/data-table) |
| Display-only moderate table | [Table](/docs/components/table) |
| Structured object tree | [ObjectInspector](/docs/components/object-inspector) |

## Ownership

| Concern | Owner |
|---------|--------|
| Execute query, page, decode types | Host |
| Safe null / binary / secret display | ResultGrid format helpers |
| Selection, sort chrome, virtual window | Embedded `DataTableState` |
| Clipboard / file export | Host via outcomes |

## Typed cells

`ResultCellKind`: Null · Bool · Integer · Float · Text · Binary · Json ·
Timestamp · Uuid · Secret · Other.

Binary never dumps raw bytes by default (`blob(N B)`). Secrets render as
`••••` until host allows `ResultRedaction::RevealSecrets`.

## ObjectInspector bridge

`result_row_to_inspector_fields(schema, row, redaction, ascii)` projects a row
into inspector fields for cell detail panels.

## Outcomes (requests)

- Export (CSV/TSV/JSON/Markdown) · Copy
- Inspect · Cell detail
- Page next/prev · Refresh · Retry
- Edit start/commit · Sort · Stats focus
- Reveal secrets toggle
