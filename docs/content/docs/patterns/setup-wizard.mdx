## Workflow

- `Enter/→ next`: invoke the focused public state-machine action and inspect its typed request.
- `← back`: forward this normalized action to the mounted public pattern state.
- `S skip optional`: forward this normalized action to the mounted public pattern state.
- `Esc cancel`: peel or cancel the current transient layer and preserve underlying state.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.

## When to use

| Use SetupWizard | Prefer |
|-----------------|--------|
| First-run product setup | Single-step Form / Dialog |
| Multi-phase onboarding with resume | FormWizard alone for generic multi-step |
| Inline setup in a pane | Fullscreen app root mode |

## Minimal host loop

```rust
use termrock::patterns::{
    SetupWizardState, SetupWizardSurfaces, example_setup_steps,
    example_capability_lines, render_setup_wizard,
};
use termrock::widgets::BUILTIN_THEME_PRESETS;

let mut state = SetupWizardState::from_steps(example_setup_steps())
    .with_title("First run");

render_setup_wizard(buf, area, SetupWizardSurfaces {
    system: &system,
    state: &mut state,
    fieldsets: &fieldsets_for_step,
    capabilities: &example_capability_lines(),
    summary_lines: &summary,
    welcome_title: "Setup",
    welcome_detail: "Configure once. Keyboard-first.",
    theme_presets: BUILTIN_THEME_PRESETS,
    theme_paint: Some(&system),
    permission: None,
});
```
