Source-owned onboarding block (migration `0238`). Composes **FormWizard** +
**Stepper** with step-kind body paint. Domain values and auth stay host-owned.

## When to use

| Use SetupWizard | Prefer |
|-----------------|--------|
| First-run product setup | Single-step Form / Dialog |
| Multi-phase onboarding with resume | FormWizard alone for generic multi-step |
| Inline setup in a pane | Fullscreen app root mode |

## Step kinds

Welcome · Capability · Account · Connection · Choices · Validation · Permission · Theme · Summary · Recovery · Custom

## Modes

- **Fullscreen** — root first-run with small safe margin  
- **Inline** — fill host pane  

## Laws

| Law | Detail |
|-----|--------|
| Safe cancel | Esc → confirm strip; never one-shot leave |
| Resume | `WizardProgress` chrome only |
| Keyboard-only | Enter/n next · p back · s skip · Ctrl+S save progress |
| No marketing splash | One-line welcome detail |
