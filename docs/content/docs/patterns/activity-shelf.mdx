## Classification and composition

**composite** · default grid 72×2

Composed public building blocks: `NotificationItem`, `SemanticStatus`, `StatusRegion`, `StatusSlot`, `ToastPriority`.

## Workflow

- `←→ select`: move visible focus, selection, pane, or hierarchy state for the next action.
- `Enter activate`: invoke the focused public state-machine action and inspect its typed request.
- `wheel navigate`: move the pattern-owned viewport without scrolling the documentation page.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.

## Migrated handbook guidance

# ActivityShelf

Glanceable strip of live/blocked operations. Prioritizes action-required and
blocked chips. Narrow widths collapse to summary or badge. Not a TaskRail.


## When to use / when not

| Use ActivityShelf | Prefer |
|-------------------|--------|
| Persistent active ops under transcript | — |
| Full task/subagent inventory | TaskRail / List |
| Ephemeral toasts only | Toast / NotificationCenter |
| Mode/connection chrome only | StatusBar slots |

## Density

| Width | Presentation |
|-------|----------------|
| ≥ 56 | Chips (glyph + title) |
| 36–55 | Icons only |
| 18–35 | One-line summary |
| < 18 | Badge count |
