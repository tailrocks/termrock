Reusable observability dashboard block. Host projects metric tiles and alerts;
TermRock lays out a responsive grid (or narrow summary), paints via public
`Sparkline` / `Gauge` APIs, and emits refresh / drill-down / time-range
**requests**.

## When to use / when not

| Use MetricsDashboard | Prefer |
|----------------------|--------|
| Ops / SRE metric overview | — |
| Table + log ops shell | `OpsDashboardState` / `layout_ops_dashboard` |
| Single chart | [Chart](/docs/components/chart) |
| Process list | [ProcessTable](/docs/patterns/process-table) |

## Ownership

| Concern | Owner |
|---------|--------|
| Scrape, query, aggregation | Host |
| Layout, focus, time/comparison chrome | `MetricsDashboardState` |
| Sparkline/Gauge raster | Public chart widgets |

## Partial failure

Each `MetricTile` has `MetricTileHealth` (`Ok` / `Warning` / `Danger` /
`Loading` / `Failed` / `Stale`). One failed tile does not blank the dashboard.

## Narrow terminals

Width ≤ 48 → `MetricsDashboardLayoutMode::Summary`: one line per metric
(`letter title value delta`).

## Keys

| Key | Action |
|-----|--------|
| Tab · hjkl | Zones · spatial tiles |
| Enter | Drill-down |
| Ctrl+R · Ctrl+T · Ctrl+D | Refresh · time · compare |
| Ctrl+K | Palette request |
