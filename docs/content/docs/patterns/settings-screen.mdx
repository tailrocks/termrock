Source-owned application block for a complete settings experience. Composes
public TermRock widgets only (migration `0237`).

## When to use

| Use SettingsScreen | Prefer |
|--------------------|--------|
| Multi-category settings with search | Standalone Form / Sidebar |
| Theme + keybinding surfaces in one shell | ThemePicker / KeybindingRecorder alone |
| App settings with dirty / restart banners | Custom Workspace layout |

## Canonical chrome

| Concern | Type |
|---------|------|
| Categories | `Sidebar` / `NavItem` |
| Search | `SearchInput` |
| Fields | `Form` / `Field` / `Fieldset` |
| Theme | `ThemePicker` body mode |
| Keybindings | `KeybindingRecorder` body mode |
| Help | `KeyboardHelp` overlay |
| Density | `SettingsDensity` Normal / Narrow / Tiny |

**Host owns:** persistence, restart application, domain values, conflict resolution.

## Anatomy

```
┌ Categories ─┬ Search ──────────────────┐
```
