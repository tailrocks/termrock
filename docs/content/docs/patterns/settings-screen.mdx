## Classification and composition

Composed public building blocks: `Field`, `FieldStatus`, `Fieldset`, `Form`, `HelpEntry`, `KeybindingRecorder`, `KeyboardHelp`, `NavItem`, `Panel`, `SearchInput`, `Sidebar`, `SidebarPresentation`, `StatefulWidget`, `StatusBar`, `StatusSlot`, `ThemePicker`, `ThemePreset`, `Widget`.

## Workflow

- `Enter open action` or `click trigger` opens a real ChoiceDialog; confirm/cancel produce different outcomes.
- `S toggle sidebar region` changes the visible application chrome.
- `↑↓/wheel select row` changes the persistent row selection.
- `/ filter` focuses a real TextInput; type or paste, then Enter applies or Escape cancels.

The preview and native Lookbook instantiate the same Rust story and state machine. Outcomes appear in the preview status line.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.

# SettingsScreen

Source-owned application block for a complete settings experience. Composes

## When to use

| Use SettingsScreen | Prefer |
|--------------------|--------|
| Multi-category settings with search | Standalone Form / Sidebar |
| Theme + keybinding surfaces in one shell | ThemePicker / KeybindingRecorder alone |
| App settings with dirty / restart banners | Custom Workspace layout |

## Canonical chrome

| Concern | Type |
|---------|------|
| Categories | `Sidebar` / `NavItem` |
| Search | `SearchInput` |
| Fields | `Form` / `Field` / `Fieldset` |
| Theme | `ThemePicker` body mode |
| Keybindings | `KeybindingRecorder` body mode |
| Help | `KeyboardHelp` overlay |
| Density | `SettingsDensity` Normal / Narrow / Tiny |

**Host owns:** persistence, restart application, domain values, conflict resolution.

## Minimal host loop

```rust
use termrock::patterns::{
    SettingsScreenState, SettingsScreenSurfaces, render_settings_screen,
    example_settings_categories, example_settings_appearance_fields,
};
use termrock::widgets::{Fieldset, BUILTIN_THEME_PRESETS};

let mut state = SettingsScreenState::new();
let nav = example_settings_categories();
let fields = example_settings_appearance_fields();
let fieldsets = [Fieldset::new("Appearance", &fields)];

render_settings_screen(buf, area, SettingsScreenSurfaces {
    system: &system,
    state: &mut state,
    nav: &nav,
    fieldsets: &fieldsets,
    theme_presets: BUILTIN_THEME_PRESETS,
    theme_paint: Some(&system),
    status_slots: &[],
    status_state: &mut status,
    section_title: "Appearance",
});
```
