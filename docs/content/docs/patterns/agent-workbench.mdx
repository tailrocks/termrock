Composition pattern for an agent shell. **Not** a product agent — consumers own wording, tools, policy, and effects. Source-owned registry block (migration `0236`).

## When to use

| Use AgentWorkbench | Prefer |
|--------------------|--------|
| Multi-pane agent UI (tasks + thread + prompt + activity) | Custom layout from Workspace + widgets |
| Trust gates / plan / diff over the shell | Standalone elevated widgets |
| Free-form agent input only | [`PromptComposer`](/docs/components/prompt-composer) alone |

## Canonical chrome (sole path)

| Concern | Type |
|---------|------|
| Tasks | `TaskRail` / `ActivityModel` (legacy `List` fallback) |
| Stream | `Transcript` (MessageThread may project into same center) |
| Activity | `ActivityShelf` / `ActivityItem` |
| Working | `WorkingStateCard` |
| Prompt | `PromptComposer` / `PromptComposerState` |
| Permission | `PermissionPrompt` / `PermissionPromptState` |
| Question / Plan / Diff / Session | `QuestionFlow`, `PlanReview`, `DiffReview`, `SessionPicker` |
| Focus / Esc layers | `InteractionScene` via `AgentWorkbenchState` |

**Deleted duals:** `ApprovalCard`, `PromptBox` on the agent path (migration `0063` / elevated `0236`).

## Anatomy

```
┌ TaskRail ──┬ Transcript ───────────────┐
│            │                           │
│            ├ ActivityShelf ────────────┤
├────────────┴ WorkingState ─────────────┤
│ Mode ribbon + PromptComposer           │
├────────────────────────────────────────┤
│ Status                                 │
└────────────────────────────────────────┘
        ┌ Permission / Plan / Diff / … ┐
        └──────────────────────────────┘
```

- Focus chrome: `PanelChrome::Focused` only on the pane that owns scene focus.
- Overlays are dismissible scene layers; **one-layer Esc**. Composer draft is never cleared by overlays.
- Densities: `Normal` (≥72) · `Narrow` (40–71) · `Tiny` (&lt;40).

## Laws

| Law | Detail |
|-----|--------|
| Draft | Overlays never clear `PromptComposerState` |
| Esc | One dismissible layer peels; no grant / submit |
| Focus | Tab cycles TaskRail → Transcript → Activity → Prompt |
| Public only | Pattern uses public widgets + layout/scene only |
| Host owns I/O | Outcomes are requests |
