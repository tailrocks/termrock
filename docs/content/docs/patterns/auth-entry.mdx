## Classification and composition

**application** · default grid 64×20

Composed public building blocks: `Checkbox`, `Panel`, `PanelVariant`, `PasswordInput`, `TextInput`, `Validation`.

## Workflow

- `Enter open action` or `click trigger` opens a real ChoiceDialog; confirm/cancel produce different outcomes.
- `S toggle sidebar region` changes the visible application chrome.
- `↑↓/wheel select row` changes the persistent row selection.
- `/ filter` focuses a real TextInput; type or paste, then Enter applies or Escape cancels.

The preview and native Lookbook instantiate the same Rust story and state machine. Outcomes appear in the preview status line.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.
