<section className="docs-home__contract" aria-labelledby="docs-home-contract">

<h2 id="docs-home-contract">Keep the boundary clear</h2>

TermRock owns terminal geometry, interaction mechanics, focus, semantic paint,
Unicode behavior, and capability fallbacks. Your application owns domain state,
language, persistence, networking, permissions, and effects.

Continue with [interaction conventions](/docs/interaction) when a screen adds
overlays or composite focus. Use [quality and migrations](/docs/quality-migrations)
before upgrading a pinned revision.
