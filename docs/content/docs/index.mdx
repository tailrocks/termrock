# TermRock

**TermRock is the ecosystem UI capability layer for building terminal interfaces
quickly.** It is a Rust crate of product-neutral widgets, interaction kernels,
and design tokens for [Ratatui](https://ratatui.rs/) apps — inspired by the open
code and strong-default ideas of [shadcn/ui](https://ui.shadcn.com/docs), adapted
to terminal geometry, focus, and Unicode safety.

## What you get

| Layer | Role |
|-------|------|
| **Widgets** | List, Table, Dialog, PromptComposer, PermissionPrompt, Tree, … with stable IDs and borrowed render data |
| **Interaction** | `InteractionScene`, `OverlayStack`, `UiIntent`, keymaps — Esc law and focus traps |
| **Design system** | Semantic `Role` palette, density, glyphs, recipes (phosphor default) |
| **Lookbook** | Deterministic SVG previews of every catalog story — same paint path as the TUI CLI |

TermRock owns reusable rendering, layout, theme roles, focus/navigation, hit
geometry, narrow-terminal behavior, and non-color cues. **Your app owns** domain
state, wording, effects, secrets, process policy, and projections into widgets.

Previews on this site are **not mockups**. They are regenerated from:

```bash
cargo run -p termrock-lookbook -- render --out docs/public/component-previews
cargo run -p termrock-lookbook -- check --dir docs/public/component-previews
```

That is the same renderer the interactive gallery CLI uses, so what you see in
the docs matches what a terminal session paints for that story.

## Quick start

```toml
# Cargo.toml — pin an exact git revision (API is pre-stable)
termrock = { git = "https://github.com/tailrocks/termrock", rev = "…" }
```

```rust
use termrock::style::DesignTokens;
use termrock::widgets::{List, ListRow, ListState, RowRole};
use ratatui_core::text::Line;

let tokens = DesignTokens::default();
let rows = [ListRow {
    id: "a",
    label: Line::from("Alpha"),
    leading: None,
    secondary: None,
    badge: None,
    shortcut: None,
    trailing: None,
    role: RowRole::Item,
    enabled: true,
    loading: false,
}];
let mut state = ListState::new(Some("a"));
// List::new(&rows, &tokens) in your frame draw
```
