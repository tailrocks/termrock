# AgentModeSelector

Autonomy / safety mode dial (Ask · Plan · Edit · Auto · FullAuto). Changes
**permission chrome expectations**, not model weights. FullAuto always uses
warning role and `needs_confirm` on change.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use AgentModeSelector | Prefer |
|-----------------------|--------|
| Composer mode badge / ribbon | — |
| Model pick | [ModelSelector](/docs/handbook/model-selector) |
| Generic workbench modes | ModeRibbon + host ids |
