# ActivityShelf

Glanceable strip of live/blocked operations. Prioritizes action-required and
blocked chips. Narrow widths collapse to summary or badge. Not a TaskRail.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

<TerminalPreview story="activity-shelf/statuses" interactive caption="ActivityShelf · activity-shelf/statuses — Ghostty truecolor focus surface" />

## When to use / when not

| Use ActivityShelf | Prefer |
|-------------------|--------|
| Persistent active ops under transcript | — |
| Full task/subagent inventory | TaskRail / List |
| Ephemeral toasts only | Toast / NotificationCenter |
| Mode/connection chrome only | StatusBar slots |

## Density

| Width | Presentation |
|-------|----------------|
| ≥ 56 | Chips (glyph + title) |
| 36–55 | Icons only |
| 18–35 | One-line summary |
| < 18 | Badge count |

## Integration

- `project_activities_for_status_bar` → StatusSlot content
- `activities_to_notifications` → NotificationCenter ingest for blocked/action/failed
