# Timeline

**Purpose.** Present time-ordered events with status, actor, and optional
grouping. Supports live streaming while preserving reading position when the
user scrolls up.

## Recipes

| Recipe | Use |
|--------|-----|
| `Detailed` (default) | Full rows: time · actor · status · text |
| `Rail` | Compact side-panel markers |
| `GroupedDay` | Day/session headers |

## Live stream

- `TimelineState::following` defaults **true** (stick to newest).
- Moving up / wheel-up **pauses** follow.
- `f` or End re-follows; call `on_append(len)` after host appends.

## Example

```rust
use termrock::widgets::{
    Timeline, TimelineEvent, TimelineState, TimelineStatus, TimelineRecipe,
};

let events = [
    TimelineEvent::with_id("a", "12:01", "Deploy")
        .status(TimelineStatus::Success)
        .actor("ci"),
    TimelineEvent::with_id("b", "12:02", "Tests")
        .status(TimelineStatus::Running)
        .active(),
];
let mut state = TimelineState::new();
// Timeline::with_events(&events, &system).recipe(TimelineRecipe::Rail)
```
