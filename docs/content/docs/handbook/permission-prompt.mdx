# PermissionPrompt

**Purpose.** Replace vague “Allow?” prompts with a **trust surface**: who asked
(including nested subagents/MCP), exact action/target, risk, egress, scope, and
decisions that **never default to grant**.

## When to use / when not

| Use PermissionPrompt | Prefer |
|----------------------|--------|
| Shell / file / network / MCP gates | — |
| Product settings toggles | Form / Switch |
| Agent prompt input | [PromptComposer](/docs/handbook/prompt-composer) |

## Installation

```toml
termrock = { git = "https://github.com/tailrocks/termrock.git", rev = "PIN" }
```

Design: `docs/design/permission-trust.md`. Overlay id: `PERMISSION_OVERLAY_ID`.

## Source files

`PermissionPrompt`, `PermissionPromptState`, `PermissionRequest`,
`PermissionQueue`, provenance / risk / scope / outcome types

## Basic example

```rust
use termrock::widgets::{
    InitiatorKind, PermissionPromptState, PermissionProvenance, PermissionRequest,
    PermissionRisk, ProvenanceHop,
};

let mut ui = PermissionPromptState::new();
let req = PermissionRequest::new("r1", "bash", "workspace")
    .risk(PermissionRisk::High)
    .command("rm -rf build/")
    .irreversible()
    .provenance(
        PermissionProvenance::main_agent("run", "main").push(ProvenanceHop::new(
            InitiatorKind::Subagent,
            "s1",
            "reviewer",
        )),
    );
let generation = ui.enqueue(req);
assert!(ui.head_generation() == Some(generation));
assert!(!ui.selected().grants());
```

## Interactive example

```rust
use termrock::{
    input::{KeyCode, KeyEvent, KeyModifiers},
    widgets::{
        PermissionAction, PermissionOutcome, PermissionPromptState, PermissionRequest,
        PermissionRisk,
    },
};

let mut ui = PermissionPromptState::new();
ui.enqueue(PermissionRequest::new("r1", "read", "src/lib.rs").risk(PermissionRisk::Low));
// Default focus is Deny — Enter does not allow.
let out = ui.handle_key(KeyEvent::new(KeyCode::Enter, KeyModifiers::NONE));
assert!(matches!(
    out,
    PermissionOutcome::Decided {
        action: PermissionAction::Deny,
        ..
    }
));
```

## Anatomy

`risk title` · `provenance path` · `action → target` · `location` · `warning` ·
`expect` · `prior grant` · `command/pattern` · `scope` · `actions` (**Deny first**)

## Public API

| API | Why |
|-----|-----|
| `enqueue` / queue | FIFO + generation stale protection |
| `PermissionRequest` builders | Risk, egress, provenance, command |
| `handle_key` / `handle_mouse` | Default-deny focus; `y` unbound |
| `open_overlay` | Trap High/Critical; Dialog Low/Medium |
| Scopes `[` `]` | Once / Session / Project / Always (consumer enforces) |

## State ownership

| TermRock | Consumer |
|----------|----------|
| Focus, queue order, audit buffer, chrome | Policy store, execution, Always persistence |
| Generation checks | Async re-validation before side effects |

## Typed outcomes

`Decided { generation, action, scope, edited }` · `Cancelled` · `StaleIgnored` ·
edit/detail toggles — **never** run the tool inside the widget.

## Variants

Risk Low→Critical · scopes · AllowEdited / AllowRestricted · InspectDetails.

## Sizes

Card / overlay dialog; narrow stacks actions. Tiny: risk + Deny/Allow minimum.

## Density

Compact compresses provenance; path must remain readable.

## Keyboard

Arrows/Tab actions · `[`/`]` scope · Enter confirm · Esc cancel head · `n` Deny ·
`e`/`p` edit · **`y` not bound**.

## Mouse

Hover selects action; click confirms. Outside-click = dismiss policy (gate cancel
on host for dismissible peels).

## Focus

Default **Deny** (or non-grant). High/Critical Trap: Esc → widget Cancelled.

## Responsive

Stack warning + actions; collapse details by default on narrow.

## Accessibility / colorless

Risk glyphs `i`/`!`/`!!`/`X` + labels; DATA EGRESS / DESTRUCTIVE text banners.

## Unicode

Command previews grapheme-safe; prefer ASCII for action labels on Minimal.

## Composition

AgentWorkbench OverlayStack · ToolCallCard waiting state · PromptComposer blur.

## Theming

Danger/Warning roles for risk; never grant-only green success styling.

## Custom recipe

```rust
// High risk → actions_for_risk puts Deny first and Allow last.
use termrock::widgets::{PermissionRequest, PermissionRisk};
let req = PermissionRequest::new("x", "bash", ".").risk(PermissionRisk::High);
assert!(req.actions_for_risk()[0].label() == "Deny");
```

## Common mistakes

- Legacy ApprovalCard / PromptBox (removed).  
- Ignoring `StaleIgnored` after async.  
- Default focus on Allow.  
- Silent overlay dismiss without gate-cancel.

## Performance

One head at a time; queue is light. Don’t block UI thread on tool execution.

## Complete application example

```text
tool needs gate → enqueue PermissionRequest → open overlay
Enter on Deny → Decided(Deny) → advance queue / fail tool
Allow path → re-check generation → execute → audit
Esc / dismissible peel → Cancelled (host permission_gate_cancel)
```
