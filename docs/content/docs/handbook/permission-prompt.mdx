# PermissionPrompt

**Purpose.** Replace vague “Allow?” prompts with a **trust surface**: who asked
(including nested subagents/MCP), exact action/target, risk, egress, scope, and
decisions that **never default to grant**.

## When to use / when not

| Use PermissionPrompt | Prefer |
|----------------------|--------|
| Shell / file / network / MCP gates | — |
| Product settings toggles | Form / Switch |
| Agent prompt input | [PromptComposer](/docs/handbook/prompt-composer) |

## Focus law

| Concern | Owner |
|---------|--------|
| Overlay trap (High/Critical) | OverlayStack AlertDialog |
| Surface input | Host `set_accepts_input` when overlay top |
| Action **cursor** | `action_cursor` (default Deny) |
| Scope cursor | `scope` via `[` `]` |

Scene surface focus ≠ decision cursor.

## Outcomes

- `Ignored`
- `ActionCursorMoved` / `ScopeChanged`
- `DetailsToggled` / `EditStarted` / `EditChanged` / `EditCancelled`
- `Decided { request_id, generation, action, scope, edited }`
- `Cancelled` / `QueueChanged` / `StaleIgnored`

## Intents

`default_permission_intent` — arrows/Tab, Enter, Esc, `d` toggle details.
**No `y` grant.** Product: `n` deny, `e`/`p` edit, `[`/`]` scope.

## Non-color

- Risk glyphs: `i`/`!`/`!!`/`X` (ASCII) or unicode
- Action cursor: `›` / `>`
- Empty: `∅` / `[ ]`
- Danger panel chrome for High/Critical

## Responsive

| Width | Layout |
|-------|--------|
| ≥ 36 | Horizontal action strip |
| &lt; 36 | Vertical action stack |
| Tiny height | Risk title + actions first |

## Safety

- Default cursor **Deny** for Low/Medium/High/Critical
- Enter on default → Deny, never Allow
- Esc → cancel without grant + advance queue
- Stale generation → `StaleIgnored` (no grant)
