# ApprovalQueue

Multi-type human-decision inbox. High-risk items **only Open** into
PermissionPrompt / QuestionFlow / PlanReview / DiffReview — never one-click bulk.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use ApprovalQueue | Prefer |
|-------------------|--------|
| Mixed pending decisions list | — |
| Single permission interaction | [PermissionPrompt](/docs/handbook/permission-prompt) |
| Full Q&A / plan / diff | QuestionFlow · PlanReview · DiffReview |

## Safety

- Default action: **Open**
- High/Critical: no quick/bulk approve
- Protocol FIFO for permission/question chains
- `y` unbound
