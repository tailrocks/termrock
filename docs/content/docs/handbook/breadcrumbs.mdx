# Breadcrumbs

**Purpose.** Location context for files, routes, schemas, object paths.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

<TerminalPreview story="breadcrumbs/path" interactive caption="Breadcrumbs · breadcrumbs/path — Ghostty truecolor focus surface" />

## One Tab stop

Host Tab focuses the control once. **Left/Right** move among segments (and
ellipsis). Avoids a Tab stop per crumb.

## Collapse

When narrow and `len > 3`: **first · … · current**. Middle ids available via
`OpenOverflow`.

## Editable mode

Optional path draft (`with_editable(true)`). Enter/Ctrl+E/`/` on current starts
edit; Enter commits; Esc cancels.

## Compose

FilePicker · SchemaBrowser · master-detail headers · migration `0155`
