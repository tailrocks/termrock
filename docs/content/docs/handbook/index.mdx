# Component handbook

These pages follow the binding standard at
`docs/design/component-documentation-standard.md` (shadcn/ui-class structure:
purpose → install → examples → anatomy → ownership → interaction → a11y →
composition → mistakes → perf → testing).

They go beyond the thin inventory pages under **Components** (generated from the
public API). Use the handbook when you need **when/why**, full anatomy,
outcomes, and a small application sketch.
