# Component handbook

These pages follow the binding standard at
`docs/design/component-documentation-standard.md` (shadcn/ui-class structure:
purpose → install → examples → anatomy → ownership → interaction → a11y →
composition → mistakes → perf → testing).

They go beyond the thin inventory pages under **Components** (generated from the
public API). Use the handbook when you need **when/why**, full anatomy,
outcomes, and a small application sketch.

| Page | Use when |
|------|----------|
| [Button](/docs/handbook/button) | Single activatable control or toolbar actions |
| [List](/docs/handbook/list) | Stable-ID vertical collections |
| [DataTable](/docs/handbook/data-table) | Virtualized / multi-column data |
| [Dialog](/docs/handbook/dialog) | Modal confirmations and messages |
| [Command palette](/docs/handbook/command-palette) | Fuzzy jump across commands |
| [Prompt composer](/docs/handbook/prompt-composer) | Agent-style multi-line input |
| [AttachmentChip](/docs/handbook/attachment-chip) | File/image/URL/code attachment tokens |
| [PasteChip](/docs/handbook/paste-chip) | Collapsed large-paste tokens |
| [Permission prompt](/docs/handbook/permission-prompt) | Trust gates with provenance and risk |
| [ObjectInspector](/docs/handbook/object-inspector) | Key/value field projection + cursor |
| [LogStream](/docs/handbook/log-stream) | Professional follow/filter/export log viewer |
| [DiffView](/docs/handbook/diff-view) | Professional unified/split read-only diffs |
| [DiffReview](/docs/handbook/diff-review) | Hunk activate veneer over DiffView |
| [Diagnostic](/docs/handbook/diagnostic) | Structured diagnostics + CodeFrame |

| [QueryEditor](/docs/handbook/query-editor) | SQL/logs/search query workbench |

| [SchemaBrowser](/docs/handbook/schema-browser) | DB catalog hierarchy navigator |
| [SearchResults](/docs/handbook/search-results) | Grouped search hits + match walk |
| [MetricsDashboard](/docs/handbook/metrics-dashboard) | Metric cards · sparklines · alerts |
