# Diagnostic and CodeFrame

Structured diagnostics (rustc/miette-class) with list, inline, and full
code-frame recipes. Severity always includes letter/glyph — never color alone.

## When to use / when not

| Use Diagnostic | Prefer |
|----------------|--------|
| Build / compiler / linter problems | — |
| Form field one-liner | Inline recipe |
| Recoverable app failure UI | [ErrorState](/docs/handbook/error-state) |
| Full file editor body | [CodeBlock](/docs/handbook/code-block) + highlight bridge |

## Model

- `Diagnostic` — severity, code, message, source, file, labels, related, notes, help, docs, fixes
- `SourceRange` / `SourceLabel` — 1-based lines, display columns (tabs expanded)
- `CodeFrame` / `CodeFrameLine` — standalone snippet paint with carets
- Recipes: `List` · `Inline` · `Full`

## Non-color severity

| Severity | Letter | ASCII glyph |
|----------|--------|-------------|
| Error | E | E |
| Warning | W | W |
| Info | I | I |
| Hint | H | H |
| Note | N | N |
| Help | ? | ? |

## Outcomes

- `CursorMoved` · `Expanded` · `Activated`
- `CopyDetails` · `ApplyFixRequested` · `OpenDocsRequested` · `FixSelected`
- Host owns clipboard, apply, and browser open

## Integration

```rust
// CodeBlock
.highlights(&diagnostics_to_highlights(&items))
.gutter_marks(&diagnostics_to_gutter_marks(&items, ascii))

// ErrorState copy-diagnostics payload
format_diagnostics_plain(&items)
```

## Keys

| Key | Action |
|-----|--------|
| j/k | Cursor |
| Space / o | Expand |
| c | Copy one · C-c copy all |
| a | Apply fix |
| [ ] | Fix cursor |
| d | Open docs |
| Enter | Activate (open location) |
