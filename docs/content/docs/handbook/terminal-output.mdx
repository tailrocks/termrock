# TerminalOutput

Presents one projected command run: metadata chrome, streaming stdout/stderr,
follow/pause, and typed control **requests**. TermRock never spawns or kills
processes.

## When to use / when not

| Use TerminalOutput | Prefer |
|--------------------|--------|
| Agent/build command panes | — |
| Compact tool summary only | [ToolCard](/docs/components/tool-card) |
| Multi-source logs | [LogStream](/docs/handbook/log-stream) |
| Owned append buffer | [LogPane](/docs/components/log-pane) |

## Safety

- No `Command::new`, no PTY in this widget
- Outcomes: `CancelRequested`, `RetryRequested`, `DetachProcessRequested`, `Copy*`, …
- Host owns process policy and secrets redaction (helpers assist display only)

## Follow / scroll

`ScrollAreaState` is sole follow authority. Scrolling away detaches; chip or `f`
re-follows. `on_append` updates unread while pinned.

## Recipes

| Recipe | Layout |
|--------|--------|
| `Compact` | Short header + few body rows |
| `Pane` (default) | Status, command, cwd, body, follow chip |
| `Fullscreen` | Extra key hints |

## Paint modes

`Ansi` · `NoColor` · `Plain` · `Raw` (escaped sequences for inspection)

## Keys

| Key | Action |
|-----|--------|
| f | Follow toggle |
| c / C-c | Cancel (running) / copy output |
| r | Retry |
| d | Detach process |
| e | Env panel |
| m / p | Paint mode / recipe |

## Example

```rust
use termrock::widgets::{
    TerminalOutput, TerminalOutputState, TerminalCommandMeta,
    TerminalLine, TerminalRunStatus,
};

let meta = TerminalCommandMeta::new("cargo test")
    .status(TerminalRunStatus::Running)
    .duration_ms(500);
let lines = [TerminalLine::stdout("1", "ok")];
let mut state = TerminalOutputState::new();
// TerminalOutput::new(&meta, &lines, &system).render(area, buf, &mut state);
let _ = (meta, lines, state);
```
