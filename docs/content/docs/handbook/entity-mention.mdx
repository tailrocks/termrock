# EntityMention

Inline structured tokens for **agents, tools, sessions, resources, and users**.
Same substrate as FileMention (`MentionRef`, `MentionDraft`, `InlineMention`)
with entity type glyphs and family-filtered completion.

## When to use / when not

| Use EntityMention | Prefer |
|-------------------|--------|
| `@agent` / tool / session references | — |
| Files and symbols | [FileMention](/docs/handbook/file-mention) |
| Permission subjects | domain host models |

## Types

`MentionType::{Agent, Tool, Session, Resource, User, Other}`

## Example

```rust
use termrock::widgets::{EntityMention, InlineMention, InlineMentionState, MentionValidity};

let mut s = EntityMention::session("s1", "chat-42", "session:42");
s.as_mut().validity = MentionValidity::Stale;
let mut st = InlineMentionState::new();
InlineMention::entity(&s, &system).paint(area, buf, &mut st);
```

## Semantic safety

`mention_semantic_description` never embeds provider payloads; set
`sensitive` to redact path-like canonical tails for recordings.
