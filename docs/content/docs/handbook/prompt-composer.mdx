# PromptComposer

Primary human → agent input: grapheme-safe multiline editing, attachments,
slash/@/# completion, mode/model chrome, queue while busy — without embedding
provider SDKs or clearing the draft when permission/plan overlays take input.

## When to use / when not

| Use PromptComposer | Prefer |
|--------------------|--------|
| Agent / chat / studio prompts | — |
| SQL / log queries | [QueryEditor](/docs/handbook/query-editor) |
| Simple one-line fields | TextInput |
| Plain notes | [TextArea](/docs/handbook/text-area) |
| Trust gates | [PermissionPrompt](/docs/handbook/permission-prompt) |

## Separation (five buckets)

| Bucket | Owns |
|--------|------|
| Text editing | `TextAreaState`, undo/redo, history, selection |
| Tokens | `ComposerChip` (file / paste / mention / media) |
| Completion | `CompletionQuery` only — host supplies candidates |
| Presentation | compact / normal / expanded / fullscreen |
| Policy | `SubmitPolicy`, busy, connection |

## Focus law

| Concern | Owner |
|---------|--------|
| Surface input gate | Host `set_accepts_input` (false when overlay tops) |
| Editor caret | `TextAreaState` inside composer |
| Chip cursor | `chip_cursor` (local) |
| Completion candidates | Consumer list + OverlayStack |
| Draft lifetime | Never cleared by accepts_input alone |

## Outcomes (selected)

- `Submit` / `Queued` / `Cancel` / `Interrupt`
- `Changed` / `DismissRequest`
- `Completion` / `CompletionClosed` / `CompletionCommitted`
- `ChipRemoved` / `ChipActivated` / `AttachRequest`
- `ExternalEditor` / `SelectionCopied`
- `ValidationFailed` / `PresentationChanged` / fullscreen

## Integrate

| Piece | How |
|-------|-----|
| CompletionMenu | On `Completion` open menu; commit → `commit_completion` |
| HistoryPicker | `submit_history_to_entries(state.submit_history())` |
| KeyboardHelp | `prompt_composer_help_entries()` + live keymap |
| TokenMeter | Status strip when `ContextEstimate.limit > 0` |
| OverlayStack | `open_completion_overlay` / `open_fullscreen_overlay` |

## Intents

`default_prompt_composer_intent` — bare Enter → Submit, Esc → Cancel.
Product chords (Ctrl+Z/Y, history, attach) stay on `handle_key`.

## Non-color

- ASCII badges via `set_ascii_fallback` / `set_colorless`
- Chip remove `×` / `x`
- Panel Focused only when `accepts_input`
- Status always worded (`BUSY`, `offline`, `queue:N`)

## Basic example

```rust
use termrock::{
    style::{Density, DesignSystem, RolePalette},
    widgets::{ModeIndicator, ModelIndicator, PromptComposer, PromptComposerState},
};

let theme = RolePalette::default();
let system = DesignSystem::new(theme, Density::Comfortable);
let mut state = PromptComposerState::new();
state.set_placeholder("Ask anything…");
state.set_mode(Some(ModeIndicator {
    label: "EDIT".into(),
    warning: false,
}));
state.set_model(Some(ModelIndicator {
    label: "model".into(),
}));
let _composer = PromptComposer::new(&system);
```

## Interactive example

```rust
use termrock::{
    input::{KeyCode, KeyEvent, KeyModifiers},
    widgets::{PromptComposerOutcome, PromptComposerState},
};

let mut state = PromptComposerState::new();
state.set_text("ship it");
let out = state.handle_key(KeyEvent::new(KeyCode::Enter, KeyModifiers::NONE));
assert!(matches!(
    out,
    PromptComposerOutcome::Submit { ref text, .. } if text == "ship it"
));
// Overlay takeover: draft preserved
state.set_text("keep");
state.set_accepts_input(false);
assert_eq!(state.text(), "keep");
assert!(matches!(
    state.handle_key(KeyEvent::new(KeyCode::Enter, KeyModifiers::NONE)),
    PromptComposerOutcome::Ignored
));
```

## Public API

| API | Why |
|-----|-----|
| `set_accepts_input(false)` | Permission/plan takeover **without** clearing draft |
| `set_busy` + queue policy | Enter enqueues while agent runs |
| `handle_paste` | Large paste → chip |
| `detect_completion` / `set_completion` | Pure trigger detect + streaming host refresh |
| `commit_completion` | Slash/@ insert without owning candidates |
| `submit_history` / `submit_history_to_entries` | HistoryPicker bridge |
| `prompt_composer_help_entries` | KeyboardHelp seed |
| Overlay helpers | Completion + fullscreen |
