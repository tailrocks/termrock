# PromptComposer

**Purpose.** Primary human → agent input: grapheme-safe multiline editing,
attachments, slash/@ completion, mode/model chrome, and **queue while busy** —
without embedding provider SDKs or clearing the draft when permission/plan
overlays take focus.

## When to use / when not

| Use PromptComposer | Prefer |
|--------------------|--------|
| Agent / chat / studio prompts | — |
| Simple one-line fields | TextInput |
| Modal confirm | Dialog |
| Trust gates | [PermissionPrompt](/docs/handbook/permission-prompt) |

## Basic example

```rust
use termrock::{
    style::{Density, DesignTokens},
    widgets::{ModeIndicator, ModelIndicator, PromptComposer, PromptComposerState},
    Theme,
};

let theme = Theme::default();
let tokens = DesignTokens::new(theme.clone(), Density::Comfortable);
let mut state = PromptComposerState::new();
state.set_placeholder("Ask anything…");
state.set_mode(Some(ModeIndicator {
    label: "EDIT".into(),
    warning: false,
}));
state.set_model(Some(ModelIndicator {
    label: "model".into(),
}));
let _composer = PromptComposer::new(&tokens, &theme);
```

## Interactive example

```rust
use termrock::{
    input::{KeyCode, KeyEvent, KeyModifiers},
    widgets::{PromptComposerOutcome, PromptComposerState},
};

let mut state = PromptComposerState::new();
state.set_text("ship it");
let out = state.handle_key(KeyEvent::new(KeyCode::Enter, KeyModifiers::NONE));
assert!(matches!(
    out,
    PromptComposerOutcome::Submit { ref text, .. } if text == "ship it"
));
// Overlay takeover: draft preserved
state.set_text("keep");
state.set_focused(false);
assert_eq!(state.text(), "keep");
```

## Anatomy

`chip_row` · multiline `editor` · mode/model badges · busy/queue chrome ·
context meter · validation · send/stop affordances  

## Public API

| API | Why |
|-----|-----|
| `set_focused(false)` | Permission/plan takeover **without** clearing draft |
| `set_busy` + queue policy | Enter enqueues while agent runs |
| `handle_paste` | Large paste → chip |
| `commit_completion` | Slash/@ insert without owning candidates |
| Overlay helpers | Completion + fullscreen |

## State ownership

| TermRock | Consumer |
|----------|----------|
| Text edit, undo, chips, queue chrome | Model routing, attachments meaning |
| Completion query detect | Candidate search |
| | Run/cancel agent on Submit / Cancel |

## Typed outcomes

`Submit` · `Queued` · `Cancel` · `Interrupt` · `Completion` · `ExternalEditor` ·
`ValidationFailed` · … — pure; effects outside.

## Variants

Presentation: Compact / Normal / Expanded / Fullscreen. Connection: Ready /
Disabled / Disconnected.

## Sizes

Compact ~2–3 editor rows; expand with content; fullscreen overlay on tiny
terminals.

## Density

Comfortable default; Compact for dense workbenches.

## Keyboard

Enter submit · Mod+Enter newline · Ctrl+C interrupt when busy · Ctrl+U cancel ·
Esc peels completion/fullscreen first · `/` `@` `#` completion triggers.

## Mouse

Editor click positions caret; chip × removes; mode/model hits open menus.

## Focus

Blur keeps draft; chip strip via BackTab; completion overlay owns keys when open.

## Responsive

`contract_for_width`; ASCII fallback on very narrow.

## Accessibility / colorless

Busy/queue/offline as words; chip type letters `F`/`P` in ASCII mode.

## Unicode

Grapheme TextArea; large paste chips avoid multi-MB wrap thrash.

## Composition

AgentWorkbench · OverlayStack (permission/plan) · CompletionMenu · ContextMeter.

## Theming

Panel focus border · warning mode badge · danger validation · TokenMeter roles.

## Custom recipe

`SubmitPolicy` for newline/queue/clear; never put provider keys in the composer.

## Common mistakes

- `clear_draft` on permission open.  
- Dual-submit while busy (disable queue policy).  
- Binding `y` globally for allow (trust surface, not composer).

## Performance

Undo snapshots bounded; paste chips; see streaming-performance for token stream
(coalesce on host).

## Complete application example

```text
composer focused → type → Enter → Submit outcome → set_busy(true)
while busy: Enter → Queued; Stop → Cancel/Interrupt
permission overlay: set_focused(false) — draft stays
on run complete: drain queue FIFO → next Submit
```
