# Menu

Vertical menu / context menu. **Cursor** is menu-local; **scene focus** is host-owned.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

<TerminalPreview story="menu/roving" interactive caption="Menu · menu/roving — Ghostty truecolor focus surface" />

## Outcomes

- `Ignored`
- `CursorMoved`
- `Activated(Id)`
- `Closed` (Esc)

## Focus law

| Concern | Owner |
|---------|--------|
| Surface focus | Host / OverlayStack / InteractionScene |
| Item cursor | `MenuState::cursor_index` |
| Paint | `Menu::focused` + cursor gutter |

## Non-color

- Cursor: `›` / `>`
- Checked: `✓` / `[x]`
- Disabled: dim + `⊘` / `#`

## Intents

`default_menu_intent` — j/k, arrows, Home/End, Enter, Space, Esc.
