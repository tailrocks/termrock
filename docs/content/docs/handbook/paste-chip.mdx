# PasteChip

Large paste summarized as a chip so multi-KB text never floods the editor wrap
path. Preview + size/lines on the chrome; full body stays host-held (or in
`PastePayload.body` for submit). Semantic summaries **never** include the body.

## When to use / when not

| Use PasteChip | Prefer |
|---------------|--------|
| Bracketed paste over threshold | — |
| File attachments | [AttachmentChip](/docs/handbook/attachment-chip) |
| Inline short paste | PromptComposer `insert_text` |

## Collapse / inspect / copy

| Action | Behavior |
|--------|----------|
| Enter | Expand / collapse preview |
| Esc | Collapse only |
| Ctrl+C | `CopyRequested { id }` — host copies body |
| Ctrl+I | `InsertRequested` — `needs_confirm` when binary |
| Delete | Remove |

## Binary

`PastePayload::binary` never auto-inserts as text; insert outcome sets
`needs_confirm: true`.

## Example

```rust
use termrock::widgets::{PastePayload, PasteChip, PasteChipState, paste_semantic_summary};

let paste = PastePayload::from_body("p1", huge);
assert!(!paste_semantic_summary(&paste).contains("secret-from-body"));
let mut st = PasteChipState::new();
PasteChip::new(&paste, &system).paint(area, buf, &mut st);
```
