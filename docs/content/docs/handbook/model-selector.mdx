# ModelSelector

Pick a model id from a **host-supplied** catalog. TermRock paints compact status
and an expandable searchable list (capabilities, context, cost/latency hints,
availability, warnings). No provider SDK or network.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use ModelSelector | Prefer |
|-------------------|--------|
| Composer model badge / menu | — |
| Agent safety mode | [AgentModeSelector](/docs/handbook/agent-mode-selector) |
| Generic form select | Select |

## Compact vs expanded

- **Compact** — one-line status for PromptComposer (`label/provider ctx $`)
- **Expanded** — filterable list; Enter confirms; Esc restores prior selection

## Consequences

`Confirmed { warning }` surfaces deprecation/cost strings for host dialogs.
