# Dialog

**Purpose.** Present a **blocking or semi-blocking card** (message, choice,
confirm) with clear focus ownership and Esc policy — without embedding product
workflow engines.

## When to use / when not

| Use Dialog | Prefer |
|------------|--------|
| Confirm / choose among few actions | ChoiceDialog |
| Read-only notice | MessageDialog |
| Global command search | [CommandPalette](./command-palette) |
| Agent permission risk | [PermissionPrompt](./permission-prompt) |
| Multi-step forms | Form / wizard pattern |

## Installation

Crate pin (see handbook index). Overlay helpers live beside dialog widgets.

## Source files

`Dialog`, `ChoiceDialog`, `MessageDialog`, `Backdrop`, `place_dialog` /
`open_dialog_overlay`, `DialogSize`

## Basic example

```rust
use ratatui_core::{layout::Rect, text::Text};
use termrock::{Theme, widgets::{Dialog, DialogSize, place_dialog}};

let theme = Theme::default();
let dialog = Dialog::new("Notice", Text::from("Done."), &theme);
let area = place_dialog(Rect::new(0, 0, 80, 24), DialogSize::default());
let _ = (dialog, area);
```

## Interactive example

```rust
use ratatui_core::text::Text;
use termrock::{
    Theme,
    input::{KeyCode, KeyEvent, KeyModifiers},
    interaction::Outcome,
    widgets::{Action, ChoiceDialog, ChoiceDialogState, Dialog},
};

let theme = Theme::default();
let actions = [
    Action { id: "ok", label: "OK", enabled: true, style: None },
    Action { id: "cancel", label: "Cancel", enabled: true, style: None },
];
let dialog = ChoiceDialog::new(
    Dialog::new("Confirm", Text::from("Continue?"), &theme),
    &actions,
);
let mut state = ChoiceDialogState::new(Some("cancel"));
let outcome = state.handle_key(&actions, KeyEvent::new(KeyCode::Enter, KeyModifiers::NONE));
assert!(matches!(outcome, Outcome::Activated("cancel")));
let _ = dialog;
```

## Anatomy

`backdrop` · `panel` · `title` · `body` · `action_bar` · focus on safe action

## Public API (intent)

| API | Why |
|-----|-----|
| `Dialog::new(title, body, theme)` | Chrome only |
| `ChoiceDialog` + state | Stable action ids + outcomes |
| `place_dialog` / overlay open | Policy-aware geometry via OverlayStack |

## State ownership

| TermRock | Consumer |
|----------|----------|
| Focused action, hits | When dialog is open |
| Placement | Copy, quit, domain confirm |
| Esc outcome | Map Esc → cancel vs trap |

## Typed outcomes

`Outcome::Activated(id)` / `Changed` / `Cancelled` — consumer closes layer and
applies policy.

## Variants / sizes / density

Message vs choice; `DialogSize` preferred/min; narrow → fullscreen promote via
overlay policy.

## Keyboard / mouse / focus

Tab/arrows among actions; Enter activates; Esc cancels (unless alert trap).
Click actions; outside-click per overlay outside policy (dialogs often Trap).

## Responsive / a11y / unicode

Stories: `dialog/message`, `dialog/narrow`, `choice-dialog/basic`. Title survives
contraction longer than subtitle/footer.

## Composition

OverlayStack Dialog/AlertDialog kind; AgentWorkbench modals; forms.

## Theming

`PanelEmphasis::Focused` / Danger for destructive confirms.

## Common mistakes

- Default-focusing “Delete” on destructive confirms.  
- Handling Esc as Allow.  
- Painting dialog without a layer in the scene.

## Performance

One card; negligible. Prefer not rebuilding action vec every frame if static.
