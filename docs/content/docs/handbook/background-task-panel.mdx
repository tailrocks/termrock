# BackgroundTaskPanel

Multi-job supervisor UI: list + live output detail, reconnect/lost states,
bounded scrollback with drop banners. Outcomes request stop/restart/detach only.

## When to use / when not

| Use BackgroundTaskPanel | Prefer |
|-------------------------|--------|
| Detached builds, watchers, servers | — |
| OS process browser | [ProcessTable](/docs/handbook/process-table) |
| Single agent shell card | [TerminalRunCard](/docs/handbook/terminal-run-card) |
| Agent task inventory | [TaskRail](/docs/handbook/task-rail) |

## Output history

`BackgroundOutputBuffer` caps lines (`BACKGROUND_TASK_DEFAULT_HISTORY`); paints
dropped-line indicator when eviction occurs.

## Keys

j/k · enter open · x stop · r restart · d detach · f follow · Shift+C clear done · esc close
