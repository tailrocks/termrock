# KeyValueTable

**Purpose.** Metadata and property panels: HTTP headers, DB columns, process
facts, permission claims, agent/tool details. One focus target per row; copy /
edit / reveal / link via chords (not tab soup).

Contracts **columns → stacked** under width pressure. Compare mode shows
before/after when fields set `.compare(…)`.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use

| Use KeyValueTable | Prefer |
|-------------------|--------|
| Detail side panels | — |
| Secrets + copy + edit | — |
| Compare local vs remote | — |
| Simple settings list | [KeyValueList](/docs/handbook/list) |
| Dialog details legacy | DetailTable |
| Nested JSON tree | ObjectInspector |

## Actions (single focus)

| Key | Action |
|-----|--------|
| j/k ↑↓ | Row navigation |
| c | Copy value |
| e | Edit (if editable) |
| r | Reveal/hide secret |
| d | Toggle compare mode |
| / | Filter keys |
| Enter | Link or copy |

## Example

```rust
use termrock::widgets::{KeyValueTable, KeyValueTableState, KvtField, KvtValidation};

let fields = [
    KvtField::pair("auth", "authorization", "Bearer …")
        .secret()
        .copyable()
        .value_type("secret")
        .source("header"),
    KvtField::pair("len", "content-length", "-1")
        .validation(KvtValidation::Error)
        .validation_message("must be >= 0"),
];
let mut state = KeyValueTableState::new().with_cursor("auth");
let _ = (fields, &mut state);
```
