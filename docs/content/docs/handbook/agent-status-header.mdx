# AgentStatusHeader

Top-level chrome for project/session, branch, mode/model, connection, work
status, context, cost/time, and action-required. **Provider-neutral.**

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

<TerminalPreview story="agent-status-header/basic" interactive caption="AgentStatusHeader · agent-status-header/basic — Ghostty truecolor focus surface" />

## When to use / when not

| Use AgentStatusHeader | Prefer |
|-----------------------|--------|
| Agent workbench header | — |
| Generic L/C/R slots | [StatusBar](/docs/handbook) if documented |
| Full token budget UI | [ContextMeter](/docs/handbook/context-meter) |

## Presentation

| Form | When |
|------|------|
| Header (1–2 rows) | Wide (≥56 cols default) |
| StatusBar | Narrow auto-contract |

## Priority

Action-required / connection issues paint before decorative cost/time.
