# StreamingMarkdown

Token-by-token AI Markdown: unfinished fences/lists/tables without thrashing
layout. Paints through `MarkdownView`; projects `plain_lines` for MessageThread.

## When to use / when not

| Use StreamingMarkdown | Prefer |
|-----------------------|--------|
| Assistant stream body | — |
| Static docs | [MarkdownView](/docs/handbook/markdown) |
| Conversation chrome | [MessageThread](/docs/handbook/message-thread) |

## Stable prefix

`committed` only grows on deltas. `tail` is the reparse window. `finish()` flushes.

## Batching

```rust
state.coalesce_deltas = 8;
state.push_delta(token); // may wait
state.apply_pending();   // force
```
