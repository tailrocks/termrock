# HostFrame (lookbook host)

How TermRock’s **lookbook** owns a frame after Break K partial. Not a public widget — a **host recipe** apps should mirror.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## Authorities (only these)

| Concern | Type |
|---------|------|
| Paint | `DesignSystem` / `RolePalette` |
| Focus / hit / layers | `InteractionScene` |
| Floating UI | `OverlayStack` |
| Domain modal body | App-owned state (`Option<…>`) |

**Deleted:** lookbook `host_focus` FocusRing fork.

## Frame loop

1. `scene.begin_frame()` (+ ensure root layer).  
2. Register shell controls with painted `Rect`s.  
3. If a modal is open: ensure modal layer (`owns_input`), register actions.  
4. `scene.reconcile()`.  
5. Paint panels with `PanelChrome::Focused` only for `scene.focused()`.  
6. `overlays.reflow` + optional `render_backdrop` when policy ≠ None.  
7. Paint overlay content into stack geometry.

## Esc order

1. `OverlayStack::handle_escape` (if stack non-empty).  
2. `InteractionScene::handle_escape` (dismissible layers).  
3. Host quit / bubble — never implicit.

## Tab

`scene.handle_key_tab_esc` — candidates limited to the top input-owning layer.
