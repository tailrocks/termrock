# DiffReview

Review a **projected** patch. TermRock owns hunk cursor, scroll, and chrome;
you own git, stage, multi-file, and line text.

## When to use / when not

| Use DiffReview | Prefer |
|----------------|--------|
| Interactive hunk nav over projected lines | — |
| Static syntax-neutral paint only | DiffView |
| Chat/tool output stream | Transcript / LogStream |

## Outcomes

- `Ignored`
- `HunkCursorMoved { index }`
- `HunkActivated { index }` — consumer stages/opens/copies
- `Scrolled { offset }`
- `ToggleMode` — split preference flip (narrow still paints unified)

## Focus law

| Concern | Owner |
|---------|--------|
| Surface focus | Host / OverlayStack / InteractionScene |
| Hunk cursor | `DiffReviewState::hunk_cursor` |
| Line buffer | Consumer projection |

## Keys

| Key | Behavior |
|-----|----------|
| `n` / `p` | Next / previous hunk |
| j/k arrows page | Line scroll |
| Home / End | First / last hunk |
| Enter | Activate hunk |
| `s` / Space | Toggle split preference |

## Non-color

- Active hunk gutter: `›` / `>` (unfocused `·` / `.`)
- Empty: `∅` / `[ ]`
- Colorless: strong add/remove; context text

## Responsive

| Width | Layout |
|-------|--------|
| ≥ 28 | Full line + gutter; split preferred when set |
| &lt; 28 | Force unified paint |
| &lt; 16 | Hunk header strip + clipped lines |
