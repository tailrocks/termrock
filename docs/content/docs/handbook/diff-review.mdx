# DiffReview

Thin review layer over [DiffView](/docs/handbook/diff-view). Same `DiffLine` /
`DiffHunk` projection; state wraps `DiffViewState`; paint delegates to DiffView.
Use when Enter should surface **activate/stage** product effects.

## When to use / when not

| Use DiffReview | Prefer |
|----------------|--------|
| Interactive hunk nav + activate | — |
| Pure read-only viewing | [DiffView](/docs/handbook/diff-view) |

## Outcomes

Maps from `DiffViewOutcome`:

- `HunkCursorMoved` · `HunkActivated` · `Scrolled` · `ToggleMode`
- `CursorMoved` · `SearchChanged` · `FoldToggled` · `Cancelled` · `Ignored`

## Keys

Same as DiffView (`n`/`p`, `s`, `/`, `z`, Enter). Prefer
`handle_key_lines(key, lines, hunks)` when a projection is available.

## Example

```rust
use termrock::widgets::{DiffLine, DiffHunk, DiffReview, DiffReviewState};

let lines = [DiffLine::added("1", "ready")];
let hunks = [DiffHunk::new(0, 1, "@@").id("h0")];
let mut state = DiffReviewState::new();
// DiffReview::new(&lines, &system).hunks(&hunks).render(area, buf, &mut state);
let _ = (lines, hunks, state);
```
