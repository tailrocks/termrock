## Usage

```rust
use termrock::widgets::{Badge, BadgeState};

Badge::new("live", &system).success().paint(area, buf, None);
Badge::count(150, &system).paint(area, buf, None); // (99+)
Badge::new("beta", &system).outline().paint(area, buf, None);

// Interactive (focus/select only when opted in)
let mut state = BadgeState::new();
state.set_focused(true);
Badge::new("filter", &system)
    .interactive(true)
    .paint(area, buf, Some(&mut state));
```

## Variants

| Variant | Paint |
|---------|-------|
| Neutral | muted `[meta]` |
| Info | info + glyph |
| Success | success + ✓ |
| Warning | warning + ! |
| Destructive | danger + error glyph |
| Outline | `⟨tag⟩` border role |
| Count | `(n)` / `(99+)` |

Default **fill is none** (no bg) so dense tables stay quiet. Use `.soft()` only when emphasis needs a quiet underlay.

## Interactive vs static

| | Static (default) | Interactive |
|--|------------------|-------------|
| Focus / select | n/a | `BadgeState` |
| Activate | ignored | Enter / click |
| Semantic role | Status content | Button control |

## Critical meaning

Status variants pair a catalog glyph with a **label** so no-color profiles still read. Prefer `plain()` for a11y (`ok (success)`).
