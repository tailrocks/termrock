## Usage

The Code view above and this source excerpt use the exact paint setup registered for `sparkline/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn sparkline(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let samples = [0.1, 0.3, 0.2, 0.7, 0.9, f64::NAN, 0.8, 0.4, 0.6, 0.95];
    frame.render_widget(
        Sparkline::new(&samples, system)
            .pre_normalized(true)
            .threshold(0.75)
            .selected(4),
        area,
    );
}
```
