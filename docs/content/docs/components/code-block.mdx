## Usage

```rust
use termrock::widgets::{
    CodeBlock, CodeBlockState, CodeWrap, RoleTokenSyntax,
};

let lines = ["fn main() {}", "    println!(\"hi\");"];
let hi = RoleTokenSyntax::rust(&system);
let mut state = CodeBlockState::new();
state.set_focused(true);

CodeBlock::new(&lines, &system)
    .language("rust")
    .path("src/main.rs")
    .line_numbers(true)
    .highlighter(&hi)
    .paint(area, buf, &mut state);
```

## Large files

Host windows the buffer; CodeBlock paints only that window:

```rust
CodeBlock::new(&slice, &system)
    .line_base(offset)
    .logical_len(total_lines)
    .line_numbers(true);
```

## Composition

| Host | Hook |
|------|------|
| Diagnostic | `CodeGutterMark` + `CodeHighlightKind::Diagnostic` |
| DiffReview | `DiffAdd` / `DiffRemove` highlights |
| PlanReview | `Emphasis` highlights / gutter pins |
| TerminalOutput | strip ANSI then `RoleTokenSyntax`, or custom highlighter |
