## Usage

```rust
use termrock::widgets::{ActionLink, ActionLinkOutcome, LinkState};

let mut state = LinkState::new();
state.set_focused(true);
let action = ActionLink::new("Run tests", &system).risk_note("cargo test");
let _ = action.paint(area, buf, &mut state);
match action.handle_key(&mut state, key) {
    ActionLinkOutcome::Activated => { /* run */ }
    ActionLinkOutcome::Ignored => {}
}
```

## vs Link

| | Link | ActionLink |
|---|------|------------|
| Destination | URL or app route | None |
| OSC 8 | URL when capable | Never |
| Risk | Destination / external cue | Optional `risk_note` |
| Outcomes | Activate + Copy | Activate |
