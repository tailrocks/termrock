## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

<TerminalPreview story="action-link/basic" interactive caption="ActionLink · ActionLink — live shared Rust state" />

## Try it

- `hover to highlight`: Move the pointer over the target; hover chrome changes without activation.
- `Enter activate`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `click action`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The demo owns ephemeral widget state between events. The widget owns painted geometry, focus/selection mechanics, and typed outcomes. The host owns domain effects and decides what an emitted outcome means to the application.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `action-link/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn action_link_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let mut state = LinkState::new();
    state.set_focused(true);
    let _ = ActionLink::new("Run tests", system)
        .risk_note("cargo test")
        .paint(area, frame.buffer_mut(), &mut state);
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.

## Test recipe

Mount `action-link/basic`, dispatch each listed action, and assert the typed outcome, changed Ratatui cells, persistent follow-up state, pointer hit geometry, and Reset behavior.
