## Live terminal (Ghostty-class)

This is a persistent sample-application demo. Navigate rows, filter through a real TextInput, toggle the sidebar region, and open the effect-free action dialog.

## Usage

```rust
use termrock::widgets::{
    example_working_state, WorkingStateCard, WorkingStateCardState,
    WorkingStateOutcome,
};

let mut state = WorkingStateCardState::new();
state.set_work(Some(example_working_state()));
WorkingStateCard::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    WorkingStateOutcome::CancelRequested { id } => { let _ = id; }
    WorkingStateOutcome::Collapsed => {
        let _ = state.to_activity_item(); // ActivityShelf
    }
    _ => {}
}
```

## Try it

- `Enter open action` or `click trigger` opens a real ChoiceDialog.
- `S toggle sidebar region` changes visible chrome.
- `↑↓/wheel select row` changes persistent selection.
- `/ filter` focuses a real TextInput; type or paste, then apply with Enter.

Accepted actions update the same mounted Rust value. The status line shows the latest outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The mounted Rust demo owns deterministic sample state. The component/pattern owns its reusable paint and interaction contracts; the consuming host owns domain policy and every external effect.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.

## Test recipe

Mount `working-state-card/basic`, dispatch only the actions listed above, and assert both the returned outcome and changed Ratatui cells. Passive demos must reject input without trapping page navigation.

## Migrated handbook guidance

# WorkingStateCard

Non-invasive “what is the agent doing now” card. Host supplies a **public
summary** only — never private chain-of-thought.
Collapsed status uses a quiet host-ticked pulse; expanded detail continues an
assistant actor rail. Pass `.tick(frame_tick)`; reduced motion stays static.


## When to use / when not

| Use WorkingStateCard | Prefer |
|----------------------|--------|
| Current turn work status | — |
| Multi concurrent ops strip | [ActivityShelf](/docs/components) |
| Raw reasoning chrome | ThinkingBlock (host policy) |
| Session-level chrome | [AgentStatusHeader](/docs/components/agent-status-header) |
