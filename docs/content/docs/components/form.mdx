## Usage

```rust
use termrock::widgets::{Field, Fieldset, Form, FormState, FormOutcome, first_invalid_id};

let fields = [
    Field::new("name", "Name", name).required(true).dirty(dirty),
    Field::new("host", "Host", host).error(err).touched(true),
];
let sets = [Fieldset::new("General", &fields)];
let mut state = FormState::new();

Form::new(&sets, &system)
    .focused_field(scene.focused())
    .paint/render...;

match state.handle_key(&sets, key, scene.focused()) {
    FormOutcome::SubmitRequested => { /* host submit */ }
    FormOutcome::Activated(id) => { /* edit field */ }
    _ => {}
}
```

## Ownership

| Concern | Owner |
|---------|--------|
| Domain values / validation | **Host** |
| dirty / touched / status projection | **Host** on `Field` |
| Field keyboard focus | **InteractionScene** |
| Scroll / hits / summary paint | **Form** |
