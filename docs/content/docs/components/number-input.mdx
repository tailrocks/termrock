**Purpose.** Integer or decimal entry for forms and settings: min/max/step,
units, empty/intermediate invalid states, steppers, and safe overflow.

## Draft vs committed

| | Draft (`draft_text`) | Committed (`value`) |
|--|----------------------|---------------------|
| Typing | live | unchanged |
| Enter / blur / step | reformatted | clamped + snapped |
| Esc | restored | unchanged |

Storage uses locale-independent `f64` with `.` as the only decimal separator.
