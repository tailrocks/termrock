## Anatomy

`area` (outer) · `content` (after margins) · `child` (placed rect)

## Usage

```rust
use termrock::layout::{Center, CenterAxis, centered_rect};

let child = Center::new(40, 12).layout(area).child;
// legacy alias with safe margin:
let child = centered_rect(52, 9, area);
```

## Axes

| Axis | Behavior |
|------|----------|
| Both | Center X and Y; preferred size |
| Horizontal | Center X; height fills content |
| Vertical | Center Y; width fills content |

## Semantics

Center is **not** interactive. Do not register it on FocusGraph — register the
**child** widgets only.

## Common mistakes

- Treating Center as a Panel (it does not paint borders)
- Forgetting max-width on wide terminals (content stretches too wide)
- Assuming underflow on tiny sizes (child is clamped inside)
