## Usage

```rust
use termrock::widgets::{RangeSlider, RangeSliderState, SliderBounds};

let mut state = RangeSliderState::new(20.0, 80.0);
state.set_focused(true);
RangeSlider::new(SliderBounds::percent(), &system)
    .label("Price")
    .paint(area, buf, &mut state);
// Tab → switch active thumb; arrows move that thumb
```

## Contract

| Concern | Rule |
|---------|------|
| Thumbs | Start/End; Tab switches |
| Clamp | Start ≤ End always |
| Tiny | Numeric `lo–hi` face |
| Outcomes | `ValueChanged { start, end }` · `ThumbChanged` |
