## Usage

The Code view above and this source excerpt use the exact paint setup registered for `key-value-table/http`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn key_value_table_http(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::widgets::LoadState;
    let fields = [
        KvtField::group("g", "Request"),
        KvtField::pair("m", "method", "GET")
            .value_type("string")
            .source("line")
            .copyable()
            .depth(1),
        KvtField::pair("h", "host", "api.tailrocks.dev")
            .value_type("host")
            .source("header")
            .copyable()
            .depth(1),
        KvtField::pair("a", "authorization", "Bearer sk-live-…")
            .value_type("secret")
            .source("header")
            .secret()
            .copyable()
            .depth(1),
        KvtField::pair("c", "content-type", "application/json")
            .value_type("mime")
            .source("header")
            .editable()
            .depth(1),
        KvtField::pair("u", "user-agent", "termrock/0.11")
            .value_type("string")
            .source("header")
            .depth(1),
    ];
    let mut state = KeyValueTableState::new().with_cursor("h");
    state.load = LoadState::Ready { count: 5 };
    KeyValueTable::new(&fields, system).render(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# KeyValueTable

**Purpose.** Metadata and property panels: HTTP headers, DB columns, process
facts, permission claims, agent/tool details. One focus target per row; copy /
edit / reveal / link via chords (not tab soup).

Contracts **columns → stacked** under width pressure. Compare mode shows
before/after when fields set `.compare(…)`.


## When to use

| Use KeyValueTable | Prefer |
|-------------------|--------|
| Detail side panels | — |
| Secrets + copy + edit | — |
| Compare local vs remote | — |
| Simple settings list | [KeyValueList](/docs/components/list) |
| Dialog details legacy | DetailTable |
| Nested JSON tree | ObjectInspector |

## Example

```rust
use termrock::widgets::{KeyValueTable, KeyValueTableState, KvtField, KvtValidation};

let fields = [
    KvtField::pair("auth", "authorization", "Bearer …")
        .secret()
        .copyable()
        .value_type("secret")
        .source("header"),
    KvtField::pair("len", "content-length", "-1")
        .validation(KvtValidation::Error)
        .validation_message("must be >= 0"),
];
let mut state = KeyValueTableState::new().with_cursor("auth");
let _ = (fields, &mut state);
```
