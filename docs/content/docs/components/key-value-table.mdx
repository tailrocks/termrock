**Purpose.** Metadata and property panels: HTTP headers, DB columns, process
facts, permission claims, agent/tool details. One focus target per row; copy /
edit / reveal / link via chords (not tab soup).

Contracts **columns → stacked** under width pressure. Compare mode shows
before/after when fields set `.compare(…)`.

## When to use

| Use KeyValueTable | Prefer |
|-------------------|--------|
| Detail side panels | — |
| Secrets + copy + edit | — |
| Compare local vs remote | — |
| Simple settings list | [KeyValueList](/docs/components/list) |
| Dialog details legacy | DetailTable |
| Nested JSON tree | ObjectInspector |

## Actions (single focus)

| Key | Action |
|-----|--------|
| j/k ↑↓ | Row navigation |
| c | Copy value |
| e | Edit (if editable) |
| r | Reveal/hide secret |
| d | Toggle compare mode |
| / | Filter keys |
| Enter | Link or copy |
