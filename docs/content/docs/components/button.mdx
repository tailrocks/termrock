## Usage

```rust
use termrock::widgets::{Button, ButtonState, ButtonVariant, ActivationOutcome};

let mut state = ButtonState::new();
state.activation.set_accepts_input(true);

Button::new("Save", &system)
    .as_primary()
    .leading("✓")
    .paint(area, buf, &mut state);

match state.handle_key(key) {
    ActivationOutcome::Activated => { /* effect */ }
    ActivationOutcome::ConfirmRequired => { /* show ? */ }
    _ => {}
}
```

## Activation law

- Enter activates on **Press** (Repeat ignored).
- Space arms on Press, activates on **Release**.
- Pointer: Down arms, Up **inside** region activates.
- Destructive: never safe default focus; optional two-step confirm.
