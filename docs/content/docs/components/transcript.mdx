## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

<TerminalPreview story="transcript/basic" interactive caption="Transcript · Transcript — live shared Rust state" />

## Try it

- `wheel to scroll`: Scroll over the preview; its own viewport moves while the docs page stays put.
- `↑↓ navigate`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The demo owns ephemeral widget state between events. The widget owns painted geometry, focus/selection mechanics, and typed outcomes. The host owns domain effects and decides what an emitted outcome means to the application.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `transcript/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn transcript_basic(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let user = [
        "Run the release suite",
        "include docs and capability checks",
    ];
    let assistant = [
        "I’ll verify the full workspace.",
        "The dependency graph is clean.",
    ];
    let thinking = [
        "Inspecting affected surfaces…",
        "Checking migration order…",
        "Comparing deterministic frames…",
        "Hidden reasoning beyond preview.",
    ];
    let tool = ["mise run check", "2,968 tests · all green"];
    let blocks = [
        TranscriptBlock::new("u1", TranscriptKind::User, &user),
        TranscriptBlock::new("a1", TranscriptKind::Assistant, &assistant),
        TranscriptBlock::new("th1", TranscriptKind::Thinking, &thinking)
            .folded(true)
            .summary("Reasoning through the verification plan"),
        TranscriptBlock::new("t1", TranscriptKind::Tool, &tool).active(true),
    ];
    let mut state = TranscriptState::new();
    frame.render_stateful_widget(&Transcript::new(&blocks, system).tick(7), area, &mut state);
}
```

## Migrated handbook guidance

# Transcript

Flagship conversation viewport. **Only** public stream widget after migration `0064`.


## When to use

| Use Transcript | Prefer |
|----------------|--------|
| Agent / chat multi-block stream | LogPane for machine logs |
| Variable-height blocks + follow | List for flat selectable rows |
| Folded tool summaries | DetailTable for key/value |

## Anatomy

- Kind prefix (glyph or ASCII) — non-color cue  
- Optional fold marker  
- Selection gutter when focused  
- Follow-tail + stable block anchor across append/resize  
- Empty label when no blocks  

## API sketch

```rust
use termrock::widgets::{Transcript, TranscriptBlock, TranscriptKind, TranscriptState};
use termrock::style::DesignSystem;

let system = DesignSystem::default();
let lines = ["hello"];
let blocks = [TranscriptBlock::new("1", TranscriptKind::User, &lines)];
let mut state = TranscriptState::new();
let _ = Transcript::new(&blocks, &system).focused(true).ascii(false);
```
