The Code view above and this source excerpt use the exact paint setup registered for `token-meter/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

// Exact paint setup used by the shared catalog story.
fn token_meter(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
