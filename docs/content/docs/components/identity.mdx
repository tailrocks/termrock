## Usage

```rust
use termrock::widgets::{Identity, IdentityRole, PresenceStatus};

Identity::new("termrock-agent", &system)
    .role(IdentityRole::Agent)
    .secondary("planning")
    .badge(true)
    .presence(PresenceStatus::Busy)
    .paint(area, buf);
```
