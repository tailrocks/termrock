## Live terminal (Ghostty-class)

One focused interactive surface. Variants are listed in **Stories** — interactivity
replaces multi-image galleries.

<TerminalPreview story="form/responsive" interactive caption="Fieldset · form/responsive — focus surface; keys/click for states" />

## Usage

```rust
use termrock::widgets::{Field, Fieldset};

let fields = [Field::new("a", "A", "1"), Field::new("b", "B", "2")];
Fieldset::new("Network", &fields).description("Connectivity");
```

Historical alias: `FormSection`.
