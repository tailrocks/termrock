## Usage

```rust
use termrock::widgets::{HighlightedText, MatchTruncate, substring_ranges};

let ranges = substring_ranges(path, query);
HighlightedText::prepared(path, ranges.as_slice(), &system)
    .truncate(MatchTruncate::KeepFirstMatch)
    .paint(area, buf);
```

## MatchRanges

Build offline when the query changes; pass prepared slices into paint every frame.
