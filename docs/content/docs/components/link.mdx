## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

<TerminalPreview story="link/basic" interactive caption="Link · Link external — live shared Rust state" />

## Try it

- `hover`: Move the pointer over the target; hover chrome changes without activation.
- `click open`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `Enter open`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `C copy destination`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The mounted widget owns interaction state, focus chrome, hit geometry, and typed outcomes. The host only forwards backend-neutral events and performs no external effects.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `link/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn link_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let mut state = LinkState::new();
    state.set_focused(true);
    let _ = Link::url("docs", "https://example.invalid/docs", system)
        .hyperlinks(true)
        .paint(area, frame.buffer_mut(), &mut state);
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
