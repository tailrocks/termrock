## Usage

```rust
use termrock::style::DesignSystem;
use termrock::runtime::FrameTick;
use termrock::widgets::{
    Anchor, Severity, Toast, ToastQueue, ToastSpec, ToastStack, TOAST_DEFAULT_TTL,
};
use std::time::{Duration, Instant};

let system = DesignSystem::default();
// Single:
Toast::new(&system, "Saved", Severity::Success)
    .anchor(Anchor::TopRight)
    .paint(area, buf);

// Queue:
let tick = FrameTick::manual(Instant::now(), Duration::ZERO, Duration::ZERO);
let mut queue = ToastQueue::new();
let _ = queue.push(tick, ToastSpec::message("s", "Saved").severity(Severity::Success));
let _ = queue.push(tick, ToastSpec::message("p", "Upload").progress(40).group("up"));
ToastStack::new(&system).paint(area, buf, &mut queue);
// NotificationCenter: queue.drain_missed()
let _ = TOAST_DEFAULT_TTL;
```

## Rules

1. Never steals keyboard focus (`is_focusable() == false`).
2. Corner placement only — no full-screen dim.
3. Pause TTL while pointer is over the stack.
4. Expired/evicted items archive for NotificationCenter.

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | caller-owned (optional host undo hotkey) |
| Mouse | covered (pause hit regions) |
| Focus | covered (never focusable) |
| Non-color cues | covered (glyphs) |
| Unicode | covered |
| Narrow terminal | covered |
