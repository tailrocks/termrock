## Usage

```rust
use termrock::style::{DesignSystem, Motion};
use termrock::widgets::{Spinner, SpinnerState, ActivityPhase};

let system = DesignSystem::default();
let mut state = SpinnerState::new();
state.set_active(working);
state.set_visible(on_screen);
if state.should_tick() {
    let _demand = state.animation_demand(tick, Motion::Full);
}
Spinner::labeled("Fetching packages", &system)
    .phase(ActivityPhase::Indeterminate)
    .paint(area, buf, &state, tick, Motion::Full);
```

## Rules

1. Prefer a verb label; compact glyph-only only when embedded in a labeled control.
2. Call `set_active(false)` / `set_visible(false)` to stop frame ticks.
3. `Motion::Off` / `Reduced` use static non-color glyphs.
