## Usage

The Code view above and this source excerpt use the exact paint setup registered for `spinner/labeled`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn spinner_labeled_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use std::time::Duration;
    use termrock::runtime::FrameTick;
    use termrock::runtime::Instant;
    use termrock::style::MotionPolicy;
    let state = SpinnerState::new();
    let tick = crate::demo::demo_tick(400);
    Spinner::labeled("Fetching packages", system).paint(
        area,
        frame.buffer_mut(),
        &state,
        tick,
        MotionPolicy::Full,
    );
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
