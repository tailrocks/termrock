## Usage

```rust
use termrock::widgets::{TextInput, TextInputState, TextInputOutcome, Validation};

let mut state = TextInputState::new("").with_allow_empty(true);
state.set_focused(true);
TextInput::new("Query", &system)
    .placeholder("Search…")
    .prefix("🔍")
    .show_clear(true)
    .paint(area, buf, &mut state);

// Host clipboard
match state.handle_key(key) {
    TextInputOutcome::ClipboardPasteRequest => {
        let _ = state.insert_str(&host_paste);
    }
    TextInputOutcome::ClipboardCopy { text } => host_copy(text),
    _ => {}
}
```

## Contract

| Concern | Rule |
|---------|------|
| Graphemes | Cursor always on extended grapheme boundary |
| Selection | Shift+arrows / mouse drag; reverse paint |
| Undo | Up to 64 snapshots |
| Paste | `insert_str` strips CR/LF and controls |
| Secret | Mask graphemes; a11y label still “secret” |
| Intent | `handle_intent` for Submit/Cancel/Move |
