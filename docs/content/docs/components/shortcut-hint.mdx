## Usage

```rust
use termrock::widgets::ShortcutHint;

// Prefer keymap derivation — no hardcoded chord labels
let hint = ShortcutHint::for_action(&map, Action::Save, &system)?
    .footer();
hint.paint(area, buf);

ShortcutHint::new("C-S", "Save", &system).inline_doc();
```

## Forms

| Form | Layout |
|------|--------|
| Footer | `C-s Save` |
| InlineDoc | `Save  C-s` |
| Keycap | `[C-s] Save` |

## Narrow contraction

Command label drops **before** the chord when width is tight so the binding remains visible.
