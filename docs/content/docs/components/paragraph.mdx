## Anatomy

Optional indent · first-line prefix · hanging body lines

Uses **Text** per line and shared wrap helpers from `crate::text`.

## Kinds

| Kind | Prefix (Unicode / ASCII) |
|------|---------------------------|
| Body | (none) |
| Quote | `│ ` / `\| ` |
| ListItem | `• ` / `* ` |
| OrderedItem | `1. ` … |

## Recipes

| Recipe | Behavior |
|--------|----------|
| Compact | Minimal indent (default) |
| Reading | Slight pad for quote/list; hanging wrap |

## Usage

```rust
use termrock::widgets::Paragraph;

Paragraph::new("Body wraps by display columns.", &system)
    .reading()
    .copyable()
    .paint(area, buf);

Paragraph::quote("Cited text…", &system).paint(area, buf);
Paragraph::list_item("Bullet…", &system).paint(area, buf);
Paragraph::ordered_item("Step…", &system, 2).paint(area, buf);

let rows = paragraph.measure_height(width);
let parts = paragraph.layout(area); // parts.lines, parts.truncated
```

## Hanging wrap

Quote/list prefixes appear on the first line; subsequent lines indent to the
prefix width so the body column stays aligned (man-page / help style).

## Markdown

`MarkdownView` paints paragraph / quote / list blocks through **Paragraph** so
wrap and prefixes stay single-sourced.
