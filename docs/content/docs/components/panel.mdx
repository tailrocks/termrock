## Anatomy

`root` · `header` · `body` · `footer` · optional `disclosure` · optional `actions`

Slots on the title line: **leading** · **title** · **subtitle** · **badge** · **trailing** · **header_actions**.

## Variants

| Variant | Border | Notes |
|---------|--------|-------|
| Bordered | box | default |
| Quiet | none | transparent fill |
| DividerOnly | top/bottom rules | ASCII fallback via GlyphSet |
| Interactive | box | panel-level focus + Activate |
| Selected | box | selection chrome — **not** focus |

Focus uses `PanelChrome::Focused` → `Role::BorderFocused` (never border weight).

## Body modes

| Mode | Use |
|------|-----|
| Host | Default — host paints children into `body` |
| Loading | `LoadingView` + optional `body_detail` |
| Empty | `EmptyState` + `body_title` / `body_detail` |
| Error | `ErrorView` + `body_title` / `body_detail` |

## Responsive drop order

First dropped under pressure → last kept:

footer → header_actions (&lt; 28 cols) → badge → trailing → subtitle → leading → title

## Usage

```rust
use termrock::{
    style::{DesignSystem, PanelChrome},
    widgets::{Panel, PanelAction, PanelBody, PanelState, PanelVariant},
};

let system = DesignSystem::default();
let actions = [PanelAction::new("retry", "Retry")];
let mut state = PanelState::new();
let body = Panel::new(&system)
    .title("Build")
    .subtitle("main")
    .badge("failed")
    .header_actions(&actions)
    .variant(PanelVariant::Bordered)
    .body(PanelBody::Error)
    .body_title("Failed")
    .body_detail("timeout")
    .paint(area, buf, Some(&mut state));
// children only inside `body` when Host mode
```

## Keyboard (when focusable)

Only **Interactive** or **collapsible** panels claim panel-level focus.
Otherwise focus stays on real interactive descendants.

| Intent | Keys (default maps) | Outcome |
|--------|---------------------|---------|
| Activate | Enter | `Activated` (interactive) or toggle (collapsible) |
| Toggle | Space | `ToggleCollapsed` |
| Expand / Collapse | Right/Left (list map) | expand/collapse |

Header actions are mouse hit-targets (`action_hits`); keyboard routing is host-owned.

## Mouse

- Click header action → `HeaderAction { id }` (does not toggle collapse)
- Click header/disclosure (collapsible) → toggle collapse
- Click hit region (interactive) → Activate

## Common mistakes

- Using selected chrome as focus — keep focus on `BorderFocused`
- Nesting Panels for padding — use Surface/padding, one Panel per region
- Painting children outside `body` / `clip`
- Focusing a static bordered panel that only wraps a list — focus the list
