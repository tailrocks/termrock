## Usage

```rust
use ratatui_core::layout::Rect;
use termrock::style::DesignSystem;
use termrock::widgets::{
    CompletionCandidate, CompletionMenu, CompletionMenuSize, CompletionMenuState,
    open_completion_overlay,
};

let system = DesignSystem::default();
let candidates = [
    CompletionCandidate::new("select", "SELECT")
        .kind("keyword")
        .group("Keywords")
        .documentation("Select rows."),
];
let mut state = CompletionMenuState::new(Some("select"));
state.set_commit_characters("().");
// async: let gen = state.begin_async(); … state.apply_results(gen, &candidates);
let bounds = Rect::new(0, 0, 80, 24);
let anchor = Rect::new(12, 6, 1, 1);
// open_completion_overlay(&mut stack, bounds, anchor, size, Some("editor"));
// CompletionMenu::new(&candidates, &system, bounds, anchor).paint(…);
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (Tab/Enter commit, Esc dismiss, roving, commit chars) |
| Mouse | covered (hover select, click commit, outside dismiss) |
| Focus | covered (active descendant; no focus trap) |
| Non-color cues | covered (gutter ›, groups, loading/stale) |
| Unicode | covered |
| Narrow terminal | covered (fullscreen promotion) |
