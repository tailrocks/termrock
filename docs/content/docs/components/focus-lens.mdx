## Usage

```rust
use termrock::interaction::{FocusGraph, FocusLens, FocusLensMode};
use termrock::style::DesignSystem;

let system = DesignSystem::default();
FocusLens::new(&graph, &system)
    .mode(FocusLensMode::Combined)
    .ascii(false)
    .render(area, buf);
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | not-applicable (inspection) |
| Mouse | not-applicable |
| Focus visualization | covered |
| Non-color cues | covered |
| ASCII | covered |
