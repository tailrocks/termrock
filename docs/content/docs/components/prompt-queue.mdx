## Usage

```rust
use termrock::widgets::{
    example_prompt_queue, AgentBusyState, PromptQueue, PromptQueueOutcome,
    PromptQueuePresentation, PromptQueueState,
};

let mut state = PromptQueueState::new();
state.set_items(example_prompt_queue());
state.set_agent(AgentBusyState::Busy);
state.presentation = PromptQueuePresentation::Expanded;
PromptQueue::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    PromptQueueOutcome::SendNext { id } => { let _ = id; }
    PromptQueueOutcome::InterruptAndSend { id } => { let _ = id; }
    _ => {}
}
```

## Try it

- `Enter open action` or `click trigger` opens a real ChoiceDialog.
- `S toggle sidebar region` changes visible chrome.
- `↑↓/wheel select row` changes persistent selection.
- `/ filter` focuses a real TextInput; type or paste, then apply with Enter.

Accepted actions update the same mounted Rust value. The status line shows the latest outcome; **Reset** creates a fresh instance.

## Migrated handbook guidance

# PromptQueue

Queue of user messages behind active agent work. **Host owns** persistence and
drain policy. Failed/cancelled entries are **held** (KD-29 — no library
auto-drain).


## When to use / when not

| Use PromptQueue | Prefer |
|-----------------|--------|
| Show/manage queued prompts while busy | — |
| Draft editing | [PromptComposer](/docs/components/prompt-composer) |
| Overlay focus FIFO | OverlayStack (not user prompts) |
