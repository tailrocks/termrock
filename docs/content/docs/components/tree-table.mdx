## Usage

The Code view above and this source excerpt use the exact paint setup registered for `tree-table/process`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn tree_table_process(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::widgets::{ColumnModel, DataColumn, DataColumnWidth, LoadState, SortSpec};
    let tokens = system.clone().density(Density::Compact);
    let columns = ColumnModel::new(vec![
        DataColumn::new("name", "PROCESS", DataColumnWidth::Min(14)).priority(100),
        DataColumn::new("pid", "PID", DataColumnWidth::Fixed(6))
            .priority(90)
            .sortable(),
        DataColumn::new("cpu", "CPU%", DataColumnWidth::Fixed(6))
            .priority(70)
            .sortable(),
        DataColumn::new("mem", "MEM", DataColumnWidth::Fixed(7)).priority(50),
    ]);
    let r0: &[&str] = &["systemd", "1", "0.1", "4.2M"];
    let r1: &[&str] = &["sshd", "482", "0.0", "8.1M"];
    let r2: &[&str] = &["bash", "1204", "1.2", "12M"];
    let r3: &[&str] = &["cargo", "1888", "42.0", "640M"];
    let r4: &[&str] = &["rustc", "1902", "88.4", "1.1G"];
    let rows = [
        TreeTableRow::new(1u64, 0, r0).branch().expanded(),
        TreeTableRow::new(482, 1, r1).branch().expanded().parent(1),
        TreeTableRow::new(1204, 2, r2)
            .branch()
            .expanded()
            .parent(482),
        TreeTableRow::new(1888, 3, r3)
            .branch()
            .expanded()
            .parent(1204),
        TreeTableRow::new(1902, 4, r4).parent(1888),
    ];
    let mut state = TreeTableState::new(Some(1888));
    state.hovered = Some(1204);
    state.load = LoadState::Ready { count: 5 };
    state.sort = Some(SortSpec {
        column: "cpu",
        ascending: false,
    });
    TreeTable::new(&tokens, &columns, &rows)
        .focused(true)
        .compact_indent(true)
        .render(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# TreeTable

**Purpose.** Hierarchy plus multi-column metadata without ambiguous Left/Right
behavior. Host projects a **flattened** visible-expanded window; TermRock owns
indent, disclosure, sticky headers, selection, and outcomes.

Use [Tree](/docs/components/list) for single-column trees and
[DataTable](/docs/components/data-table) for flat grids.


## When to use

| Use TreeTable | Prefer |
|---------------|--------|
| Process / PID trees with CPU·MEM | — |
| DB schema browsers | — |
| Task / epic hierarchies | — |
| Dependency graphs (tree form) | Graph when cycles dominate |
| Single-column files | Tree |
| Flat query results | DataTable |

## Nav modes

| Mode | Left / Right |
|------|----------------|
| `Hierarchy` (default) | Collapse·parent / expand·enter child |
| `Cell` | Column cursor (Shift = hierarchy) |
| `Scroll` | Horizontal scroll only |

Cycle with `\`.

## Basic example

```rust
use termrock::widgets::{
    ColumnModel, DataColumn, DataColumnWidth, TreeTable, TreeTableRow, TreeTableState,
};

let columns = ColumnModel::new(vec![
    DataColumn::new("name", "Name", DataColumnWidth::Min(12)).priority(100),
    DataColumn::new("cpu", "CPU", DataColumnWidth::Fixed(6)).sortable(),
]);
let root: &[&str] = &["systemd", "0.1"];
let child: &[&str] = &["sshd", "0.0"];
let rows = [
    TreeTableRow::new(1u64, 0, root).branch().expanded(),
    TreeTableRow::new(2, 1, child).parent(1),
];
let mut state = TreeTableState::new(Some(1));
let _ = (columns, rows, &mut state);
```
