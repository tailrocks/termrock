## Usage

```rust
use ratatui_core::layout::Rect;
use termrock::interaction::{OverlaySize, OverlayStack};
use termrock::style::DesignSystem;
use termrock::widgets::{
    Popover, PopoverState, open_popover_overlay, POPOVER_OVERLAY_ID,
};

let system = DesignSystem::default();
let mut stack = OverlayStack::<&str>::new();
let bounds = Rect::new(0, 0, 80, 24);
let anchor = Rect::new(10, 5, 8, 1);
let size = OverlaySize::menu(28, 10);
let mut state = PopoverState::new();
let _ = state.open_on_stack(&mut stack, bounds, anchor, size, Some("trigger"));
// Paint: Popover::new("Settings", &system).paint(entry.rect, buf, &mut state);
// Host fills state.slots().body. Dismiss via stack → opener focus restored.
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (Esc / Cancel → close request; stack owns dismiss) |
| Mouse | covered (outside dismiss non-modal; trap when modal) |
| Focus | covered (opener restore, enter_focus, optional focus trap) |
| Non-color cues | covered (border roles, slots, ASCII mode) |
| Unicode | covered |
| Narrow terminal | covered (drawer / fullscreen contraction) |

## Stories

- `popover/basic` — header + body host content
- `popover/slots` — header / body / footer without Panel
- `popover/modal` — focus trap modality chrome
- `popover/narrow` — contraction path
- `popover/unicode` — CJK / emoji paint
