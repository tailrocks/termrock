## Anatomy

`title` · optional `rule` under the title

Built on **Text** for grapheme-safe paint.

## Levels

| Level | Weight | Default rule | Compact prefix |
|-------|--------|--------------|----------------|
| H1 | Strong + underline | yes (reading/default) | `# ` |
| H2 | Strong | reading only | `## ` |
| H3 | TextStrong role | no | `### ` |

## Recipes

| Recipe | Behavior |
|--------|----------|
| Default | H1 gets rule when height ≥ 2 |
| Compact | Single line + `#` depth prefixes (ASCII-friendly) |
| Reading | H1/H2 prefer rule under title |

## Usage

```rust
use termrock::widgets::{Heading, HeadingLevel};

Heading::new("Document", &system).h1().reading().paint(area, buf);
Heading::new("Section", &system).level(HeadingLevel::H2).compact();

let parts = heading.paint(area, buf);
// parts.title, parts.rule
```

## No-color / ASCII

Compact prefixes and GlyphSet rule units (`═`/`=` for H1, `─`/`-` for H2)
communicate hierarchy without relying on color alone.

## vs Text / Section / MarkdownView

| | Heading | Text | Section | MarkdownView |
