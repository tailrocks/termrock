**Purpose.** Date, time, and range selection when browse UX helps. Not a
replacement for every timestamp field.

## When TextInput is better

Use plain **TextInput** for:

- Rare free-form ISO stamps and log paste
- Machine-oriented values with no browse need
- Host-normalized strings without min/max UI

Use **DateTimePicker** for:

- Month navigation and “today”
- Inclusive ranges
- Stepped time lists
- Visible unavailable days (min/max)

## Ownership

| Concern | Owner |
|---------|--------|
| Civil storage types | TermRock |
| Presentation format enums | TermRock |
| “Today” civil date | Host (`set_today`) |
| Real timezone math | Host |
| Timezone **label** display | TermRock (`with_timezone_label`) |

## Storage

Locale-independent:

- `CivilDate` — proleptic Gregorian `YYYY-MM-DD`
- `CivilTime` — `HH:MM[:SS]` 24h storage
- `CivilDateTime` / `CivilDateRange`

Formats (`DateDisplayFormat`, `TimeDisplayFormat`) are **explicit**, never
inferred from host locale.

## Non-color states

`[sel]` · `*today*` · `>focus<` · `.unavailable.` — also bold / reverse /
underline roles when color is available.
