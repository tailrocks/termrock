## Usage

```rust
use ratatui_core::text::Line;
use termrock::widgets::{
    List, ListRow, ListState, ListSelectionMode, filter_list_rows,
};

let rows = [
    ListRow::group_header("g", Line::from("Running")),
    ListRow::item("a", Line::from("Build"))
        .secondary(Line::from("src/lib.rs"))
        .status(Line::from("ok"))
        .actions(Line::from("stop"))
        .shortcut("b"),
];
let mut state = ListState::new(Some("a"));
state.set_selection_mode(ListSelectionMode::Range);
// typeahead: Char keys; search: '/' then query; filter projection:
// let view = filter_list_rows(&rows, state.search_query().unwrap_or(""));

List::new(&rows, &system)
    .comfortable()
    .empty_message(Line::from("No items"));
```

## Rules

1. Prefer builders over struct literals (`ListRow` gained fields).
2. Keys: intents first (`handle_intent`); typeahead for printables.
3. Narrow drop order: shortcut → actions → badge → status → secondary → trailing → leading → primary.
4. Group headers / separators are not navigable.
5. Host owns durable selection storage; List holds active + multi model for the frame.

## Interaction contract

| Axis | Status |

| Keyboard | covered (intents + typeahead + search) |
| Mouse | covered (hit regions, multi check) |
