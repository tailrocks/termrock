- `/ search`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `Enter inspect`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `log-stream/follow`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn log_stream_follow(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let lines = log_stream_sample_lines();
    let mut state = LogStreamState::new();
    state.recipe = termrock::widgets::LogLineRecipe::Detailed;
    state.on_append(lines.len() as u16, area.height.saturating_sub(1));
    LogStream::new(&lines, system)
        .title("app.log")
        .render(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# LogStream

O(visible) paint over a **consumer-owned** line projection. TermRock owns scroll
offset, follow/detach chrome, search/level filters, selection/bookmarks, and
line recipes — not the history buffer.


## When to use / when not

| Use LogStream | Prefer |
|---------------|--------|
| Live/tail logs (stern/k9s-class) | — |
| Multi-source projected windows | — |
| Single local append+evict buffer | [LogPane](/docs/components/log-pane) (project via `log_lines_from_plain`) |
| Structured k8s/agent events | [EventStream](/docs/components/event-stream) |
| Chat/agent turns | [Transcript](/docs/components/transcript) |
| Chronological recipes | [Timeline](/docs/components/timeline) |

## Outcomes

- `Ignored`
- `Scrolled { offset }` — moved while already pinned
- `Detach` / `Follow` — left or re-attached to the tail
- `SelectionChanged { ids }` — multi-select
- `Copy { text }` / `Export { text }` — host owns clipboard/file I/O
- `BookmarkToggled { id, on }`
- `SearchChanged` / `LevelFilter` / `HScrolled` / `Cancelled` / `AckDropped`

## Focus law

| Concern | Owner |
|---------|--------|
| Surface focus | Host / InteractionScene |
| Scroll + follow + unread | `LogStreamState` → `ScrollAreaState` |
| Line buffer / history bound | Consumer (or LogPane) |
| Copy / export side effects | Consumer |

## Recipes and wrap

| Recipe | Layout |
|--------|--------|
| `Detailed` (default) | timestamp · source · severity · body |
| `Compact` | severity + body |

| Wrap | Behavior |
|------|----------|
| `Clip` (default) | h-scroll with `h`/`l` |
| `Wrap` | soft-wrap (toggle `w`) |

## Non-color

- Levels: `i`/`!`/`x` or ASCII `I`/`W`/`E` / letters `TDIWE`
- Follow chip: `↓ follow` / `v follow`; unread `N new`
- Dropped / batch / reconnect on chip or banner
- Empty: `∅` / `[ ]`
- Bookmark: `★` / `*`
- Cursor gutter: `›` / `>`

## Basic example

```rust
use termrock::{
    style::DesignSystem,
    widgets::{LogLevel, LogLine, LogStream, LogStreamState},
};

let system = DesignSystem::default();
let lines = [
    LogLine::new("1", LogLevel::Info, "ready")
        .timestamp("12:00:00")
        .source("main"),
];
let mut state = LogStreamState::new();
state.on_append(1, 8);
// LogStream::new(&lines, &system).title("app.log").focused(true)
//     .render(area, buf, &mut state);
let _ = (system, lines, state);
```
