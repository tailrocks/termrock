## Usage

```rust
use termrock::widgets::{Toggle, ToggleState, ToggleValue};

let mut state = ToggleState::new();
state.set_focused(true);
Toggle::new("Bold", &system).paint(area, buf, &mut state);

// Icon-only requires accessible_label
Toggle::new("", &system)
    .icon("B")
    .accessible_label("Bold")
    .compact()
    .paint(area, buf, &mut state);
```

## Contract

| Concern | Rule |
|---------|------|
| Pressed | `[label]` + bold/reverse (not color alone) |
| Unpressed | Spaced face |
| Indeterminate | `[~label]`; next activate → Pressed |
| Space/Enter | Flip value when focused |
| Icon-only | `accessible_label` required |

## Not for forms

Use **Checkbox** for form fields, **Switch** for settings On/Off.
