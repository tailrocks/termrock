**Purpose.** Compact form/toolbar control that opens a navigable option list.

## Value vs highlight

| | Meaning |
|--|---------|
| `value()` | Committed selection |
| `highlight()` | Open-list keyboard cursor |

Esc closes without committing. Enter commits highlight.

## Recipes

- **Inline** — default field
- **Form** — label row
- **Compact** — toolbar
