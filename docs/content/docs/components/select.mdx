## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

<TerminalPreview story="select/basic" interactive caption="Select · Select — live shared Rust state" />

## Try it

- `Enter/click open`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `↑↓ highlight`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `type to filter`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `Enter select`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `Esc close`: Open the transient state first, then cancel it; focus and the underlying state are preserved.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The demo preserves widget state between events. The component owns hit geometry, focus/selection mechanics, and typed outcomes; the host applies domain effects.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `select/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn select_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let opts = select_demo_options();
    let mut state = SelectState::new()
        .with_recipe(SelectRecipe::Form)
        .with_value("apple");
    state.set_focused(true);
    frame.render_stateful_widget(
        Select::new(&opts, system).label("Fruit").ascii(true),
        area,
        &mut state,
    );
}
```

## Value vs highlight

| | Meaning |
|--|---------|
| `value()` | Committed selection |
| `highlight()` | Open-list keyboard cursor |

Esc closes without committing. Enter commits highlight.

## Host overlay

```rust
match state.handle_key(key, &options, bounds) {
    SelectOutcome::Opened { presentation } => match presentation {
        SelectPresentation::Popover => open_popover_overlay(...),
        SelectPresentation::Fullscreen => { /* fullscreen panel */ }
        _ => {}
    },
    SelectOutcome::ValueChanged { id } => host.set(id),
    _ => {}
}
```
