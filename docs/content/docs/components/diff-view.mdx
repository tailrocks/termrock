## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

<TerminalPreview story="diff/basic" interactive caption="DiffView · Diff view unified — live shared Rust state" />

## Try it

- `↑↓ move`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `N/P next/previous hunk`: Move through the real focus/selection model; the next action uses the new target.
- `/ search`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `wheel scroll`: Scroll over the preview; its own viewport moves while the docs page stays put.
- `click line`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The mounted widget owns interaction state, focus chrome, hit geometry, and typed outcomes. The host only forwards backend-neutral events and performs no external effects.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `diff/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn diff_basic(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let (lines, hunks) = diff_sample_lines();
    let mut state = DiffViewState::new();
    state.mode = DiffMode::Unified;
    DiffView::new(&lines, system)
        .hunks(&hunks)
        .title("main.rs")
        .render(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# DiffView

O(visible) paint over a **consumer-owned** line projection. TermRock owns mode
resolution, scroll, search, fold, cursor/hunk chrome, line numbers, word-level
spans, and no-color prefixes — not git, staging, or multi-file loading.


## When to use / when not

| Use DiffView | Prefer |
|--------------|--------|
| Read-only patch viewing (delta/GitUI-class) | — |
| Interactive hunk activate/stage | [DiffReview](/docs/components/diff-review) veneer |
| Structured events | [EventStream](/docs/components/event-stream) |
| Plain logs | [LogStream](/docs/components/log-stream) |

## Outcomes

- `Scrolled` · `CursorMoved` · `HunkCursorMoved` · `HunkActivated`
- `ModeChanged` · `SearchChanged` · `FoldToggled` · `FileNavigated` · `Cancelled` · `Ignored`

## Modes

| Preference | Effective |
|------------|-----------|
| `Auto` (default) | Split when width ≥ 56; else unified |
| `Split` | Prefer split; collapses under narrow |
| `Unified` | Always single column |

## Non-color

- Prefixes: `+` / `-` / ` ` (always painted)
- Active gutter: `›` / `>`; inactive hunk `·` / `.`
- Whitespace marker: `·` / `~`
- Empty: `∅` / `[ ]`
- Colorless: strong add/remove + bold word spans

## Keys

| Key | Action |
|-----|--------|
| n/p | Hunk step |
| j/k page Home/End | Scroll / first-last hunk |
| s | Cycle mode |
| / | Search |
| z | Fold hunk |
| l · w · . | Line nos · word-diff · whitespace |
| Enter | Activate hunk |

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
