# DiffView

Projected patch paint with unified/split modes, line numbers, word-level spans,
folding, search, and hunk navigation. Host owns git and history; TermRock owns
chrome.

## Example

```rust
use termrock::widgets::{DiffLine, DiffHunk, DiffView, DiffViewState};

let lines = [
    DiffLine::removed("1", "before").old_no(1),
    DiffLine::added("2", "after").new_no(1),
];
let hunks = [DiffHunk::new(0, 2, "@@").id("h0")];
let mut state = DiffViewState::new();
// DiffView::new(&lines, &system).hunks(&hunks).render(area, buf, &mut state);
let _ = (lines, hunks, state);
```
