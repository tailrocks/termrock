## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

## Try it

- `Enter/Space toggle`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `←→ choose remove`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `Delete remove`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `click`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The mounted widget owns interaction state, focus chrome, hit geometry, and typed outcomes. The host only forwards backend-neutral events and performs no external effects.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `chip/filter`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn chip_filter_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::widgets::{Chip, ChipState};
    let chunks = Layout::horizontal([
        Constraint::Length(14),
        Constraint::Length(14),
        Constraint::Min(12),
    ])
    .split(area);
    let mut a = ChipState::new(true);
    a.set_focused(true);
    let _ = Chip::new("rust", "rust", system).paint(chunks[0], frame.buffer_mut(), &mut a);
    let mut b = ChipState::new(false);
    let _ = Chip::new("go", "go", system).paint(chunks[1], frame.buffer_mut(), &mut b);
    let mut c = ChipState::new(false);
    let _ = Chip::new("ts", "typescript", system).removable(true).paint(
        chunks[2],
        frame.buffer_mut(),
        &mut c,
    );
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
