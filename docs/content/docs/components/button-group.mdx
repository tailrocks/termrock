## Usage

```rust
use termrock::widgets::{ButtonGroup, ButtonGroupItem, ButtonGroupState};

let items = [
    ButtonGroupItem::new("cancel", "Cancel"),
    ButtonGroupItem::destructive("delete", "Delete"),
    ButtonGroupItem::primary("save", "Save"),
];
let mut state = ButtonGroupState::new();
state.set_surface_focused(true);
let parts = ButtonGroup::new(&items, &system)
    .separated() // or .connected()
    .paint(area, buf, &mut state);

// Host overflow menu from parts.overflow_ids
// Enter → default (primary); Space → roving cursor
```

## Contract

| Concern | Rule |
|---------|------|
| Enter | Default / primary action |
| Space | Roving cursor command |
| Narrow | Low priority → `…` overflow; primary kept |
| Connected | 1-col `│` separators between faces |
| Auto-stack | Opt-in `.stack_below(n)` (default off) |
| Loading/disabled | Face paints; cannot activate |
| Semantics | Group + each visible command as Button |

## vs ActionBar / Toolbar

Prefer **ButtonGroup** for overflow, variants, default Enter, and roving.
Keep **ActionBar** for simple labeled strips. **Toolbar** owns rich command catalogs.
