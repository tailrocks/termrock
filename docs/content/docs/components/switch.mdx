## Usage

```rust
use termrock::widgets::{Switch, SwitchState, SwitchOutcome};

let mut state = SwitchState::new(false);
state.set_focused(true);
Switch::new("dark", "Dark mode", &system)
    .description("Follow system appearance")
    .paint(area, buf, &mut state);

// Scroll-safe: Down arms, Up-in-region commits
```

## Contract

| Concern | Rule |
|---------|------|
| Value text | `[ON ]` / `[OFF]` by default (no color-only) |
| Settings row | Label left · track right |
| Compact | Track left · label right |
| Space/Enter | Toggle when focused |
| Pointer | Down arm · Up-in-region toggle (scroll-safe) |
| Loading / RO / disabled | No activate |
| Invalid | Danger chrome |

## Appropriate vs not

| Need | Control |
|------|---------|
| Settings preference | **Switch** |
| Form checked item | Checkbox |
| Toolbar sticky tool | Toggle |
| Exclusive options | RadioGroup |
