## Usage

```rust
use ratatui_core::layout::Rect;
use termrock::style::DesignSystem;
use termrock::widgets::{
    DropdownMenu, DropdownMenuState, MenuNode, open_dropdown_menu_overlay, measure_menu_panel,
};

let system = DesignSystem::default();
let nodes = vec![
    MenuNode::command("open", "Open").shortcut("C-o"),
    MenuNode::submenu("more", "More", vec![MenuNode::command("a", "A")]),
];
let mut state = DropdownMenuState::new();
let bounds = Rect::new(0, 0, 80, 24);
let _ = state.open_from_keyboard(&nodes, bounds);
// open_dropdown_menu_overlay(...); DropdownMenu::new(&nodes, &system).paint(...)
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (roving, typeahead, Esc layers, Right submenu) |
| Mouse | covered (hit activate, scroll, outside dismiss via stack) |
| Focus | covered (opener restore on OverlayStack) |
| Non-color cues | covered (marks, ASCII, disabled ⊘, shortcuts) |
| Unicode | covered |
| Narrow terminal | covered (PreferCommandPalette) |
