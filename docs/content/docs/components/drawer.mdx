## Usage

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{Drawer, DrawerState, DrawerEdge};

let system = DesignSystem::default();
let mut state = DrawerState::new();
state.set_edge(DrawerEdge::Right);
let _ = state.open_on_stack(&mut stack, bounds, Some("main"));
Drawer::new("Inspector", &system)
    .footer(Some("esc · [ ] resize"))
    .paint(entry.rect, buf, &mut state);
// Host paints into state.body_area() — main view selection/scroll unchanged.
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (Esc close, `[`/`]` resize) |
| Mouse | covered (handle drag resize; outside dismiss via stack) |
| Focus | covered (modal trap; non-modal no trap; opener restore) |
| Non-color cues | covered (handle glyphs, ASCII/no-motion) |
| Unicode | covered |
| Narrow terminal | covered (compact / fullscreen) |
