## Usage

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{BreadcrumbItem, Breadcrumbs, BreadcrumbsState};

let system = DesignSystem::default();
let items = [
    BreadcrumbItem::new("h", "home"),
    BreadcrumbItem::new("s", "src").current(true),
];
let mut state = BreadcrumbsState::new();
state.set_focused(true);
let _ = Breadcrumbs::new(&items, &system).ascii(true);
```

## State and typed outcomes

The mounted widget owns interaction state, focus chrome, hit geometry, and typed outcomes. The host only forwards backend-neutral events and performs no external effects.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.

## Migrated handbook guidance

# Breadcrumbs

**Purpose.** Location context for files, routes, schemas, object paths.


## One Tab stop

Host Tab focuses the control once. **Left/Right** move among segments (and
ellipsis). Avoids a Tab stop per crumb.

## Collapse

When narrow and `len > 3`: **first · … · current**. Middle ids available via
`OpenOverflow`.

## Editable mode

Optional path draft (`with_editable(true)`). Enter/Ctrl+E/`/` on current starts
edit; Enter commits; Esc cancels.

## Compose

FilePicker · SchemaBrowser · master-detail headers · migration `0155`
