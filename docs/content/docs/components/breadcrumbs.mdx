## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

## Try it

- `←→ move`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `Enter navigate/edit`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `Ctrl+E edit path`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `click segment`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The mounted widget owns interaction state, focus chrome, hit geometry, and typed outcomes. The host only forwards backend-neutral events and performs no external effects.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `breadcrumbs/path`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn breadcrumbs_path_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let items = [
        BreadcrumbItem::new("home", "home"),
        BreadcrumbItem::new("proj", "projects"),
        BreadcrumbItem::new("tr", "termrock"),
        BreadcrumbItem::new("src", "src").current(true),
    ];
    let mut state = BreadcrumbsState::new();
    state.set_focused(true);
    state.set_focus_index(2);
    let _ = Breadcrumbs::new(&items, system)
        .ascii(true)
        .separator(BreadcrumbSeparator::Slash)
        .paint(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# Breadcrumbs

**Purpose.** Location context for files, routes, schemas, object paths.


## One Tab stop

Host Tab focuses the control once. **Left/Right** move among segments (and
ellipsis). Avoids a Tab stop per crumb.

## Collapse

When narrow and `len > 3`: **first · … · current**. Middle ids available via
`OpenOverflow`.

## Editable mode

Optional path draft (`with_editable(true)`). Enter/Ctrl+E/`/` on current starts
edit; Enter commits; Esc cancels.

## Compose

FilePicker · SchemaBrowser · master-detail headers · migration `0155`

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.

## Test recipe

Mount `breadcrumbs/path`, dispatch each listed action, and assert the typed outcome, changed Ratatui cells, persistent follow-up state, pointer hit geometry, and Reset behavior.
