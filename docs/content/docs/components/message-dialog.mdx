## Usage

```rust
use ratatui_core::text::Text;
use termrock::{style::DesignSystem, widgets::{DetailCapability, DetailRow, DetailTableState, Dialog, MessageDialog}};

let system = DesignSystem::default();
let details = [DetailRow { id: "stage", label: "Stage", value: "Build", href: None, capability: DetailCapability::None, emphasis: false, style: None }];
let dialog = MessageDialog::new(Dialog::new("Failure", Text::from("Build failed"), &system), &details, &system).wrap(true);
let mut state = DetailTableState::<&str>::default();
let outcome = state.select_next(&details);
```

## State and typed outcomes

The widget owns deterministic paint and layout. The host owns all surrounding state and effects; this demo intentionally exposes no fake cursor, click, or keyboard behavior.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
