Binary inspector over a **host-projected page** (`HexWindow`). TermRock owns
row virtualization metrics from `total_len`, cursor/selection in absolute
offsets, and chrome — never file I/O.

## When to use / when not

| Use HexViewer | Prefer |
|---------------|--------|
| Binary / blob inspection | — |
| Text source files | [CodeBlock](/docs/components/code-block) |
| Structured logs | [LogStream](/docs/components/log-stream) |

## Paging contract

```text
Host projects: base_offset + data[] + total_len
Scroll/cursor use absolute offsets
PageNeeded { offset } → host re-reads page containing offset
```

## Non-color selection

- Cursor: `›` / `>` gutter + `⟨XX⟩` / `[XX]` around active byte
- Selection: `{XX}` braces
- Bookmarks: `★` / `*`

## Inspector

Endian-aware `u8`/`u16`/`u32`/`u64` at cursor (`e` toggles LE/BE).

## Keys

| Key | Action |
|-----|--------|
| hjkl / arrows | Navigate |
| / n N | Search |
| b e a w | Bookmark · endian · ascii mode · bpr |
| c x y | Copy hex · ASCII · export |
