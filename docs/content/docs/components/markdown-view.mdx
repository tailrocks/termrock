## Usage

```rust
use termrock::widgets::{MarkdownView, MarkdownViewState, project_markdown};

let blocks = project_markdown(source);
let mut state = MarkdownViewState::new();
state.set_focused(true);

MarkdownView::new(&blocks, &system)
    .section_gap(true)
    .paint(area, buf, &mut state);
```

## Features

- Headings, paragraphs, lists, tasks, quotes, rules, fences, tables
- Multi-row measure + scroll virtualization
- Unfinished fences (`incomplete`) without layout thrash
- Inline `**` / `*` / `` ` `` / `[text](url)` light parse
- Link activation via mouse or Tab + Enter
- Responsive tables (drop trailing columns when narrow)
- Glow-style section gaps before H1/H2 and rules

## Host parsing

`project_markdown` is dependency-free. For full CommonMark, project into
`MarkdownBlock` yourself and pass the slice to `MarkdownView`.
