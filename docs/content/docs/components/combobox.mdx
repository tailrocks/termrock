## Live terminal (Ghostty-class)

This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

## Try it

- `type to filter`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `↓ open suggestions`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `↑↓ choose`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `Enter commit`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `Esc close`: Open the transient state first, then cancel it; focus and the underlying state are preserved.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## State and typed outcomes

The mounted widget owns interaction state, focus chrome, hit geometry, and typed outcomes. The host only forwards backend-neutral events and performs no external effects.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `combobox/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn combobox_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let mut state: ComboboxState<&'static str> = ComboboxState::new()
        .with_creatable(false)
        .with_exact_required(true);
    state.set_focused(true);
    state.set_value(Some("rs"), Some("Rust".into()));
    state.set_draft("Rust");
    let _ = Combobox::new(system).label("Language").ascii(true).paint(
        area,
        frame.buffer_mut(),
        &mut state,
    );
}
```

## Migrated handbook guidance

# Combobox & Autocomplete

**Purpose.** Free-form or constrained values with suggestions. TermRock owns
draft typing, menu navigation, and race-safe apply. Hosts own fetch/rank and
OverlayStack.


## Three values

| Value | API |
|-------|-----|
| Draft | `draft()` |
| Active suggestion | `active_suggestion()` |
| Committed | `value()` / `value_label()` |

## Async race gate

```rust
// on DraftChanged { generation }
host.fetch(text, generation);

// on response
if state.apply_suggestions(generation, &cands) {
    // fresh
} // stale generation → false, ignored
```

## Modes

- **Combobox** — `ComboboxState::new()`: exact-required, not creatable by default  
- **Autocomplete** — `ComboboxState::autocomplete()`: creatable free text
