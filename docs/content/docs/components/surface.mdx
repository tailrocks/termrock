## Usage

```rust
use termrock::{style::DesignSystem, widgets::{Surface, SurfaceRecipe, SurfaceFill}};

let system = DesignSystem::default();
let content = Surface::new(&system)
    .recipe(SurfaceRecipe::Focused)
    .paint(area, buf);
// Children paint only inside content (clip contract).
// Canvas / terminal-default:
Surface::new(&system).recipe(SurfaceRecipe::Canvas).fill(SurfaceFill::TerminalDefault);
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | not-applicable |
| Mouse | covered (hit region via `SurfaceParts::hit`) |
| Focus | covered (recipe `Focused` / `Role::BorderFocused`) |
| Non-color cues | covered |
| Unicode | covered |
| Narrow terminal | covered |
