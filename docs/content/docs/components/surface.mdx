This is an honest paint-only preview. It accepts no keyboard or pointer input; resize the page to inspect its responsive rendering.

## Usage

```rust
use termrock::{style::DesignSystem, widgets::{Surface, SurfaceRecipe, SurfaceFill}};

let system = DesignSystem::default();
let content = Surface::new(&system)
    .recipe(SurfaceRecipe::Focused)
    .paint(area, buf);
// Children paint only inside content (clip contract).
// Canvas / terminal-default:
Surface::new(&system).recipe(SurfaceRecipe::Canvas).fill(SurfaceFill::TerminalDefault);
```

## State and typed outcomes

The widget owns deterministic paint and layout. The host owns all surrounding state and effects; this demo intentionally exposes no fake cursor, click, or keyboard behavior.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
