## Usage

```rust
use termrock::widgets::{Skeleton, SkeletonRecipe, SkeletonLayout, SkeletonShape};

Skeleton::new(4, &system); // legacy staggered lines
Skeleton::card(3, &system);
Skeleton::table(3, 5, &system);
Skeleton::recipe(SkeletonRecipe::Rows, 6, &system);
// Prefer LoadingView/Spinner when structure is unknown.
```

## Rules

1. Use only when final structure is known.
2. Default static — no constant shimmer.
3. `measure_height` / `reserved_height` to avoid layout jump.
