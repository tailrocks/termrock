## Usage

```rust
use termrock::widgets::{Slider, SliderState, SliderBounds, SliderMark};

let mut state = SliderState::new(50.0);
state.set_focused(true);
Slider::new(SliderBounds::percent(), &system)
    .label("Volume")
    .marks(&[SliderMark::labeled(0.0, "lo"), SliderMark::new(100.0)])
    .paint(area, buf, &mut state);
```

## Contract

| Concern | Rule |
|---------|------|
| Keys | ←→ step · PgUp/PgDn page · Home/End · Enter/digits edit |
| Pointer | Click/drag track · wheel step |
| ASCII | `*` handle · `=` fill · `-` empty |
| Tiny | Width &lt; 10 → numeric-only |
| Precision | Pair value field when exactness matters |

## Not for

Read-only completion → **Progress**. Exact free entry without bounds → **TextInput**.
