**Purpose.** Recipients, filters, tags, file mentions, command arguments — an
owned token collection with a draft input. Hosts own async completion menus.

## vs TokenStrip

| | TokenStrip | TokenField |
|--|------------|------------|
| Data | borrowed projection | owned tokens + draft |
| Input | none | free-text commit |
| Focus | roving on chips | draft ↔ tokens one surface |

## Focus model

One host Tab stop for the field. Inside:

- **Draft** — type; Left at caret start moves to last token
- **Token** — Left/Right; optional remove part without Tab
- Empty draft **Backspace** removes previous token
- **Alt+Left/Right** reorders focused token
