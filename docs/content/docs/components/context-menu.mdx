## Usage

The Code view above and this source excerpt use the exact paint setup registered for `context-menu/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn context_menu_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let nodes = vec![
        MenuNode::command("cut", "Cut").shortcut("C-x"),
        MenuNode::command("copy", "Copy").shortcut("C-c"),
        MenuNode::command("paste", "Paste").shortcut("C-v"),
        MenuNode::separator("s"),
        MenuNode::command("rename", "Rename"),
        MenuNode::command("delete", "Delete").destructive(true),
    ];
    let mut state = DropdownMenuState::context();
    let _ = state.open_from_context_pointer(&nodes, area);
    DropdownMenu::new(&nodes, system).paint(area, frame.buffer_mut(), &mut state);
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
