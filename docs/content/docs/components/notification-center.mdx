## Usage

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{
    NotificationCenter, NotificationCenterState, NotificationRecipe, example_notifications,
};

let system = DesignSystem::default();
let mut state = NotificationCenterState::new();
state.replace_items(example_notifications(now_secs));
// From toast: state.ingest_from_toast_queue(&mut queue, now_secs);
state.set_recipe(NotificationRecipe::Drawer);
let _ = state.open();
NotificationCenter::new(&system).paint(area, buf, &mut state);
// Persist: host saves state.items()
```

## Keys

`j`/`k` move · `enter` open · `u` mark read · `U` all read · `x` dismiss · `c` clear · `/` filter · `esc` close · `1` first action
