## Usage

```rust
use termrock::widgets::{Checkbox, CheckboxState, CheckboxValue};

let mut state = CheckboxState::new(false);
state.set_focused(true);
Checkbox::new("enable", "Enable notifications", &system)
    .description("Optional product emails")
    .paint(area, buf, &mut state);

// Mixed group parent
let value = CheckboxValue::from_children([true, false, true]);
state.set_value(value); // Indeterminate
```

## Contract

| Concern | Rule |
|---------|------|
| Values | Unchecked · Checked · Indeterminate |
| Space/Enter | Activate (mixed/off → on → off) |
| Hit | Full root including label |
| ASCII/mono | `[x]` `[ ]` `[-]` |
| Invalid | Danger chrome; still host-owned message |
| Read-only | Visible value; no activate |
| Description | Row 2; drop when height &lt; 2 or width &lt; 12 |

## Not for

| Need | Use |
|------|-----|
| Toolbar sticky tool | Toggle |
| Settings On/Off | Switch |
| Exclusive options | RadioGroup |
