## Usage

```rust
use ratatui_core::text::Line;
use termrock::{
    interaction::{UiIntent, NavigationMove},
    style::DesignSystem,
    widgets::{Tree, TreeNode, TreeOutcome, TreeState},
};

let system = DesignSystem::phosphor();
let nodes = [
    TreeNode::new("src", Line::from("src"), 0).branch().expanded(),
    TreeNode::new("lib", Line::from("lib.rs"), 1).badge(Line::from("rs")),
];
let tree = Tree::from_system(&nodes, &system);
let mut state = TreeState::new(Some("src"));
let outcome = state.handle_intent(&nodes, UiIntent::Move(NavigationMove::Next));
// Expansion is a request — consumer flips `expanded` on Toggle:
// TreeOutcome::Toggle("src")
```

Empty trees:

```rust
Tree::from_system(&[], &system).empty_message("No files");
```

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (`UiIntent` / expand-collapse / cancel) |
| Mouse | covered (disclosure, row, check, scrollbar) |
| Focus | covered (bold + underline when focused selection) |
| Non-color cues | covered (gutter, disclosure, underline) |
| Unicode | covered |
| Narrow terminal | covered (indent collapse + part drop) |
| Empty / loading / error | covered |
