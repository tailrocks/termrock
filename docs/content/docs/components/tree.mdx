## Usage

```rust
use ratatui_core::text::Line;
use termrock::widgets::{
    Tree, TreeNode, TreeState, TreeOutcome, filter_tree_with_ancestors,
};

let nodes = [
    TreeNode::new("root", Line::from("src"), 0).branch().expanded(),
    TreeNode::new("lazy", Line::from("vendor"), 1)
        .lazy_branch()
        .parent("root"),
    TreeNode::new("lib", Line::from("lib.rs"), 1)
        .parent("root")
        .actions(Line::from("open")),
];
let mut state = TreeState::new(Some("root"));

// Left: collapse expanded OR parent
// Right: expand/load OR first child
// Typeahead: printable keys
// Filter (host reprojects):
let view: Vec<_> = filter_tree_with_ancestors(&nodes, "lib")
    .into_iter().cloned().collect();

Tree::new(&nodes, &system).empty_message("No files");
```

## Keyboard semantics

| Key | Behavior |
|---|---|
| ↑/↓ / j/k | Move cursor among enabled nodes |
| ← / h | Collapse expanded branch; else select parent |
| → / l | Expand collapsed/lazy branch; else first child |
| Enter | Activate |
| Space | Multi-check toggle when enabled |
| printable | Typeahead jump |
| `/` | Filter query chrome (host filters) |

## Rules

1. Host owns expansion set and lazy fetch; Tree emits `Toggle(id)`.
2. Prefer builders; new fields `actions`, `parent`.
3. Filter with `filter_tree_with_ancestors` so paths stay navigable.
4. Large trees: project visible flat slice + `set_virtual_window` / anchors.
5. ASCII: `GlyphSet::Ascii` → `v`/`>` disclosure.

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (intents + typeahead + filter) |
| Mouse | covered (row, disclosure, check) |
| Focus | covered (cursor) |
