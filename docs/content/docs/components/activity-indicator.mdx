## Live terminal (Ghostty-class)

One focused interactive surface. Variants are listed in **Stories** — interactivity
replaces multi-image galleries.

<TerminalPreview story="activity-indicator/basic" interactive caption="ActivityIndicator · activity-indicator/basic — focus surface; keys/click for states" />

## Usage

```rust
use termrock::style::{DesignSystem, Motion};
use termrock::widgets::{ActivityIndicator, SpinnerState, ActivityPhase};

let system = DesignSystem::default();
let mut state = SpinnerState::new();
state.set_phase(ActivityPhase::Reconnecting);
ActivityIndicator::new("Reconnecting to agent", &system)
    .detail("attempt 2/5")
    .paint(area, buf, &state, tick, Motion::Full);
```

## Interaction contract

| Axis | Status |
