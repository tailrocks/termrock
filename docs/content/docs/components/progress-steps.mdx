## Usage

```rust
use termrock::widgets::{
    ProgressSteps, ProgressStepsState, example_build_pipeline,
};

let steps = example_build_pipeline();
let mut state = ProgressStepsState::new(); // passive live progress
ProgressSteps::new(&steps, &system)
    .title("Build")
    .paint(area, buf, &mut state);

// Interactive recovery:
// let mut state = ProgressStepsState::interactive();
// enter/r → RetryRequested on failed+retryable steps
```

## vs Stepper

Stepper is form **navigation** chrome. ProgressSteps is **execution** progress
for pipelines (CI / agent plans).

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (interactive mode) |
| Mouse | covered (interactive select) |
| Focus | covered (passive unfocused by default) |
| Non-color cues | covered (marks) |
| Unicode | covered |
| Narrow terminal | covered (summary contraction) |
