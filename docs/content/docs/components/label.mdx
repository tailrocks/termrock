## Usage

```rust
use termrock::widgets::{Label, FieldCaption};

Label::new("Name", &system)
    .for_id("name")
    .required()
    .focused()
    .paint(area, buf);

FieldCaption::new("Endpoint", &system)
    .for_id("ep")
    .required()
    .help("Base URL")
    .paint(area, buf);
```

## Marks & tones

| Mark | Cue |
|------|-----|
| Required | ` *` |
| Optional | ` (opt)` when wide |
| Disabled | ` ⊘` / ` x` |

| Tone | Role |
|------|------|
| Default / Focused | Text (+ bold when focused) |
| Disabled | TextDisabled |
| Invalid | Danger |
| Warning | Warning |

## Layouts

| Recipe | Description row |
|--------|-----------------|
| Stacked | Under label when width ≥ 28 |
| Compact | Never (single line) |
| Inline | Never (host places control beside) |

Descriptions **contract before** labels when narrow.

## Semantic scene

`register_semantic` emits a non-focusable content node with
`description` like `required; for=name` for Studio / help.
