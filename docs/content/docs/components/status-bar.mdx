## Usage

```rust
use termrock::widgets::{
    StatusBar, StatusBarState, StatusSlot, TransientStatus,
};

let left = [StatusSlot::mode("mode", "NOR")];
let center = [StatusSlot::focus_zone("fz", "transcript")];
let right = [
    StatusSlot::selection("sel", "2"),
    StatusSlot::connection("c", "ok"),
    StatusSlot::shortcut("h", "C-p"),
];

let mut state = StatusBarState::new();
StatefulWidget::render(
    &StatusBar::with_center(&left, &center, &right, &system)
        .rich()
        .transient(&TransientStatus::new("saved")),
    area,
    buf,
    &mut state,
);
```

## Regions

| Region | Typical content |
|--------|-----------------|
| Left | Mode, primary status |
| Center | Focus zone, path/context, transient |
| Right | Selection, connection, clock, shortcuts |

Priority contraction still applies across the full width; essentials survive.

## Kinds (non-color glyphs)

Mode · Connection · Selection · Context · Shortcut · FocusZone · Transient · Text

ASCII via `GlyphSet::Ascii`.

## Recipes

| Recipe | Behavior |
|--------|----------|
| Minimal | Mode, connection, focus zone, high-priority text |
| Compact (default) | Drops shortcuts first under pressure |
| Rich | Keeps key hints |

## Transient

Ephemeral center message. Does not remove mode/connection. No hit region.
