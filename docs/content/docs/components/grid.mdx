## Anatomy

`content` · `column_tracks[]` · `row_tracks[]` · `cells[]` · `overflowed`

## Usage

```rust
use termrock::layout::{Grid, TrackSize, GridAutoFlow, form_grid_template};

let layout = Grid::columns(3)
    .gaps(1, 1)
    .auto_row(TrackSize::Fixed(4))
    .layout_flow(area, 6, GridAutoFlow::Row);

let form = form_grid_template(area.width);
```

## Tracks

| Track | Behavior |
|-------|----------|
| `Fixed(n)` | Exact cells |
| `Weight` / `fr` | Share residual |
| `MinMax` | Preferred clamped to [min, max] |

## Navigation

Grid is **not** interactive by default. Hosts wire:

```rust
use termrock::layout::grid_neighbor_2d;
// Arrow Right → grid_neighbor_2d(items, focus, 1, 0)
```

## Overflow

Track minima that exceed the axis shrink from the end; `overflowed` is set.
