## Usage

```rust
use termrock::layout::{
    Grid, TrackSize, GridAutoFlow, OverflowPolicy,
    form_grid_template, dashboard_grid_template, settings_grid_template,
    grid_neighbor_2d,
};

let layout = Grid::columns(3)
    .gaps(1, 1)
    .auto_row(TrackSize::Fixed(4))
    .layout_flow(area, 6, GridAutoFlow::Row);

let form = form_grid_template(area.width);
let dash = dashboard_grid_template(area.width, 3, 18, 1);
let settings = settings_grid_template(area.width, 18, 2);

// Studio
let _ = layout.debug_summary();
```

## State and typed outcomes

The widget owns deterministic paint and layout. The host owns all surrounding state and effects; this demo intentionally exposes no fake cursor, click, or keyboard behavior.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
