## Usage

The Code view above and this source excerpt use the exact paint setup registered for `toggle-group/format`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn toggle_group_format_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let items = [
        ToggleGroupItem::new("b", "B").pressed(true).priority(90),
        ToggleGroupItem::new("i", "I").pressed(true).priority(80),
        ToggleGroupItem::new("u", "U").priority(70),
    ];
    let mut state = ToggleGroupState::new();
    state.set_surface_focused(true);
    state.cursor = Some("i");
    let _ = ToggleGroup::new(&items, system).multiple().compact().paint(
        area,
        frame.buffer_mut(),
        &mut state,
    );
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
