## Anatomy

`root` · `header` · `description` · `body` · `footer`  
Built on Panel + raised Surface — no nested box soup.

## Usage

```rust
use termrock::{style::DesignSystem, widgets::{Card, PanelAction, PanelBody}};

let system = DesignSystem::default();
let actions = [PanelAction::new("open", "Open")];
let body = Card::new(&system)
    .title("Latency")
    .badge("live")
    .description("p99 last hour")
    .header_actions(&actions)
    .footer("dashboard")
    .paint(area, buf, None);
// paint children only inside `body`
```

## Composition

- **ToolCard** paints via Card chrome (status leading + badge; body = tool output)
- Dashboard metric tiles use Card + host body content
- Prefer Card for elevated content; Panel for workspace chrome
- Loading / empty / error: `Card::body(PanelBody::…)` same as Panel

## Focus

Same as Panel: only `interactive(true)` or `collapsible(true)` claims card-level focus.
