## Anatomy

`root` · `header` · `description` · `body` · `footer`  
Built on Panel + raised Surface — no nested box soup.

## Usage

```rust
use termrock::{style::DesignSystem, widgets::Card};

let system = DesignSystem::default();
let body = Card::new(&system)
    .title("Latency")
    .description("p99 last hour")
    .footer("dashboard")
    .paint(area, buf, None);
// paint children only inside `body`
```

## Composition

- **ToolCard** paints via Card chrome
- Dashboard metric tiles use Card + host body content
- Prefer Card for elevated content; Panel for workspace chrome
