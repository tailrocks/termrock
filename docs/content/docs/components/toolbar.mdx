## Usage

```rust
use termrock::widgets::{Toolbar, ToolbarItem, ToolbarState};

let items = [
    ToolbarItem::action("save", "Save").hint("C-s").priority(90),
    ToolbarItem::toggle("wrap", "Wrap", false),
    ToolbarItem::separator("s"),
    ToolbarItem::action("help", "Help").priority(10),
];
let mut state = ToolbarState::horizontal();
state.set_surface_focused(true);
state.set_cursor(Some("save"));

StatefulWidget::render(
    &Toolbar::new(&items, &system).overflow_id("more"),
    area,
    buf,
    &mut state,
);
```

## Focus model

| Layer | Meaning |
|-------|---------|
| `surface_focused` | Host gave keyboard ownership to the toolbar |
| roving cursor | Active descendant among interactive items |
| content selection | Lives on lists/tables — **independent** |

## Overflow

Low-`priority` items drop into `state.overflow_indices`. The overflow chip uses
`overflow_id`. Host owns the overflow menu UI.

## Items

| Kind | Role |
|------|------|
| Action | Activate on Enter/click |
| Toggle | Emits `Toggled { pressed }` (host applies) |
| Separator | Visual only |
| Label | Non-interactive title |

## vs ActionBar

Prefer **Toolbar** for contextual chrome. Prefer **ActionBar** for simple dialog
footer action rows.
