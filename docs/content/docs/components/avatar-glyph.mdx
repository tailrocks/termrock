## Usage

```rust
use termrock::widgets::{AvatarGlyph, AvatarSize, PresenceStatus, IdentityRole};

AvatarGlyph::new("Ada Lovelace", &system)
    .size(AvatarSize::Normal)
    .with_presence(PresenceStatus::Online)
    .paint(area, buf);

AvatarGlyph::new("agent", &system)
    .role(IdentityRole::Agent)
    .role_glyph()
    .compact()
    .paint(area, buf);
```
