## Usage

```rust
use termrock::widgets::{KeyValueList, KeyValueListState, KvEntry, KvStatus};

let entries = [
    KvEntry::group_header("g", "Network"),
    KvEntry::pair("host", "Host", "localhost").copyable(),
    KvEntry::pair("tls", "TLS", "required").status(KvStatus::Warning),
];
let mut state = KeyValueListState::new();
KeyValueList::dense(&entries, &system).paint(area, buf, &mut state);
```

## vs DetailTable

Prefer **KeyValueList** for settings/summaries (groups, density, redaction,
stacked contraction). Keep **DetailTable** for selection-heavy dialog detail
bodies with measured scroll caching.
