## Usage

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{
    EmptyState, EmptyKind, EmptyAction, example_empty_search,
};

let system = DesignSystem::default();

EmptyState::new("No results", &system)
    .kind(EmptyKind::NoResults)
    .explanation("Try another query")
    .primary(EmptyAction::with_shortcut("Clear filters", "esc"))
    .secondary(EmptyAction::new("Edit query"))
    .example("status:failed")
    .paint(area, buf);

// Recipes
example_empty_search(&system).paint(area, buf);
```

## Rules

1. Prefer EmptyState over a blank panel body.
2. Primary action is dominant and never destructive-by-default.
3. Use `EmptyKind` to pick glyph/tone (first-use, no-data, no-results, filtered-out, permission).
4. Small panes auto-contract toward inline; force with `.inline()`.
5. Hard failures → `ErrorView`, not EmptyState.

## Interaction contract

| Axis | Status |
|---|---|
| Keyboard | covered (Tab / Enter / 1–2 when actions present) |
| Mouse | covered (click lower action bands) |
| Focus | covered (action focus when interactive) |
| Non-color cues | covered (glyph + labels) |
| Unicode | covered |
| Narrow terminal | covered (inline contraction) |
