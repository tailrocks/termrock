# 0081 — FocusGraph public focus authority

## Mission

Evolve focus into a predictable graph: linear Tab, spatial arrows, zones,
parent/child traps, opener restore, history, roving collections, Focus Lens.

## Preserve

| Surface | Role |
|---------|------|
| `InteractionScene` layers / Esc / hit | Still owns input layers |
| Crate-private `FocusRing` | Unchanged private implementation |
| Collection selection (`ListState` cursor) | Not focus |
| `accepts_input` host gates | Input grant ≠ graph focus |

## Added

| API | Role |
|-----|------|
| `FocusGraph<Id>` | Sole **public** focus graph |
| `FocusNode` | id, parent, zone, area, enabled, focusable, roving, tab_index |
| `FocusNavMode` | Linear / Spatial / Hybrid |
| `FocusOutcome` | Ignored / Unchanged / Changed { from, to } (public) |
| `FocusDebugSnapshot` | Studio summary |
| `FocusLens` | Debug paint: tab indices + focused marker |
| `from_interaction` / `apply_to_scene` / `sync_from_scene` | Scene bridge |
| `apply_request(FocusRequest)` | EventResult focus coordination |
| `InspectorPanel::FocusGraph` | Studio panel |

## Focus vs selection vs pointer

1. **Focus** — `FocusGraph` keyboard surface owner.
2. **Selection** — widget-local cursor while a **roving** node is focused.
3. **Pointer** — `focus_at` moves focus only; Activate is a separate intent.
4. **Hybrid mode** — arrows spatial outside roving; inside roving, arrows stay widget Move.

## Consumer edits

```rust
use termrock::interaction::{FocusGraph, FocusNavMode, FocusNode, FocusLens};

let mut focus = FocusGraph::new().mode(FocusNavMode::Hybrid);
focus.begin_frame();
focus.register(FocusNode::leaf("sidebar", sidebar_rect).zone("sidebar").tab_index(0));
focus.register(FocusNode::roving_collection("list", list_rect).tab_index(1));
focus.register(FocusNode::leaf("editor", editor_rect).tab_index(2));
let _ = focus.reconcile();

// Tab
let _ = focus.handle_key(tab_key);
// Modal
focus.push_trap("dialog", Some("editor"));
// …
let _ = focus.pop_trap();

// Studio
let lines = focus.debug_snapshot().summary_lines(4);
// Paint lens after chrome
FocusLens::new(&focus, &system).render(area, buf);
```

Bridge from scene:

```rust
let mut focus = FocusGraph::from_interaction(&scene);
focus.sync_from_scene(&scene);
// after graph Tab:
focus.apply_to_scene(&mut scene);
```
