# 0154 — TreeNavigation

## Mission

Hierarchical **route** navigation for project, schema, settings, and docs trees.
Distinct from data [`Tree`](../crates/termrock/src/widgets/tree.rs): route ≠ focus,
lazy load generation, active ancestors, typeahead, context actions.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tree` / `TreeNode` / `TreeState` / multi-check | **Preserved** — data hierarchy |
| Tree Studio stories (`tree/*`) | **Preserved** |
| `NavigationList` / `Sidebar` | **Preserved** — flat/primary app rail |
| `TreeNavigation` / `TreeNavNode` / outcomes | **Added** |
| Example projectors (project/schema/settings/docs) | **Added** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     TreeNavigation, TreeNavigationState, TreeNavNode, TreeNavigationOutcome,
+     example_project_tree,
+ };

+ let nodes = example_project_tree(); // or host projection
+ let mut state = TreeNavigationState::new(Some("main"));
+ state.set_focused(true);
+ state.reconcile_route(&nodes);

+ match state.handle_key(key, &nodes) {
+     TreeNavigationOutcome::RouteChanged { id } => host.open(id),
+     TreeNavigationOutcome::FocusChanged { .. } => {}
+     TreeNavigationOutcome::ExpandToggled { id, expanded } => host.set_expand(id, expanded),
+     TreeNavigationOutcome::LazyLoadRequested { id, generation } => {
+         host.load_children(id, generation);
+     }
+     TreeNavigationOutcome::ContextMenuRequested { id } => host.menu(id),
+     TreeNavigationOutcome::Cancelled => {}
+     _ => {}
+ }
+ // when lazy returns:
+ if state.apply_lazy_result(generation) {
+     nodes = host.project(); // route preserved via reconcile_route
+ }

+ TreeNavigation::new(&nodes, &system).ascii(false).paint(area, buf, &mut state);
```

### Arrow semantics

| Key | Behavior |
|-----|----------|
| ↑/↓ | Focus among visible rows |
| ← | Collapse expanded branch, else parent |
| → | Expand / lazy-load, else first child |
| Enter | Route if routeable; else toggle expand |
| Typeahead | Prefix jump on labels |
| `/` | Filter (route kept) |

### vs Tree

| | TreeNavigation | Tree |
|--|----------------|------|
| Purpose | Routes / explorer | Data / multi-check |
| Selection | `route` + `focus` | `selected` (+ checks) |
| Lazy | `LazyLoadRequested` + gen | Host-only |
| Ancestors | Painted strong | Not tracked |
