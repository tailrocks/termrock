# 0329 — Tabs rule keeps the selection wash

**Version:** `v0.14.0`
**Kind:** behavioral

The default `TabsActiveCue::Rule` now combines both selected-tab signals:

- the existing `Role::SelectionTint` background wash;
- the focus-aware bottom rule introduced in migration 0327.

The rule uses `Role::Accent` when the selected tab owns focus and
`Role::Border` otherwise. The background keeps the same theme override and
motion behavior as `TabsActiveCue::AccentPill`.

No consumer edit is required. `AccentPill`, `Connected`, and `Marker` remain
available as explicit alternatives.
