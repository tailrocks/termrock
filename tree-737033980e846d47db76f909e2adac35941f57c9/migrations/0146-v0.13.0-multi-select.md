# 0146 — MultiSelect searchable multi-choice

## Mission

Searchable multiple-choice selector: check state ≠ keyboard highlight, select
all / clear, max selection, groups, chip summary with overflow, range select,
popover/fullscreen modes for filters and task pickers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Stub `controls::MultiSelect` / `Added` / `Removed` | **Deleted** |
| `Select` / `SelectOption` / `SelectPresentation` / `SelectRecipe` | **Preserved** — shared option model & presentation |
| `Selection` (widgets) | **Preserved** — ordered membership |
| `CollectionState` | **Preserved** — list highlight |
| Full `multi_select.rs` | **Added** |

## Consumer edits

```diff
- let mut state = MultiSelectState::new(vec![]);
- state.focused = true;
- match state.handle_key(key, &ids) {
-     MultiSelectOutcome::Added(id) => {}
-     MultiSelectOutcome::Removed(id) => {}
-     _ => {}
- }
- MultiSelect::new(&pairs, &system).render(area, buf, &state);

+ let options = vec![
+     SelectOption::group("g", "Lang"),
+     SelectOption::option("rs", "Rust"),
+     SelectOption::option("go", "Go"),
+ ];
+ let mut state = MultiSelectState::new()
+     .with_searchable(true)
+     .with_max_selected(Some(5))
+     .with_max_summary_chips(3)
+     .with_selected(["rs"]);
+ state.set_focused(true);
+ match state.handle_key(key, &options, bounds) {
+     MultiSelectOutcome::Opened { presentation } => { /* overlay */ }
+     MultiSelectOutcome::Toggled { id, checked } => {}
+     MultiSelectOutcome::SelectAll { count } => {}
+     MultiSelectOutcome::Cleared => {}
+     MultiSelectOutcome::RangeApplied { ids } => {}
+     MultiSelectOutcome::MaxReached { max } => {}
+     MultiSelectOutcome::Closed => {}
+     _ => {}
+ }
+ MultiSelect::new(&options, &system)
+     .label("Filters")
+     .paint_stacked(area, buf, &mut state);
```

### Keys (open)

| Chord | Action |
|-------|--------|
| Space | Toggle highlight |
| Enter | Confirm & close |
| Esc | Close (keep checks) |
| Ctrl+A | Select all visible |
| Ctrl+D | Clear |
| Shift+↑/↓ | Range check |
| Type | Search filter |

### Closed summary

Shows up to `max_summary_chips` labels as chips, then `+N`. × clears.
