# 0109 — Toolbar roving action strip

## Mission

Roving-focus contextual command strip: buttons, toggles, separators, labels,
key hints, icons, responsive overflow, command metadata, and clear separation
between toolbar surface focus and content selection.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ActionBar`, `Action`, `ActionBarState` | **Preserve** — simple dialog footer strips |
| `DataTableToolbar` | **Preserve** — table-local bulk labels (can host Toolbar later) |
| `Toolbar`, `ToolbarItem`, `ToolbarState`, `ToolbarOutcome` | **Added** |
| `RovingFocusGroup` | **Preserve** — used as toolbar cursor engine |
| Dialog `ChoiceDialog` action paint | **Preserve** — still ActionBar |

## API sketch

```rust
use termrock::widgets::{
    Toolbar, ToolbarItem, ToolbarState, ToolbarOutcome, ToolbarOrientation,
};
use termrock::style::DesignSystem;

let system = DesignSystem::default();
let items = [
    ToolbarItem::action("save", "Save").hint("C-s").command("file.save").priority(90),
    ToolbarItem::separator("s1"),
    ToolbarItem::toggle("wrap", "Wrap", false).priority(40),
    ToolbarItem::action("help", "Help").priority(10),
];

let mut state = ToolbarState::horizontal();
state.set_surface_focused(true); // host: toolbar owns keys
state.set_cursor(Some("save"));

// paint
StatefulWidget::render(
    &Toolbar::new(&items, &system).overflow_id("more").compact(),
    area,
    buf,
    &mut state,
);

// keys only when surface_focused
match Toolbar::new(&items, &system).overflow_id("more").handle_key(&mut state, key, area) {
    ToolbarOutcome::Activated(id) => { /* run command */ }
    ToolbarOutcome::Toggled { id, pressed } => { /* apply */ }
    ToolbarOutcome::OverflowOpened => { /* open menu from state.overflow_indices */ }
    ToolbarOutcome::CursorMoved { .. } => {}
    ToolbarOutcome::Ignored => {}
    _ => {}
}
```

## Focus model

| Concept | Owner |
|---------|--------|
| Surface focus (`surface_focused`) | Host / InteractionScene |
| Roving cursor (`state.cursor`) | Toolbar |
| Content selection (list/table) | Content widgets — **never** cleared by Toolbar |

When `surface_focused == false`, keys are ignored even if a cursor is set.

## Overflow

Items that do not fit move to `state.overflow_indices` (lowest `priority` first).
Requires `overflow_id` for the "⋯" chip. Host paints the overflow menu.

## vs ActionBar

| | Toolbar | ActionBar |
|--|---------|-----------|
| Roving / keys | yes | caller-owned |
| Overflow | yes | clip only |
| Toggles / labels / hints | yes | labels only |
| Use | contextual chrome | dialog footers |
