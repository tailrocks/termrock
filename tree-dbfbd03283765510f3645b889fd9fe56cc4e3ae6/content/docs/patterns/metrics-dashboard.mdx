## Workflow

- `arrows select metric`: move visible focus, selection, pane, or hierarchy state for the next action.
- `Enter inspect`: invoke the focused public state-machine action and inspect its typed request.
- `Tab focus region`: move visible focus, selection, pane, or hierarchy state for the next action.
- `Ctrl+T range`: forward this normalized action to the mounted public pattern state.
- `Ctrl+R refresh`: forward this normalized action to the mounted public pattern state.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.

## Migrated handbook guidance

# MetricsDashboard

Reusable observability dashboard block. Host projects metric tiles and alerts;
TermRock lays out a responsive grid (or narrow summary), paints via public
`Sparkline` / `Gauge` APIs, and emits refresh / drill-down / time-range
**requests**.


## When to use / when not

| Use MetricsDashboard | Prefer |
|----------------------|--------|
| Ops / SRE metric overview | — |
| Table + log ops shell | `OpsDashboardState` / `layout_ops_dashboard` |
| Single chart | [Charts](/docs/interaction-notes) |
| Process list | [ProcessTable](/docs/patterns/process-table) |

## Ownership

| Concern | Owner |
|---------|--------|
| Scrape, query, aggregation | Host |
| Layout, focus, time/comparison chrome | `MetricsDashboardState` |
| Sparkline/Gauge raster | Public chart widgets |

## Partial failure

Each `MetricTile` has `MetricTileHealth` (`Ok` / `Warning` / `Danger` /
`Loading` / `Failed` / `Stale`). One failed tile does not blank the dashboard.

## Narrow terminals

Width ≤ 48 → `MetricsDashboardLayoutMode::Summary`: one line per metric
(`letter title value delta`).
