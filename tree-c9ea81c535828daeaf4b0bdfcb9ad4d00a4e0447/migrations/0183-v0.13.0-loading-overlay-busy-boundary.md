# 0183 — LoadingOverlay and BusyBoundary

## Mission

Coordinated loading that blocks **only the affected region** instead of freezing
the whole application. Modes: non-blocking busy, blocking, cancellable,
optimistic, and stale-content. Preserve readable content when safe; explain what
is unavailable; manage focus and input routing explicitly; avoid overlay abuse
for short operations (min-show + short-op policy). Nested region + cancellation
tests.

Research: async UI boundaries, Textual workers, agent tool execution.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `LoadingView` | **Preserved** — centered body placeholder (Panel `PanelBody::Loading`) |
| `Spinner` / `ActivityIndicator` | **Preserved** — composed for glyphs/ticks |
| `Backdrop` (modal) | **Preserved** — full-screen modal wash; not regional busy |
| Full-app OverlayStack loading | **Avoid** for short ops; use BusyBoundary on panes |
| `BusyMode` | **Added** |
| `BusyBoundaryState` + input routing | **Added** |
| `LoadingOverlay` paint | **Added** |
| `BusyBoundary` paint helpers | **Added** |
| Nested boundary helpers | **Added** |
| Min-show / short-op constants | **Added** |

Nothing deleted. Prefer LoadingOverlay+BusyBoundary for regional work;
LoadingView remains for full body replace.

## Consumer edits

```diff
+ use termrock::widgets::{
+     BusyBoundary, BusyBoundaryState, BusyMode, BusyRoute, LoadingOverlay,
+ };
+ use termrock::runtime::FrameTick;
+ use termrock::style::Motion;

  // Regional busy (table pane, not whole app):
+ let mut busy = BusyBoundaryState::new();
+ let _ = busy.begin(BusyMode::Cancellable, "Syncing");
+ busy.set_expected_ms(Some(2_000)); // short ops skip heavy wash
+ busy.set_unavailable(Some("Edits paused"));
+ // each frame:
+ busy.advance_ms(delta_ms);
+ // paint content first, then:
+ BusyBoundary::paint(pane, buf, &mut busy, &system, tick, Motion::Full);
+ // input:
+ match busy.route_key(key) {
+     BusyRoute::Cancel => { /* abort work */ }
+     BusyRoute::Blocked => { /* swallow */ }
+     BusyRoute::Deliver => { /* handle as normal */ }
+     BusyRoute::Outside => {}
+ }

  // Nested:
+ let mut child = BusyBoundaryState::nested_under(&parent);
+ BusyBoundary::paint_nested(parent_area, child_area, buf, &mut parent, &mut child, &system, tick, motion);
```

### Stories
