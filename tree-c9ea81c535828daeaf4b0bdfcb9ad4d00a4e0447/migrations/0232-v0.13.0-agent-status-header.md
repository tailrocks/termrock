# 0232 — AgentStatusHeader compact agent/session chrome

## Mission

Compact top-level status for the current agent/session: project/session, branch,
agent/mode/model, connection, working/waiting, context usage, cost/time when
provided, action-required. **Actionable state outranks decorative metadata.**
Narrow layouts contract into `StatusBar` slots. Quick actions: sessions, model,
tasks, help. Provider-neutral.

Research: Grok Build headers, OpenCode, Amp, IDE workspace headers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `StatusBar` / `StatusSlot` / regions / recipes | **Preserved** — general bar; header contracts into it |
| `ModeRibbon` | **Preserved** — mode strip only |
| `ContextMeter` | **Preserved** — full budget surface |
| `Connectivity` status_bar projection | **Preserved** |
| Agent workbench south `StatusBar` slots | **Preserved** (can project via `project_status_slots`) |
| `AgentStatusHeader` / snapshot / actions | **Added** |
| Nothing deleted | |

## API

```rust
use termrock::widgets::{
    AgentStatusHeader, AgentStatusHeaderState, AgentStatusSnapshot,
    AgentWorkStatus, AgentConnectionStatus, AgentStatusAction,
    AgentStatusHeaderOutcome, example_agent_status,
};

let mut state = AgentStatusHeaderState::new();
state.set_snapshot(example_agent_status());
// auto_contract: width < 56 → StatusBar paint
AgentStatusHeader::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    AgentStatusHeaderOutcome::Action(AgentStatusAction::Sessions) => { /* picker */ }
    AgentStatusHeaderOutcome::Action(AgentStatusAction::Model) => { /* model */ }
    AgentStatusHeaderOutcome::Action(AgentStatusAction::Tasks) => { /* rail */ }
    AgentStatusHeaderOutcome::Action(AgentStatusAction::Help) => { /* help */ }
    _ => {}
}

// Explicit StatusBar projection for host-owned south bar:
let slots = state.project_status_slots();
```

### Priority (drop order under pressure)

2. Connection offline/degraded  
3. Working / streaming  
4. Project · branch · session  
5. Mode · model · context · queue
