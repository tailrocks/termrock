# 0123 — Markdown premium

## Mission

Editorial, streaming-capable Markdown for terminal apps: multi-row layout,
dependency-free projection, unfinished fences without thrash, selection/copy,
source anchors, link activation, responsive tables, Glow-style section gaps,
and composition with Heading, Paragraph, CodeBlock, and Link.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `MarkdownView::new` / `first` / `compact_headings` | **Preserved** |
| `MarkdownBlock` / `MarkdownBlockKind` | **Migrated** — expanded kinds + fields |
| `project_plain_lines` | **Preserved** — aliases enhanced [`project_markdown`] |
| `Widget` render path | **Preserved** |
| Heading / Paragraph paint reuse | **Preserved** |
| `CodeBlock` for fences | **Composed** |
| `MarkdownViewState`, outcomes, inlines, anchors | **Added** |
| Full CommonMark crate | **Not added** — host may supply projected blocks |

## API sketch

```rust
use termrock::widgets::{
    MarkdownView, MarkdownViewState, MarkdownOutcome, project_markdown,
};

let blocks = project_markdown(source);
let mut state = MarkdownViewState::new();
state.set_focused(true);

let view = MarkdownView::new(&blocks, &system)
    .compact_headings(false)
    .fence_line_numbers(true)
    .section_gap(true);

let parts = view.paint(area, buf, &mut state);
// parts.links — hit regions for OSC-8 / host open
match view.handle_key(&mut state, key) {
    MarkdownOutcome::LinkActivated { href, .. } => { /* open */ }
    MarkdownOutcome::Copy { text } => { /* clipboard */ }
    MarkdownOutcome::Scrolled { scroll_y } => {}
    _ => {}
}
```

## Block kinds

`Paragraph` · `Heading` · `Code` · `Fence` · `Quote` · `ListItem` ·
`OrderedItem` · `TaskItem` · `Rule` · `Table` · `Blank`

## Streaming

Open fence without close → one `Fence` block with `incomplete: true` and a
stable trailing cue. Measure does not reflow earlier blocks when the body grows
if the host re-projects only the tail (append-friendly).
