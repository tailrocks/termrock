## Usage

The Code view above and this source excerpt use the exact paint setup registered for `callout/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn callout_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let tokens = system.clone().density(Density::default());
    Widget::render(
        &Callout::new("Heads up", &tokens)
            .body("Non-color risk glyph present.")
            .tone(CalloutTone::Warning),
        area,
        frame.buffer_mut(),
    );
}
```
