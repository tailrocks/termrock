# 0246 — ErrorRecovery / CrashReport composition block

## Mission

Graceful recovery for serious failures: human summary, preserved work, recovery
options (restart/restore session, copy diagnostics, logs, environment/
capabilities, report issue, safe quit), redacted crash-report projection, and
inline fallback when full-screen paint is compromised. **Host owns** panic
hooks, process restart, session persistence, log tails, issue trackers, and
terminal restore.

Research: crash reporters, terminal panic hooks, session restoration, resilient
CLI design (references only).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ErrorState` / `ErrorView` / `Recovery` / `ErrorKind::Crash` | **Preserved** — summary paint |
| `example_error_crash` and ErrorState recipes | **Preserved** — standalone stories remain |
| `List` | **Preserved** — recovery action list |
| `StatusBar` | **Preserved** — chrome |
| `redact_history_text` / `HistoryRedaction` | **Preserved** — used inside crash redaction |
| `DoctorReport` | **Preserved** — optional capabilities cue |
| Panic hooks / process spawn / network issue submit | **Host-owned** |
| Dual recovery UI vs ErrorState without composition | **Forbidden** as product path — compose ErrorRecovery |
| `ErrorRecoveryState` · `render_error_recovery` · `redact_crash_report_text` | **Added** (`patterns/error_recovery`) |

## Consumer API

```rust
use termrock::patterns::{
    ErrorRecoveryState, ErrorRecoverySurfaces, ErrorRecoveryMode, ErrorRecoveryOutcome,
    CrashReportSnapshot, example_crash_snapshot_with_secrets, build_redacted_crash_report,
    render_error_recovery, seed_inline_fallback, seed_terminal_restore_failed,
};

let mut state = ErrorRecoveryState::new(); // or ::inline_fallback()
let snap = example_crash_snapshot_with_secrets();
// seed_terminal_restore_failed(&mut state);

render_error_recovery(buf, area, ErrorRecoverySurfaces {
    system: &system,
    state: &mut state,
    snapshot: &snap,
    doctor: None,
});

match state.handle_key(key, &snap) {
    ErrorRecoveryOutcome::RestartRequested => { /* host restart */ }
    ErrorRecoveryOutcome::RestoreSessionRequested => { /* host restore */ }
    ErrorRecoveryOutcome::CopyDiagnostics { text } => { /* clipboard redacted text */ }
    ErrorRecoveryOutcome::ReportIssue { text } => { /* open tracker */ }
    ErrorRecoveryOutcome::SafeQuit => { /* restore tty then exit */ }
    ErrorRecoveryOutcome::OpenLogs => { /* host tail */ }
    ErrorRecoveryOutcome::ShowCapabilities => { /* doctor / env */ }
    _ => {}
}

// Pure redaction path (same as copy):
let safe = build_redacted_crash_report(&snap);
```

### Modes

| Mode | Panes |
|------|-------|
| Full | Summary · Actions · Diagnostics (redacted) · Preserved · Status |
| InlineFallback | Summary · Actions · Status (no diagnostics pane) |

### Laws

| Law | Detail |
|-----|--------|
| Secret redaction | `build_redacted_crash_report` / `redact_crash_report_text` on copy+report |
| Host effects | No panic hook, process, or network in pattern |
| Keyboard parity | r/s/c/l/e/i/q always available (not hover-only) |
| ErrorState compose | Summary pane paints public ErrorState |

### Stories

- `error-recovery/{basic,redacted,inline,unicode}`

## Second-pass design review

**Decisions**

1. Elevated composition peer to HelpCenter — ErrorState remains the summary body.
2. Crash report text is always redacted before copy/report outcomes.
3. Inline fallback drops diagnostics pane but keeps action chords.
4. Panic hooks and terminal restore stay host/session-owned.

**Rejected**

- Embedding Sentry/upload backends.
- Installing `std::panic` hooks in the pattern.
- Second ErrorState paint fork for crash-only UI.

**Residual limits**

- Redaction is pattern-based, not a secrets vault.
- PTY fault injection: honest skip if harness lacks PTY; unit covers redaction + outcomes.
