# 0219 — ToolCallCard and elevated ToolStatus

## Mission

Reusable compact-to-expanded representation of agent tool execution: queued,
preparing, running, waiting for input, waiting for permission, streaming,
success, warning, failure, cancelled, and detached. Show tool name, meaningful
verb, actor/provenance, arguments summary, duration, result summary, risk, and
actions. Inline expansion and fullscreen semantic zoom. Redact secrets; make
data egress explicit. Never couple to a specific agent provider or tool protocol.

Research: Grok Build, Amp, OpenCode, Claude Code tool presentations.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ToolCard` | **Preserved** — thin paint-only summary (Card chrome + status badge) |
| `ToolStatus` | **Migrated (breaking)** — elevated lifecycle: `Pending`→`Queued`, `Done`→`Success`, `Error`→`Failed`; added Preparing, WaitingInput, WaitingPermission, Streaming, Warning, Detached |
| `SemanticStatus::from_tool_status` | **Migrated** — maps full elevated set |
| `TerminalOutput` | **Preserved** — full command/PTY chrome; compose for detail panes |
| `PermissionPrompt` | **Preserved** — host focuses via `PermissionFocus` outcome |
| Provider / MCP / process spawn | **Never TermRock** |
| `ToolCall` · `ToolRisk` · `ToolCallAction` · `ToolCallCard*` · `project_tool_call_lines` · `redact_tool_secrets` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    ToolCall, ToolCallCard, ToolCallCardState, ToolCallCardOutcome,
    ToolCallPresentation, ToolRisk, ToolStatus, example_tool_calls,
    project_tool_call_lines, redact_tool_secrets, TOOL_CALL_FULLSCREEN_OVERLAY_ID,
};

let call = ToolCall::new("t1", "bash", "ran cargo test")
    .status(ToolStatus::Success)
    .args_summary("cargo test -p termrock")
    .result_summary("ok · 12 passed")
    .duration("1.2s")
    .risk(ToolRisk::Read)
    .secrets_redacted(true)
    .has_diff(false)
    .has_log(true);

let mut st = ToolCallCardState::new();
// ToolCallCard::new(&call, &system).paint(area, buf, &mut st);

match st.handle_key(key, &call) {
    ToolCallCardOutcome::CancelRequested { id } => { /* host cancel */ }
    ToolCallCardOutcome::RetryRequested { id } => { /* host retry */ }
    ToolCallCardOutcome::PermissionFocus { id } => { /* focus PermissionPrompt */ }
    ToolCallCardOutcome::FullscreenRequested { id } => {
        // push overlay TOOL_CALL_FULLSCREEN_OVERLAY_ID
    }
    ToolCallCardOutcome::CopyArgs { text, .. }
    | ToolCallCardOutcome::CopyResult { text, .. } => { /* clipboard; already redacted */ }
    ToolCallCardOutcome::Expanded { .. } | ToolCallCardOutcome::Collapsed { .. } => {}
    _ => {}
}

// MessageThread plain-line projection
let lines = project_tool_call_lines(&call, st.is_expanded(), ascii);
```

### ToolStatus rename map

| Old | New |
|-----|-----|
| `Pending` | `Queued` (default) |
| `Done` | `Success` |
| `Error` | `Failed` |
| — | `Preparing`, `WaitingInput`, `WaitingPermission`, `Streaming`, `Warning`, `Detached` |

### Keys

| Key | Action |
|-----|--------|
| Enter / Space | Toggle expand |
| `c` | Cancel (when `can_cancel`) |
| `r` | Retry (when `can_retry`) |
| `p` | Permission focus (WaitingPermission) |
| `d` / `l` | Open diff / log (host) |
| `f` | Fullscreen zoom |
| Esc | Exit fullscreen → expanded |
| Ctrl+A / Ctrl+C | Copy args / result (redacted) |
