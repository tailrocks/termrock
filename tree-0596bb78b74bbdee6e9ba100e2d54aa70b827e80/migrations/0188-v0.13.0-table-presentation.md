# 0188 — Table presentation redesign

## Mission

Redesign `Table` as a polished static / moderately sized columnar presentation
component: headers, alignment, widths, clip/ellipsis overflow, row and optional
cell focus, row selection, empty/loading/error body states, responsive column
priorities, quiet/bordered/striped/compact recipes, sticky header, and horizontal
scroll. Display model stays separate from interactive [`DataTable`] (cursor,
sort/filter execution, 1M virtual windows).

Research: Rich tables, Glow, DB clients, btop, TermRock DataTable / List.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Table::new` / `focused` / `column_gap` | **Preserved** (`column_gap` now optional override; recipe supplies default) |
| `Column` / `ColumnWidth` / `CellAlignment` / `SortDirection` | **Preserved** |
| `Column.priority` + `.priority()` | **Added** (default 50; higher survives width pressure longer) |
| `TableRow` / builders / `composed` | **Preserved** |
| `TableState` selection, hover, offset, regions, `resolve_widths` | **Preserved** |
| `TableOutcome` | **Preserved** |
| `TableRecipe` Quiet\|Bordered\|Striped\|Compact | **Added** |
| `TableBodyState` Ready\|Loading\|Error | **Added** |
| `CellOverflow` Clip\|Ellipsis | **Added** |
| `Table::{recipe, body_state, sticky_header, overflow, empty_message, loading_message, error_message, from_system}` | **Added** |
| `TableState::{h_offset, focused_column, scroll_horizontal, set_focused_column, visible_column_indices}` | **Added** |
| Selection marker `▸ ` | **Migrated** → design-system `SelectionChrome` gutter (`▌` / ASCII) + Fill/Tint hierarchy |
| Layout collapse rightmost-only | **Migrated** → lowest **priority** first (ties still rightmost) |
| `default_table_intent` Left/Right | **Added** → `NavigationMove::Left` / `Right` (cell focus or H-scroll) |
| `DataTable` | **Preserved** — interactive kit; do not merge |

`Column` gained `priority: u8` — prefer builders (`Column::new(...).priority(n)`)
over struct literals.

## Consumer edits

```diff
  use termrock::widgets::{
-     Column, ColumnWidth, Table, TableRow, TableState,
+     Column, ColumnWidth, Table, TableBodyState, TableRecipe, TableRow, TableState,
  };

  let columns = [
-     Column { id: "name", title: Line::from("Name"), width: ColumnWidth::Min(8), ... },
+     Column::new("name", "Name", ColumnWidth::Min(8)).priority(100),
+     Column::new("meta", "Meta", ColumnWidth::Min(12)).priority(10),
  ];
  let mut state = TableState::new(Some("r1"));
- frame.render_stateful_widget(&Table::new(&columns, &rows, &system), area, &mut state);
+ frame.render_stateful_widget(
+     &Table::new(&columns, &rows, &system)
+         .recipe(TableRecipe::Bordered)
+         .body_state(TableBodyState::Ready)
+         .empty_message(Line::from("No rows"))
+         .sticky_header(true),
+     area,
+     &mut state,
+ );
  // Left/Right: cell focus among visible columns, else horizontal scroll
  // state.scroll_horizontal(1); state.set_focused_column(Some("name"));
```

### Stories

- Existing `table/*` preserved
- `table/bordered`, `table/striped`, `table/compact`
- `table/loading`, `table/error`, `table/priority`
