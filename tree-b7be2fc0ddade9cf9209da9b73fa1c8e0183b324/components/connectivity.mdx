## Usage

```rust
use termrock::widgets::{
    ReconnectingState, OfflineBanner, OfflineSurface, ConnectivityPresentation,
    StatusSlot, StatusBar,
};

let mut conn = ReconnectingState::new("agent://prod-1");
conn.begin_reconnect(3);
conn.set_now_secs(now);
conn.set_last_success_secs(Some(last_ok));

// StatusBar
let label = conn.status_bar_content();
let right = [conn.status_slot_template("c", &label)];

// Banner
OfflineBanner::new(&conn, &system).paint(banner_row, buf);

// Full recovery
conn.set_presentation(ConnectivityPresentation::Full);
OfflineSurface::new(&system).paint(area, buf, &mut conn);

// Notifications
center.ingest_item(conn.to_notification_item("conn-1"));
```

## Rules

1. Prefer banner for transient blips; full surface for auth/unavailable/long outages.
2. Always show **target** + phase; include last-ok and retry when known.
3. Default **drafts + selection preserved** — say so on full surface.
4. Project StatusBar/NotificationCenter from the same state (no private strings).
5. Esc dismisses banner only; StatusBar still carries the connection cue.
