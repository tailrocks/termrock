## Usage

The Code view above and this source excerpt use the exact paint setup registered for `working-state-card/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn working_state_card_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::patterns::{
        WorkingStateCard, WorkingStateCardState, WorkingStatePresentation, example_working_state,
    };
    let mut state = WorkingStateCardState::new();
    state.set_work(Some(example_working_state()));
    state.presentation = WorkingStatePresentation::Expanded;
    state.focused = true;
    frame.render_stateful_widget(&WorkingStateCard::new(system).tick(3), area, &mut state);
}
```

## Migrated handbook guidance

# WorkingStateCard

Non-invasive “what is the agent doing now” card. Host supplies a **public
summary** only — never private chain-of-thought.
Collapsed status uses a quiet host-ticked pulse; expanded detail continues an
assistant actor rail. Pass `.tick(frame_tick)`; reduced motion stays static.


## When to use / when not

| Use WorkingStateCard | Prefer |
|----------------------|--------|
| Current turn work status | — |
| Multi concurrent ops strip | [ActivityShelf](/docs/components) |
| Raw reasoning chrome | ThinkingBlock (host policy) |
| Session-level chrome | [AgentStatusHeader](/docs/components/agent-status-header) |
