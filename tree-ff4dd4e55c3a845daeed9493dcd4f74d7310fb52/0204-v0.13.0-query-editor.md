# 0204 — QueryEditor code-oriented query workbench

## Mission

Code-oriented editor for SQL, logs, search languages, and structured queries:
syntax-ready multiline draft, completion, diagnostics, parameters, history,
run/stop, selection execution, format request, saved queries. Language services
and execution stay application-provided. Integrates CompletionMenu, CodeFrame /
Diagnostic, KeyboardHelp, HistoryPicker, and a results slot for host
DataTable / future ResultGrid. Draft and cursor survive result focus changes.
Compact and fullscreen modes.

Research: TablePlus-like query editors, database TUIs, Grafana query workflows,
terminal editors.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextArea` / `TextAreaState` | **Preserved** — edit kernel embedded as `QueryEditorState.editor` |
| `CompletionMenu` / `CompletionCandidate` | **Preserved** — host paints overlay; state nests `CompletionMenuState` |
| `Diagnostic` / `CodeFrame` / `SourceLabel` | **Preserved** — diagnostics strip + optional frame helper |
| `KeyboardHelp` / `HelpEntry` | **Preserved** — `query_editor_help_entries()` seed for live keymap merge |
| `HistoryPicker` / `HistoryEntry` | **Preserved** — `OpenHistory` / `saved_queries_to_history` bridge |
| `DataTable` | **Preserved** — host paints results into `QueryEditorSlots.results` |
| `ResultGrid` | **Not yet** — separate component; QueryEditor only provides results slot chrome |
| `PromptComposer` | **Preserved** — different product shell (agent prompts) |
| Language servers / DB drivers / formatters | **Never in TermRock** — outcomes only |
| `QueryEditor*` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    QueryEditor, QueryEditorState, QueryEditorOutcome, QueryFocus,
    QueryParameter, QueryResultSummary, QueryRunStatus, QueryLanguage,
    CompletionCandidate, CompletionMenu, Diagnostic, DiagnosticSeverity,
    HistoryPicker, KeyboardHelp, DataTable,
};

let mut state = QueryEditorState::with_text("select 1");
state.language = QueryLanguage::sql();
state.set_parameters(vec![QueryParameter::new("limit", "100").type_hint("int")]);

// Paint workbench
QueryEditor::new(&system)
    .title("sql")
    .diagnostics(&diags)
    .render(area, buf, &mut state);

// Host paints result grid into state.slots.results
// DataTable::new(...).render(state.slots.results, buf, &mut table_state);

// Input
match state.handle_key(key, &diags) {
    QueryEditorOutcome::RunRequested { text, selection_only, language } => {
        // execute; then state.set_run(QueryRunStatus::Running { run_id });
    }
    QueryEditorOutcome::StopRequested { run_id } => { /* cancel */ }
    QueryEditorOutcome::FormatRequested { text, language } => {
        // pretty-print → state.set_text(&formatted)
    }
    QueryEditorOutcome::CompletionRequested { query, cursor, language } => {
        // open CompletionMenu with host candidates
    }
    QueryEditorOutcome::OpenHistory => { /* HistoryPicker */ }
    QueryEditorOutcome::FocusChanged(QueryFocus::Results) => {
        // draft/cursor still intact
    }
    _ => {}
}
```

### Keys (Ctrl chords — no function keys in TermRock KeyCode)

| Key | Action |
|-----|--------|
| Ctrl+R / Ctrl+Enter | Run (selection if any, else full buffer) |
| Ctrl+Shift+S | Stop |
| Ctrl+F | Format request |
| Ctrl+S | Save query request |
| Ctrl+H | Open history |
| Ctrl+Shift+O | Open saved queries |
| Ctrl+Space | Completion request |
| Ctrl+J | Cycle focus: editor → results → diagnostics → params |
| Ctrl+1..4 | Focus zone |
| Ctrl+M | Cycle compact / normal / fullscreen |
| Ctrl+Shift+F | Fullscreen |
| Ctrl+? | Keyboard help |
| Esc | Close completion / leave zone / cancel |
