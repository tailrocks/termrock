## Live terminal (Ghostty-class)

This preview is a persistent Rust tree. Move selection, collapse or expand branches, and click rows; Reset restores the initial hierarchy.

<TerminalPreview story="tree/navigation" interactive caption="Tree · Navigate and collapse the real hierarchy" />

## Usage

```rust
use ratatui_core::text::Line;
use termrock::style::DesignSystem;
use termrock::widgets::{Tree, TreeNode, TreeState, filter_tree_with_ancestors};

let system = DesignSystem::default();
let nodes = [
    TreeNode::new("src", Line::from("src"), 0).branch().expanded(),
    TreeNode::new("lazy", Line::from("vendor"), 1).lazy_branch().parent("src"),
];
let mut state = TreeState::new(Some("src"));
// filter: filter_tree_with_ancestors(&nodes, "ven")
Tree::new(&nodes, &system);
```

## Try it

- `↑↓ select`: move by stable row identity.
- `←→ collapse/expand`: mutate disclosure state through `TreeState`.
- `click row`: select the hit-tested row.

Accepted actions update the same mounted Rust value. The status line shows the latest outcome; **Reset** creates a fresh instance.

## State and typed outcomes

`TreeState` owns selection and expansion. The host owns domain loading and effects; the demo uses deterministic in-memory nodes only.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.

## Test recipe

Mount `tree/navigation`, dispatch selection, disclosure, and pointer events, then assert the outcome and visible hierarchy.
