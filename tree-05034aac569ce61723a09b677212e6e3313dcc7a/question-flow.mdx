# QuestionFlow

Agent/workflow interview surface. Returns structured `QuestionAnswerSet` only;
hosts own workflow policy. **Never clears** PromptComposer draft.

## When to use / when not

| Use QuestionFlow | Prefer |
|------------------|--------|
| Multi-step agent questions | — |
| Multi-field data forms | [FormWizard](/docs/handbook/form-wizard) |
| Trust gates | [PermissionPrompt](/docs/handbook/permission-prompt) |
