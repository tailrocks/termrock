# 0080 — EventResult + typed component outcomes

## Mission

Standardize how components report consumed input, domain messages, redraw,
focus requests, and overlay requests without forcing a global app architecture.

## Added

| API | Role |
|-----|------|
| `interaction::EventResult<M, FocusId>` | Envelope: propagation, message, redraw, focus, overlay |
| `Redraw`, `Propagation` | Paint + bubble/stop |
| `FocusRequest<Id>` | Set / Clear / Next / Previous (framework) |
| `OverlayRequest` | DismissTop / Dismiss / OpenJump / OpenCommandPalette / OpenNamed |
| `compose_bubble`, `compose_capture` | Nested composites |
| `Outcome::into_event_result` | List shared outcomes → envelope |
| `ActivationOutcome::into_event_result` | Button path |
| `handle_key_result` / `handle_intent_result` | List, Picker, ThemePicker, Section, Alert, Activation |

## Preserved

- Per-widget `*Outcome` enums as **domain messages** (`M`)
- Existing `handle_key` → `*Outcome` APIs (additive `*_result` paths)
- `InteractionOutcome`, `OverlayOutcome` (scene/stack, not widget envelope)

## Expanded (same commit)

`UiIntent` gained global/edit variants (`FocusNext`, `Search`, `Help`, …). Widget
`handle_intent` matches use `_ => Ignored` for unknown intents.

## Consumer edits

### Prefer EventResult at host boundary

```rust
use termrock::interaction::{EventResult, OverlayRequest};

// Before
match list.handle_key(&rows, key) {
    Outcome::Ignored => {}
    Outcome::Activated(id) => open(id),
    _ => { dirty = true; }
}

// After
let r = list.handle_key_result(&rows, key);
if let Some(Outcome::Activated(id)) = r.message() {
    open(id.clone());
}
if r.redraw().needs_paint() {
    dirty = true;
}
if matches!(r.overlay(), Some(OverlayRequest::DismissTop)) {
    stack.handle_escape();
}
```

### Nested composites

```rust
use termrock::interaction::compose_bubble;

let result = compose_bubble(child.handle_key_result(key), || parent.handle_key_result(key));
```

### ThemePicker / Alert

Raw `match key.code` removed; intents + `handle_key_result` (cancel →
`OverlayRequest::DismissTop`).
