# 0229 — CheckpointTimeline rewindable session history

## Mission

Rewindable session history for agent turns, file states, and significant
actions: labels, actor, timestamp, summary, changed files, tool calls,
irreversible boundaries, branch/fork, preview, rewind, restore. **Viewing ≠
mutating** — Browse/Preview never rewrite session; Restore/Rewind are request
outcomes only. Warn when uncommitted work or external effects cannot restore.
**Never** clears host PromptComposer draft. Compare is pure (host opens
DiffReview). Uses Timeline as list substrate where appropriate.

Research: Grok Build rewind, IDE local history, Git reflog, notebook checkpoints.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Timeline` / `TimelineEvent` / `TimelineState` / recipes | **Preserved** — general chronology |
| `TimelineOutcome::RestoreRequested` / `CompareRequested` + `checkpoint_mode` | **Preserved** — generic Timeline path |
| Thin `CheckpointTimeline` façade wrapping Timeline in `timeline.rs` | **Deleted** |
| `HistoryPicker` | **Preserved** — field-local value history |
| `DiffReview` | **Preserved** — compare host target |
| PromptComposer draft | **Never touched** |
| `Checkpoint` · `CheckpointBoundary` · elevated `CheckpointTimeline*` | **Added** (`checkpoint_timeline` module) |

## Breaking API

```rust
// Before
let events = [
    TimelineEvent::checkpoint("c0", "10:00", "session open"),
    TimelineEvent::checkpoint("c1", "10:05", "after plan"),
];
let mut state = TimelineState::new();
CheckpointTimeline::new(&events, &system).render(area, buf, &mut state);
// Enter → TimelineOutcome::RestoreRequested

// After
use termrock::widgets::{
    CheckpointTimeline, CheckpointTimelineState, CheckpointTimelineOutcome,
    example_checkpoints,
};

let mut state = CheckpointTimelineState::new();
state.set_checkpoints(example_checkpoints());
CheckpointTimeline::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    CheckpointTimelineOutcome::PreviewOpened { id } => { /* view only */ }
    CheckpointTimelineOutcome::RestoreRequested { id } => { /* host restores */ }
    CheckpointTimelineOutcome::RewindRequested { id } => { /* host rewinds */ }
    CheckpointTimelineOutcome::CompareRequested { from, to } => { /* DiffReview */ }
    CheckpointTimelineOutcome::Cancelled => { /* draft intact */ }
    _ => {}
}
```

Generic Timeline checkpoint rows still work:

```rust
state.set_checkpoint_mode(true);
// Enter → TimelineOutcome::RestoreRequested
```

### Modes

| Mode | Meaning |
|------|---------|
| Browse | Viewing history (safe) |
| Preview | Inspect checkpoint; draft preserved; no mutation |
| Confirm | Explicit restore/rewind request; **Cancel** default focus |

### Boundaries

Soft · DirtyWorkspace · ExternalEffects · Irreversible (blocks restore)

### Keys

j/k · Enter preview · r restore · w rewind · c compare · a anchor · f follow ·
Esc back/cancel · confirm: ←/→ · Enter · **y unbound**

### Stories

- `checkpoint-timeline/{basic,preview,confirm,boundaries,narrow,unicode}`
- `timeline/checkpoint` — Timeline row kind substrate only
