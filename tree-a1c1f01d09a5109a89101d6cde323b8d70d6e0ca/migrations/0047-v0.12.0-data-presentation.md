# 0047 — Data presentation foundation

## Removed surface

None. Existing `Table`, `VirtualGrid`, `DetailTable`, `LogPane`, `DiffView`,
and charts remain.

## Canonical addition

Shared kits in `termrock::widgets::data_view` (re-exported from `widgets`):

- `VirtualWindow` — O(1) scroll over u64 logical lengths (incl. 1_000_000)
- `ColumnModel` / `DataColumn` / `ColumnPin` / `DataColumnWidth`
- `SelectionModel` / `SelectionMode` / `CellCoord`
- `LoadState`, `DataDensity`, `SortSpec`, `FilterSpec`
- `CopyPayload`, `ExpandState`, `DataViewOutcome`
- `data_view_bench` — story/bench constants (`ROWS_10`, `ROWS_10K`, `ROWS_1M`, …)

Design SoT: `docs/design/data-presentation.md`.

### Consumer direction

New large-table work should project **only** `VirtualWindow::visible_range()`
rows. Do not build a full `Vec` of 1M row widgets.

```rust
use termrock::widgets::{VirtualWindow, ColumnModel, SelectionModel, LoadState};

let mut rows = VirtualWindow::new(1_000_000, 40);
let (start, end) = rows.visible_range();
let page = source.project(start, end);
```
