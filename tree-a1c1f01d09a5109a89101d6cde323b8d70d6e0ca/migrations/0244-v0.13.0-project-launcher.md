# 0244 — ProjectLauncher composition block

## Mission

Complete **project/session launcher composition**: recent projects, favorites,
workspaces, branches, sessions, remote/local status, search, grouping, preview,
open/new/import, and errors. Inline quick launcher and full-screen home.
Responsive density. **Discovery and persistence stay application-owned**.

Research: IDE welcome screens, zoxide/fzf workflows, agent session launchers
(interaction references only — not a clone API).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `QuickOpen` / `QuickOpenState` | **Preserved** — palette / inline fast path |
| `SessionPicker` / `SessionEntry` / `example_sessions` | **Preserved** — sessions pane |
| `ConnectionStatus` (from ConnectionManager module) | **Preserved** — remote/local chrome on rows + StatusBar |
| `ConnectionManager` full inventory | **Preserved** — not dual-path; launcher does **not** embed full CM |
| `SearchInput` | **Preserved** — filter bar |
| `List` / group headers | **Preserved** — project catalog |
| `PreviewCard` | **Preserved** — selection preview |
| `EmptyState` / FirstUse | **Preserved** — onboarding entry |
| `StatusBar` | **Preserved** — summary chrome |
| `SetupWizard` | **Preserved** — host routes `OnboardingRequested` → setup; not re-painted here |
| Project discovery / history DB / git / network probes | **Host-owned** |
| `ProjectLauncherState` · `render_project_launcher` | **Added** (`patterns/project_launcher`) |

```rust
    example_project_quick_open, seed_stale_state, seed_onboarding_state,
    render_project_launcher, project_launcher_layout_density,

use termrock::widgets::example_sessions;

let mut state = ProjectLauncherState::new(); // or ::inline()

render_project_launcher(buf, area, ProjectLauncherSurfaces {

    state: &mut state,

    sessions: &sessions,
    preview: Some(preview),
    quick_open_items: &qo,

match state.handle_key(key, &projects, &sessions, &qo) {
    ProjectLauncherOutcome::OpenRequested { id } => { /* open project */ }
    ProjectLauncherOutcome::NewRequested => { /* create */ }
    ProjectLauncherOutcome::ImportRequested => { /* import/clone */ }
    ProjectLauncherOutcome::FavoriteToggled { id, on } => { /* persist pin */ }
    ProjectLauncherOutcome::SessionResume { id } => { /* resume */ }
    ProjectLauncherOutcome::SessionCreate { title } => { /* new session */ }
    ProjectLauncherOutcome::FilterChanged { query } => { /* reproject */ }
    ProjectLauncherOutcome::StaleAck { id } => { /* clear badge */ }
    ProjectLauncherOutcome::OnboardingRequested => { /* SetupWizard */ }
    _ => {}
}
```

### Modes & densities

| Mode | Density | Panes |
|------|---------|-------|
| `Home` | Normal ≥96 | Search · Projects · Sessions · Preview · Status (+ Onboarding) |
| `Home` | Narrow 52–95 | Search · Projects · Sessions · Status (no preview) |
| `Home` / `Inline` | Tiny &lt;52 or Inline | Search · Projects · Status |

### Laws

| Law | Detail |
|-----|--------|
| Public only | Composes public widgets; no project-list paint forks |
| Host discovery | Outcomes are requests only |
| Density=None | Last paint width drives collapse; Tab clamps to visible panes |
| Keyboard parity | open/new/import/fav/quick/session documented in status |
| ConnectionStatus | Product-neutral status enum for chrome — not full ConnectionManager |

## Second-pass design review

**Decisions**

1. Elevated pattern peer to FileManager / Observability — composition only.
2. Use `ConnectionStatus` for row + StatusBar chrome; do not embed full
   ConnectionManager (avoids dual connection UX).
3. `SessionPicker` owns session catalog interaction; launcher maps
   Opened/Create to SessionResume/SessionCreate.
4. Inline mode drops sessions/preview for zoxide-class speed; home keeps full.
5. Stale/missing are host-projected `ProjectPathStatus` — no FS probe in crate.

**Rejected**

- In-crate project scanners, history DBs, git branch enumeration.
- Cloning IDE welcome or fzf API shape.
- Dual interactive launcher vs a second welcome helper.

**Residual limits**

- Preview body is host-projected.
- SetupWizard is reached via `OnboardingRequested` outcome, not embedded paint.
- PTY/fuzz not required; unit + structural gates cover interaction.
