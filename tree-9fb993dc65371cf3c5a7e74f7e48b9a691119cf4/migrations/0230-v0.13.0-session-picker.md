# 0230 — SessionPicker agent session lifecycle

## Mission

Polished selector for creating, resuming, searching, renaming, archiving, and
deleting agent sessions: project, branch, status, recency, model/mode, summary,
unread/action-required, pinning, search, preview. **Preserve draft and app
context on cancel.** Safe delete/archive confirmation (Cancel default).
Multi-device/remote status. Thousands of sessions via windowed list + provider
search request. Popover and fullscreen presentation forms.

Research: Amp sessions, OpenCode sessions, Grok Build picker, project launchers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `SessionItem` / `SessionPicker` / `SessionPickerOutcome::Picked` / `session_picker_handle_key` / `ListState` state in `agent_blocks` | **Deleted** |
| `Picker` / `HistoryPicker` | **Preserved** — generic / value history |
| `CommandPalette` | **Preserved** — commands |
| PromptComposer draft | **Never touched** on cancel |
| `ModeRibbon` | **Preserved** in `agent_blocks` |
| `SessionEntry` · elevated `SessionPicker*` | **Added** (`session_picker` module) |

## Breaking API

```rust
// Before
let sessions = [SessionItem { id: "s1", title: "A", meta: Some("2m") }];
let mut state = ListState::new(Some("s1"));
SessionPicker::new(&sessions, &system).render(area, buf, &mut state);
session_picker_handle_key(&mut state, &rows, key); // Picked(id)

// After
use termrock::widgets::{
    example_sessions, SessionPicker, SessionPickerState, SessionPickerOutcome,
};

let mut state = SessionPickerState::new();
state.set_sessions(example_sessions());
// host draft stays intact while open
SessionPicker::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    SessionPickerOutcome::Opened { id } => { /* resume */ }
    SessionPickerOutcome::CreateRequested { title } => { /* new */ }
    SessionPickerOutcome::RenameRequested { id, title } => { /* … */ }
    SessionPickerOutcome::DeleteRequested { id } => { /* after confirm */ }
    SessionPickerOutcome::ArchiveRequested { id } => { /* … */ }
    SessionPickerOutcome::QueryChanged { query, provider_search } => { /* filter / remote */ }
    SessionPickerOutcome::LoadMore { offset } => { /* page */ }
    SessionPickerOutcome::Cancelled => { /* draft & context preserved */ }
    _ => {}
}
```

### Safety

| Rule | Detail |
|------|--------|
| Esc | `Cancelled` — no open/delete; host draft preserved |
| Delete / Archive | Confirm phase; **Cancel** default focus |
| `y` | Unbound |
| Disabled session | Cannot Open |

### Scale

- Local filter on windowed `sessions`
- `total_count` + `LoadMore` near end
- `QueryChanged.provider_search` when catalog large and query ≥ 2 chars

### Stories

- `session-picker/{basic,search,confirm,empty,narrow,unicode}`
