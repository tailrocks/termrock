# 0195 — LogStream continuous professional log viewer

## Mission

Redesign the log viewer for continuous professional use: follow-tail, pause,
unread/new-lines indicator, timestamps, source, severity, ANSI-safe body,
wrapping / horizontal scroll, search, filters, bookmarks, selection, copy and
export outcomes, bounded history / dropped-line indicators, burst batching,
reconnect banners, virtualization + stable anchors, compact and detailed line
recipes. Deliberate LogPane migration path (project, do not delete).

Research: k9s, stern-style workflows, Textual logs, btop, TermRock LogPane.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `LogStream` / `LogLine` / `LogLevel` / `LogStreamState` | **Migrated** — new module `widgets/log_stream.rs` (left `review`) |
| `LogStreamOutcome` | **Migrated** — richer non-`Copy` outcomes (search, filter, copy, export, bookmark, h-scroll, ack) |
| Follow / unread via `ScrollAreaState` | **Preserved** — sole authority |
| `default_log_stream_intent` | **Migrated** — Space no longer Toggle; `f` product chord for follow |
| Compact / detailed recipes (`LogLineRecipe`) | **Added** |
| `LogWrap`, h-scroll, search, level floor, bookmarks, selection | **Added** |
| `filter_log_lines`, `escape_log_text`, `log_lines_from_plain` | **Added** |
| `log_stream_bench` constants | **Added** |
| `LogPane` / `LogPaneState` | **Preserved** — owns append buffer; projects into LogStream when needed |
| DiffReview in `review` | **Preserved** — LogStream removed from that module |
| Old `LogLine { id, level, text }` struct literals | **Migrated** — prefer `LogLine::new(...).timestamp(...).source(...)` |

## Consumer API sketch

```rust
use termrock::widgets::{
    LogLevel, LogLine, LogLineRecipe, LogStream, LogStreamState, LogWrap,
    filter_log_lines, log_lines_from_plain, log_stream_bench,
};

let lines = [
    LogLine::new("1", LogLevel::Info, "ready")
        .timestamp("12:00:00")
        .source("main"),
    LogLine::new("2", LogLevel::Error, "fail").timestamp("12:00:01"),
];
let mut state = LogStreamState::new(); // following by default
state.recipe = LogLineRecipe::Detailed;
state.on_append(lines.len() as u16, viewport);
// Host: bounded drop / reconnect / burst
state.report_dropped(42);
state.set_reconnect_message(Some("resumed".into()));
state.report_batched(64);
// Anchor across reproject
state.capture_anchor(&lines);
// …reproject…
state.restore_anchor(&lines);

// Keys need the projected window (filter / select / copy / bookmark)
let out = state.handle_key(key, &lines);
// Scroll-only path when no window available:
// state.handle_key_scroll(key);

LogStream::new(&lines, &system)
    .title("app.log")
    .focused(true)
    .render(area, buf, &mut state);

// LogPane bridge
let mut ids = Vec::new();
let mut texts = Vec::new();
let projected = log_lines_from_plain(pane.lines(), &mut ids, &mut texts);
```

### Keys

| Key | Action |
|-----|--------|
| j/k ↑↓ | Cursor / scroll (detaches follow when moving up) |
| f | Toggle follow |
| Space | Toggle multi-select on cursor line |
| / | Search (type; Esc clears) |
| `[` | Cycle level floor |
| h/l ←→ | Horizontal scroll (clip mode) |
| w | Toggle wrap |
| d | Toggle compact/detailed recipe |
| m | Bookmark toggle |
| c | Copy selected or cursor line (host clipboard) |
| C-e | Export filtered view (host write) |
| b | Ack dropped / reconnect chrome |
| Home / End / PgUp / PgDn | Scroll extremes / re-follow |

## LogPane migration

1. Keep `LogPane` when the host must own a single append+evict buffer.
2. For stern/k9s-class multi-source viewing, project into `LogLine` each frame
   and paint with `LogStream`.
3. Bridge plain owned lines: `log_lines_from_plain` (level defaults Info).
4. Prefer native `LogLine` fields when severity, source, timestamp are known.
5. On history eviction, call `state.report_dropped(n)`; on reconnect, set
   `set_reconnect_message`.
