## Usage

```rust
use termrock::widgets::{
    RadioGroup, RadioOption, RadioState, RadioSelectionPolicy,
};

let options = [
    RadioOption::new("plan", "Plan").description("Read-only"),
    RadioOption::new("build", "Build").badge("default"),
    RadioOption::new("ask", "Ask"),
];
let mut state = RadioState::new(Some("build"));
state.set_surface_focused(true);

RadioGroup::new(&options, &system)
    .legend("Workbench mode")
    .paint(area, buf, &mut state);

// Destructive / review: move without commit
state.set_policy(RadioSelectionPolicy::ActivateToSelect);
```

## State and typed outcomes

The widget owns deterministic paint and layout. The host owns all surrounding state and effects; this demo intentionally exposes no fake cursor, click, or keyboard behavior.

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
