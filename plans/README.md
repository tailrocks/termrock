## Findings considered and rejected

- **Rounded borders as the new default** — rejected: phosphor identity law
  (square caps) and Jackin brand law; shipped as opt-in token instead
  (plan 002).
- **Solid-color dimmed backdrop** — rejected: `DIALOG_BACKDROP = Color::Reset`
  policy is deliberate (documented in `style/mod.rs:58-63`) so overlays
  inherit the operator's terminal theme; dimming ships as a glyph wash over
  Reset bg (plan 005).
- **Changing `StackSpec::default()` gap to density values** — rejected:
  bare `Stack` is a low-level primitive used outside design-system contexts;
  density flows in via `from_system`/`with_spacing` adoption instead
  (plan 003 step 4).
- **`BrandPill` primitive** — deferred: brand marks stay product-side per
  the design doc's boundary check; revisit only on a second consumer's
  evidence.
- **CI-level grep gate for `bg = None`** — deferred in favor of in-repo
  policy tests (plan 010 step 4); promote to CI later if drift recurs.
