## Findings considered and rejected

- Replacing the accepted canvas renderer with a Ghostty/VT renderer: rejected as
  a prerequisite. Rendering quality is accepted; live state and event routing
  are the missing layer. Keep renderer research independent and evidence-gated.
- Adding more baked frames or longer tours: rejected. A larger slideshow still
  cannot type text, drag a divider, open a dialog, or expose real outcomes.
- Reimplementing widget behavior in React: rejected. It would create a second
  behavior model and violate Lookbook's public-API-only rule.
- Inferring a terminal cursor from painted glyphs: rejected. The widget paints
  its real caret; passive controls must never receive a synthetic block cursor.
- Giving passive components fake actions: rejected. Passive paint stays live,
  but only real configuration/state controls are advertised.
