# 0261 — Surface ladder and semantic role expansion

## Mission

Make layered surfaces, quiet row states, and actor accents real semantic
tokens. Phosphor now paints an obsidian surface ladder instead of inheriting
the terminal background everywhere.

## Visible defaults

- `Canvas`, `Surface`, `Raised`, `Elevated`, and `Sunken` carry distinct dark
  backgrounds.
- `StatusBar` paints a `Surface` band.
- tint selection uses `SelectionTint`; hover wash uses `HoverTint`.
- success, hints, and chart series no longer collapse onto one accent green.

Compare surface, list, and tree stories in the lookbook across phosphor,
paper, ANSI, and high-contrast capability variants.

## Public API changes

`Role` adds `Raised`, `Sunken`, `SelectionTint`, `HoverTint`,
`ActionConstructive`, `DisclosureHeader`, `InfoStrong`, `InfoDim`,
`ActorUser`, `ActorAssistant`, `ActorThinking`, `ActorTool`, `ActorPlan`, and
`ActorSystem`. `ROLE_COUNT` changes from 49 to 63.

`ListRowRecipe` adds `hover_wash`, separating hovered-label styling from the
row background wash. Custom recipe construction must populate both fields.

Custom positional palette data must add all new roles in declaration order.
`Role` remains `#[non_exhaustive]`; external matches must retain a wildcard.

## Terminal-native opt-out

Hosts that must inherit the operator terminal background can select:

```rust
use termrock::style::DesignSystem;

let system = DesignSystem::terminal_native();
```

This keeps phosphor foreground semantics while restoring terminal-default
surface and status-bar backgrounds.

## Validation

```bash
rtk cargo nextest run -p termrock 'style::'
rtk cargo nextest run -p termrock surface
rtk cargo nextest run -p termrock list
rtk cargo nextest run -p termrock tree
rtk mise run check
```
