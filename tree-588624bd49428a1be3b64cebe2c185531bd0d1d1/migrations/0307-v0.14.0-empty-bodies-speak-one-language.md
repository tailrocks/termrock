# 0307 — Empty bodies speak one language

Fourteen widgets wrote their own empty state as a parenthesised lowercase
fragment — `(empty)`, `(no slides)`, `(no notifications)`, `(empty tree)` —
painted flush at the top-left in muted text, while the `EmptyState` widget that
exists for exactly this job had no adopters among them.

## Behavior changes

Four widgets now paint through `EmptyState` (glyph + sentence, one rule):
`Carousel`, `NotificationCenter`, `CheckpointTimeline`, `FilePicker`, and
`TraceWaterfall` for its host-supplied message.

Every remaining empty literal loses its parentheses and becomes a sentence:

| Widget | Before | After |
|---|---|---|
| `Carousel` | `(no slides)` | `No slides` |
| `NotificationCenter` | `(no notifications)` | `No notifications` |
| `CheckpointTimeline` | `(no checkpoints)` | `No checkpoints yet` |
| `FilePicker` | `(empty)` | `Empty folder` |
| `TraceWaterfall` | `(no spans)` | `No spans` |
| `FileTree` | `(no matches)` / `(empty tree)` | `No matches` / `Empty tree` |
| `SearchResults` | `(no results)` | `No results` |
| `Transcript` | `(empty transcript)` / `(empty)` in ASCII | `No messages yet` |
| `MessageThread` | `(empty thread)` | `No messages yet` |
| `DataTable`, `TreeTable` | `(empty)` | `No rows` |
| `KeyValueTable` | `(empty)` | `No fields` |
| `TreeNavigation` | `(empty)` | `Nothing here` |
| `ModelModeSelectors` | `(no models)` | `No models` |
| `DependencyGraph` | `(no nodes)` | `No nodes` |

`Transcript` no longer swaps its label for `(empty)` under ASCII — the label is
copy, and copy does not change with the glyph profile.

## Consumer edits

- A host asserting on any literal above: the parentheses are gone and the copy
  is sentence case. Hosts that set their own empty label are unaffected.

## Validation

```sh
rg -n '"\((empty|no )' crates/termrock/src/widgets/   # → 0
mise run check
```
