## Usage

The Code view above and this source excerpt use the exact paint setup registered for `label/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn label_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::widgets::FieldCaption;
    let _ = FieldCaption::<&str>::new("Display name", system)
        .for_id("name")
        .required()
        .help("Shown in the session list")
        .paint(area, frame.buffer_mut());
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
