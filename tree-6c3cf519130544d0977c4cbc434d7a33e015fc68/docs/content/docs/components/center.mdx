## Anatomy

`area` (outer) · `content` (after margins) · `child` (placed rect)

## Usage

```rust
use termrock::layout::{Center, CenterAxis, centered_rect};

let child = Center::new(40, 12).layout(area).child;

// dialog = safe 1-cell margin when room
let child = centered_rect(52, 9, area);

// recipes
let hero = Center::onboarding(48, 10).layout(area).child;
let fail = Center::failure(40, 8).layout(area).child;

// caps
let child = Center::new(100, 20)
    .max(48, 16)
    .min(12, 4)
    .layout(area)
    .child;
```

## Axes

| Axis | Behavior |
|------|----------|
| Both | Center X and Y; preferred size |
| Horizontal | Center X; height fills content |
| Vertical | Center Y; width fills content |

## Semantics

Center is **not** interactive and must not be a focus node. Register only the
**child** widgets, or:

```rust
layout.register_child_semantics(&mut scene, "empty", "No items");
```

## Safety

Child is always ⊆ outer. Empty / tiny terminals never underflow. Preferred size
is clamped by max, min (when room), margins, and available cells.

## Common mistakes

- Treating Center as a Panel (it does not paint borders)
- Registering Center on FocusGraph (register children only)
- Forgetting max-width on wide terminals
- Assuming underflow on tiny sizes (child is clamped inside)
