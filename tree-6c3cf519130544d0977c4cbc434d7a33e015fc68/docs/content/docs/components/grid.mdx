## Anatomy

`content` · `column_tracks[]` · `row_tracks[]` · `cells[]` · `column_sizes` · `row_sizes` · `overflowed`

## Usage

```rust
use termrock::layout::{
    Grid, TrackSize, GridAutoFlow, OverflowPolicy,
    form_grid_template, dashboard_grid_template, settings_grid_template,
    grid_neighbor_2d,
};

let layout = Grid::columns(3)
    .gaps(1, 1)
    .auto_row(TrackSize::Fixed(4))
    .layout_flow(area, 6, GridAutoFlow::Row);

let form = form_grid_template(area.width);
let dash = dashboard_grid_template(area.width, 3, 18, 1);
let settings = settings_grid_template(area.width, 18, 2);

// Studio
let _ = layout.debug_summary();
```

## Tracks

| Track | Behavior |
|-------|----------|
| `Fixed(n)` / `content(n)` | Exact cells (`content` = host-measured intrinsic) |
| `Weight` / `fr` | Share residual after fixed/minmax |
| `MinMax` | Preferred clamped to [min, max]; may grow to max |

## Overflow

| Policy | Behavior |
|--------|----------|
| `ShrinkFromEnd` (default) | From the end: `min(claim, remaining)` |
| `ClipTail` | Keep head tracks; tail → 0 |
| `EqualShare` | Peel cells from the end until fit |

`GridLayout::overflowed` is set when any fixed/minmax track falls below min.

## Navigation

Grid is **not** interactive by default. Hosts wire:

```rust
use termrock::layout::grid_neighbor_2d;
// Arrow Right → grid_neighbor_2d(items, focus, 1, 0)
```

## Hits & semantics

```rust
let hits = layout.hit_regions();
layout.register_semantic_group(&mut scene, "g", "grid", |i| format!("c{i}"));
```

## vs Stack / WorkSurface / VirtualGrid

| | Grid | Stack | WorkSurface | VirtualGrid |
|--|------|-------|-------------|-------------|
| Axes | 2D tracks | 1D | 1D named | virtual data |
| Spans | yes | no | no | cells |
| Use | forms, dashboards | anatomy | app chrome | large tables |

## Common mistakes

- Making every grid keyboard-focusable — only host-selected cells/controls
- Using VirtualGrid for static dashboard cards — prefer Grid + Card
- Ignoring `overflowed` on narrow terminals
- Nesting Grid for 1D packing — use Stack
