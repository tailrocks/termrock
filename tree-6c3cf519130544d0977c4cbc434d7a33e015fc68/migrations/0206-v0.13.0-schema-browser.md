# 0206 — SchemaBrowser hierarchical catalog navigator

## Mission

Hierarchical database/schema navigator: connections, databases, schemas, tables,
views, columns, indexes, constraints, routines; loading/error/lazy states;
search; status; context actions. Lazy expansion with application-owned metadata
fetching. Detail previews and QuickOpen integration. Expanded state preserved
across refresh and reconnect. Contracts side pane → drawer → fullscreen.

Research: TablePlus, DataGrip, pgcli ecosystems, file-tree navigation.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tree` / `TreeNode` / `TreeState` / `TreeNodeStatus` | **Preserved** — paint/nav substrate |
| `FileTree` | **Preserved** — filesystem domain; not SQL catalog |
| `QuickOpen` / `Breadcrumbs` | **Preserved** — bridges `schema_to_quick_open_items`, `schema_breadcrumbs_from_path` |
| `QueryEditor` / `ResultGrid` | **Preserved** — open/query outcomes hand off |
| Catalog/SQL drivers | **Never in TermRock** — outcomes only |
| `SchemaBrowser*` | **Added** |

## Consumer API sketch

use termrock::widgets::{
    SchemaBrowser, SchemaBrowserState, SchemaBrowserEntry, SchemaNodeKind,
    SchemaConnStatus, schema_to_quick_open_items, apply_expanded_set,
};

let entries = [
    SchemaBrowserEntry::connection("c", "prod", "prod").expanded(),
    SchemaBrowserEntry::database("db", "app", "prod/app", 1).parent("c").expanded(),
    SchemaBrowserEntry::schema("s", "public", "prod/app/public", 2).parent("db").expanded(),
    SchemaBrowserEntry::table("t", "users", "prod/app/public/users", 3).parent("s").lazy(),
    SchemaBrowserEntry::column("t.id", "id", "prod/app/public/users.id", 4)
        .parent("t").type_label("int8").key_badge("PK").nullable(false),
];
let mut state = SchemaBrowserState::with_selected(Some("t"));

### Keys

| Key | Action |
|-----|--------|
| j/k · arrows | Tree nav |
| Enter | Open / expand lazy |
| `/` | Filter |
| `r` / `R` | Refresh node / all |
| Ctrl+Shift+C | Reconnect |
| `y` | Copy qualified path |
| `p` | Preview |
| Ctrl+O | QuickOpen |
| `g` | Breadcrumbs path |
| `q` / `d` / `x` | Query / describe / context menu |
