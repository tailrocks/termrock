# 0100 — DesignSystem complete recipes and presets

## Mission

Complete terminal design system: semantic roles (already syntax/diff/chart),
component recipes, presets (Phosphor/Slate/Paper/ANSI/High-Contrast/Adaptive),
partial package merge, capability ladders, elevation + breakpoints.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DesignSystem`, `RolePalette`, `Role` | **Preserve & extend** |
| `Density`, `Motion`, `GlyphSet`, `SpacingScale`, `SelectionChrome` | **Preserve** |
| `PanelRecipe`, `ListRowRecipe`, `panel_recipe`, `list_row_recipe` | **Preserve** |
| `ColorCapability`, `quantize` | **Preserve** |
| `phosphor` / `slate` palettes | **Preserve**; add paper/ansi/high_contrast |
| New `ThemePackage`, `Elevation`, `BreakpointScale` | **Added** |
| New `button_recipe`, `input_recipe` | **Added** |
| `with_role` / `merge` on DesignSystem | **Added** |
| `no_color` / `ascii` / `adaptive` | **Added** |
| Theme picker builtins | **Extended** to 6 presets |
| Component-local RGB (production) | **Avoid**; recipes use roles only |

## Presets

| Id | Builder | Notes |
|----|---------|-------|
| phosphor / obsidian | `DesignSystem::phosphor()` | Default gutter selection |
| slate | `DesignSystem::slate()` | Cool gray |
| paper | `DesignSystem::paper()` | Light / fill selection |
| ansi | `DesignSystem::ansi()` | 16-color capability |
| high-contrast | `DesignSystem::high_contrast()` | A11y bold pairs |
| adaptive | `DesignSystem::adaptive()` | Env quantize; mono→ASCII |

## API

```rust
use termrock::style::{
    DesignSystem, ThemePackage, Elevation, ButtonRecipeVariant, ControlState, Role,
};

let system = DesignSystem::phosphor();
let paper = DesignSystem::paper();
let mono = DesignSystem::slate().no_color();

// Partial package
let branded = system.with_role(Role::Accent, /* Style */);
let merged = DesignSystem::phosphor().merge(package.palette());

// Recipes
let btn = system.button_recipe(ButtonRecipeVariant::Primary, ControlState::Focused);
let input = system.input_recipe(ControlState::Focused, false);
let elev = system.elevation(Elevation::Raised);

// Packages
for pack in ThemePackage::builtins() {
    let _ = pack.system;
}
```
