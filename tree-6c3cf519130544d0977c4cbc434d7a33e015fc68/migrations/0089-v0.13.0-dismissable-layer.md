# 0089 — DismissableLayer

## Mission

Reusable dismissal controller for transient surfaces (overlays, menus, toasts),
with nested capture/bubble, double-dismiss prevention, and pointer press/release
safety.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `LayerDismissPolicy` | **Preserve** + `DismissAction::{from,to}_layer` |
| `OverlayStack::handle_escape` / outside | **Behavior preserved**; powered by DismissableLayer |
| Immediate outside-click dismiss | **Still available** via `handle_outside_click` (synthetic press+up) |
| New pointer APIs | **Added** `handle_pointer_down` / `handle_pointer_up` |

## Added

| API | Module |
|-----|--------|
| `DismissableLayer` | `interaction` |
| `DismissPolicy` / `DismissAction` / `DismissReason` | `interaction` |
| `DismissDecision` / `DismissGuard` / `DismissEventId` | `interaction` |
| `PointerGesture` / `DismissPhase` | `interaction` |
| `evaluate_escape_stack` / `evaluate_outside_top` | `interaction` |
| `OverlayStack::{handle_pointer_down, handle_pointer_up, top_dismissable}` | `interaction` |

## Consumer edits

```rust
use termrock::interaction::{
    DismissableLayer, DismissPolicy, DismissGuard, DismissEventId, DismissDecision,
    OverlayStack,
};

// Standalone surface
let mut layer = DismissableLayer::new(DismissPolicy::dismissible());
layer.set_rect(menu_rect);
let mut guard = DismissGuard::new();
let e = DismissEventId(1);
match layer.on_escape(&mut guard, e) {
    DismissDecision::Dismiss { .. } => { /* close */ }
    DismissDecision::Consumed => { /* critical trap */ }
    DismissDecision::Bubble => { /* host handles Esc */ }
    DismissDecision::None => {}
}

// Overlay host — prefer press/release for drag-safe outside dismiss
stack.handle_pointer_down(pos);
// ... later ...
stack.handle_pointer_up(pos);
// or one-shot:
stack.handle_outside_click(pos);
```

## Laws

1. One dismiss per `DismissEventId`.
2. Outside = press outside + release outside.
3. Esc peels top dismissible layer only.
