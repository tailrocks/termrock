## Usage

The Code view above and this source excerpt use the exact paint setup registered for `center/both`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn center_both_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    use termrock::layout::Center;
    use termrock::widgets::{EmptyState, Panel};
    let child = Center::new(28, 6).layout(area).child;
    let _ = Panel::new(system)
        .title("centered")
        .paint(child, frame.buffer_mut(), None);
    let inner = Panel::new(system).title("centered").inner(child);
    Widget::render(
        &EmptyState::new("No selection", system).detail("Pick a story"),
        inner,
        frame.buffer_mut(),
    );
}
```

## Common mistakes

- Do not treat separate Lookbook stories as runtime states or a slide sequence.
- Do not duplicate hit testing, focus, or keyboard rules in the host.
- Do not infer an action from visual styling; handle the widget's typed outcome.
