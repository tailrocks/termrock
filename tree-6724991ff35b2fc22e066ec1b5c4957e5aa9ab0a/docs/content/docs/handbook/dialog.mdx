# Dialog

**Purpose.** Frame a short message or choice as a **modal layer**: title, body,
optional actions. TermRock places and paints; you decide open/close policy and
effects.

Use `ChoiceDialog` when actions need stable IDs and keyboard traversal.
`place_dialog` / OverlayStack integrate with Esc peel law.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use Dialog | Prefer |
|------------|--------|
| Confirm destructive action | — |
| Short system message | — |
| Multi-step forms | Form / FormWizard |
| Agent trust gates | [PermissionPrompt](/docs/handbook/permission-prompt) |
| Fuzzy command jump | [Command palette](/docs/handbook/command-palette) |

## Focus law

| Concern | Owner |
|---------|--------|
| Overlay trap / Esc peel | OverlayStack |
| Surface focus (which layer) | Host / InteractionScene |
| Action **cursor** among buttons | `ChoiceDialogState::cursor` (host may project scene focus into it) |
| Tab between action ids when registered | Host scene only — **not** ChoiceDialog |

## Outcomes (`interaction::Outcome`)

- `Ignored`
- `Changed` — action cursor moved
- `Activated(Id)`
- `Cancelled` — Esc

## Intents

`default_choice_dialog_intent` — Left/Right (j/k), Home/End, Enter, Esc.
**Tab is not mapped.**

## Non-color

- Cursor: ActionFocused role, or `›label‹` / `[label]` with `ascii` / `colorless`
- Danger variant: `!` title prefix + danger border
- Backdrop: terminal Reset (not hard black)

## Responsive

| Width | Layout |
|-------|--------|
| ≥ 28 | Horizontal action bar |
| &lt; 28 | Vertical stack of actions |
| height &lt; 3 | Title/border only |

## Basic example

```rust
use ratatui_core::{layout::Rect, text::Text};
use termrock::{
    style::DesignSystem,
    widgets::{Dialog, DialogSize, place_dialog},
};

let system = DesignSystem::default();
let dialog = Dialog::new("Notice", Text::from("Done."), &system);
let area = place_dialog(Rect::new(0, 0, 80, 24), DialogSize::default());
assert!(area.width > 0);
let _ = dialog;
```

## Interactive example

```rust
use ratatui_core::text::Text;
use termrock::{
    input::{KeyCode, KeyEvent, KeyModifiers},
    interaction::Outcome,
    style::DesignSystem,
    widgets::{Action, ChoiceDialog, ChoiceDialogState, Dialog},
};

let system = DesignSystem::default();
let actions = [
    Action { id: "ok", label: "OK", enabled: true, style: None },
    Action { id: "cancel", label: "Cancel", enabled: true, style: None },
];
let choice = ChoiceDialog::new(
    Dialog::new("Confirm", Text::from("Continue?"), &system),
    &actions,
);
let mut state = ChoiceDialogState::new(Some("cancel"));
let outcome = state.handle_key(&actions, KeyEvent::new(KeyCode::Enter, KeyModifiers::NONE));
assert!(matches!(outcome, Outcome::Activated("cancel")));
let _ = choice;
```

## State ownership

| TermRock | Consumer |
|----------|----------|
| Action cursor, hit regions, loading gate | Open policy, message copy, effects |
| Overlay place/open helpers | Scene registration of action ids (optional) |
