# 0214 — SlashCommandMenu

## Mission

Command completion surface optimized for prompt composers: command name, aliases,
description, arguments, shortcut, provider/plugin source, disabled reason, recent
commands, and nested argument completion. Integrate the global command system
while allowing composer-specific commands. Fuzzy ranges, async plugin commands,
loading / empty / error (via completion status) states. Preserve draft text and
replace only the intended token range. Compact and fullscreen modes.

Research: Grok Build, OpenCode, Claude Code, terminal shells, command palettes.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `CompletionMenu` / `CompletionCandidate` / `CompletionStatus` | **Preserved** — paint + async chrome |
| `CommandPalette` / `CommandEntry` | **Preserved** — global surface; bridge via `slash_commands_from_command_entries` |
| `PromptComposer` `CompletionKind::Slash` + `detect_completion` | **Preserved** — sibling detect; slash menu owns richer catalog |
| `fuzzy_match_label` | **Preserved** — reused for slash filter |
| Plugin / command execution I/O | **Never TermRock** — outcomes only |
| `SlashCommandMenu*` · `SlashCommand` · detect/apply helpers | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    SlashCommand, SlashCommandMenu, SlashCommandMenuState, SlashCommandMenuOutcome,
    SlashArgument, SlashCommandSource, detect_slash_query, apply_slash_insert,
    filter_slash_commands, example_slash_catalog, slash_commands_from_command_entries,
    CompletionStatus,
};

let mut catalog = example_slash_catalog();
// merge global palette entries
catalog.extend(slash_commands_from_command_entries(&global_entries));

let mut state = SlashCommandMenuState::new();
// after editor key
if state.sync_from_draft(&draft, cursor_byte) {
    // open overlay
}
let visible = state.visible_commands(&catalog);
match state.handle_key(key, &catalog, &visible) {
    SlashCommandMenuOutcome::CommandCommitted { insertion, needs_arguments, .. } => {
        draft = apply_slash_insert(&draft, state.query.as_ref().unwrap(), &insertion);
        // draft preserved outside range
    }
    SlashCommandMenuOutcome::Execute { id, args } => { /* host runs */ }
    SlashCommandMenuOutcome::Dismissed => { /* Esc — draft intact */ }
    _ => {}
}

// paint (caret-anchored)
SlashCommandMenu::new(&catalog, &system, bounds, anchor)
    .paint(area, buf, &mut state);

// async plugins
let gen = state.begin_async();
// … host fetch …
state.apply_async_commands(gen, &plugin_cmds);
```

### Draft law

`apply_slash_insert` only rewrites `trigger_byte..cursor_byte`. Surrounding
text and chips are untouched. `set_accepts_input(false)` does not clear query
until host closes or draft no longer matches `/`.
