# 0242 — Logs and ObservabilityDashboard composition block

## Mission

Complete **operational monitoring composition**: filters/query, time range,
LogStream, EventStream, MetricsDashboard, status summary, details inspector,
alerts, live/pause, reconnect chrome, dropped-data warning, bookmarks, and
drill-down. Responsive pane collapse and keyboard focus zones. **Data
acquisition stays application-owned** (no tailers, scrapers, or sockets).

Research: k9s, btop, Grafana concepts, terminal log tools (references only).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `LogStream` / `LogStreamState` / follow/pause/bookmarks/dropped | **Preserved** — composed |
| `EventStream` / backpressure / severity filter | **Preserved** — composed |
| `MetricsDashboard` / tiles / alerts / time range | **Preserved** — composed |
| `ObjectInspector` | **Preserved** — drill-down detail |
| `SearchInput` | **Preserved** — global query bar |
| `StatusBar` | **Preserved** — summary chrome |
| `layout_ops_dashboard` / `OpsDashboardSlots` | **Preserved** — thin AppShell geometry only; **not** dual interactive path |
| Local re-paint of streams/metrics | **Forbidden** |
| Log tailers / Prometheus / OTLP / sockets | **Host-owned** |
| `ObservabilityDashboardState` · `render_observability_dashboard` | **Added** (`patterns/observability_dashboard`) |

```rust
match state.handle_key(key, &logs, &events, &tiles, &alerts, &inspect) {
    ObservabilityDashboardOutcome::LiveToggled { live } => { /* host pause feed */ }
    ObservabilityDashboardOutcome::ReconnectRequested => { /* host reconnect */ }
    ObservabilityDashboardOutcome::AckDropped => { /* host clear gap counters */ }
    ObservabilityDashboardOutcome::BookmarkToggled { id, on } => { /* persist */ }
    ObservabilityDashboardOutcome::DrillDown { kind, id } => { /* fill inspector */ }
    ObservabilityDashboardOutcome::QueryChanged { query } => { /* reproject */ }
    ObservabilityDashboardOutcome::TimeRangeChanged(r) => { /* scrape window */ }
    _ => {}
}
```

### Laws

| Law | Detail |
|-----|--------|
| Public only | Composes public widgets; no stream/metrics paint forks |
| Host acquisition | Outcomes are requests only |
| Density=None | Last paint width drives collapse; Tab clamps to visible panes |
| Focus chrome | Search `set_focused`; child painters get `.focused(bool)` |
| Live/pause | Projects into LogStream/EventStream follow + Metrics pause |

## Second-pass design review

**Decisions**

1. Elevated pattern peer to Git/Database workbench — not a second ops_dashboard paint path.
2. Keep `layout_ops_dashboard` as thin geometry; interactive surface is ObservabilityDashboard.
3. Global SearchInput projects into log/event filters; metrics time range stays MetricsDashboard-owned.
4. Drill-down fills host-supplied inspector fields (workbench stores kind/id only).

**Rejected**

- Embedding log tailers or metric scrapers.
- Forking LogStream/EventStream paint bodies into the pattern.
- Replacing ops_dashboard without preserving layout helper.

**Residual limits**

- Metrics alerts stay inside MetricsDashboard chrome (no separate Alerts pane id).
- Inspector fields are host-projected (workbench does not auto-build from every selection type).
- PTY not required; unit + structural gates cover interaction.
