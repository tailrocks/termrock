# 0035 — Variable-height streaming transcript

## Removed surface

None required. `StreamView` remains for one-line stream projections. Prefer
`Transcript` for mixed-height agent sessions.

## Canonical addition

```rust
use termrock::widgets::{
    Transcript, TranscriptBlock, TranscriptKind, TranscriptOutcome, TranscriptState,
};

let lines = ["hello", "world"];
let blocks = [TranscriptBlock::new("m1", TranscriptKind::Assistant, &lines)];
let mut state = TranscriptState::new(); // follow=true
let view = Transcript::new(&blocks, &theme);
// state.handle_key(key, &blocks) / handle_mouse(mouse, &blocks)
```

Rules:

- Blocks carry stable IDs and revisions; height is `lines.len()` or 1 when folded.
- Viewport is display-row based across variable block heights.
- Follow mode sticks to the tail; manual upward scroll detaches.
- Visual anchor `(id, row)` survives append/resize when the block still exists.
- Outcomes are pure messages (`Activated`, `FoldToggled`, `FollowChanged`, …).

## Ownership

TermRock owns viewport, anchor, follow, and paint. Consumers own wrap/measure
lines, domain models, streaming transport, and fold application.
