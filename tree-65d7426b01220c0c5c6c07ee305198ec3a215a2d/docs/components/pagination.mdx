## Usage

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{PageTotal, Pagination, PaginationState};

let system = DesignSystem::default();
let mut state = PaginationState::new(1, 25, PageTotal::Known(1000));
state.set_focused(true);
// PageRequested { request } → host.fetch(request.offset(), request.limit())
let _ = Pagination::new(&system);
```

## Migrated handbook guidance

# Pagination

**Purpose.** Navigate pages of remote or expensive datasets. Host **fetches**;
TermRock emits [`PageRequest`] `{ page, page_size, offset() }`.


## Not scrolling

| | Pagination | Virtualization |
|--|------------|----------------|
| Data | Discrete remote pages | Local / stream window |
| UX | Page 3 of 12 | Continuous scroll |
| API | `LIMIT/OFFSET`, `?page=` | Paint slice only |

`pagination_guidance::WHEN_VIRTUALIZE` documents the choice.

## Totals

- `PageTotal::Known(n)` — full chrome, last page  
- `Unknown` — next allowed; no last  
- `AtLeast(n)` — summary `of n+`
