## Usage

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{MultiSelect, MultiSelectState, SelectOption};

let system = DesignSystem::default();
let options = [
  SelectOption::option("rs", "Rust"),
  SelectOption::option("go", "Go"),
];
let mut state = MultiSelectState::new().with_selected(["rs"]);
state.set_focused(true);
let _ = MultiSelect::new(&options, &system).label("Filters");
```

## Check vs highlight

| | Meaning |
|--|---------|
| `selected()` / `is_checked` | Ordered membership |
| `highlight()` | Keyboard cursor in open list |

Space toggles check; reverse video is highlight only.

## Keys (open)

- **Space** — toggle · **Enter** — done/close · **Esc** — close keep checks  
- **Ctrl+A** — select all visible · **Ctrl+D** — clear  
- **Shift+↑/↓** — range check · type — search
