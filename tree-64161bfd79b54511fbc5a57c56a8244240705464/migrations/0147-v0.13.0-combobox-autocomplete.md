# 0147 — Combobox & Autocomplete

## Mission

Editable input + suggestion collection: draft / active suggestion / committed
value kept separate; async suggestions with generation race gating; host
OverlayStack + CompletionMenu (no private popup geometry).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Stub `controls::Combobox` / `QueryChanged` / `Selected { index }` | **Deleted** |
| `CompletionMenu` / `CompletionCandidate` / `open_completion_overlay` | **Preserved** — used by Combobox |
| `TextInput` | **Preserved** — draft buffer |
| `ComboboxState` / `ComboboxOutcome` / `ComboMode` / `SuggestionStatus` | **Added** |
| `Autocomplete` / `AutocompleteState` | **Added** (aliases + autocomplete defaults) |

## Consumer edits

```diff
- let mut state = ComboboxState::new().free_text(true);
- state.set_focused(true);
- match state.handle_key(key, result_len) {
-     ComboboxOutcome::QueryChanged => {}
-     ComboboxOutcome::Selected { index } => {}
-     ComboboxOutcome::SubmitQuery => {}
-     _ => {}
- }
- Combobox::new("Pick…", &system).render(area, buf, &state);

+ let mut state: ComboboxState<&str> = ComboboxState::new()
+     .with_creatable(false)
+     .with_exact_required(true);
+ // or: ComboboxState::autocomplete() for free-text defaults
+ state.set_focused(true);
+
+ match state.handle_key(key, &candidates) {
+     ComboboxOutcome::DraftChanged { text, generation } => {
+         state.mark_loading();
+         host.fetch(text, generation); // async
+     }
+     ComboboxOutcome::MenuOpened { generation } => {
+         open_completion_overlay(...);
+         host.fetch(state.draft().into(), generation);
+     }
+     ComboboxOutcome::Committed { id, label } => { /* value */ }
+     ComboboxOutcome::Created { text } => { /* free text */ }
+     ComboboxOutcome::ValidationFailed { reason } => {}
+     ComboboxOutcome::MenuClosed | ComboboxOutcome::Dismissed | ComboboxOutcome::Blurred => {}
+     _ => {}
+ }
+
+ // when fetch returns:
+ if state.apply_suggestions(generation, &candidates) {
+     // applied; stale generations return false
+ }
+
+ Combobox::new(&system)
+     .label("Language")
+     .paint_with_menu(area, buf, &mut state, &candidates);
```

### Three values

| Value | API |
|-------|-----|
| Typed text | `draft()` |
| Active suggestion | `active_suggestion()` |
| Committed | `value()` / `value_label()` |

### Key semantics

| Key | Behavior |
|-----|----------|
| Type | Draft change + open menu + bump generation |
| ↓/↑ | Open / navigate menu |
| Enter | Commit highlight, else exact match, else create/validate |
| Tab | Commit highlight if menu open; else host Tab |
| Esc | Close menu first; then restore/clear draft → Dismissed |
| Blur | `blur()` closes menu, keeps draft |

### Race gate

`apply_suggestions(generation, …)` ignores `generation != suggestion_generation()`.
