# 0059 — OverlayStack helpers for drawer, popover, tooltip, jump

## Removed surface

None. Floating UI that invented private placement is **discouraged**; new helpers
make the stack path the only recommended API.

## Canonical replacement

| Concern | API |
|---------|-----|
| Unified stack | `OverlayStack`, `OverlaySpec`, `place_overlay`, `OverlayPolicy::for_kind` |
| Drawer | `OverlaySpec::drawer`, `open_drawer_overlay`, `place_drawer`, `dismiss_drawer_overlay` |
| Popover | `OverlaySpec::popover`, `open_popover_overlay`, `place_popover` |
| Tooltip | `OverlaySpec::tooltip`, `open_tooltip_overlay`, `place_tooltip` |
| Select menu | `OverlaySpec::select` |
| Fullscreen / jump | `OverlaySpec::fullscreen`, `open_jump_overlay`, `JumpOverlayState::open_on_stack` |
| Existing | Dialog, CompletionMenu, CommandPalette open/place helpers (unchanged) |

**Law:** Escape closes exactly one conceptual interaction layer (`handle_escape`).

## Consumer edits

```rust
// Drawer
open_drawer_overlay(&mut stack, bounds, "settings", size, Some(focus_id));

// Popover under trigger
open_popover_overlay(&mut stack, bounds, trigger_rect, OverlaySize::menu(24, 8), Some(focus_id));

// Tooltip (no input ownership)
open_tooltip_overlay(&mut stack, bounds, anchor, OverlaySize::menu(20, 1), None);

// Jump mode
jump_state.open_on_stack(&mut stack, bounds, Some(focus_id));
// Esc → stack.handle_escape() → restore focus; jump_state.close()
```

Prefer `OverlaySpec::*` constructors over hand-built structs so policy defaults stay correct.

## Ownership

Stack owns geometry, z-order, peel, reflow. Widgets own paint into `entry.rect` and
typed content outcomes. Focus restore ids are app/scene-owned.
