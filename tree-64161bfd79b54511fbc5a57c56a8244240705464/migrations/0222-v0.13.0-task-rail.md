# 0222 — TaskRail ActivityModel side panel

## Mission

Unified task and agent activity side panel: group workflows, subagents,
foreground/background tasks, watchers, and completed history. Collapse, filter,
search, selection, semantic zoom, status, elapsed, progress, dependencies, and
contextual actions. Prioritize needs-input. Collapse into Drawer or StatusBar
summary responsively. Application-neutral `ActivityModel`.

Research: Grok Build tasks pane, Amp sessions, OpenCode agents, CI lists, Zellij.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `TaskRail` List façade (`agent_blocks`) | **Deleted** — replaced by elevated `task_rail` module |
| `List` / `ListState` / `ListRow` | **Preserved** — internal paint substrate + `project_task_rail_list_rows` |
| `ActivityShelf` / `ActivityItem` | **Preserved** — glanceable strip; bridges via `to_shelf_item` / `activity_models_to_shelf` |
| `StatusBar` / Drawer / Panel | **Preserved** — status projection + drawer id for host |
| `SemanticStatus` / `ActivityKind` | **Preserved** |
| Agent workbench List task paint | **Preserved** — still host `List`; may adopt `project_task_rail_list_rows` |
| `progress_steps_as_list_rows` | **Preserved** — still projects to List |
| `ActivityModel` · `ActivityScope` · `TaskRail*` · filter/sort/rows | **Added** |

## Breaking: TaskRail constructor

```rust
// Before (ListRow façade)
TaskRail::new(&rows, &system, "Tasks")  // StatefulWidget + ListState
// After
use termrock::widgets::{ActivityModel, TaskRail, TaskRailState, example_activity_models};
let items = example_activity_models();
let mut st = TaskRailState::new();
TaskRail::new(&items, &system).title("Tasks").paint(area, buf, &mut st);
// or StatefulWidget::render(&TaskRail::new(...), area, buf, &mut st);
```

### Consumer API sketch

```rust
use termrock::widgets::{
    ActivityModel, ActivityScope, ActivityDependency, ActivityKind, SemanticStatus,
    TaskRail, TaskRailState, TaskRailOutcome, TaskRailPresentation, TaskRailZoom,
    sort_activity_models, filter_activity_models, project_task_rail_for_status_bar,
    task_rail_status_slot, activity_models_to_shelf, TASK_RAIL_DRAWER_OVERLAY_ID,
};

let mut items = vec![
    ActivityModel::new("p1", "allow: rm")
        .needs_input(true)
        .waiting_reason("permission")
        .scope(ActivityScope::Foreground),
    ActivityModel::new("b1", "cargo test")
        .scope(ActivityScope::Background)
        .kind(ActivityKind::Build)
        .progress(40)
        .depend(ActivityDependency::new("s1", "review")),
];

let mut st = TaskRailState::new(); // Completed collapsed by default
// st.filter = "cargo".into();
// if area.width < TASK_RAIL_DRAWER_WIDTH { open drawer overlay }

TaskRail::new(&items, &system).paint(area, buf, &mut st);

match st.handle_key(key, &items) {
    TaskRailOutcome::Activated { id } => { /* jump */ }
    TaskRailOutcome::CancelTask { id } => { /* host cancel */ }
    TaskRailOutcome::RetryTask { id } => { /* host retry */ }
    TaskRailOutcome::FocusTranscript { id } => { /* focus log */ }
    TaskRailOutcome::GroupToggled { scope, collapsed } => {}
    TaskRailOutcome::FilterChanged { query } => {}
    TaskRailOutcome::PreferDrawer => { /* host Drawer */ }
    _ => {}
}

// StatusBar when collapsed
let proj = project_task_rail_for_status_bar(&items, ascii);
let slot = task_rail_status_slot("tasks", &proj, false);

// ActivityShelf strip from same model
let shelf_items = activity_models_to_shelf(&items);
```

### Keys

| Key | Action |
|-----|--------|
| j/k ↑↓ | Navigate list |
| Enter / Space | Activate item or toggle group |
| Tab | Jump first needs-input |
| `/` | Filter mode |
| Esc / Enter | Leave filter mode |
| x | CancelTask |
| r | RetryTask |
| t | FocusTranscript |
| d | InspectDeps |
| f | Promote / PreferDrawer |
| z | Toggle zoom compact/detail |
| h / l | Collapse / expand group |
| Shift+H | Hide completed |
