# 0213 — FileMention and EntityMention

## Mission

Inline structured tokens for files, symbols, agents, tools, sessions, and
resources: display label, canonical id/path, type glyph, validity
(stale/missing/ambiguous), preview, and removal. Integrate completion, keyboard
navigation, copy, and semantic descriptions. Cursor movement treats mentions as
**atomic** across text/token boundaries. Support ambiguous names and
disambiguation. **No** provider-specific resource lookup.

Research: editor mentions, chat mentions, agent file-reference syntax.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `CompletionMenu` / `CompletionCandidate` | **Preserved** — menu chrome; mention projects candidates |
| `Tag` / `TokenPart` / `TokenStatus` | **Preserved** — inline mention paint |
| `PromptComposer` `CompletionKind::FileMention` / `SymbolMention` | **Preserved** — trigger detection sibling |
| `ComposerChip::mention` | **Preserved** — chip form; use `MentionRef::to_composer_label` |
| `detect_completion` (`@`/`#`) | **Preserved** — plain draft; mention adds family-aware detect |
| Filesystem / LSP / provider lookup | **Never TermRock** — host projects candidates + validity |
| `FileMention` · `EntityMention` · `MentionDraft` · `InlineMention` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    FileMention, EntityMention, MentionRef, MentionType, MentionValidity,
    MentionCandidate, MentionDisambiguator, MentionDraft, MentionCursor,
    InlineMention, InlineMentionState, FileMentionState, EntityMentionState,
    detect_file_mention_query, detect_entity_mention_query,
    filter_mention_candidates, apply_mention_insert, mention_to_completion_candidate,
    mention_semantic_description, CompletionMenu, CompletionMenuState,
};

// Domain
let file = FileMention::path("f1", "main.rs", "src/main.rs");
let missing = FileMention::missing("m", "gone.rs", "old/gone.rs");
let amb = FileMention::ambiguous("u", "util.rs", vec![
    MentionDisambiguator::new("a/util.rs", "util.rs").detail("a/"),
    MentionDisambiguator::new("b/util.rs", "util.rs").detail("b/"),
]);
let agent = EntityMention::agent("a1", "planner", "agent:planner");

// Atomic draft cursor
let mut draft = MentionDraft::from_text("see ");
draft.insert_mention(file.mention.clone());
draft.move_left(); // lands OnMention (atomic)
draft.delete_backward(); // removes whole token

// Completion (host ranks; TermRock paints menu)
let mut fm = FileMentionState::new();
fm.sync_from_draft(&text, cursor_byte);
if let Some(q) = &fm.query {
    let hits = filter_mention_candidates(&candidates, &q.query, Some(MentionFamily::File));
    // map to CompletionCandidate via mention_to_completion_candidate
    let next = apply_mention_insert(&text, q, &hits[0].insert_markup());
}

// Inline paint
let mut st = InlineMentionState::new();
InlineMention::file(&missing, &system).paint(area, buf, &mut st);
// Ctrl+C → CopyRequested { id }; Enter on ambiguous → DisambiguateRequested
```

### Markup

Neutral export form: `@[kind:id|label]` via `MentionRef::to_markup` /
`parse_mention_markup` / `parse_draft_with_mentions`.

### Keys (focused inline mention)

| Key | Action |
|-----|--------|
| ←/→ on Tag | Body ↔ Remove |
| Delete | Remove |
| Enter | Activate or open disambiguation |
| Ctrl+C | CopyRequested (id only) |
| Ctrl+P | PreviewRequested |
| Ctrl+D | DisambiguateRequested |
| j/k · Enter in disambiguation | Navigate · select |
