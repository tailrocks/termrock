# 0324 — The default frame goes on a diet

**Version:** `v0.14.0`
**Kind:** breaking (pattern layout signatures, one fixture type)

Plan 017 Part B wrote the information budget into law §4.2 and applied it to
six surfaces. Five rows were deferred because the plan that owned the missing
piece had not run yet. Those plans have since landed, so the reasons expired
and the rows are finished here.

## 1. One voice for what a surface cut

```rust
// Before — the same sentence, written five times, agreeing by luck
if hidden > 0 {
    paint(&format!("+{hidden} more"));
}

// After
if let Some(note) = termrock::text::more_note(hidden) {
    paint(&note);
}
```

`more_note` returns `None` when nothing was hidden, so a caller spends no row
on it. `design_gate.rs::one_overflow_note` fails the build on a local copy.

Plan 022 applied a *template* at four sites, not an authority — and the fifth
surface to clip went silent. `integration_status`'s Capabilities, Permissions
and Logs tabs dropped every row past their window and their pane height with
no cue at all. They now reserve the last row (`clip_bottom`) and say what they
held back.

## 2. `plan_review` states its size in the title

```rust
// Before: "Plan v3 · Refactor the parser · high", then repainted over the
// panel border in bold `Role::ActorPlan`.
// After:  "Refactor the parser(v3)[7]" through `Panel::title_spec`.
```

The over-paint said "plan" in the same hue as the accent rail beside it and
spent the row's bold budget on chrome. Risk did not disappear: it rides the
glyph on the summary row, which already carries the risk tone, and the full
list is one pane tab away. The document gutter (mark, line number, rule) drops
to `Role::TextFaint` through `TieredRow`, so prose is the brightest thing on
its row.

## 3. `MetricTile` thresholds wait for focus

A threshold line draws across every tile on a dashboard whether or not the
operator is looking at that one. It is the second question — asked after "what
is the number" — so focus is the keypress that asks it. `MetricTileView::focused(true)`
restores it.

## 4. The review step shows what changed

```rust
// Before
pub summary_lines: &'a [&'a str],          // "Theme: phosphor"

// After
pub summary_lines: &'a [SetupSummaryLine<'a>],
// SetupSummaryLine::edited("Endpoint", "https://api.example")
// SetupSummaryLine::untouched("Theme", "phosphor")
```

The pattern cannot know which values the operator touched, so the host says.
The default frame lists what changed and ends with `+N more · a all`; `a`
toggles the full config and returns `SetupWizardOutcome::SummaryDetailToggled`.

## 5. Two workbenches drop to three panes

```rust
// Before
database_workbench_layout_density(area, &ws, density)
observability_dashboard_layout_density(area, &ws, density)

// After
database_workbench_layout_density(area, &ws, density, state.panes())
observability_dashboard_layout_density(area, &ws, density, state.open_panes())
```

`DatabaseWorkbenchPanes` and `ObservabilityPanes` are `Default`-off. The
default frame is nav + main + status; the panes an operator *consults* rather
than works in arrive on a chord:

| Surface | Chord | Pane |
|---|---|---|
| `database_workbench` | `^b` | connection rail |
| `database_workbench` | `^i` | object inspector |
| `observability_dashboard` | `^l` | log stream |
| `observability_dashboard` | `^e` | event stream |
| `observability_dashboard` | `^i` | inspector |
| `observability_dashboard` | `^a` | alert list |

Each emits `PaneToggled { pane, open }`. `Tab` cycles only what the frame
shows, so focus never lands on a pane with no cells.

Two further findings fell out of measuring these frames for the first time:

- **`MetricsDashboard::hints(bool)`** — embedded in a shell that already has a
  status bar, it painted a second five-chord footer. The shell owns the frame's
  one hint row; standalone use is unchanged (`hints` defaults to `true`).
- **Alerts are opt-in.** Every tile states its own health in a letter; the
  alert list restated the same crossings in a second colour band, which is what
  pushed the frame to nine hues against a budget of eight. The status strip now
  states the count it used to compute and discard.

## Consumer edits

```rust
// Layout callers add the pane set (`::default()` gives the diet frame).
let panes = database_workbench_layout_density(area, &ws, density, DatabaseWorkbenchPanes::default());

// Setup hosts build typed review lines instead of "label: value" strings.
let summary = vec![SetupSummaryLine::edited("Endpoint", &endpoint)];

// Dashboards that want the old five-pane frame open them explicitly.
state.toggle_logs();
state.toggle_events();
state.toggle_inspector();
```
