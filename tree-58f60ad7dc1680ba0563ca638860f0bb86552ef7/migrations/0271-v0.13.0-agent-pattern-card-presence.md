# Agent pattern-card presence

`SubagentCard`, `TerminalRunCard`, and `WorkingStateCard` now share the agent
presence vocabulary: quiet running pulses, semantic completion/failure marks,
one-line collapsed summaries, and continuing actor rails on expanded detail.

Pass a deterministic host paint tick to active cards:

```rust
SubagentCard::new(&run, &system).tick(frame_tick);
TerminalRunCard::new(&run, &lines, &system).tick(frame_tick);
WorkingStateCard::new(&system).tick(frame_tick);
```

Remove consumer-owned activity pulses, status gutters, and expanded accent
rails. Reduced-motion systems render static presence across every tick.

Validate with `cargo test -p termrock subagent`, `terminal_run`, and
`working_state`, then `mise run gate`.
