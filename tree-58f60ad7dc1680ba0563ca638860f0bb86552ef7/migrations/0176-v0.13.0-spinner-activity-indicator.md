# 0176 — Spinner and ActivityIndicator

## Mission

Semantic activity indicators with deterministic cadence. Every indicator pairs a
glyph with a meaningful verb/label unless embedded in a labeled control. Phases:
indeterminate, waiting, queued, reconnecting. Capability-aware glyph sequences,
reduced-motion static fallback, and **no frame ticks** when inactive or not
visible.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Spinner::new` / `.ascii` / `frame_glyph` / `render(area,buf,tick,motion)` | **Preserved** |
| Braille + ASCII frame tables (80ms period) | **Preserved** (constants exported) |
| `Motion::animate_spinners` / `spinner_step` / `spinner_demand` | **Preserved** |
| `LoadingView::new(label, frame, system)` | **Preserved** (host supplies frame) |
| Progress indeterminate | **Unchanged** |
| Spinner home `primitives.rs` | **Migrated** → `widgets/spinner.rs` |
| `SpinnerState`, phases, variants, ActivityIndicator | **Added** |
| Label law + idle redraw gates | **Added** |

## Consumer edits

```diff
  use termrock::widgets::Spinner;
+ use termrock::widgets::{
+     Spinner, SpinnerState, ActivityPhase, ActivityIndicator, SpinnerVariant,
+ };
  use termrock::runtime::FrameTick;
  use termrock::style::Motion;

- let s = Spinner::new(&system);
- s.render(area, buf, tick, motion);
+ let mut state = SpinnerState::new();
+ // Stop ticks when work ends or panel hides:
+ state.set_active(working);
+ state.set_visible(panel_on_screen);
+ if state.should_tick() {
+     let demand = state.animation_demand(tick, motion); // host wake
+ }
+ Spinner::labeled("Fetching packages", &system)
+     .phase(ActivityPhase::Indeterminate)
+     .paint(area, buf, &state, tick, motion);
+
+ // Compact only when control already labeled:
+ state.set_embedded_in_labeled_control(true);
+ Spinner::new(&system).embedded(true).variant(SpinnerVariant::CompactInline)
+     .paint(icon_slot, buf, &state, tick, motion);
+
+ ActivityIndicator::new("Reconnecting", &system)
+     .detail("attempt 2/5")
+     .paint(area, buf, &state, tick, motion);
```

### Phases

| Phase | Motion Full | Static (Off) |
|-------|-------------|--------------|
| Indeterminate | braille / `\|/-\` | `●` / `o` |
| Waiting | slow pulse | `·` / `.` |
| Queued | static | `○` / `o` |
| Reconnecting | reverse braille | `◌` / `?` |

### Stories

- `spinner/labeled`, `phases`, `compact`, `ascii`
- `activity-indicator/basic`
- `motion/presence-spinner` (preserved)
