# 0281 — Craft helpers: one label painter, one path contraction, one inset token

The craft pass (plans/022) gives TermRock one sanctioned way to paint a label,
contract a path, reserve chrome insets, size a rhythm band, and paint a list
scrollbar. Widgets that used to hand-roll each of these now call shared
helpers, so the geometry and truncation sweeps in later steps are call-site
swaps instead of new per-widget logic.

## Moved surface

`CellAlignment` and `CellOverflow` are defined in `termrock::text`, not in
`termrock::widgets::table`. Both remain re-exported from `termrock::widgets`,
so `use termrock::widgets::CellAlignment;` keeps working; `use
termrock::widgets::table::CellAlignment;` (module path) does not.

```rust
// Before
use termrock::widgets::CellAlignment;
// After — either path resolves; prefer the canonical one
use termrock::text::CellAlignment;
```

## New surface

```rust
use ratatui_core::{buffer::Buffer, layout::Rect, style::Style, text::Line};
use termrock::{
    scroll::paint_list_scrollbar,
    style::{ContentInset, DesignSystem, KvSeparator, SpacerBand},
    text::{CellAlignment, LinePlacement, paint_line_overflow, paint_text, truncate_path},
};

fn paint(buffer: &mut Buffer, area: Rect, line: &Line<'_>, system: &DesignSystem) {
    let ellipsis = system.glyphs.ellipsis();
    let inset: ContentInset = system.content_inset(true);
    let inner = inset.apply(area);

    // Plain labels: grapheme-safe, never a silent hard cut.
    paint_text(buffer, inner, "session title", Style::default(), ellipsis);

    // Styled lines: per-span styles survive alignment and contraction.
    let mut scratch = String::new();
    paint_line_overflow(
        buffer,
        inner,
        line,
        Style::default(),
        LinePlacement::contracting(ellipsis).align(CellAlignment::Right),
        &mut scratch,
    );

    // Paths keep the discriminating tail.
    let shown = truncate_path("src/widgets/quick_open.rs", 20, ellipsis);
    assert_eq!(shown, "…/quick_open.rs");

    // Rhythm bands are dropped before content rows are.
    let band: SpacerBand = system.spacing.band();
    let rows = band.resolve(inner.height, 6);
    let _ = (rows, system.kv_separator() == KvSeparator::Gutter);

    // One scroll language, painted into a reserved gutter.
    paint_list_scrollbar(buffer, inner, 120, usize::from(inner.height), 0, system);
}
```

## Ownership changes

| Concern | Before | Now |
|---|---|---|
| Label truncation | `take_display_cols` / `chars().take` per widget | `text::paint_text` |
| Styled-line clipping | `table::render_line_overflow` (private) | `text::paint_line_overflow` |
| Path truncation | end-cut per widget | `text::truncate_path` |
| Chrome inset | per-widget literals, collapsing when narrow | `DesignSystem::content_inset` |
| Section rhythm | four private spacer flags | `SpacingScale::band` + `SpacerBand::resolve` |
| Key/value separator | `"  "` / `" : "` / `GUTTER` per widget | `DesignSystem::kv_separator` |
| List scroll indication | duplicated thumb math | `scroll::paint_list_scrollbar` |

## Behavior changes

- **Right-aligned cells contract from the head.** A right-aligned `1234 5678`
  in five columns now renders `…5678` instead of `1234…`: alignment pulled the
  meaningful tail to the edge, so the head is what gets surrendered.
- **ASCII ellipsis is no longer clipped to one cell.** Under
  `GlyphSet::Ascii`, contraction painted a bare `.`; it now paints the full
  `...` and reserves its three columns.
- **Bordered chrome reserves at least one column** through
  `content_inset(true)` at every density, including `Density::Dashboard`,
  where padding used to resolve to zero. Only call sites migrated to
  `content_inset` change; the geometry sweep across the bordered-overlay
  family lands in the next step of plans/022.

## Consumer edits

- Constructing `DesignSystem` with a struct literal: add
  `kv_separator: KvSeparator::default()`. Builder and `DesignSystem::new`
  paths need no change.
- Matching on `termrock::widgets::table` module paths for `CellAlignment` /
  `CellOverflow`: switch to `termrock::text` or the `termrock::widgets`
  re-export.
- Pinning right-aligned truncated output in a snapshot: re-bless; the
  ellipsis moved to the leading edge.
