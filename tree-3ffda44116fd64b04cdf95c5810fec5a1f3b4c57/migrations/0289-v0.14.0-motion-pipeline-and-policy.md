# 0289 — Motion: demand-driven pipeline, policy tiers, layer-1 animation

"The fluidity is 80% render-pipeline discipline + 20% tasteful effects. Effects
on a flickering pipeline read as jank, not polish" —
`docs/design/tui-motion-system.md` §1. This boundary lands the discipline half
and the vocabulary that the effects half will use.

## 1. `runtime::run` is demand-driven (behavioral, breaking)

The loop used to call `terminal.draw` once per iteration: a screen with nothing
happening still painted at the poll cadence. It now paints only when a frame is
owed — input arrived, a model deadline came due, or a 16 ms scroll flush is
pending.

**What this changes for a host:** state that mutates outside of events no longer
appears on screen by luck of the next poll. Report it through `next_deadline`,
which is the existing contract for timed state:

```rust
termrock::runtime::run(
    &mut model,
    RunOptions::default(),
    render,
    update,
    // Was easy to leave as `|_| None` while the fixed cadence hid the gap.
    |model| model.earliest_deadline(),
)?;
```

`RunOptions` gains `synchronized_output: bool` (default `true`), which wraps
every frame in DEC mode 2026 Begin/EndSynchronizedUpdate. Terminals without the
mode ignore the sequence — that *is* the documented silent degrade — so leave it
on unless you are debugging a terminal that mishandles it.

New in `runtime`:

| Item | Purpose |
|------|---------|
| `Presenter` | dirty coalescing, in-flight backpressure, min draw interval, cursor de-dup, `next_wake` |
| `FrameRate` / `TickLadder` | `Idle → Ambient(12) → Active(30) → Ceiling(60)`, recomputed per frame |
| `ScrollClock` / `SCROLL_FLUSH_INTERVAL` | 16 ms scroll cadence, deliberately not riding the animation rung |
| `QuietBackend` | drops empty-diff draws and redundant cursor commands |

Hosts running their own loop should wrap their backend once:

```rust
let backend = QuietBackend::new(CrosstermBackend::new(writer));
let mut terminal = Terminal::new(backend)?;
```

Without it an unchanged frame still emits ~19 bytes of style-reset epilogue plus
a full cursor sequence, which restarts the hardware blink every frame.

## 2. `Motion` is now `MotionPolicy`, `Reduced` is now `Basic`

The names come from the SoT §3 tier table. One enum survives; the type also
moved from `style::density` to `style::motion`.

| Before | After |
|--------|-------|
| `style::Motion` | `style::MotionPolicy` |
| `Motion::Full` | `MotionPolicy::Full` |
| `Motion::Reduced` | `MotionPolicy::Basic` |
| `Motion::Off` | `MotionPolicy::Off` |

`use termrock::style::MotionPolicy;` and a variant rename is the whole edit;
`DesignSystem::motion(..)` is unchanged apart from its parameter type.

New on the type:

- `MotionPolicy::from_env()` — reads `TERMROCK_ANIMATIONS=full|basic|none`, then
  honors `REDUCE_MOTION`. Call it at startup and hand the result to
  `DesignSystem::motion(..)`; nothing reads the environment during paint.
- `allows_transitions()` / `allows_ambient()` — ask the right question.
  `animate_spinners()` used to answer *both*, so gating a fade on it made
  `Basic` snap instead of fading.
- `clamp_duration(Duration)` — `Full` passes through, `Basic` caps at
  `BASIC_TRANSITION_CAP` (120 ms), `Off` collapses to zero.

**Check your call sites:** anything that wrote
`if motion.animate_spinners() { fade() }` should now ask
`allows_transitions()`. The behavior changes for `Basic`, which is the point.

## 3. `MotionChannel` — declare what a motion means

```rust
use termrock::style::MotionChannel;

let channel = MotionChannel::Work;      // spinner frames
channel.period_ms();                    // 80
channel.frame_rate();                   // FrameRate::Active
channel.phase(tick.elapsed_ms());       // wall-clock 0.0..1.0 for ambient loops
channel.frame(tick.elapsed_ms(), 10);   // frame index for frame sets
```

| Channel | Period | Rung | Meaning |
|---------|--------|------|---------|
| `Work` | 80 ms | Active | bounded work in progress |
| `Wait` | 240 ms | Active-adjacent (Ambient) | waiting on something external |
| `Stream` | 120 ms | Active | content arriving |
| `Live` | 2 s | Ambient | alive and idle — presence, not progress |
| `Static` | — | **Idle** | done / failed / offline; never animates |

`Static → Idle` is deliberate: a terminal state must not cost a frame.

Ambient loops phase on wall clock and transitions count ticks (§4 glue rule).
`MotionChannel::phase` is the wall-clock side; mixing the two is the bug the
rule exists to prevent.

## 4. Shimmer replaces whole-block pulsing

`style::shimmer_at` / `shimmer_cells` produce a raised-cosine band travelling
across a row, capped at `AMBIENT_PEAK` (0.33). Static at the bright end under
`Basic`, dark under `Off`.

A skeleton that pulses as one block reads as a spinner, which the skeleton
contract forbids (§6). Sweep instead.

## 5. Layer-1 value animation

`style::Easing` (ten curves) plus `runtime::{Tween, Spring, Animator, AnimId}`.

```rust
use termrock::runtime::{AnimId, Animation, Animator, Spring, Tween};
use termrock::style::Easing;

let mut animator = Animator::new();
animator.insert(AnimId(1), Animation::Tween(Tween::to(0.0, 1.0, (180, Easing::CubicOut))));
animator.retarget_spring(AnimId(2), progress);   // safe to call every update
for (id, value) in animator.tick(tick.delta()) { /* paint */ }
presenter.request_rate(animator.frame_rate());   // Idle once everything settles
```

`Elastic`, `Bounce`, and strong `Back` curves do not exist and will not be
added: on a cell grid an overshoot quantizes to a row popping past its target
and back (§5, §7 anti-pattern 6).

Use a `Spring` for anything whose target moves mid-flight (streaming progress, a
climbing counter) — a `Tween::retarget` restarts the rate and pops.

`style::scroll_ease_duration(rows)` gives the §5 distance-scaled scroll duration
(80 ms floor, 200 ms cap).

## 6. `Presence` can finally exit

Every constructor zeroed `exit_duration`, so `PresencePhase::Exiting` was
unreachable and transient surfaces could only vanish.

```rust
let toast = Presence::toast(Duration::from_secs(4))
    .with_exit(Duration::from_millis(120));
// while painting:
let alpha = toast.exit_alpha(tick);        // 1.0 unless leaving
let progress = toast.phase_fraction(tick); // progress through the timed phase
```

`request_hide` now consults `allows_transitions()`, so `Basic` still fades and
only `Off` hides instantly.

## Ownership and rollback

The kernel owns the clock, the ladder, and the wire; widgets declare a channel
and take a tick. Hosts still own effects and domain state. Rollback is
source-only.
