# 0087 — OverlayStack premium (queue, pointer route, picker)

## Mission

Complete OverlayStack as the sole floating-UI authority: modal request queue,
transitive nested dismiss, pointer routing, placement diagnostics, picker
overlay helpers, demote fullscreen.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Existing `OverlayStack::open` / Esc / reflow | **Preserve** (Stack mode default) |
| Direct-child-only nested dismiss | **Fix** → transitive descendants |
| Stack-as-queue for dialogs | **Split** → explicit `OpenMode::Queue` |
| Picker without stack helper | **Migrate** → `open_picker_overlay` |

## Added

| API | Role |
|-----|------|
| `OpenMode::{Stack,Queue,Replace}` | Open scheduling |
| `OverlayOutcome::Queued` | Deferred modal |
| `PointerRoute` / `route_pointer` | Host pointer routing |
| `PlacementResult` / `place_overlay_detailed` | Flip/clamp/promote diagnostics |
| `kind_blocks_queue` | Queue policy table |
| `enqueue` / `drain_queue` / `drain_queue_all` | Modal FIFO |
| `demote_top_fullscreen` | Undo narrow/fullscreen promote |
| `handle_pointer` | Unified outside-click entry |
| `open_picker_overlay` / `place_picker` / `PICKER_OVERLAY_ID` | Picker/Select migration |

## Consumer edits

```rust
use termrock::interaction::{
    OpenMode, OverlayOutcome, OverlaySpec, OverlayStack, OverlaySize, PointerRoute,
};
use termrock::widgets::{open_picker_overlay, open_dialog_overlay, PickerSize};

let mut stack = OverlayStack::<&'static str>::new();
let bounds = terminal_area;

// Immediate open (unchanged)
open_dialog_overlay(&mut stack, bounds, preferred, Some("btn"));

// True modal queue (second dialog waits)
let _ = stack.open_with(
    bounds,
    OverlaySpec::dialog("next", OverlaySize::dialog(40, 10), Some("a")),
    OpenMode::Queue,
);
// On Esc of top: queue drains automatically

// Picker as Select overlay
open_picker_overlay(&mut stack, bounds, anchor, PickerSize::default(), Some("field"));

// Esc law
match stack.handle_escape() {
    OverlayOutcome::Dismissed { focus, .. } => { /* restore focus */ }
    OverlayOutcome::Ignored => { /* trap */ }
    OverlayOutcome::UnhandledEscape => { /* scene / quit */ }
    _ => {}
}

// Pointer
match stack.route_pointer(pos) {
    PointerRoute::OutsideTop { .. } => { let _ = stack.handle_outside_click(pos); }
    PointerRoute::Top { .. } => { /* widget hits */ }
    _ => {}
}
```

## Laws

1. Escape closes exactly one conceptual layer.
2. Nested dismiss is transitive.
3. Queue only when both top and request are blocking kinds.
4. Placement remains deterministic under reflow.
