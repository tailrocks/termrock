# 0221 — ActivityShelf concurrent activity strip

## Mission

Compact persistent summary of currently active or blocked operations: multiple
concurrent tasks with status, elapsed time, actor, progress, waiting reason, and
jump/open actions. Prioritize blocked and user-action-required items. Contract
to one-line summary or badge in narrow layouts. Do **not** duplicate full
TaskRail. Integrate with StatusBar and notifications via projection helpers.

Research: agent activity indicators, build queues, IDE background task surfaces.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TaskRail` (List façade) | **Preserved** — vertical task/subagent list; distinct from shelf |
| `List` / `ListState` / `ListRow` | **Preserved** — TaskRail substrate; not used by ActivityShelf |
| `StatusBar` / `StatusSlot` / `StatusKind` | **Preserved** — `project_activities_for_status_bar` + `activity_status_slot` |
| `NotificationCenter` / `NotificationItem` / Toast kinds | **Preserved** — `activity_to_notification` / `activities_to_notifications` |
| `SemanticStatus` / `StatusIndicator` | **Preserved** — status glyphs/roles |
| `Spinner` / `ActivityIndicator` | **Preserved** — glyph animation; shelf uses static SemanticStatus frames |
| Process cancel | **Never** — dismiss is UI-only unless host maps |
| `ActivityItem` · `ActivityShelf*` · sort/plan/summary helpers | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    ActivityItem, ActivityKind, ActivityShelf, ActivityShelfState, ActivityShelfOutcome,
    ActivityShelfPresentation, SemanticStatus, example_activities,
    sort_activity_items, project_activities_for_status_bar, activity_status_slot,
    activities_to_notifications, StatusBar, StatusBarState,
};

let items = example_activities();
// action-required / blocked sort first
let _ = sort_activity_items(&items);

let mut st = ActivityShelfState::new();
// Auto: chips → icons → summary → badge by width
// st.force_presentation = Some(ActivityShelfPresentation::Summary);

ActivityShelf::new(&items, &system).paint(area, buf, &mut st);

match st.handle_key(key, &items) {
    ActivityShelfOutcome::Activated { id } => { /* jump to tool/thread */ }
    ActivityShelfOutcome::Dismissed { id } => { /* UI dismiss; optional host cancel */ }
    ActivityShelfOutcome::OverflowOpen => { /* host menu of overflow ids */ }
    _ => {}
}

// StatusBar integration
let proj = project_activities_for_status_bar(&items, ascii);
let slot = activity_status_slot("activities", &proj, width < 24);
// StatusBar::new(&[slot], &[], &system) …

// Notifications for blocked / action / failed
let notes = activities_to_notifications(&items, now_secs);
```

### Keys

| Key | Action |
|-----|--------|
| ←/→ or h/l | Select (horizontal) |
| ↑/↓ or k/j | Select (vertical) |
| Enter / Space | Activate / jump |
| x / Delete | Dismiss (if dismissible) |
| o | Toggle overflow |
| Esc | Close overflow |
