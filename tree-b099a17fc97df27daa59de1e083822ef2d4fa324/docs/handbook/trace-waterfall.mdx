# TraceWaterfall

Nested span visualization with duration bars on a shared time axis. Host
projects flattened visible hierarchy; TermRock paints name column + waterfall
bars, zoom/pan chrome, and emits selection/expand/detail **requests**.

## When to use / when not

| Use TraceWaterfall | Prefer |
|--------------------|--------|
| Distributed trace / agent tool spans | — |
| Chronological event list | [Timeline](/docs/handbook/timeline) |
| Process latency only | [ProcessTable](/docs/handbook/process-table) / Metrics |

## Ownership

| Concern | Owner |
|---------|--------|
| Trace fetch, span tree expansion data | Host |
| Zoom/pan window, selection, filter | `TraceWaterfallState` |
| Detail side panel | Host via `DetailsRequested` + ObjectInspector |

## Hierarchy vs timeline nav

| Mode | h/l | j/k |
|------|-----|-----|
| **Hierarchy** (default) | Collapse/expand or parent | Select spans |
| **Timeline** (`Ctrl+\`) | Pan time window | Select spans |

Vertical scroll and time pan are independent (Shift+wheel pans time).

## Compose

```rust
// ObjectInspector fields
span_to_inspector_fields(span)

// Timeline export (host formats when/duration labels)
span_to_timeline_event(span, &when_buf, &dur_buf)
```

## Keys

| Key | Action |
|-----|--------|
| j/k · h/l | Nav (mode-dependent) |
| Ctrl+= − 0 · [ ] | Zoom / fit / pan |
| / · Ctrl+P | Filter · critical path |
| Enter · i | Expand / details |
