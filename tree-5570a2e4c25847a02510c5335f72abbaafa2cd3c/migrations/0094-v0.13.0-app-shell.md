# 0094 — AppShell (canonical application composition)

## Mission

Canonical top-level composition for full-screen and inline TermRock apps:
header, sidebar, main, inspector, footer/status, optional command strip,
overlay bounds, focus zones, responsive collapse, lifecycle chrome.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `WorkSurface`, `RegionSpec`, `RegionId` | **Preserve** — AppShell uses them as geometry engine |
| `ResponsiveSurface::AppShell`, `AdaptiveAnatomy` | **Preserve** — collapse authority |
| `layout_app_shell`, `AppShellConfig`, `AppShellSlots`, `AppShellRecipe`, `AppShellZone`, `AppShellLifecycle` | **Added** (canonical) |
| `layout_agent_shell` / `AgentShellSlots` | **Migrated** — thin Workbench wrapper (rail=sidebar, prompt=command, status=footer) |
| `layout_ops_dashboard` / `OpsDashboardSlots` | **Migrated** — thin Dashboard recipe wrapper |
| `layout_studio_shell` / `StudioShellSlots` | **Migrated** — Workbench + bottom inspector sub-split of main; knobs=inspector rail |
| `layout_resource_browser` | **Migrated** — Workbench (rail=sidebar, preview=inspector) |
| `agent_workbench` / `render_agent_workbench` | **Preserve** — product block still owns domain paint; may adopt AppShell geometry later |
| Ad-hoc multi-region hosts without AppShell | **Migrate** consumers to `layout_app_shell` |

## Recipes

| Recipe | Topology |
|--------|----------|
| `Workbench` | header · sidebar · main · inspector · command? · footer |
| `Dashboard` | header? · metrics · main · log · footer |
| `MasterDetail` | header? · sidebar · main · footer |
| `Minimal` | main · footer? |

## Consumer edits

```rust
use termrock::patterns::{
    layout_app_shell, AppShellConfig, AppShellLifecycle, AppShellRecipe, AppShellZone,
};

// Prefer recipes:
let slots = layout_app_shell(area, AppShellConfig::workbench());
// or
let slots = layout_app_shell(area, AppShellConfig::dashboard());
let slots = layout_app_shell(area, AppShellConfig::master_detail());
let slots = layout_app_shell(area, AppShellConfig::minimal());

// Lifecycle (host maps product state):
let mut cfg = AppShellConfig::workbench();
cfg.lifecycle = AppShellLifecycle::Offline;
let slots = layout_app_shell(area, cfg);

// Paint by zone; route focus via slots.focus_order / zone ids.
if let Some(sidebar) = slots.zone(AppShellZone::Sidebar) {
    // paint nav into sidebar
}
// OverlayStack host bounds:
// overlays.set_bounds(slots.overlay_bounds);
// Drawer rails: host opens OverlayStack for slots.drawer_zones
```

Specialized wrappers still work (same field shapes):

```rust
use termrock::patterns::{layout_agent_shell, AgentShellLayout};
let a = layout_agent_shell(area, AgentShellLayout::default());
// a.rail / a.stream / a.prompt / a.status
```

## Removed concepts

None deleted from public API. AppShell is additive; specialized shells reimplemented on top.
