# 0156 — Pagination

## Mission

Page navigation for remote datasets and bounded result sets. **Not** scroll
virtualization. Host owns fetching; TermRock emits typed [`PageRequest`].

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Prior Pagination widget | **None** (greenfield) |
| `Virtualizer` / list scroll windows | **Preserved** — different problem |
| DataTable / DataView host paging | **Compose** with Pagination chrome |
| `PageRequest` / `PageTotal` / `Pagination*` | **Added** |

## When virtualization is better

Prefer **Virtualizer** / virtual lists when data is local or continuously
windowed. Prefer **Pagination** when each page is a distinct remote fetch.

Constant: `termrock::widgets::pagination_guidance::WHEN_VIRTUALIZE`.

## Consumer edits

```diff
+ use termrock::widgets::{
+     PageRequest, PageTotal, Pagination, PaginationOutcome, PaginationState,
+ };

+ let mut state = PaginationState::new(1, 25, PageTotal::Known(1000));
+ state.set_focused(true);
+ match state.handle_key(key) {
+     PaginationOutcome::PageRequested { request } => {
+         state.set_loading(true);
+         host.fetch(request.offset(), request.limit());
+     }
+     PaginationOutcome::PageSizeChanged { request, .. } => host.fetch(0, request.limit()),
+     _ => {}
+ }
+ // on response:
+ state.set_loading(false);
+ state.set_total(PageTotal::Known(total));
+ // or Unknown / AtLeast(n)

+ Pagination::new(&system).ascii(false).paint(area, buf, &mut state);
```

### Keys

| Key | Behavior |
|-----|----------|
| `[` / `]` or p/n | Prev / next |
| Home / End | First / last |
| `g` or digit | Jump entry |
| `s` | Cycle page size |
| Tab | Cycle internal parts |

### Stories

- `pagination/full`, `unknown`, `loading`, `minimal`, `jump`
