# 0220 — TerminalRunCard shell command card

## Mission

Specialize ToolCallCard for shell/terminal commands and live output: exact
command, cwd, environment/redaction summary, provenance, status, elapsed time,
stdout/stderr, exit code/signal, and actions. Support stop, detach, retry, copy,
open fullscreen, and permission boundary. Preserve user scroll while output
streams. Clearly distinguish **proposed** vs **executed** command and **edited
approval**. Safe ANSI parsing via AnsiText/TerminalOutput substrate.

Research: agent CLIs, CI command cards, terminal output panes.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TerminalOutput` + recipes/state/outcomes | **Preserved** — full command pane; card composes it for stream body |
| `TerminalCommandMeta` · `TerminalLine` · `TerminalStream` · `TerminalEnvEntry` | **Preserved** — shared projection substrate |
| `TerminalRunStatus` | **Elevated** — add `WaitingPermission`; `can_cancel` includes permission/detached; `needs_permission()` |
| `filter_terminal_lines` · `escape_raw_terminal` · `redact_env_value` · `format_duration_ms` | **Preserved** |
| `ToolCallCard` / `ToolCall` | **Preserved** — `terminal_run_to_tool_call` bridge |
| `AnsiText` / `AnsiLine` | **Preserved** — safe ANSI paint path |
| Process/PTY spawn/kill | **Never TermRock** |
| `TerminalRun` · `TerminalRunCard*` · `TerminalCommandPhase` · `TerminalRunEnv` · project helpers | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    TerminalRun, TerminalRunCard, TerminalRunCardState, TerminalRunCardOutcome,
    TerminalRunPresentation, TerminalRunStatus, TerminalRunEnv, TerminalLine,
    example_terminal_runs, example_terminal_run_lines, terminal_run_to_tool_call,
    project_terminal_run_lines, TERMINAL_RUN_FULLSCREEN_OVERLAY_ID,
};

let run = TerminalRun::new("r1", "echo hello")
    .approval_edited(true)
    .execute("echo hello-world") // edited approval → phase EditedApproval
    .status(TerminalRunStatus::Succeeded)
    .exit_code(0)
    .cwd("/proj")
    .env(vec![TerminalRunEnv::secret("TOKEN")])
    .actor("agent");

let lines = [
    TerminalLine::stdout("1", "hello-world"),
];
let mut st = TerminalRunCardState::new();
st.presentation = TerminalRunPresentation::Expanded;
st.on_append(lines.len() as u16, 8); // host after stream append

// TerminalRunCard::new(&run, &lines, &system).paint(area, buf, &mut st);

match st.handle_key(key, &run, &lines) {
    TerminalRunCardOutcome::StopRequested { id } => { /* host kill */ }
    TerminalRunCardOutcome::DetachRequested { id } => { /* host detach */ }
    TerminalRunCardOutcome::RetryRequested { id } => { /* host re-run */ }
    TerminalRunCardOutcome::PermissionFocus { id } => { /* PermissionPrompt */ }
    TerminalRunCardOutcome::FullscreenRequested { id } => {
        // overlay TERMINAL_RUN_FULLSCREEN_OVERLAY_ID
    }
    TerminalRunCardOutcome::ScrollDetached { .. } => { /* user reading; keep scroll */ }
    TerminalRunCardOutcome::CopyCommand { text, .. }
    | TerminalRunCardOutcome::CopyOutput { text, .. } => { /* clipboard */ }
    _ => {}
}

// Thread projection / tool bridge
let _ = project_terminal_run_lines(&run, &lines, true, false);
let _ = terminal_run_to_tool_call(&run);
```

### Command phases

| Phase | When |
|-------|------|
| `Proposed` | Not executed; pending or waiting permission |
| `EditedApproval` | `approval_edited` or executed ≠ proposed |
| `Executed` | Spawned with executed argv (= proposed) |

### Keys (card + substrate)

| Key | Action |
|-----|--------|
| Enter / Space | Toggle expand |
| `c` | Stop (when cancellable) else copy (substrate) |
| `r` | Retry |
| `d` | Detach process |
| `p` | Permission focus |
| `f` (compact) / Shift+F | Fullscreen |
| `f` (expanded) | Follow toggle (substrate) |
| `y` | Copy command (redacted) |
| Esc | Exit fullscreen → expanded |
| Page/wheel | Scroll; detaches follow |

- `terminal-run-card/{running,permission,edited,failed,narrow}`
