## Usage

The Code view above and this source excerpt use the exact paint setup registered for `date-time-picker/date`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn date_time_picker_date_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let today = CivilDate::new(2026, 8, 10).unwrap();
    let mut state = DateTimePickerState::new(DateTimePickerKind::Date)
        .with_date(CivilDate::new(2026, 8, 15).unwrap())
        .with_min_date(CivilDate::new(2026, 8, 1).unwrap())
        .with_max_date(CivilDate::new(2026, 8, 31).unwrap())
        .with_timezone_label("UTC");
    state.set_focused(true);
    state.set_today(today);
    let _ = state.open(area);
    DateTimePicker::new(system)
        .label("Due date")
        .ascii(true)
        .paint(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# DateTimePicker

**Purpose.** Date, time, and range selection when browse UX helps. Not a
replacement for every timestamp field.


## When TextInput is better

Use plain **TextInput** for:

- Rare free-form ISO stamps and log paste
- Machine-oriented values with no browse need
- Host-normalized strings without min/max UI

Use **DateTimePicker** for:

- Month navigation and “today”
- Inclusive ranges
- Stepped time lists
- Visible unavailable days (min/max)

## Ownership

| Concern | Owner |
|---------|--------|

| “Today” civil date | Host (`set_today`) |
| Real timezone math | Host |
| Timezone **label** display | TermRock (`with_timezone_label`) |

## Storage

Locale-independent:

- `CivilDate` — proleptic Gregorian `YYYY-MM-DD`
- `CivilTime` — `HH:MM[:SS]` 24h storage
- `CivilDateTime` / `CivilDateRange`

Formats (`DateDisplayFormat`, `TimeDisplayFormat`) are **explicit**, never
inferred from host locale.

## Non-color states

`[sel]` · `*today*` · `>focus<` · `.unavailable.` — also bold / reverse /
underline roles when color is available.
