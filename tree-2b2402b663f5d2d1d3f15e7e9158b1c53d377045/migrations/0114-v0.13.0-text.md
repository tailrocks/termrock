# 0114 — Text semantic typography primitive

## Mission

Canonical styled text for semantic content: roles, multi-span runs, emphasis,
dimming, wrap/truncate/align, selectable/copy policy, syntax-independent
annotations and highlights, grapheme-safe measurement, and terminal-default
background preservation.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `crate::text::{display_cols, take_display_cols, …}` | **Preserve** — measurement kernel |
| `crate::text::{wrap_display_cols, truncate_display_cols, expand_tabs, TruncateMode}` | **Added** — wrap/truncate helpers |
| `Heading` / `Paragraph` | **Migrated** — paint via `Text` (public API preserved) |
| `EmptyState` title/detail | **Migrated** — multi-span / single `Text` paint |
| `TextArea` / `TextInput` | **Preserve** — editors, not display typography |
| `ansi_text::styled_spans` | **Preserve** — ANSI ingest → ratatui spans |
| Ad hoc `buffer.set_stringn` + `Role` style in labels | **Migrate** → `Text` / `TextSpan` |
| `Text`, `TextSpan`, layout types | **Added** |

## API sketch

```rust
use termrock::widgets::{
    Text, TextSpan, TextOverflow, TextAlign, SelectablePolicy, TextEmphasis, ascii_ellipsis,
};
use termrock::style::Role;

// Single run
Text::new("Body copy", &system)
    .role(Role::Text)
    .wrap()
    .copyable()
    .paint(area, buf);

// Multi-span semantic line
Text::spans(
    [
        TextSpan::new("Status: ").role(Role::TextMuted),
        TextSpan::new("READY").role(Role::Success).strong(),
        TextSpan::new("hit").highlight(true).annotation("search"),
        TextSpan::new("code").code(),
    ],
    &system,
)
.truncate()
.paint(area, buf);

// Layout without paint
let layout = text.layout(width, height);
let plain = text.plain(); // controls stripped, tabs expanded — clipboard-safe
```

## Policies

| Concern | Behavior |
|---------|----------|
| Background | `preserve_bg(true)` default — clears role `bg` so terminal/parent shows |
| Overflow | `Clip` · `Wrap` · `Truncate` · `TruncateStart` · `TruncateMiddle` |
| Align | `Start` · `Center` · `End` |
| Selectable | `None` · `Copyable` · `Selectable` (plain path ready) |
| Tabs | Expanded to `tab_width` (default 4) before measure/paint |
| Controls | Stripped from plain and paint |

## Heading / Paragraph

```rust
// Unchanged call sites
Heading::new("Title", &system).level(HeadingLevel::H1);
Paragraph::new("Prose…", &system).muted(true);
// Internally: Text spans + truncate / wrap
```
