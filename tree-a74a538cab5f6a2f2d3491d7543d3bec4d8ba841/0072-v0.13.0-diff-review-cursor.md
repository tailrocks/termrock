# 0072 — DiffReview hunk cursor vs scene focus

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `DiffReviewOutcome::HunkFocused` | `DiffReviewOutcome::HunkCursorMoved` |
| `hunk_index` (primary) | `hunk_cursor` / `hunk_cursor()` (`hunk_index()` deprecated) |
| `handle_key(key, hunk_count: usize)` | `handle_key(key, hunks: &[DiffHunk])` |
| Ungated keys | `accepts_input` / `set_accepts_input` |
| Paint-only `tokens` + ignore hunk | `system` + `hunks()` + gutter chrome |
| Immutable `render(..., &state)` | `render(..., &mut state)` |

## Added

| API | Role |
|-----|------|
| `DiffReviewOutcome::Scrolled { offset }` | Line/page scroll |
| `handle_intent` / `default_diff_review_intent` | Intent-first line scroll + activate |
| `handle_mouse` | Wheel + click-to-hunk |
| `DiffHunk::contains_line` / `end` | Hit tests |
| `DiffReview::focused` / `ascii` / `colorless` / `hunks` | Surface + a11y |
| Empty / tiny header recipes | Responsive |

## Consumer edits

```rust
// Before
DiffReviewOutcome::HunkFocused { index } => …
state.handle_key(key, hunks.len());
DiffReview::new(&lines, &tokens).render(area, buf, &state);

// After
DiffReviewOutcome::HunkCursorMoved { index } => …
state.set_accepts_input(scene.is_focused(DIFF_ID));
state.handle_key(key, &hunks);
DiffReview::new(&lines, &system)
    .hunks(&hunks)
    .focused(true)
    .render(area, buf, &mut state);
```
