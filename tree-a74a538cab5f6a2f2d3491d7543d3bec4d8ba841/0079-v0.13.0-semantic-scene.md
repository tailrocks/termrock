# 0079 — SemanticScene public frame-local semantic tree

## Removed / replaced

| Surface | Replacement |
|---------|-------------|
| Crate-private thin `SemanticScene` (id/area only) | Public `SemanticScene<Id, Action>` with parent tree |
| Silent duplicate ignore on semantic register | `Result<(), SemanticError>` + diagnostics |
| `SemanticElement { enabled }` field layout | `SemanticNode { disabled, parent, label, … }` |
| Policy “SemanticScene must not be public” | SemanticScene is intentional public tooling API |

`InteractionScene` remains the **sole** focus / Esc / mouse authority. SemanticScene does not own focus.

## Added

| API | Role |
|-----|------|
| `SemanticNode` / `SemanticElement` alias | Frame node: parent, role, label, description, area, flags, actions |
| `SemanticState` | selected/expanded/checked/busy/invalid/pressed |
| `SemanticRole` extensions | Button, Input, List, ListItem, Tree, Table, Tab, Dialog, Menu, Status, Heading, Image, Progress, Custom + `as_str()` |
| `SemanticScene::{register, register_child, begin_frame, reserve}` | Cheap per-frame tree build |
| `hit_test`, `focus_order`, `children_of`, `path_to`, `help_lines`, `jump_regions` | Discovery |
| `snapshot` / `snapshot_with` / `SemanticSnapshot::to_text` | Studio, remote, AI-readable UI |
| `from_interaction` | Adapter from InteractionScene elements |
| `SemanticError` / `SemanticDiagnostic` | Collision and integrity |
| `InspectorPanel::Semantics` + `DesignInspectorFrame.semantics` | Studio panel |
| `assign_jump_badges_from_semantics` | Jump mode from semantic tree |

## Consumer edits

### Before

```rust
// SemanticScene was not public; only InteractionScene registration existed.
scene.register(InteractionElement::control(id, layer, area))?;
```

### After

```rust
use termrock::interaction::{
    SemanticNode, SemanticRole, SemanticScene, SemanticState,
};

let mut semantics = SemanticScene::<&str>::new();
semantics.begin_frame();
semantics.register(
    SemanticNode::content("list", list_area)
        .role(SemanticRole::List)
        .label("Files"),
)?;
semantics.register_child(
    "list",
    SemanticNode::control("row0", row_area)
        .role(SemanticRole::ListItem)
        .label("a.rs")
        .state(SemanticState { selected: true, ..Default::default() }),
)?;

// Jump mode
use termrock::widgets::assign_jump_badges_from_semantics;
let targets = assign_jump_badges_from_semantics(&semantics);

// Studio / AI
let snap = semantics.snapshot();
let text = snap.to_text();
```

Optional projection from interaction registrations:

```rust
let semantics = SemanticScene::from_interaction(&interaction_scene);
```

### DesignInspectorFrame

New required field `semantics: &[&str]` (use `&[]` when unused). New panel
`InspectorPanel::Semantics`.

## Ownership

| Concern | Owner |
|---------|-------|
| Focus, Esc, layers, action dispatch | `InteractionScene` |
| Labels, parent tree, a11y/help/jump/snapshot | `SemanticScene` |
| Domain state / effects | Consumer |
