# 0050 — Terminal capability architecture

## Removed surface

None. Existing `ColorCapability::detect_from_env`, `GlyphSet`, and
`SessionOptions` remain.

## Canonical addition

Module `termrock::capability` / crate re-exports:

- `CapabilityKind`, `CapabilitySet`, `FallbackPolicy`, `fallback_policies`
- `CapabilityProfile` (modern / compatible / minimal / inline / headless)
- `CapabilityOverrides`, `resolve_capabilities`, `EffectiveCapabilities`
- `detect_environment`, `DetectionReport`, `EnvHints`
- `build_doctor_report`, `format_doctor_text`, `DoctorReport`
- `SessionFlags` (+ `From` into crossterm `SessionOptions` when featured)

Design: `docs/design/terminal-capability-architecture.md`.

### Host usage

```rust
use termrock::{
    CapabilityOverrides, CapabilityProfile, resolve_capabilities,
    build_doctor_report, format_doctor_text, Theme,
};

let eff = resolve_capabilities(None, CapabilityOverrides::default());
let theme = Theme::default().quantized(eff.set.color);
let flags = eff.session_flags();
// optional: Session::enter(stdout, flags.into()) with feature crossterm

println!("{}", format_doctor_text(&build_doctor_report(None, Default::default())));
```

### Env overrides

`TERMROCK_PROFILE`, `TERMROCK_COLOR`, `TERMROCK_GLYPHS`, plus standard `NO_COLOR`.
