# 0136 — Slider and RangeSlider

## Mission

Terminal-native bounded numeric controls: single and range thumbs, step/page/
Home/End, marks, labels, direct numeric entry, disabled/read-only, horizontal
and vertical orientation, ASCII/no-color handles, tiny-width numeric fallback.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Progress` / `ProgressKind` | **Preserved** — read-only completion indicator |
| `SegmentedMeter` | **Preserved** — share chart |
| `TextInput` | **Preserved** — free text; Slider embeds simple edit buffer |
| `Slider`, `RangeSlider`, bounds, marks, outcomes | **Added** |

No prior Slider call sites. Do **not** use Slider alone where exact precision is
required without a value field (built-in value text/edit or host TextInput).

## API sketch

```rust
use termrock::widgets::{
    Slider, SliderState, SliderBounds, SliderMark, SliderOutcome,
    RangeSlider, RangeSliderState, RangeThumb,
};

let bounds = SliderBounds::percent(); // 0..=100 step 1
let mut state = SliderState::new(50.0);
state.set_focused(true);
Slider::new(bounds, &system)
    .label("Volume")
    .marks(&[SliderMark::labeled(0.0, "lo"), SliderMark::new(100.0)])
    .paint(area, buf, &mut state);

// Keys: ←→ step, PgUp/PgDn page, Home/End, Enter/digits edit
// Mouse: drag/click track; wheel steps

let mut range = RangeSliderState::new(20.0, 80.0);
range.set_focused(true);
RangeSlider::new(bounds, &system)
    .label("Filter")
    .paint(area, buf, &mut range);
// Tab switches active thumb
```

## Behavior

| Concern | Rule |
|---------|------|
| Handle (ASCII) | `*` reverse/bold |
| Handle (Unicode) | `●` |
| Fill / empty | `=` / `-` or `━` / `─` |
| Tiny width (&lt; 10) | Numeric-only face |
| Edit | Enter or digit starts; Enter commits; Esc cancels |
| Range | Start cannot pass end; Tab toggles thumb |
| Vertical | Bottom = min, top = max |

## Appropriate use

| Need | Control |
|------|---------|
| Bounded approximate setting / filter | **Slider** / **RangeSlider** |
| Exact free-form number | TextInput (+ optional Slider) |
| Read-only completion | Progress |
