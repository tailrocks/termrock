# 0265 — Overlay elevation and shared shells

Dialogs, popovers, menus, drawers, notification centers, and toasts now paint
their shells through `SurfaceRecipe::Overlay`: elevated fill, shared border
geometry, and semantic focused-border color. Modal backdrops dim by default
with a static glyph wash over the terminal-default background.

## Visual changes

- `Backdrop::default()` and `Backdrop::from_tokens()` dim. Use
  `Backdrop::reset()` for the former transparent/reset field.
- Toast borders are neutral; severity appears on the icon and accent rail.
- Toast progress uses the shared fractional block ramp over a sunken track.
- Status-bar slots gain muted separators while the band retains `Role::StatusBar`.
- `Surface::border_style(Style)` customizes semantic border color without
  forking glyph geometry. Focus still changes color, never border weight.

No overlay-stack ownership or dismissal behavior changed. Consumers that
assert exact buffer geometry should regenerate fixtures after updating.
