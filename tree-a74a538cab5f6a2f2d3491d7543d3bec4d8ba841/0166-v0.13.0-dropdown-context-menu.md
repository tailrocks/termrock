# 0166 — DropdownMenu and ContextMenu redesign

## Mission

Command menus with nested items, stateful rows, shortcuts, and contextual
placement — roving focus, typeahead, semantic command keys, generated shortcut
hints, pointer/keyboard/context opening, nested OverlayStack dismiss, and
promotion of deep or oversized trees to CommandPalette-style pages.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `MenuNode`, `MenuRowKind`, `MenuCommandRef` | **Preserved** (shared model; extended) |
| `MenuRowKind::{Loading, CustomPreview}` | **Added** |
| `MenuNode::destructive`, `loading`, `custom_preview`, `label_row` | **Added** |
| `OverlayKind::{Menu, ContextMenu}` placement policies | **Preserved** |
| `Menu` / `MenuState` / `MenuOutcome` (flat) | **Preserved** (simple single-panel adapter) |
| `MenuItem` | **Moved** to `dropdown_menu` (re-exported from `menu_nav`) |
| `ContextMenu = Menu` type alias | **Deleted** → `ContextMenu = DropdownMenu` |
| `DropdownMenu`, `DropdownMenuState`, overlay helpers | **Added** |
| `flatten_menu_nodes`, palette promotion thresholds | **Added** |
| MenuBar cascade | **Preserved** (now paints loading/preview/destructive) |

## Consumer edits

```diff
- use termrock::widgets::{ContextMenu, Menu, MenuItem, MenuState};
+ use termrock::widgets::{
+     ContextMenu, DropdownMenu, DropdownMenuState, MenuNode,
+     open_dropdown_menu_overlay, open_context_menu_overlay,
+     open_menu_submenu_overlay, measure_menu_panel, flatten_menu_nodes,
+ };

  // Hierarchical (preferred)
+ let nodes = vec![
+     MenuNode::command("open", "Open").shortcut("C-o"),
+     MenuNode::checkbox("wrap", "Wrap", true),
+     MenuNode::submenu("more", "More", vec![MenuNode::command("a", "A")]),
+     MenuNode::command("del", "Delete").destructive(true),
+ ];
+ let mut state = DropdownMenuState::new();
+ match state.open_from_keyboard(&nodes, bounds) {
+     DropdownMenuOutcome::PreferCommandPalette => { /* open palette with flatten_menu_nodes */ }
+     DropdownMenuOutcome::Opened { .. } => {
+         let size = measure_menu_panel(&nodes, false);
+         open_dropdown_menu_overlay(&mut stack, bounds, anchor, size, Some("trigger"));
+     }
+     _ => {}
+ }
+ DropdownMenu::new(&nodes, &system).paint_cascade(root_rect, bounds, buf, &mut state);

  // Context (right-click / context key)
+ let mut ctx = DropdownMenuState::context();
+ let _ = ctx.open_from_context_pointer(&nodes, bounds);
+ open_context_menu_overlay(&mut stack, bounds, origin, size, opener);

  // Flat Menu still works for simple lists:
  let items = [MenuItem::new("a", "Open")];
  let mut state = MenuState::new();
  Menu::new(&items, &system).render(area, buf, &mut state);
```

### Item kinds

| Kind | Notes |
|------|--------|
| Command | leaf activate → `Activated { id, command }` |
| Checkbox | host-owned bit → `CheckToggled` |
| Radio | group + selected → `RadioSelected` |
| Submenu | Right / Activate opens nested stack layer |
| Separator / Section (label) | non-interactive |
| Loading / CustomPreview | non-interactive placeholders |
| `destructive` flag | `Role::Danger` paint |

### Opening triggers

`MenuOpenTrigger::{Keyboard, Pointer, ContextPointer, ContextKey}`

### Promotion

`dropdown_menu_presentation_for` → `CommandPalette` when width ≤ 36, height ≤ 14,
item count > 24, or depth ≥ 4. Host opens palette with `flatten_menu_nodes`.

### Stories

- `dropdown-menu/basic`, `nested`, `kinds`
- `context-menu/basic`, `nested`
