# Typed Form values through FieldRow

`Field::value` is now `FieldRowValue` instead of `&str`. Form rows paint
through the canonical `FieldRow`, including plain, masked, and required-unset
values. Invalid rows use `Role::InputInvalid`; supporting validation remains
`Role::Danger`.

Before:

```rust
Field::new("token", "Token", "••••");
Field::new("region", "Region", "required");
```

After:

```rust
Field::new("token", "Token", "ignored").masked(8);
Field::new("region", "Region", "").unset("required").required(true);
```

`Field` and `Fieldset` are now `Clone`, not `Copy`, because composed values own
Ratatui spans. Filtered projections must use `.cloned()`. Search integrations
use `FieldRowValue::searchable_text()`; masked/composed content is never leaked.

Validate with `cargo nextest run -p termrock form form_wizard field_row` and
`mise run gate`.
