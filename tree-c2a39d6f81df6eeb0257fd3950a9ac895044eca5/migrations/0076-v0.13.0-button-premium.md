# 0076 — Button premium redesign

## Removed / renamed

| Removed | Replacement |
|---------|-------------|
| `ActivationState::set_focused` (primary) | `set_accepts_input` (deprecated alias kept) |
| `ActivationState::is_focused` (primary) | `accepts_input` |
| Raw Enter/Space match as sole law | `default_button_intent` + `handle_intent` |
| `IconButton::new(glyph, system)` | `IconButton::new(glyph, accessible_label, system)` |
| Default `accepts_input = true` | Default **false** until host grants |

## Added

| API | Role |
|-----|------|
| `ButtonVariant` / `ButtonSize` | Chrome + density |
| `ActivationOutcome::{Pressed, ConfirmRequired}` | Arm + pending confirm |
| `Button::{variant, size, leading, trailing, full_width, accessible_label, ascii, colorless}` | Recipes |
| `Button::is_safe_default_focus` | Destructive safety |
| `default_button_intent` | Semantic Activate |
| Loading distinct paint | vs disabled |

## Consumer edits

```rust
// Before
state.activation.set_focused(true);
Button::new("Save", &tokens).primary(true);
IconButton::new("×", &tokens);

// After
state.activation.set_accepts_input(true);
Button::new("Save", &system).variant(ButtonVariant::Primary);
IconButton::new("×", "Close", &system);
// Destructive dialog: focus Cancel/Secondary, never Delete by default
```
