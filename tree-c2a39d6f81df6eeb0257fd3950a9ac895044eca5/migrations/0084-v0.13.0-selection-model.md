# 0084 — SelectionModel (single / multi / range)

## Mission

Consistent selection membership separate from focus, active cursor, and paint.

## Added

| API | Module | Role |
|-----|--------|------|
| `SelectionKind` | `interaction` | None / Single / Multiple / Range |
| `SelectionModel<Id>` | `interaction` | Ordered membership + anchor |
| `SelectionDelta` | `interaction` | Typed changes |
| `SelectionVisual` | `interaction` | Gutter / Fill / Tint / Check (non-color) |
| `select_subtree` | `interaction` | Hierarchical helper |

## Migrated

| Surface | Change |
|---------|--------|
| `widgets::Selection` | Facade over `SelectionModel::multiple()` |
| `data_view::SelectionModel` | Row set → `rows: interaction::SelectionModel`; cell cursor kept |
| List multi-select | Unchanged API via `Selection` facade |
| DataTable paint | `is_row_selected` |

## Laws

1. Focus ≠ active ≠ selected/checked.
2. Filtered views: `select_all(visible)` does not drop off-window members; `reconcile(valid)` drops deleted.
3. Range uses host-provided **visible order** (disabled omitted by host).
4. Visual recipes must not rely on color alone (`SelectionVisual::requires_glyph`).

## Consumer edits

```rust
use termrock::interaction::{SelectionModel, SelectionKind, SelectionDelta};

let mut sel = SelectionModel::multiple();
let _ = sel.toggle(&"a");
let _ = sel.extend_range(&["a", "b", "c"], &"c");

// List multi-select (unchanged call shape)
state.enable_multi_select();
state.selection_mut().unwrap().toggle(&id);

// Data table rows
state.selection.toggle_row(id);
state.selection.is_row_selected(&id);
// was: state.selection.selected_rows.contains(&id)
```

### data_view::SelectionModel

- `selected_rows` field → `rows` model + `selected_rows()` method.
- Prefer `is_row_selected` / `selected_rows()`.

## Cell / hierarchical (same release track)

| API | Role |
|-----|------|
| `CellCoord` / `CellSelectionModel` | Single + rectangular cell range |
| `deselect_subtree` | Hierarchical deselect helper |
| List `Shift+Space` / `select_range_to` | Anchor range along visible order |
| `data_view::SelectionModel.cells` | Embeds `CellSelectionModel` |
