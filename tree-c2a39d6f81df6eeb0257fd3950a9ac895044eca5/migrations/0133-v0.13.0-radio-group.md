# 0133 — RadioGroup

## Mission

Single-choice group with predictable roving navigation: vertical/horizontal
orientation, disabled options, descriptions, badges, typeahead, controlled
state, and a documented selection policy (follow-focus vs activate-to-select).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `RadioState::new(selected)` / `selected` / `active` / `set_selected` | **Preserved** |
| `RadioOutcome::Selected(Id)` | **Preserved** |
| `RadioOutcome::CursorMoved` | **Added** (ActivateToSelect) |
| `RadioGroup::new(&[(Id,&str)], …)` | **Migrated** → `RadioGroup::new(&[RadioOption], system)` |
| `RadioOption`, legend, orientation, policy, parts, semantics | **Added** |
| Headless `RadioState::handle_key(key, &[Id])` | **Preserved** (ids-only helper) |
| Prefer `RadioGroup::handle_key` / `paint` for full metadata | **Canonical** |
| `Checkbox` / `ToggleGroup` / `Tabs` / `ModeRibbon` | **Preserved** (distinct roles) |

## Consumer edits

```diff
- let options = [("a", "Alpha"), ("b", "Beta")];
- RadioGroup::new(&options, &system).render(area, buf, &mut state);
+ let options = [
+     RadioOption::new("a", "Alpha").description("…"),
+     RadioOption::new("b", "Beta").badge("rec"),
+ ];
+ let mut state = RadioState::new(Some("a"));
+ state.set_surface_focused(true);
+ RadioGroup::new(&options, &system)
+     .legend("Pick one")
+     .paint(area, buf, &mut state);
```

```rust
// Default: FollowFocus — arrows commit selection (native/Radix)
// Explicit activate for review/destructive choices:
state.set_policy(RadioSelectionPolicy::ActivateToSelect);
// Down → CursorMoved; Space/Enter → Selected
```

## Selection policy

| Policy | Arrow / typeahead | Space / Enter |
|--------|-------------------|---------------|
| **FollowFocus** (default) | Selects + moves active | Selects active |
| **ActivateToSelect** | Moves active only | Selects active |

## Behavior

| Concern | Rule |
|---------|------|
| Marks | Unicode catalog ●/○; ASCII/mono `(*)` / `( )` |
| Disabled | Skipped by roving; muted paint |
| Narrow | Horizontal stacks vertical when width &lt; `stack_below` (default 28) |
| Typeahead | Printable chars jump by label prefix |
| Hit | Full option row (mark + label + description) |
