# 0119 — Tag, Chip, and TokenStrip

## Mission

Removable/selectable compact tokens for filters, attachments, entities, and
structured input: static tags, interactive chips, selected/removable/error/
loading states, internal Body|Remove focus without Tab explosion, strip wrap/
scroll/`+N` overflow, ASCII glyphs, and explicit `remove {label}` semantics.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tag::new` / `Chip::new` | **Migrated** — richer builders; default Tag is **static** (use `removable_tag` or `.removable(true)`) |
| `TagState` / `ChipState` | **Migrated** — add `TokenPart`; ChipState no longer `Copy` |
| `TagOutcome` / `ChipOutcome` | **Migrated** — more variants (`PartChanged`, `Activated`, `Remove` on chip) |
| `TokenPart`, `TokenStatus`, `TokenStrip`, `TokenItem` | **Added** |
| `remove_label` | **Added** — a11y/inspection string |
| Module | **Split** → `widgets/tag_chip.rs` |
| `PromptComposer` chip paint | **Migrated** → `Tag::removable_tag` paint |
| `ComposerChip` domain model | **Preserve** — product attachment model |

## API sketch

```rust
use termrock::widgets::{
    Tag, TagState, Chip, ChipState, TokenPart,
    TokenStrip, TokenItem, TokenStripState, remove_label,
};

// Tag (entity / attachment)
let tag = Tag::removable_tag("p1", "paste.txt", &system);
let mut st = TagState::new();
st.set_focused(true);
// Left/Right: Body ↔ Remove (no Tab)
// Delete / Enter on Remove → TagOutcome::Remove

// Chip (filter)
let chip = Chip::new("rust", "rust", &system).removable(true);
let mut cs = ChipState::new(false);
cs.set_focused(true);
// Space/Enter on Body → toggle Selected/Unselected

// Strip (TokenField shared behavior)
let items = [
    TokenItem::chip("a", "rust").selected(true),
    TokenItem::tag("b", "file.rs").removable(true),
];
let strip = TokenStrip::new(&items, &system).wrap().max_visible(8);
let mut ss = TokenStripState::new();
ss.set_surface_focused(true);
strip.paint(area, buf, &mut ss);
strip.handle_key(&mut ss, key);

assert_eq!(remove_label("paste"), "remove paste");
```

## Focus model

| Layer | Keys |
|-------|------|
| Between tokens | Host roving / TokenStrip arrows |
| Body ↔ Remove | Left/Right (or h/l) **inside** focused token |
| Tab | Host only — never used for remove |

## Breaking notes

- `Tag::new` is no longer removable by default.
- `ChipState` / `TagState` gained `part` and are not simple public-field structs
  for remove_region (geometry lives in `TokenParts`).
- Prefer `paint` + typed outcomes over old `handle_key(key, id, removable)`.
