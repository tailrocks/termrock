## Canonical addition

```rust
use termrock::widgets::{
    PermissionPrompt, PermissionPromptState, PermissionRequest, PermissionRisk,
    PermissionScope, PermissionAction, PermissionOutcome, PermissionProvenance,
    ProvenanceHop, InitiatorKind, PermissionActionKind,
};

let mut state = PermissionPromptState::new();
let req = PermissionRequest::new("id", "bash", "workspace")
    .risk(PermissionRisk::High)
    .action_kind(PermissionActionKind::Shell)
    .command("rm -rf build/")
    .irreversible()
    .provenance(
        PermissionProvenance::main_agent("run", "main")
            .push(ProvenanceHop::new(InitiatorKind::Subagent, "s1", "reviewer")),
    );
state.enqueue(req);

match state.handle_key(key) {
    PermissionOutcome::Decided { action, scope, generation, edited, .. } => { /* policy */ }
    PermissionOutcome::StaleIgnored { .. } => { /* ignore */ }
    PermissionOutcome::Cancelled { .. } => { /* no grant */ }
    _ => {}
}

frame.render_stateful_widget(&PermissionPrompt::new(&theme), area, &mut state);
```

### Guarantees

- Default selection is Deny (never Allow).  
- Esc cancels without grant.  
- Queue generations block stale Enter.  
- Provenance chain for nested subagent/MCP.
