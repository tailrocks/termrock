# TreeTable recipe rows and pointer hover

`TreeTable` now resolves selected and hovered rows through the shared list-row
recipe. Selection uses the configured semantic tint/fill/gutter chrome and
pointer hover uses `HoverTint` across the complete row.

`TreeTableState` adds public `hovered: Option<Id>`. Hosts constructing state
with `TreeTableState::new` or `Default` need no edits. Hosts using exhaustive
struct literals must initialize `hovered` to `None`; direct literals are
discouraged because internal geometry fields remain widget-owned.

Before:

```rust
let mut state = TreeTableState::new(Some(selected));
// Pointer movement had no retained visual identity.
```

After:

```rust
let mut state = TreeTableState::new(Some(selected));
// `handle_mouse(MouseEventKind::Moved, ..)` updates `state.hovered`.
```

No compatibility paint path remains. Validate with:

```text
cargo nextest run -p termrock tree_table
mise run gate
```
