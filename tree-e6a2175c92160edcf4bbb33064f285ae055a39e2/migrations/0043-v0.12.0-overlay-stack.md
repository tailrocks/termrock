# 0043 — Unified OverlayStack

## Removed surface

None. This migration **adds** the public overlay authority. Legacy crate-private
`OverlayHost` / `OverlayController` remain private (see migration `0034`); do not
use them. Ad-hoc per-widget placement (inline geometry math, independent Esc
handlers) should move onto [`OverlayStack`].

`place_completion_menu` remains, but its body now delegates to
[`place_overlay`] with [`OverlayKind::Completion`] policy.

## Canonical replacement

```rust
use termrock::{
    OverlayId, OverlayKind, OverlayOutcome, OverlayPolicy, OverlaySize, OverlaySpec,
    OverlayStack, place_overlay,
};
use termrock::widgets::{
    open_command_palette_overlay, open_completion_overlay, open_dialog_overlay,
    place_command_palette, place_completion_menu, place_dialog,
    CommandPaletteSize, CompletionMenuSize, DialogSize,
};

let mut stack = OverlayStack::<&'static str>::new();
let bounds = /* full screen or host rect */;

// Open (z-order = open order; last is top)
stack.open(
    bounds,
    OverlaySpec::dialog("confirm", OverlaySize::dialog(40, 10), Some("save-btn")),
);
// Nested child
stack.open(
    bounds,
    OverlaySpec::menu("file-menu", anchor, OverlaySize::menu(20, 8), None)
        .with_parent("confirm"),
);

// Esc closes exactly one conceptual layer
match stack.handle_escape() {
    OverlayOutcome::Dismissed { id, focus } => { /* restore focus */ }
    OverlayOutcome::Ignored => { /* alert trap */ }
    OverlayOutcome::UnhandledEscape => { /* consumer quit policy */ }
    _ => {}
}

// Outside click / wheel / resize
let _ = stack.handle_outside_click(pointer);
if stack.wheel_captured(pointer) { /* do not scroll parent */ }
stack.reflow(new_bounds);

// Widget helpers (same policies)
open_completion_overlay(&mut stack, bounds, anchor, CompletionMenuSize::default(), Some("editor"));
open_command_palette_overlay(&mut stack, bounds, CommandPaletteSize::default(), Some("editor"));
open_dialog_overlay(&mut stack, bounds, DialogSize::default(), Some("trigger"));
```

### Law

**Escape closes exactly one conceptual interaction layer.** A top layer with
`LayerDismissPolicy::Trap` (e.g. alert dialog) protects every layer beneath it
without peeling them.

### Policy table (defaults)

| Kind | Esc | Outside | Focus trap | Backdrop | Prefer | Narrow |
|------|-----|---------|------------|----------|--------|--------|
| Tooltip | Ignore | Dismiss | no | None | Above | Hide |
| Popover | Dismiss | Dismiss | no | None | Below | Center |
| Menu / Select | Dismiss | Dismiss | yes | None | Below | Clamp |
| ContextMenu | Dismiss | Dismiss | yes | None | Origin | Clamp |
| Completion | Dismiss | Dismiss | no | None | Below, no cover | Clamp |
| Dialog | Dismiss | Trap | yes | Dim | Center | Fullscreen |
| AlertDialog | Trap | Trap | yes | Occlude | Center | Fullscreen |
| Drawer | Dismiss | Dismiss | yes | Dim | End edge | Fullscreen |
| CommandPalette | Dismiss | Dismiss | yes | Dim | Center | Fullscreen |
| Fullscreen | Dismiss | Trap | yes | Occlude | Fill | Fullscreen |

Pair with [`InteractionScene`]: after open, call
`stack.sync_scene_layers(&mut scene)` (or `sync_scene_layers_unit`) so Esc/outside
policies stay consistent with registered layers.

## Exact consumer edits

1. Own one `OverlayStack<FocusId>` at the shell (not one stack per widget).
2. Open dialogs, palettes, completion, menus through `stack.open` or the
   widget helpers (`open_*_overlay`).
3. On Esc, call `stack.handle_escape()` **before** domain quit — one layer only.
4. On terminal resize, call `stack.reflow(new_bounds)` and re-paint with
   `entry.rect`.
5. Replace local `place_*` geometry with `place_overlay` / kind helpers when
   custom widgets need the same flip/clamp/narrow behavior.
6. Restore focus from `OverlayOutcome::Dismissed { focus, .. }`.

## Ownership

TermRock owns z-order, placement (anchor/flip/clamp/minmax/narrow), backdrop
policy, Esc/outside/wheel routing flags, opener focus tokens, and nested
dismiss of children when a parent is removed.

Consumers own paint payloads, domain state, quit policy, and which focus id
is stored as opener.

## Migrated widgets (this boundary)

- **CompletionMenu** — `place_completion_menu` → `place_overlay`;
  `open_completion_overlay` / `dismiss_completion_overlay`.
- **CommandPalette** — `place_command_palette`, `open_command_palette_overlay`,
  `dismiss_command_palette_overlay`.
- **Dialog** — `place_dialog`, `open_dialog_overlay`, `open_alert_dialog_overlay`,
  `dismiss_dialog_overlay`.
