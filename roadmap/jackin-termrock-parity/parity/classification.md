## Verdict procedure

Apply in order: (1) product noun in public model → `example composite`; (2) multi-widget recipe with host-owned domain data → `example composite`; (3) neutral single-purpose chrome → `generic building block`; (4) shared block/recipe model → `generic building block`; (5) ambiguous primitives default to widgets and assemblies to patterns. Override to `product-specific` only when the Jackin brand/domain is itself the capability and no neutral primitive or teachable recipe remains.
