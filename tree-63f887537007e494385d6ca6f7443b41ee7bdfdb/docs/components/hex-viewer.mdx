## Try it

- `arrows move byte`: Move through the real focus/selection model; the next action uses the new target.
- `Shift+arrows select`: Move through the real focus/selection model; the next action uses the new target.
- `wheel scroll`: Scroll over the preview; its own viewport moves while the docs page stays put.
- `click byte`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `I inspector`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `B bookmark`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `hex-viewer/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn hex_viewer_basic(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let data = hex_viewer_sample();
    let win = HexWindow::new(0, &data, data.len() as u64);
    let mut state = HexViewerState::new();
    state.bytes_per_row = 16;
    state.cursor = 0x10;
    HexViewer::new(win, system)
        .title("blob.bin")
        .render(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# HexViewer

Binary inspector over a **host-projected page** (`HexWindow`). TermRock owns
row virtualization metrics from `total_len`, cursor/selection in absolute
offsets, and chrome — never file I/O.


## When to use / when not

| Use HexViewer | Prefer |
|---------------|--------|
| Binary / blob inspection | — |
| Text source files | [CodeBlock](/docs/components/code-block) |
| Structured logs | [LogStream](/docs/components/log-stream) |

## Paging contract

```text
Host projects: base_offset + data[] + total_len
Scroll/cursor use absolute offsets
PageNeeded { offset } → host re-reads page containing offset
```

## Non-color selection

- Cursor: `›` / `>` gutter + `⟨XX⟩` / `[XX]` around active byte
- Selection: `{XX}` braces
- Bookmarks: `★` / `*`

## Inspector

Endian-aware `u8`/`u16`/`u32`/`u64` at cursor (`e` toggles LE/BE).
