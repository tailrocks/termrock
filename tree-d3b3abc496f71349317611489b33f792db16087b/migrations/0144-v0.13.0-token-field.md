# 0144 — TokenField editable token collection

## Mission

Editable collection of chips/tokens with free-text draft: add/remove/reorder/
select, duplicate policy, overflow, paste multi-value, completion hooks, and a
single surface focus (no Tab stop per token).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tag` / `Chip` / `TokenStrip` | **Preserved** — display/roving primitives TokenField paints with |
| `TokenItem` projection | **Preserved** — TokenStrip stays projection-only |
| `ComposerChip` / PromptComposer | **Preserved** — product chips; may project into TokenField later |
| `TokenField` / `FieldToken` / `TokenFieldState` | **Added** — owns tokens + draft |
| `DuplicatePolicy` / `CommitSeparators` / `TokenFieldZone` | **Added** |

## Consumer edits

```rust
use termrock::widgets::{
    CommitSeparators, DuplicatePolicy, FieldToken, TokenField, TokenFieldOutcome, TokenFieldState,
    TokenStatus,
};

let mut state = TokenFieldState::new()
    .with_duplicate_policy(DuplicatePolicy::RejectLabel)
    .with_separators(CommitSeparators::email())
    .with_multi_select(false)
    .with_max_visible(8);
state.set_focused(true);

match state.handle_key(key) {
    TokenFieldOutcome::TokenAdded { id, label } => { /* … */ }
    TokenFieldOutcome::TokenRemoved { id } => { /* … */ }
    TokenFieldOutcome::TokenReordered { from, to } => { /* … */ }
    TokenFieldOutcome::CompletionRequested { query } => {
        // host async suggestions → state.apply_suggestion(id, label)
    }
    TokenFieldOutcome::ClipboardPasteRequest => {
        let _ = state.paste_values(&host.paste());
    }
    TokenFieldOutcome::Submitted => { /* form submit */ }
    TokenFieldOutcome::DraftChanged => {}
    _ => {}
}

TokenField::new(&system)
    .label("To")
    .placeholder("Add recipient…");
```

### Focus (one surface)

| Zone | Navigation |
|------|------------|
| Draft | type freely; Left at start → last token |
| Token body | Left/Right across tokens; Right → remove part if removable |
| Empty draft + Backspace | remove previous token |
| Alt+Left/Right on token | reorder |

Host Tab enters/leaves the **field**, not each chip.

### Paste

`paste_values` splits on `,` `;` newline; commits each non-empty part as a token.
