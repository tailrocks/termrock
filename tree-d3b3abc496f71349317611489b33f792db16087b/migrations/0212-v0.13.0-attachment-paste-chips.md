# 0212 — AttachmentChip and PasteChip

## Mission

Structured compact representations of files, images, URLs, selected code, and
large pasted text: type, name, size/line count, status, validation, remove,
open/preview, retry, upload/indexing progress. Collapse large pastes while
preserving inspectability and copy (by id). Stable IDs; no sensitive bodies in
semantic summaries. Wrap, horizontal scroll, and `+N` overflow via TokenStrip.
Compose with PromptComposer and permission / data-egress hosts (outcomes only).

Research: Grok Build paste/file chips, modern chat attachments, terminal prompt
composers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tag` / `Chip` / `TokenStrip` / `TokenStatus` / `TokenPart` | **Preserved** — chrome + strip layout |
| `ComposerChip` / `ChipKind` | **Preserved** — list model in PromptComposer; bridges added |
| PromptComposer chip paint | **Migrated** — paints via AttachmentChip / PasteChip |
| Upload / open / clipboard I/O | **Never TermRock** — outcomes only |
| `AttachmentItem` · `PastePayload` · `AttachmentChip` · `PasteChip` | **Added** |
| `attachment_to_composer_chip` / `paste_to_composer_chip` / reverse | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    AttachmentItem, AttachmentType, AttachmentStatus, AttachmentChip, AttachmentChipState,
    AttachmentChipOutcome, PastePayload, PasteChip, PasteChipState, PasteChipOutcome,
    paint_attachment_strip, TokenStripLayout, TokenStripState,
    attachment_semantic_summary, paste_semantic_summary,
    ComposerChip, attachment_to_composer_chip, paste_to_composer_chip,
};

// Domain
let file = AttachmentItem::file("f1", "main.rs")
    .bytes(4200)
    .line_count(128)
    .status(AttachmentStatus::Uploading { progress: 40 });
let paste = PastePayload::from_body("p1", large_text);
// Binary never auto-inserts
let bin = PastePayload::binary("b1", 12_288);

// Single chip paint
let mut st = AttachmentChipState::new();
st.set_focused(true);
AttachmentChip::new(&file, &system).paint(area, buf, &mut st);

let mut ps = PasteChipState::new();
PasteChip::new(&paste, &system).handle_key(&mut ps, enter); // Expanded
// CopyRequested { id } — host copies body; outcome never carries body text
// semantic summaries omit bodies and full sensitive paths
assert!(!attachment_semantic_summary(&file.sensitive(true)).contains("/home"));

// Strip: wrap / scroll / overflow
let mut strip = TokenStripState::new();
paint_attachment_strip(
    &[file],
    &[paste],
    area,
    buf,
    &system,
    &mut strip,
    TokenStripLayout::Wrap,
    8,
    ascii,
    &[],
);

// PromptComposer bridge
state.add_chip(ComposerChip::from_attachment(&file));
state.add_chip(ComposerChip::from_paste(&paste));
```

### Outcomes

| AttachmentChip | PasteChip |
|----------------|-----------|
| Activated · Removed · OpenRequested · PreviewRequested · RetryRequested · PartChanged | Expanded · Collapsed · Removed · CopyRequested · InsertRequested { needs_confirm } · PreviewRequested · RetryRequested · PartChanged |

### Keys (focused chip)

| Key | Attachment | Paste |
|-----|------------|-------|
| Enter | Activate / remove part | Expand toggle |
| Esc | — | Collapse |
| Delete / Backspace | Remove | Remove |
| Ctrl+O / Ctrl+P | Open / preview | Preview |
| Ctrl+C | — | Copy body (host) |
| Ctrl+I | — | Insert (binary confirms) |
| Ctrl+R | Retry when error | Retry when error |
