# 0098 — Grid layout primitive

## Mission

Predictable terminal grid for dashboards, forms, settings, and card collections:
tracks (fixed / fr / minmax), gaps, spans, auto-flow, responsive templates,
deterministic overflow, optional spatial navigation helpers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Stack` / `Inline` | **Preserve** — 1D packing |
| `WorkSurface` / `Workspace` | **Preserve** — named app panes |
| `layout::{Grid, TrackSize, layout_grid, …}` | **Added** |
| Form `columns_for` | **Migrated** — uses `form_grid_template` + surface policy |

## API

```rust
use termrock::layout::{
    Grid, GridItem, GridSpec, TrackSize, GridAutoFlow,
    layout_grid, form_grid_template, dashboard_grid_template,
    grid_neighbor_2d, grid_reading_neighbor,
};

// Equal columns + auto-flow
let layout = Grid::columns(3)
    .gaps(1, 1)
    .auto_row(TrackSize::Fixed(4))
    .layout_flow(area, 6, GridAutoFlow::Row);

// Explicit spans
let layout = layout_grid(area, &GridSpec::columns_fr(2).rows([
    TrackSize::Fixed(3),
    TrackSize::fr(1),
]), &[
    GridItem::span(0, 0, 2, 1),
    GridItem::cell(0, 1),
    GridItem::cell(1, 1),
]);

// Responsive templates
let form = form_grid_template(width);      // 1 or 2 cols
let dash = dashboard_grid_template(width, 3, 18, 1);

// Spatial nav (host wires intents)
if let Some(next) = grid_neighbor_2d(&items, focus, 1, 0) { /* right */ }
```

## Overflow

Track minima exceeding the axis shrink from the **end** (`overflowed = true`).
Out-of-range placements resolve to zero-size rects.
