# PlanReview

Interactive review for agent-generated plans. Host owns execution policy;
outcomes are **requests only**. Approve is never the initial focus.

## Live terminal (Ghostty-class)

One focused interactive surface — the same TermRock paint path as the lookbook
and [Components](/docs/components) pages. **Not SVG.** Focus the frame; use keys
or click to step multi-state packs when available.

## When to use / when not

| Use PlanReview | Prefer |
|----------------|--------|
| Approve/revise agent plan before work | — |
| Single tool/shell trust gate | [PermissionPrompt](/docs/handbook/permission-prompt) |
| Patch/hunk accept | [DiffReview](/docs/handbook/diff-review) |
| Multi-question interview | [QuestionFlow](/docs/handbook/question-flow) |
| Live pipeline progress | [ProgressSteps](/docs/components/progress-steps) (if present) |

## Domain

- `PlanDocument` — body, sections, tasks, risks, assumptions, files, refs, risk, previous
- `PlanComment` + `PlanCommentAnchor` — line/range/section/task/file/orphan
- `remap_plan_comments` / `update_plan` — preserve stable anchors across revisions

## Actions (safe focus)

Abandon · Revise · Feedback · Approve… · Approve

Default: `RequestRevision` (low/medium) or `Abandon` (high/critical). Enter
confirms focus only. Bare `a` moves focus — does not grant.
