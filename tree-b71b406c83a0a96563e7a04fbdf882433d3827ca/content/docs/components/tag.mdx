replaces multi-image galleries.

## Usage

```rust
use termrock::widgets::{Tag, TagState, TokenPart, remove_label};

let tag = Tag::removable_tag("p1", "paste.txt", &system);
let mut state = TagState::new();
state.set_focused(true);
// Right → focus remove; Enter/Delete → remove
tag.paint(area, buf, &mut state);

assert_eq!(remove_label("paste.txt"), "remove paste.txt");
```

## Focus

| Part | Keys |
|------|------|
| Body | Enter activates |
| Remove | Enter / Delete removes |
| Body ↔ Remove | Left / Right (not Tab) |
