# 0113 — Accordion disclosure groups

## Mission

Single- or multi-open disclosure groups composed from [`Collapsible`] paint and
[`RovingFocusGroup`] navigation: Home/End, typeahead, disabled items, stable
IDs, controlled open sets, and recipes for section / settings / logs / FAQ.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Collapsible` / `CollapsibleState` | **Preserve** — single disclosure primitive; Accordion paints each trigger through it |
| `RovingFocusGroup` | **Preserve** — active-descendant navigation (Home/End, typeahead) |
| `Section::collapsible` / `Panel::collapsible` | **Preserve** — standalone chrome collapse, not multi-item groups |
| `Tree` branch expand | **Preserve** — hierarchical collection, not free-form FAQ/settings groups |
| Ad-hoc stacks of collapsibles with hand-rolled focus | **Migrate** → `Accordion` |
| `Accordion` + items/state/outcomes/recipes | **Added** |

## API sketch

```rust
use termrock::widgets::{
    Accordion, AccordionItem, AccordionState, AccordionOutcome, AccordionMode,
};

let items = [
    AccordionItem::new("gen", "General").content_height(4),
    AccordionItem::new("net", "Network").content_height(4),
    AccordionItem::new("x", "Locked").disabled(true),
];
let mut state = AccordionState::new().initially_open(["gen"]);
state.set_surface_focused(true);
state.set_cursor(Some("gen"));

// Recipes: section (multi), settings (single), logs (multi + keep-mounted), faq (single)
let acc = Accordion::settings(&items, &system)
    .max_content_height(8); // host nests ScrollArea in content rects

let parts = acc.paint(area, buf, &mut state);
if let Some(body) = parts.content_of(&"gen") {
    // paint domain UI; large bodies → ScrollArea::… inside body
}

// Interaction — navigation focus ≠ expanded
match acc.handle_key(&mut state, key) {
    AccordionOutcome::CursorMoved { to, .. } => { /* roving only */ }
    AccordionOutcome::Opened { id } | AccordionOutcome::ExclusiveOpened { id, .. } => { /* */ }
    AccordionOutcome::Closed { id } => { /* */ }
    AccordionOutcome::Ignored => {}
}

// Controlled open set each frame
let open = vec!["gen"];
let parts = Accordion::section(&items, &system)
    .open_ids(&open)
    .paint(area, buf, &mut state);
// outcomes Opened/Closed do not mutate state.open when controlled
```

## Focus model

| Layer | Meaning |
|-------|---------|
| `surface_focused` | Host gave keyboard ownership to the accordion |
| `roving` cursor | Navigation focus (active descendant) |
| `open` set | Expanded bodies — **independent** of cursor |

## Keys

| Input | Result |
|-------|--------|
| Up/Down, j/k | Move cursor |
| Home / End | First / last enabled |
| Printable | Typeahead jump |
| Enter / Space | Toggle expand on cursor |
| Right / Left | Expand / collapse cursor |
| Click trigger | Focus + toggle |

## Recipes

| Recipe | Mode | Trigger | Policy |
|--------|------|---------|--------|
| Section | Multiple | Section | Unmount |
| Settings | Single | Section | Unmount |
| Logs | Multiple | Inline | KeepMounted |
| FAQ | Single | Section | Unmount |

## Large content

`max_content_height` / per-item `content_height` size the content rect. Host
nests `ScrollArea` (or equivalent) inside open content — Accordion never owns
scroll offsets.

## Dynamic items

Stable IDs survive insert/remove/reorder. `reconcile_open` drops unknown open
ids; roving `reconcile` moves cursor off removed/disabled entries.
