# Composer and permission trust chrome

`PromptComposer` now paints a semantic sunken editor with the catalog-owned
`Glyph::Prompt` prefix. `PermissionPrompt` uses a muted focus-visible frame,
severity rail, and shared `ActionBar` chip treatment.

Remove consumer-owned composer backgrounds/prompt marks and permission severity
frames/action strips. Focus remains border color, never border weight. Existing
interaction and outcome contracts are unchanged.

Validate with `cargo test -p termrock prompt_composer`,
`cargo test -p termrock permission`, and `mise run gate`.
