# 0150 — KeybindingRecorder

## Mission

Settings control for capturing and validating user keybindings against
[`Keymap`](../crates/termrock/src/keymap.rs), reserved terminal hazards, and
neutral protocol limits. Escape law: **Esc always cancels recording**.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `KeyChord` / `KeyBinding` / `Keymap` / `remap` / `conflicts` | **Preserved** — source of truth |
| `format_chord` / `format_sequence` / `Kbd` / `ShortcutHint` / `ChordFormat` | **Preserved** — display |
| `raw_bytes_to_chord` | **Preserved** — PTY capture path |
| `HintBar` | **Preserved** — advertisement |
| KeyboardHelp (not yet shipped) | **Integrate later** via `binding_from_recorder` + Keymap |
| Prior recorder widget | **None** (greenfield) |
| `KeybindingRecorder` / `KeybindingRecorderState` / outcomes | **Added** |

## Consumer edits

```diff
+ use termrock::keymap::{KeyChord, Keymap};
+ use termrock::widgets::{
+     KeybindingRecorder, KeybindingRecorderOutcome, KeybindingRecorderState,
+     binding_from_recorder,
+ };

+ let mut state = KeybindingRecorderState::new("app.save", "Save")
+     .with_chords([KeyChord::ctrl(KeyCode::Char('s'))]);
+ state.load_occupied_from_keymap(&map, Action::Save, |a| format!("{a:?}"));
+ state.set_focused(true);

+ match state.handle_key(key) {
+     KeybindingRecorderOutcome::RecordingStarted => { /* steal focus / filter keys */ }
+     KeybindingRecorderOutcome::Committed { chords } => {
+         let _ = state.apply_to_keymap(&mut map, Action::Save);
+         let _ = chords;
+     }
+     KeybindingRecorderOutcome::RecordingCancelled { .. } => {}
+     KeybindingRecorderOutcome::ValidationFailed { limit } => { /* show limit */ }
+     KeybindingRecorderOutcome::RestoredDefault { .. } | KeybindingRecorderOutcome::Cleared => {}
+     _ => {}
+ }

+ KeybindingRecorder::new(&system).ascii(false).paint(area, buf, &mut state);

+ // KeyboardHelp / keymap row:
+ let binding = binding_from_recorder(&state, Action::Save, Visibility::Shown);
```

### Escape law

| Context | Esc |
|---------|-----|
| Recording | Cancel recording; restore committed value |
| Idle | `Blurred` (host moves focus) |

Never trap: no mode requires a non-Esc secret exit.

### Idle keys

| Key | Behavior |
|-----|----------|
| Enter / Space | Start recording |
| `r` | Restore default |
| Del / Backspace | Clear |
| Esc | Blur |

### Recording keys

| Key | Behavior |
|-----|----------|
| Esc | Cancel |
| Enter | Commit sequence |
| Backspace | Pop last chord |
| Other | Capture as `KeyChord` |

### Built-in reserved

Ctrl+C/Z/S/Q/`\` — terminal hazards (`default_reserved_chords`). Host extends
via `push_reserved` / `with_reserved`.
