# 0294 — Silent clips say what they held back

Three more lists stopped at a fixed count with nothing marking the cut, and two
maskers counted code points where they should have counted graphemes or
columns.

## Behavior changes

- **`Connectivity`** listed four offline capabilities and dropped the rest
  silently, while the queued-actions list directly above it already ended in
  `+N more`. The two now match.
- **`MetricsDashboard`** listed three alerts and dropped the rest. A dashboard
  that hides alerts without saying so is the one place this matters most; it
  paints `+N more` when the list is longer.
- **`HistoryPicker`'s `MaskMiddle` redaction** split by `chars()`, so a family
  emoji or a combining accent could be cut mid-cluster and leak half of
  itself. It masks by grapheme cluster now, and takes its ellipsis from the
  glyph catalog instead of a literal.
- **`SearchInput`'s status label** was capped at twelve *code points*; it is
  painted, so it is now capped at twelve display columns and a wide glyph
  counts for the two cells it spends.

## Consumer edits

- A host laying out around `Connectivity`'s or `MetricsDashboard`'s list gets
  one more row when the list is longer than the shown count.
- Snapshots of a `MaskMiddle` redaction over non-ASCII text change: the cut
  falls on a cluster boundary.

## Validation

```sh
cargo nextest run -p termrock --all-features connectivity history_picker search_input
mise run check
```
