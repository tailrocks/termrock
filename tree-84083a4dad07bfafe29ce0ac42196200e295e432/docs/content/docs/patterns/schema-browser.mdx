## Workflow

- `↑↓ select`: move visible focus, selection, pane, or hierarchy state for the next action.
- `←→ collapse/expand`: forward this normalized action to the mounted public pattern state.
- `Enter activate`: invoke the focused public state-machine action and inspect its typed request.
- `/ filter`: focus the real field and edit its persistent Unicode-safe draft.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.

## Migrated handbook guidance

# SchemaBrowser

Hierarchical catalog navigator for connections → databases → schemas →
tables/views → columns/indexes/constraints/routines. Host owns metadata fetch
and SQL; TermRock paints the tree and emits **typed requests**.

## Ownership

| Concern | Owner |
|---------|--------|
| Catalog introspection, reconnect | Host |
| Cursor, filter, presentation, expand preserve set | `SchemaBrowserState` |
| Children load / open query / DDL UI | Host via outcomes |

## Lazy expansion & preserve

1. Host projects flattened **visible** rows (`branch` + `TreeNodeStatus::Lazy`).
2. Expand → `LoadChildrenRequested` or `Toggle`.
3. `state.expanded` accumulates open branch ids.
4. On refresh/reconnect: reproject, then `apply_expanded_set(&mut entries, &state.expanded)` and `state.reconcile_expanded(&live_ids)`.
