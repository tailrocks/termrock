## Usage

The Code view above and this source excerpt use the exact paint setup registered for `skeleton/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn skeleton(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    frame.render_widget(Skeleton::new(4, system), area);
}
```
