## Usage

The Code view above and this source excerpt use the exact paint setup registered for `diff-review/hunks`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn diff_review_hunks(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let (lines, hunks, files) = diff_review_sample();
    let mut state = DiffReviewState::new();
    state.set_hunk_cursor(0);
    DiffReview::new(&lines, system)
        .hunks(&hunks)
        .files(&files)
        .title("PR · agent review")
        .render(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# DiffReview

Interactive review **on top of** [DiffView](/docs/components/diff-view). TermRock
owns selection, decisions, comments, focus regions, confirm banners, and undo
for session review ops. You own git staging, plan apply, agent policy, and
editor launch.


## When to use / when not

| Use DiffReview | Prefer |
|----------------|--------|
| Git / PR / agent patch review | — |
| Plan step accept/reject list | [PlanReview](/docs/components/plan-review) |
| Read-only viewing only | [DiffView](/docs/components/diff-view) |

## Ownership

| Concern | Owner |
|---------|--------|
| Surface focus | Host / scene |
| Scroll / mode / hunk cursor | `DiffReviewState.view` (`DiffViewState`) |
| Selection · decisions · comments · undo | `DiffReviewState` |
| VCS / apply / editor side effects | Consumer (outcomes only) |

## Outcomes (requests)

- `DecisionSet` / `ApproveRequested` / `RejectRequested` / `StageRequested` /
  `UnstageRequested` / `ApplyRequested`
- `CommentAdded` / `CommentResolved` / `CommentRemoved` / `CommentDraftChanged`
- `ExternalEditorRequested { path, line }`
- `ConfirmRequired` / `ConfirmCancelled` (safe verbs, no false VCS claims)
- `Undone` / `Redone`
- View-forwarded: `Scrolled` · `HunkCursorMoved` · `HunkActivated` · `ToggleMode` …

## Safe destructive language

Bulk reject/apply shows a confirm strip: `mark rejected 3 units? Enter=yes Esc=no`.
Verbs are `mark approved` / `request stage of` / `request apply of` — never
“committed” or “pushed”.
