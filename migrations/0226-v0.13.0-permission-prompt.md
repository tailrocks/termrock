# 0226 — PermissionPrompt Global trust surface

## Mission

Signature trust surface substantially better than a generic Allow dialog: who
initiated, provenance chain, exact operation, target, execution location,
accessed/transmitted data, destination, expected result, reversibility, risk,
requested scope. Allow once/session/project/always, deny, edit command/pattern,
restrict scope, inspect details, request changes. Concurrent request queue with
stale-generation protection. Safe initial focus; explicit destructive/data-egress
language. Exhaustive security and nested-subagent tests.

Research: Grok Build permissions, Amp plugin prompts, browser permissions, sudo,
security review UIs.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `PermissionPrompt` / `PermissionPromptState` / `PermissionQueue` | **Elevated** — checklist paint + helpers; security tests expanded |
| `PermissionRequest` / risk / scope / actions / outcomes | **Preserved** — full model already Global-shaped (0046/0077) |
| `PermissionProvenance` / hops / nested subagent | **Elevated** — `initiated_by`, `nest_depth` |
| `PermissionScope` | **Elevated** — `allow_label()` (`Allow once` … `Allow always`) |
| Stale generation / FIFO queue / audit | **Preserved** |
| Overlay `PERMISSION_OVERLAY_ID` trap | **Preserved** |
| Process/network I/O | **Never TermRock** |
| Legacy ApprovalCard | **Already removed** (historical) |

## Consumer API sketch

```rust
use termrock::widgets::{
    PermissionPrompt, PermissionPromptState, PermissionRequest, PermissionRisk,
    PermissionActionKind, PermissionScope, PermissionProvenance, ProvenanceHop,
    InitiatorKind, PermissionOutcome, PERMISSION_OVERLAY_ID,
};

let mut state = PermissionPromptState::new();
state.enqueue(
    PermissionRequest::new("r1", "bash", "workspace")
        .risk(PermissionRisk::High)
        .action_kind(PermissionActionKind::Shell)
        .provenance(
            PermissionProvenance::main_agent("main", "agent")
                .push(ProvenanceHop::new(InitiatorKind::Subagent, "s1", "reviewer"))
                .push(ProvenanceHop::new(InitiatorKind::McpServer, "fs", "filesystem")),
        )
        .command("rm -rf build/")
        .expected("remove build artifacts")
        .location("local", Some("sandbox:off".into()))
        .egress("https://api.example.com", "src/**")
        .irreversible()
        .scope(PermissionScope::Once),
);

// Host: state.set_accepts_input(stack.is_top(PERMISSION_OVERLAY_ID));
// PermissionPrompt::new(&system).render(area, buf, &mut state);

match state.handle_key(key) {
    PermissionOutcome::Decided { generation, action, scope, edited, .. } => {
        // Host enforces policy; ignore if not live
    }
    PermissionOutcome::StaleIgnored { .. } => { /* no grant */ }
    PermissionOutcome::Cancelled { .. } => { /* no grant */ }
    _ => {}
}
```

### Safety laws (unchanged, reaffirmed)

| Law | Behavior |
|-----|----------|
| Default cursor | **Deny** for all risks |
| Enter default | Denies, never Allows |
| `y` | Not bound to grant |
| Esc | Cancel without grant; advances queue |
| Stale generation | `StaleIgnored` — no grant |
| High/Critical strip | Deny before Allow |

### Keys

| Key | Action |
|-----|--------|
| ←/→ Tab | Action cursor |
| Enter | Confirm cursor action |
| Esc | Cancel / leave edit |
| n | Deny |
| d | Details toggle |
| e / p | Edit command / pattern |
| [ ] | Scope cycle once→session→project→always |
