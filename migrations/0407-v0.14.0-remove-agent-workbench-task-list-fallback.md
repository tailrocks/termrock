# 0407 — v0.14.0 remove AgentWorkbench task-list fallback and SettingsShell aliases

## Breaking change

Remote commit `628be0da` makes `TaskRail` the sole AgentWorkbench task
surface and removes the retired SettingsShell type aliases.

## AgentWorkbench

`WorkbenchKeyOutcome::TaskList` and `AgentWorkbenchState::task_list` are
removed. The legacy `legacy_tasks` and `tasks` inputs, the `empty_task_row`
helper, and the legacy list projection are removed as well. `task_models` is
now required: `AgentWorkbenchState::handle_key` accepts
`&[ActivityModel]`, and `WorkbenchSurfaces::task_models` accepts the required
slice used by `TaskRail`.

## SettingsScreen

The `SettingsShellOutcome` and `SettingsShellState` aliases are deleted and
are no longer re-exported. Use `SettingsScreenOutcome` and
`SettingsScreenState` directly.

## Consumer impact

Update AgentWorkbench hosts to provide a task-model slice, including an empty
slice when the rail has no tasks, and remove legacy list rows and the old
`handle_key` argument. Replace SettingsShell aliases with the canonical
SettingsScreen types. No compatibility aliases or fallback task surface
remain.
