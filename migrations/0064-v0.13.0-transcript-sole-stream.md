# 0064 — Transcript sole stream (Break J remainder)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `StreamView` | `Transcript` |
| `StreamItem` | `TranscriptBlock` (one or more lines) |
| `StreamItemKind` | `TranscriptKind` |

## Canonical replacement

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{Transcript, TranscriptBlock, TranscriptKind, TranscriptState};

let system = DesignSystem::default();
let user = ["Hello"];
let asst = ["Hi there", "second line"];
let blocks = [
    TranscriptBlock::new("u1", TranscriptKind::User, &user),
    TranscriptBlock::new("a1", TranscriptKind::Assistant, &asst),
];
let mut state = TranscriptState::new();
// Host gates keys; focused is paint/accepts-input chrome only.
state.set_focused(true);
let widget = Transcript::new(&blocks, &system)
    .focused(true)
    .ascii(false)
    .colorless(false);

// frame.render_stateful_widget(&widget, area, &mut state);
let _ = state.handle_key(key, &blocks);
// or intents:
// use termrock::interaction::{default_transcript_intent, UiIntent};
// if let Some(i) = default_transcript_intent(key) { state.handle_intent(i, &blocks); }
```

### Kind map

| StreamItemKind | TranscriptKind |
|----------------|----------------|
| User | User |
| Assistant | Assistant |
| Tool | Tool |
| System | System |
| Thinking | Thinking |

## Consumer edits

1. Delete `StreamView` / `StreamItem*` imports.
2. Project each turn to `TranscriptBlock` with stable `id` + `lines`.
3. Own scroll/follow via `TranscriptState` (follow default true).
4. Call `handle_key` only when the transcript owns scene focus.
5. Prefer `TranscriptKind` glyphs for non-color kind cues; use `.ascii(true)` / `.colorless(true)` under capability constraints.

## Workbench

`AgentWorkbenchState::handle_key` now takes `transcript` + `transcript_blocks` and routes when focus is `transcript`.
