# 0315 — Examples stop hand-rolling chrome

Plan 016 removed raw paint from `patterns/`. This closes the other half: the
places where an example still had its own answer to a question the widget layer
already answers — selection, notices, pending work, focus.

## Behavior changes

**Selection is chrome again.** `ConnectionManager`, `GitWorkbench` and
`ActivityShelf` painted the selected row as a full-width reversed slab, which
erased the row's own status: a failing connection and a healthy one looked
identical once selected. They now use the row recipe's tint plus weight, and
keep the reversed form only where it is the sole cue — a colorless terminal.

**`SettingsScreen`'s conflict banner is a `Callout`.** It was a full-width
warning-coloured string; it now states a title and a consequence with the
severity on its glyph. The screen's `colorless` flag is wired through instead
of being accepted and discarded.

**`AuthEntry` says when it is working.** A submit in flight painted nothing at
all while silently refusing input; it now shows the waiting glyph and
`Signing in…` / `Creating account…` / `Sending link…`. Host errors are a
`Callout` rather than a red line, and the duplicated field-error summary — which
leaked internal field ids like `identity: …` — is gone; a field states its own
problem inline, once.

**`SetupWizard` reads as data.** The capability report and the review summary
were flat single-tone rows; both are `KeyValueList` now, with labels strong,
findings quiet, and the severity on the row's status. The dead `if ascii { .. }
else { .. }` branches that returned the same string are removed.

**`Sidebar` focus stops being sticky.**

```rust
// Before: focus, once granted, could never be taken back.
state.nav.focused = self.focused || state.nav.focused;

// After: the host states focus every frame.
state.nav.focused = self.focused;
```

`Sidebar::new` also defaults to `focused: false` — a surface does not own focus
until its host says so.

**`AppDashboard`** takes its glyph profile from the design system instead of
hardcoding `.ascii(true)`, and states sidebar focus explicitly.

## Consumer edits

- A host that relied on `Sidebar` keeping focus after one `.focused(true)` must
  pass focus each frame; a host that never called `.focused(..)` and relied on
  the old `true` default must now opt in.
- Snapshots of a selected connection / branch / activity row: tint and weight,
  not a reversed slab.
- Snapshots of the settings banner, the auth error line, the wizard capability
  and summary lists: all now widget-composed.

## Gate

`design_gate.rs::patterns_compose_chrome` fails on `Role::Selection` anywhere
under `patterns/`, and on `Modifier::REVERSED` outside a colorless branch.

## Validation

```sh
cargo nextest run -p termrock --all-features --test design_gate patterns_compose_chrome
rg -n "\|\| state\.nav\.focused" crates/termrock/src/widgets/sidebar.rs   # → 0
mise run check
```
