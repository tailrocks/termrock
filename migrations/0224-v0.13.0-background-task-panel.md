# 0224 — BackgroundTaskPanel long-job monitor

## Mission

Persistent monitoring and control UI for detached commands, watchers, servers,
and long jobs: live output, status, restart count, ports/resources, elapsed,
follow/pause, stop, restart, detach, open, notifications. Reconnect and
lost-process states. Bounded output history with dropped-line indicators.
Compact rail row and full pane. **Process control is application-owned.**

Research: IDE task terminals, process supervisors, Grok Build watchers, Zellij.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TerminalOutput` / `TerminalLine` / `TerminalOutputState` | **Preserved** — detail stream paint + follow |
| `TerminalRunCard` | **Preserved** — single agent shell card |
| `ProcessTable` | **Preserved** — OS process monitor (signals) |
| `TaskRail` / `ActivityModel` | **Preserved** — bridge `background_task_to_activity` |
| `NotificationCenter` / Toast | **Preserved** — `background_task_to_notification` |

| `BackgroundTask` · buffer · panel state/outcomes | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    BackgroundTask, BackgroundTaskKind, BackgroundTaskStatus, BackgroundTaskPanel,
    BackgroundTaskPanelState, BackgroundTaskPanelOutcome, BackgroundOutputBuffer,
    BackgroundOutputLine, example_background_tasks, BACKGROUND_TASKS_OVERLAY_ID,
    background_task_to_activity, background_task_to_notification,
};

let mut task = BackgroundTask::new("b1", "cargo watch")
    .kind(BackgroundTaskKind::Watcher)
    .command("cargo watch -x test")
    .status(BackgroundTaskStatus::Running)
    .restart_count(2)
    .port("0")
    .resources("cpu 3%")
    .duration_ms(120_000)
    .notify_on_finish(true);

// Host appends output (bounded)
task.output.append(BackgroundOutputLine::stdout("1", "ok"));

let mut st = BackgroundTaskPanelState::new();
// BackgroundTaskPanel::new(&[task], &system).paint(area, buf, &mut st);

match st.handle_key(key, &tasks) {
    BackgroundTaskPanelOutcome::StopRequested { id } => { /* host stop */ }
    BackgroundTaskPanelOutcome::RestartRequested { id } => { /* host restart */ }
    BackgroundTaskPanelOutcome::DetachRequested { id } => { /* host detach UI */ }
    BackgroundTaskPanelOutcome::ClearCompleted { ids } => { /* host drop rows */ }
    BackgroundTaskPanelOutcome::FollowChanged { following } => {}
    BackgroundTaskPanelOutcome::Closed => { /* close drawer */ }
    BackgroundTaskPanelOutcome::Opened { id } => { /* focus task */ }
    _ => {}
}

// TaskRail / notifications
let _ = background_task_to_activity(&task);
if let Some(n) = background_task_to_notification(&task, now) { /* ingest */ }
```

### Status lifecycle

`Pending` · `Running` · `Reconnecting` · `Lost` · `Succeeded` · `Failed` ·
`Stopped` · `Detached`
