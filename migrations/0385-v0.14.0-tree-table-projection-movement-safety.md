# 0385 — v0.14.0 TreeTable projected movement safety

## Boundary

Directional movement uses physical insertion points when the cursor is on a
non-selectable row. Leading and trailing projection gaps no longer jump to an
unrelated selectable row: movement is inert at the logical boundary and
scrolls the virtual window when the requested direction has room.

## Consumer impact

No host API changes. Group, disabled, and loading rows can surround a slice
without corrupting selection identity or directional navigation.
