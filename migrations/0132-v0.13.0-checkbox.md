# 0132 — Checkbox (binary + tri-state)

## Mission

Robust form-field selection control: checked / unchecked / indeterminate,
disabled, invalid, read-only, label + description, Space/Activate + pointer hit
on the full root, ASCII and no-color marks, list/table composition, mixed-group
parent via `CheckboxValue::from_children`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Checkbox::new(id, label, system)` | **Preserved** shape; paint path upgraded |
| `CheckboxState::new(checked)` / `set_checked` / `is_checked` | **Preserved** |
| `CheckboxOutcome::ValueChanged { id, checked: bool }` | **Migrated** → `{ id, value: CheckboxValue }` |
| `render` / StatefulWidget | **Preserved** (calls `paint`) |
| `CheckboxValue`, `CheckboxParts`, description, invalid, read-only | **Added** |
| `Glyph::CheckMixed` / `GlyphSet::check_mixed` | **Added** |
| `Toggle` / `Switch` / list multi-select marks | **Preserved** (distinct roles) |

## Consumer edits

```diff
- match outcome {
-     CheckboxOutcome::ValueChanged { id, checked } => model.set(id, checked),
-     _ => {}
- }
+ match outcome {
+     CheckboxOutcome::ValueChanged { id, value } => {
+         model.set(id, value); // or value.as_bool() / value.is_checked()
+     }
+     _ => {}
+ }
```

```rust
// Tri-state / mixed group
let parent = CheckboxValue::from_children(children.iter().map(|c| c.checked));
state.set_value(parent);

// Description + invalid form field
Checkbox::new("tos", "I agree", &system)
    .description("Required to continue")
    .paint(area, buf, &mut state);
state.set_invalid(true);
```

## Behavior

| Concern | Rule |
|---------|------|
| Space / Enter | Activate when focused + enabled + not read-only |
| Indeterminate activate | → Checked |
| Checked activate | → Unchecked |
| Hit target | Full root (box + label + description) |
| ASCII / mono | `[x]` / `[ ]` / `[-]` always |
| Unicode | catalog ☑ ☐ ▣ |
| Narrow height 1 | Drop description |
| Tiny width | Box-first; label clips |
