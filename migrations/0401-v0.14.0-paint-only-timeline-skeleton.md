# 0401 — v0.14.0 Timeline paint contract and Skeleton consolidation

## Breaking change

`Timeline::render_stateful` is renamed to `paint`; its stateless `Widget`
dispatch is removed while the stateful adapter remains. The preceding
`Skeleton` consolidation is paint-only as well. No compatibility shims or
legacy render paths remain.

## Persistent-state paint paths

Keep each state value across frames, route input through it, then paint:

```rust
let mut timeline_state = TimelineState::new();
Timeline::with_events(&events, &system).paint(
    area,
    frame.buffer_mut(),
    &mut timeline_state,
);

let skeleton_state = SkeletonState::new();
Skeleton::recipe(SkeletonRecipe::Rows, 4, &system).paint(
    area,
    frame.buffer_mut(),
    &skeleton_state,
);
```

`TimelineState` owns cursor, viewport, filter, selection, expansion, and hit
regions. `SkeletonState` owns visibility and shimmer/activity state. Hosts must
retain those values and call `paint` directly on every frame; Timeline's
stateful adapter delegates to the same paint path.
