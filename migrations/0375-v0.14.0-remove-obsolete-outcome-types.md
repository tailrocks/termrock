# 0375 — v0.14.0 remove obsolete outcome types

## Boundary

The public widget namespace no longer exports `CalloutOutcome`,
`DataViewOutcome`, or `StreamingMarkdownOutcome`. These enums were declared
but no implementation constructed or matched on them, so removing them does
not change runtime behavior.

## Consumer migration

Remove imports and type references to the deleted enums. Use the outcome or
value type owned by the concrete surface:

- Callout interaction methods return `AlertOutcome<Id>`.
- Data views share value types such as `CopyPayload`, `FilterSpec`, and
  `SortSpec`; the interactive table surface returns
  `DataTableOutcome<RowId, ColId>`.
- Streaming markdown interaction methods return `MarkdownOutcome`.

No compatibility aliases are provided. Hosts must update their imports and
signatures to the current surface-specific contracts.

## Rollback

If a consumer still names one of these types, keep it on the previous release
or revert this removal until its imports and signatures are migrated. The
removed enums have no behavior to preserve, and no compatibility alias is
provided in this release.
