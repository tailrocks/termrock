# 0425: Preserve extended key modifiers

## Boundary

The backend-neutral keyboard contract preserves every Crossterm modifier bit
that the backend reports. `SUPER`, `HYPER`, and `META` must remain distinct
from one another and from Shift, Control, and Alt through event conversion and
key-chord matching.

## Change

`KeyModifiers` now models and validates the six Crossterm modifier bits:
Shift, Control, Alt, Super, Hyper, and Meta. The Crossterm adapter copies all
six bits, and `KeyChord::from(KeyEvent)` retains Super, Hyper, and Meta while
continuing to canonicalize Shift into the character value for `Char` keys.

Serialized modifier values may now use bits `0x08`, `0x10`, and `0x20`.
Unknown bits remain rejected. Keymaps that previously matched a plain or
three-modifier chord do not implicitly match an extended-modifier chord.

## Host migration

Hosts may bind extended modifiers by composing the public
`KeyModifiers::SUPER`, `HYPER`, and `META` constants (or the corresponding
`with_super`, `with_hyper`, and `with_meta` helpers). Review any serialized
keymaps that intentionally reject values above `0x07`; those values are now
valid only when they represent the six supported modifier bits.
