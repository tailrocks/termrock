# 0174 — Toast redesign

## Mission

Transient notifications with priority, actions, lifecycle, and non-disruptive
placement. Kinds: info/success/warning/error/progress/undo; persistent and
grouped; queueing, dedup, replace, timeout pause; never steals keyboard focus;
missed items archived for NotificationCenter.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Severity`, `Anchor` | **Preserved** |
| `Toast::new(system, msg, severity).anchor().margins().style().rect()` | **Preserved** |
| `Widget` for `Toast` / `&Toast` | **Preserved** (paint path upgraded) |
| `ToastLifetime::{Persistent,ExpiresAfter}` | **Preserved** |
| `ToastState::{new,show,dismiss,advance,is_visible,next_deadline,is_focusable}` | **Preserved** (+ `set_paused`) |
| TTL tests (2s expire / persistent) | **Preserved** |
| Stories `toast/success`, `narrow`, `unicode` | **Preserved** (+ new kinds/stack) |
| `ToastKind`, `ToastPriority`, `ToastSpec`, `ToastQueue`, `ToastStack` | **Added** |
| `ToastArchive` / `drain_missed` (NotificationCenter route) | **Added** |
| `TOAST_DEFAULT_TTL` (4s) | **Added** |
| Single-toast only host code | **Migrate** optionally → `ToastQueue` |

## Consumer edits

```diff
  use termrock::widgets::{Anchor, Severity, Toast, ToastLifetime, ToastState};
+ use termrock::widgets::{
+     ToastQueue, ToastSpec, ToastStack, ToastKind, ToastPriority, TOAST_DEFAULT_TTL,
+ };
  use termrock::runtime::FrameTick;

  // Single toast (unchanged)
  let toast = Toast::new(&system, "Saved", Severity::Success).anchor(Anchor::TopRight);
  let mut state = ToastState::new(ToastLifetime::ExpiresAfter(TOAST_DEFAULT_TTL));
  state.show(tick);
  if state.is_visible(tick) {
      toast.paint(area, buf); // or Widget::render
  }

  // Queue (recommended multi-toast host)
+ let mut queue = ToastQueue::new();
+ queue.set_anchor(Anchor::TopRight);
+ let _ = queue.push(tick, ToastSpec::message("save", "Saved").severity(Severity::Success));
+ let _ = queue.push(tick, ToastSpec::message("job", "Uploading").progress(40).group("upload"));
+ let _ = queue.push(tick, ToastSpec::message("del", "Deleted").undo("Undo"));
+ // hover over stack:
+ queue.set_paused(true); // freezes TTL
+ let _ = queue.advance(tick);
+ ToastStack::new(&system).paint(area, buf, &mut queue);
+ // NotificationCenter inbox:
+ let missed = queue.drain_missed();
```

### Rules

1. **Never focusable** — `ToastState::is_focusable() == false`; no focus trap.
2. **Non-disruptive** — small corner cards; no dim full-screen backdrop.
3. **Pause** — pointer over stack freezes TTL (`set_paused`).
4. **Missed** — expired/evicted entries go to `missed` for NotificationCenter.

### Stories

- `toast/success`, `narrow`, `unicode` (migrated)
- `toast/kinds`, `stack`, `persistent` (new)
