# 0256 — MetricRadar multi-axis comparison (shadcn radar peer)

## Mission

Close shadcn **radar** chart TUI gaps with an honest multi-metric peer:
axes × series as grouped horizontal bars (shared scale, legend, selection,
missing). Polar spider / circular grid remains **N/A**. Matrix:
`docs/design/shadcn-radar-charts-coverage.md`.

| Polar / spider / circular grid widgets | **Not added** — N/A |
| `BarSeries` / `Chart` | **Preserved** — single-dimension peers |
| `MetricAxis` · `MetricSeries` · `MetricRadar` | **Added** |

## Consumer API

```rust
use termrock::widgets::{MetricAxis, MetricRadar, MetricSeries, ScaleMode, VizGlyphSet};

let axes = [
    MetricAxis::new("cpu"),
    MetricAxis::new("mem"),
    MetricAxis::new("io"),
];
let prod = [72.0, 48.0, 90.0];
let stage = [55.0, 80.0, 40.0];
let series = [
    MetricSeries::new("prod", &prod),
    MetricSeries::new("stage", &stage),
];

MetricRadar::new(&axes, &series, &system)
    .title("capacity")
    .show_legend(true)
    .scale(ScaleMode::Fixed { min: 0.0, max: 100.0 })
    .glyphs(VizGlyphSet::Ascii)
    .selected_axis(0)
    .selected_series(1)
    .render(area, buf);
```

## Behavior

- Each axis is one row: label + one bar slot per series (1-col gap when multi).
- Domain from all finite series values (+ 0 baseline) under `ScaleMode`.
- Non-finite values paint the shared missing mark.
- Legend row: series marker + label (toggle with `show_legend`).
- Selection emphasizes axis label and/or series fill (ASCII `X` when selected).
