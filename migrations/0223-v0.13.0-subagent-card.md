# 0223 — SubagentCard delegated agent work

## Mission

Reusable representation of delegated agent work: role, task, parent/provenance,
status, model/mode, context, elapsed, progress, latest summary, output preview,
actions. Steer, message, inspect, cancel, retry, detach, promote result — as
**requests only** (no agent control). Live work vs completed artifact. Compact
row, card, fullscreen. Nested delegation readable.

Research: multi-agent products, Grok Build subagents, orchestration dashboards.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TaskRail` / `ActivityModel` / `ActivityScope::Subagent` | **Preserved** — inventory; bridge `subagent_to_activity_model` |
| `ActivityShelf` / `ActivityKind::Subagent` | **Preserved** |
| `ToolCallCard` | **Preserved** — tools ≠ subagents |
| `PermissionPrompt` provenance hops | **Preserved** — separate trust UI |
| `SemanticStatus` / `Card` | **Preserved** — status + chrome |
| Agent runtime / spawn / cancel process | **Never TermRock** |
| `SubagentRun` · `SubagentCard*` · phase · actions · project lines | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    SubagentRun, SubagentCard, SubagentCardState, SubagentCardOutcome,
    SubagentPresentation, SubagentPhase, SemanticStatus,
    example_subagent_runs, subagent_to_activity_model, project_subagent_lines,
    SUBAGENT_FULLSCREEN_OVERLAY_ID,
};

let run = SubagentRun::new("sa1", "reviewer", "review PR")
    .parent("main")
    .hop("main")
    .hop("sub:reviewer")
    .status(SemanticStatus::Running)
    .model("grok-4")
    .mode("plan")
    .context("24k · 6 tools")
    .elapsed("42s")
    .progress(55)
    .latest_summary("reading…")
    .output_preview("found 3 risks")
    .depth(1);

let mut st = SubagentCardState::new();
st.presentation = SubagentPresentation::Card;
// SubagentCard::new(&run, &system).paint(area, buf, &mut st);

match st.handle_key(key, &run) {
    SubagentCardOutcome::SteerRequested { id } => { /* host steer */ }
    SubagentCardOutcome::MessageRequested { id } => { /* host message */ }
    SubagentCardOutcome::InspectRequested { id } => { /* host inspect */ }
    SubagentCardOutcome::CancelRequested { id } => { /* host cancel */ }
    SubagentCardOutcome::RetryRequested { id } => { /* host retry */ }
    SubagentCardOutcome::DetachRequested { id } => { /* host detach */ }
    SubagentCardOutcome::PromoteResult { id } => { /* host promote */ }
    SubagentCardOutcome::FullscreenRequested { id } => {
        // overlay SUBAGENT_FULLSCREEN_OVERLAY_ID
    }
    SubagentCardOutcome::OpenParent { parent_id, .. } => { /* focus parent */ }
    _ => {}
}

// TaskRail inventory
let activity = subagent_to_activity_model(&run);
// MessageThread lines
let lines = project_subagent_lines(&run, st.is_expanded(), ascii);
```

### Live vs artifact

| Phase | When | Key actions |
|-------|------|-------------|
| `Live` | Running/queued/waiting | steer · message · cancel · detach |
| `Artifact` | Success/fail result | promote · retry (fail) · inspect |

### Keys

| Key | Action |
|-----|--------|
| Enter / Space | Toggle row ↔ card |
| s / m | Steer / message (live) |
| i | Inspect |
| c / r / d | Cancel / retry / detach (gated) |
| p | Promote result (artifact success) |
| f | Fullscreen |
| u | Open parent |
| Esc | Fullscreen → card |
