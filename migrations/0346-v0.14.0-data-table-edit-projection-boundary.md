# 0346: DataTable editing follows projected row and column availability

## Boundary

An inline edit draft is valid only while its projected row and column remain
available. Host filtering, paging, loading, or responsive projection may
remove either one between input events.

## Change

DataTable now cancels an edit safely when the visible row projection is empty,
and clears the draft when the current column disappears. Edit input no longer
indexes an empty row projection.

## Consumer impact

No consumer edit is required. Hosts receive `EditCancelled` when the edit
target is no longer present and can re-project normally.
