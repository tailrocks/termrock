# 0163 — KeyboardHelp

## Mission

Contextual, **generated** keyboard/interaction help from live keymaps, focus
zones, overlays, and semantic actions. Compact footer + searchable categorized
modal; conflicts and remaps; mouse equivalents; no stale hardcoded shortcuts.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `HintBar` / `Hint` / `HintSpan` | **Preserved** — footer paint atom |
| `ShortcutHint` / `Kbd` | **Preserved** — single chord display |
| `Keymap` / `KeyBinding` / `Conflict` | **Preserved** — generation source |
| `KeyboardHelp*` | **Added** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     KeyboardHelp, KeyboardHelpState, help_entries_from_keymap, merge_help_entries,
+     open_keyboard_help_overlay, filter_help_entries,
+ };

+ // Every frame: rebuild from live sources (never hardcode chords)
+ let mut entries = help_entries_from_keymap(&keymap, &system, |action, binding| { … });
+ entries = merge_help_entries([entries, help_entries_from_overlays(&stack)]);
+
+ // Footer strip
+ let mut state = KeyboardHelpState::new();
+ KeyboardHelp::new(&entries, &system).paint(footer_area, buf, &mut state);
+
+ // Modal (? key or host)
+ let _ = state.open_modal();
+ open_keyboard_help_overlay(&mut stack, bounds, Default::default(), Some(focus));
+ let visible = filter_help_entries(&entries, state.query_text());
+ KeyboardHelp::new(&visible, &system).paint(modal_area, buf, &mut state);
```

### Never-stale rule

Chord strings must come from `format_binding` / binding glyphs on the **current**
`Keymap` instance. Remaps via `Keymap::remap` appear automatically next frame.

### Stories

- `keyboard-help/footer`, `modal`, `search`, `tiny`, `ascii`
