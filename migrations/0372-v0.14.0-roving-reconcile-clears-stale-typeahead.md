# 0372: Roving reconciliation clears stale typeahead

## Boundary

When reconciliation changes the active identity because a row is removed or
disabled, the typeahead buffer must not carry text from the old active context.

## Change

Reconciliation now clears typeahead only when it changes active identity. Stable
projections keep their existing buffer so multi-character matching still works.

## Consumer impact

No consumer edit is required. Active-ID repair now starts typeahead from a clean
buffer while unchanged projections preserve normal typeahead behavior.
