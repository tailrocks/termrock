# 0129 — IconButton premium

## Mission

Compact glyph action with **mandatory** accessible labeling: tooltip/help
integration, toggle, badges, loading/disabled/destructive, toolbar recipes,
safe hit slop without stretching the visual glyph, ASCII + text fallbacks.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `IconButton::new(glyph, accessible_label, system)` | **Preserved** |
| `ActivationState` law (shared with Button) | **Preserved** |
| `IconButtonState` as alias of `ButtonState` | **Migrated** → dedicated state (hit/visual/toggle) |
| `render` | **Preserved** (calls `paint`) |
| `IconButtonParts`, size, badge, help, hit slop | **Added** |
| `toolbar_icon_action` | **Added** |
| `PanelAction::icon` | **Added** (optional) |

## API sketch

```rust
use termrock::widgets::{
    IconButton, IconButtonState, IconButtonSize, toolbar_icon_action, ActivationOutcome,
};

let mut state = IconButtonState::new();
state.activation.set_accepts_input(true);

IconButton::new("×", "Close", &system)
    .help("Close the dialog (Esc)")
    .ascii_glyph("x")
    .badge("3")
    .toggle(true)
    .paint(area, buf, &mut state);

// Hit uses slop (≥3); visual stays 1–2 cells
assert!(state.hit.unwrap().width >= 3);

// Toolbar projection: label kept for a11y even when icon paints
let item = toolbar_icon_action("close", "×", "Close");
```

## Hit slop

| Region | Role |
|--------|------|
| `visual` | Painted glyph (1–2 cols, centered) |
| `hit` | Pointer target ≥ `ICON_BUTTON_MIN_HIT` (3) without stretching glyph |

## Breaking note

Hosts using `IconButtonState` as `ButtonState` must switch to
`IconButtonState` and read `state.hit` instead of `state.region`.
