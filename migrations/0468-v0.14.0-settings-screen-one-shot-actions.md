# 0468: SettingsScreen physical one-shot actions

## Boundary

`SettingsScreenState::handle_key` is the pattern-level adapter for settings
overlay, persistence/discard, focus-region, drawer, reset, search, and footer
actions. Held keys must not repeat one-shot transitions or outcomes.

## Change

- Only `Press` events open or close help, save or discard, cycle the focus
  region, toggle the drawer, blur with `Esc`, reset, focus search, or emit
  footer actions.
- Delegated child surfaces retain their own lifecycle and repeatable navigation
  behavior.
- `Release` events remain ignored.

## Host migration

Hosts routing raw `SettingsScreen` events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize overlay, persistence, reset, search,
or footer outcomes from `Repeat` or `Release`.
