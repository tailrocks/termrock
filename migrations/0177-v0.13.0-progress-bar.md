# 0177 — ProgressBar redesign

## Mission

Determinate and indeterminate progress with percentage, units, rate, ETA,
phases, buffering, paused, cancelled, complete, and failed states. Compact /
detailed / multi-line recipes; tiny widths and ASCII/no-color; throttled
updates; task and transfer projection helpers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ProgressKind::{Determinate,Indeterminate}` | **Preserved** |
| `ProgressKind::indeterminate_from` | **Preserved** |
| `Progress::new` / `.label` / `.frames` / `Widget` | **Preserved** (`Progress` = `ProgressBar`) |
| Fill geometry tests (½ track, narrow %, CJK) | **Preserved** |
| `MIN_WIDTH_WITH_PERCENTAGE` (16) | **Preserved** (now public) |
| `ProgressBar`, `ProgressBarState`, status/recipe/unit | **Added** |
| Spinner (glyph activity) | **Unchanged** (separate) |

## Consumer edits

```diff
  use termrock::widgets::{Progress, ProgressKind};
+ use termrock::widgets::{
+     ProgressBar, ProgressBarState, ProgressRecipe, ProgressStatus, ProgressUnit,
+ };

  // Unchanged one-shot paint:
  Progress::new(ProgressKind::Determinate { fraction: 0.62 }, &system)
      .label("Build")
-     ; // Widget::render
+     .paint(area, buf);

  // Transfer / task model:
+ let mut state = ProgressBarState::transfer(done_bytes, total_bytes);
+ state.set_label("Download");
+ state.set_rate(Some(bytes_per_sec));
+ state.recompute_eta();
+ state.set_status(ProgressStatus::Running); // Paused | Buffering | Cancelled | Complete | Failed
+ state.set_recipe(ProgressRecipe::Detailed); // Compact | MultiLine
+ // throttle noisy updates:
+ state.set_value_throttled(new_value, Instant::now());
+ ProgressBar::paint_state(&system, area, buf, &mut state, tick, motion);
```

### Recipes

| Recipe | Layout |
|--------|--------|
| Compact | label + track + % (≥16 cols) |
| Detailed | + units/rate/ETA meta when wide |
| MultiLine | title / track / meta (3 rows) |

### Stories

- `progress/determinate`, `detailed`, `multi-line`, `failed`, `narrow`, `unicode`
