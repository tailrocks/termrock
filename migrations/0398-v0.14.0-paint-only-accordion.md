# 0398 — v0.14.0 paint-only Accordion

## Breaking change

`Accordion` no longer implements Ratatui's stateless `Widget` trait. The
removed implementations created a fresh `AccordionState` for each render,
discarding persistent open, focus, and geometry state.

No compatibility shim or legacy `render` path remains.

## Persistent-state paint path

Keep one `AccordionState` across frames, route input through the accordion,
then paint explicitly:

```rust
let mut accordion_state = AccordionState::new();
let parts = Accordion::section(&items, &system).paint(
    area,
    frame.buffer_mut(),
    &mut accordion_state,
);
```

Hosts retain the state for open ids, roving focus, cached parts, and hit
regions. Use `open_ids` on the accordion builder when expansion is controlled.
