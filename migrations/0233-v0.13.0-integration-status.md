# 0233 — IntegrationStatus MCP/plugin health surfaces

## Mission

Status and management for MCP servers, plugins, extensions, tools, and external
integrations: connected / disconnected / starting / error / permission required /
update available / disabled / degraded. Source, capabilities, permissions, last
error, logs, restart / enable / disable / details outcomes. Compact badges vs
full diagnostic panels. Explicit third-party provenance. Safe permission and
data-egress language. No process/network I/O — host owns lifecycle.

Research: Grok Build extension/MCP views, editor extension managers, service
health panels.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `connectivity` Offline/Reconnecting | **Preserved** — single remote target chrome |
| `PermissionPrompt` | **Preserved** — trust gates; open via `PermissionRequested` |
| `AgentStatusHeader` | **Preserved** — session chrome |
| `IntegrationStatus` / entries / presentations | **Added** |
| Nothing deleted | |

## API

```rust
use termrock::widgets::{
    IntegrationStatus, IntegrationStatusState, IntegrationStatusPresentation,
    IntegrationStatusOutcome, example_integrations,
};

let mut state = IntegrationStatusState::new();
state.set_entries(example_integrations());
// Badge | CompactList | Panel
IntegrationStatus::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    IntegrationStatusOutcome::RestartRequested { id } => { /* host restarts */ }
    IntegrationStatusOutcome::PermissionRequested { id, permission_id } => {
        /* open PermissionPrompt — never auto-grant */
    }
    IntegrationStatusOutcome::EnableRequested { id } => {}
    IntegrationStatusOutcome::DisableRequested { id } => {}
    IntegrationStatusOutcome::LogsRequested { id } => {}
    IntegrationStatusOutcome::UpdateRequested { id } => {}
    _ => {}
}
```
