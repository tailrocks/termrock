# 0411: Tree pointer focus synchronizes the collection bridge

## Boundary

Tree pointer regions can move focus without going through keyboard navigation.
Each click must update the tree cursor and the collection identity used by
typeahead.

## Change

TreeState now routes disclosure, checkbox, branch-row, and leaf-row pointer
focus through one helper. The helper synchronizes the cursor,
`CollectionState::active`, and follow-selection state. Leaf activation still
commits semantic selection only on the second click / activation path.

## Consumer impact

No consumer change is required. After clicking a row, subsequent typeahead
starts after the clicked identity, matching keyboard navigation and painted
pointer focus.
