# 0168 — Dialog redesign

## Mission

Canonical modal interaction surface: title, description, body, actions, close
policy, focus trap (OverlayStack), initial focus, opener restoration, scrolling
content, loading, and validation. Recipes: normal, compact, wide, fullscreen,
destructive. Enter/default and Escape without accidental submission. Nested
child overlays under the dialog; tiny-terminal promotion.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DIALOG_OVERLAY_ID`, `place_dialog`, `open_dialog_overlay`, `open_alert_dialog_overlay`, `dismiss_dialog_overlay` | **Preserved** |
| `DialogSize`, `DialogVariant`, `Backdrop` | **Preserved** |
| `Dialog::new` / `from_system` / `emphasis` / `variant` / `footer_hint` / `loading` + `Widget` | **Preserved** |
| `description`, `recipe`, `paint` + `DialogSlots` | **Added** |
| `DialogState`, `DialogOutcome`, `DialogClosePolicy`, `DialogFocusZone`, `DialogRecipe` | **Added** |
| `default_dialog_intent`, `open_dialog_configured`, `open_dialog_child_overlay` | **Added** |
| `ChoiceDialog` / `ChoiceDialogState` | **Migrated** (wraps `DialogState`; same `Outcome` API) |
| `MessageDialog` | **Preserved** (uses slot paint) |
| Duplicated modal open paths | **Consolidated** into `open_dialog_configured` |

## Consumer edits

```diff
  use termrock::widgets::{Dialog, ChoiceDialog, ChoiceDialogState, open_dialog_overlay};
+ use termrock::widgets::{
+     Dialog, DialogState, DialogRecipe, DialogClosePolicy, DialogFocusZone,
+     open_dialog_configured, open_dialog_child_overlay,
+ };

  // Chrome
  Dialog::new("Notice", Text::from("Saved"), &system)
+     .description("Optional subtitle")
+     .recipe(DialogRecipe::Normal)
      .footer_hint("esc dismiss");

  // Full engine
+ let mut state = DialogState::new();
+ state.set_close_policy(DialogClosePolicy::ConfirmOnly); // alert
+ state.set_initial_focus(DialogFocusZone::Actions);
+ state.set_default_action(Some("ok"));
+ state.set_validation_message(None);
+ // Enter from Body is ignored by default (no accidental submit)
+ state.set_require_action_focus_for_enter(true);
+ let _ = state.open_on_stack(&mut stack, bounds, DialogSize::default(), Some("trigger"));

  // Nested popover under dialog
+ open_dialog_child_overlay(&mut stack, bounds, anchor, size, "picker", Some("trigger"));
+ // dismiss dialog peels children

  // ChoiceDialog still works
  let mut choice = ChoiceDialogState::new(Some("accept"));
+ choice.dialog_mut().set_recipe(DialogRecipe::Destructive);
```

### Enter / Esc

| Context | Enter | Esc |
|---------|-------|-----|
| Action zone | Activate cursor / default | Dismiss if `Dismissible` |
| Body zone | **Ignored** (default; no accidental submit) | Same Esc policy |
| Loading / validation | Blocked | Esc still follows policy |
| `ConfirmOnly` | Action only | Trap unless `cancel_action` set |

### Recipes

`DialogRecipe::{Normal, Compact, Wide, Fullscreen, Destructive}` — tiny bounds
force Fullscreen via `dialog_recipe_for_bounds`.

### Stories

- `dialog/message`, `destructive`, `compact`, `narrow`, `unicode`
