# 0041 — Design inspector studio shell

## Canonical addition

`DesignInspector` multi-panel studio shell:

- `InspectorPanel::{Focus, Layers, Tokens, Recipes}`
- `DesignInspectorFrame` carries focus, layer, layers[], recipes[], density,
  capability, selection chrome

Height ≥ 2 paints a tab strip; body shows the selected panel.

`patterns::layout_studio_shell` / `StudioShellSlots` — preview + inspector +
optional knobs + status geometry for lookbook Studio.

## Consumer edits

```rust
let frame = DesignInspectorFrame {
    focused: Some("prompt"),
    layer: Some("approval"),
    capability: ColorCapability::Truecolor,
    density: "comfortable",
    layers: &["root", "approval"],
    recipes: &["list_row", "panel"],
    selection_chrome: "gutter",
};
DesignInspector::new(frame, &theme).panel(InspectorPanel::Layers)

let slots = layout_studio_shell(area, StudioShellLayout::default());
// paint preview in slots.preview, inspector in slots.inspector
```
