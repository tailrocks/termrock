# 0234 — WorkingStateCard privacy-safe agent work summary

## Mission

Transparent but non-invasive summary of what the agent is doing now: phase,
application-supplied public summary (never private chain-of-thought), files/
resources, elapsed, next expected action, cancel/inspect. Phases: planning,
searching, editing, running, waiting, reviewing. Collapse into ActivityShelf
when not expanded. Semantic description + no-color.

Research: agent status surfaces with privacy-preserving reasoning summaries.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ActivityShelf` / `ActivityItem` | **Preserved** — collapse target via `to_activity_item` |
| `ThinkingBlock` | **Preserved** — optional raw thinking chrome (host policy); not this card |
| `AgentStatusHeader` | **Preserved** — session chrome |
| `ToolCallCard` / `TerminalRunCard` | **Preserved** — inspect targets |
| `WorkingStateCard` / `WorkingState` | **Added** |
| Nothing deleted | |

## API

```rust
use termrock::widgets::{
    WorkingStateCard, WorkingStateCardState, WorkingState, WorkingPhase,
    WorkingStatePresentation, WorkingStateOutcome, example_working_state,
    merge_working_into_shelf,
};

let mut state = WorkingStateCardState::new();
state.set_work(Some(example_working_state()));
// summary is host-authored public text — never CoT
WorkingStateCard::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    WorkingStateOutcome::CancelRequested { id } => { /* stop */ }
    WorkingStateOutcome::InspectRequested { id } => { /* open tool card */ }
    WorkingStateOutcome::Collapsed => {
        if let Some(item) = state.to_activity_item() {
            // paint ActivityShelf with item
        }
    }
    _ => {}
}
```

### Privacy

| Rule | Detail |
|------|--------|
| Field name | `summary` (not thinking body) |
| Chrome title | `Working · {phase}` — never “thinking” |
| Semantic | “Agent status: …” |
| Host duty | Only pass user-safe summaries |
