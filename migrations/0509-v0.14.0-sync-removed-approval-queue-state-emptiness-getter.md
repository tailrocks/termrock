# 0509: Synchronize removed ApprovalQueueState emptiness getter

## Boundary

The dead-accessor sweep removed the unused `ApprovalQueueState::is_empty`
getter. The generated public API snapshot retained its signature even though
the getter is no longer available.

## Change

Removed the one stale snapshot entry for `ApprovalQueueState::is_empty`
deleted by `855e4147`.

## Host migration

Use `ApprovalQueueState::len` when a queue count is needed; derive emptiness
from that count at the host boundary. No compatibility alias or deprecation
period is provided.
