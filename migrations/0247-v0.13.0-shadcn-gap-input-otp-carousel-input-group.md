# 0247 — shadcn gap close: InputOtp, Carousel, InputGroup

## Mission

Close TUI-feasible **missing** rows from the shadcn → TermRock coverage matrix
(`docs/design/shadcn-termrock-coverage.md`): Input OTP, Carousel, Input Group.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` / `PasswordInput` / `NumberInput` | **Preserved** — not replaced |
| `PreviewCard` / `Popover` (Hover Card partial) | **Preserved** |
| `ComposedRow` / `ListRow` (Item partial) | **Preserved** |
| Dual “OTP via NumberInput only” product path | **Superseded** for PIN/OTP UX by `InputOtp` |
| `InputOtp`, `Carousel`, `InputGroup` | **Added** |

## Consumer API

```rust
use termrock::widgets::{
    InputOtp, InputOtpState, OtpCharset,
    Carousel, CarouselState, example_carousel_slides,
    InputGroup, InputGroupState, example_url_input_addons,
};

// OTP
let mut otp = InputOtpState::new(6);
match otp.handle_key(key) {
    InputOtpOutcome::Completed { value } => { /* host verify */ }
    _ => {}
}
InputOtp::new(&system).label("Code").paint(area, buf, &otp);

// Carousel
let slides = example_carousel_slides();
let mut car = CarouselState::new();
let _ = car.handle_key(key, &slides);
Carousel::new(&slides, &system).paint(area, buf, &car);

// Input group
let addons = example_url_input_addons();
let mut ig = InputGroupState::new();
ig.set_focused(true);
InputGroup::new(&addons, &system).placeholder("host").paint(area, buf, &mut ig);
```
