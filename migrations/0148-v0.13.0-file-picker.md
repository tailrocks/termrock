# 0148 — FilePicker

## Mission

Reusable file/directory browser composed from PathInput, CollectionState list
navigation, Selection multi-check, and OverlayStack dialogs. Hosts own all
filesystem (or SSH/remote) I/O with cancellable, generation-gated listings and
previews. No `std::fs` inside TermRock.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `PathInput` / `PathInputState` / `PathStyle` / path helpers | **Preserved** — embedded path field |
| `CollectionState` / `Selection` | **Preserved** — list focus + multi-check |
| `OverlaySpec::dialog` / `OverlayStack` | **Preserved** — modal presentation helpers |
| `Picker` | **Preserved** — domain-neutral query+list; not path/FS-shaped |
| `Tree` | **Preserved** — not required for FilePicker v1 list browser |
| `ResourceBrowser` pattern | **Preserved** — product pattern; FilePicker is neutral FS browser |
| Prior incomplete `file_picker.rs` draft (if any) | **Replaced** by this API |
| `FilePicker` / `FilePickerState` / `FilePickerOutcome` / entry model | **Added** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     FileEntry, FilePicker, FilePickerMode, FilePickerOutcome, FilePickerState,
+     FilePreview, FILE_PICKER_OVERLAY_ID,
+ };
+ use termrock::interaction::{OverlaySize, OverlayStack};

+ let mut state = FilePickerState::new("/home/u")
+     .with_mode(FilePickerMode::OpenFile)
+     .with_multi(false)
+     .with_preview(true);
+ state.set_focused(true);

+ // open modal (optional)
+ let _ = FilePickerState::open_overlay(
+     &mut stack,
+     terminal_bounds,
+     OverlaySize::dialog(72, 20),
+     Some(opener_focus),
+ );

+ // first paint / navigate: request listing
+ match state.request_list(state.cwd().to_owned()) {
+     FilePickerOutcome::ListRequested { path, generation } => {
+         // host: cancel previous; async list(path); then:
+         // state.apply_listing(generation, path, entries, None)
+         // or state.apply_listing_error(generation, msg)
+         let _ = (path, generation);
+     }
+     _ => {}
+ }

+ match state.handle_key(key) {
+     FilePickerOutcome::ListRequested { path, generation } => { /* host list */ }
+     FilePickerOutcome::PreviewRequested { path, generation } => {
+         // host preview; then state.apply_preview(...)
+         let _ = (path, generation);
+     }
+     FilePickerOutcome::FilterChanged => {
+         // hidden toggled (Ctrl+H) — re-list if host dropped hidden entries
+     }
+     FilePickerOutcome::Confirmed { paths } => { /* use paths */ }
+     FilePickerOutcome::Cancelled => {
+         let _ = FilePickerState::dismiss_overlay(&mut stack);
+     }
+     _ => {}
+ }

+ FilePicker::new(&system)
+     .title("Open file")
+     .ascii(false)
+     .paint(area, buf, &mut state);
```

### Ownership

| Concern | Owner |
|---------|--------|
| Listing, preview bytes, permissions, cancel tokens | Host |
| Entry kind / hidden / size / modified labels | Host projection |
| Filter (hidden, name), sort, multi-select, crumbs UI | FilePicker |
| Path typing / style | Embedded PathInput |
| Modal geometry | OverlayStack + host paint into overlay rect |

### Modes

| Mode | Selectable |
|------|------------|
| `OpenFile` / `SaveFile` | non-directories |
| `OpenDirectory` | directories |
| `OpenAny` | both |

Dirs always navigate (Enter/Right/double-click). Multi: Space toggles checks;
confirm uses checked set (or highlight fallback).

### Race gate

`apply_listing(generation, …)` / `apply_listing_error` ignore stale generations
(`generation != listing_generation()`).

### Keys (list pane)

| Key | Behavior |
|-----|----------|
| ↑/↓ | Roving highlight |
| Enter | Open dir or confirm file |
| Space | Multi toggle |
| Left / Backspace | Parent breadcrumb |
| Right | Open highlighted dir |
| Tab | Cycle List → Path → Preview |
| Ctrl+L | Focus path |
| Ctrl+H | Toggle show-hidden → `FilterChanged` |
| Esc | `Cancelled` |

Tiny terminals (`width < 48` or host fullscreen): presentation contracts;
preview drops under width/height thresholds.

### Stories

- `file-picker/unix`
- `file-picker/windows`
- `file-picker/ssh`
- `file-picker/no-preview`
