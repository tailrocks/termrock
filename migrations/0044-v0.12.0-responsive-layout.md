# 0044 — Responsive layout system

## Removed surface

None. This migration **adds** the public responsive-layout authority under
`termrock::layout` (re-exported at the crate root).

Ad-hoc per-widget width cutoffs for multi-pane / metadata / actions should
migrate toward [`ResponsiveSurface`] and [`AdaptiveAnatomy`] instead of new
magic numbers.

`Form` column selection now consults `ResponsiveSurface::Form.form_columns`
in addition to the existing minimum column-width floor.

## Canonical replacement

```rust
use termrock::{
    AdaptiveAnatomy, AnatomyPart, ContentPriority, ContractionStage,
    ResponsiveSurface, ViewportClass, WIDTH_LADDER, contract_parts,
};

// Classify host size
let class = ViewportClass::classify(term_width, term_height);
// or per surface:
let shell = ResponsiveSurface::AppShell.classify(term_width, term_height);

match shell.stage {
    ContractionStage::Full | ContractionStage::CompactSpacing => { /* full chrome */ }
    ContractionStage::SinglePane => { /* hide docked secondary */ }
    ContractionStage::DrawerOrOverlay => { /* open secondary as overlay */ }
    ContractionStage::LineMode => { /* essential-only line UI */ }
    _ => {}
}

if shell.anatomy.essential { /* always paint primary labels/actions */ }
if shell.anatomy.optional_meta { /* badges, shortcuts */ }
if shell.anatomy.secondary_actions { /* non-primary toolbar */ }
if shell.anatomy.multi_pane { /* split workspace */ }
if shell.anatomy.use_drawer { /* OverlayStack drawer */ }

// Declare parts; contract to budget
let parts = [
    AnatomyPart::essential("label", 24, 1),
    AnatomyPart::optional("meta", 12),
];
let visible = contract_parts(&parts, area.width, shell.anatomy);
```

### Law

**Primary labels and primary actions survive longer than decorative or
secondary information.** `ContentPriority::Essential` remains visible through
line-mode. Optional metadata and secondary actions drop earlier.

### Progression

1. Full anatomy  
2. Compact spacing  
3. Shortened secondary labels  
4. Hidden low-priority metadata  
5. Collapsed secondary actions  
6. Single-pane layout  
7. Drawer or overlay replacement  
8. Line-mode fallback  

### Width matrix

Test and validate against `WIDTH_LADDER`: 160, 120, 100, 80, 60, 40, 20.

## Exact consumer edits

1. Shells: own one `ViewportClass` / surface classify per frame (or on resize).  
2. Replace magic `if width < N` metadata drops with `anatomy.optional_meta` /
   `anatomy.secondary_actions` / `anatomy.multi_pane`.  
3. Prefer `contract_parts` or existing `ComposedRow` / `PanelSlots` for paint.  
4. When `use_drawer`, open secondary via `OverlayStack` instead of zero-width
   splits.  
5. Density: use `class.anatomy.density` or `stage.suggested_density()` for tokens.  

## Ownership

TermRock owns priority tiers, stage bands, surface policies, and contraction
helpers. Consumers own domain copy, which labels are essential vs optional, and
product-specific drawer content.
