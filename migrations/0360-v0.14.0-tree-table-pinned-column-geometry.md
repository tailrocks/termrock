# 0360: TreeTable pinned columns share physical geometry

## Boundary

`ColumnPin::Start` and `ColumnPin::End` are positional contracts. Horizontal
scrolling applies only to the unpinned center strip, and header hits must use
the same rectangles as body cells.

## Change

TreeTable now resolves one physical rectangle per painted column. Start pins
anchor from the left, end pins anchor from the right, and center columns scroll
between them. The same rectangles drive header paint, header hit regions, and
body paint; pinned widths no longer inflate the horizontal scroll range.

## Consumer impact

No consumer edit is required. Existing pin declarations now produce their
declared edge placement and stable header hit geometry.
