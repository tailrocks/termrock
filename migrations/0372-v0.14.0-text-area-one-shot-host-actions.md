# 0372 — v0.14.0 TextArea host actions run once per physical key press

## Boundary

TextArea host-facing actions no longer repeat while a key is held. Enter from
idle, clipboard requests, external-editor requests, and fullscreen requests
respond only to a physical key press. Text insertion and caret navigation
remain repeatable.

## Host migration

No host API changed. Hosts may continue routing TextArea key events directly;
they receive one-shot outcomes only for `KeyEventKind::Press`.
