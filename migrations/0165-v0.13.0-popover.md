# 0165 — Popover redesign

## Mission

Anchored non-modal (default) interactive surface for settings, filters,
pickers, and details — with explicit modality, collision placement via
[`OverlayStack`], outside/Esc dismissal, nested overlays, opener restoration,
presentation contraction (anchored → drawer → fullscreen), and header/body/footer
slots **without** forcing `Panel`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `POPOVER_OVERLAY_ID` | **Preserved** (`"termrock.popover"`) |
| `place_popover(bounds, anchor, size)` | **Preserved** |
| `open_popover_overlay(…)` | **Preserved** (non-modal default) |
| `OverlayKind::Popover` default policy | **Preserved** (owns input, Esc/outside dismiss, no trap, no dim) |
| `Popover::new(title, system)` + `Widget` | **Preserved** (title paints as header; elevated fill + border) |
| `Popover` thin title-only chrome in `menu_nav` | **Deleted** (moved to `popover` module) |
| `PopoverState`, `PopoverOutcome`, slots, modality, nested open | **Added** |
| `open_popover_modal_overlay`, `open_popover_nested_overlay`, `open_popover_configured`, `open_popover_with_presentation` | **Added** |
| `popover_presentation_for`, `PopoverPresentation` | **Added** (contract to drawer/fullscreen) |
| Implementation home | **Moved** `menu_nav` → `popover` module |

```diff
+ };

  let mut stack = OverlayStack::new();
  let bounds = /* terminal */;
  let anchor = /* trigger rect */;

- let _ = open_popover_overlay(&mut stack, bounds, anchor, size, Some("trigger"));
- Widget::render(&Popover::new("Tip", &system), stack.top().unwrap().rect, buf);

+ let mut state = PopoverState::new(); // or PopoverState::modal()
+ let out = state.open_on_stack(&mut stack, bounds, anchor, size, Some("trigger"));
+ // or: open_popover_overlay / open_popover_modal_overlay / open_popover_configured
+
+ if let Some(entry) = stack.top() {
+     Popover::new("Settings", &system)
+         .footer(Some("esc · close"))

+     // Host paints domain widgets into state.slots().body (and header/footer).
+ }

+ state.sync_with_stack(&stack, &OverlayId::from_static(POPOVER_OVERLAY_ID));
```

### Modality

| `PopoverModality` | Stack policy |
|-------------------|--------------|
| `NonModal` (default) | Popover kind: Esc/outside dismiss, owns input, **no** focus trap, no dim |
| `Modal` | Focus trap, dim backdrop, outside **trap**, may fullscreen on narrow |

### Presentation contraction

`popover_presentation_for(bounds, preferred)` returns:

| Condition | Presentation |
|-----------|--------------|
| Fits | `Anchored` |
| Width ≤ 40, height room | `Drawer` |
| Height tight / both tight / preferred larger than bounds | `Fullscreen` |

Hosts reflow with `open_popover_configured` or `PopoverState::sync_presentation`.

### Slots (no forced Panel)

```rust
Popover::slots(&system)
    .header(Some("Filters"))
    .footer(Some("esc"))
    .border(true) // optional
    .paint(overlay_rect, buf, &mut state);
let PopoverSlots { header, body, footer, .. } = state.slots();
// paint domain content into body
```

### Nested overlays

```rust
open_popover_nested_overlay(
    &mut stack, bounds, child_anchor, size,
    POPOVER_OVERLAY_ID, // parent id
    Some("trigger"),
);
// Dismissing parent cascades children via OverlayStack.
```
