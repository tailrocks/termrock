# 0355: TreeTable rejects toggles on disabled rows

## Boundary

TreeTable multi-select toggles must honor the same row eligibility contract as
keyboard space and pointer selection paths.

## Change

`TreeTableState::handle_intent(UiIntent::Toggle)` now returns `Ignored` for a
disabled cursor row instead of adding or removing that row from the
`SelectionModel`.

## Consumer impact

No consumer edit is required. Disabled rows remain visible but cannot mutate
multi-select state through semantic toggle intents.
