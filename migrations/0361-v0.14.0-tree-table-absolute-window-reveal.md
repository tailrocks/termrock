# 0361: TreeTable reveals projected rows in absolute window space

## Boundary

TreeTable hosts may pass only the flattened slice addressed by
`VirtualWindow::visible_range()`. `cursor_row` is local to that slice, while
`VirtualWindow::offset` is a logical absolute index.

## Change

Cursor reveal now computes `window.offset + cursor_row` before calling
`VirtualWindow::reveal`. Reconciliation and movement no longer reset a
scrolled projected slice toward logical row zero.

## Consumer impact

No consumer edit is required. Hosts that project from `window.visible_range()`
retain their current logical offset across selection reconciliation and local
cursor movement.
