# 0331 — Jackin parity handoff

**Version:** `v0.14.0`
**Kind:** additive + behavioral + migration guidance

TermRock now contains the reusable capabilities and visual-regression contract
needed to migrate Jackin from revision
`5ff94ee117fd4a1b72fdd0d1b1847815055a93ac`.

## Consumer migration

Jackin's inventoried TermRock usage has a current public export or an explicit
forward replacement. Migrate imports directly to the current modules; do not
add compatibility facades. In particular, replace the old root theme with
`termrock::style::RolePalette`, normally
`RolePalette::tailrocks_phosphor()`, and follow the earlier numbered
migrations for renamed APIs.

Two formerly host-local generic capabilities are public:

- Implement `TerminalCellSource` for an emulator or terminal snapshot, return
  borrowed `TerminalCell` values, then paint it with
  `TerminalCellGrid::new(&source)`. The widget clips to its Ratatui area,
  preserves style and diff metadata, and clears cells absent from a shrinking
  source.
- Replace host-local immediately-ready blocking adapters with
  `ReadySubscription::new(value)` or `ready_subscription(value)`. The first
  `poll_next()` returns `Ready(value)` and later polls return `Closed`; the
  adapter is fused, executor-neutral, and performs no spawning or blocking.

Jackin product assemblies remain consumer-owned. BrandHeader, digital rain,
launch animation, and other brand/domain compositions must not move into
`termrock::widgets`. Neutral parts use TermRock primitives; multi-widget
product recipes remain application code or `termrock::patterns` examples.

## Visual contract

The default phosphor presentation retains current interaction improvements
while restoring the selected old-revision details explicitly chosen during
review:

- Tabs use the focus-aware selected rule and keep the selection background
  wash; see migrations 0327 and 0329.
- ChoiceDialog centers actions, keeps them horizontal when their measured
  labels and chrome fit, and stacks only on real horizontal overflow; see
  migrations 0328 and 0330.

Other old-revision differences are evidence, not implicit requirements. A
future visual restoration needs its own deliberate change and migration.

## PNG regression workflow

The Jackin-used widget subset has committed phosphor PNG baselines rendered
from Ratatui buffers by `termrock-raster` with pinned JetBrains Mono fonts.
The comparison predicate is decoded pixels at zero tolerance, not encoded PNG
bytes.

Run:

```sh
mise run png-baselines
```

After an intentional paint change, inspect the rendered difference, then:

```sh
mise run bless-pngs
```

Commit every changed baseline in the same pull request. A platform-only
mismatch with no intended paint change is a raster pipeline defect and must
not be blessed.

The historical side harness and roadmap comparison reports are audit tools;
they are not runtime dependencies or consumer migration requirements.
