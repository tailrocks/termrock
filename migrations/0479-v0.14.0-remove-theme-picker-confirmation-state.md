# 0479: Remove write-only ThemePicker confirmation state

## Boundary

The orphan-purge tranche removed every reader and writer for
`ThemePickerState::confirmed`, leaving a private `Option` initialized only to
`None`. The state is not part of selection, activation, or theme resolution.

## Change

- Remove the dead `confirmed` field and initializer.
- Synchronize the generated API snapshot after tranche 2 removed the related
  `clear_confirmed`, `confirm_id`, and `confirmed` methods.

## Host migration

Hosts must use `ThemePickerOutcome::ConfirmIndex` from activation and resolve
the selected preset explicitly. No compatibility alias or deprecation period
is provided.
