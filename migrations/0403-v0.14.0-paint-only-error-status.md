# 0403 — v0.14.0 ErrorState and StatusIndicator use one paint path

## Breaking change

`ErrorState::paint(area, buffer, &mut ErrorStateState)` is now its only entry;
the passive paint, `paint_with_state`, and stateless `Widget` implementations
are removed. `StatusIndicator::paint(area, buffer, Option<&StatusIndicatorState>)`
is also the only entry; its passive paint, `paint_with_state`, and stateless
`Widget` implementations are removed. No compatibility shims remain.

## Consumer impact

Keep error interaction state across frames. Pass `None` to StatusIndicator when
the host has no clock state:

```rust
let mut error_state = ErrorStateState::new();
error.paint(area, frame.buffer_mut(), &mut error_state);
status.paint(area, frame.buffer_mut(), None);
```

Block error recipes read persistent disclosure and focus state through the same
paint path.
