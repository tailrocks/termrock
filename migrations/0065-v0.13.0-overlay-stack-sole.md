# 0065 — OverlayStack sole overlay authority (Break D / M4)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| Public `ModalStack` | Host domain state + [`OverlayStack`] |
| Public `ModalClickResult` / `classify_click` | `OverlayStack::handle_outside_click` |
| Private `OverlayHost` / `EscCascade` / `OverlayController` | `OverlayStack` |
| FocusRing `open_modal(&mut ModalStack, …)` | `push_modal_scope` / `pop_modal_scope` (crate-private ring) |

**Kept public:** `render_backdrop` paint helper — call only when `stack.backdrop_policy() != BackdropPolicy::None` (or host equivalent).

## Canonical replacement

```rust
use termrock::interaction::{
    OverlayId, OverlayOutcome, OverlaySize, OverlaySpec, OverlayStack, BackdropPolicy,
    render_backdrop,
};
use termrock::widgets::open_dialog_overlay;

let mut stack = OverlayStack::<FocusId>::new();
let bounds = terminal_area;
let _ = open_dialog_overlay(&mut stack, bounds, preferred, Some(opener));

// Esc: overlay before scene
match stack.handle_escape() {
    OverlayOutcome::Dismissed { focus, .. } => { /* restore focus */ }
    OverlayOutcome::Ignored => { /* trap — e.g. permission cancel path */ }
    OverlayOutcome::UnhandledEscape => { /* scene.handle_escape() */ }
    _ => {}
}

// Paint
stack.reflow(bounds);
if stack.backdrop_policy() != BackdropPolicy::None {
    render_backdrop(frame, bounds);
}
// then paint top entry content into stack.top().rect
```

## Lookbook / hosts

Replace `ModalStack<T>` with `OverlayStack` + `Option<T>` domain payload. Register every floating UI via `stack.open`.
