# 0231 — PromptQueue editable agent prompt queue

## Mission

Visible, editable queue of user messages waiting behind active agent work:
queued / sending / blocked / failed / cancelled / sent; reorder, edit, delete,
send next, interrupt-and-send. Clear busy semantics. Preserve attachment and
mention identities. Compact composer summary + expanded manager. **Persistence
and drain policy stay host-owned** (KD-29: library does not auto-drain on
fail/cancel).

Research: async chat products, agent prompt queues, task schedulers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `PromptComposer` draft / chips / submit policy | **Preserved** |
| Thin in-composer queue FIFO + status `queue:N` | **Preserved** (enqueue chrome) |
| `QueuedPrompt { id, text, chip_ids }` struct body | **Migrated** → [`PromptQueueItem`] (re-export alias `QueuedPrompt`) |
| OverlayStack queue | **Preserved** (unrelated focus FIFO) |
| `PromptQueue` / `PromptQueueState` / statuses / compact+expanded | **Added** |
| Auto-drain on fail/cancel | **Never** in library |

## Breaking API

```rust
// Before
let entry = QueuedPrompt { id, text, chip_ids };
// entry.chip_ids field

// After
use termrock::widgets::{
    PromptQueue, PromptQueueItem, PromptQueueState, PromptQueuePresentation,
    PromptQueueOutcome, AgentBusyState, example_prompt_queue, QueuedPrompt,
};

// QueuedPrompt is type alias for PromptQueueItem
let entry = PromptQueueItem::from_text_and_chip_ids(id, text, chip_ids);
// or rich:
let entry = PromptQueueItem::new(id, text)
    .attachments(vec![/* PromptQueueRef */])
    .mentions(vec![]);
let ids = entry.chip_ids(); // method

// Management UI
let mut q = PromptQueueState::new();
q.set_items(example_prompt_queue());
q.set_agent(AgentBusyState::Busy);
q.presentation = PromptQueuePresentation::Expanded;
PromptQueue::new(&system).paint(area, buf, &mut q);

// Composer bridge
let mut projected = composer.project_prompt_queue(true);
```

### Outcomes (requests only)

| Outcome | Meaning |
|---------|---------|
| `SendNext` / `SendFront` | Host sends |
| `InterruptAndSend` | Interrupt run then send |
| `Edited` / `Deleted` / `Reordered` | Host persists |
| `Retry` | Failed entry |
| Presentation Expanded/Compact | UI only |

### Keys (expanded)
