# 0300 — The accent budget

`Role::Accent` was spent on ambient chrome: permanent mode bands, every search
match, every hint, every running step, filter rows painted end to end in the
brand green. The design language reserves it for the operator's *current
intent* — the one live or primary thing on screen
(`docs/design/termrock-design-language.md` §3, law 1.1).

## Value changes

| Site | Before | Now |
|---|---|---|
| `HighlightKind::Match` (unselected) | `Warning` | `TextStrong` — a page of matches is not a page of warnings |
| `HighlightKind::Soft` | `Info` | `TextMuted` |
| `DiagnosticSeverity::{Hint, Help}` | `Accent` | `Info` |
| `ProgressStepStatus::{Running, Retrying}` | `Accent` | `InfoDim` |
| `ProgressKind::{Running, Buffering}` | `Accent` | `InfoDim` |
| `TerminalRunStatus::Running` | `Accent` | `InfoDim` |
| `SearchResultKind::Object` | `Accent` | `Info` |
| `ModeRibbon` active chip | `Accent` | `TextStrong` (its brackets already mark it) |
| `WorkingState::{Editing, Running}` | `Accent` | `InfoDim` |
| `BackgroundTaskStatus::Running` | `Accent` | `InfoDim` |

Accent that survives is intent-gated: a selected row's gutter, a focused
control's cue, an active sort column, the resize chevrons *while* resizing.
`PromptComposer`'s caret is accent only while the composer accepts input — a
blocked composer is not the current intent.

`TraceWaterfall` and `DependencyGraph` filter rows painted `/query_` end to end
in accent. They now read as text on a `Sunken` well with accent on the caret
cell alone.

## Gate

`design_gate.rs::accent_budget` renders a list and a status bar under phosphor
and counts cells whose foreground or background is the reserved accent.

Measured after this sweep: a 60×12 list with a selected row spends **one**
accent cell (its gutter mark); a three-slot status bar spends **none**. The
budget is set at 8 — room for a focused control's chip, not for a flood.
Raising it is a design decision, not a test fix.

## Consumer edits

- A host matching on any role above gets the new value; re-pin snapshots that
  asserted the brand green on running work, hints, or search matches.
- A host that relied on unselected matches being `Warning`-colored should set
  the highlight style explicitly.

## Validation

```sh
cargo nextest run -p termrock --all-features --test design_gate accent_budget
mise run check
```
