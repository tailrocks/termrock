# 0250 — Sidebar collapse filter + sectioned nav fixture

## Mission

Close shadcn **sidebar** blocks (sidebar-01…07) on the existing Sidebar peer:
document coverage, ship [`filter_nav_collapsed`] for TUI-honest nested hide when
sections/groups are collapsed, wire filter into NavigationList key/paint paths,
and add `example_sectioned_sidebar_nav`.

Matrix: `docs/design/shadcn-sidebar-blocks-coverage.md`.

## Consumer API

```rust
use termrock::widgets::{
    filter_nav_collapsed, example_sectioned_sidebar_nav, Sidebar, SidebarState,
    SidebarOutcome, NavItem,
};

let mut tree = example_sectioned_sidebar_nav();
let mut state = SidebarState::new(Some("intro"));
// Keys use collapse filter internally:
match state.handle_key(key, &tree) {
    SidebarOutcome::ExpandToggled { id, expanded } => {
        // host mutates full tree
        if let Some(n) = tree.iter_mut().find(|i| i.id == id) {
            n.expanded = expanded;
        }
    }
    SidebarOutcome::Selected(route) => { /* host navigate */ }
    SidebarOutcome::ToggleRail { .. } => { /* chrome */ }
    SidebarOutcome::OpenDrawer | SidebarOutcome::OpenPalette => { /* host */ }
    SidebarOutcome::ContextMenuRequested { id } => { /* dropdown peer */ }
    _ => {}
}

// Pure helper for host projection:
let visible = filter_nav_collapsed(&tree);
```
