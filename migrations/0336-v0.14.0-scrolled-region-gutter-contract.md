# 0336 — Scrolled-region gutter contract

**Version:** `v0.14.0`
**Kind:** breaking API cleanup

`paint_scrolled_region` never used its `content` rectangle. It only paints the
list-style scrollbar in the supplied gutter, so the unused rectangle was
removed from the public contract and all core callers.

## Canonical signature

Before:

```rust
scroll::paint_scrolled_region(
    buffer,
    content,
    gutter,
    total,
    viewport,
    offset,
    system,
);
```

After:

```rust
scroll::paint_scrolled_region(buffer, gutter, total, viewport, offset, system);
```

The painter does not mutate or style `content`; pass only the reserved gutter
rectangle. Use `paint_overflow_scrollbar` for junie line-cell scrollbar
geometry.
