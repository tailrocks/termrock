# 0034 — Unified InteractionScene

## Removed surface

Public re-exports of parallel interaction authorities:

- `termrock::OverlayController`, `OverlayEscResult`
- `termrock::interaction::{EscCascade, EscLayer, EscOutcome}`
- `termrock::interaction::{OverlayHost, OverlayId, OverlayKind, OverlayLayer}`
- `termrock::interaction::{OverlayController, OverlayEscResult}`

`OverlayHost::dismiss_top_esc` no longer peels a lower dismissible layer under a
non-dismissible top (legacy rposition bug).

Migration `0033` is VirtualGrid resident projection; this boundary is `0034`.

## Canonical replacement

```rust
use termrock::{
    InteractionElement, InteractionLayer, InteractionOutcome, InteractionScene,
    LayerDismissPolicy, LayerKind, dispatch_keymap_action,
};

let mut scene = InteractionScene::<&str, &str, MyAction>::new();
scene.ensure_root(InteractionLayer {
    id: "root",
    kind: LayerKind::Root,
    owns_input: true,
    esc: LayerDismissPolicy::Ignore,
    outside: LayerDismissPolicy::Ignore,
    focus_return: None,
});
scene.begin_frame();
scene.register(
    InteractionElement::control("ok", "root", rect).actions(vec![MyAction::Confirm]),
)?;
scene.reconcile();

// Esc: dismiss top if Dismissible, ignore if Trap, UnhandledEscape on root.
match scene.handle_escape() {
    InteractionOutcome::LayerDismissed { layer, focus } => { /* … */ }
    InteractionOutcome::UnhandledEscape => { /* consumer quit policy */ }
    InteractionOutcome::Ignored => { /* trapped */ }
    _ => {}
}

// Keymap + availability (same set as hints/palette):
let outcome = dispatch_keymap_action(&scene, &keymap, key);
```

Lifecycle each frame:

1. `begin_frame` (clears elements; keeps focus + layers)
2. ensure root / push overlays as needed
3. `register` painted elements with actions
4. `reconcile` focus
5. route keys (`handle_key_tab_esc`, `dispatch_keymap_action`) and mouse
6. paint using `focused()` / hit geometry

## Exact consumer edits

1. Replace `OverlayController` + `EscCascade` + ad-hoc focus glue with one
   `InteractionScene`.
2. On Esc, handle `UnhandledEscape` for quit — TermRock never invents Quit.
3. Non-dismissible dialogs use `LayerDismissPolicy::Trap` so lower menus cannot
   be peeled while the dialog is topmost.
4. Advertise actions only when valid; disabled actions vanish from
   `available_actions` and `dispatch_keymap_action` together.
5. `FocusRing` remains available for lookbook migration; new shells should use
   the scene focus API.

## Ownership

TermRock owns focus reconciliation, hit order, layer Esc/outside policy, and
action availability projection. Consumers own quit, effects, domain actions,
and paint payloads.
