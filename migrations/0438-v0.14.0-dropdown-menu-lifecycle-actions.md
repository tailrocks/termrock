# 0438: DropdownMenu lifecycle actions

## Boundary

`DropdownMenuState::handle_key` treats activation, dismissal, cascade
transitions, and typeahead as distinct physical-key paths. A held key must not
reopen nested panels, peel multiple layers, toggle a menu item, or feed a
press-only key into typeahead.

## Change

- Press Enter, Space, and Escape perform menu activation, toggling, or
  dismissal. Repeat and Release are ignored before frame reconciliation.
- Press Right/Left and `l`/`h` open or close cascade layers. Repeat and Release
  cannot repeat those transitions; `h`/`l` remain available for typeahead when
  no cascade transition applies.
- `typeahead_buffer()` now reports the active collection frame's roving buffer,
  removing the stale duplicate mirror. Failed multi-character prefixes and
  layer transitions therefore expose the same buffer the cursor uses.
- PageUp/PageDown map to repeatable collection page intents. Ordinary vertical
  navigation and printable typeahead remain repeatable; Release remains a
  no-op.

## Host migration

Hosts routing raw DropdownMenu events must continue passing the complete
`KeyEvent`, including its lifecycle kind. Do not synthesize repeated activation,
dismissal, cascade, or toggle outcomes for Repeat or Release events. Semantic
`handle_intent` remains phase-free; adapters converting physical events to
one-shot intents must retain the Press gate.
