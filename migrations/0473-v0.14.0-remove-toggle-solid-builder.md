# 0473: Remove the zero-reference `Toggle::solid` builder

## Boundary

`Toggle::solid` was a public fluent builder with no call sites in the complete
workspace corpus. Its removal narrows the API to exercised construction paths.

## Change

- Remove `Toggle::solid` completely.
- Preserve `ToggleRecipe::Solid` and the explicit `.recipe(ToggleRecipe::Solid)`
  builder path for callers that need the solid recipe.

## Host migration

Consumers calling `Toggle::solid()` must select the recipe explicitly:

```rust
Toggle::new(label, system).recipe(ToggleRecipe::Solid)
```

No compatibility alias or deprecation period is provided.
