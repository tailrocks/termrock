# 0058 — Category-leading Tree redesign

## Removed surface

- Hardcoded disclosure glyphs `"▾"` / `"▸"` outside the glyph catalog.
- Hardcoded multi-select markers `"[x] "` / `"[ ] "`.
- Fixed indent of `depth * 2` ignoring density and narrow contraction.
- Empty tree paint as a silent no-op only (no empty message).
- Cancel/Esc intent mapped only to `Ignored` (no typed cancel).

## Canonical replacement

| Concept | API |
|---------|-----|
| Fluent nodes | `TreeNode::new` + `.branch/.expanded/.leading/.secondary/.badge/.shortcut/.trailing/.disabled/.loading/.error/.with_status` |
| Paint root | `Tree::new` or `Tree::from_system` |
| Empty | `Tree::empty_message(&str)` |
| Recipes | `resolve_list_row` / selection gutter + focus underline (shared with List) |
| Indent | `Density::tree_indent` (2/1/1) with narrow collapse to 1 then 0 |
| Disclosure | `GlyphSet::disclosure_open/closed` |
| Checks | `GlyphSet::check_on/off` via `ListRowRecipe` |
| Cancel | `TreeOutcome::Cancelled` |

Expansion remains **consumer-owned**: `TreeOutcome::Toggle(id)` requests disclosure
inversion; Tree never mutates `expanded` itself.

## Consumer edits

### Fluent nodes

```rust
// Before
TreeNode {
    id: "src",
    label: Line::from("src"),
    leading: None,
    secondary: None,
    badge: None,
    shortcut: None,
    trailing: None,
    depth: 1,
    branch: true,
    expanded: true,
    enabled: true,
    status: TreeNodeStatus::Ready,
}

// After
TreeNode::new("src", Line::from("src"), 1).branch().expanded()
```

### Empty tree

```rust
Tree::from_system(&[], &system).empty_message("No files")
```

### Cancel

```rust
match state.handle_intent(&nodes, UiIntent::Cancel) {
    TreeOutcome::Cancelled => { /* dismiss pane / clear focus */ }
    other => { /* … */ }
}
```

### Density indent

Comfortable = 2 cells/depth, Compact/Dashboard = 1. Narrow viewports clamp indent
further. Prefer `DesignSystem::phosphor()` / density-aware tokens.

## Removed concepts

None of the prior public method names were deleted. Behavior changes:

- Selected rows may paint a selection gutter (`▌` / `>`) like List.
- Multi-select uses catalog glyphs; buffer snapshots that assumed `[x]` need update.
- Esc/Cancel yields `TreeOutcome::Cancelled`.

## Ownership

Unchanged: consumer owns flattened projection, expansion, filtering, and effects.
Tree owns selection, multi-check, scroll, hover, hit regions, and typed outcomes.
