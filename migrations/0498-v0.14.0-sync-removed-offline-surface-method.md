# 0498: Synchronize removed OfflineSurface semantic method

## Boundary

The semantic-registration sweep removed the unused semantic adapter from
`OfflineSurface`. The generated public API snapshot retained its signature
even though the method is no longer available.

## Change

Removed the one stale snapshot entry for
`OfflineSurface::register_semantic` deleted by `6faa9fb0`.

## Host migration

Use `OfflineSurface::paint` with the host-owned `ReconnectingState`. Semantic
registration is no longer provided by this surface. No compatibility alias or
deprecation period is provided.
