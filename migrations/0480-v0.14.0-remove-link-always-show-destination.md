# 0480: Remove the orphan Link destination convenience builder

## Boundary

`Link::always_show_destination` had no repository caller and duplicated the
general `destination_display` builder. The explicit policy enum is the single
composable API for choosing destination visibility.

## Change

- Remove `Link::always_show_destination`.
- Use `Link::destination_display(DestinationDisplay::Always)` when destination
  text must always be shown.

## Host migration

Replace:

```rust
link.always_show_destination()
```

with:

```rust
link.destination_display(DestinationDisplay::Always)
```

No compatibility alias or deprecation period is provided.
