# 0341 — VirtualGrid width-policy freshness

**Version:** `v0.14.0`  
**Kind:** behavioral

`VirtualGrid` now invalidates auto-resolved column widths when the caller
changes a width policy, available content width, or column count. A same-size
column-list update no longer leaves stale header and cell geometry in the
rendered frame.

Widths supplied through `VirtualGridState::set_column_widths` remain explicit
caller-owned overrides. Auto-resolved widths and explicit overrides are now
tracked separately, so a later render cannot silently replace a persisted
host choice.
