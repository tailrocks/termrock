# Overlay and picker recipe rows

MenuBar panels and CommandPalette now use the canonical overlay `Surface`.
CommandPalette query input uses the semantic sunken band. Menu, palette,
QuickOpen, HistoryPicker, FilePicker, Select, and MultiSelect row owners resolve
selection through the shared list-row recipe instead of reverse-video or neon
selection slabs.

`Picker` continues to delegate rows to `List`; `Combobox` continues to delegate
its popup to `CompletionMenu`. Consumers should remove local selection-color
overrides and supply semantic state only. Public constructors and state models
are unchanged.

Before:

```rust
let style = system.style(Role::Selection);
```

After:

```rust
let recipe = system.resolve_list_row(visual_state);
```

Validate with targeted widget tests and `mise run gate`.
