# 0482: Remove write-only row and diff fields

## Boundary

`DiffSyntaxSpan::_tag` and `ListRowRecipe::show_gutter_slot` were public fields
with no readers. Their values could be supplied by a host but could not affect
diff painting or row layout, leaving misleading configuration surface.

## Change

- Remove `DiffSyntaxSpan::_tag`; syntax spans retain their range and semantic
  role.
- Remove the unused `DiffSyntaxSpan<'a>` lifetime; use `DiffSyntaxSpan` in
  annotations and slices.
- Remove `ListRowRecipe::show_gutter_slot`; list rows always use the canonical
  reserved gutter defined by the recipe's `gutter` field.

## Host migration

Delete struct-literal assignments to either field. No replacement is needed:
`DiffSyntaxSpan::new(start, end, role)` remains the constructor, and gutter
reservation is fixed by the shared row recipe.

No compatibility alias or deprecation period is provided.
