# 0374: Roving typeahead folds Unicode case

## Boundary

Roving typeahead's case-insensitive matching must work for Unicode labels and
input, not only ASCII text.

## Change

Typeahead now uses Unicode-aware lowercase folding for its buffer and entry
labels.

## Consumer impact

No consumer edit is required. Existing ASCII matching remains unchanged, while
labels such as `Éclair` now match lowercase `é` input.
