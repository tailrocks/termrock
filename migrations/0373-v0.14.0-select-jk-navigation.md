# 0373 — v0.14.0 non-searchable Select reserves j/k for list navigation

## Boundary

Focused non-searchable Select no longer opens from plain `j`, `k`, `J`, or `K`.
When open, those unmodified keys move the active option without wrapping.
Searchable Select keeps its existing typeahead behavior. Arrow navigation keeps
the collection's configured wrap policy.

## Host migration

No host API changed. Hosts that used these unmodified characters to open a
non-searchable Select should bind activation to Enter or Space instead.
