# 0238 — SetupWizard (onboarding) first-run block

## Mission

Premium first-run / onboarding flow for terminal apps: welcome, capability
check, account/connection, choices, validation, permissions, theme preview,
summary, and recovery. Composes **FormWizard** + **Stepper** (and Form,
EmptyState, ThemePicker, PermissionPrompt). Keyboard-only completion, resume
via `WizardProgress`, **safe two-step cancel**, inline and fullscreen modes.
No marketing splash screens. Auth, persistence, and grants stay **host-owned**.

Research: CLI installers, Huh, cloud auth flows, native onboarding.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `FormWizard` / `FormWizardState` / `WizardProgress` | **Preserved** — embedded chrome |
| `Stepper` / `StepItem` | **Preserved** — via FormWizard |
| `Form` / `EmptyState` / `ThemePicker` / `PermissionPrompt` | **Preserved** — body composition |
| Thin `blocks::FormWizard` (already elevated 0151) | Unchanged |
| `SetupWizardState` / `render_setup_wizard` / step kinds | **Added** |
| Domain values / OAuth / disk | **Host-owned** |

## Consumer API

```rust
use termrock::patterns::{
    SetupWizardState, SetupWizardSurfaces, SetupWizardMode, SetupStepKind,
    example_setup_steps, example_capability_lines, example_setup_summary_lines,
    example_setup_account_fields, render_setup_wizard, layout_setup_wizard,
};
use termrock::widgets::{Fieldset, WizardGate, BUILTIN_THEME_PRESETS};

let mut state = SetupWizardState::from_steps(example_setup_steps())
    .with_title("First run")
    .with_mode(SetupWizardMode::Fullscreen);

// Resume
// state.resume(&saved_progress);

// each frame — host picks fieldsets by current step kind
let fields = example_setup_account_fields();
let fieldsets = [Fieldset::new("Account", &fields)];
let caps = example_capability_lines();
let summary = example_setup_summary_lines();

render_setup_wizard(buf, area, SetupWizardSurfaces {
    system: &system,
    state: &mut state,
    fieldsets: &fieldsets,
    capabilities: &caps,
    summary_lines: &summary,
    welcome_title: "Setup",
    welcome_detail: "Configure once. Keyboard-first.",
    theme_presets: BUILTIN_THEME_PRESETS,
    theme_paint: Some(&preview_system),
    permission: None,
});

match state.handle_key(key, &fieldsets, BUILTIN_THEME_PRESETS) {
    SetupWizardOutcome::Finished => { /* host activate product */ }
    SetupWizardOutcome::CancelConfirmed => { /* host exit setup */ }
    SetupWizardOutcome::CancelConfirmOpen => { /* paint already shows strip */ }
    SetupWizardOutcome::Wizard(FormWizardOutcome::ProgressSaved { progress }) => {
        host.persist(progress);
    }
    SetupWizardOutcome::Form(out) => { /* field activation */ }
    SetupWizardOutcome::Theme(out) => { /* live preview */ }
    _ => {}
}
```

### Step kinds

`Welcome` · `Capability` · `Account` · `Connection` · `Choices` · `Validation` ·
`Permission` · `Theme` · `Summary` · `Recovery` · `Custom`

### Modes

| Mode | Behavior |
|------|----------|
| `Fullscreen` | Slight margin; full first-run root |
| `Inline` | Fill host pane; stepper may contract |

### Laws

| Law | Detail |
|-----|--------|
| Safe cancel | Esc opens confirm; Enter/y confirms; Esc/n stays |
| Resume | `WizardProgress` only — domain values host reloads |
| Gates | Host projects `WizardGate`; Account default Invalid |
| Density | No marketing multi-paragraph splash |
