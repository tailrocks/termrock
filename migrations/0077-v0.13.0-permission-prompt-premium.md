# 0077 — PermissionPrompt premium (cursor + accepts_input)

## Removed / renamed

| Removed | Replacement |
|---------|-------------|
| `PermissionOutcome::SelectionChanged` | `ActionCursorMoved` (decision) or `ScopeChanged` (scope) |
| Primary `selected()` naming | `action_cursor()` (`selected()` deprecated) |
| Ungated keys when overlay not top | `set_accepts_input` |

## Added

| API | Role |
|-----|------|
| `accepts_input` / `set_accepts_input` | Host/overlay gate |
| `PermissionPrompt::{focused, colorless}` | Surface chrome + a11y |
| Intent-first `handle_key` | Uses `default_permission_intent` then product chords |
| Action cursor non-color marks | `›` / `>` |
| Narrow vertical action stack | Responsive |
| Empty `∅` / `[ ]` mark | Empty queue |

## Safety preserved

- Default action cursor is **Deny** for all risks
- `y` not bound to Allow
- Esc cancels without grant
- Stale generation protection

## Consumer edits

```rust
// Before
PermissionOutcome::SelectionChanged => redraw(),
let a = state.selected();

// After
PermissionOutcome::ActionCursorMoved | PermissionOutcome::ScopeChanged => redraw(),
let a = state.action_cursor();
state.set_accepts_input(stack.is_top(PERMISSION_OVERLAY_ID));
```
