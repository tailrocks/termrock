# 0093 — ComponentContract and registry metadata

## Mission

Kernel-owned `ComponentContract` schema v3, validation, official catalog, and
`termrock contract` CLI. Complements (does not replace) quality axes JSON v1/v2.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Quality contracts JSON | **Preserve** |
| Fixture `entry.json` schema 1 | **Preserve** for install |
| New `termrock::registry` | **Added** |

## Added

| API | Role |
|-----|------|
| `RegistryItemKind` | primitive…template |
| `ComponentContract` | Full metadata |
| `validate_contracts` | CI |
| `official_kernel_contracts` | Embedded catalog |
| `termrock contract list\|check` | Tooling |

## Consumer edits

```rust
use termrock::registry::{
    official_kernel_contracts, validate_contracts, ComponentContract, RegistryItemKind,
};

let catalog = official_kernel_contracts();
assert!(validate_contracts(&catalog).ok());
let panel = catalog.iter().find(|c| c.id == "Panel").unwrap();
assert_eq!(panel.kind, RegistryItemKind::Primitive);
```

```bash
termrock contract check
```

## Validation

```bash
cargo test -p termrock --all-features --lib registry
cargo run -p termrock-cli -- contract check
```
