# 0091 — TerminalCapabilities and CapabilityBoundary

## Mission

First-class progressive enhancement: resolve capabilities, project themes, and
drive widgets without env reads in paint. Pure inject path for PTY tests.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `EffectiveCapabilities` | **Alias** of `TerminalCapabilities` |
| Profiles / set / doctor / CLI doctor | **Preserve** |
| New | `CapabilityBoundary`, `detect_from_hints`, `resolve_from_detection` |

## Added

| API | Role |
|-----|------|
| `TerminalCapabilities` | Primary resolved model |
| `TerminalCapabilities::{detect,resolve,for_profile,with_hints,boundary}` | Host API |
| `CapabilityBoundary` | Widget progressive-enhancement contract |
| `ComponentCapabilityHints` | colorless / ascii / mouse / … |
| `detect_from_hints` / `EnvHints::fixture*` | Pure detection |
| `resolve_from_detection` | Pure resolve |

## Consumer edits

```rust
use termrock::capability::{
    TerminalCapabilities, CapabilityBoundary, CapabilityProfile, CapabilityOverrides,
    EnvHints,
};

// Production
let caps = TerminalCapabilities::resolve(None, CapabilityOverrides::from_env_keys(
    std::env::var("TERMROCK_COLOR").ok().as_deref(),
    std::env::var("TERMROCK_GLYPHS").ok().as_deref(),
    std::env::var("TERMROCK_PROFILE").ok().as_deref(),
));
let boundary = caps.boundary();
let system = boundary.project_system(DesignSystem::default());
let session = caps.session_flags(); // or boundary.session_flags()

// Widget paint
let hints = boundary.component_hints();
widget.ascii(hints.ascii).colorless(hints.colorless);

// Tests / PTY
let caps = TerminalCapabilities::with_hints(
    EnvHints::fixture("xterm-256color", Some("truecolor"), true),
    Some(CapabilityProfile::Modern),
    CapabilityOverrides::default(),
);
assert!(caps.boundary().colorless()); // NO_COLOR
```
