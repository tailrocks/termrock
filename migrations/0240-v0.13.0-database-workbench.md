# 0240 — DatabaseWorkbench composition block

## Mission

Source-owned **database application composition** demonstrating TermRock data
widgets: connection inventory, schema browser, query tabs/editor, result grid,
object inspector, history, status bar, command palette, and export/copy actions.
Focus zones, responsive density collapse, typed run/cancel/error/transaction/
disconnect messages. Host owns protocol clients, pools, vaults, and result
pages — no sockets or SQL drivers inside the pattern.

Research: TablePlus, DataGrip, pgcli/lazysql-style tools, high-quality developer
workbenches (experience only; not product clones).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ConnectionManager` / `ConnectionManagerState` | **Preserved** — composed (launcher presentation) |
| `SchemaBrowser` / `QueryEditor` / `ResultGrid` / `ObjectInspector` | **Preserved** — paint delegated |
| `HistoryPicker` / `CommandPalette` / `StatusBar` | **Preserved** — overlays + chrome |
| `AgentWorkbench` | **Preserved** — agent domain, not DB |
| Local re-implementation of child paint | **Forbidden** |
| SQL client / vault / TcpStream | **Host-owned** — never in pattern |
| `DatabaseWorkbenchState` · `render_database_workbench` | **Added** (`patterns/database_workbench`) |

## Consumer API

```rust
use termrock::patterns::{
    DatabaseWorkbenchState, DatabaseWorkbenchSurfaces, DatabaseWorkbenchDensity,
    DatabaseWorkbenchOutcome, DatabaseConnGate, DatabaseTxStatus,
    example_schema_entries, example_result_columns, example_result_rows,
    example_result_row_refs, example_inspect_fields, example_db_history,
    example_db_commands, render_database_workbench, database_workbench_layout_density,
};

let mut state = DatabaseWorkbenchState::new();
// state.density = Some(DatabaseWorkbenchDensity::Narrow);
// state.set_conn_gate(DatabaseConnGate::Disconnected);

let schema = example_schema_entries();
let cols = example_result_columns();
let data = example_result_rows();
let mut cells = Vec::new();
let rows = example_result_row_refs(&data, &mut cells);
let inspect = example_inspect_fields();
let history = example_db_history();
let commands = example_db_commands();

render_database_workbench(buf, area, DatabaseWorkbenchSurfaces {
    system: &system,
    state: &mut state,
    schema_entries: &schema,
    result_columns: &cols,
    result_rows: &rows,
    inspect_fields: &inspect,
    history: &history,
    commands: &commands,
});

match state.handle_key(key, &schema, &history, &commands, rows.len()) {
    DatabaseWorkbenchOutcome::RunRequested { tab_id, text, .. } => {
        state.begin_run("run-1");
        // host execute; then finish_run_success / finish_run_error
    }
    DatabaseWorkbenchOutcome::CancelRequested { run_id, .. } => { /* host cancel */ }
    DatabaseWorkbenchOutcome::RunBlocked { reason, .. } => { /* toast gate */ }
    DatabaseWorkbenchOutcome::ExportRequested { format, visible_rows, .. } => {
        // host serializes page — outcome carries no row bodies
    }
    DatabaseWorkbenchOutcome::CopyRequested { kind, .. } => { /* clipboard policy */ }
    _ => {}
}
```

### Densities

| Density | Width default | Visible panes |
|---------|---------------|---------------|
| `Normal` | ≥ 88 | Connections · Schema · Query · Results · Inspector · Status |
| `Narrow` | 48–87 | Connections · Schema · Query · Results · Status (no inspector) |
| `Tiny` | < 48 | Query · Results · Status |

### Laws

| Law | Detail |
|-----|--------|
| Public only | Pattern imports public widgets + layout; no local visual substitutes |
| Host I/O | Run/cancel/export are requests; no SQL/network/vault |
| Disconnect gate | `DatabaseConnGate` blocks run when not Connected |
| Export | `ExportRequested` carries format + counts, never full result payload |
| Esc | Leaves overlay or returns focus to query; root `Cancelled` |
| Focus | Tab cycles density-visible zones |

## Second-pass design review

**Decisions**

1. **Pattern module** next to AgentWorkbench — composition block, not a new widget paint engine.
2. **Gate run at workbench** — child QueryEditor may still emit RunRequested; workbench rewrites to RunBlocked when disconnected.
3. **Export/copy outcomes omit row bodies** — host serializes; prevents accidental secret dumps in logs.
4. **Compose ConnectionManager** rather than fork connection UI.

**Rejected**

- Embedding sqlx/postgres/SSH clients.
- Monolithic paint that reimplements ResultGrid/SchemaBrowser.
- Auto-run on tab switch.
- Bulk export without gate.

**Residual limits**

- Per-tab results not fully multi-buffered (single ResultGridState; host may swap).
- Inspector field projection is host-supplied (not auto-bound to cell selection in v1).
- PTY not required; unit + structural gates cover interaction.
