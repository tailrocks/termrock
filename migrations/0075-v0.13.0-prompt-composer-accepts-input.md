# 0075 — PromptComposer accepts_input (scene/overlay gate)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `PromptComposerState::set_focused` (primary) | `set_accepts_input` (`set_focused` deprecated) |
| `PromptComposerState::is_focused` (primary) | `accepts_input` (`is_focused` deprecated) |
| Internal `focused` field | `accepts_input` |
| Internal `chip_focus` | `chip_cursor` |

## Added

| API | Role |
|-----|------|
| `set_accepts_input` / `accepts_input` | Host gates keys when overlay steals input |
| `handle_intent` | Submit / Cancel peel |
| `default_prompt_composer_intent` | Bare Enter/Esc map |

## Consumer edits

```rust
// Before
state.set_focused(false); // permission open
if state.is_focused() { … }

// After
state.set_accepts_input(false);
if state.accepts_input() { … }
// Draft still preserved
```

```rust
// Optional intent path
if let Some(i) = default_prompt_composer_intent(key) {
    let _ = state.handle_intent(i);
}
```
