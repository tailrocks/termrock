# 0387: TreeTable routes shifted page keys

## Boundary

TreeTable must not discard Shift-modified vertical and page intents that remain
valid list navigation.

## Change

Only Shift+Left/Right and `h`/`j`/`l` hierarchy chords bypass the default list
intent map. Shift+Up/Down/PageUp/PageDown now retain their vertical semantics.

## Consumer impact

No consumer edit is required. Shifted page and vertical keys work through
empty virtual projections while hierarchy chords retain their existing policy.
