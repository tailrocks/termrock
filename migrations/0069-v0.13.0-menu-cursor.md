# 0069 — Menu / Sidebar cursor vs scene focus

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `MenuOutcome::FocusChanged` | `MenuOutcome::CursorMoved` |
| `MenuState::focus_index` (primary) | `cursor_index` (`focus_index` deprecated) |
| `SidebarState::focus_index` | `cursor_index` |
| Ungated menu keys | `accepts_input` / `set_accepts_input` |

## Added

| API | Role |
|-----|------|
| `Menu::focused` / `ascii` / `colorless` | Surface chrome |
| `handle_intent` / `default_menu_intent` | Intent-first nav |
| `handle_mouse` | Click / wheel |
| Non-color cursor / check / disabled marks | Accessibility |

## Consumer edits

```rust
// Before
MenuOutcome::FocusChanged => …
let i = state.focus_index();

// After
MenuOutcome::CursorMoved => …
let i = state.cursor_index();
Menu::new(&items, &system).focused(true).ascii(false);
```
