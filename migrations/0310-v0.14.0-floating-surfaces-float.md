# 0310 — Floating surfaces actually float

Two overlays had the wrong amount of chrome. `Tooltip` gave its `Rich` variant
an elevated fill and gave `Plain` and `Shortcut` nothing at all — bare text
written straight over whatever live content sat underneath, legible or not.
`Drawer` drew all four border edges *and* a handle column at the docked edge,
so the seam against the host pane carried three vertical rules.

## Behavior changes

**`Tooltip`** — every variant now paints an overlay surface: elevated fill, a
quiet `Role::Border` outline, and one cell of inset. The tooltip is a floating
thing and reads like one over any background.

This costs geometry, and callers size tooltips themselves:

```rust
use termrock::widgets::{TOOLTIP_CHROME_COLS, TOOLTIP_CHROME_ROWS};

// A one-line tooltip needs three rows now, not one.
let height = 1 + TOOLTIP_CHROME_ROWS;
```

`TooltipContent::measure_cols` already includes `TOOLTIP_CHROME_COLS`, so a
caller sizing from it needs no change; a caller that hardcoded a height does.

**`Drawer`** — the docked edge is borderless. The handle column was already
the rule at that seam, and the border stacked on top of it and on the host
pane's own edge. A right-docked drawer draws top, right and bottom; a
bottom-docked drawer draws left, right and bottom; and so on.

## New surface

```rust
use ratatui_widgets::borders::Borders;
use termrock::widgets::{Surface, SurfaceRecipe};

Surface::new(&system)
    .recipe(SurfaceRecipe::Overlay)
    .bordered(true)
    .borders(Borders::ALL & !Borders::LEFT) // omit the docked edge
    .content_inset()
    .paint(area, buffer);
```

`Surface::borders` defaults to all four edges, so every existing call is
unchanged.

## Consumer edits

- A host that sized a tooltip's rect by hand adds `TOOLTIP_CHROME_ROWS` to the
  height (and `TOOLTIP_CHROME_COLS` to the width if it did not use
  `measure_cols`).
- Snapshots of a plain or shortcut tooltip gain a border and an inset; drawer
  snapshots lose one rule at the docked edge.

## Validation

```sh
cargo nextest run -p termrock --all-features tooltip drawer
mise run check
```
