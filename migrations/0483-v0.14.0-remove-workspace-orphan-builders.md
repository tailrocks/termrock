# 0483: Remove workspace-orphan builder methods

## Boundary

The component API cleanup removed builder methods with zero call sites across
the workspace, tests, and harnesses. Keeping unexercised one-off builders made
the public surface imply supported behavior that the component system never
used or verified.

## Change

Removed orphan builders from result cells, action bars, badges, callouts,
charts, citations, code blocks/frames, content, controls, data tables, date
pickers, diagnostics, diff lines/reviews, forms, wizards, highlighted text,
identity, keyboard hints, key/value tables, keybinding recording, markdown,
model selectors, numeric inputs, object inspection, pagination, panels,
paragraphs, password/path inputs, scroll areas, search inputs, sections,
segmented meters, separators, surfaces, text areas, toggle groups, and
viewports.

## Host migration

Delete calls to the removed methods. The component defaults now apply. Where a
component still exposes an explicit policy API, use that API rather than a
removed convenience toggle; no compatibility alias or deprecation period is
provided.
