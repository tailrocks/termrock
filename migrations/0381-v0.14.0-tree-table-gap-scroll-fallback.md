# 0381: TreeTable gap movement retains virtual scroll fallback

## Boundary

TreeTable movement at a non-selectable edge must still scroll a partial
projection when the virtual window has room to move.

## Change

Up and Down now attempt one virtual-window movement before returning `Ignored`
at leading or trailing non-selectable gaps. Selection and cursor identity stay
unchanged while the projection scrolls.

## Consumer impact

No consumer edit is required. Edge movement continues scrolling virtual
projections and remains inert only at the logical boundary.
