# 0384 — v0.14.0 TreeTable hierarchy action guards

## Boundary

TreeTable collapse accepts a declared parent only when it appears before the
cursor, has a shallower depth, and is selectable. Malformed, forward, group,
disabled, or otherwise invalid parents fall back to the nearest safe ancestor.
Rows in `TreeNodeStatus::Loading` are inert for keyboard hierarchy actions and
disclosure-pointer actions, even when enabled.

## Consumer impact

No host API changes. Hosts may keep grouping and loading rows in a flattened
projection without allowing them to become unsafe hierarchy targets.
