# 0262 — Border shape token

## Mission

Make single-line corner shape theme-selectable while preserving phosphor's
square default and the color-only focus law.

## Public API changes

`DesignSystem` adds the public `border_shape: BorderShape` field. Consumers
using struct literals must add `BorderShape::Square`; builder-based consumers
need no edit. Alternate themes can opt into rounded corners:

```rust
use termrock::style::{BorderShape, DesignSystem};

let system = DesignSystem::default().border_shape(BorderShape::Rounded);
```

`Panel` and bordered `Surface` consume the shared token. Rounded changes only
corner glyphs; border weight and semantic focus color remain unchanged.
`GlyphSet::Ascii` resolves either shape to `+`, `-`, and `|`.

## Validation

```bash
rtk cargo nextest run -p termrock panel surface
rtk mise run check
```
