# 0071 — LogStream premium redesign

## Removed surface

| Removed | Replacement |
|---------|-------------|
| Ungated keys always handled | `accepts_input` / `set_accepts_input` |
| `LogStream::new(…, tokens)` paint-only | `system` + `focused` / `ascii` / `colorless` |
| Immutable `render(..., &state)` | `render(..., &mut state)` (hit geometry + metrics) |
| Level glyph private only | `LogLevel::glyph(ascii)` public |

## Added

| API | Role |
|-----|------|
| `LogStreamOutcome::Scrolled { offset }` | Offset change without follow flip |
| `handle_intent` / `default_log_stream_intent` | Intent-first scroll + follow |
| `handle_mouse` | Wheel detach; chip click re-follow |
| `set_following` / `accepts_input` | Host integration |
| Follow chip paint | Non-color follow/pinned status |
| Empty / narrow / tiny recipes | Responsive + a11y |

## Outcome map

| Event | Outcome |
|-------|---------|
| First scroll while following | `Detach` |
| Further scroll while pinned | `Scrolled { offset }` |
| End / re-follow / chip click / `f` on | `Follow` |
| `f` / Space while following | `Detach` |

## Consumer edits

```rust
// Before
LogStream::new(&lines, &tokens).render(area, buf, &state);
state.handle_key(key);

// After
state.set_accepts_input(scene.is_focused(LOG_ID));
LogStream::new(&lines, &system)
    .focused(true)
    .ascii(false)
    .render(area, buf, &mut state);
match state.handle_key(key) {
    LogStreamOutcome::Detach => { /* chrome */ }
    LogStreamOutcome::Follow => { /* chrome */ }
    LogStreamOutcome::Scrolled { offset } => { let _ = offset; }
    LogStreamOutcome::Ignored => {}
}
```
