# 0245 — HelpCenter / CommandReference composition block

## Mission

Complete **contextual product help** from **real component/command metadata**:
search, topic navigation, keyboard map, command reference, tutorials /
troubleshooting, context help, capability diagnostics (doctor projection), and
markdown links/anchors. Compact overlay and full documentation modes.
**No second hand-maintained shortcut table** — chords come from live
`HelpEntry` / keymap generators only.

Research: Vim/Helix help, Zellij key help, CLI man pages, command palettes
(references only).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `KeyboardHelp` / `HelpEntry` / `help_entries_from_keymap` / `example_help_entries` | **Preserved** — keyboard map SoT |
| `CommandPalette` / `CommandEntry` / `entries_from_keymap` | **Preserved** — host palette; help projects `command_entries_from_help` |
| `MarkdownView` / `project_markdown` / anchors/links | **Preserved** — topic body |
| `SearchInput` | **Preserved** — filter |
| `List` | **Preserved** — nav / commands / diagnostics |
| `DoctorReport` / `build_doctor_report` / `format_doctor_text` | **Preserved** — projected findings; no re-detect |
| Registry `official_ids` / contracts | **Preserved** — inspect rows host-projected |
| Standalone KeyboardHelp overlay / CommandPalette / doctor CLI | **Preserved** — not dual interactive help center |
| Parallel static shortcut documentation table | **Forbidden** |
| Help file / network I/O inside pattern | **Host-owned** |
| `HelpCenterState` · `render_help_center` | **Added** (`patterns/help_center`) |

## Consumer API

```rust
use termrock::patterns::{
    HelpCenterState, HelpCenterSurfaces, HelpCenterDensity, HelpCenterMode,
    HelpCenterOutcome, example_help_topics, example_help_center_entries,
    example_help_center_commands, example_help_doctor_report,
    command_entries_from_help, render_help_center, seed_compact_mode,
};
use termrock::style::DesignSystem;

let system = DesignSystem::default();
let mut state = HelpCenterState::new(); // or ::compact()
let topics = example_help_topics();
let help = example_help_center_entries(&system); // live keymap → HelpEntry
let cmds = command_entries_from_help(&help);     // same chords
let doctor = example_help_doctor_report();

render_help_center(buf, area, HelpCenterSurfaces {
    system: &system,
    state: &mut state,
    topics: &topics,
    help_entries: &help,
    commands: &cmds,
    doctor: Some(&doctor),
    component_ids: &[],
});

match state.handle_key(key, &topics, &help, &cmds, Some(&doctor), &[]) {
    HelpCenterOutcome::TopicOpened { id } => { /* load topic */ }
    HelpCenterOutcome::CommandRun { id } => { /* execute */ }
    HelpCenterOutcome::LinkFollowed { href, .. } => { /* navigate */ }
    HelpCenterOutcome::AnchorJumped { anchor } => { /* scroll */ }
    HelpCenterOutcome::DoctorOpened => { /* show doctor CLI / pane */ }
    HelpCenterOutcome::InspectComponent { id } => { /* studio inspect */ }
    _ => {}
}
```

### Modes & densities

| Mode | Density | Panes |
|------|---------|-------|
| Full | Normal ≥96 | Search · Nav · Keyboard · Commands · Body · Diagnostics · Status |
| Full | Narrow 52–95 | Search · Nav · Commands · Body · Diagnostics (no keyboard) |
| Full / Compact | Tiny &lt;52 or Compact | Search · Body/Keyboard · Status |

### Laws

| Law | Detail |
|-----|--------|
| Single shortcut SoT | `HelpEntry` from keymap; `command_entries_from_help` only |
| Public paint only | KeyboardHelp / MarkdownView / List / SearchInput |
| Host markdown | Topics carry host-assembled markdown strings |
| Doctor | Project `DoctorReport`; do not call detect inside pattern handlers |
| Density=None | Last paint width; Tab clamps |

### Stories

- `help-center/{basic,compact,narrow,doctor,unicode}`

## Second-pass design review

**Decisions**

1. Elevated composition peer to ProjectLauncher / FileManager.
2. Keyboard map always paints `KeyboardHelp` with live `HelpEntry` slices.
3. Command reference rows derive from the same HelpEntry stream so chords cannot
   drift from KeyboardHelp.
4. Doctor findings are host-projected; `build_doctor_report` used only in fixtures.
5. Compact mode drops nav/commands for overlay-class help.

**Rejected**

- Second static chord table in the pattern.
- Embedding full CommandPalette overlay as the only command path.
- Re-running capability detection on every paint.
- Cloning Vim tags or man-page CMS.

**Residual limits**

- Markdown projection re-runs per paint (host may cache blocks later).
- Component inspect list is host-supplied ids (registry optional).
- PTY/fuzz not required.
