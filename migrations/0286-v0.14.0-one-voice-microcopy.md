# 0286 — One voice: the microcopy standard

Two microcopy systems used to coexist with no arbitration — a terse terminal
voice (lowercase labels, fragment errors, `C-s`) and an app voice (Title case,
full sentences, `Ctrl+S`) — sometimes inside a single string. Case, punctuation,
and key notation are hierarchy channels on a cell grid, so the split was not
cosmetic: it spent those channels at random.

`docs/design/web-premium-tui-law.md` §4.1 now carries the standard as binding
law, and two gates in `crates/termrock/tests/design_gate.rs` enforce the
mechanical half.

## The standard

1. Labels, buttons, titles: **sentence case** (`Cancel`, `Sign in`, `Procs`).
2. Hints: **lowercase verbs, keys as chips** — `[esc] cancel · [enter] open`.
   `·` separates hint pairs only, never a key from its label. No trailing
   periods.
3. Key notation: **one system** — `C-s`, `S-tab`, `A-r`; bare keys spelled
   `esc enter tab space ↑↓←→`. Painted strings never hardcode `Ctrl+S` or `⌘K`.
4. Ellipsis resolves through the glyph catalog, never a bare `...` literal.
5. Error copy: `<what failed> — <recovery>`, sentence case, no `error:` prefix.
6. Placeholders: sentence case with an ellipsis (`Search settings…`).
7. Running verbs: lowercase gerund beside the spinner (`loading…`).
8. `OK` is `OK`, never `Ok`.

## What changed in painted output

### Key notation

Every spelled chord in a painted literal became the dash form. Comments and
documentation prose keep the spelled wording, and `widgets::kbd` is untouched —
it *is* the formatter, and `ChordFormat::docs()` still renders `Ctrl+S` for
documentation surfaces.

| Before | After |
|--------|-------|
| `Ctrl+S` | `C-s` |
| `Ctrl+Shift+O` | `C-S-o` |
| `Alt+R` | `A-r` |
| `Ctrl+Enter` | `C-enter` |
| `Ctrl+Space` | `C-space` |
| `ctrl+p` | `C-p` |
| `⌃c` | `C-c` |
| `Alt/Ctrl/Shift+Enter` | `A-enter / C-enter / S-enter` |

Affected surfaces: `PromptComposer`, `CommandPalette`, `SlashCommandMenu`,
`MenuBar`, `ToolCallCard`, `MessageThread`, `HistoryPicker`, `QuickOpen`,
`TerminalOutput`, and the `AuthEntry`, `QueryEditor`, `SettingsScreen`,
`MetricsDashboard` patterns. Hosts that matched on these strings (rather than on
`KeyChord`) must update their expectations; matching on strings was always a
bug, and `widgets::kbd::format_chord` is the supported path.

### Ellipsis and loading copy

- `CompletionMenu`, `CommandPalette`, and `QuickOpen` each had one gated ASCII
  literal that replaced the *whole* message, so a host-supplied
  `loading_message` was discarded on ASCII terminals. Now only the default has
  an ASCII twin; custom copy is painted as written.
- `[...] loading` / `[...] searching` are gone; the copy is `Loading…` /
  `Searching…` with `Loading...` / `Searching...` ASCII twins.
- `PreviewCard` paints `loading…` instead of `… loading` — verb first, so the
  row reads as an action in progress rather than an elision.
- `Tabs` overflow resolves `Glyph::Ellipsis` through the catalog and pads it to
  the same 3-cell budget in both profiles; the trigger no longer shifts by a
  cell between Unicode and ASCII.
- `IconButton` / the primitive loading face take their glyph from the catalog on
  the monochrome path too, which means `Glyph::Loading` (`◔`, ASCII `:`) rather
  than a hardcoded `...`.
- `QueryEditor`'s running marker was `…run` on Unicode and `...` on ASCII — the
  ASCII form silently dropped the verb. Both now read `run…` / `run...`.

### Case

`FileOpKind::label()` returns sentence case (`Copy`, `Move`, `Delete`,
`Rename`, `New file`, `New directory`); ids are unchanged. Panel titles
capitalize their first word: `procs`→`Procs`, `catalog`→`Catalog`,
`sql`→`SQL`, `ops`→`Ops`, `find`→`Find`, `shell`→`Shell`, `host`→`Host`,
`metrics`→`Metrics`, `problems`→`Problems`, `build`→`Build`, `crates`→`Crates`,
`repo`→`Repo`, `req`→`Request`. `filter bindings...`→`Filter bindings...`.

### Error copy

The `error · {message}` and `error: {err}` prefixes are removed from
`SearchResults`, `ResultGrid`, and `ProjectLauncher`: severity is carried by the
`Danger` role and the status glyph, so the word spent cells saying it twice.
`NotificationCenter`'s `Ok` is now `OK`.

Two prefixes survive on purpose: `ConnectionManager`'s `error   {err}` is a
key-value *label* in an aligned detail list, and `ErrorState::diagnostics_text`
is clipboard payload, not painted chrome.

### Secret masks

The three-way mask split (`*`, `•`, `••••••••`) collapses onto `Glyph::Mask`
(`●`, ASCII `*`) repeated `style::MASK_CELLS` (8) times. `AuthEntry`,
`ObjectInspector`, `KeyValueTable`, and `HistoryPicker`'s redaction all use it.
Fixed width is deliberate — a mask that tracked the secret's length would leak
it. Tests asserting `•` should assert `●` (or `style::MASK_CELLS`).

### Hint verbs

`esc` reads `cancel` wherever it dismisses one layer: `esc close` and
`esc dismiss` are gone from `Popover`, `Drawer`, `Dialog`, `PreviewCard`,
`NotificationCenter`, and `FullscreenViewer`.

Three verbs are **sanctioned exceptions** — normalizing them would describe the
wrong behavior:

| Surface | Verb | Why |
|---------|------|-----|
| `FullscreenViewer` | `esc demote` | Returns fullscreen to inline; nothing is cancelled |
| `JumpOverlay`, `EmptyState` | `esc clear` | Clears a typed prefix or filter, not a layer |
| `EmptyState` | `esc back` | Navigates, not dismisses |
| `CommandPalette` | `esc clear/cancel` | Staged: clears the query first, then cancels |

## New public surface

- `style::MASK_CELLS` — cells painted for a fully masked secret.

## Gates

`crates/termrock/tests/design_gate.rs`:

- `no_bare_ellipsis_in_paint` — a `...` inside a painted string literal must sit
  within four lines of an `ascii` gate (its ASCII twin) or be resolved from the
  catalog.
- `one_chord_notation` — no `Ctrl+`/`Alt+`/`Shift+`/`Cmd+` in a painted literal,
  and no Mac modifier symbol bound to a key (`⌘K`). A bare `⌘` used as a
  resource badge is allowed; `kbd.rs` is exempt as the formatter.

Both scans skip everything from the first `#[cfg(test)]`, skip comment lines,
and skip `example_*` payload functions, whose literals are simulated
third-party output (git porcelain, cargo test lines) rather than microcopy.

## Ownership and rollback

Copy stays TermRock's for its own chrome; hosts still own domain wording.
Rollback is source-only.

## Validation

```sh
cargo nextest run -p termrock --test design_gate
rg -n '"[^"]*(Ctrl|Cmd)\+' crates/termrock/src -g '*.rs'   # kbd.rs + one negative fixture only
mise run gate
```
