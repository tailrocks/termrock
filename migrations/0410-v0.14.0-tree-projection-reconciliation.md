# 0410: Tree projection reconciliation repairs stale identities

## Boundary

Hosts can replace a tree's full flattened projection between render frames.
The previous projection may contain the cursor, semantic selection, or hover
identity even though the replacement no longer does.

## Change

`TreeState` now reconciles identities at the render boundary. Full projections
repair the cursor through the interactive collection and clear removed or
noninteractive semantic selection. Partial virtual windows preserve stable
off-window identities while still repairing identities present in the window
that are no longer interactive. Hover state is retained only for a row with a
freshly painted hit region. Collection active state follows the repaired
cursor.

## Consumer impact

No consumer change is required. Full projections no longer strand keyboard
focus on removed or disabled rows. Virtualized hosts retain off-window cursor
and semantic-selection identities until a subsequent projection resolves
them.
