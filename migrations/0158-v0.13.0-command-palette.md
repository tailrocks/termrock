# 0158 — CommandPalette flagship redesign

## Mission

Universal command surface: fuzzy search + highlighting, groups, recent /
contextual actions, shortcuts, nested pages, arguments, previews, async
generation gates, history, and fullscreen promotion on small terminals.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Picker` / `PickerState` / `PickerOutcome` | **Preserved** — general query+list popup |
| `OverlayStack` `CommandPalette` kind + place/open/dismiss | **Preserved** (IDs/helpers kept) |
| `COMMAND_PALETTE_OVERLAY_ID` | **Preserved** |
| `CommandPaletteSize` | **Preserved** |
| `CommandPaletteState = PickerState` type alias | **Deleted** — own state machine |
| `CommandPalette` over `ListRow` only | **Migrated** → `CommandEntry` model |
| `CommandPaletteOutcome::{QueryChanged, Activated, …}` | **Migrated** — richer variants |
| Fuzzy / filter helpers | **Added** |
| `entries_from_keymap` | **Added** |

## Consumer edits

```diff
- use termrock::widgets::{CommandPalette, CommandPaletteState, ListRow};
- let rows = [ListRow::item("quit", Line::from("Quit"))];
- let mut state = CommandPaletteState::new(Some("quit"));
- CommandPalette::handle_key(&mut state, key, &rows);
- CommandPalette::new("Commands", &rows, &system)

+ use termrock::widgets::{
+     CommandEntry, CommandPalette, CommandPaletteOutcome, CommandPaletteState,
+     filter_command_entries, example_command_catalog,
+ };
+
+ let catalog = example_command_catalog(); // or host-built CommandEntry tree
+ let mut state = CommandPaletteState::new(None);
+ state.set_focused(true);
+ state.set_accepts_input(true);
+
+ // Sync path:
+ let visible = state.refilter(&catalog);
+ match state.handle_key(key, &visible) {
+     CommandPaletteOutcome::QueryChanged { query, generation } => {
+         // Async path: fetch with generation; apply only if still current:
+         // if state.apply_results(generation, &host_rows) { … }
+         let _ = (query, generation);
+     }
+     CommandPaletteOutcome::Activated { id, command, argument } => host.run(id, command, argument),
+     CommandPaletteOutcome::NeedArguments { id, prompt } => { /* UI already in arg phase */ }
+     CommandPaletteOutcome::PageOpened { page_id } => { let _ = state.refilter(&catalog); }
+     CommandPaletteOutcome::Cancelled => stack.handle_escape(),
+     _ => {}
+ }
+ CommandPalette::new("Commands", &visible, &system).paint(area, buf, &mut state);
```

### Async contract

1. On `QueryChanged { generation, query }` start host fetch tagged with `generation`.
2. When results arrive, call `state.apply_results(generation, &entries)` — returns
   `false` if stale (user typed again).
3. `set_loading(true/false)` drives the loading chrome.

### Esc law

1. Non-empty query → clear query (`QueryChanged`)
2. Nested page → `PageClosed`
3. Argument phase → back to browse
4. Else → `Cancelled` (OverlayStack restores opener focus)

### Stories

- `command-palette/basic`, `empty`, `no-result`, `loading`, `fuzzy`, `nested`,
  `args`, `ascii`, `narrow`, `unicode`
