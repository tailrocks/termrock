# 0352: DataTable cell selection follows host column identity

## Boundary

`DataTableState::cursor_col` is a visible-column ordinal, but `CellCoord` is
indexed by the host column model. Responsive projection, visibility changes,
and column reordering must not retarget an existing cell selection.

## Change

DataTable stores cell coordinates with source column indexes, remaps them by
column identity when the host model is reordered, and preserves the cursor's
visible ordinal separately. Mouse, keyboard range, and paint paths now share
that distinction.

## Consumer impact

No consumer edit is required. Existing `CellCoord` consumers should continue
mapping its `col` through the host column model, including hidden columns.
