# 0445: PathInput physical one-shot actions

## Boundary

`PathInputState::handle_key` is the raw physical keyboard adapter for the
filesystem-aware path field. Browse, completion, cancellation, and delegated
text-input one-shot actions must not repeat while a key is held.

## Change

- Non-Press Enter, Tab, BackTab, and Escape events are ignored before the
  nested `TextInputState` is synchronized.
- Non-Press Ctrl+O browse, Ctrl+M submit, clipboard Ctrl+C/X/V, and
  destructive Ctrl+U/K/W actions are ignored before synchronization or a host
  outcome.
- Repeatable history, navigation, and ordinary printable text editing remain
  supported. Semantic `handle_intent` remains phase-free.

## Host migration

Hosts routing raw `PathInputState` events must continue passing complete
`KeyEvent` values, including lifecycle kind. Do not synthesize repeated
browse, completion, cancel, submit, clipboard, or destructive editor actions
from Repeat or Release events. Use `handle_intent` for semantic commands that
are not raw physical keyboard events.
