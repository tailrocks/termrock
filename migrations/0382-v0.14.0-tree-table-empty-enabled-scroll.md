# 0382: TreeTable scrolls all-nonselectable projections

## Boundary

TreeTable must keep virtual scrolling available when a projected slice has no
selectable rows.

## Change

Movement now attempts virtual-window scrolling before returning `Ignored` from
an all-nonselectable projection. Selection and cursor identity stay unchanged.

## Consumer impact

No consumer edit is required. Loading, group, and disabled-only slices can
still advance through a virtual logical universe.
