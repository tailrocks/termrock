# 0202 — FileTree filesystem explorer

## Mission

Filesystem-specialized Tree: git status, file types, hidden/ignored, lazy
directories, search, reveal active file, multi-select, rename/create/delete as
**typed requests**, preview integration. FS and Git I/O outside the component.
Symlinks, permission errors, huge dirs (host windows), path normalization.
Yazi-like chords and safe destructive flows. Integrate with QuickOpen and
Breadcrumbs.

Research: Yazi, ranger, lf, broot, VS Code, lazygit file lists.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tree` / `TreeNode` / `TreeState` | **Preserved** — general hierarchy; FileTree projects into it |
| `FileEntryKind` (file_picker) | **Preserved** — `FileTreeKind::from_entry_kind` |
| `QuickOpen` / `Breadcrumbs` | **Preserved** — bridges `file_tree_to_quick_open_items`, `breadcrumbs_from_path` |
| `FileTree` / `FileTreeEntry` / outcomes | **Added** |
| DiffReview file list | **Preserved** — review-specific rows, not FS explorer |
| FS/Git process IO | **Never in TermRock** |

## Consumer API sketch

```rust
use termrock::widgets::{
    FileTree, FileTreeState, FileTreeEntry, FileGitStatus, FileTreeKind,
    breadcrumbs_from_path, file_tree_to_quick_open_items,
};

let entries = [
    FileTreeEntry::dir("src", "src", "src", 0).expanded(),
    FileTreeEntry::file("src/main.rs", "main.rs", "src/main.rs", 1)
        .parent("src")
        .git(FileGitStatus::Modified)
        .file_type("rs"),
    FileTreeEntry::dir("src/w", "w", "src/w", 1).parent("src").lazy_dir(),
];
let mut state = FileTreeState::with_selected(Some("src/main.rs"));
// Host: match OpenRequested / LoadChildrenRequested / DeleteRequested / …

FileTree::new(&entries, &system).title("repo").render(area, buf, &mut state);

// Bridges
let crumbs = breadcrumbs_from_path("src/main.rs");
let qo = file_tree_to_quick_open_items(&entries, true);
```

### Keys (Yazi-class)

| Key | Action |
|-----|--------|
| j/k h/l · arrows | Tree nav (via Tree) |
| Enter | Open file / toggle dir |
| `/` | Filter |
| `.` / `i` | Toggle hidden / ignored |
| `n` / `N` | Create file / dir request |
| `r` | Rename draft |
| `d` | Delete (confirm if multi) |
| `y` | Copy path(s) |
| `p` | Preview request |
| `C-o` | QuickOpen request |
| `g` / `G` | Breadcrumbs path / OS reveal |
