# 0418: Keymap resolution uses canonical key events

## Boundary

All keymap resolution must use the same event-to-chord normalization. Shift is
intrinsic to character casing, while release events are inert; repeat events
remain available for repeatable actions.

## Change

`resolve_keymap_action` now rejects release events and converts the complete
`KeyEvent` through `KeyChord::from`. Shifted character events therefore match
plain uppercase character bindings consistently with the interaction bridge.

## Consumer impact

Consumers using `resolve_keymap_action` receive the same character modifier
normalization and release filtering as `dispatch_keymap_action`. No consumer
change is required unless it depended on release events resolving actions.
