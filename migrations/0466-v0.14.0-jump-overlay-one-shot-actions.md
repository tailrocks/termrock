# 0466: JumpOverlay physical one-shot actions

## Boundary

`JumpOverlayState::handle_key` is the raw keyboard adapter for direct jump
labels, multi-key prefixes, and Escape cancellation. Held keys must not mutate
the prefix or activate/dismiss a target repeatedly.

## Change

- Only Press events are accepted by the raw JumpOverlay adapter.
- Repeat and Release events are ignored before prefix, activation, or Escape
  state changes.
- Semantic cancellation and replay helpers remain unchanged; replay continues
  to construct Press events.

## Host migration

Hosts routing raw JumpOverlay events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize prefix, activation, or dismissal
outcomes from `Repeat` or `Release` events.
