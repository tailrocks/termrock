# 0137 — Field, Fieldset, and Form architecture

## Mission

Compositional form architecture: Field projections (label/value/status,
dirty/touched), Fieldset groups, Form layouts (responsive/stacked/compact/inline),
submit/reset outcomes, error summary, and first-invalid focus — without hidden
application state.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Scene-owned field focus (`Form::focused_field`) | **Preserved** |
| Scroll / hit regions / page keys | **Preserved** |
| `FormField` with `Line` label/value/help/error | **Migrated** → [`Field`] with `&str` + [`FieldStatus`] |
| `FormSection { title: Line, fields }` | **Migrated** → [`Fieldset::new(legend, fields)`] |
| `FormOutcome::Activated` / `Scrolled` / `Ignored` | **Preserved** |
| `FormOutcome::SubmitRequested` / `ResetRequested` | **Added** |
| `FormLayout`, pure helpers (`first_invalid_id`, …) | **Added** |
| `FieldCaption` / `Label` / `Description` | **Preserved** — Field uses them for chrome |
| `FormWizard` | **Preserved** |

Type aliases: `FormField = Field`, `FormSection = Fieldset` (same shapes as new types).

## Consumer edits

```diff
- use ratatui_core::text::Line;
- FormField::new("name", Line::from("Name"), Line::from("Ada"))
-     .help(Line::from("…"))
-     .error(Line::from("…"));
- FormSection { title: Line::from("General"), fields: &fields }
+ Field::new("name", "Name", "Ada")
+     .help("…")
+     .error("…")
+     .dirty(true)
+     .touched(true);
+ Fieldset::new("General", &fields).description("Profile")
```

```rust
// Submit / reset (host owns values)
match state.handle_key(&fieldsets, key, focused) {
    FormOutcome::SubmitRequested => { /* validate + submit */ }
    FormOutcome::ResetRequested => { /* reset model; reproject fields */ }
    FormOutcome::Activated(id) => { /* open editor for id */ }
    _ => {}
}

// First invalid after failed submit
if let Some(id) = state.focus_first_invalid(&fieldsets) {
    scene.focus(id);
}
```

## Behavior

| Concern | Rule |
|---------|------|
| Values | Host-owned; Field projects display strings only |
| Focus | Host/scene; Form never cycles Tab |
| Submit | Ctrl+Enter / Ctrl+S / `UiIntent::Submit` |
| Reset | Ctrl+R → `ResetRequested` (host applies) |
| Errors | `FieldStatus::Error` + optional summary strip |
| Dirty | Trailing `·` on label (non-color) |
| Layouts | Responsive / Stacked / Compact / Inline |
