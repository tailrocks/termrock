# 0169 — AlertDialog

## Mission

Specialized high-risk confirmation surface **distinct from generic Dialog**:
exact scope, consequences, reversibility, target, safer alternatives; typed
confirmation; countdown only when justified; destructive-default **policy**
(never default-focus danger); non-dismissable critical state; safe Enter.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `OverlayKind::AlertDialog` policy (Esc trap, occlude, focus trap) | **Preserved** |
| `open_alert_dialog_overlay` (Dialog id, ConfirmOnly) | **Preserved** (generic alert open) |
| `Dialog` / `DialogState` / destructive recipe | **Preserved** (engine under AlertDialog) |
| `ALERT_DIALOG_OVERLAY_ID`, `AlertDialog`, `AlertDialogState`, scope model | **Added** |
| PermissionPrompt high-risk overlay | **Unchanged** (can adopt AlertDialog later) |
| Generic Dialog for low-risk notices | **Preserved** (do not use AlertDialog) |

## Consumer edits

```diff
+ use termrock::widgets::{
+     AlertDialog, AlertDialogState, AlertKind, AlertScope, AlertConfirmGates,
+     AlertReversibility, dismiss_alert_dialog_overlay,
+ };

+ let mut state = AlertDialogState::new(
+     AlertKind::Delete,
+     AlertScope::new("bucket/prod", "Permanently deletes all objects.")
+         .scope_detail("1.2M objects")
+         .safer_alternative("Lifecycle expire after 30 days.")
+         .reversibility(AlertReversibility::Irreversible),
+     "delete",
+     "keep",
+ );
+ // Optional gates:
+ state.set_gates(AlertConfirmGates::typed("bucket/prod"));
+ // state.set_gates(AlertConfirmGates::countdown(3_000)); // only if justified
+ // state.set_locked(true); // critical non-dismissable

+ let _ = state.open_on_stack(&mut stack, bounds, Some("trigger"));
+ // Keys: Enter on Keep → Cancelled; move to Delete after gates → Confirmed
+ // Esc (confirm-only) → Cancelled{keep}; locked → EscTrapped
+ // stack: outside + Esc trapped at overlay policy level
+ AlertDialog::new(&system).paint(rect, buf, &mut state);
```

### Safe focus / Enter

| Path | Result |
|------|--------|
| Open | Cursor on **cancel** (Keep/Deny) |
| Enter (default) | `Cancelled { id: cancel }` — never destroys |
| Move to confirm + Enter (gates ok) | `Confirmed { id }` |
| Confirm without typed/countdown | `ConfirmBlocked` / `TypedMismatch` |
| Esc (confirm-only) | `Cancelled { cancel }` |
| Esc (locked) | `EscTrapped` |
| Outside click | Stack `Ignored` (trap) |
