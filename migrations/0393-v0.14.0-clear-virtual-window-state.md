# 0393: List virtual-window mode transitions synchronize collection metadata

## Boundary

Switching a `ListState` from a virtual projection back to a full projection
can happen before the next paint or reconciliation.

## Change

`ListState::set_virtual_window` now synchronizes embedded
`CollectionState` metadata immediately in both directions. Entering a virtual
window preserves an off-window active ID before reconciliation; passing
`total_len == 0` clears virtual metadata so pre-reconcile movement uses
full-projection recovery instead.

## Consumer impact

The existing `total_len == 0` opt-out remains the way to disable list
virtualization. No explicit consumer migration is required.
