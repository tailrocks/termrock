# 0339 — Select intents use the filtered collection

**Version:** `v0.14.0`  
**Kind:** behavioral

An open searchable `Select` now uses one current collection projection for
reconciliation, keyboard movement, semantic intents, and paint. Semantic
navigation can no longer leave the active search results and highlight an
option that is not visible.

The projection still includes disabled options for canonical roving-state
handling, skips group and separator rows as selectable entries, and ignores a
stale query when search is disabled. There is no separate full-option intent
path.
