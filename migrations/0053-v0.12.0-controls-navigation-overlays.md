# 0053 — Controls, navigation, and overlays (Plan 051)

## Additions

| Surface | Notes |
|---------|--------|
| `Checkbox`, `RadioGroup`, `Switch` | Controlled values via outcomes |
| `Select`, `MultiSelect`, `Combobox` | Menu open/close; Combobox is Picker evolution |
| `Menu`, `ContextMenu`, `MenuItem` | Roving focus, skip disabled, Esc closes |
| `Sidebar`, `Breadcrumbs` | Rail/collapse, middle overflow |
| `Drawer`, `Popover`, `Tooltip` | OverlayStack integration for drawer |

## Picker

`Picker` remains; prefer `Combobox` for query+results free-text/select-only variants.

## Ownership

Values controlled by consumer; overlays use `OverlayStack` laws; no domain validation inside controls.

## Validation

```bash
cargo test -p termrock --lib controls menu_nav
```
