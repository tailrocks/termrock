# 0180 — StatusIndicator + shared SemanticStatus

## Mission

Compact semantic status primitive for connections, tasks, agents, rows, and
services. One shared vocabulary (glyph + label + style) so components stop
inventing private status glyph sets. Color alone is never sufficient.

Research: btop process states, collab presence dots, agent/tool rails.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `StatusBar`, `StatusSlot`, `StatusBar::StatusKind` | **Preserved** — bar chrome slots; not the shared indicator vocab |
| `ToolStatus`, `PresenceStatus` | **Preserved** domain enums; glyphs/roles **migrated** via `.semantic()` → `SemanticStatus` |
| `ProgressStatus`, `ProgressStepStatus`, `Severity` | **Preserved**; **map into** `SemanticStatus` (`from_*`); ProgressSteps **bracket marks** stay pipeline-local |
| Private ad-hoc status dots | **Migrate** to `SemanticStatus` + `StatusIndicator` |
| `SemanticStatus` leaf (`semantic_status.rs`) | **Added** — 11 kinds; no domain imports (avoids widget cycles) |
| Domain `from_*` mappings | **Added** on `SemanticStatus` in `status_indicator.rs` |
| `StatusIndicator` + Compact/Labeled/Elapsed | **Added** |
| `StatusIndicatorState` (elapsed, a11y label) | **Added** |
| `example_status_catalog` | **Added** |
| Tool cancelled glyph `⊘` / presence Away `◐` as private sets | **Deleted** as private; use shared glyphs (`‖` paused, `◌` idle) |

`StatusKind` on the status bar is intentionally **not** renamed or merged: bar
slots encode chrome regions; `SemanticStatus` encodes lifecycle/presence for
inline indicators.

## Consumer edits

```diff
+ use termrock::widgets::{
+     StatusIndicator, StatusIndicatorVariant, StatusIndicatorState, SemanticStatus,
+     example_status_catalog,
+ };

  // Domain → shared vocab
+ let kind = SemanticStatus::from_tool_status(tool.status);
+ // or from_presence / from_progress_status / from_progress_step_status / from_severity

  // Labeled (default)
+ StatusIndicator::new(kind, &system).label("agent").paint(area, buf);

  // Compact dot (semantic a11y still required via state)
+ let mut st = StatusIndicatorState::new();
+ st.set_accessible_label("agent online");
+ StatusIndicator::compact(SemanticStatus::Online, &system)
+     .paint_with_state(area, buf, Some(&st));

  // Elapsed
+ StatusIndicator::new(SemanticStatus::Running, &system)
+     .label("job")
+     .elapsed_secs(125)
+     .paint(area, buf);

  // Capability
+ StatusIndicator::new(kind, &system).ascii(true); // force ASCII glyphs
```
