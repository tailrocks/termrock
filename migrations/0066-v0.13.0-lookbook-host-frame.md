# 0066 — Lookbook HostFrame (InteractionScene + OverlayStack host)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `crates/termrock-lookbook/src/host_focus.rs` (~500 LOC FocusRing fork) | `host_frame.rs` + public `InteractionScene` |
| Lookbook `FocusRing` / `FocusTarget` / `FocusScope` type aliases | `FocusId` + `LayerId` + scene layers |
| FocusRing modal scope helpers in lookbook | Scene `LayerId::Modal` + `OverlayStack` entry |

**Library:** FocusRing remains crate-private for unit tests only — not reintroduced publicly.

## Canonical host shape

```rust
// lookbook-private (Break K / M12 → Studio StoryContext)
struct HostFrame {
    theme: RolePalette,
    scene: InteractionScene<FocusId, LayerId, ()>,
    overlays: OverlayStack<()>,
    frame_bounds: Rect,
}

// Each frame
host.begin_shell_frame(modal_open);
host.register_shell(FocusId::Sidebar, sidebar, true);
host.register_shell(FocusId::Preview, preview, true);
host.reconcile();

// Tab
host.handle_scene_key(tab_key);

// Focus-trap prototype
host.open_focus_trap(); // OverlayStack
// … domain Option for ChoiceDialog state …
host.close_focus_trap(); // restores scene focus_return
```

Panel chrome:

```rust
PanelChrome::Focused if scene.focused() == Some(&id) else PanelChrome::Normal
```

## Consumer / fork edits

1. Do **not** copy `host_focus.rs` into apps — use `InteractionScene` + `OverlayStack`.
2. Map shell regions to `InteractionElement::control` each frame (`begin_frame` first).
3. Floating UI: `overlays.open` + optional scene layer with `owns_input`.
4. Esc order: OverlayStack (if top) → scene → host quit policy.
