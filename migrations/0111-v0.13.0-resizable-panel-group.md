# 0111 — ResizablePanelGroup multi-handle layout

## Mission

Higher-order multi-panel layout built on SplitPane semantics: N panels, N−1
handles, constrained redistribution, collapse/restore, keyboard resize, saved
presets, and responsive side-panel → drawer recipes — without coupling panel
content to the layout engine.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `SplitPane` / `SplitPaneState` / `SplitRatio` | **Preserve** — binary splits |
| `Workspace` / `WorkSurface` / `AppShell` | **Preserve** — app chrome recipes |
| `ResizablePanelGroup` + state/layout/outcomes | **Added** |
| Content/focus/scroll inside panels | **Host-owned** — never reset by layout |

## API sketch

```rust
use termrock::widgets::{
    ResizablePanelGroup, ResizablePanelGroupState, ResizablePanelSpec,
    workbench_panels, dashboard_panels, PanelId, PanelGroupRecipe,
};

let panels = workbench_panels(); // sidebar | main | inspector
let group = ResizablePanelGroup::new(&panels, &system).workbench();
let mut state = ResizablePanelGroupState::new();

// Geometry only — paint your content into panel rects
let layout = group.layout(area, &mut state);
group.paint_handles(area, buf, &mut state);

for panel in &layout.panels {
    if panel.drawer {
        // host: open drawer overlay for panel.id
        continue;
    }
    if panel.collapsed || panel.area.is_empty() {
        continue;
    }
    // paint domain widgets into panel.area; keep their scroll/focus state
}

// Interaction
state.set_focused_handle(Some(0));
let out = group.handle_key(&mut state, key, area);
let out = group.handle_mouse(&mut state, mouse, area);

// Collapse / presets
group.collapse(&mut state, &PanelId::from_static("sidebar"));
state.save_preset("dev");
group.apply_preset(&mut state, "dev", area);
```

## vs SplitPane / Workspace / AppShell

| | ResizablePanelGroup | SplitPane | Workspace | AppShell |
|--|---------------------|-----------|-----------|----------|
| Panels | N with handles | 2 | Tree of leaves | Named chrome slots |
| Drag resize | yes | yes | no | no |
| Content | host | host | host | host |
| Drawer recipe | yes | no | collapse only | narrow config |
