# 0359: TreeTable retains the hierarchy column

## Boundary

TreeTable’s first painted column owns indentation, disclosure, and the primary
row label. Responsive contraction must not replace that structural column with
a data column.

## Change

TreeTable now repairs the shared responsive width result when its first visible
column was dropped: the lowest-priority retained column is removed and the
hierarchy column is inserted with the width that fits the current budget.

## Consumer impact

No consumer edit is required. Narrow TreeTables continue to paint hierarchy
semantics in the first column, regardless of relative column priorities.
