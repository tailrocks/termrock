# 0429: MenuBar one-shot actions

## Boundary

`MenuBarState::handle_key` treats menu activation, mnemonic toggles, mnemonic
activation, and the narrow CommandPalette handoff as physical key-press
actions. A held key must not activate a menu command, toggle mnemonic mode,
or request a replacement palette repeatedly.

## Change

For the MenuBar keyboard adapter:

- `Press` Ctrl+Shift+M toggles sticky mnemonic mode; Repeat and Release are
  ignored.
- `Press` mnemonic letters open a top menu or activate a matching menu item;
  Repeat and Release are ignored.
- In CommandPalette presentation, `Press` Enter, Space, or Down requests the
  palette handoff; Repeat and Release are ignored.
- Arrow movement, page-independent menu traversal, and other repeatable
  navigation remain repeatable.

The press checks apply to the direct MenuBar branches that otherwise bypass
`default_menu_bar_intent`, whose Enter/Space/Escape mappings already reject
non-Press events.

## Host migration

Hosts routing raw MenuBar events must continue passing the complete `KeyEvent`,
including its lifecycle kind. Do not synthesize a second menu activation,
mnemonic toggle, or CommandPalette handoff for Repeat or Release events; the
MenuBar state adapter consumes them as no-ops.
