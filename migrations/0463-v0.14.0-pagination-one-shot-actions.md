# 0463: Pagination physical one-shot actions

## Boundary

`PaginationState::handle_key` is the raw keyboard adapter for discrete page
navigation. Held keys must not repeat jump-entry lifecycle, page-size, focus,
or activation actions.

## Change

- Only Press events can start or finish jump entry with `g`/`/`, Escape,
  Enter, or a direct page digit.
- Only Press events can cycle page size, activate a pagination part, or move
  the part focus with Tab/BackTab.
- Repeat events remain available for page/part navigation and jump-draft
  editing.
- Release events remain ignored.
- Semantic intent and pointer paths are unchanged.

## Host migration

Hosts routing raw Pagination events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize jump, page-size, focus, or
activation outcomes from `Repeat` or `Release` events.
