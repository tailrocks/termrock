# 0126 — AvatarGlyph and Identity

## Mission

Terminal-native identity markers for users, agents, services, and collaborators:
initials, semantic glyphs, presence, role badges, deterministic color seeds,
fixed **1- and 2-cell** avatar widths across glyph profiles, and no-color
legibility — without raster images.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Icon` / `Glyph` | **Preserved** — Avatar may use `AvatarFace::Glyph` / role glyphs |
| `Badge` | **Preserved** — Identity role chip uses outline Badge |
| Raster / image avatars | **Not added** — out of terminal-native scope |
| `AvatarGlyph`, `Identity`, helpers | **Added** |

## API sketch

```rust
use termrock::widgets::{
    AvatarGlyph, AvatarSize, Identity, IdentityRole, PresenceStatus, AvatarFace,
    initials_from_name,
};

// 1-cell / 2-cell faces
AvatarGlyph::new("Ada Lovelace", &system)
    .size(AvatarSize::Normal) // or .compact()
    .with_presence(PresenceStatus::Online)
    .paint(area, buf);

// Thread row
Identity::new("termrock-agent", &system)
    .role(IdentityRole::Agent)
    .secondary("planning")
    .badge(true)
    .presence(PresenceStatus::Busy)
    .paint(area, buf);
```

## Width contract

| Size | Face cells | + presence |
|------|------------|------------|
| Compact | 1 | +0/1 |
| Normal | 2 | +0/1 |
| Presence | 2 | +1 when status ≠ None |

ASCII and monochrome profiles keep the same column counts (no emoji width surprises on the face budget).
