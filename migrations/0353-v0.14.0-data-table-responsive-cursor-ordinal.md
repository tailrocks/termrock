# 0353: DataTable cursor and hits follow the responsive projection

## Boundary

Responsive width resolution can drop a visible middle column. The cursor and
pointer regions must still agree with the columns that are painted.

## Change

DataTable reanchors a cursor whose column was dropped to the nearest retained
column, compares focus against visible ordinals, and publishes visible
ordinals in cell hit regions. Compressed paint order no longer retargets
keyboard or pointer focus.

## Consumer impact

No consumer edit is required. `DataTableCellRegion::col_index` remains the
visible-column ordinal even when responsive projection omits another column.
