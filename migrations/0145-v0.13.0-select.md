# 0145 — Select (CollectionState + popover recipes)

## Mission

Single-choice Select: closed trigger + open list on [`CollectionState`]
navigation, value ≠ highlight, groups/separators, search/typeahead, recipes
(inline/form/compact), and popover vs fullscreen for tiny terminals.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Stub `controls::Select` / `SelectState` / `SelectOutcome::{OpenMenu,CloseMenu,Selected}` | **Deleted** — replaced |
| `RadioGroup` | **Preserved** — always-visible exclusive options |
| `Picker` | **Preserved** — full query+list shell |
| `CollectionState` / roving typeahead | **Preserved** — used internally |
| `Popover` / `open_popover_overlay` | **Preserved** — host places overlays from outcomes |
| `Select` / `SelectOption` / `SelectRecipe` / `SelectPresentation` | **Added** in `select.rs` |

## Consumer edits

```diff
- let mut state = SelectState::new(None::<&str>);
- state.set_focused(true);
- match state.handle_key(key, &ids) {
-     SelectOutcome::OpenMenu => { /* open overlay */ }
-     SelectOutcome::CloseMenu => {}
-     SelectOutcome::Selected(id) => {}
-     _ => {}
- }
- Select::new("Pick…", &system).render(area, buf, &mut state, Some("Apple"));

+ let options = vec![
+     SelectOption::group("g", "Fruits"),
+     SelectOption::option("apple", "Apple").description("red"),
+     SelectOption::option("banana", "Banana"),
+ ];
+ let mut state = SelectState::new()
+     .with_recipe(SelectRecipe::Form)
+     .with_searchable(true)
+     .with_value("apple");
+ state.set_focused(true);
+ match state.handle_key(key, &options, bounds) {
+     SelectOutcome::Opened { presentation } => {
+         // host: open_popover_overlay / fullscreen by presentation
+     }
+     SelectOutcome::Closed => {}
+     SelectOutcome::ValueChanged { id } => { /* controlled value */ }
+     SelectOutcome::HighlightChanged { id } => {}
+     SelectOutcome::SearchChanged { query } => {}
+     _ => {}
+ }
+ Select::new(&options, &system)
+     .label("Fruit")
+     .placeholder("Select…")
+     .paint_stacked(area, buf, &mut state);
```

### Value vs highlight

- **Value** — committed selection (`state.value()`)
- **Highlight** — open-list cursor (`state.highlight()` via CollectionState)
- Esc closes without committing highlight

### Recipes

| Recipe | Use |
|--------|-----|
| `Inline` | Default field trigger |
| `Form` | Label + form density |
| `Compact` | Toolbar |

### Tiny terminals

`SelectPresentation::Fullscreen` when bounds width &lt; 28 or height &lt; 10
(or host forces). Outcome `Opened { presentation }` / `PresentationChanged`.
