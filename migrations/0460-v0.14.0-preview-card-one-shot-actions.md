# 0460: PreviewCard physical one-shot actions

## Boundary

`PreviewCardState::handle_key` is the raw keyboard adapter for pinned preview
cards. Held keys must not repeat opening a preview or unpinning it.

## Change

- Only Press events can activate pinned Enter open or Escape/P unpin actions.
- Repeat and Release events are ignored.
- Unpinned previews continue to own no keyboard input.
- Semantic intent and pointer/presence paths are unchanged.

## Host migration

Hosts routing raw PreviewCard events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize pinned open or unpin outcomes from
`Repeat` or `Release` events.
