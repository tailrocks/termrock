# 0181 — EmptyState redesign

## Mission

Useful empty and first-run surfaces instead of blank boxes: title, explanation,
primary/secondary actions, example, shortcut, illustration glyph, contextual
details. Differentiates first-use, no-data, no-results, filtered-out, and
permission-limited. Contracts to concise inline form in small panes. Primary
action stays dominant and safe (never destructive-by-default).

Research: shadcn empty patterns, IDE welcome screens, CLI onboarding.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `EmptyState::new(title, system)` | **Preserved** |
| `.detail(...)` | **Preserved** (alias of `.explanation`) |
| `.glyph(...)` | **Preserved** (illustration override) |
| `Widget` paint for EmptyState | **Preserved** |
| Panel `PanelBody::Empty` using EmptyState | **Preserved** (still title/detail/glyph) |
| Implementation in `view_state.rs` | **Migrated** → `widgets/empty_state.rs` |
| `EmptyKind` (5 kinds) | **Added** |
| `EmptyDensity` Full / Inline | **Added** |
| `EmptyAction`, primary/secondary | **Added** |
| example/context/shortcut fields | **Added** |
| `EmptyStateState` + keyboard/mouse outcomes | **Added** |
| Recipes: table, logs, sessions, projects, search, permission | **Added** |
| Blank title-only centered line as the only API | **Superseded** by rich empty |

`LoadingView` / `ErrorView` / `Banner` stay in `view_state.rs`. Prefer
`ErrorView` for hard failures; EmptyState for zero-data and recovery.

## Consumer edits

```diff
- use termrock::widgets::EmptyState;
+ use termrock::widgets::{
+     EmptyState, EmptyKind, EmptyAction, EmptyDensity, EmptyStateState,
+     example_empty_search, example_empty_table,
+ };

  // Unchanged minimal:
  EmptyState::new("No results", &system).detail("Try another query");

  // Rich empty:
+ EmptyState::new("No results", &system)
+     .kind(EmptyKind::NoResults)
+     .explanation("Try another query")
+     .primary(EmptyAction::with_shortcut("Clear filters", "esc"))
+     .secondary(EmptyAction::new("Edit query"))
+     .context("filters: status=running")
+     .example("status:failed")
+     .shortcut("esc clear · / edit");

  // Small pane:
+ EmptyState::new("No selection", &system).inline();

  // Recipe:
+ example_empty_table(&system).paint(area, buf);
```
