# 0182 — ErrorState and Recovery

## Mission

Structured recoverable failure presentation: summary, human explanation,
technical details (collapsed by default), source, retry, alternative, copy
diagnostics, and report issue. Differentiates validation, network, permission,
not-found, conflict, crash, and unsupported-capability. Explains retry safety
and whether user work was preserved. Recipes: inline, pane, dialog, full-screen.

Research: browser/IDE error surfaces, cloud CLIs, terminal crash recovery.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ErrorView::new(title, system)` | **Preserved** as type alias `ErrorView = ErrorState` |
| `.detail(...)` | **Preserved** (alias of `.explanation`) |
| `Widget` paint | **Preserved** |
| Panel `PanelBody::Error` | **Preserved** (title/detail path) |
| Implementation in `view_state.rs` | **Migrated** → `widgets/error_state.rs` |
| `ErrorState` | **Added** (canonical name) |
| `ErrorKind` (8 kinds) | **Added** |
| `Recovery` + `RecoveryAction` | **Added** |
| `RetrySafety` | **Added** (Safe / Unsafe / Unknown) |
| `ErrorRecipe` Inline/Pane/Dialog/FullScreen | **Added** |
| `ErrorStateState` (details expand + focus) | **Added** |
| `ErrorStateOutcome` | **Added** |
| Domain examples (`example_error_*`) | **Added** |
| Title-only danger line as sole API | **Superseded** by structured recovery |

`EmptyState` stays for zero-data; hard failures use `ErrorState` / `ErrorView`.
`LoadingView` / `Banner` remain in `view_state.rs`.

## Consumer edits

```diff
- use termrock::widgets::ErrorView;
+ use termrock::widgets::{
+     ErrorState, ErrorView, ErrorKind, Recovery, RecoveryAction, RetrySafety,
+     ErrorStateState, example_error_network,
+ };

  // Unchanged minimal:
  ErrorView::new("Failed", &system).detail("Timed out");

  // Structured recovery:
+ let err = ErrorState::new("Request failed", &system)
+     .kind(ErrorKind::Network)
+     .explanation("Could not reach the API")
+     .technical("timeout after 30s: GET /v1/jobs")
+     .source("jobs-service")
+     .recovery(
+         Recovery::none()
+             .with_retry(RecoveryAction::with_shortcut("Retry", "r"))
+             .with_retry_safety(RetrySafety::Safe)
+             .with_copy_diagnostics(true)
+             .with_work_preserved(true, Some("Draft retained")),
+     );
+ let mut state = ErrorStateState::new(); // details collapsed by default
+ err.paint_with_state(area, buf, &mut state);
+ // host: on CopyDiagnostics → clipboard err.diagnostics_text()
```
