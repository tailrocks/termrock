# 0155 — Breadcrumbs

## Mission

Location context and ancestor navigation for files, routes, schemas, and object
paths. Single host Tab stop; Left/Right among segments. Collapse keeps root and
current; middle becomes ellipsis / overflow menu. Optional editable path mode.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `menu_nav::Breadcrumbs` (join labels only) | **Migrated** → `breadcrumbs.rs` |
| `BreadcrumbItem` / `BreadcrumbsState` / `Navigate` / `OpenOverflow` | **Preserved** (expanded) |
| `FilePicker` `FileBreadcrumb` | **Preserved** — path-specific; compose via adapter |
| Status, editable mode, separators, hits | **Added** |

## Consumer edits

```diff
- Breadcrumbs::new(&items, &system).render(area, buf, &state);
+ let mut state = BreadcrumbsState::new().with_editable(true);
+ state.set_focused(true);
+ match state.handle_key(key, &items) {
+     BreadcrumbsOutcome::Navigate(id) => host.go(id),
+     BreadcrumbsOutcome::OpenOverflow { ids } => host.menu(ids),
+     BreadcrumbsOutcome::EditCommitted { path } => host.set_path(path),
+     _ => {}
+ }
+ let hits = Breadcrumbs::new(&items, &system)
+     .ascii(false)
+     .separator(BreadcrumbSeparator::Slash)
+     .paint(area, buf, &mut state);
+ // mouse: state.handle_mouse(ev, &items, &hits)
```

### Semantics

| Concept | Behavior |
|---------|----------|
| Tab stops | **One** control; Left/Right inside |
| Collapse | First + `…` + current (width < 40, len > 3) |
| Current | Bold + underline (no-color) |
| Editable | Ctrl+E or `/` or Enter on current |
| Overflow | Enter on ellipsis → `OpenOverflow` |

### Compose

- FilePicker path chrome  
- Schema browser object path  
- Master-detail header
