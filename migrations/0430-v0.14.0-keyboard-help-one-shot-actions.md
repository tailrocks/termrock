# 0430: KeyboardHelp one-shot actions

## Boundary

`KeyboardHelpState::handle_key` treats modal open and close triggers as
physical key-press actions. A held key must not reopen the help modal, reset
its query, or close the modal repeatedly.

## Change

- `Press` `?` opens modal help from Footer mode; Repeat and Release are
  ignored.
- `Press` Escape closes Modal mode; Repeat and Release are ignored before
  query text input can cancel its draft.
- Modal query editing and arrow/page navigation retain their repeatable
  behavior.

## Host migration

Hosts routing raw KeyboardHelp events must continue passing the complete
`KeyEvent`, including its lifecycle kind. Do not synthesize modal open or
close outcomes for Repeat or Release events; the state adapter consumes those
events as no-ops.
