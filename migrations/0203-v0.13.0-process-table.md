# 0203 — ProcessTable process / task monitor

## Mission

Process and task monitoring table with tree and flat modes: PID, command, CPU,
memory, status, user, elapsed time, hierarchy, search, sort, filters, details,
signals, and refresh cadence. Selection survives refresh and process churn via
**stable identity** (`ProcessKey` = pid + start marker). Safe signal /
terminate / kill confirmation. Host owns enumeration and signal syscalls.

Research: btop, bottom, htop, procs, process explorers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TreeTable` / `TreeTableState` / `TreeTableRow` | **Preserved** — generic hierarchy+columns substrate; process demos may stay |
| `DataTable` / `ColumnModel` / `VirtualWindow` / `SortSpec` / `LoadState` | **Preserved** — layout/window/load kits reused |
| `process_column_model()` | **Added** — default process columns |
| `ProcessKey` · `ProcessRow` · `ProcessTable` · outcomes | **Added** |
| Host `sysinfo` / `procfs` / kill(2) | **Never in TermRock** — outcomes only |
| TreeTable process lookbook story | **Preserved** — generic TreeTable demo; ProcessTable has its own stories |

### Keys (htop/btop-class)

| Key | Action |
|-----|--------|
| j/k · arrows · PgUp/Dn · Home/End | Navigate visible projection |
| `/` · Esc · Backspace | Filter enter / cancel / edit |
| `s` / `S` | Cycle sort key / flip ascending |
| `t` | Flat ↔ tree |
| `r` | Refresh request |
| `x` / `K` / `C-9` | TERM / KILL (confirm) |
| `C-c` | INT request |
| `i` · Enter | Details |
| `y` | Copy command line(s) |
| Space | Multi-check (when enabled) |
| `+` / `-` | Refresh cadence chrome (×2 / ÷2) |
| Confirm Enter/y · Esc/n | Accept / cancel signal |

## Stable identity

```text
ProcessKey { pid, start_ms }
```

Never key selection on PID alone — recycled PIDs would silently retarget signals.
