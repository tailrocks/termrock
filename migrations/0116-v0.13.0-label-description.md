# 0116 — Label & Description field captions

## Mission

Consistent labeling for fields, settings, controls, and metadata: semantic
association with target ids, required/optional/disabled/invalid/warning/help
states, stacked/inline/compact recipes, description-before-label contraction,
and semantic-scene help strings for inspection.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Text` / `TextSpan` | **Preserve** — paint primitive |
| `FormField` label/help/error as `Line` | **Preserve** data model |
| `Form` paint of label + supporting | **Migrated** → `Label` + `Description` |
| Toolbar `Label` item kind | **Preserve** — toolbar chrome, not form labels |
| `Card` description line | **Preserve** — card body blurb |
| `Section::description` | **Preserve** — section chrome |
| `Label`, `Description`, `FieldCaption`, marks/tones/layouts | **Added** |
| `line_plain` | **Added** — `Line` → plain for Label paint |

## API sketch

```rust
use termrock::widgets::{
    Label, Description, FieldCaption, CaptionLayout, LabelTone, DescriptionKind,
};

// Standalone label
Label::new("Name", &system)
    .for_id("name")
    .required()
    .focused()
    .paint(area, buf);

// Description kinds
Description::new("help text", &system).for_id("name");
Description::error("must be unique", &system);
Description::warning("deprecated", &system);
Description::meta("synced 2m ago", &system);

// Caption = label + description (descriptions drop first when narrow)
FieldCaption::new("Endpoint", &system)
    .for_id("ep")
    .required()
    .help("https://…")
    .stacked() // or .compact() / .inline()
    .paint(area, buf);

// Semantic scene
label.register_semantic(&mut scene, "lbl-name", area);
// description includes "required; for=name"
```

## Contraction

| Width | Behavior |
|------:|----------|
| ≥ 28 | Description paints |
| < 28 | Description contracted; label remains |
| < 14 (compact) | Required/optional marks may drop |

Constants: `DROP_DESCRIPTION_WIDTH`, `DROP_MARK_WIDTH`.

## Form migration

`Form` field rows paint labels via `Label` (required `*`, disabled `⊘`/`x`,
invalid/focus tones) and supporting help/error via `Description` (auto-contracts
under narrow columns). `FormField` still stores `Line` values; `line_plain`
bridges to the caption primitives.
