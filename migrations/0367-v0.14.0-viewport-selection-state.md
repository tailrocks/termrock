# 0367: Stateful selectable Viewport

## Boundary

`Viewport` interaction state must survive rebuilding the borrowed render
configuration. Scroll offsets, pointer selection, drag anchors, and measured
cell layout now belong to a caller-owned state value.

## Change

`Viewport`'s `StatefulWidget` state is now `ViewportState`, not
`DialogScroll`. `ViewportState::scroll` carries the two-axis offsets.
`Viewport` exposes pointer selection, word selection, copy, Escape clearing,
selection-aware rendering, and scrollbar routing. `ViewportEvent::Copy` is
returned for the host clipboard implementation.

## Consumer impact

Replace `DialogScroll` viewport state with `ViewportState` and read or write
offsets through `state.scroll`. Pass the state to `Viewport::on_mouse`,
`Viewport::on_key`, and selection helpers. Handle `ViewportEvent::Copy` in the
host. `CellPos`, `ViewportEvent`, and `ViewportState` are available from
`termrock::widgets`.
