# 0153 — Sidebar & NavigationList

## Mission

Primary application navigation with sections, hierarchy, badges, status, and
responsive collapse (expanded / rail / drawer / palette). **Route state is
distinct from keyboard focus.** Integrates with AppShell start dock and
semantic command ids.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `menu_nav::Sidebar` / `SidebarItem { id, label, enabled }` | **Migrated** → `sidebar.rs` |
| `SidebarState::{selected, expanded, cursor_index, accepts_input}` | **Migrated** — route vs focus; presentation enum |
| `SidebarOutcome::{Ignored, Selected, ToggleRail}` | **Preserved** (+ richer variants) |
| `ResourceBrowser` sidebar composition | **Preserved** (same Selected outcome) |
| `AppShell` layout slots | **Preserved** — paint Sidebar into start dock |
| `NavigationList` / `NavItem` / hierarchy / filter | **Added** |
| `example_*_nav` projectors | **Added** (database, settings, agent) |

## Consumer edits

```diff
- use termrock::widgets::menu_nav::{Sidebar, SidebarItem, SidebarState, SidebarOutcome};
+ use termrock::widgets::{
+     Sidebar, SidebarItem, SidebarState, SidebarOutcome, SidebarPresentation,
+     NavigationList, NavItem, example_settings_nav,
+ };

  let items = [
-     SidebarItem::new("a", "A"),
+     NavItem::new("a", "Profile").command("settings.profile").depth(1),
+     // SidebarItem is type alias for NavItem
  ];
  let mut state = SidebarState::new(Some("a"));
+ state.set_focused(true);

  match state.handle_key(key, &items) {
      SidebarOutcome::Selected(id) => host.navigate(id), // route changed
+     SidebarOutcome::FocusChanged { id } => { /* optional a11y */ }
      SidebarOutcome::ToggleRail { expanded } => { /* layout */ }
+     SidebarOutcome::OpenPalette | SidebarOutcome::OpenDrawer => { /* shell */ }
+     SidebarOutcome::ExpandToggled { id, expanded } => host.set_expand(id, expanded),
      _ => {}
  }

- Sidebar::new(&items, &system).render(area, buf, &state);
+ Sidebar::new(&items, &system)
+     .show_panel(true)
+     .title("Settings")
+     .paint(area, buf, &mut state);
```

### Route ≠ focus

| Field | Meaning |
|-------|---------|
| `route()` / `selected()` | Active destination |
| `focus()` | Keyboard cursor (roving) |
| Enter / click leaf | Sets route |

### Presentation

| Mode | When |
|------|------|
| Expanded | Full labels |
| Rail | Compact (`[` toggle or width < 12) |
| Drawer | Host overlay (`Ctrl+B` outcome) |
| Palette | Host command palette (`Ctrl+P` outcome) |

### Stories

- `sidebar/settings`, `sidebar/database`, `sidebar/agent`, `sidebar/rail`
- `navigation-list/basic`
