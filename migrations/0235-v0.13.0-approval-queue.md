# 0235 — ApprovalQueue unified human decisions inbox

## Mission

Unified surface for pending permissions, questions, plans, diffs, and other
human decisions: priority, type, actor, age, blocking, summary, preview; open,
approve where **safe**, defer, dismiss. **Never** one-click bulk for high-risk.
Preserve protocol FIFO where required. Badge / drawer / full views. Project to
NotificationCenter and TaskRail.

Research: agent approval flows, code review queues, security request dashboards.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `PermissionPrompt` / `PermissionQueue` | **Preserved** — full trust-gate UI; queue opens them |
| `QuestionFlow` / `PlanReview` / DiffReview | **Preserved** — full HITL; items reference them |
| `NotificationCenter` / `TaskRail` | **Preserved** — receive projections |
| `ApprovalQueue` / `ApprovalItem` | **Added** |
| Nothing deleted | |

## API

```rust
use termrock::widgets::{
    ApprovalQueue, ApprovalQueueState, ApprovalQueuePresentation,
    ApprovalQueueOutcome, example_approval_queue,
    approval_items_to_notifications, approval_items_to_activity_models,
};

let mut state = ApprovalQueueState::new();
state.set_items(example_approval_queue());
ApprovalQueue::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    ApprovalQueueOutcome::Open { id, kind, generation } => {
        // route to PermissionPrompt / QuestionFlow / PlanReview / DiffReview
    }
    ApprovalQueueOutcome::ApproveRequested { id, generation } => {
        // only Low/Medium; host re-validates
    }
    ApprovalQueueOutcome::BulkApproveDenied { reason, blocked } => {
        // never silent grant
    }
    ApprovalQueueOutcome::BulkApproveRequested { ids } => {
        // Low-only multi-select
    }
    _ => {}
}

// Integrations
let notes = approval_items_to_notifications(&state.items, now);
let tasks = approval_items_to_activity_models(&state.items);
```

### Safety

| Rule | Detail |
|------|--------|
| Default action | **Open** (never Approve) |
| High/Critical | Quick approve **denied**; must Open |
| Bulk (`A`) | Low-risk only; mixed selection **denied** |
| `y` | Unbound |
| Protocol kinds | Permission/Question keep FIFO among peers |
