# 0374 — v0.14.0 add the host supplied Lockup widget

## Boundary

`Lockup` is a new public widget for a host supplied identity mark. The default
form adds one display cell of padding; `.compact()` removes that padding.
`width()` uses terminal display cells. `paint` and `paint_with_state` return
`LockupParts`, whose `content` rectangle is the clipped painted region.

## Host integration

Existing host APIs do not change. Use the parts returned by the same paint
operation when registering semantics:

```rust
let lockup = Lockup::new(mark, &system);
let parts = lockup.paint(area, &mut buffer);
lockup.register_semantic(&mut scene, id.clone(), parts, true);

let state = LockupState {
    hovered: true,
    pressed: false,
};
let parts = lockup.paint_with_state(area, &mut buffer, state);
lockup.register_semantic_with_state(&mut scene, id, parts, true, state);
```

The host supplies the mark and owns its action. Hover and press styling use the
accent palette; only the pressed flag is represented in semantic state.

## Rollback

This addition is optional. Hosts can keep their existing renderer or remove
Lockup calls when rolling back to a build that does not export the widget.
