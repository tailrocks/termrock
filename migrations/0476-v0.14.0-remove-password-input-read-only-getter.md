# 0476: Remove the unreferenced PasswordInput read-only getter

## Boundary

`PasswordInputState::is_read_only` had no call sites in the complete workspace
corpus. Password masking, reveal policy, and read-only edit guards remain
state-owned; only the unreferenced public projection is removed.

## Change

- Remove `PasswordInputState::is_read_only` completely.
- Preserve `set_read_only`, read-only enforcement, and the distinct getters on
  other input state types.

## Host migration

Consumers needing the setting must retain the value they pass to
`set_read_only`; no compatibility alias or deprecation period is provided.
