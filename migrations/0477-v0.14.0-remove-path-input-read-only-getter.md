# 0477: Remove the unreferenced PathInput read-only getter

## Boundary

`PathInputState::is_read_only` had no call sites in the complete workspace
corpus. Path read-only behavior remains enforced and propagated to the nested
editor; only the unreferenced public projection is removed.

## Change

- Remove `PathInputState::is_read_only` completely.
- Preserve `set_read_only`, nested-editor propagation, completion guards, and
  the distinct getters on other input state types.

## Host migration

Consumers needing the setting must retain the value they pass to
`set_read_only`; no compatibility alias or deprecation period is provided.
