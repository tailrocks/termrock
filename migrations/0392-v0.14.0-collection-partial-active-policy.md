# 0392: Partial collection windows expose active-ID policy

## Boundary

A missing active ID in a partial projection is ambiguous: it may be outside
the window or no longer valid.

## Change

`CollectionState::reconcile_window` now takes `VirtualWindowActivePolicy`.
`PreserveMissing` retains off-window identity; `InvalidateMissing`
authoritatively clears or reconciles absent IDs even for partial empty or
disabled projections. `ListState` exposes the same policy and defaults to
`PreserveMissing`.

## Consumer impact

Existing virtual-window behavior remains preservation-first. Hosts that know
the active ID was removed must set `InvalidateMissing` before reconciliation.
