# 0062 — InteractionScene sole focus authority (pre-1.0 M3 / Break C0 + F collections)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| Public `FocusRing`, `FocusTarget`, `FocusOutcome` | `InteractionScene` (+ host-local focus ring only if needed) |
| Public `SemanticScene` registration authority | Register elements on `InteractionScene` only |
| `ListState` / `TreeState` / `TableState` / `VirtualGridState` `set_focused` / `is_focused` / `focused` field | Host gates keys via scene; paint via `Widget::focused(bool)` |
| Widget handlers early-return when “unfocused” | Handlers always apply when **called**; host must not dispatch |

**Residual (not removed this MS):** editor/chrome `set_focused` on `TextArea`, `PromptComposer`, controls, `SplitPane`, etc. (accepts-input / surface enable — rename to `set_accepts_input` follows). Form still owns field focus until M8 interim is completed. Lookbook uses a **host-local** `FocusRing` copy (`host_focus.rs`) until full InteractionScene HostFrame cutover.

## Canonical replacement

### Collections

```rust
// Host
if scene.focused() == Some(&list_id) {
    state.handle_key(&rows, key);
}
List::new(&rows, &system)
    .focused(scene.focused() == Some(&list_id))
    .render(area, buf, &mut state);
```

### Library focus

```rust
use termrock::interaction::{InteractionScene, InteractionElement, InteractionLayer};
// NOT: termrock::interaction::FocusRing
```

## Consumer edits

1. Delete all `list_state.set_focused(true)` / `tree_state.set_focused` / table / virtual grid focus APIs.
2. Only call collection `handle_key` / `handle_intent` when the surface owns scene focus.
3. Pass `.focused(bool)` into `List` / `Tree` / `Table` / `VirtualGrid` for selection underline / chrome.
4. Stop importing public `FocusRing` — migrate to `InteractionScene` or own host focus registry.

## What becomes simpler

One focus truth for collections: scene (or host) decides; widgets pure outcomes + paint flag.

## New constraints

- Collection widgets must not store keyboard-focus authority.
- Hosts that call `handle_key` on unfocused collections will process keys (by design).
