# 0067 — Form scene-owned field focus (Break F remainder)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `FormOutcome::FocusChanged` | Host `InteractionScene::focus` / `focus_move` |
| `FormState.focused` / `FormState::focus` / `FormState::focused()` | `Form::focused_field(Option<&Id>)` paint param |
| Tab / Up / Down / Home / End field cycle in `FormState::handle_key` | Host scene field registration + tab/esc |
| Click-to-focus inside form | Host: `hit_id` → `scene.focus`; form `click` only **activates** when already focused |
| `set_active` / `is_active` as primary names | `set_accepts_input` / `accepts_input` (deprecated aliases kept briefly) |

## Canonical replacement

```rust
use termrock::interaction::InteractionScene;
use termrock::widgets::{Form, FormState, FormOutcome, FormSection};

// Host owns field focus
let focused = scene.focused(); // Option<&FieldId>

Form::new(&sections, &system)
    .focused_field(focused)
    .render(area, buf, &mut state);

// After paint: register each field region on the scene
for region in state.field_regions() {
    scene.register(InteractionElement::control(
        region.id.clone(),
        form_layer,
        region.area,
    ));
}

// Keys: Tab via scene; Enter via form with host focus
if let Some(intent) = default_form_intent(key) {
    let _ = state.handle_intent(&sections, intent, scene.focused());
}

// Pointer
if let Some(id) = state.hit_id(pos).cloned() {
    if scene.focused() != Some(&id) {
        let _ = scene.focus(id);
        state.ensure_visible(Some(id));
    } else {
        let _ = state.click(pos, scene.focused());
    }
}
```

## Consumer edits

1. Delete matches on `FormOutcome::FocusChanged`.
2. Stop calling `FormState::focus` / reading `focused()`.
3. Pass scene focus into `Form::focused_field` every paint.
4. Register field rects on `InteractionScene` each frame.
5. Prefer `set_accepts_input` over `set_active`.
