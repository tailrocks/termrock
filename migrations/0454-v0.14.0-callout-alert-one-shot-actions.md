# 0454: Callout alert physical one-shot actions

## Boundary

`AlertState::handle_key_with` is the raw physical keyboard adapter for
acknowledgement, dismissal, action activation, and detail disclosure. A held
key must not repeat those host-facing outcomes or state transitions.

## Change

- Bare Escape dismissal, Enter acknowledgement/action activation, and `d`
  detail toggling now require a single `Press` event.
- Repeat remains supported for action-bar navigation and typed-entry behavior.
- Semantic `handle_intent_with` remains phase-free for keymap-driven hosts.

## Host migration

Hosts routing raw Alert keyboard events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize repeated dismiss, acknowledge,
action, or detail-toggle outcomes from `Repeat` or `Release` events.
