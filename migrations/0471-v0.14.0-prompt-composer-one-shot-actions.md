# 0471: PromptComposer physical one-shot actions

## Boundary

`PromptComposerState::handle_key` is the composer-level adapter for host
shortcuts, cancellation, completion layers, chip focus, and chip mutation.
Held keys must not repeat host side effects or remove multiple chips.

## Change

- Only `Press` events emit copy/interrupt, external-editor, busy-cancel,
  attach, and fullscreen requests.
- Only `Press` events focus or mutate the chip strip for BackTab, Delete,
  Backspace, Enter, and Esc actions.
- Text editing, caret navigation, selection extension, and history motion retain
  their repeatable behavior.

## Host migration

Hosts routing raw `PromptComposer` events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize host or chip outcomes from `Repeat`
or `Release`.
