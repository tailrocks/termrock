# 0467: SetupWizard physical one-shot actions

## Boundary

`SetupWizardState::handle_key` is the pattern-level keyboard adapter for safe
cancel confirmation, summary detail toggling, and progress persistence. Held
keys must not repeat cancellation transitions or host-facing one-shot
outcomes.

## Change

- Only Press events can open, dismiss, or confirm the safe-cancel layer.
- Only Press events can toggle summary detail or request progress save.
- Delegated child surfaces retain their own lifecycle and repeatable navigation
  contracts.
- Release events remain ignored.

## Host migration

Hosts routing raw SetupWizard events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize cancel, summary, or save outcomes
from `Repeat` or `Release` events.
