# 0391: Full collection windows repair stale active IDs

## Boundary

Off-window active preservation applies only to partial virtual projections;
full projections contain enough information to reconcile stale identities.

## Change

`CollectionState::reconcile_window` now preserves a missing active ID only when
the supplied window is genuinely partial. Full windows repair stale active IDs
through normal enabled-row reconciliation, including the all-disabled case.

## Consumer impact

Virtual windows retain their off-window identity contract. Full-window and
all-disabled projections no longer keep an active ID that is absent or invalid.
