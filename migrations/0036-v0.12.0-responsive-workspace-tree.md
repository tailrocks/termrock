# 0036 — Responsive workspace tree

## Canonical addition

```rust
use termrock::layout::{
    PaneConstraint, PaneId, Workspace, WorkspaceAxis, WorkspaceNode, WorkspaceState,
};

let ws = Workspace::new(WorkspaceNode::Split {
    axis: WorkspaceAxis::Horizontal,
    ratio_percent: 30,
    first: Box::new(WorkspaceNode::Leaf {
        id: PaneId::from_static("rail"),
        constraint: PaneConstraint::Min(12),
        collapse_priority: 0,
    }),
    second: Box::new(WorkspaceNode::Leaf {
        id: PaneId::from_static("main"),
        constraint: PaneConstraint::Weight(1),
        collapse_priority: 1,
    }),
});
let mut state = WorkspaceState::new();
let panes = ws.layout(area, &state); // every rect ⊆ area
```

`WorkSurface` remains for flat region tracks. Prefer `Workspace` for nested
pane trees with collapse/zoom.

## Ownership

TermRock owns containment and collapse under pressure. Consumers own domain
content painted into pane rects and product collapse policy triggers.
