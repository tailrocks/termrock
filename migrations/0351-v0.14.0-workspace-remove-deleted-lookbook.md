# 0351: Workspace membership matches the canonical catalog

## Boundary

The canonical catalog merge removed the legacy `termrock-lookbook` crate, but
the root workspace still referenced its deleted manifest.

## Change

Remove the deleted lookbook path from the workspace members so Cargo metadata,
checks, tests, and documentation operate on the crates that exist.

## Consumer impact

No Rust API changes. Workspace consumers must use the canonical catalog crate;
the removed lookbook path is no longer a valid package target.
