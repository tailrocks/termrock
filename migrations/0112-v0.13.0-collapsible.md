# 0112 — Collapsible disclosure primitive

## Mission

Accessible expand/collapse primitive for optional detail: controlled or
uncontrolled open state, trigger + content anatomy, disabled, nested depth,
semantic Expand/Collapse/Toggle/Activate intents, keep-mounted policy for child
state, and inline/section variants with glyph and ASCII fallbacks.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Section::collapsible` / `SectionState` collapse | **Preserve** — editorial chrome that may collapse its body |
| `Panel::collapsible` / panel header collapse | **Preserve** — bordered region chrome |
| `Tree` branch disclosure | **Preserve** — collection hierarchy, not free-form detail |
| `ThinkingBlock` | **Migrated** — disclosure glyphs from `DesignSystem` / `GlyphSet` (no hard-coded ▾/▸) |
| `Collapsible` + state/parts/outcomes | **Added** — product-neutral disclosure primitive |
| Ad-hoc ▾/▸ labels for tool detail | **Migrate** → `Collapsible` |

Compose Section/Panel when you need chrome; use `Collapsible` when you only need
a disclosure trigger + optional body band (tool args, optional forms, nested
detail without a panel border).

## API sketch

```rust
use termrock::widgets::{
    Collapsible, CollapsibleState, CollapsibleVariant,
    CollapsedContentPolicy, CollapsibleOutcome,
};

let system = DesignSystem::default();
let mut state = CollapsibleState::new();
state.set_focused(true);

// Uncontrolled: state owns open
let body = Collapsible::new("Tool details", &system)
    .inline() // or .section()
    .paint(area, buf, &mut state);
if body.height > 0 {
    // paint children into body
}

// Controlled: host open flag each frame
let body = Collapsible::new("Details", &system)
    .open(host_open)
    .keep_mounted() // host retains child domain state while closed
    .depth(1)
    .paint(area, buf, &mut state);

// Interaction
let out = state.handle_key(key, disabled, Some(host_open) /* or None */);
// Opened / Closed / Ignored — controlled path does not mutate state.open
if let Some(open) = out.open() {
    host_open = open;
}
```

## Intents / focus

| Intent / input | Result |
|----------------|--------|
| Activate / Toggle (Enter, Space) | toggle open |
| Expand (Right, `l`) | open if closed |
| Collapse (Left, `h`) | close if open |
| Mouse down on trigger | focus + toggle |
| Disabled | ignore keys/mouse |

Focus stays on the **trigger**. Host registers content descendants in the focus
graph only while open. `CollapsedContentPolicy::KeepMounted` is a host signal:
geometry is still zero when closed; domain state may live.

## Variants

| Variant | Trigger paint |
|---------|---------------|
| `Inline` (default) | `Role::Text` |
| `Section` | `Role::TextStrong` + rule fill when open |

Glyphs: `GlyphSet::disclosure_open/closed` (Unicode ▾/▸, ASCII `v`/`>`).

## vs Section / Panel / Tree

| | Collapsible | Section | Panel | Tree |
|--|-------------|---------|-------|------|
| Border box | no | no | yes | no |
| Mission | disclosure | editorial group | region chrome | hierarchy |
| Nested | depth indent | depth indent | N/A | branch nodes |
