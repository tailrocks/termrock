# 0248 — AuthEntry (shadcn signup blocks TUI peer)

## Mission

Ship a keyboard-first **auth-entry** composition covering the CLI-honest job of
shadcn signup blocks (signup-01…04): multi-field identity + password, optional
confirm/terms, validation, submit/cancel, sign-up ↔ sign-in switch. Host owns
network auth and secrets.

Matrix: `docs/design/shadcn-signup-blocks-coverage.md`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` / `PasswordInput` / `PasswordConfirmState` / `Checkbox` / `Panel` | **Preserved** — composed, not forked |
| `SetupWizard` account step | **Preserved** — multi-step onboarding peer |
| Dual product-branded signup screens | **Forbidden** — product-neutral AuthEntry only |
| Cover-image / marketing hero chrome | **N/A** — optional aside text only |
| `AuthEntryState` · `render_auth_entry` · `AuthEntryOutcome` | **Added** (`patterns/auth_entry`) |

## Consumer API

```rust
use termrock::patterns::{
    AuthEntryState, AuthEntrySurfaces, AuthEntryOutcome, AuthEntryMode,
    example_auth_aside_lines, render_auth_entry,
};

let mut state = AuthEntryState::sign_up(); // or ::sign_in()
// optional: state.set_require_terms(false);

match state.handle_key(key) {
    AuthEntryOutcome::Submitted { identity, password_filled, .. } => {
        let secret = state.take_password_secret(); // host vault / network
        let _ = (identity, password_filled, secret);
    }
    AuthEntryOutcome::ValidationFailed { errors } => { /* show errors */ }
    AuthEntryOutcome::ModeSwitched { mode } => { /* chrome */ }
    AuthEntryOutcome::Cancelled => { /* dismiss */ }
    AuthEntryOutcome::SecondaryAction { id } => { /* oauth / forgot */ }
    _ => {}
}

let mut surfaces = AuthEntrySurfaces::english(&system, &mut state);
surfaces.aside_lines = example_auth_aside_lines(); // signup-02/04 text peer
render_auth_entry(buf, area, surfaces);
```

### Laws

| Law | Detail |
|-----|--------|
| Secrets | Outcomes never embed password plaintext; use accessors |
| Host I/O | No network, OAuth, or vault inside pattern |
| Keyboard | Tab fields · Enter submit · Esc cancel · Ctrl+G mode |
| Image chrome | Aside lines only — no continuous image theater |
