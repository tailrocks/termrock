# 0099 — Center layout primitive

## Mission

Rigorous axis-aware centering with max/min constraints, margins, and safe
tiny-terminal behavior. Pure geometry — no fake interactive semantic node.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `centered_rect` | **Preserve** — now implemented via `Center::dialog` |
| `resolve_dialog` centered placement | **Migrated** onto `Center` |
| `layout::{Center, CenterSpec, layout_center, …}` | **Added** |
| EmptyState / LoadingView / ErrorView vertical block | **Migrated** onto `Center` + Stack |
| `paint_centered_line` | **Uses** `center_line_x` |

## API

```rust
use termrock::layout::{Center, CenterAxis, centered_rect};

// Both axes
let child = Center::new(40, 12).layout(area).child;

// Dialog (1-cell safe margin when room)
let child = Center::dialog(52, 9).layout(area).child;
// equivalent: centered_rect(52, 9, area)

// Horizontal strip only
let strip = Center::new(20, 1)
    .axis(CenterAxis::Horizontal)
    .layout(area)
    .child;

// Caps
let child = Center::new(100, 20)
    .max_width(48)
    .max_height(16)
    .min(12, 4)
    .margin(2, 1)
    .layout(area)
    .child;
```

## Semantics

Center does **not** register focus or semantics. Hosts paint children into
`CenterLayout::child` and register the **child** interactive nodes only.
