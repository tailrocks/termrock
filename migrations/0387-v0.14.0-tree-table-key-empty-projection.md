# 0387 — v0.14.0 TreeTable key routing for empty projections

## Root cause

`TreeTableState::handle_key` returned before mapping keys to `UiIntent`, so
the existing empty-projection fallback in `handle_intent` was unreachable from
keyboard input.

## Change

Empty ready or partial projections now route mapped vertical keys through
`handle_intent`, enabling Up, Down, PageUp, and PageDown virtual scrolling.
Non-vertical keys remain ignored, and load-state retry handling remains first.

## Consumer impact

No consumer edit is required. Hosts can navigate empty partial projections
while their virtual slice is being reloaded or reprojected.
