# 0474: Remove the orphan backdrop adapter

## Boundary

`termrock::interaction::paint_backdrop` was an unused free-function adapter.
`OverlayStack::paint_backdrop` is the live owner of backdrop painting and
already resolves the active overlay policy.

## Change

- Remove the free `interaction::paint_backdrop` function and its private module.
- Preserve `OverlayStack::paint_backdrop` as the only backdrop paint entry.

## Host migration

Hosts calling the removed free function must retain the owning
`OverlayStack` and call:

```rust
stack.paint_backdrop(buffer, system);
```

No compatibility alias or deprecation period is provided.
