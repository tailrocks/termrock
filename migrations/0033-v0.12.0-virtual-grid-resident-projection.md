# 0033 — VirtualGrid resident projection contract

## Removed surface

These methods no longer accept columns as their only borrowed projection:

```rust
state.handle_key(event, columns)
state.handle_mouse(event, columns)
```

No compatibility overload remains.

## Canonical replacement

Pass the same current resident row projection used to render the grid:

```rust
state.handle_key(event, columns, rows)
state.handle_mouse(event, columns, rows)
```

The interaction boundary now resolves stable row IDs, honors `GridRow::enabled`,
and applies the authoritative `total_rows` boundary. Rendering stops before
known dataset end, does not publish phantom hit regions, and computes range
selection from the actual anchor and cursor.

Resident rows should be ordered by absolute `GridRow::index` for binary lookup.
Unordered projections remain correct through a linear fallback.

## Exact consumer edits

Before:

```rust
let outcome = state.handle_key(key, &columns);
let pointer_outcome = state.handle_mouse(mouse, &columns);
```

After:

```rust
let outcome = state.handle_key(key, &columns, &resident_rows);
let pointer_outcome = state.handle_mouse(mouse, &columns, &resident_rows);
```

Handle the `row_id` already carried by `CursorMoved` and `Activated` when the
cursor row is resident:

```rust
if let VirtualGridOutcome::Activated { row_id: Some(id), .. } = outcome {
    activate_row(id);
}
```

Set `GridRow::enabled = false` for projected rows that must remain visible but
must not accept keyboard or pointer selection.

## Removed concepts

- Interactive rows beyond a known `total_rows`
- Selectable disabled resident rows
- `row_id: None` for every keyboard outcome regardless of residency
- Cell range styling derived from each cell rather than anchor/cursor bounds
- Interaction handlers disconnected from the rendered row projection

## Ownership changes

TermRock owns dataset-boundary enforcement, enabled-row navigation, resident ID
resolution, selection geometry, and range chrome. Consumers own the backing
dataset, paging/fetching, resident projection lifetime, domain activation, and
effects triggered from typed outcomes.
