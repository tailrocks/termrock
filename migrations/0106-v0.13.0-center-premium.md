# 0106 — Center premium placement

## Mission

Small, rigorous primitive for centering and constrained content: horizontal /
vertical / both axes, max/min bounds, safe margins, tiny-terminal safety.
Pure geometry — never a fake interactive semantic node.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Center`, `CenterSpec`, `CenterAxis`, `CenterLayout`, `layout_center` | **Preserve** (expanded) |
| `centered_rect`, `center_line_x`, `center_block_y` | **Preserve** |
| `resolve_dialog` centered placement | **Preserve** — uses Center (+ safe margin / max) |
| EmptyState / LoadingView / ErrorView | **Preserve** — already Center + Stack |
| `Center::onboarding` / `Center::failure` recipes | **Added** |
| `CenterLayout::register_child_semantics` | **Added** (child only, never Center) |
| `CenterLayout::debug_summary`, `max()`, `size()` | **Added** |
| Full-dimension property tests | **Added** |
| Fake “center” focus targets | **Deleted** (never ship) |

## API sketch

```rust
use termrock::layout::{Center, CenterAxis, centered_rect};

// Both axes
let child = Center::new(40, 12).layout(area).child;

// Dialog (1-cell safe margin when room)
let child = Center::dialog(52, 9).layout(area).child;
// alias: centered_rect(52, 9, area)

// Onboarding / failure recipes
let hero = Center::onboarding(48, 10).layout(area).child;
let fail = Center::failure(40, 8).layout(area).child;

// Caps + mins
let child = Center::new(100, 20)
    .max(48, 16)
    .min(12, 4)
    .margin(2, 1)
    .layout(area)
    .child;

// Single-axis
let strip = Center::new(20, 1)
    .axis(CenterAxis::Horizontal)
    .layout(area)
    .child;

// Semantics: register the **child**, never Center itself
layout.register_child_semantics(&mut scene, "empty", "No items");
```

## Semantics

Center does **not** claim focus or paint. Hosts:

1. Resolve `CenterLayout::child`
2. Paint domain widgets into `child`
3. Register those widgets (or `register_child_semantics` for static content)

## Safety

- Saturating arithmetic only; child ⊆ outer always
- Empty outer → zero-size child
- Preferred size clamped after margins and max/min
- Property tests cover outer widths 0..=40, multiple heights, all axes, safe margin on/off

## Migrated call sites

- `EmptyState` / `ErrorView` / `LoadingView` (vertical Center + Stack)
- `resolve_dialog` / `centered_rect` / overlay dialog placement path
- Studio stories: `center/{both,dialog,horizontal,max,tiny,vertical,onboarding,failure}`
