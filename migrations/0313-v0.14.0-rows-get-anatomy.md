# 0313 — Rows get anatomy

Ten data widgets built each row as one `format!` or `join(" ")` and painted it
with one style: timestamp, source, level, message and counts all arrived in the
same voice. The text ladder — primary, muted secondary, faint meta — was
structurally unreachable there. Tables had the same gap one level up: no column
could say it holds numbers, so the design language's numeric-faint rule was
unimplementable by hosts.

## Behavior changes

**Data rows read as tiers.** `LogStream`, `EventStream`, `TraceWaterfall`,
`DiagnosticList`, `ObjectInspector`, `SearchResults`, `CheckpointTimeline`,
`TerminalOutput`, `HexViewer` and the offline banner now paint each part in the
tone its tier earns:

| Widget | Loud | Quiet | Faint |
|---|---|---|---|
| `LogStream` | message | source, batch count | timestamp |
| `EventStream` | summary | type, source, batch | timestamp, fields, correlation |
| `TraceWaterfall` | span name | service prefix, header meta | — |
| `DiagnosticList` | message | file:line:col | code, source |
| `ObjectInspector` | value | key, compare value | `:` / `=` / `<type>` |
| `SearchResults` | title | source, snippet | — |
| `CheckpointTimeline` | label | branch | timestamp |
| `TerminalOutput` | line body | — | — |
| `HexViewer` | hex bytes | ASCII pane | offset |

The status glyph keeps its severity role in every one of them (plan 007's
rule); what changed is that the *words* no longer borrow it. A page of stderr,
a column of error diagnostics, and a critical trace span are readable text with
a colored marker, not a wall of red.

**Wrapped rows.** In `LogStream` and `TerminalOutput` the tiers ride the first
row of a wrapped line; a continuation row is all message, in one tone.

## New surface

```rust
use termrock::widgets::{Column, ColumnKind, ColumnWidth, DataColumn, DataColumnWidth};

// Table (Line cells)
let size = Column::new("size", "Size", ColumnWidth::Fixed(8)).kind(ColumnKind::Numeric);
let state = Column::new("state", "S", ColumnWidth::Fixed(3)).kind(ColumnKind::Status);

// DataTable / TreeTable / VirtualGrid (&str cells)
let mem = DataColumn::new("mem", "MEM", DataColumnWidth::Fixed(6)).kind(ColumnKind::Numeric);
```

- `ColumnKind::Text` (default) — the row's own tone.
- `ColumnKind::Numeric` — the quiet tier, so the identity column stays loud.
- `ColumnKind::Status` — the row tone, and the cell contracts by clipping
  instead of ellipsizing, so a one-cell status column shows its letter rather
  than an ellipsis.

`ComposedRowParts` gains a part×tone paint path:

```rust
let parts = row.composed().parts_for_width(width);
parts.paint_with(buffer, area, &recipe); // label / secondary / trailing / shortcut tones
parts.paint(buffer, area, style);        // still available for one honest tone
```

`ComposedRowParts::paint` also stops flattening styled spans: the part tone is
the base and a span that states its own style keeps it.

## Breaking changes

- `Column` gained a public field `kind`. Struct-literal construction must add
  `kind: ColumnKind::Text`; `Column::new(..)` callers are unaffected.
- `DataColumn` gained a public field `kind`, with the same note.
- Snapshot tests of any widget in the table above will differ: the row is no
  longer one foreground.

## Gate

`design_gate.rs::data_rows_have_ladder` renders `LogStream`, `EventStream` and
`TraceWaterfall` and asserts every painted data row carries at least two
foregrounds. A new data widget that builds its row as one joined string cannot
pass it.
