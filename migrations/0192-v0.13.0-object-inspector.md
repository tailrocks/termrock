# 0192 — ObjectInspector typed expandable inspector

## Mission

Expandable typed inspector for JSON, YAML, TOML, structured logs, Rust debug
data, and application trees: objects/arrays/scalars, stable paths, type-aware
formatting, lazy expansion, search, copy path/value, edit hooks, compare/diff,
virtualization + depth limits, compact vs fullscreen, escaped controls, secret
redaction.

Research: browser devtools, jq/fx, Textual trees, DB JSON inspectors.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ObjectInspector` / `ObjectInspectorState` / `InspectorField` names | **Preserved** (moved to `object_inspector` module) |
| Index cursor + scroll + accepts_input | **Preserved** |
| `ObjectInspectorOutcome::CursorMoved { index }` | **Migrated** → adds `path: String` |
| `ObjectInspectorOutcome::Activate { index }` | **Preserved** |
| `handle_key(key, field_count: usize)` | **Migrated** → prefer `handle_key(key, fields)`; legacy `handle_key_count` |
| `handle_mouse(event, field_count)` | **Migrated** → prefer fields; legacy `handle_mouse_count` |
| `InspectorField { key, value, depth }` literals | **Migrated** → builders (`::new`, `.path`, `.kind`, …) |
| Expansion by path, search, secrets, compare, edit, fullscreen | **Added** |
| `InspectKind` / `InspectMode` / `InspectPresentation` | **Added** |
| `escape_inspect_value` / `filter_inspect_fields` | **Added** |
| `KeyValueTable` / `Tree` | **Preserved** — complementary |
| LogStream / DiffReview in `review.rs` | **Preserved** |

## Consumer edits

```diff
- InspectorField { key: "id", value: "42", depth: 0 }
+ InspectorField::new("id", "42").path("id").kind(InspectKind::String).depth(0)

- state.handle_key(key, fields.len())
+ state.handle_key(key, &fields)
  // or legacy: state.handle_key_count(key, fields.len())

- ObjectInspectorOutcome::CursorMoved { index }
+ ObjectInspectorOutcome::CursorMoved { index, path, .. }

  // Expansion preserve:
+ state.set_expanded("spec.containers", true);
+ // host reprojects only visible expanded nodes
+ state.reconcile(&fields);
```
