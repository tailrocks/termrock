# 0397 — v0.14.0 paint-only SegmentedControl and ToggleGroup

## Breaking change

`SegmentedControl` and `ToggleGroup` no longer implement Ratatui's stateless
`Widget` trait. Their removed render paths fabricated fresh state on every
frame, discarding persistent selection, focus, roving, and interaction
geometry.

## Stateful paint migration

Retain the control state across frames and call the explicit `paint` method:

```rust
let mut segmented_state = SegmentedControlState::new(None);
segmented_control.paint(area, frame.buffer_mut(), &mut segmented_state);

let mut toggle_state = ToggleGroupState::new();
toggle_group.paint(area, frame.buffer_mut(), &mut toggle_state);
```

Route keyboard and mouse input through the same state before repainting. No
compatibility shim or legacy stateless render path remains.
