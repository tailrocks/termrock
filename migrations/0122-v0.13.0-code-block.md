# 0122 — CodeBlock premium

## Mission

Production code / command rendering: pluggable syntax, line numbers, highlight
ranges, selection, horizontal scroll and wrap, copy, source metadata, intentional
control/tab display, streaming fences, large-file windowing, ANSI/no-color
syntax fallbacks, and composition hooks for diagnostics, diff, plan, and
terminal output.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `SyntaxHighlighter` trait | **Migrated** — `highlight_line` lifetime is line-bound (`&self`, `'line`) |
| `PlainSyntax` | **Preserved** |
| `CodeBlock::new` / `language` / `line_numbers` / `first_line` / `highlighter` | **Preserved** (highlighter may change type) |
| `Widget` render path | **Preserved** — ephemeral state from `first_line` |
| `Role::Syntax*` | **Preserved** — used by `RoleTokenSyntax` |
| `text::expand_tabs` / wrap helpers | **Preserved** — code uses `prepare_code_display` |
| `CodeBlockState`, outcomes, wrap/controls, marks, meta | **Added** |
| `TokenSyntax`, `RoleTokenSyntax`, `AnsiSyntax` | **Added** |
| Markdown `MarkdownBlockKind::Code` | **Preserved** — still plain; may host-compose CodeBlock later |
| DiffReview / PlanReview | **Preserved** — compose via highlights / gutter marks |

## API sketch

```rust
use termrock::widgets::{
    CodeBlock, CodeBlockState, CodeHighlight, CodeHighlightKind, CodeGutterMark,
    CodeWrap, ControlRender, RoleTokenSyntax, prepare_code_display,
};
use termrock::style::Role;

let lines = ["fn main() {}", "    println!(\"hi\");"];
let hi = RoleTokenSyntax::rust(&system);
let mut state = CodeBlockState::new();
state.set_focused(true);

let block = CodeBlock::new(&lines, &system)
    .language("rust")
    .path("src/main.rs")
    .line_numbers(true)
    .wrap(CodeWrap::Clip) // or Wrap
    .controls(ControlRender::Visible) // caret notation for C0
    .highlighter(&hi)
    .streaming(false);

let parts = block.paint(area, buf, &mut state);
match block.handle_key(&mut state, key) {
    CodeBlockOutcome::Copy { text } => { /* OSC 52 */ }
    CodeBlockOutcome::LineActivated { line } => { /* jump */ }
    CodeBlockOutcome::Scrolled { scroll_y, scroll_x } => {}
    _ => {}
}

// Large file: host windows the buffer
CodeBlock::new(&window_slice, &system)
    .line_base(2000)
    .logical_len(50_000)
    .line_numbers(true);

// Diagnostics / diff composition
let marks = [CodeGutterMark::new(12, '!', Role::Danger)];
let highs = [CodeHighlight::line(12, CodeHighlightKind::Diagnostic)];
block.gutter_marks(&marks).highlights(&highs);
```

## Policies

| Concern | Behavior |
|---------|----------|
| Tabs | Expanded to `tab_width` (default 4) |
| Controls | `Visible` (`^C`), `ExpandTabs` (strip), `Placeholder` (`·`) |
| Overflow | `Clip` + `scroll_x` · `Wrap` soft rows |
| Virtualization | Paint only provided `lines` window; `line_base` + `logical_len` clamp scroll |
| Streaming | Trailing `…` / `...` cue |
| No-color | `RoleTokenSyntax` + `syntax_role_style` → bold/dim/underline |
| Copy | Selection / cursor / window; tabs expanded, controls stripped |

## Breaking notes

- `SyntaxHighlighter::highlight_line` no longer couples segment lifetime to `&self`.
- Prefer `paint` + `CodeBlockState` for interactive / virtualized use; `Widget` remains.
