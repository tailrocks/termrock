# 0227 — QuestionFlow multi-question HITL

## Mission

Multi-question human-in-the-loop for agents and workflows: single/multiple
choice, free text, other option, validation, optional questions, multi-question
as steps/tabs, per-question scroll/cursor, review before submit. Preserve host
composer draft. Queued sets with actor/provenance. Fullscreen for complex
content. Structured answers only — no workflow policy in TermRock.

Research: Grok Build question view, form wizards, conversational agent prompts.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `QuestionFlow` / `QuestionStep` / `QuestionOption` / `QuestionFlowState<Id>` in `agent_blocks` | **Deleted** |
| `FormWizard` / `Stepper` | **Preserved** — multi-field forms, not agent interview |
| `PermissionPrompt` | **Preserved** — trust, not Q&A |
| PromptComposer draft buffer | **Never touched** by QuestionFlow |
| `Question` · `QuestionSet` · `QuestionAnswer` · elevated `QuestionFlow*` | **Added** |

## Breaking API

```rust
// Before
let steps = [QuestionStep { id: "q1", prompt: "Go?", options: &opts, required: true }];
let mut state = QuestionFlowState::new(1);
QuestionFlow::new(&steps, &system).render(area, buf, &mut state);
state.handle_key(&steps, key); // Answered { step, option }

// After
use termrock::widgets::{
    Question, QuestionOption, QuestionSet, QuestionFlow, QuestionFlowState,
    QuestionFlowOutcome, QuestionAnswer, example_question_set,
};

let mut state = QuestionFlowState::new();
state.open_set(example_question_set()); // or enqueue()
// composer draft remains host-owned
QuestionFlow::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    QuestionFlowOutcome::Answered { question_id, answer } => { /* store */ }
    QuestionFlowOutcome::Submitted { set_id, answers } => { /* structured set */ }
    QuestionFlowOutcome::ValidationFailed { message, .. } => { /* show */ }
    QuestionFlowOutcome::Cancelled => { /* keep composer draft */ }
    QuestionFlowOutcome::FullscreenRequested => { /* overlay */ }
    _ => {}
}
```

### Question kinds

| Kind | Keys |
|------|------|
| SingleChoice | j/k · Enter |
| MultiChoice | j/k · Space toggle · Enter next |
| FreeText | type · Enter |
| Other option | Enter → other text mode |

### Review

`v` opens review when required answers present; Enter submits; Esc returns.
