# 0110 — StatusBar premium regions and recipes

## Mission

Low-noise status surface for mode, connection, selection, context, focus zone,
and contextual shortcuts — with left/center/right bands, priority contraction,
semantic glyphs, transient messages, and minimal/compact/rich recipes.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `StatusBar::new(left, right, system)` | **Preserve** |
| `StatusSlot` fields `id/content/priority/min_width/enabled/style/hover_style` | **Preserve** |
| `StatusBarState::{hovered, regions, hover, click}` | **Preserve** |
| `StatusSlot::{region, kind, glyph, style_explicit}` | **Added** |
| `StatusRegion`, `StatusKind`, `StatusBarRecipe`, `TransientStatus` | **Added** |
| `StatusBar::with_center`, recipes, `transient` | **Added** |
| `StatusBarState::transient` / `set_transient` | **Added** |
| Struct-literal-only `StatusSlot { ... }` without new fields | **Migrated** — use builders |

## API sketch

```rust
use termrock::widgets::{
    StatusBar, StatusBarState, StatusSlot, StatusKind, StatusRegion,
    TransientStatus, StatusBarRecipe,
};

let left = [StatusSlot::mode("mode", "NOR")];
let center = [
    StatusSlot::focus_zone("focus", "main"),
    StatusSlot::context("path", "src/lib.rs"),
];
let right = [
    StatusSlot::selection("sel", "3"),
    StatusSlot::connection("conn", "ok"),
    StatusSlot::shortcut("hint", "C-s"),
];

let mut state = StatusBarState::new();
state.set_transient(Some("saved"));

StatefulWidget::render(
    &StatusBar::with_center(&left, &center, &right, &system)
        .rich()
        .transient(&TransientStatus::new("saved")),
    area,
    buf,
    &mut state,
);

// Recipes
StatusBar::new(&left, &right, &system).minimal(); // drops shortcuts
StatusBar::new(&left, &right, &system).compact(); // default
StatusBar::new(&left, &right, &system).rich();
```

## Consumer edits

```diff
- StatusSlot { id, content, priority, min_width, enabled, style, hover_style: None }
+ StatusSlot::new(id, content).priority(p).style(style)
+ // or StatusSlot::mode / connection / context / shortcut / focus_zone
```

## Transient rules

- Reserve center budget for the message after allocating essentials
- Do **not** drop mode/connection/focus-zone solely for transient text
- Transient has **no** hit region (not interactive)
