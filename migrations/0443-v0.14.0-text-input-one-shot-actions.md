# 0443: TextInput physical one-shot actions

## Boundary

`TextInputState::handle_key` is the raw physical keyboard adapter for a
reusable text field. Lifecycle actions, host-facing clipboard outcomes, and
destructive editor chords must not repeat while a key is held.

## Change

- Non-Press Enter, Tab, BackTab, and Escape events are ignored before the
  field changes editing state or submits/cancels.
- Non-Press Ctrl+M, clipboard chords (Ctrl+C/X/V), and destructive editor
  chords (Ctrl+U/K/W) are ignored before an outcome or editor mutation.
- Ordinary printable text and cursor/navigation repeats remain supported for
  held-key editing. Semantic `handle_intent` remains phase-free.

## Host migration

Hosts routing raw `TextInputState` events must continue passing complete
`KeyEvent` values, including lifecycle kind. Do not synthesize repeated
submit, cancel, clipboard, or destructive editor actions from Repeat or
Release events. Use `handle_intent` for semantic commands that are not raw
physical keyboard events.
