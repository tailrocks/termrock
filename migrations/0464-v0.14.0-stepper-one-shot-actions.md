# 0464: Stepper physical one-shot actions

## Boundary

`StepperState::handle_key` is the raw keyboard adapter for step navigation and
activation. Held keys must not repeat menu lifecycle or step activation
actions.

## Change

- Only Press events can open or close the menu, activate the selected step, or
  jump directly to a numbered step.
- Repeat events remain available for directional, Home, and End navigation.
- Release events remain ignored.
- Semantic intent and pointer paths are unchanged.

## Host migration

Hosts routing raw Stepper events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize menu or activation outcomes from
`Repeat` or `Release` events.
