# 0461: Sidebar physical one-shot actions

## Boundary

`NavigationListState::handle_key` and `SidebarState::handle_key` are raw
keyboard adapters. Held keys must not repeat navigation lifecycle actions or
sidebar presentation transitions.

## Change

- Only Press events can start or finish navigation filtering, request a
  context menu, disclose a section, activate a route, toggle the rail, open a
  palette/drawer, or blur the sidebar.
- Repeat events remain available for filter text editing and collection
  navigation.
- Release events remain ignored.
- Intent and pointer paths are unchanged.

## Host migration

Hosts routing raw Sidebar or NavigationList events must pass complete
`KeyEvent` values, including lifecycle kind. Do not synthesize lifecycle or
presentation outcomes from `Repeat` or `Release` events.
