# 0184 — Offline and ReconnectingState

## Mission

Specialized connectivity state for remote sessions, databases, agents, and
services: connection target, last successful time, retry state, queued actions,
offline capabilities, manual actions. Distinguishes disconnected, reconnecting,
authentication required, and server unavailable. Preserves local drafts and
selection. Unobtrusive banner plus full error variant. Integrates with StatusBar
and NotificationCenter.

Research: remote IDEs, database clients, SSH tools, collaborative agent UIs.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `StatusSlot::connection` / `StatusKind::Connection` | **Preserved** — project content via `ReconnectingState::status_bar_content` |
| `NotificationCenter` / `NotificationItem` | **Preserved** — ingest via `to_notification_item` |
| `ActivityPhase::Reconnecting` / Spinner | **Preserved** — map from `ConnectivityPhase::activity_phase` |
| `SemanticStatus::Offline` / Online | **Preserved** — map via `semantic_status()` |
| `ErrorState` | **Preserved** — hard failures; connectivity is specialized offline/reconnect |
| `LoadingOverlay` / `BusyBoundary` | **Preserved** — regional load, not transport lifecycle |
| `ReconnectingState` | **Added** |
| `ConnectivityPhase` (5) | **Added** |
| `OfflineBanner` / `OfflineSurface` / `OfflineChrome` | **Added** |
| Queued actions + offline capabilities | **Added** |
| StatusBar + NotificationCenter projectors | **Added** |

Nothing deleted. Hosts that used ad-hoc `"offline"` strings in StatusBar should
project from `ReconnectingState`.

## Consumer edits

```diff
+ use termrock::widgets::{
+     ReconnectingState, ConnectivityPhase, OfflineBanner, OfflineSurface,
+     ConnectivityPresentation, QueuedConnectivityAction, OfflineCapability,
+     StatusSlot, StatusBar, NotificationCenterState,
+ };

+ let mut conn = ReconnectingState::new("agent://prod-1");
+ conn.set_now_secs(now);
+ conn.set_last_success_secs(Some(last_ok));
+ conn.begin_reconnect(3);
+ conn.enqueue(QueuedConnectivityAction::new("send", "Send prompt"));
+ conn.set_offline_capabilities(vec![
+     OfflineCapability::new("Edit drafts", true),
+     OfflineCapability::new("Run remote tools", false),
+ ]);
+ // drafts/selection preserved by default

  // StatusBar
+ let label = conn.status_bar_content();
+ let right = [conn.status_slot_template("c", &label)];

  // Banner (unobtrusive)
+ OfflineBanner::new(&conn, &system).paint(banner_area, buf);

  // Full outage
+ conn.set_presentation(ConnectivityPresentation::Full);
+ OfflineSurface::new(&system).paint(area, buf, &mut conn);

  // NotificationCenter
+ center.ingest_item(conn.to_notification_item("conn-1"));
```
