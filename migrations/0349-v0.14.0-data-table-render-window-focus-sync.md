# 0349: DataTable render-time window clamps refresh logical focus

## Boundary

Rendering derives the virtual row viewport from the current terminal area and
may clamp `VirtualWindow::offset`. The cursor's absolute selection focus must
follow that render-time state change.

## Change

DataTable synchronizes cursor focus after viewport assignment and window
clamping during render. Resize-driven window changes therefore cannot leave
`SelectionModel::focus_row` pointing at the prior logical offset.

## Consumer impact

No consumer edit is required. Hosts may resize or change footer/toolbar
presence without manually repairing selection focus.
