# 0330 — ChoiceDialog centers actions

**Version:** `v0.14.0`
**Kind:** behavioral + additive

`ChoiceDialog` now centers actions by default:

- horizontal actions are centered as one measured group;
- vertically stacked actions are centered individually;
- hit regions cover only the painted button labels.

`ActionBar::centered(bool)` is available for other compositions. Its default
remains `false`, so existing standalone action bars keep their alignment.

No `ChoiceDialog` consumer edit is required.
