# 0446: TokenField physical one-shot actions

## Boundary

`TokenFieldState::handle_key` is the raw physical keyboard adapter for a
tokenized field with a nested text draft. Lifecycle, completion, and token
membership actions must not repeat while a key is held.

## Change

- Non-Press Enter, Tab, BackTab, and Escape events are ignored before draft
  synchronization or draft commit/submit/cancel handling.
- Non-Press Ctrl+M, clipboard Ctrl+C/X/V, and destructive Ctrl+U/K/W events
  are ignored before the nested draft can emit an outcome or mutate.
- Non-Press separator commits, empty-draft token removal, token deletion,
  token selection toggles, and token reordering are ignored before membership
  mutation.
- Ordinary draft text, cursor navigation, and draft deletion repeats remain
  supported. Semantic `handle_intent` remains phase-free.

## Host migration

Hosts routing raw `TokenFieldState` events must continue passing complete
`KeyEvent` values, including lifecycle kind. Do not synthesize repeated
submit, cancel, completion, clipboard, destructive editor, or token
membership actions from Repeat or Release events. Use `handle_intent` for
semantic commands that are not raw physical keyboard events.
