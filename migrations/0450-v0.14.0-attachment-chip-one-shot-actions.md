# 0450: Attachment chip physical one-shot actions

## Boundary

`AttachmentChip` and `PasteChip` raw key adapters expose host actions and
expand/collapse state. Retry, open, preview, copy, insert, activation, and
collapse actions must not repeat while a key is held.

## Change

- Non-Press attachment retry/open/preview chords are ignored before host
  outcomes are emitted.
- Non-Press paste activation, Escape collapse, and copy/insert/preview/retry
  chords are ignored before expansion, collapse, or host outcomes.
- Delegated `Tag` keyboard handling remains press-only; mouse handling and
  semantic behavior remain unchanged.

## Host migration

Hosts routing raw chip events must continue passing complete `KeyEvent` values,
including lifecycle kind. Do not synthesize repeated host actions or
expand/collapse transitions from Repeat or Release events.
