# Table recipe rows and raised headers

`Table` and `DataTable` now route selection and hover through the shared list
row recipe. Selected rows use semantic tint plus gutter; hovered rows use the
shared hover wash. Header bands use `Role::Raised` with muted labels.

Remove consumer-owned row focus colors and header backgrounds. Selection and
data models are unchanged. Validate with `cargo test -p termrock table` and
`mise run gate`.
