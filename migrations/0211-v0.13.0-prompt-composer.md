# 0211 — PromptComposer flagship agent input (Global contract)

## Mission

Flagship input surface for terminal AI agents: multiline grapheme-safe editing,
selection, undo/redo, history, attachments, paste chips, slash commands,
file/symbol mentions, completion, model/mode indicators, queueing, submit,
interrupt, cancel, and external editor. Draft preserved when permissions,
questions, plans, sessions, or command palette temporarily take over. Separate
text editor, token model, completion, presentation, and application submission
policy. Compact / normal / expanded / fullscreen. Benchmark large prompts,
streaming completion updates, and repeated paste.

Research: Grok Build prompt widget, Amp, OpenCode, Claude Code, prompt-toolkit,
terminal editors.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextArea` / `TextAreaState` | **Preserved** — edit kernel in `PromptComposerState.editor` |
| `CompletionMenu` | **Preserved** — host paints candidates; composer emits `Completion` / commit |
| `HistoryPicker` | **Preserved** — `submit_history` + `submit_history_to_entries` bridge |
| `KeyboardHelp` | **Preserved** — `prompt_composer_help_entries()` seed |
| `TokenMeter` / `Tag` / `Panel` | **Preserved** — status meter + chip chrome |
| OverlayStack helpers | **Preserved** — completion + fullscreen overlay ids |
| `AgentWorkbench` south pane | **Preserved** — still composes `PromptComposer` |
| Provider SDKs / `$EDITOR` spawn / clipboard I/O | **Never in TermRock** — outcomes only |
| `set_focused` / `is_focused` | **Deleted** — use `set_accepts_input` / `accepts_input` |
| `detect_completion` | **Public** (was private) |
| `ChipKind::Mention` · help/history bridges · `bench` · `PROMPT_*_LIMIT` | **Added** |
| `PromptComposer*` core | **Hardened** (not replaced) |

## Consumer API sketch

```rust
use termrock::widgets::{
    PromptComposer, PromptComposerState, PromptComposerOutcome,
    SubmitPolicy, ComposerPresentation, ComposerConnection,
    ModeIndicator, ModelIndicator, ContextEstimate, ComposerChip,
    ChipKind, CompletionKind, detect_completion, prompt_composer_help_entries,
    submit_history_to_entries, LARGE_PASTE_THRESHOLD,
    PROMPT_COMPLETION_OVERLAY_ID, PROMPT_FULLSCREEN_OVERLAY_ID,
};

let mut state = PromptComposerState::new();
state.set_mode(Some(ModeIndicator { label: "PLAN".into(), warning: false }));
state.set_model(Some(ModelIndicator { label: "model-a".into() }));
state.set_context(ContextEstimate { used: 12_000, limit: 128_000 });
state.set_busy(true); // Enter → Queued

// Overlay takeover — do NOT clear_draft
state.set_accepts_input(false);
// … PermissionPrompt / PlanReview / SessionPicker / CommandPalette …
state.set_accepts_input(true);

// Streaming completion refresh (host candidates; no draft mutate)
if let Some(q) = detect_completion(&state.text(), state.editor.cursor()) {
    state.set_completion(q);
}

PromptComposer::new(&system).render(area, buf, &mut state);

// HistoryPicker projection
let rows = submit_history_to_entries(state.submit_history());
// KeyboardHelp seed
let help = prompt_composer_help_entries();
```

### Removed

```rust
// Before (deleted)
state.set_focused(false);
if state.is_focused() { … }

// After
state.set_accepts_input(false);
if state.accepts_input() { … }
```

### Keys (product)

| Key | Action |
|-----|--------|
| Enter | Submit / queue (policy) |
| Alt/Ctrl/Shift+Enter | Newline when submit-on-enter |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+A · selection | Select all · shift-extend |
| Ctrl+C | Copy selection, or soft interrupt when busy |
| Ctrl+U / Ctrl+Backspace | Cancel when busy |
| Ctrl+E | External editor request |
| Ctrl+Shift+O | Attach request |
| Ctrl+Shift+F | Fullscreen request |
| Up/Down | History at line edges |
| / @ # | Completion triggers |
| Esc | Completion → fullscreen → selection → dismiss |
