# 0510: Synchronize removed BackgroundOutputBuffer emptiness getter

## Boundary

The dead-accessor sweep removed the unused `BackgroundOutputBuffer::is_empty`
getter. The generated public API snapshot retained its signature even though
the getter is no longer available.

## Change

Removed the one stale snapshot entry for `BackgroundOutputBuffer::is_empty`
deleted by `855e4147`.

## Host migration

Use `BackgroundOutputBuffer::len` when a buffered-line count is needed; derive
emptiness from that count at the host boundary. No compatibility alias or
deprecation period is provided.
