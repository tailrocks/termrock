# 0301 — Stream rows keep their words

`LogStream` and `EventStream` painted each whole row in its level's or
severity's color, so a busy log was a wall of red and amber sentences and the
message itself was the hardest thing to read. The level is one fact about the
row; it belongs in one cell.

## Behavior changes

- **`LogStream`**: the message, timestamp and source read in `Role::Text`
  (`TextMuted` for trace and debug when the stream is not the focus surface).
  The level glyph keeps the level's color, at whatever column the recipe puts
  it — compact rows after the bookmark mark, detailed rows after the timestamp
  and source, and it follows horizontal scroll.
- **`LogStream`'s reconnect banner**: sentence in `Role::Text`, `!` in
  `Role::Warning`.
- **`EventStream`**: rows read in `Role::Text`; the severity glyph that opens
  every row form keeps the severity color.

Colorless mode is unaffected: it already prints the level letter and no color
is applied.

A new test pins the rule — no painted log row may carry more than one cell in
a level color.

## Consumer edits

- Snapshots asserting a red error *line* or an amber warning *line*: assert on
  the glyph cell instead. The row's own selection chrome is unchanged.

## Validation

```sh
cargo nextest run -p termrock --all-features log_stream event_stream
mise run check
```
