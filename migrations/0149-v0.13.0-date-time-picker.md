# 0149 — DateTimePicker

## Mission

Date, time, and range selection only where terminal browse UX helps. Locale-
independent civil storage with explicit presentation formats. Host injects
“today” and timezone **labels**; TermRock does not ship a TZ database or call
the clock for committed values.

## When TextInput is better

Prefer plain `TextInput` for rare ISO paste, log stamps, and machine-oriented
fields with no calendar/range/stepped-time need. Prefer DateTimePicker when
users navigate months, pick ranges, see min/max unavailable days, or choose
from a time list.

Constant: `termrock::widgets::date_time_picker_guidance::WHEN_TEXT_INPUT`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` / `Validation` | **Preserved** — field draft + chrome |
| `CollectionState` | **Preserved** — day list + time list |
| `OverlaySpec::dialog` / `OverlayStack` | **Preserved** — modal helpers |
| `NumberInput` constraints pattern | **Inspired** — min/max validity; separate types |
| Prior DateTime / Calendar widgets | **None** (greenfield) |
| `CivilDate` / `CivilTime` / `CivilDateTime` / `CivilDateRange` | **Added** |
| `DateTimePicker` / `DateTimePickerState` / outcomes | **Added** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     CivilDate, CivilTime, DateTimePicker, DateTimePickerKind, DateTimePickerOutcome,
+     DateTimePickerState, DATE_TIME_PICKER_OVERLAY_ID,
+ };

+ let mut state = DateTimePickerState::new(DateTimePickerKind::Date)
+     .with_min_date(CivilDate::new(2026, 1, 1).unwrap())
+     .with_max_date(CivilDate::new(2026, 12, 31).unwrap())
+     .with_timezone_label("UTC");
+ state.set_today(host_today); // required for *today* marker
+ state.set_focused(true);

+ match state.handle_key(key) {
+     DateTimePickerOutcome::Opened { view, presentation } => {
+         // optional: open_overlay into OverlayStack
+         let _ = (view, presentation);
+     }
+     DateTimePickerOutcome::DateChanged { date } => host.set_date(date),
+     DateTimePickerOutcome::TimeChanged { time } => host.set_time(time),
+     DateTimePickerOutcome::DateTimeChanged { value } => host.set_dt(value),
+     DateTimePickerOutcome::RangeChanged { range } => host.set_range(range),
+     DateTimePickerOutcome::ValidationFailed { reason } => { /* field chrome */ }
+     DateTimePickerOutcome::Cancelled | DateTimePickerOutcome::Closed => {}
+     _ => {}
+ }

+ DateTimePicker::new(&system)
+     .label("Due")
+     .ascii(false)
+     .paint(area, buf, &mut state);
```

### Storage vs presentation

| Layer | API |
|-------|-----|
| Storage | `CivilDate` / `CivilTime` / `CivilDateTime` / `CivilDateRange` |
| Date paint/parse | `DateDisplayFormat::{Iso,YmdSlash,MdySlash,DmySlash}` |
| Time paint/parse | `TimeDisplayFormat::{Hm24,Hms24,Hm12}` |
| TZ | `with_timezone_label` — display only |

### Non-color day states

| State | Glyph |
|-------|-------|
| Selected | `[dd]` |
| Today | `*dd*` |
| Focus | `>dd<` |
| Unavailable | `.dd.` |
| Other month | `·dd·` |

### Keys

| Key | Behavior |
|-----|----------|
| Alt+Down | Open expanded |
| Esc | Close expanded, then Cancel |
| Tab | Field → Calendar/DayList → TimeList |
| Arrows | Calendar day nav |
| PgUp/PgDn | Month |
| Home | Jump today |
| Digits | Typeahead day / hour jump |
| Enter | Commit focus / draft |

Tiny width (`< 36`): day list fallback + fullscreen presentation.
