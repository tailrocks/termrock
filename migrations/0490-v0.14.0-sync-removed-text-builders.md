# 0490: Synchronize removed Text and TextSpan builders

## Boundary

The uniform widget cleanup removed eight zero-caller convenience builders from
the canonical text primitives. The generated public API snapshot retained
their signatures even though the methods are no longer available.

## Change

Removed the eight stale snapshot entries for `TextSpan::borrowed`,
`TextSpan::emphasis`, and `Text::{strong, dim, muted, align, tab_width,
ellipsis}` deleted by `ddde585f`.

## Host migration

Use `TextSpan::new` followed by the remaining span builders for span content
and emphasis. Use `Text::role`, `Text::emphasis`, `Text::center`, and the
remaining overflow/policy builders for text configuration. No compatibility
aliases or deprecation period is provided.
