# 0179 — Skeleton redesign

## Mission

Low-noise structural placeholders for async content when the **final structure is
known**. Text lines, rows, cards, tables, and custom cell shapes. Static by
default (no shimmer); optional Full-motion pulse only when host enables it.
Preserve layout height to reduce jumping. Prefer LoadingView/Spinner when
structure is unknown.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Skeleton::new(rows, system)` | **Preserved** (staggered lines) |
| `Widget` for Skeleton | **Preserved** |
| Panel `paint_skeleton_body` | **Preserved** |
| Stories `skeleton/basic`, `narrow`, `unicode` | **Preserved** |
| Implementation in `view_state.rs` | **Migrated** → `widgets/skeleton.rs` |
| `SkeletonShape`, `SkeletonLayout`, recipes, state | **Added** |
| Constant shimmer | **Rejected** (default static) |

## Consumer edits

```diff
  use termrock::widgets::Skeleton;
+ use termrock::widgets::{Skeleton, SkeletonLayout, SkeletonRecipe, SkeletonShape, SkeletonState};

  // Unchanged:
  Skeleton::new(4, &system); // Widget::render / paint

  // Recipes:
+ Skeleton::card(3, &system);
+ Skeleton::table(3, 5, &system);
+ Skeleton::recipe(SkeletonRecipe::Rows, 6, &system);
+ Skeleton::layout(
+     SkeletonLayout::shapes([
+         SkeletonShape::line(),
+         SkeletonShape::line_indent(2),
+         SkeletonShape::card(2),
+     ]).reserved_height(8), // hold final layout space
+     &system,
+ );

  // Optional shimmer (Full motion only):
+ let mut state = SkeletonState::new();
+ state.set_shimmer(true); // still no tick under Motion::Off/Reduced
+ if state.should_tick(motion) { /* schedule redraw */ }
+ sk.paint_with_state(area, buf, &state, tick, motion);
```
