# 0348: DataTable cursor and selection focus stay in logical space

## Boundary

DataTable exposes a projected row cursor while `SelectionModel::focus_row` is
an absolute logical coordinate. Window movement, First/Last, and pointer
navigation must update both views together.

## Change

Cursor changes now synchronize absolute row and visible-column focus. The sync
runs after projection clamping, virtual-window scrolling, page movement,
First/Last, mouse cell/context clicks, and row fallback clicks.

## Consumer impact

No consumer edit is required. `selection.focus_row` and `focus_col` now track
the cursor's logical target after keyboard, wheel, and pointer movement.
