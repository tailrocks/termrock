# 0410 — v0.14.0 remove Panel and Card `Widget` implementations

## Breaking change

`Panel` and `Card` no longer implement Ratatui's stateless `Widget` trait for
owned or borrowed values. `Widget::render`, `.render`, and
`Frame::render_widget` calls with either type are removed. No compatibility
adapter or legacy render path remains.

## Canonical paint path

Paint directly into the frame buffer and use the returned body rectangle for
host-owned children:

```rust
let body = panel.paint(area, frame.buffer_mut(), None);
let body = card.paint(area, frame.buffer_mut(), None);
```

The signatures are:

```rust
Panel::paint(area, buffer, state: Option<&mut PanelState>) -> Rect
Card::paint(area, buffer, state: Option<&mut PanelState>) -> Rect
```

For collapsible or interactive containers, retain one state value across
frames and pass it to every paint call:

```rust
let mut panel_state = PanelState::new();
let body = panel.paint(area, frame.buffer_mut(), Some(&mut panel_state));

let mut card_state = PanelState::new();
let body = card.paint(area, frame.buffer_mut(), Some(&mut card_state));
```

## State and `None` semantics

- `None` is intentional for non-interactive or host-state-free paint. It does
  not create or mutate a `PanelState`; state-driven collapse and focus use
  their default presentation.
- `Some(&mut PanelState)` is caller-owned persistent state. `collapsed` and
  `focused` drive the panel presentation, while paint refreshes cached
  `parts` and header `action_hits` for later layout and hit testing.
- `Card` forwards the same `PanelState` contract to its composed `Panel`; it
  has no separate `CardState`. `layout(area, Option<&PanelState>)` is the
  read-only geometry form, and `inner(area)` remains the no-state body helper.

## Registry contract

`ComponentKind::Widget` describes a Ratatui `Widget` or `StatefulWidget`
implementation. `ComponentKind::Paint` describes a public direct-buffer paint
API. The `PUBLIC_UI_INVENTORY` entries for both `Panel` and `Card` therefore
advertise `Paint`, not `Widget`; their layout family, docs slugs, and
representative stories remain unchanged. Catalog consumers must select the
explicit `.paint(area, buffer, state)` contract.
