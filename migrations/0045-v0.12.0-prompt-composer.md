# 0045 — Flagship PromptComposer

## Removed surface

None. `PromptBox` / `PromptBoxState` remain for simple embeds.

## Canonical addition

```rust
use termrock::widgets::{
    PromptComposer, PromptComposerState, PromptComposerOutcome,
    SubmitPolicy, ComposerPresentation, ComposerConnection,
    ModeIndicator, ModelIndicator, ContextEstimate, ComposerChip,
};

let tokens = DesignTokens::new(theme.clone(), Density::Comfortable);
let mut state = PromptComposerState::new();
// Temporary overlay (permission, plan, palette): blur only
state.set_focused(false);
// … later …
state.set_focused(true); // draft still present

frame.render_stateful_widget(
    &PromptComposer::new(&tokens, &theme),
    area,
    &mut state,
);
```

### Capability map

| Need | Support |
|------|---------|
| Grapheme multiline | `TextAreaState` |
| Cursor / mouse | editor + layout hits |
| Undo/redo | Ctrl+Z / Ctrl+Y snapshots |
| History | Up/Down on edge lines |
| Draft preservation | blur does not clear |
| Slash / @ / # | `CompletionQuery` + outcomes |
| Attachments / paste chips | `ComposerChip` |
| Mode / model / context | indicators + `TokenMeter` |
| Queue while busy | `set_busy(true)` → `Queued` |
| Submit / cancel / interrupt | outcomes |
| Newline | Alt/Ctrl/Shift+Enter when submit-on-enter |
| External editor | `ExternalEditor` outcome |
| Disabled / disconnected | `ComposerConnection` |
| Validation | empty / busy / offline |
| Compact/normal/expanded/fullscreen | `ComposerPresentation` |
| Bracketed paste | `Event::Paste` / `handle_paste` |
| Narrow / ascii / no-color | presentation + roles + ascii flags |

### Policy separation

`SubmitPolicy` is application-owned. Provider submission is never inside the widget.
