# 0127 — HighlightedText and MatchRanges

## Mission

Reusable match rendering for search, fuzzy finders, completion, and command
palettes: multiple ranges, grapheme-safe byte indices, overlap resolution,
selected/focused states, no-color emphasis, match-preserving truncation, and
source preservation for copy — without recomputing fuzzy scores in paint.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextSpan::highlight` / `Text` | **Preserved** — HighlightedText paints through Text spans |
| `CompletionCandidate` | **Migrated** — optional `match_ranges` + `matches()` builder |
| Host fuzzy / ranking | **Caller-owned** — only ranges + source are painted |
| `HighlightedText`, `MatchRanges`, helpers | **Added** |

## API sketch

```rust
use termrock::widgets::{
    HighlightedText, MatchRanges, MatchRange, MatchTruncate, substring_ranges,
};

// Host scores offline once per query:
let ranges = substring_ranges(label, query); // or fuzzy → MatchRange list
let prep = ranges; // already prepared by helper

HighlightedText::prepared(label, prep.as_slice(), &system)
    .selected() // palette cursor row
    .truncate(MatchTruncate::KeepFirstMatch)
    .paint(row_area, buf);

// Completion
CompletionCandidate::new(id, label).matches(prep.as_slice());
```

## Overlaps

`MatchRanges::prepare` snaps graphemes, sorts, then splits overlaps with
priority: Focused > Annotation > Match > Soft.

## Truncation

| Policy | Behavior |
|--------|----------|
| `KeepFirstMatch` | Window around first match (default) |
| `KeepFocusedMatch` | Window around focused range |
| `End` | End ellipsis |
| `Middle` | Head … tail |
