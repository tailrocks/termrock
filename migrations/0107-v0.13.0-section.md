# 0107 — Section editorial grouping

## Mission

Editorial grouping that communicates hierarchy without a full border box:
heading, description, status, header actions, optional divider, indent/depth for
nesting, quiet vs emphasized recipes, and collapsible body.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Section`, `SectionState`, `SectionOutcome` (content.rs) | **Migrated** → `widgets/section.rs` |
| `Section::new(title, tokens).description(..).render(area,buf,state)` | **Migrated** → `.paint(area, buf, Some(state))` |
| `SectionState::handle_key(key)` | **Migrated** → `handle_key(key, collapsible)` |
| `SectionState::handle_intent(intent)` | **Migrated** → `handle_intent(intent, collapsible)` |
| `SectionState::handle_mouse` | **Migrated** — actions first, then header toggle |
| `SectionVariant`, `SectionParts`, `SectionAction` | **Added** |
| `SectionOutcome::HeaderAction` | **Added** (outcome no longer always `Copy`) |
| `Heading` / `Paragraph` / `Callout` | **Preserve** |
| `FormSection` | **Preserve** — form field groups; hosts may use `Section` for chrome |
| Full box `Panel` for every group | **Avoid** — prefer Section for editorial hierarchy |

## API sketch

```rust
use termrock::widgets::{
    Section, SectionAction, SectionState, SectionVariant, SectionOutcome,
};
use termrock::style::DesignSystem;

let system = DesignSystem::default();
let actions = [SectionAction::new("reset", "Reset")];

// Quiet settings group
let body = Section::new("Appearance", &system)
    .description("Theme and density")
    .quiet()
    .paint(area, buf, None);
// children into `body`

// Emphasized + divider
let body = Section::new("Security", &system)
    .emphasized()
    .status("3")
    .actions(&actions)
    .paint(area, buf, None);

// Collapsible
let mut state = SectionState::new();
state.set_focused(true);
let body = Section::new("Advanced", &system)
    .collapsible(true)
    .paint(area, buf, Some(&mut state));
let out = state.handle_key(key, true);

// Nested
Section::new("Child", &system).depth(1).indent(0).paint(nested_area, buf, None);
```

## Responsive drop order

Under narrow width:

1. header actions (&lt; 28 cols)
2. status (&lt; 20)
3. description (&lt; 16)
4. title (kept)

## Focus

- Non-collapsible: focus stays on interactive **descendants** in body
- Collapsible: header may take focus; Enter/Space/Toggle → `ToggleCollapsed`
- Header action clicks → `HeaderAction { id }` (no collapse)

## Consumer edits

```diff
- section.render(area, buf, &mut state)
+ section.paint(area, buf, Some(&mut state))

- state.handle_key(key)
+ state.handle_key(key, section.is_focusable())
```

## Stories

- `section/quiet`, `section/emphasized`, `section/collapsible`
- `section/actions`, `section/nested`, `section/narrow`
