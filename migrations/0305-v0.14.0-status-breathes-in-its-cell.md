# 0305 — A live status breathes in its own cell

Plan 007 moved status colour off whole rows and onto the glyph cell. This adds
the missing half: a status that is *still happening* now says so with motion,
and one that has finished says so by being perfectly still.

## `SemanticStatus` declares a channel

```rust
SemanticStatus::Running.channel();   // MotionChannel::Live  — a slow breathe
SemanticStatus::Waiting.channel();   // MotionChannel::Wait  — a quicker pulse
SemanticStatus::Online.period_ms();  // HEARTBEAT_PERIOD_MS (5 s), not 2 s
SemanticStatus::Success.channel();   // MotionChannel::Static — no frames, ever
```

Every terminal state — `Success`, `Failed`, `Warning`, `Offline`, `Paused`,
`Queued`, `Idle`, `Unknown` — is `Static` on purpose. Gravity: a finished thing
must not keep moving, and a state that costs frames forever is a bug wearing
polish. `Online` breathes on the 5 s heartbeat rather than the channel's 2 s,
because presence should be barely perceptible; anything faster reads as
activity.

## `StatusIndicator` breathes the cell, never the label

The status cell's foreground is modulated by a sin² breathe whose trough is
`AMBIENT_PEAK` (0.33) below full. The label keeps the body tone and does not
move: words are not a signal.

Amplitude, phase source, and tier all come from the shared vocabulary, so a
spinner and a status dot in the same state stay in step instead of drifting.

## Reduced motion

`MotionPolicy::Basic` and `Off` return brightness `1.0`, so two ticks render
identical cells and the status stays fully legible. Nothing is lost: the glyph
and the label already carry the meaning.

## New public surface

- `style::channel_brightness(policy, channel, elapsed_ms) -> f32`
- `style::breathe_over(policy, elapsed_ms, period_ms) -> f32`
- `SemanticStatus::{channel, period_ms}`

Both helpers return `1.0` for terminal channels and reduced tiers, so callers
multiply unconditionally rather than branching at every site.

## Where the time comes from

`StatusIndicator::paint` is unchanged — no new parameter. The frame time
arrives through `DesignSystem::at(tick)` (migration 0299), which is why that
seam existed. A host that never calls `at` gets a settled, static indicator.
