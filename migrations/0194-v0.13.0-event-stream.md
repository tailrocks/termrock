# 0194 — EventStream structured high-volume viewer

## Mission

Generic high-volume structured-event viewer distinct from plain logs: event
type, timestamp, severity, actor/source, structured fields, correlation IDs,
filtering, grouping, pause/follow, details, pluggable row summaries, burst
batching / backpressure indicators, stable anchors, unread counts, and
sustained-rate paint budgets.

Research: observability consoles, Kubernetes events, agent activity streams.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `LogStream` / `LogLine` / `LogLevel` | **Preserved** — plain text / level logs |
| `Timeline` | **Preserved** — chronological presentation recipes |
| `EventStream` / `StreamEvent` / `EventStreamState` | **Added** (new surface) |
| `EventSeverity` / filter / backpressure / anchors | **Added** |
| `event_stream_bench` constants | **Added** |
| Nothing deleted | Compose with ObjectInspector for deep detail |

## Consumer API sketch

```rust
use termrock::widgets::{
    EventStream, EventStreamState, StreamEvent, EventSeverity, event_stream_bench,
};

let events = [
    StreamEvent::with_id("e1", "Warning", "12:01:01", "FailedMount")
        .severity(EventSeverity::Warn)
        .source("kubelet")
        .fields("vol=cfg")
        .detail("MountVolume.SetUp failed…")
        .batch_count(3)
        .correlation("deploy-9"),
];
let mut state = EventStreamState::new(); // following by default
state.on_append(events.len() as u16, viewport);
// Host burst: coalesce rows + report_backpressure(dropped, batched)
state.report_backpressure(50, 64);
// Pause on scroll; unread via state.unread(); f re-follows
// Anchor: state.capture_anchor(&events); …reproject…; state.restore_anchor(&events);
EventStream::with_events(&events, &system)
    .focused(true)
    .render(area, buf, &mut state);
```

### Keys

| Key | Action |
|-----|--------|
| j/k ↑↓ | Select (detaches follow when moving up) |
| f | Toggle follow |
| / | Text filter |
| `[` | Cycle severity floor |
| i / Space | Toggle inline detail |
| b | Ack backpressure counters |
| Enter | Activate (open detail) |
