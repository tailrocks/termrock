# 0121 — Link and ActionLink

## Mission

Terminal-safe navigation links and lightweight inline actions: OSC 8 when
capable, always-visible destination or risk for external URLs, copy action,
application routes, focus/hover/visited/disabled, and a separate ActionLink
for button-like inline activates (no destination URL).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `osc::encode_hyperlink_open` / `Request::HyperlinkOpen` / `HyperlinkRegion` | **Preserved** — Link builds regions + encode helpers; host still emits OSC |
| `Role::Link` / `Role::LinkHover` | **Preserved** — sole paint roles |
| `ButtonVariant::Link` | **Preserved** — button chrome density, not navigation destinations |
| `DetailTable` link rows (`DetailCapability::Link`, `ActivateLink`, `hyperlink_regions`) | **Preserved** — table-owned activation; may paint with `Link` later |
| `Link`, `ActionLink`, `LinkState`, `LinkDestination`, `LinkOutcome`, … | **Added** — new module `widgets/link.rs` |
| Prior dedicated `Link` widget | **N/A** — greenfield |

## API sketch

```rust
use termrock::widgets::{
    ActionLink, DestinationDisplay, Link, LinkOutcome, LinkState, LinkVariant,
};

// External URL — OSC 8 when terminal capable; destination never hidden
let mut state = LinkState::new();
state.set_focused(true);
let link = Link::url("docs", "https://example.invalid/docs", &system)
    .hyperlinks(caps.hyperlinks)
    .osc_id("docs")
    .variant(LinkVariant::Underline);
let parts = link.paint(area, buf, &mut state);
if let Some((open, close)) = link.osc_requests(&state) {
    // host encodes via termrock::osc::encode
    let _ = (open, close);
}
match link.handle_key(&mut state, key) {
    LinkOutcome::Activated { destination, external } => { /* open */ }
    LinkOutcome::Copy { text } => { /* OSC 52 clipboard */ }
    _ => {}
}

// App route — never OSC 8
Link::app_route("Settings", "app://settings", &system)
    .destination_display(DestinationDisplay::Never)
    .paint(area, buf, &mut state);

// Inline action (not navigation)
ActionLink::new("Run tests", &system)
    .risk_note("cargo test")
    .paint(area, buf, &mut action_state);
```

## Destination policy

| `DestinationDisplay` | External URL | App route |
|----------------------|--------------|-----------|
| `Auto` (default URL) | Always show URL (risk) | — |
| `Always` | Always show | Show route |
| `Never` | External cue only (`↗` / `^`) | Hide route |

External destinations **never** paint as bare labels with no risk cue.

## Forms

| Widget | Role | OSC 8 | Outcomes |
|--------|------|-------|----------|
| `Link` | Navigation | URL only when `hyperlinks` + eligible scheme | Activate / Copy |
| `ActionLink` | Inline action | Never | Activate only |
