# 0406 — v0.14.0 unify stateful paint vocabulary

## Breaking change

Stateful widget rendering now uses the explicit `paint` vocabulary. Render
aliases were removed from controls and pattern-facing widgets, including
Checkbox, RadioGroup, Switch, ModelSelector, AgentModeSelector, QuestionFlow,
ToolCallCard, and Spinner. Spinner's stateless `Widget` fallback is also gone;
its stateful paint path is the only rendering entry.

## Consumer impact

Replace calls to the removed stateful `render` aliases with the corresponding
`paint` method and retain the existing state value across frames. Hosts that
used `Widget` rendering for Spinner must create/retain `SpinnerState` and pass
the host tick and motion policy to `paint`. No compatibility aliases remain.
