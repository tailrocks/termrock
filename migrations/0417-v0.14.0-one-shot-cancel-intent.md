# 0417: Escape cancellation is press-only

## Boundary

Escape cancellation is a one-shot action. Key repeats must not cancel a text
area a second time or re-run cancellation after the initial press.

## Change

The default text-area intent mapper emits `UiIntent::Cancel` only for an Escape
press. The raw `TextAreaState` handler applies the same press-only boundary, so
repeated Escape events are ignored while navigation movement remains repeatable.

## Consumer impact

Consumers that dispatch text-area cancellation through either the shared intent
mapper or the raw state handler now receive cancellation only on the initial
Escape press. No consumer change is required unless it depended on repeated
Escape events finishing editing.
