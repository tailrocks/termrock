# 0388 — v0.14.0 paint-only links and controls

## Breaking change

`Link`, `ActionLink`, `Toggle`, and `Collapsible` intentionally no longer
implement Ratatui's `Widget` trait. Rendering and interaction state are now
explicit. No compatibility shim or legacy `render` path remains.

## New call path

The host keeps the corresponding state, handles interaction through the public
widget/state APIs, then paints into the frame:

```rust
let _ = link.paint(area, buf, &mut link_state);
let _ = action_link.paint(area, buf, &mut link_state);
let _ = toggle.paint(area, buf, &mut toggle_state);
let content = collapsible.paint(area, buf, &mut collapsible_state);
```

Use `LinkState` for `Link` and `ActionLink`, `ToggleState` for `Toggle`, and
`CollapsibleState` for `Collapsible`. Register semantic regions from the same
state when building the interaction scene.
