# 0173 — Alert and Callout redesign

## Mission

Inline informational, success, warning, error, and destructive-context messages
with title, description, details, actions, dismissibility, source, and status
glyphs. Border/gutter/text hierarchy (not huge fills). Compact and section
recipes. Readable in no-color and ASCII. Composes with forms, diagnostics,
permissions, and empty states.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Callout::new(title, system).body().tone()` | **Preserved** |
| `CalloutTone::{Info,Success,Warning,Danger}` | **Preserved** (+ `Destructive`, `Neutral`) |
| `Widget` for Callout | **Preserved** |
| `Alert::new(title, system).tone()` | **Preserved** (default recipe Section) |
| `AlertTone` alias | **Preserved** |
| `AlertState::{focused,region}` public fields | **Preserved** |
| `AlertState::handle_key` / `handle_intent` / `handle_key_result` | **Preserved** (1-arg); actions via `*_with` |
| `AlertOutcome::{Ignored,Dismissed,Acknowledged}` | **Preserved** (now generic `Id = ()`) |
| Thin implementations in `content.rs` | **Migrated** → `widgets/callout.rs` |
| `Banner` (single-line Severity) | **Unchanged** |
| `AlertDialog` (modal high-risk) | **Unchanged** |
| `CalloutRecipe`, slots, source, details, actions | **Added** |
| Gutter rail + section border paint | **Added** |

## Consumer edits

```diff
  use termrock::widgets::{Callout, CalloutTone, Alert, AlertState, AlertTone};
+ use termrock::widgets::{CalloutRecipe, AlertRecipe, Action};

  // Callout — compact (default) or section
  Callout::new("Heads up", &system)
      .body("…")
      .tone(CalloutTone::Warning)
+     .source("validator")
+     .section() // or .compact()
+     .ascii(true) // no-color terminals
      ;

  // Alert — dismissible, focusable
  let mut state = AlertState::new();
  state.set_focused(true);
  Alert::new("Deploy failed", &system)
      .tone(AlertTone::Danger)
+     .body("Rollout aborted")
+     .details("health check timeout")
+     .source("pipeline #42")
+     .actions(&[Action { id: "retry", label: "Retry", enabled: true, style: None }])
+     .banner() // Section recipe
      .paint(area, buf, &mut state);

- state.handle_key(key); // still works for dismiss/ack without actions
+ state.handle_key_with(key, &actions, true); // action navigation + Enter activate
```

### Recipes

| Recipe | Look |
|--------|------|
| Compact | gutter rail + title/body (inline) |
| Section | bordered + multi-line + source + actions |

### Stories

- `callout/basic`, `tones`, `section`, `unicode`
- `alert/danger`, `banner`, `compact`
