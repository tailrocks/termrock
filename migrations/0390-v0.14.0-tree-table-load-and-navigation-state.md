# 0390 — v0.14.0 TreeTable load and navigation state

## Boundary

Enter and `r` request a retry only for retryable errors. Empty and loading
states retain their existing retry behavior; non-retryable errors remain inert.
The backslash navigation-mode shortcut is handled even for an empty
projection and still requires a physical press.

## Consumer impact

No host API changes. Hosts can mark an error non-retryable and expose mode
changes while rows are loading or filtered out.
