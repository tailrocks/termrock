# 0414: InteractionScene gates pointer hits by input ownership

## Boundary

An open modal layer owns input while it is the top input-owning layer. Pointer
hit testing must use the same ownership boundary as keyboard focus
reconciliation.

## Change

`InteractionScene::hit_test` now rejects enabled, visible elements from lower
layers whenever a higher input-owning layer is present. Focus candidates and
pointer hits share the same layer-input predicate, while non-owning layers
remain transparent to the active owner.

## Consumer impact

No consumer change is required. Pointer clicks outside a trapping modal remain
ignored, and clicks on the modal's own registered elements continue to move
focus normally.
