# 0362: TreeTable hover follows painted row geometry

## Boundary

Hover is frame geometry state. A refreshed projection, loading/empty body, or
zero-area render must not leave an ID hovered when no current row hit region
represents it.

## Change

TreeTable preserves hover only while the refreshed painted row regions still
contain the hovered ID, and clears it on empty/load/zero-area frames.

## Consumer impact

No consumer edit is required. Hover remains stable across ordinary repaints
but clears automatically when its row leaves the current painted projection.
