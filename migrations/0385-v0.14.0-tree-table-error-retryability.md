# 0385: TreeTable honors error retryability

## Boundary

TreeTable must not emit retry actions for errors that explicitly disallow
retry.

## Change

Enter and `r`/`R` now emit `RetryLoad` for retryable errors only. Existing
loading and empty-state retry behavior remains unchanged.

## Consumer impact

No consumer edit is required. Non-retryable error surfaces now remain inert
until the host supplies a new load state.
