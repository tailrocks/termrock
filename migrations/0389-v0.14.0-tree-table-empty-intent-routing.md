# 0389 — v0.14.0 TreeTable empty intent routing

## Boundary

Page intents scroll an empty virtual projection by one viewport in the
requested direction. Key events are mapped to semantic movement and page
intents before empty-row indexing, so directional and page keys remain safe
while the projection is empty.

## Consumer impact

No host API changes. Non-navigation row actions remain inert when there is no
projected row.
