# 0253 — BarSeries stacked segments + bipolar negatives

## Mission

Close shadcn **bar** chart gaps (`chart-bar-stacked`, `chart-bar-negative`):
true multi-segment horizontal stacks and bipolar domain with zero baseline.
Matrix: `docs/design/shadcn-bar-charts-coverage.md`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `BarDatum::new` / `value` | **Preserved** — solid bars (`segments: &[]`) |
| `BarSeries` solid paint | **Preserved** |
| `BarDatum::stacked` · `segments` · bipolar paint | **Added** |
| Claiming stacked via `SegmentedMeter` alone as bar-stacked | **Superseded** for category bars — use `BarDatum::stacked` |

## Consumer API

```rust
use termrock::widgets::{BarDatum, BarSeries, ScaleMode};

// Solid positive / negative
let bars = [
    BarDatum::value("loss", -5.0),
    BarDatum::value("gain", 10.0),
];
BarSeries::new(&bars, &system)
    .scale(ScaleMode::Auto)
    .selected(1)
    .render(area, buf);

// Stacked segments (chart-bar-stacked)
let segs = [1.0, 2.0, 1.0];
let stacked = [BarDatum::stacked("q1", &segs)];
BarSeries::new(&stacked, &system)
    .scale(ScaleMode::Auto)
    .render(area, buf);
```
