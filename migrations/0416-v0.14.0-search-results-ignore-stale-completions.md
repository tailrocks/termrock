# 0416: SearchResults ignores stale completions

## Boundary

`SearchResultsState` owns the lifecycle status for the currently active search
generation. An asynchronous completion tagged with an older generation is no
longer authoritative and must not mutate current status or result metadata.

## Change

`apply_results` now ignores every completion whose generation is older than
the current generation. A late old result no longer changes an active search
to `Stale`, which previously broke loading, retry, and cancellation routing.
`SearchResultsStatus::Stale` remains available when the current host generation
explicitly reports that state.

Completions for the current cancelled generation remain ignored, while newer
generations continue to advance the generation and replace the status.

## Consumer impact

No consumer change is required. Hosts may continue tagging results with the
generation returned by `begin_search`; stale completions are safely dropped at
the state boundary.
