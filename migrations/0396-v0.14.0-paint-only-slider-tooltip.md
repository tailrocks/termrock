# 0396 — v0.14.0 Slider family and Tooltip are paint-only

## Breaking change

`Slider` and `RangeSlider` no longer implement Ratatui's stateless `Widget`
trait. Their explicit `paint` methods now require persistent mutable slider
state. `Tooltip` also drops its stateless `Widget` implementations and
`paint_always`; its gated `paint` takes `&TooltipState`, so visibility,
disabled, and essential-elsewhere policy cannot be bypassed.

## Consumer impact

Retain each state value and paint through the explicit stateful entries:

```rust
let mut slider_state = SliderState::new(0.5);
slider.paint(area, frame.buffer_mut(), &mut slider_state);

let mut range_state = RangeSliderState::new(0.25, 0.75);
range.paint(area, frame.buffer_mut(), &mut range_state);

let tooltip_state = TooltipState::new();
tooltip.paint(area, frame.buffer_mut(), &tooltip_state);
```

Route input through the same state before repainting.
