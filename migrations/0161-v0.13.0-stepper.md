# 0161 — Stepper

## Mission

Reusable progress/navigation chrome for multi-step flows (FormWizard, onboarding,
plans, migrations): status marks without color, horizontal/vertical layout,
policy-gated jumps, and narrow contraction to numeric or menu presentation.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `FormWizard` flow gates / nav / review | **Preserved** |
| `WizardStep` | **Migrated** → type alias of `StepItem` |
| `WizardStepStatus` | **Migrated** → type alias of `StepStatus` |
| `WizardStepStatus::Upcoming` | **Renamed** → `StepStatus::Future` |
| Inline FormWizard `paint_stepper` | **Migrated** → embeds `Stepper` |
| `Stepper*` public API | **Added** |

## Consumer edits

```diff
- WizardStepStatus::Upcoming
+ StepStatus::Future  // or WizardStepStatus::Future

+ use termrock::widgets::{
+     StepItem, StepStatus, Stepper, StepperNavPolicy, StepperOrientation,
+     StepperPresentation, StepperState, example_onboarding_steps,
+ };

+ let items = example_onboarding_steps();
+ let mut state = StepperState::with_len(items.len())
+     .policy(StepperNavPolicy::Linear)
+     .orientation(StepperOrientation::Horizontal);
+ state.set_focused(true);
+ state.set_current(1, items.len(), true);
+ match state.handle_key(key, &items) {
+     StepperOutcome::StepActivated { index, id } => host.goto(index, &id),
+     _ => {}
+ }
+ Stepper::new(&items, &system).paint(area, buf, &mut state);
```

### Policies

| Policy | Activation |
|--------|------------|
| `DisplayOnly` | Never |
| `Linear` | Current + completed/skipped/error + earlier |
| `Free` | Any non-disabled |
| `Host` | Always emit (FormWizard gates) |

### Presentation

| Width (horizontal) | Presentation |
|--------------------|--------------|
| > 48 | Expanded |
| ≤ 48 | Compact |
| ≤ 28 | Menu (`n/N title ▸`) |

### Stories

- `stepper/horizontal`, `vertical`, `error`, `numeric`, `menu`, `ascii`
