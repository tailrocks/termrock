# 0472: TextArea physical one-shot actions

## Boundary

`TextAreaState::handle_key` is the standalone multi-line editor adapter. It
owns entry into editing and host-facing clipboard, external-editor, and
fullscreen outcomes. Held physical keys must not repeat those lifecycle or
host side effects.

## Change

- Only `Press` events begin editing from idle with Enter.
- Only `Press` events emit clipboard copy/cut/paste, external-editor, and
  fullscreen requests while editing.
- Text insertion, caret and word movement, scrolling, indentation, and
  undo/redo retain their repeatable behavior.

## Host migration

Hosts routing raw `TextAreaState` events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize lifecycle or host outcomes from
`Repeat` or `Release`.
