# 0470: CommandPalette physical one-shot actions

## Boundary

`CommandPaletteState::handle_key` is the widget-level adapter for command
history, query editing, result navigation, and modal command execution. Held
keys must not repeat history mutation.

## Change

- Only `Press` events step command history with `Ctrl+P` / `Ctrl+N`.
- Existing Press-only argument submission/cancellation, modal cancellation, and
  focus traversal remain Press-only.
- Query editing and result navigation retain their repeatable behavior.

## Host migration

Hosts routing raw `CommandPalette` events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize history or modal outcomes from
`Repeat` or `Release`.
