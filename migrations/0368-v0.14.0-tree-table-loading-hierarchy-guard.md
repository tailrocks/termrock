# 0368: TreeTable loading rows reject hierarchy actions

## Boundary

TreeTable rows marked `Loading` are non-interactive even when a host leaves
their `enabled` flag set while content is being fetched.

## Change

Keyboard hierarchy intents and disclosure-pointer hits now share the same
loading-state guard as selection eligibility.

## Consumer impact

No consumer edit is required. Hosts may continue representing loading branches
with either the `loading` builder or an explicit `Loading` status.
