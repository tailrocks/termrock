# 0319 — Empty states, one-column glyphs, honest card chrome

The remaining-surface sweep. Plans 016/010/021 had already taken the
`Panelish` duplicates, the destructive confirms, the rainbow status strip and
the ops-dashboard focus cycle; this closes what was left.

## Behavior changes

**Empty panes say what is missing.** Twenty-one surfaces painted a muted
parenthetical — `"(no topics)"`, `"(select a task)"`, `"(no pending
decisions)"` — which names nothing and reads as debug output. Each is an
`EmptyState` with a title, a kind, and the next action where one exists
(`n new, i import`).

**Two-column emoji leave the chrome.** `🔒`, `📎`, `🖼`, `🔗`, `📋`, `📄`,
`📁`, `👁`, `💬` sat in one-column glyph slots, so every column to their right
shifted by a cell on exactly the rows that had them. Attachment, citation and
mention kinds use one-column marks; file and folder marks come from the glyph
catalog, which already answers `▫`/`▪` under Unicode and keeps the emoji for
the Enhanced profile. `🧪` is out of the demo fixtures.

**A running command is not a focused pane.** `TerminalRunCard` claimed
`PanelChrome::Focused` for every Running or WaitingPermission card, so a
workbench with ten running commands had ten bright borders and no way to see
which one the keyboard was on. Focus chrome follows focus; the status glyph and
the badge carry "running".

**Colorless keeps the status glyph.** The same card *removed* its leading
status glyph under `colorless` — exactly the mode where the glyph is the only
cue left. It is always painted now.

**Ahead/behind and egress markers degrade.** `↑`/`↓` in the git workbench's
branch list and `↗` in the integration status list were hardcoded Unicode; they
resolve through the glyph catalog, so an ASCII terminal gets ASCII.

## Gates

- `design_gate.rs::patterns_have_real_empty_states` — no `"(no …"` or
  `"(select …"` literal anywhere in `widgets/` or `patterns/`.
- `design_gate.rs::no_wide_emoji_in_chrome` — no emoji-presentation character
  (U+1F000–U+1FAFF) in painted chrome; the catalog's Enhanced column is where
  those belong.

## Consumer edits

- Snapshots of any empty pane listed above: a titled empty state, not a
  parenthetical line.
- Snapshots containing attachment / citation / mention / path kind glyphs.
- Snapshots of a running `TerminalRunCard`: neutral border unless focused.
