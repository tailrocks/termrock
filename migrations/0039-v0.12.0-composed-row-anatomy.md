# 0039 — Composed row and panel anatomy

## Removed surface

- String-only list/tree paint paths that treated a row as `label` + optional
  `trailing` only, without shared contraction.
- `Panel` title-only chrome without priority-ordered slots.
- Ad-hoc local leading/trailing layout in Tree paint (status/trailing).

## Canonical replacement

| Concept | API |
|---------|-----|
| Shared row anatomy | `ComposedRow<Id>` + `ComposedRowParts` |
| Contraction | `ComposedRow::parts_for_width` — drop order shortcut → badge → secondary → leading → primary |
| Paint | `ComposedRowParts::paint` |
| List rows | `ListRow` fields: `leading`, `primary` (`label`), `secondary`, `badge`, `shortcut`, `trailing`, `loading` + `ListRow::composed` / `ListRow::item` |
| Tree rows | `TreeNode` same optional fields + `TreeNode::new` / `TreeNode::composed` |
| Table rows | `TableRow::{leading,badge}` + `TableRow::composed` |
| Panel slots | `PanelSlots` + `Panel::{subtitle,leading,trailing,footer,slots,slots_for_width,block_for_width}` |

`Panel` still takes `&DesignTokens` only (no Theme constructor). Focus remains
`PanelEmphasis` → `Role::BorderFocused` via `panel_recipe` — border **weight**
never encodes focus.

## Consumer edits

### List

```rust
// Before
ListRow {
    id,
    label: Line::from("Build"),
    trailing: Some(Line::from("ok")),
    role: RowRole::Item,
    enabled: true,
}

// After
let mut row = ListRow::item(id, Line::from("Build"));
row.badge = Some(Line::from("ok"));
// or keep trailing — maps to badge in composed() when badge is unset
row.trailing = Some(Line::from("ok"));
```

Prefer `ListRow::item` so new anatomy fields stay defaulted.

### Tree

```rust
// Before
TreeNode {
    id,
    label: Line::from("src"),
    trailing: None,
    depth: 0,
    branch: true,
    expanded: true,
    enabled: true,
    status: TreeNodeStatus::Ready,
}

// After
let mut node = TreeNode::new(id, Line::from("src"), 0);
node.branch = true;
node.expanded = true;
// optional: node.leading / secondary / badge / shortcut
```

Struct literals must include `leading`, `secondary`, `badge`, `shortcut`
(usually `None`).

### Table

```rust
TableRow::new(id, &cells)
// or
TableRow {
    id,
    cells: &cells,
    leading: None,
    badge: None,
    enabled: true,
    emphasis: false,
    style: None,
}
```

### Panel

```rust
Panel::new(&tokens)
    .title("Main")
    .subtitle("context")
    .leading("*")
    .trailing("3")
    .footer("Esc close")
    .emphasis(PanelEmphasis::Focused);
```

Narrow widths drop footer → trailing → subtitle → leading before title.

## Ownership

| Concern | Owner |
|---------|--------|
| Domain labels/status values | Consumer projection |
| Drop priority + grapheme paint | TermRock `ComposedRow` / `PanelSlots` |
| Focus border role | TermRock `Panel` + tokens |
| Action effects | Consumer (outcomes only) |
