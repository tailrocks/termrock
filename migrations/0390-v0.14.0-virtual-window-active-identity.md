# 0390: Virtual movement preserves off-window active identity

## Boundary

Virtualized collection movement must not infer a replacement cursor from a
partial projection when the active identity is outside that projection.

## Change

`CollectionState` preserves a missing active ID for virtual windows and returns
control to the owning virtualizer. VirtualList movement is non-wrapping, so
projected edge movement also reaches that virtualizer. Non-virtual collections
retain their normal missing-active recovery and wrap policy.

VirtualList reports no movement for row, page, or already-satisfied First/Last
actions when the owning virtualizer clamps or is already at its boundary.

Intent dispatch initializes virtual metadata before handling a pre-paint or
empty projection, so an off-window active ID is not cleared on the first event.

## Consumer impact

VirtualList Up/Down movement now scrolls the virtualizer while preserving the
off-window selected ID until the host supplies the next projection.
