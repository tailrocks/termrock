# 0379: TreeTable Up stops before the first selectable row

## Boundary

TreeTable backward movement must not select a later row when the cursor is on
a leading group or loading row.

## Change

Backward movement now returns `Ignored` when the cursor's insertion point is
before every selectable row. Forward movement retains its recovery to the
first selectable row.

## Consumer impact

No consumer edit is required. Up remains at the leading non-selectable row
until a selectable predecessor exists.
