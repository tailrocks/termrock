# 0363: TreeTable header hits follow painted column geometry

## Boundary

Header hit regions are frame geometry state. A reordered, removed, or otherwise
changed column model must not let cached geometry sort the wrong column.

## Change

TreeTable validates a header hit against the current visible sortable column and
the cached painted column index and rectangle before emitting `SortSpec`.

## Consumer impact

No consumer edit is required. Hosts must still render after changing columns;
stale cached header geometry now fails closed until the next valid frame.
