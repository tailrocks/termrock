# 0370: TreeTable movement recovers from non-selectable cursors

## Boundary

TreeTable Up/Down movement must not skip the nearest selectable row when a
projection leaves the cursor on a group or disabled row before reconciliation.

## Change

Movement now treats a non-selectable cursor as an insertion point in the
selectable row indexes, preserving direction while recovering the cursor.

## Consumer impact

No consumer edit is required. Reprojected rows can be handled immediately; the
first directional movement chooses the nearest valid row in that direction.
