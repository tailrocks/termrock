# 0103 — Panel / Card premium anatomy

## Mission

Harden Panel and Card into composable containers with full header anatomy:
badge, header actions, body modes, responsive drop order, and descendant-first
focus. ToolCard and dashboard cards build on Card chrome without nested boxes.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Panel`, `PanelSlots`, `PanelVariant`, `PanelBody`, `PanelParts` | **Preserve** |
| `PanelState`, `PanelOutcome::{Ignored,Activated,ToggleCollapsed}` | **Preserve** (outcome no longer `Copy`) |
| `Panel::title/subtitle/leading/trailing/footer/emphasis/chrome/variant/body` | **Preserve** |
| `Panel::collapsible`, `raised`, `paint`, `layout`, `inner` | **Preserve** |
| `Card`, `CardParts`, description band | **Preserve** |
| `ToolCard` | **Preserve** — paints via Card; body no longer duplicates title line |
| `PanelAction`, `Panel::badge`, `Panel::header_actions` | **Added** |
| `PanelOutcome::HeaderAction { id }` | **Added** |
| `PanelState::action_hits` | **Added** (filled during `paint`) |
| `Panel::actions_visible`, `register_semantic` | **Added** |
| `Card::badge`, `header_actions`, `is_focusable` | **Added** |
| Nested box-of-boxes / product-branded panels | **Deleted** (never ship) |

## Drop order (narrow width)

Chrome contracts first-dropped → last-kept:

1. footer  
2. header_actions (hidden when width &lt; 28)  
3. badge  
4. trailing  
5. subtitle  
6. leading  
7. title (survives)

## Focus policy

- Default: focus belongs to interactive **descendants** (list, buttons, inputs).
- Panel-level focus only when `variant == Interactive` **or** `collapsible`.
- Selected ≠ Focused: `PanelVariant::Selected` uses selection surface + gutter;
  focus still uses `PanelChrome::Focused` → `Role::BorderFocused`.
- Header action clicks emit `HeaderAction` and do **not** toggle collapse.

## API sketch

```rust
use termrock::widgets::{
    Panel, PanelAction, PanelBody, PanelOutcome, PanelState, PanelVariant, Card,
};
use termrock::style::{DesignSystem, PanelChrome};

let system = DesignSystem::default();
let actions = [
    PanelAction::new("retry", "Retry"),
    PanelAction::new("logs", "Logs"),
];

let mut state = PanelState::new();
let body = Panel::new(&system)
    .title("Build")
    .subtitle("main")
    .leading("!")
    .badge("failed")
    .header_actions(&actions)
    .footer("esc")
    .body(PanelBody::Error)
    .body_title("Failed")
    .body_detail("timeout")
    .paint(area, buf, Some(&mut state));

// Mouse on action band
let out = state.handle_mouse(mouse, /*collapsible*/ false, /*interactive*/ false);
// PanelOutcome::HeaderAction { id: "retry" }

// Card / tool / dashboard
let body = Card::new(&system)
    .title("Latency")
    .badge("live")
    .description("p99 last hour")
    .header_actions(&actions)
    .paint(area, buf, None);
```

## Consumer edits

1. Match on `PanelOutcome` — variant is no longer `Copy` (owns `String` id).
2. Prefer `.badge(...)` for status chips; keep `.trailing(...)` for passive meta.
3. Wire `HeaderAction` from `state.handle_mouse` (or host routing via `action_hits`).
4. Do not put focus on static bordered panels — only Interactive / collapsible.
5. ToolCard hosts: chrome has name/status; expanded body is detail-only.
