# 0465: Tabs physical one-shot actions

## Boundary

`TabsState::handle_key` is the raw keyboard adapter for tab focus, activation,
overflow, close, and reorder actions. Held keys must not repeat one-shot tab
actions.

## Change

- Only Press events can request close, toggle or dismiss overflow, reorder a
  tab, or manually activate the focused tab.
- Repeat events remain available for directional, Home, and End navigation;
  automatic activation still follows repeatable focus movement.
- Release events remain ignored.
- Semantic intent and pointer paths are unchanged.

## Host migration

Hosts routing raw Tabs events must pass complete `KeyEvent` values, including
lifecycle kind. Do not synthesize close, overflow, reorder, or activation
outcomes from `Repeat` or `Release` events.
