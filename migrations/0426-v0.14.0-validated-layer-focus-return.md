# 0426: Validate layer focus restoration

## Boundary

`InteractionScene` validates a dismissed layer's requested focus return
against the current frame and active input layer before restoring it. Stale
overlay opener IDs must not become focused state after a layer is removed.

## Change

When a dismissible layer closes through Escape or an outside click:

- A present, focusable, enabled, visible opener on the active input layer is
  restored.
- A missing, disabled, hidden, or inactive-layer opener is rejected.
- Rejected openers use the normal `InteractionScene::reconcile` focus order,
  which selects the first valid active-layer candidate or clears focus when no
  candidate exists.

The same validated restoration path serves keyboard and pointer dismissal.
Valid focus-return behavior is unchanged. Layer policy still decides whether
Escape or an outside click may dismiss the top layer.

## Host migration

Hosts may continue supplying a stable `focus_return` ID when opening a layer.
They must register current-frame focusable elements before reconciliation and
must treat the returned `focus` in `LayerDismissed` as authoritative. Hosts
must not restore an opener ID separately after scene dismissal.
