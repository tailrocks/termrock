# Composition and measurement primitives

Plan 007 replaces consumer-owned paint and sizing workarounds with canonical,
product-neutral TermRock building blocks. These APIs are additive; consumers
can migrate one workaround at a time.

## Canonical replacements

| Consumer workaround | Canonical API |
|---|---|
| Hand-painted label/value/secret rows | `widgets::FieldRow` and `FieldRowValue` |
| Hand-painted actor/block gutter | `widgets::AccentRail` |
| Parallel tree renderer | `widgets::Tree` with `ToneTier` and pinned label scroll |
| Manual content-sized panel allocation | `layout::panel_stack` and `PanelStackBlock` |
| Three-pass hint-bar reflow | `widgets::HintBar::measured_height` and `leading_spacer` |
| Hand-computed detail-table dimensions | `widgets::DetailTable::measure` |
| Consumer five-slot dialog shim | `widgets::Dialog` slot composition from migration 0263 |

## Consumer edits

Before:

```rust
let detail_width = rows.iter().map(measure_detail_row).max().unwrap_or(0);
let hint_rows = reflow_hints(&hints, available_width).len();
```

After:

```rust
let detail_width = DetailTable::new(&rows, &system).measure().0;
let hint_rows = HintBar::new(&hints, &system)
    .leading_spacer(true)
    .measured_height(available_width);
```

Delete copied row, rail, tree, panel-stack, hint-reflow, and detail-width
renderers after migrating. Do not keep aliases or dual paint paths.
