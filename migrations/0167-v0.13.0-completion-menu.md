# 0167 — CompletionMenu redesign

## Mission

Reusable anchored suggestion surface for editors and inputs: groups, fuzzy
ranges, kind glyphs, details, documentation preview, async generation gates,
loading / empty / stale chrome, commit characters, active-descendant navigation
(editor keeps focus), Tab/Enter/Esc via semantic intents, clamp/flip placement,
and fullscreen promotion on small terminals.

## Consumer edits

```diff
  let mut state = CompletionMenuState::new(Some("select"));
+ state.set_commit_characters("().");
+ state.set_show_docs(true);

+ // host fetch…

  let cand = CompletionCandidate::new("map", "map")

+ // Tab / Enter → Committed; Esc → Dismissed; '(' → CommitWithChar if configured

  // Geometry

+ // small terminals → Fullscreen via completion_presentation_for / open_completion_configured

+     .paint(area, buf, &mut state);
```

### Active descendant

`OverlayKind::Completion` keeps `focus_trap: false`. Semantic node is
**not** focusable; `selected` is the active descendant while the editor retains
keyboard focus. Host routes keys into the menu only when the popup is open.

### Async

```text
begin_async() → generation N, status Loading
apply_results(N, …) → Ready/Empty
apply_results(old, …) → GenerationStale (ignored)
mark_stale() → Stale chrome
```
