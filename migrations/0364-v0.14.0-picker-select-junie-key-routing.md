# 0364: Picker and Select follow Junie key routing

## Boundary

Picker secondary actions and Select list navigation are public interaction
contracts. Their key phase must not be confused with typeahead or value cycling.

## Change

Picker now emits `PickerOutcome::Secondary` for Delete on the selected row.
Closed Select ignores `j`/`k` (including modified forms), while an open,
non-searchable Select uses those keys to move its highlight without wrapping.

## Consumer impact

Hosts handling Picker outcomes must route `Secondary` to the row-level action
(Junie uses it to close a tab). Select hosts can rely on `j`/`k` highlight
movement while open; arrow keys retain closed-value cycling.
