# 0124 — AnsiText

## Mission

Safely parse and paint ANSI-styled terminal output inside TermRock surfaces:
SGR colors/styles, resets, CR/BS/tabs, OSC 8 hyperlinks, malformed sequences,
no-color/strip modes, incremental streaming with bounded history, and
LogStream / TerminalOutput integration — without leaking escapes to the host PTY.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `strip_bytes` | **Preserved** |
| `styled_spans` / `line_from_ansi` | **Preserved** — now route through full parser |
| `text::{strip_bytes, styled_spans}` re-exports | **Migrated** — broader re-export surface |
| `anstyle_parse` dependency | **Preserved** |
| `AnsiStream`, `AnsiLine`, `AnsiText` widget | **Added** |
| Full VT100 emulator (cursor modes, alt screen) | **Out of scope** — dropped CSI non-SGR |

## API sketch

```rust
use termrock::ansi_text::{
    AnsiStream, AnsiText, AnsiTextState, AnsiParseOptions, parse_lines, lines_for_log,
};
use termrock::widgets::LogPaneState;

// One-shot parse (log append)
let lines = lines_for_log(chunk, system.style(Role::Text));
for line in lines {
    log_pane.append(line);
}

// Streaming PTY / tool output
let mut stream = AnsiStream::new(AnsiParseOptions::for_system(&system))
    .with_max_lines(10_000);
stream.feed(bytes);
stream.drain_into_lines(|line| log_pane.append(line));

// Widget paint
let parsed = parse_lines(src, &opts);
let mut state = AnsiTextState::new();
AnsiText::lines(&parsed, &system)
    .mode(AnsiTextMode::NoColor)
    .paint(area, buf, &mut state);
```

## Safety

- ESC / CSI / OSC / DCS never appear in segment text (`is_paint_safe`)
- Non-SGR CSI ignored (no host cursor motion)
- OSC 8 only `http(s)` / `mailto` / `file` schemes
- Incomplete sequences held across `feed` boundaries; never flushed raw
