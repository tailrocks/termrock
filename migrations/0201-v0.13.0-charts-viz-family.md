# 0201 — Sparkline, Chart, Gauge, Histogram visualization family

## Mission

Coherent terminal data-viz family: time series, bars, stacked bars, histogram
buckets, gauges, thresholds, labels, legends, missing data, selected points.
Braille/block/ASCII capability fallbacks with consistent scale semantics.
Autoscale, fixed, log, time-window. No-color via glyphs, markers, labels, and
ordering. Benchmark streaming updates and tiny dimensions.

Research: btop, bottom, gping, Ratatui charts, observability dashboards.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Sparkline::new(samples, system)` | **Migrated** — autoscales raw values; use `.pre_normalized(true)` for old `0..=1` path |
| `BarDatum` / `BarSeries` | **Preserved** API; shared glyphs/scale/selection |
| `MeterSegment` / `SegmentedMeter` | **Preserved**; no-color uses series markers |
| `Role::ChartSeries*` / `ChartAxis` / `ChartGrid` | **Preserved** |
| `Chart` / `ChartSeries` | **Added** |
| `Gauge` | **Added** |
| `Histogram` / `HistBucket` | **Added** |
| `ScaleMode` / `ScaleDomain` / `VizGlyphSet` | **Added** shared substrate |
| `charts_bench` | **Added** |
| Nothing deleted | Compose; TokenMeter stays separate usage meter |

## Consumer API sketch

```rust
use termrock::widgets::{
    Sparkline, Chart, ChartSeries, Gauge, Histogram, HistBucket,
    BarSeries, BarDatum, SegmentedMeter, MeterSegment,
    ScaleMode, VizGlyphSet,
};

// Sparkline: raw series + threshold + selection
Sparkline::new(&cpu, &system).threshold(80.0).selected(i).window(60);

// Multi-series chart
Chart::new(&[ChartSeries::new("cpu", &cpu), ChartSeries::new("mem", &mem)], &system)
    .title("host")
    .thresholds(&[90.0])
    .scale(ScaleMode::Fixed { min: 0.0, max: 100.0 });

// Gauge
Gauge::percent(72.0, &system).label("cpu").unit("%").thresholds(&[70.0, 90.0]);

// Histogram
Histogram::new(&[HistBucket::new("0-10", 3.0), HistBucket::new("10-20", 8.0)], &system)
    .selected(1);

// Legacy bars still work
BarSeries::new(&[BarDatum { label: "a", fraction: 0.5 }], &system);
```
