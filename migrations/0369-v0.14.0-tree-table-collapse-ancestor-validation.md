# 0369: TreeTable collapse validates parent ancestry

## Boundary

TreeTable collapse must move only to a preceding, shallower row in the current
projection. A stale parent ID must not target a later or unrelated row.

## Change

Explicit parent lookup is now constrained to the rows before the cursor and to
rows with a lower hierarchy depth; the existing depth fallback handles invalid
metadata.

## Consumer impact

No consumer edit is required. Reordered or stale parent metadata now safely
falls back to the nearest selectable preceding ancestor.
