# 0386: TreeTable cycles nav mode on empty projections

## Boundary

TreeTable navigation-mode configuration must remain available even when the
current virtual projection has no rows.

## Change

The `\` mode-cycle key now runs independently of row normalization. Empty
virtual projections can switch navigation modes without changing scroll or
selection state.

## Consumer impact

No consumer edit is required. Focused TreeTable surfaces can keep changing
navigation mode while awaiting a projected slice.
