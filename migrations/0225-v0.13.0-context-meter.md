# 0225 — ContextMeter budget display

## Mission

Trustworthy context/token/resource budget display: used/available, compaction
threshold, model limit, included sources, cached content, pending attachments,
warning, expandable breakdown. Avoid false precision when approximate. Concise
composer/status form and detailed popover. Show actions that reduce usage or
trigger compaction. Generic measurement units beyond tokens.

Research: Amp compaction, OpenCode context displays, AI chat token meters.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TokenMeter` | **Preserved** — thin used/limit paint; prefer ContextMeter for full budget |
| Charts `Gauge` / `SegmentedMeter` | **Preserved** — generic viz |
| `ProgressBar` | **Preserved** — task progress ≠ context budget |
| Process/PTY | **Never** |
| `ContextBudget` · `BudgetMeasure` · `ContextMeter*` · format helpers | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    ContextBudget, ContextMeter, ContextMeterState, ContextMeterPresentation,
    ContextSource, ContextSourceKind, BudgetMeasure, BudgetPrecision, BudgetUnit,
    format_budget_compact, context_budget_from_tokens,
};

let budget = ContextBudget::tokens(160_000, 200_000)
    .compaction_threshold_pct(75)
    .model("grok-4", Some(200_000))
    .source(ContextSource::new("m", "messages", 100_000))
    .source(ContextSource::new("t", "tools", 40_000).kind(ContextSourceKind::Tool))
    .cached(10_000)
    .pending_attachments(5_000)
    .warning("near limit")
    .compact_action("compact now")
    .reduce_action("drop attachments");

// Approximate estimator
let approx = ContextBudget::new(BudgetMeasure::approximate(
    48_000,
    Some(128_000),
    BudgetUnit::Tokens,
));

// Unknown totals — indeterminate bar, never "100%"
let unknown = ContextBudget::new(BudgetMeasure::unknown(BudgetUnit::Tokens));

let mut st = ContextMeterState::new();
st.presentation = ContextMeterPresentation::Compact; // or Expanded / Popover
// ContextMeter::new(&budget, &system).paint(area, buf, &mut st);

match st.handle_key(key, &budget) {
    ContextMeterOutcome::CompactRequested => { /* host compact */ }
    ContextMeterOutcome::ReduceRequested => { /* host drop attachments */ }
    ContextMeterOutcome::Activated | ContextMeterOutcome::OpenBreakdown => { /* popover */ }
    _ => {}
}

// StatusBar one-liner without widget:
let _ = format_budget_compact(&budget.measure);
```

### Precision rules

| Precision | Display |
|-----------|---------|
| Exact | Full counts; % as integer |
| Approximate | `~` prefix; % rounded to 5% |
| Unknown | `—`; hatch bar; **never 100%** |

### Keys

| Key | Action |
|-----|--------|
| Enter | Activate (when focused) |
| e | Toggle expand |
| c | Compact request (if action / at threshold) |
| r | Reduce request |
| b | Open breakdown |
| Esc | Collapse |

### Stories

- `context-meter/{low-mid-high,indeterminate,approximate,expanded,mono,bytes}`
