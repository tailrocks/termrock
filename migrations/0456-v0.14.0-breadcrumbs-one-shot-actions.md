# 0456: Breadcrumbs physical one-shot actions

## Boundary

`BreadcrumbsState::handle_key` is the raw physical keyboard adapter for trail
navigation, overflow, and optional path editing. Held keys must not repeat
navigation outcomes, edit-mode transitions, activation, blur, or overflow
close requests through one-shot controls.

## Change

- Repeat and release events are ignored for Enter, Space, Escape, Ctrl+E, and
  slash edit/activation controls where they start, finish, cancel, open, close,
  or blur the control.
- Left/Right/Home/End navigation and ordinary draft text/backspace editing
  remain repeatable.
- Semantic `handle_intent` remains phase-free.

## Host migration

Hosts routing raw Breadcrumbs events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize repeated activation, edit-mode,
overflow, blur, or cancel outcomes from `Repeat` or `Release` events.
