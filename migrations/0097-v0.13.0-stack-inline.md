# 0097 — Stack and Inline layout primitives

## Mission

Ergonomic vertical/horizontal packing with terminal-cell spacing, alignment,
justify, wrap, and deterministic overflow — without retained layout state.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `WorkSurface` / `Workspace` | **Preserve** — multi-pane shells with named regions |
| `bottom_rows`, `Slots`, `centered_rect` | **Preserve** — specialized helpers |
| `layout::{Stack, Inline, FlexSize, layout_stack, …}` | **Added** |
| Ad hoc `y += h` packing in components | **Migrate** reps (Card description, Callout body) |

## API

```rust
use termrock::layout::{
    Stack, Inline, FlexSize, Align, Justify, direction_for_width, layout_stack, StackSpec,
};

// Vertical (Stack)
let layout = Stack::new().gap(1).layout(area, &[
    FlexSize::Fixed(2),
    FlexSize::Weight(1),
    FlexSize::Fixed(1),
]);
let body = layout.get(1).unwrap();

// Horizontal (Inline)
let cols = Inline::new().gap(1).layout(area, &[
    FlexSize::Weight(1),
    FlexSize::Weight(1),
]);

// Wrap chips
let chips = Inline::new().wrap(true).gap(1).layout(area, &[
    FlexSize::Fixed(6),
    FlexSize::Fixed(6),
    FlexSize::Fixed(6),
]);

// Responsive direction
let dir = direction_for_width(area.width, 60);
```

## Overflow

When fixed/preferred sum exceeds main axis: shrink from the **end**, set
`StackLayout::overflowed`. Weight children take residual after mins.

## WorkSurface vs Stack

| | Stack/Inline | WorkSurface |
|--|--------------|-------------|
| Identity | index only | `RegionId` |
| Use | component anatomy | app chrome panes |
| Align/justify/wrap | yes | no |

## Migrated

- `Card` description/body split uses `Stack`
- `Callout` title/body rows use `Stack`
