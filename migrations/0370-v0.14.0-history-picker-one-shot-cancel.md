# 0370 — v0.14.0 HistoryPicker cancellation is one-shot

## Boundary

`HistoryPickerState::handle_key` now closes the picker only for a press-phase
Escape event. Repeat and release events are ignored before the picker
reconciles its visible rows, so they cannot close the surface or change its
draft while being ignored.

## Change

- Bare Escape press keeps its `Cancelled` outcome and preserves the saved
  draft for restoration by the host.
- Escape repeat and release return `Ignored` and preserve the open state and
  draft.
- Key repeats for navigation such as Down remain enabled.

## Host migration

No host change is required. Hosts should treat `Ignored` as a no-op and may
continue to restore the preserved draft after `Cancelled`.
