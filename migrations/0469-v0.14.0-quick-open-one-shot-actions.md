# 0469: QuickOpen physical one-shot actions

## Boundary

`QuickOpenState::handle_key` is the widget-level adapter for quick-open modal
navigation and host-facing transitions. Held keys must not repeat provider
selection or other modal actions.

## Change

- Only `Press` events cycle providers with `Ctrl+P` / `Ctrl+N`.
- Existing Press-only confirmation, cancellation, focus traversal, jump-mode,
  and presentation transitions remain Press-only.
- Query editing and result navigation retain their repeatable behavior.

## Host migration

Hosts routing raw `QuickOpen` events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize provider changes or modal outcomes
from `Repeat` or `Release`.
