# 0040 — Agent Workbench pattern

## Canonical addition

`patterns::AgentWorkbenchState` + `render_agent_workbench` +
`agent_workbench_layout` / `sync_workbench_scene` / `WorkbenchModals`.

Agent blocks (product-neutral):

- `ModeRibbon` / `WorkbenchMode` / `ModeRibbonState`
- `QuestionFlow` / `QuestionStep` / `QuestionFlowState`
- `PlanReview` / `PlanStep` / `PlanReviewState`
- `SessionPicker` / `SessionItem` / `TaskRail`

Consumers own state across frames:

- `AgentWorkbenchState.scene` — persistent `InteractionScene` (Esc/focus)
- `AgentWorkbenchState.workspace` — collapse/zoom
- `AgentWorkbenchState.task_list` — task rail list state
- `AgentWorkbenchState.mode_ribbon` / `question` — mode + interview state

## Consumer integration

```rust
let mut workbench = AgentWorkbenchState::new();
let modes = default_modes("plan");
// each frame:
render_agent_workbench(buf, area, WorkbenchSurfaces {
    tokens: &tokens,
    state: &mut workbench,
    tasks: &task_rows,
    modes: &modes,
    transcript: &transcript,
    transcript_state: &mut tstate,
    prompt: &prompt,
    prompt_state: &mut pstate,
    status_slots: &slots,
    status_state: &mut sstate,
    approval: Some((&card, &mut astate)),
    question: Some(&flow),
});
// Esc peels top dismissible layer (approval → question → …):
workbench.handle_escape();
workbench.focus_pane(WorkbenchPane::Prompt);
```
