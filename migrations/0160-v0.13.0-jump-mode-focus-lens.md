# 0160 — JumpMode and FocusLens

## Mission

Terminal-native direct navigation over `SemanticScene` regions (easymotion-style
labels) plus FocusLens inspection chrome. Widgets participate only via semantic
registration — JumpMode never reaches into component state machines.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `JUMP_OVERLAY_ID`, open/dismiss overlay helpers | **Preserved** |
| `JumpOverlay` paint widget | **Preserved** — enhanced (ascii/colorless/prefix) |
| `JumpOverlayState` | **Preserved** — multi-key prefix + filter |
| `JumpMode` / `JumpModeState` | **Added** as type aliases |
| `JumpTarget.badge: char` | **Migrated** → `keys: String` + `badge()` helper |
| `assign_jump_badges` / `_from_semantics` | **Preserved** — now prefix-free multi-key labels |
| `JumpFilter`, `collect_jump_candidates`, `generate_jump_labels` | **Added** |
| `FocusLens` | **Preserved** — modes, ascii, colorless |
| `FocusLensMode` | **Added** |
| Component widgets | **Unchanged** — register semantics only |

## Consumer edits

```diff
- JumpTarget { id, area, badge: 'f' }
+ JumpTarget::new(id, area, "f")
+ // or multi-key when many targets:
+ let targets = assign_jump_badges_from_semantics(&scene);
+ // filtered:
+ let targets = assign_jump_labels_from_semantics(
+     &scene,
+     &JumpFilter::new().roles([SemanticRole::Button]),
+ );

  let mut state = JumpOverlayState::new(); // = JumpModeState
  state.open_on_stack(&mut stack, bounds, Some(focus));
  match state.handle_key(key, &targets) {
-     JumpOutcome::Activated(id) => …
+     JumpOutcome::Activated(id) => …
+     JumpOutcome::Prefix { keys, remaining } => { /* optional chrome */ }
      JumpOutcome::Dismissed => …
  }
  JumpOverlay::from_state(&targets, &system, &state).render(area, buf);

  // FocusLens
  FocusLens::new(&graph, &system)
+     .mode(FocusLensMode::Combined)
+     .ascii(false)
      .render(area, buf);
```

### Label algorithm

Prefix-free equal-length batches: `n≤26` → single letters; larger → length 2+
(`aa`…), so multi-key entry cannot collide with a shorter complete label.

### Stories

- `jump-overlay/basic`, `jump-mode/multi`, `jump-mode/filter`, `jump-mode/ascii`
- `focus-lens/combined`
