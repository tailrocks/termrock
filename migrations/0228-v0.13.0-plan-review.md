# 0228 — PlanReview interactive plan document review

## Mission

Interactive review surface for agent-generated plans: Markdown body, sections,
source refs, tasks, risks, assumptions, affected files; line/range comments with
stable-anchor remapping across revisions; version-diff pane; approve / approve
with conditions / request revision / edit feedback / abandon. **Safe focus** —
Approve never initial; Enter confirms focused action only; `y` unbound; Esc
cancels without approve.

Research: Grok Build plan approval, code review workflows, document annotation.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Thin `PlanStep` / `PlanReview` / `PlanReviewState<Id>` / `PlanReviewOutcome::Accepted` (bare `a`) in `agent_blocks` | **Deleted** |
| `PermissionRisk` | **Preserved** — aggregate plan risk + default focus |
| `PermissionPrompt` | **Preserved** — single-action trust gate |
| `DiffReview` | **Preserved** — patch review; PlanReview is plan-level |
| `QuestionFlow` | **Preserved** — interview HITL |
| `ProgressSteps` | **Preserved** — execution progress |
| `ResponsiveSurface::PlanReview` | **Preserved** (policy key) |
| `PlanDocument` · `PlanAction` · elevated `PlanReview*` · `remap_plan_comments` | **Added** |

## Breaking API

```rust
// Before
let steps = [PlanStep { id: "s1", title: "Inspect", detail: None, accepted: false }];
let mut state = PlanReviewState::new(Some("s1"));
PlanReview::new(&steps, &system).render(area, buf, &mut state);
state.handle_key(&steps, key); // Char('a') → Accepted (unsafe bare grant)

// After
use termrock::widgets::{
    PlanDocument, PlanReview, PlanReviewState, PlanReviewOutcome, PlanAction,
    example_plan_document, PermissionRisk,
};

let mut state = PlanReviewState::new();
state.open(example_plan_document()); // or PlanDocument::new(...)
PlanReview::new(&system).paint(area, buf, &mut state);

match state.handle_key(key) {
    PlanReviewOutcome::Approved => { /* host executes */ }
    PlanReviewOutcome::ApprovedWithConditions { conditions } => { /* … */ }
    PlanReviewOutcome::RevisionRequested { feedback } => { /* … */ }
    PlanReviewOutcome::Abandoned => { /* discard */ }
    PlanReviewOutcome::Cancelled => { /* Esc peel — not abandon */ }
    PlanReviewOutcome::CommentAdded(c) => { /* store */ }
    PlanReviewOutcome::ActionFocused(PlanAction::Approve) => { /* focus only */ }
    _ => {}
}
```

### Action-focus rules

| Rule | Detail |
|------|--------|
| Default focus | `PlanAction::default_for_risk(risk)` — **never Approve** |
| Low/Medium | `RequestRevision` |
| High/Critical | `Abandon` |
| Enter | Confirms **focused** action only |
| `a` / `r` / `x` / `c` | Move focus only (do not resolve) |
| `y` | Unbound |
| Esc | `Cancelled` (≠ Abandoned); plan stays open for host peel |
| Empty plan | Grant actions removed from strip |
| Risk upgrade | Snaps focus off grant-class actions |

### Comments

`m` starts comment on selection; `remap_plan_comments` / `update_plan` preserve
section/task/file anchors and in-range lines; lost anchors become `Orphan`.
