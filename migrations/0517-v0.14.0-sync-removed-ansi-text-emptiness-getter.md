# 0517: Synchronize removed AnsiText emptiness getter

## Boundary

The dead-accessor sweep removed the unused `AnsiText::is_empty` getter. The
generated public API snapshot retained three duplicate signatures even though
the getter is no longer available.

## Change

Removed all three stale snapshot entries for `AnsiText::is_empty` deleted by
`855e4147`.

## Host migration

Use `AnsiText::len` when a line count is needed; derive emptiness from that
count at the host boundary. No compatibility alias or deprecation period is
provided.
