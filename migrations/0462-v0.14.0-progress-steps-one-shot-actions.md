# 0462: ProgressSteps physical one-shot actions

## Boundary

`ProgressStepsState::handle_key` is the raw keyboard adapter for interactive
pipeline steps. Held keys must not repeat lifecycle outcomes or blur focus.

## Change

- Only Press events can activate/retry a step with Enter or `r`/`R`.
- Only Press events can blur interactive focus with Escape.
- Repeat events remain available for `j`/`k` and Up/Down selection navigation.
- Release events remain ignored.
- Semantic intent and pointer paths are unchanged.

## Host migration

Hosts routing raw ProgressSteps events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize activation, retry, or blur
outcomes from `Repeat` or `Release` events.
