# 0383: TreeTable pages empty virtual projections

## Boundary

TreeTable vertical movement must remain available when a partial virtual
projection is temporarily empty.

## Change

Empty projections now route Up, Down, PageUp, and PageDown through the virtual
window before returning `Ignored`. Selection and cursor identity stay intact.

## Consumer impact

No consumer edit is required. Hosts can page through unloaded or empty virtual
slices without synthesizing placeholder rows.
