# 0412: Tree input reconciles projections before dispatch

## Boundary

Hosts may replace a tree projection and dispatch input before the next render.
That input must not operate on a removed cursor identity.

## Change

`TreeState::handle_key` and `TreeState::handle_intent` now run the shared
allocation-free projection reconciliation before dispatch. Keyboard routing
uses a private already-reconciled dispatcher to avoid repeating the scan.
Full projections therefore repair a stale cursor before activation or
navigation; partial virtual windows retain their off-window identity policy.

## Consumer impact

No consumer change is required. Input dispatched between host projection
replacement and painting now activates or navigates the repaired interactive
row instead of ignoring the event or skipping the first valid row.
