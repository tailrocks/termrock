# 0378: TreeTable invalidates stale row geometry

## Boundary

TreeTable pointer geometry must not authorize disclosure actions after a host
reprojects the same row ID with different hierarchy semantics.

## Change

`reconcile` clears cached row regions. A fresh render must repopulate geometry
before pointer input is accepted, so branch, depth, and disclosure changes are
validated by current paint.

## Consumer impact

No consumer edit is required. Hosts should continue reconciling before render;
pointer input naturally waits for the next painted projection.
