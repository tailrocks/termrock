# 0475: Remove the unreferenced NumberInput read-only getter

## Boundary

`NumberInputState::is_read_only` had no call sites in the complete workspace
corpus. Read-only behavior remains enforced by the state and its keyboard
adapter; only the unreferenced public projection is removed.

## Change

- Remove `NumberInputState::is_read_only` completely.
- Preserve `set_read_only`, read-only edit guards, and the distinct getters on
  other input state types.

## Host migration

Consumers needing the setting must retain the value they pass to
`set_read_only`; no compatibility alias or deprecation period is provided.
