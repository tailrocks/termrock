# 0187 — Tree hierarchy redesign

## Mission

Redesign Tree for files, schemas, tasks, settings, and object hierarchies:
stable IDs, lazy children, loading/error child state, expansion, active cursor,
selection/check, icons, metadata, context actions, typeahead. Left/right
collapse and expand-or-enter semantics. Filtering retains ancestor context.
Virtual windows + scroll anchors for large trees. ASCII disclosure/indent
fallbacks via glyph set.

Research: file explorers, broot, Yazi, VS Code trees, TermRock List/VirtualList.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tree::new` / `from_system` / `focused` / `empty_message` | **Preserved** |
| `TreeNode::new` / builders / flattened host projection | **Preserved** |
| `TreeState` selection, multi-check, scroll, hover | **Preserved** |
| `TreeOutcome` | **Preserved** |
| `default_tree_intent` Left/Right Expand/Collapse | **Preserved** + richer enter/parent |
| Expansion on `TreeNode.expanded` (host-owned) | **Preserved** |
| `TreeNavigation` (route tree) | **Preserved** — distinct product |
| `TreeNodeStatus::Lazy` | **Added** |
| `TreeNode::{actions, parent}` + `lazy_branch` | **Added** |
| Typeahead via CollectionState | **Added** |
| `filter_tree_with_ancestors` | **Added** |
| Virtual window + Virtualizer anchors | **Added** |
| Filter `/` chrome | **Added** |
| Right on expanded → first child | **Added** (was ignored) |

`TreeNode` gained `actions` and `parent` fields — prefer builders over struct
literals.

## Consumer edits

```diff
  use termrock::widgets::{Tree, TreeNode, TreeState, TreeOutcome};
+ use termrock::widgets::filter_tree_with_ancestors;

  let nodes = [
      TreeNode::new("root", Line::from("src"), 0).branch().expanded(),
+     TreeNode::new("lazy", Line::from("vendor"), 1)
+         .lazy_branch()
+         .parent("root"),
+     TreeNode::new("f", Line::from("lib.rs"), 1)
+         .parent("root")
+         .actions(Line::from("open")),
  ];
  let mut state = TreeState::new(Some("root"));
  // Right: expand lazy/collapsed OR enter first child when expanded
  // Left: collapse expanded OR select parent
  // Typeahead: printable chars
  // Filter:
+ state.set_filter_query(Some("lib".into()));
+ let view: Vec<_> = filter_tree_with_ancestors(&nodes, "lib")
+     .into_iter().cloned().collect();
  // Virtual large flat projection:
+ state.set_virtual_window(window_start, total);
+ state.capture_scroll_anchor(); // before rebuild
```
