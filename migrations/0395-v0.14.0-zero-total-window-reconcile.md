# 0395: Zero-total window reconciliation clears virtual mode

## Boundary

A virtual host can reconcile an empty universe before the next input event.

## Change

`CollectionState::reconcile_window` now clears virtual-window metadata and
resets the offset when `total_len == 0`. Empty reconciliation cannot leave a
`window_start` marker that makes later full-projection movement preserve a
stale off-window active ID. The zero-total contract is authoritative even if a
caller supplies an inconsistent nonempty window; that projection is ignored.

## Consumer impact

No consumer change is required. Zero-total virtual reconciliation is now
consistent with `set_virtual_window(..., 0)`.
