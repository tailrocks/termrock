# 0074 — CommandPalette / Picker premium redesign

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `PickerOutcome::SelectionChanged` | `PickerOutcome::CursorMoved` |
| `CommandPaletteOutcome::SelectionChanged` | `CommandPaletteOutcome::CursorMoved` |
| Always-focused palette panel | `CommandPalette::focused` + `PickerState::set_accepts_input` |
| Ungated keys | `accepts_input` |

## Added

| API | Role |
|-----|------|
| `PickerState::set_accepts_input` | Host/overlay gate |
| `Picker::{focused, ascii, colorless}` | Surface + a11y paint |
| `CommandPalette::{focused, ascii, colorless, footer_hint, empty_message}` | Premium chrome |
| `CommandPalette::handle_intent` | Intent-first results nav |
| Empty `∅` / `[ ]` cue | Accessibility |
| Footer hint row | Keyboard discoverability |

## Consumer edits

```rust
// Before
PickerOutcome::SelectionChanged => redraw(),
CommandPalette::new(title, &rows, &tokens)

// After
PickerOutcome::CursorMoved => redraw(),
CommandPaletteOutcome::CursorMoved => redraw(),
state.set_accepts_input(stack.is_top(COMMAND_PALETTE_OVERLAY_ID));
CommandPalette::new(title, &rows, &system)
    .focused(true)
    .ascii(false)
```
