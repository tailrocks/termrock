# 0134 — Switch

## Mission

Immediate on/off settings control distinct from Checkbox: explicit On/Off text,
settings-row and compact recipes, disabled / read-only / loading / error,
scroll-safe pointer (Down arm / Up-in-region), and documented appropriate use.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Switch::new(id, label, system)` | **Preserved** shape |
| `SwitchState::new` / `is_on` / `set_on` / `set_focused` / `set_enabled` | **Preserved** |
| `SwitchOutcome::ValueChanged { id, on }` | **Preserved** |
| `render` / StatefulWidget | **Preserved** (calls `paint`) |
| Mouse **Down** toggle | **Migrated** → Down arms, **Up-in-region** toggles |
| `SwitchParts`, recipe, description, loading, read-only, invalid | **Added** |
| `Checkbox` / `Toggle` | **Preserved** (distinct roles) |

## Consumer edits

```rust
let mut state = SwitchState::new(false);
state.set_focused(true);
Switch::new("dark", "Dark mode", &system)
    .description("Follow system appearance")
    .paint(area, buf, &mut state);

// Scrollable settings lists: handle Down + Up (not Down alone)
match sw.handle_mouse(&mut state, event) {
    SwitchOutcome::ValueChanged { on, .. } => model.set_dark(on),
    _ => {}
}
```

```diff
- // Old: Left Down toggled immediately
+ // New: Left Down arms; Left Up inside hit toggles
+ // Drag-out or wheel cancels — no accidental toggle while scrolling
```

## Appropriate vs inappropriate use

| Need | Use |
|------|-----|
| Settings preference (immediate on/off) | **Switch** |
| Form agreement / multi-select item | Checkbox |
| Toolbar sticky tool | Toggle |
| Exclusive multi-option | RadioGroup |
| Momentary command | Button |

## Behavior

| Concern | Rule |
|---------|------|
| Track text | Default `[ON ]` / `[OFF]` (never color-only) |
| Settings row | Label leading, track trailing |
| Compact | Track leading + label |
| Space / Enter | Toggle when focused + activatable |
| Pointer | Down arm · Up-in-region toggle |
| Loading / RO / disabled | No activate |
| Invalid | Danger chrome |
