# 0251 — AppDashboard (shadcn dashboard-01 / all-blocks index)

## Mission

Consolidate first-party ui.shadcn.com/blocks coverage and ship a keyboard-first
**AppDashboard** composition for `dashboard-01`: sidebar nav + main (+ metrics /
footer) without dual paint of charts/tables. Host owns data panes.

Matrix SoT: `docs/design/shadcn-blocks-coverage.md` (25 first-party ids).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `layout_ops_dashboard` / `layout_app_shell` | **Preserved** — AppDashboard composes |
| `Sidebar` / charts / DataTable | **Preserved** — host paints into main |
| Dual full dashboard widget with chart paint | **Forbidden** |
| `AppDashboardState` · `layout_app_dashboard` · `render_app_dashboard` | **Added** |

## Consumer API

```rust
use termrock::patterns::{
    AppDashboardState, AppDashboardSurfaces, AppDashboardOutcome, AppDashboardPane,
    example_dashboard_nav, layout_app_dashboard, render_app_dashboard,
};

let mut state = AppDashboardState::new(Some("home"));
let nav = example_dashboard_nav(); // or host NavItem tree

match state.handle_key(key, &nav) {
    AppDashboardOutcome::RouteSelected { id } => { /* host navigate */ }
    AppDashboardOutcome::MainKey { key } => { /* host table/charts keys */ }
    AppDashboardOutcome::PaneFocused { pane } => { /* chrome */ }
    AppDashboardOutcome::Cancelled => { /* leave */ }
    _ => {}
}

let slots = layout_app_dashboard(area, Default::default());
// host: paint DataTable into slots.main, charts into slots.metrics
render_app_dashboard(buf, area, AppDashboardSurfaces {
    system: &system,
    state: &mut state,
    nav: &nav,
    title: "Overview",
    main_placeholder: "",
});
```
