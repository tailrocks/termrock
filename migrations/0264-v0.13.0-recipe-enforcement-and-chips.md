# 0264 — Recipe-enforced controls, chips, tints, and meters

TermRock now paints control visuals through the design-system recipes. Primary
and destructive buttons are filled chips, badges default to a soft surface,
the phosphor selection default is a gutter plus quiet tint, progress bars use
fractional block cells over a sunken track, and full EmptyState layouts use a
framed inset surface.

## Consumer migration

No interaction APIs changed. Consumers that intentionally pinned the previous
flat visuals can opt out explicitly:

```rust
let badge = Badge::new("new", &system).fill(BadgeFill::None);
let system = DesignSystem::phosphor().selection(SelectionChrome::Gutter);
```

Before, application themes could accidentally make primary button labels dark
on a transparent terminal background. Button fills and labels now come from
`DesignSystem::button_recipe`; customize the semantic roles or recipe inputs,
not widget-local background stripping.

`Surface::bordered(true)` now fulfills its documented force-border contract
for recipes such as `Inset`, using `Role::Border`. Border geometry remains the
system's single-line square default and focus changes color, never weight.

Validate pinned consumers with:

```text
mise run check
mise run gate
```
