# 0239 — ConnectionManager block (inventory, secrets, dual views)

## Mission

Reusable management for database, SSH, API, and service connections: list with
per-row status, search, groups, recent, favorites, clear **target + environment**
identity, add/edit/test, credentials with safe secret entry/redaction,
reconnect, and gated delete. Compact **launcher** and **full** management
presentations share one state/outcome model. Offline connectivity projects into
`ReconnectingState` / Offline* surfaces; connection errors project into
diagnostic summaries. **Protocol clients, sockets, credential vaults, and
persistence stay application-provided** (outcomes/requests only).

Research: TablePlus, SSH managers, cloud CLIs, service dashboards.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `IntegrationStatus` (MCP/plugins) | **Preserved** — different inventory domain |
| `SessionPicker` (agent sessions) | **Preserved** — not service connections |
| `SchemaBrowser` connection tree nodes | **Preserved** — schema, not catalog manager |
| `ReconnectingState` / `OfflineBanner` / `OfflineSurface` | **Preserved** — composed via projection helpers |
| `PasswordInput` / secret policies | **Preserved** — form secret field |
| `Diagnostic` / `DiagnosticView` | **Preserved** — host may embed; we project summary only |
| `SetupWizard` connection step fields | **Preserved** — onboarding forms; optional host compose later |
| `ConnectionEntry` · `ConnectionManager*` | **Added** (`widgets/connection_manager`) |
| Prior dedicated ConnectionManager | **None** (greenfield) |

## Consumer API

```rust
use termrock::widgets::{
    example_connections, ConnectionManager, ConnectionManagerState,
    ConnectionManagerOutcome, ConnectionManagerPresentation, ConnectionListView,
    connection_to_reconnecting_state, connection_error_diagnostic,
};

let mut state = ConnectionManagerState::new();
state.set_connections(example_connections());
state.set_presentation(ConnectionManagerPresentation::Full);
// or Launcher for compact chrome

ConnectionManager::new(&system)
    .ascii(false)
    .paint(area, buf, &mut state);

match state.handle_key(key) {
    ConnectionManagerOutcome::ConnectRequested { id } => { /* host open */ }
    ConnectionManagerOutcome::TestRequested { id } => { /* host probe */ }
    ConnectionManagerOutcome::ReconnectRequested { id } => { /* host retry */ }
    ConnectionManagerOutcome::SaveRequested {
        id,
        draft,
        has_secret_draft,
    } => {
        let secret = if has_secret_draft {
            Some(state.take_form_secret())
        } else {
            None
        };
        // host persists entry + vault; never log secret
        let _ = (id, draft, secret);
    }
    ConnectionManagerOutcome::DeleteRequested { id } => { /* after confirm */ }
    ConnectionManagerOutcome::FavoriteToggled { id, favorite } => { /* persist */ }
    ConnectionManagerOutcome::QueryChanged { query } => { /* local filter already applied */ }
    ConnectionManagerOutcome::ViewChanged(view) => { /* All/Favorites/Recent/Group */ }
    ConnectionManagerOutcome::Cancelled => { /* dismiss */ }
    _ => {}
}

// Offline / diagnostics (no fork of those modules)
if let Some(rs) = state.reconnecting_state_for(None) {
    // paint OfflineBanner / OfflineSurface with rs
}
if let Some(diag) = state.diagnostic_for_current() {
    // map into Diagnostic / DiagnosticView region
}
```

### Safety

| Rule | Detail |
|------|--------|
| Esc (browse) | `Cancelled` |
| Delete | Confirm phase; **Cancel** default focus; `y` unbound |
| Secrets | Never in paint when masked, `Debug`, semantic/scene credential labels, or ordinary outcomes; host `take_form_secret` after Save |
| Protocol / vault / network | Host only |

### Presentation

- `ConnectionManagerPresentation::Launcher` — compact list, quick connect
- `ConnectionManagerPresentation::Full` — list + detail + form phases

### Stories

- `connection-manager/{full,launcher,empty,error,secret,confirm,narrow,unicode}`

## Second-pass design review

**Decisions**

1. **Widget module, Block registry kind** — peers like SessionPicker/IntegrationStatus live under `widgets/`; elevated inventory with dual presentation is a Block in the contract catalog.
2. **Outcomes-only I/O** — connect/test/reconnect/save/delete are requests; component never opens sockets or stores secrets.
3. **PasswordInput for form secrets** — reuses reveal/Debug redaction; list rows only show `ConnectionCredentialMeta` markers.
4. **Project into existing Offline/Diagnostic** — `connection_to_reconnecting_state` + `ConnectionDiagnosticSummary` avoid forking Offline* or DiagnosticView.

**Rejected alternatives**

- Embedding Tcp/SSH clients or keyring — violates host boundary and product neutrality.
- Storing raw secrets on `ConnectionEntry` with paint-only mask — leaks via Debug/scene.
- Forking a second OfflineState machine inside the manager — duplicates connectivity.
- Auto-delete on `d` / `y` without confirm — unsafe vs SessionPicker laws.

**Residual limits**

- Form is single-line field chrome (not full Form/Fieldset); enough for connection identity + secret; hosts may overlay richer forms.
- Clone of state drops secret draft (safe); hosts should take secret on Save immediately.
- PTY harness not required for this inventory peer; unit + structural gates cover redaction/interaction.
- Virtualization is windowed list only (64); host pages large remote catalogs.
