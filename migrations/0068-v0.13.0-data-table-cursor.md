# 0068 — DataTable cursor vs scene focus

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `DataTableOutcome::FocusChanged` | `DataTableOutcome::CursorMoved` |
| `DataTableState::focus_row` / `focus_col` | `cursor_row` / `cursor_col` |
| `DataTable::new(tokens, …)` param name | `system` (sole DesignSystem paint) |

## Added

| API | Role |
|-----|------|
| `DataTable::focused(bool)` | Scene ownership chrome |
| `accepts_input` / `set_accepts_input` | Host input gate |
| `colorless` | Reduced-color paint |
| `handle_intent` / `default_data_table_intent` | Intent-first nav |
| `handle_mouse` | Wheel + click-to-cursor |

## Consumer edits

```rust
// Before
match state.handle_key(key, rows, cols) {
    DataTableOutcome::FocusChanged => { … }
    …
}
let r = state.focus_row;

// After
match state.handle_key(key, rows, cols) {
    DataTableOutcome::CursorMoved => { /* table-internal cursor */ }
    …
}
let r = state.cursor_row;
DataTable::new(&system, &cols, &rows).focused(scene_owns_table);
```

## Law

- **Scene focus** = which surface owns keys (host).
- **Cursor** = which projected row/col is active inside the table.
- Never invent unloaded rows for select-all.
