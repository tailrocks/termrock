# Plan review golden composition chrome

`patterns::PlanReview` now identifies plans with a semantic `ActorPlan` rail
and title accent. Task panes use shared `FieldRow` composition, and approval
choices use shared `ActionBar` chips while retaining safe, non-granting initial
focus.

Remove consumer-owned plan borders, task-row formatting, and approval strips
around this pattern. Continue projecting plan domain state into `PlanDocument`;
interaction outcomes and host-owned execution policy are unchanged.

Validate with `cargo test -p termrock plan_review` and `mise run gate`.
