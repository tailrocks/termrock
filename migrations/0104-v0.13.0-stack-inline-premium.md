# 0104 — Stack / Inline premium layout

## Mission

Ergonomic vertical and horizontal packing with terminal-cell spacing tokens:
alignment, distribution, wrap, fill, min/max preferred, responsive direction,
explicit overflow policy, semantic grouping, and hit geometry — without
retained layout state.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Stack`, `Inline`, `FlexSize`, `Align`, `Justify`, `StackSpec`, `StackLayout` | **Preserve** (expanded) |
| `layout_stack`, `layout_stack_into`, `direction_for_width` | **Preserve** |
| `WorkSurface` / `Workspace` | **Preserve** — named multi-pane shells |
| `bottom_rows`, `Slots`, `centered_rect` | **Preserve** |
| `OverflowPolicy` | **Added** (`ShrinkFromEnd` default, `ClipTail`, `EqualShare`) |
| `Justify::SpaceAround` | **Added** |
| `FlexSize::fill()`, `ideal_main`, `max_main` | **Added** |
| `Stack`/`Inline` `.direction` / `.responsive` / `.overflow` / `.layout_with_cross` | **Added** |
| `layout_stack_with_cross`, `layout_stack_into_cross` | **Added** |
| `StackLayout::{hit_regions, register_semantic_group, len, iter}` | **Added** |
| Internal main-size scratch | **≤64 stack buffer** (heap only when more children) |
| Ad hoc `y += 1` packing in ThinkingBlock / QuestionFlow / ModeRibbon | **Migrated** to Stack/Inline |

## API sketch

```rust
use termrock::layout::{
    Stack, Inline, FlexSize, Align, Justify, OverflowPolicy, direction_for_width,
};

// Vertical anatomy
let layout = Stack::new().gap(1).layout(area, &[
    FlexSize::Fixed(2),
    FlexSize::fill(),
    FlexSize::Fixed(1),
]);

// Horizontal + wrap
let chips = Inline::new().wrap(true).gap(1).layout(area, &[
    FlexSize::Fixed(6),
    FlexSize::Fixed(6),
    FlexSize::Fixed(6),
]);

// Responsive direction (narrow → vertical, wide → horizontal)
let layout = Stack::new()
    .responsive(area.width, 60)
    .gap(1)
    .layout(area, &[FlexSize::fill(), FlexSize::fill()]);

// Overflow: keep head, clip tail
let tight = Stack::new()
    .overflow(OverflowPolicy::ClipTail)
    .layout(area, &[FlexSize::Fixed(3), FlexSize::Fixed(3), FlexSize::Fixed(3)]);

// Cross-axis center (non-stretch) with intrinsic heights
let row = Inline::new()
    .align(Align::Center)
    .layout_with_cross(area, &[FlexSize::Fixed(8)], &[1]);

// Hits + semantics
let hits = layout.hit_regions(); // HitRegion<usize>
layout.register_semantic_group(&mut scene, "g", "stack", |i| format!("c{i}"));
```

## Overflow rules

| Policy | Behavior when fixed/preferred sum > main axis |
|--------|-----------------------------------------------|
| `ShrinkFromEnd` (default) | From the end: assign `min(claim, remaining)` |
| `ClipTail` | From the start: keep head; tail → 0 |
| `EqualShare` | Peel cells from the end until sum ≤ available |

Weight children receive residual after fixed/preferred. Preferred may **grow**
toward `max` when residual remains after weights. `StackLayout::overflowed` is
set when any fixed/preferred child is below `min_main`.
