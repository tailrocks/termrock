# 0345: DataTable pointer input follows painted body geometry

## Boundary

DataTable pointer actions are authorized by geometry produced by the latest
render. Empty, loading, and error states paint no body rows and must not leave
stale body hit regions active.

## Change

Body hit testing now uses the exact painted body width and height. Zero-sized
renders clear the stored body geometry, and status rows remain non-clickable.
Header interactions and host input gating are unchanged.

## Consumer impact

No consumer edit is required. Pointer events outside currently painted body
rows now return `DataTableOutcome::Ignored`.
