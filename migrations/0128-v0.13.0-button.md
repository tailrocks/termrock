# 0128 — Button anatomy refresh

## Mission

Canonical primary action control: full variant set, sizes, glyphs, loading /
disabled / pending confirmation, full-width, activation law (press/release /
repeat / double-trigger prevention), and affordance that does **not** rely on
brackets alone.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Button`, `ButtonState`, `ButtonVariant`, `ButtonSize` | **Preserved** + enhanced |
| `ActivationState` / `ActivationOutcome` | **Preserved** (shared law) |
| `IconButton` | **Preserved** |
| `Button::primary(bool)` | **Preserved** (compat) |
| `Button::{as_primary, as_link, …}`, `paint`, `ButtonParts`, hover | **Added** |
| Bracket-only outline identity | **Migrated** — role + BOLD/UNDERLINE primary; brackets ASCII secondary |

## Activation law

| Gesture | Behavior |
|---------|----------|
| Enter / Submit / Toggle | Activate on **Press**; **Repeat ignored** |
| Space | Arm on Press; activate on **Release** |
| Pointer Left | Arm on Down; activate on **Up inside** region |
| Up outside / leave | Disarm; no activate |
| Disabled / loading / `accepts_input=false` | Never activate |
| Pending confirmation | First Activate → `ConfirmRequired`; second → `Activated` |

## Affordance

| Variant | Primary cues |
|---------|----------------|
| Primary / Success / Command | Accent/Success role + **BOLD** |
| Link | **UNDERLINED** (never brackets) |
| Outline | UNDERLINE when focused; `[label]` only when mono/ASCII |
| Destructive | Danger + BOLD; `!` prefix when mono; never default focus |
| Quiet / Secondary | Pad + UNDERLINE when surface-focused |
