# 0493: Synchronize removed ButtonGroup protocol method

## Boundary

The dead-protocol sweep removed the unused `EventResult` wrapper from
`ButtonGroup`. The generated public API snapshot retained its signature even
though the method is no longer available.

## Change

Removed the one stale snapshot entry for
`ButtonGroup::handle_key_result` deleted by `6faa9fb0`.

## Host migration

Handle button-group keyboard outcomes through `ButtonGroup::handle_key`.
`ButtonGroup::register_semantic` and direct mouse handling remain available.
No compatibility alias or deprecation period is provided.
