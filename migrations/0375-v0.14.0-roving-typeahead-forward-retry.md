# 0375: Roving typeahead retries after the active row

## Boundary

Repeated typeahead must cycle matching rows in forward projection order, even
when the accumulated prefix misses and the latest character is retried alone.

## Change

Single-character fallback now uses the same next-after-active starting point as
the accumulated-prefix search.

## Consumer impact

No consumer edit is required. Repeated character input continues forward from
the current active row instead of jumping to the first match.
