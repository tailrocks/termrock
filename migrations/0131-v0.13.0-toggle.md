# 0131 — Toggle and ToggleGroup

## Mission

Single and grouped pressable sticky-state controls distinct from checkboxes,
switches, and tabs: pressed/unpressed/indeterminate, icon-only with a11y,
single- and multi-select groups, roving focus, non-color pressed marks, and
priority overflow for compact toolbars.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Checkbox` / `CheckboxState` | **Preserved** — form field checked semantics |
| `Switch` / `SwitchState` | **Preserved** — settings On/Off |
| `RadioGroup` | **Preserved** — exclusive form options with descriptions |
| `Tabs` / `ModeRibbon` | **Preserved** — content/mode navigation |
| `ToolbarItemKind::Toggle` | **Preserved** — light toolbar embed |
| `IconButton::toggle` | **Preserved** — glyph pressed chrome |
| `Button` / `ButtonGroup` | **Preserved** — momentary actions |
| `Toggle`, `ToggleGroup`, values, outcomes | **Added** |

No forced call-site migrate. Prefer Toggle/ToggleGroup when sticky tool state,
group policy, indeterminate, or overflow matter.

## When not to use ToggleGroup

| Need | Use instead |
|------|-------------|
| Form boolean | Checkbox |
| Settings preference | Switch |
| Content/view panels | Tabs / SegmentedControl / ModeRibbon |
| One-shot command | Button / ButtonGroup |
| Exclusive options with long help | RadioGroup |

## API sketch

```rust
use termrock::widgets::{
    Toggle, ToggleState, ToggleValue, ToggleOutcome,
    ToggleGroup, ToggleGroupItem, ToggleGroupState, ToggleGroupOutcome,
};

// Single
let mut state = ToggleState::with_value(ToggleValue::Unpressed);
state.set_focused(true);
Toggle::new("Bold", &system).paint(area, buf, &mut state);
// Space/Enter → ToggleOutcome::ValueChanged { value }

// Multi format toolbar
let items = [
    ToggleGroupItem::new("b", "B").pressed(true),
    ToggleGroupItem::new("i", "I"),
    ToggleGroupItem::new("u", "U"),
];
let mut gstate = ToggleGroupState::new();
gstate.set_surface_focused(true);
ToggleGroup::new(&items, &system)
    .multiple()
    .compact()
    .paint(area, buf, &mut gstate);

// Single align (connected)
ToggleGroup::new(&align_items, &system)
    .single()
    .connected()
    .paint(area, buf, &mut gstate);
// Space → SelectionChanged { id: Some(..) } (host clears other pressed flags)
```

## Behavior

| Concern | Rule |
|---------|------|
| Pressed (no color) | Brackets `[B]` + bold/reverse |
| Unpressed | Spaced face ` B ` (or compact) |
| Indeterminate | `[~B]`; activate → Pressed |
| Icon-only | Mandatory `accessible_label` |
| Group single | One pressed; re-press ignored unless `allow_empty` |
| Group multi | Independent `ItemChanged` |
| Overflow | Low priority → `…`; pressed high priority kept |
| Roving | Arrows move cursor; Space activates cursor |
