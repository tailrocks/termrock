# 0386 — v0.14.0 TreeTable empty projection movement

## Boundary

When a virtual projection contains no selectable rows, directional movement
scrolls the logical window when possible and stays inert at its boundary.
Selection and cursor identity remain unchanged while the host supplies another
slice.

## Consumer impact

No host API changes. Empty or group-only slices remain navigable through the
virtual collection instead of becoming a dead end.
