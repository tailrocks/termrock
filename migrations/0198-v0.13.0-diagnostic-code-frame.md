# 0198 — Diagnostic and CodeFrame

## Mission

Structured diagnostics with source context and actionable fixes: severity,
code, message, source, range, related locations, notes, help, documentation
link, suggested fixes, and copyable details. Single- and multi-line spans,
tabs, Unicode, overlapping diagnostics, truncated files. Recipes: list,
inline, full code-frame. Severity never color-alone. Integrate with build
output, editors, forms, CodeBlock, and ErrorState.

Research: rustc, miette, Rich tracebacks, IDE problems panels, code frames.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `CodeBlock` / `CodeHighlightKind::Diagnostic` / `CodeGutterMark` | **Preserved** — editor body; bridges via `diagnostics_to_highlights` / `_gutter_marks` |
| `ErrorState` copy-diagnostics | **Preserved** — feed `format_diagnostics_plain` |
| `Severity` (toast) | **Preserved** — map with `DiagnosticSeverity::from_toast` |
| `UiDiagnostics` (host frame notes) | **Preserved** — unrelated studio/semantic notes |
| `Diagnostic` / `DiagnosticView` / `DiagnosticState` | **Added** |
| `CodeFrame` / `CodeFrameLine` | **Added** |
| `SourceRange` / `SourceLabel` / notes / fixes | **Added** |
| `diagnostic_bench` | **Added** |
| Nothing deleted | Compose, do not replace CodeBlock |

## Consumer API sketch

```rust
use termrock::widgets::{
    Diagnostic, DiagnosticSeverity, DiagnosticView, DiagnosticState, DiagnosticRecipe,
    SourceLabel, SourceRange, SuggestedFix, CodeFrame, CodeFrameLine,
    diagnostics_to_highlights, format_diagnostics_plain,
};

let labels = [
    SourceLabel::primary(SourceRange::line_span(2, 5, 12)).label("expected i32"),
];
let items = [
    Diagnostic::new("d1", DiagnosticSeverity::Error, "mismatched types")
        .code("E0308")
        .file("src/main.rs")
        .labels(&labels)
        .help("add a type ascription")
        .fixes(&[SuggestedFix::new("f1", "annotate").replacement("let x: i32 = …")]),
];
let lines = [
    CodeFrameLine::new(1, "fn main() {"),
    CodeFrameLine::new(2, "    let x = foo();"),
];
let mut state = DiagnosticState::new();
// Space expand · c copy · a apply fix · d docs · Enter activate
DiagnosticView::new(&items, &system)
    .recipe(DiagnosticRecipe::Full)
    .source_lines(&lines)
    .render(area, buf, &mut state);

// CodeBlock bridge:
// CodeBlock::… .highlights(&diagnostics_to_highlights(&items))

// ErrorState copy:
// recovery.with_copy_diagnostics(true); host puts format_diagnostics_plain(&items) on clipboard
```
