# 0457: DetailTable physical one-shot activation

## Boundary

`DetailTableState::handle_key` is the raw keyboard adapter for row navigation
and capability activation. Held Enter must not repeatedly request copy or link
activation from the selected row.

## Change

- Repeat and release Enter events are ignored.
- Press Enter still activates the selected row's copy or link capability (or
  reports selection when the row has no capability).
- Up/Down and j/k navigation remain repeatable.
- Mouse and direct semantic methods are unchanged.

## Host migration

Hosts routing raw DetailTable events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize copy or link activation from
`Repeat` or `Release` events.
