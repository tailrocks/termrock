# 0086 — Virtualizer (1D / 2D large collections)

## Mission

Reusable virtualizer for fixed/variable extents, overscan, sticky regions,
stable anchors, visible-range queries, and O(viewport) paint/semantics over
million-row logical datasets.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `data_view::VirtualWindow` | **Preserve** fixed-slot facade; `to_virtualizer` / `from_virtualizer` |
| `VirtualGridState` first_row/first_col fields | **Migrate** into `Virtualizer2D` |
| `DataTableState::{window,col_window}` | **Preserve** `VirtualWindow` public fields |
| Dense `Vec` of 1M extents | **Forbidden** |
| Semantic nodes for every logical row | **Forbidden** — sticky + visible only |

## Added

| API | Module | Role |
|-----|--------|------|
| `ExtentPolicy` | `widgets` | Fixed / Variable estimated |
| `StickyRegion` | `widgets` | Leading/trailing always-in-set counts |
| `VirtSlice` / `VirtRange` | `widgets` | Visible + measure half-open windows |
| `Virtualizer` | `widgets` | 1D engine |
| `Virtualizer2D` | `widgets` | Independent row/col engines |
| `fixed_visible_range` | `widgets` | Shared fixed-slot math |
| `VirtualWindow::to_virtualizer` | `widgets` | Lift facade |
| `VirtualGridState::virtualizer` | `widgets` | Access embedded 2D engine |

## Consumer edits

```rust
use termrock::widgets::{Virtualizer, Virtualizer2D, StickyRegion, ExtentPolicy};
use termrock::widgets::data_view_bench;

// 1D fixed — 1M rows, no allocation
let mut v = Virtualizer::fixed(1)
    .with_len(data_view_bench::ROWS_1M)
    .with_viewport(40)
    .with_overscan(5)
    .with_sticky(StickyRegion { leading: 1, trailing: 0 });
v.set_offset(100_000);
let slice = v.visible_slice(); // body only
// Host projects slice.measure_start..measure_end for prefetch
// SemanticScene: register v.semantic_count() nodes, not logical_len
let mut idx = Vec::new();
v.semantic_indices(&mut idx);

// Variable height: measure only the prefetch window
let mut tall = Virtualizer::variable(2).with_len(10_000).with_viewport(30);
for i in tall.measure_slice().measure_start..tall.measure_slice().measure_end {
    tall.note_measured(i, host_measure(i));
}
tall.forget_measured_outside(8);

// Grid
let mut g = Virtualizer2D::fixed_cells();
g.set_shape(1_000_000, 64);
g.set_viewport(40, 16);
assert!(g.visible_cells_budget() <= 40 * 16);

// VirtualGrid: window via virtualizer
let first = state.first_row(); // unchanged API
state.virtualizer_mut().rows.set_overscan(4);

// VirtualWindow still works for DataTable
state.window = VirtualWindow::new(1_000_000, 40);
let v = state.window.to_virtualizer();
```

## Laws

1. Paint / measure / semantic registration stay O(visible + sticky + overscan).
2. Variable extents use sparse `note_measured` only; never dense length arrays.
3. Sticky leading/trailing always in the semantic set; body virtualizes the middle.
4. `on_items_changed` + anchors handle insert/delete/filter without full remeasure.
