# 0371: Roving movement repairs disabled active IDs once

## Boundary

Roving and Collection movement must not skip the nearest enabled item when a
host-provided active ID is disabled before reconciliation.

## Change

Directional movement now computes from the disabled entry's physical insertion
point and performs the requested steps once, including wrap behavior.

## Consumer impact

No consumer edit is required. Existing active IDs and projections continue to
be accepted; movement no longer advances twice after repairing a disabled ID.
