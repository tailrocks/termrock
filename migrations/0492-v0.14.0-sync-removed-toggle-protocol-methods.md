# 0492: Synchronize removed toggle protocol methods

## Boundary

The dead-protocol sweep removed three unused `EventResult` and semantic
registration wrappers from toggle controls. The generated public API snapshot
retained their signatures even though the methods are no longer available.

## Change

Removed the three stale snapshot entries for `Toggle::handle_key_result`,
`ToggleGroup::handle_key_result`, and `ToggleGroup::register_semantic`
deleted by `6faa9fb0`.

## Host migration

Handle direct `Toggle` and `ToggleGroup` outcomes through their remaining
`handle_key`/`handle_mouse` methods. Register individual toggles through the
remaining `Toggle::register_semantic` method where needed. No compatibility
aliases or deprecation period is provided.
