# 0186 — VirtualList

## Mission

High-performance list for extremely large or streaming collections. Uses the
shared [`Virtualizer`] with stable logical indices, overscan, variable extents,
sticky headers, and anchor preservation. Host projects only the measure window.
Async page loading, placeholders, follow-tail, filtering chrome, live updates.
Semantic registration limited to visible/near-visible items. Diagnostics expose
visible ranges and measurement counts. Million-row logical benchmarks stay
O(viewport).

Research: Textual virtual lists, VisiData, log tails, TermRock Virtualizer.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Virtualizer` / `VirtSlice` / `StickyRegion` / `ExtentPolicy` | **Preserved** — window math authority |
| `List` / `ListRow` / `ListState` | **Preserved** — body paint + selection on **projected** window |
| `ListState::set_virtual_window` | **Preserved** — light facade; prefer VirtualList for large N |
| `VirtualWindow` (data_view) | **Preserved** — fixed-slot DataTable facade |
| `VirtualGrid` | **Preserved** — 2D grids |
| `virtualizer/million-fixed` story | **Preserved** |
| `VirtualList` + `VirtualListState` | **Added** |
| `VirtualListItem` projection | **Added** |
| Follow-tail / page status / filter chrome | **Added** |
| `VirtualListDiagnostics` | **Added** |
| O(logical_len) paint/semantics | **Rejected** by design |

Nothing deleted. Hosts with million-row `List` + manual window should migrate to
VirtualList.

## Consumer edits

```diff
+ use termrock::widgets::{
+     VirtualList, VirtualListState, VirtualListItem, VirtualListFollow,
+     VirtualPageStatus, StickyRegion, ListRow,
+ };

+ let mut state = VirtualListState::new();
+ state.set_logical_len(1_000_000);
+ state.set_viewport_extent(h);
+ state.set_overscan(4);
+ state.set_sticky(StickyRegion { leading: 1, trailing: 0 });
+ state.set_follow(VirtualListFollow::Tail); // logs
+ // async:
+ state.set_page_status(VirtualPageStatus::Loading);

+ let mut indices = Vec::new();
+ state.projection_indices(&mut indices); // sticky + measure window only
+ let projected: Vec<_> = indices.iter().map(|&i| {
+     VirtualListItem::new(i, ListRow::item(i, Line::from(format!("row {i}"))))
+     // or VirtualListItem::placeholder(i, id) while page loads
+ }).collect();

+ VirtualList::new(&projected, &system)
+     .show_diagnostics(true)
+     .paint(area, buf, &mut state);

+ // ranges / diagnostics
+ let vis = state.visible_range();
+ let d = state.diagnostics(); // semantic_count << logical_len
```
