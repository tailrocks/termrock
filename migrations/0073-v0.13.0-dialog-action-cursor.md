# 0073 — Dialog / ChoiceDialog action cursor vs scene focus

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `ChoiceDialogState.focused` | `cursor` (`focused()` deprecated) |
| `ActionBarState.focused` | `cursor` |
| Tab / BackTab in ChoiceDialog `handle_key` | Host `InteractionScene` when actions are focus targets; Left/Right for local cursor |
| Ungated keys when overlay not top | `accepts_input` / `set_accepts_input` |

## Added

| API | Role |
|-----|------|
| `default_choice_dialog_intent` | Left/Right, Enter, Esc; **no Tab** |
| `ChoiceDialog::ascii` / `colorless` | Action chrome |
| `ActionBar::ascii` / `colorless` / `vertical` | Shared bar recipes |
| Narrow ChoiceDialog stacks actions | Responsive |

## Consumer edits

```rust
// Before
let mut state = ChoiceDialogState::new(Some("ok"));
state.focused = scene.focused().cloned();
// Tab moved actions via handle_key

// After
let mut state = ChoiceDialogState::new(Some("ok"));
state.cursor = scene.focused().cloned(); // host projection
state.set_accepts_input(stack.is_top(DIALOG_ID));
// Tab: scene only
// Left/Right / Enter / Esc: default_choice_dialog_intent + handle_intent
```

```rust
// ActionBar
ActionBarState { cursor: Some(id), regions: vec![] }
```
