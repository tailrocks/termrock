# 0358: TreeTable cursor follows responsive paint projection

## Boundary

TreeTable cell navigation exposes a visible-column ordinal, while responsive
width resolution may omit low-priority columns from the painted projection.

## Change

After resolving widths, TreeTable reanchors a cursor whose source column was
dropped to the nearest retained visible column. Cell paint compares the cursor
against the retained source-column index, so keyboard state and painted focus
cannot diverge when earlier columns are omitted.

## Consumer impact

No consumer edit is required. `TreeTableState::cursor_col` remains a visible
column ordinal and now always identifies a column represented in the current
responsive paint geometry.
