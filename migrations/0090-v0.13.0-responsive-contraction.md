# 0090 — Responsive and contraction premium

## Mission

Named breakpoint recipes, height ladder, overflow actions, inspector snapshot,
and Table / Dialog / Tabs / Form migrations off magic width constants.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| Existing stage / anatomy / surface policy | **Preserve** |
| `WIDTH_LADDER` | **Preserve** + `HEIGHT_LADDER` |
| Table `width >= 10/14` chrome | **Migrate** → `table_row_shows_optional` |
| ChoiceDialog `width < 28` | **Migrate** → `dialog_stack_actions` |
| Tabs always show glyph | **Migrate** → hide only under extreme contraction |

## Added

| API | Role |
|-----|------|
| `HEIGHT_LADDER` | Height matrix samples |
| `Breakpoint` / `ResponsiveRecipe` | Named local breakpoint sets |
| `OverflowAction` | Drop / Truncate / OverflowMenu / Drawer / … |
| `ResponsiveSnapshot` | Studio / inspector lines |
| `table_row_shows_optional` | Table chrome |
| `dialog_stack_actions` | Dialog action layout |
| `tabs_show_status_glyphs` | Tab status chrome |

## Consumer edits

```rust
use termrock::layout::{
    ResponsiveSurface, ResponsiveRecipe, ResponsiveSnapshot, WIDTH_LADDER, HEIGHT_LADDER,
    table_row_shows_optional, dialog_stack_actions,
};

let class = ResponsiveSurface::Form.classify(term_w, term_h);
let cols = ResponsiveSurface::Form.form_columns(term_w);

// Named recipe (agent shell)
let agent = ResponsiveRecipe::AGENT_SHELL.classify(term_w, term_h);

// Inspector
let snap = ResponsiveSnapshot::for_surface(ResponsiveSurface::Table, term_w, term_h);
for line in snap.lines() { /* Studio panel */ }

// Table row chrome
let (show_leading, show_badge) = table_row_shows_optional(area.width);
```
