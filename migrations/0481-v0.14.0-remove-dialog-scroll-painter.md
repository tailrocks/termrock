# 0481: Remove the orphan DialogScroll painter

## Boundary

`DialogScroll::paint_scrollbars` had no caller in the repository and duplicated
the responsible widget/layout paint paths. The scroll state remains reusable;
scrollbar geometry and painting remain available through `ScrollArea::paint_bars`
and the shared scroll rendering functions.

## Change

- Remove `DialogScroll::paint_scrollbars` and its block-border-only helpers.
- Keep `DialogScroll` focused on scroll state, input, and bounds.

## Host migration

Hosts that need scrollbars must use the component or layout that owns the
viewport. For `ScrollArea`, call `ScrollArea::paint_bars`; for shared rendering,
use the existing `termrock::scroll::paint_scrollbar` primitives with explicit
geometry.

No compatibility alias or deprecation period is provided.
