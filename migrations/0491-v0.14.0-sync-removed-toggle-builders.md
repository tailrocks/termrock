# 0491: Synchronize removed toggle builders

## Boundary

The uniform widget cleanup removed nine zero-caller convenience builders from
the toggle primitives. The generated public API snapshot retained their
signatures even though the methods are no longer available.

## Change

Removed the nine stale snapshot entries for `Toggle::{compact, quiet,
colorless}`, `ToggleGroup::{orientation, overflow_label}`, and
`ToggleGroupItem::{value, icon, accessible_label, enabled}` deleted by
`ddde585f`.

## Host migration

Use the canonical `size`, `recipe`, and public item fields when constructing
toggle controls. Use `ToggleGroup::compact`, `connected`, `multiple`, or
`single` for the remaining group configuration. No compatibility aliases or
deprecation period is provided.
