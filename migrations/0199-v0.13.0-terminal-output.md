# 0199 — TerminalOutput safe command presentation

## Mission

Safe terminal command execution/output presentation: command, cwd, env
summary/redaction, stdout/stderr, live streaming, exit/signal/duration, cancel,
detach, retry, copy. Safe ANSI parse (AnsiText/AnsiLine); raw/plain modes.
Preserve scroll when reading while output continues. Recipes: compact card,
pane, fullscreen. **Never executes commands** — typed control requests only.

Research: Grok Build, Amp, OpenCode, terminal emulators, CI command logs.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `AnsiText` / `AnsiLine` / `AnsiStream` | **Preserved** — safe parse/paint substrate |
| `ToolCard` | **Preserved** — compact agent tool summary; compose with TerminalOutput for body |
| `LogStream` / `LogPane` | **Preserved** — multi-source logs / owned buffers |
| `TerminalOutput` / `TerminalLine` / `TerminalCommandMeta` | **Added** |
| `TerminalOutputState` / outcomes / recipes | **Added** |
| `terminal_output_bench` | **Added** |
| Process spawn/kill | **Never in TermRock** |

## Consumer API sketch

```rust
use termrock::widgets::{
    TerminalOutput, TerminalOutputState, TerminalCommandMeta, TerminalLine,
    TerminalRunStatus, TerminalEnvEntry, TerminalOutputRecipe,
};

let meta = TerminalCommandMeta::new("cargo test")
    .cwd("/proj")
    .env(&[TerminalEnvEntry::secret("TOKEN")])
    .status(TerminalRunStatus::Running)
    .duration_ms(1200)
    .pid(42);
let lines = [
    TerminalLine::stdout("1", "running 1 test"),
    TerminalLine::stderr("2", "warning: …"),
];
let mut state = TerminalOutputState::new(); // follow-tail
state.on_append(lines.len() as u16, viewport);
// User scrolls → Detach; f → Follow; c → CancelRequested (host kills)
// C-c / c (when done) → CopyOutput; r → RetryRequested; d → DetachProcessRequested

TerminalOutput::new(&meta, &lines, &system)
    .title("build")
    .render(area, buf, &mut state);
```

### Keys

| Key | Action |
|-----|--------|
| f | Toggle follow |
| c | Cancel (if running) else copy |
| C-c | Copy output |
| y | Copy command |
| r | Retry request |
| d | Detach process request |
| e | Toggle env |
| 1/2 | Hide stdout / stderr |
| m | Cycle paint mode |
| p | Cycle recipe |
| o | Open cwd request |
