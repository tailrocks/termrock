# 0135 — SegmentedControl

## Mission

Compact mutually exclusive view/mode selector: text/icons/badges, disabled
segments, priority overflow, responsive collapse into a Select-like trigger,
roving focus with FollowFocus selection, and active state without neon fill.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `SegmentedMeter` | **Preserved** — chart/share meter (unrelated) |
| `Tabs` | **Preserved** — multi-panel content navigation |
| `RadioGroup` | **Preserved** — form exclusive choice |
| `ToggleGroup` | **Preserved** — sticky multi/single tools |
| `ModeRibbon` | **Preserved** — agent workbench seed (may project later) |
| `SegmentedControl` + items/state/outcomes | **Added** |

No forced migrate. Prefer SegmentedControl for product-neutral view modes,
density, filters; keep ModeRibbon for agent-specific chrome until projected.

## API sketch

```rust
use termrock::widgets::{
    SegmentedControl, SegmentedControlState, SegmentedItem, SegmentedControlOutcome,
};

let items = [
    SegmentedItem::new("list", "List").priority(90),
    SegmentedItem::new("grid", "Grid").icon("#").priority(80),
    SegmentedItem::new("table", "Table").badge("12").priority(40),
];
let mut state = SegmentedControlState::new(Some("grid"));
state.set_surface_focused(true);

let parts = SegmentedControl::new(&items, &system)
    .collapse_below(18) // Select-like under 18 cols; 0 = never
    .paint(area, buf, &mut state);

match control.handle_key(&mut state, key) {
    SegmentedControlOutcome::Selected { id } => { /* apply mode */ }
    SegmentedControlOutcome::MenuOpened => {
        // Host menu from parts.overflow_ids (or all items when collapsed)
    }
    _ => {}
}
```

## Distinctions

| Control | Role |
|---------|------|
| **SegmentedControl** | Dense exclusive mode/view on one surface |
| **Tabs** | Content panel ownership / multi-page |
| **RadioGroup** | Form field + legend + descriptions |
| **ToggleGroup** | Sticky tools (often multi) |
| **SegmentedMeter** | Proportional share chart |

## Behavior

| Concern | Rule |
|---------|------|
| Selection | FollowFocus — arrows/typeahead commit |
| Active | `[Seg]` + bold/reverse (not neon fill only) |
| Overflow | Low priority → `…`; selected kept |
| Collapse | Width &lt; `collapse_below` → Select trigger |
| Disabled | Skipped by roving |
