# 0164 — Tooltip redesign

## Mission

Delayed contextual help for truncated labels, icon buttons, and statuses —
focus- and pointer-triggered, non-focus-stealing, with plain / shortcut / rich
variants and reduced-motion instant show. Essential information must also be
available without hover.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TOOLTIP_OVERLAY_ID`, `place_tooltip`, `open_tooltip_overlay` | **Preserved** |
| `OverlayKind::Tooltip` policy (no input ownership) | **Preserved** |
| `Presence::tooltip` delay engine | **Preserved** |
| `Tooltip::new(text, system)` | **Preserved** |
| `TooltipState::tick_hover` / `is_visible` / `next_deadline` | **Preserved** (outcomes added) |
| `TooltipState::advance(tick, hovering, motion)` | **Migrated** → `set_pointer_over` + `advance(tick, motion)` or `advance_with_triggers` |
| `TooltipContent`, variants, triggers, essential gate | **Added** |
| Implementation home | **Moved** `menu_nav` → `tooltip` module |

## Consumer edits

```diff
  let mut state = TooltipState::new();
- state.tick_hover(delta_ms, hovering);
+ let _ = state.tick_hover(delta_ms, hovering); // still works; returns TooltipOutcome

- state.advance(tick, hovering, motion);
+ state.set_pointer_over(hovering);
+ // optional: state.set_focus_within(anchor_focused);
+ let _ = state.advance(tick, motion);
+ // or: state.advance_with_triggers(tick, hovering, focused, motion);

  // Essential info must not be hover-only:
+ let content = TooltipContent::plain("…").essential_elsewhere(true);
+ Tooltip::content(content, &system).shortcut().paint(area, buf, &state);

  // Reduced motion: pass Motion::Reduced | Off → zero show delay
```

### Variants

| Variant | Content |
|---------|---------|
| Plain | body |
| Shortcut | body + right-aligned chord |
| Rich | title + body (+ optional shortcut) |

### Stories

- `tooltip/plain`, `shortcut`, `rich`, `ascii`
