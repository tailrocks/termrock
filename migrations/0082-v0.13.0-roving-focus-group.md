# 0082 — RovingFocusGroup (active descendant)

## Mission

Reusable roving / active-descendant behavior for menus, radios, toolbars, tabs,
and collections — separate from external `FocusGraph` ownership.

## Added

| API | Role |
|-----|------|
| `RovingFocusGroup<Id>` | Active child cursor |
| `RovingEntry` | id + enabled + typeahead label |
| `RovingOrientation` | Vertical / Horizontal / Both |
| `RovingOutcome` | ActiveChanged / Ignored |
| `roving_hint_keymap*` | Generated footer hints |
| `register_semantic` | SemanticScene projection |

## Migrated

| Widget | Change |
|--------|--------|
| `RadioState` | Uses `RovingFocusGroup`; `active()` replaces `focus_index` |
| `MenuState` | Index roving via `RovingFocusGroup<usize>`; no longer `Copy` |

## Laws

1. External focus = one roving surface on `FocusGraph`.
2. Active descendant = `RovingFocusGroup::active`.
3. Disabled skipped; `reconcile` after virtual window / mutation.
4. Activate remains host/widget outcome.

## Consumer edits

```rust
use termrock::interaction::{RovingEntry, RovingFocusGroup, RovingOrientation};

let mut roving = RovingFocusGroup::new().orientation(RovingOrientation::Vertical);
let entries = vec![
    RovingEntry::new("a", "Alpha"),
    RovingEntry::new("b", "Beta").enabled(false),
    RovingEntry::new("c", "Gamma"),
];
let _ = roving.reconcile(&entries);
let _ = roving.move_next(&entries);
assert_eq!(roving.active(), Some(&"c"));
```

### RadioState

```rust
// Before
state.focus_index

// After
state.active()
```

### MenuState

`MenuState` is no longer `Copy` (holds `RovingFocusGroup`). Use `.clone()` if needed.
