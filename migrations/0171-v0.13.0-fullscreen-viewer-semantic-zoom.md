# 0171 — FullscreenViewer and SemanticZoom

## Mission

Reusable promotion path from compact row → inline detail → fullscreen
inspection. Preserves selection, focus token, scroll anchor, and source
context across promote/demote without copying application document state.
Chrome: title, breadcrumbs, actions, search, help, close/restore. Body is a
host-owned slot for CodeBlock, DiffReview, logs, objects, tasks, or media.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `OverlaySpec::fullscreen`, `OverlayKind::Fullscreen` | **Preserved** (placement authority) |
| `OverlayStack::{open,dismiss,handle_escape,promote_top_fullscreen}` | **Preserved** |
| `UiIntent::Fullscreen` / Cancel / Help / Search | **Preserved** (viewer routes them) |
| HistoryPicker / CompletionMenu / Dialog / Drawer fullscreen presentation | **Unchanged** (own overlay ids; may promote *into* FullscreenViewer later) |
| Ad-hoc “fullscreen chrome” in consumers | **Migrate** → `FullscreenViewer` + `SemanticZoomState` |
| `FullscreenViewer`, `FullscreenViewerState`, slots, outcomes | **Added** |
| `SemanticZoomState`, `ZoomLevel`, `SourceContext`, `ScrollAnchor` | **Added** |
| `ViewerContentKind`, `ViewerChromeFocus`, `SemanticZoomBadge` | **Added** |
| `FULLSCREEN_VIEWER_OVERLAY_ID`, open/dismiss/nested helpers | **Added** |
| Prior `widgets/fullscreen_viewer` public surface | **None** (greenfield module) |

## Escape law (exact)

1. **Nested child** under viewer (`fullscreen_viewer_has_nested_top` / host hint)
   → `FullscreenViewerOutcome::NestedEscape` — host calls
   `OverlayStack::handle_escape` once (peel one layer). **Do not demote zoom.**
2. Else if **help** open → close help.
3. Else if **search** open → close search and clear query.
4. Else **demote** one zoom level:
   - Fullscreen → Detail (viewer `open=false`; host dismisses fullscreen overlay
     and paints inline detail with restored `SourceContext`)
   - Detail → Compact → `Closed { restore }`
5. Host re-applies `restore` (selection, scroll anchor, focus token) to the
   origin widget. Document body stays host-owned — never cloned into TermRock.

## Consumer edits

```diff
  use termrock::style::DesignSystem;
+ use termrock::widgets::{
+     Action, FullscreenViewer, FullscreenViewerState, FullscreenViewerOutcome,
+     SemanticZoomState, SourceContext, ScrollAnchor, ViewerContentKind, ZoomLevel,
+     open_fullscreen_viewer_overlay, open_fullscreen_viewer_child_overlay,
+     dismiss_fullscreen_viewer_overlay, FULLSCREEN_VIEWER_OVERLAY_ID,
+ };

+ let mut zoom = SemanticZoomState::new();
+ zoom.set_content_kind(ViewerContentKind::Code);
+ let ctx = SourceContext::new("main.rs")
+     .selection(Some("main.rs"))
+     .scroll(ScrollAnchor::at(line, col).with_id("line-id"))
+     .focus_token("file-list")
+     .path(["repo", "src", "main.rs"]);
+
+ // Compact → Detail (inline; no overlay)
+ let _ = zoom.promote(ctx.clone());
+ // Detail → Fullscreen
+ let mut viewer = FullscreenViewerState::new();
+ match viewer.enter_fullscreen(ctx, "main.rs") {
+     FullscreenViewerOutcome::Opened { .. } => {
+         let _ = viewer.open_on_stack(&mut stack, bounds, Some("file-list"));
+     }
+     _ => {}
+ }
+
+ // Paint chrome; host paints CodeBlock/Diff/log into body slot
+ FullscreenViewer::new(&system, &actions)
+     .paint(entry.rect, buf, &mut viewer);
+ code_block.paint(viewer.body_area(), buf, &mut code_state);
+
+ // Esc: nested first
+ match viewer.handle_escape(Some(&stack)) {
+     FullscreenViewerOutcome::NestedEscape => {
+         let _ = stack.handle_escape();
+         viewer.sync_with_stack(&stack);
+     }
+     FullscreenViewerOutcome::Demoted { restore, .. }
+     | FullscreenViewerOutcome::Closed { restore } => {
+         let _ = dismiss_fullscreen_viewer_overlay(&mut stack);
+         // re-apply restore to list/code selection + scroll
+         let _ = restore;
+     }
+     _ => {}
+ }
```

### Content kinds (chrome badge only)

`Code | Diff | Log | Object | Task | Media | Custom` — does **not** own the
view. Host projects domain state into the body rect.

### Stories

- `fullscreen-viewer/basic`, `diff`, `log`, `zoom-badge`, `narrow`, `unicode`
