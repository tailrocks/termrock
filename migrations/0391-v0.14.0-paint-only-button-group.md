# 0391 — v0.14.0 paint-only ButtonGroup

## Breaking change

`ButtonGroup` no longer implements Ratatui's stateless `Widget` trait. The
stateless path constructed a fresh `ButtonGroupState` for every render, so
focus, cursor, hover, overflow, and paint geometry could not persist. No
compatibility shim or legacy render path remains.

## Persistent-state paint path

Retain one `ButtonGroupState` across frames and pass it to `paint`:

```rust
let mut button_group_state = ButtonGroupState::new();
ButtonGroup::new(&items, &system).paint(
    area,
    frame.buffer_mut(),
    &mut button_group_state,
);
```

Route keyboard and mouse input through the same state before or between paint
calls. The explicit state path preserves group focus, cursor, hover, overflow,
and hit geometry.
