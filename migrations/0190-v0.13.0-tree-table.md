# 0190 — TreeTable (hierarchy + columns)

## Mission

Combine hierarchical rows with columns without confusing navigation: expansion,
lazy children, sticky headers, sortable data columns, selection, grouping,
aggregate rows, virtualized visible expanded slices, responsive priorities, and
compact indent. Left/Right meaning is explicit via [`TreeTableNavMode`].

Research: process trees, file trees with metadata, IDE outlines, DB schema browsers.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tree` / `TreeNode` / `TreeState` | **Preserved** — single-column hierarchy |
| `DataTable` / `ColumnModel` / `VirtualWindow` | **Preserved** — flat multi-column kit |
| `TreeNodeStatus` | **Reused** by TreeTable rows |
| `TreeTable` / `TreeTableRow` / `TreeTableState` / `TreeTableOutcome` | **Added** (new surface) |
| `TreeTableNavMode` Hierarchy\|Cell\|Scroll | **Added** |
| `TreeTableRowKind` Data\|Group\|Aggregate | **Added** |
| `default_tree_table_intent` | **Added** |
| `filter_tree_table_with_ancestors` | **Added** |
| `TreeNavigation` (route tree) | **Preserved** — distinct product |
| Nothing deleted | — |

TreeTable is a **new** public widget. No removal of Tree or DataTable.

## Consumer API sketch

```rust
use termrock::widgets::{
    ColumnModel, DataColumn, DataColumnWidth, LoadState, TreeTable, TreeTableNavMode,
    TreeTableRow, TreeTableState, TreeTableOutcome,
};

let columns = ColumnModel::new(vec![
    DataColumn::new("name", "PROCESS", DataColumnWidth::Min(14)).priority(100),
    DataColumn::new("cpu", "CPU%", DataColumnWidth::Fixed(6)).priority(80).sortable(),
]);
// Host projects ONLY visible expanded slice (and optional virtual window).
let cells_root: &[&str] = &["systemd", "0.1"];
let cells_child: &[&str] = &["sshd", "0.0"];
let rows = [
    TreeTableRow::new(1u64, 0, cells_root).branch().expanded(),
    TreeTableRow::new(2, 1, cells_child).parent(1),
];
let mut state = TreeTableState::new(Some(1));
state.set_logical_rows(10_000); // flattened expanded universe
state.set_nav_mode(TreeTableNavMode::Hierarchy); // default
// match state.handle_key(&rows, &columns, key) {
//   TreeTableOutcome::ExpandToggled(id) => host.toggle_expand(id),
//   TreeTableOutcome::Selected(id) => ...,
//   _ => {}
// }
TreeTable::new(&system, &columns, &rows)
    .focused(true)
    .compact_indent(true)
    .render(area, buf, &mut state);
```

### Left/Right policy

| Mode | Left | Right |
|------|------|-------|
| **Hierarchy** (default) | Collapse expanded; else select parent | Expand / lazy load; else enter first child |
| **Cell** | Previous column / h-scroll | Next column / h-scroll |
| **Scroll** | H-scroll only | H-scroll only |

Shift+Left/Right always hierarchy (even in Cell mode). `\` cycles modes.
