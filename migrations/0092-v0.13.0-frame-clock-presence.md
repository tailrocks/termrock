# 0092 — FrameClock, Presence, and motion

## Mission

Public injectable frame clock, timed presence, and animation demand helpers.
Migrate Spinner, Progress, Toast, Tooltip onto shared primitives.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `FrameTick` | **Preserve** |
| `FrameClock` | **Public** |
| `Motion` | **Preserve** |
| Tooltip hover_ms-only | **Migrate** → Presence |
| Toast shown_at Instant | **Migrate** → Presence |

## Added

| API | Module |
|-----|--------|
| `FrameClock` public | `runtime` |
| `Presence` / `PresencePhase` / `PresenceChange` | `runtime` |
| `AnimationDemand` / `spinner_demand` / `spinner_step` / `pulse_fraction` | `runtime` |
| `earliest_deadline` / `min_deadline` | `runtime` |
| `FrameTick::{elapsed_ms,delta_ms,spinner_step,pulse_fraction}` | `runtime` |
| `ProgressKind::indeterminate_from` | `widgets` |
| `TooltipState::advance` | `widgets` |
| `ToastState::advance` / `is_focusable` | `widgets` |

## Consumer edits

```rust
use termrock::runtime::{FrameClock, FrameTick, Presence, spinner_demand, earliest_deadline};
use termrock::style::Motion;
use termrock::widgets::{Progress, ProgressKind, Spinner};

let mut clock = FrameClock::from_start(start);
let tick = clock.tick_at(now);

// Spinner
Spinner::new(&system).render(area, buf, tick, system.motion);

// Progress
let kind = ProgressKind::indeterminate_from(tick, Motion::Full);

// Toast / tooltip deadlines for poll
let mut toast = Presence::toast(Duration::from_secs(3));
toast.request_show(tick);
let demand = spinner_demand(tick, Motion::Full, busy).merge(toast.demand());
let poll = earliest_deadline([demand.next_deadline, other]);
```
