# 0303 — Spinner phases declare a motion channel

`ActivityPhase` carried an ad-hoc `period_scale()` multiplier and a set of
reduced-motion fallbacks chosen per phase, with no shared vocabulary. Two
surfaces in the same state drifted out of phase because each did its own tick
math, and the `Indeterminate` fallback was a **filled** `●` — the mark that
elsewhere means "terminal state reached", on the one thing that has not reached
one.

## Phases gain a channel

```rust
ActivityPhase::Indeterminate.channel();   // MotionChannel::Work   (80 ms)
ActivityPhase::Waiting.channel();         // MotionChannel::Wait   (240 ms)
ActivityPhase::Streaming.channel();       // MotionChannel::Stream (120 ms)
ActivityPhase::Done.channel();            // MotionChannel::Static (no frames)
```

| Removed | Replacement |
|---------|-------------|
| `ActivityPhase::period_scale() -> u64` | `ActivityPhase::period_ms()`, from the channel |

`SpinnerState::frame_period_ms()` is new and reads the channel's cadence; a host
that set its own `period_ms` still wins, so a measured rhythm is preserved.

`animates()` is now derived (`channel() != Static`) rather than a separate
match, so a phase cannot claim to animate while declaring itself terminal.

## Two new phases

- `ActivityPhase::Streaming` — content is arriving. A ripple, not a spin:
  `SPINNER_STREAM_UNICODE` (`∻ ≈ ∿ ≋`) / `SPINNER_STREAM_ASCII` (`~ - ~ =`),
  both one column per frame.
- `ActivityPhase::Done` — terminal success. One settled `✓` (ASCII `+`), never
  a sequence, and it schedules no frames.

`ActivityPhase` is `#[non_exhaustive]`, so matches already carry a wildcard arm.

## Reduced-motion marks changed

Every phase keeps a *distinct* static mark — reduced is not frozen, and two
phases sharing a mark would destroy the distinction the tier is meant to
preserve.

| Phase | Before (Unicode) | After |
|-------|------------------|-------|
| `Indeterminate` | `●` | `○` |
| `Queued` | `○` | `◌` |
| `Reconnecting` | `◌` | `◍` |
| `Waiting` | `·` | `·` |
| `Streaming` | — | `≈` |
| `Done` | — | `✓` |

ASCII `Indeterminate` moves `o` → `O` so it stops colliding with `Queued`.

If you asserted on `●` for a stopped spinner, assert `○`.

## Ownership and rollback

Hosts still own phase and label; TermRock owns cadence and marks. Rollback is
source-only.
