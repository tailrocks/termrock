# 0376: TreeTable preserves virtual selection identity

## Boundary

TreeTable virtual projections must not treat an off-window selected row as
removed merely because the host supplied a different visible slice.

## Change

When `VirtualWindow::logical_len` proves that the supplied rows are partial,
`reconcile` preserves a selected ID absent from that slice. Full projections
retain the existing fallback repair for IDs removed from the data set.

## Consumer impact

No consumer edit is required. Selection remains stable while hosts reproject
different virtual windows.
