# 0415: CommandPalette keeps keyword ranges out of label highlights

## Boundary

CommandPalette fuzzy metadata distinguishes the primary label from auxiliary
keywords. Keyword matches determine inclusion and score, but their offsets are
not offsets into the painted primary label.

## Change

`filter_command_entries` now retains highlight ranges only when the winning
match is in `CommandEntry::label`. A keyword winner remains score-only, so the
label painter cannot apply keyword offsets to unrelated label text. Label and
keyword scores are compared after applying the keyword penalty.

## Consumer impact

No consumer change is required. Keyword-only rows remain searchable and sort
with the existing penalty, while primary-label highlighting no longer paints
the wrong graphemes.
