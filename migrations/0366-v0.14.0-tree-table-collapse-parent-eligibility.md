# 0366: TreeTable collapse skips non-selectable parents

## Boundary

TreeTable hierarchy collapse must not move the keyboard cursor onto group,
disabled, loading, or otherwise non-selectable rows supplied as parent metadata
or encountered during the depth walk.

## Change

Explicit parent lookup and fallback ancestor lookup now require `selectable` so
collapse targets remain valid selection identities.

## Consumer impact

No consumer edit is required. Hosts may continue supplying parent IDs and flat
depths; non-selectable ancestors are skipped automatically.
