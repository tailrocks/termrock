# 0373: Roving movement stops after missing-active recovery

## Boundary

Directional movement must not skip the first enabled entry when a stale active
ID is absent from the current projection.

## Change

After reconciling a missing active ID, movement now returns the repair outcome
instead of advancing a second time. Empty-state movement retains its existing
contract.

## Consumer impact

No consumer edit is required. Stale active IDs now recover to the first valid
entry through both Roving and Collection APIs.
