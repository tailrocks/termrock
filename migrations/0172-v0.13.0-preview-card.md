# 0172 — PreviewCard

## Mission

Non-essential contextual preview for selected resources (files, commands,
symbols, sessions). Delayed pointer/focus/selection show, metadata + rich body,
loading / error / stale chrome, pin-to-open, application-owned async data with
generation race gates. Never hides required information exclusively in the
preview.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tooltip` / `Presence::tooltip` delay | **Preserved** (pattern; separate id) |
| `OverlayKind::Tooltip` unpinned open | **Preserved** (no input ownership) |
| `OverlayKind::Popover` pinned open | **Preserved** (light input) |
| `QuickOpen` inline preview pane | **Unchanged** (may host `PreviewCard` later) |
| `FilePicker` / `ImageSurface` previews | **Unchanged** |
| `CapabilityPreviewHost` / `PreviewPresentation` | **Unchanged** (media protocol, not hover card) |
| Ad-hoc hover/detail cards in consumers | **Migrate** → `PreviewCard` |
| `PreviewCard`, state, content, helpers | **Added** (greenfield) |

## Consumer edits

```diff
+ use termrock::widgets::{
+     PreviewCard, PreviewCardContent, PreviewCardState, PreviewLoadState,
+     PreviewMetadata, PreviewResourceKind, PreviewTrigger,
+     open_preview_card_overlay, dismiss_preview_card_overlay,
+     example_file_preview,
+ };

+ let mut state = PreviewCardState::with_delay(Duration::from_millis(300));
+ state.set_trigger(PreviewTrigger::Any);
+ // List cursor changed:
+ match state.set_selection(item_id) {
+     PreviewCardOutcome::SelectionChanged { generation, .. } => {
+         // cancel in-flight IO for older gens; kick fetch
+         let _ = generation;
+         let PreviewCardOutcome::Loading { generation } = state.begin_fetch() else { return };
+         host.fetch_preview(generation, item_id);
+     }
+     _ => {}
+ }
+ // Async result:
+ if let PreviewCardOutcome::ContentApplied { .. } = state.apply_ready(gen) {
+     /* swap host content snapshot */
+ }
+ // Frame:
+ state.set_pointer_over(hovering);
+ state.set_focus_within(anchor_focused);
+ state.set_selection_active(has_cursor);
+ match state.advance(tick, motion) {
+     PreviewCardOutcome::Shown => {
+         let size = PreviewCard::new(content, &system).overlay_size();
+         let _ = open_preview_card_overlay(&mut stack, bounds, anchor, size, Some("list"));
+     }
+     PreviewCardOutcome::Hidden => {
+         let _ = dismiss_preview_card_overlay(&mut stack);
+     }
+     _ => {}
+ }
+ // Paint only if visible; content.essential_elsewhere must be true for required facts
+ PreviewCard::new(content, &system).paint(entry.rect, buf, &mut state);
+ // Pin sticky:
+ let _ = state.pin(); // then open_preview_card_pinned_overlay for Popover policy
```

### Rules

1. **Non-essential** — list columns / labels must still convey required facts
   (`essential_elsewhere: true` enforced by default).
2. **No focus theft** — unpinned uses Tooltip overlay policy (`owns_input: false`).
3. **Rapid selection** — `set_selection` debounces show and bumps generation;
   `apply_ready` / `apply_error` drop stale gens.
4. **Pin** — sticky visibility; Esc unpins; Enter → `OpenRequested` (host may
   open FullscreenViewer).

### Stories

- `preview-card/file`, `command`, `symbol`, `session`, `loading`, `error`, `pinned`
