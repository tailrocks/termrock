# 0350: DataTable zero-visible-column focus is canonical

## Boundary

Column visibility can temporarily project an empty visible-column set while a
host hides or restores columns. Cursor and selection focus must remain valid
through that transition.

## Change

DataTable clamps its visible-column cursor with saturating bounds and
synchronizes `SelectionModel::focus_col` during render and interaction
normalization. Hiding every column therefore cannot preserve a stale column
ordinal that later paints or routes as focus.

## Consumer impact

No consumer edit is required. Hosts may change column visibility between
frames without manually repairing DataTable cursor or selection focus.
