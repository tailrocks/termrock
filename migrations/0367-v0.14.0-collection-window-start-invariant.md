# 0367: Collection virtual windows clamp their start

## Boundary

`CollectionState` virtualization metadata must keep the effective window start
within the legal scroll range, including after first/last navigation.

## Change

`reconcile_window` now normalizes an out-of-range `window_start` to the maximum
legal offset before storing it or exposing it through navigation.

## Consumer impact

No consumer edit is required. Hosts may continue passing a stale window start
while the total count or viewport changes; the state uses the nearest valid
window start.
