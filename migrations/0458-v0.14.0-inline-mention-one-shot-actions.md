# 0458: InlineMention physical one-shot actions

## Boundary

`InlineMention::handle_key` is the raw keyboard adapter around Tag behavior
and mention-specific copy, preview, and disambiguation actions. Held keys must
not repeat host outcomes or open/close/commit a disambiguation surface.

## Change

- Repeat and release events are ignored for copy, preview, disambiguation open,
  ambiguous Enter, disambiguation Escape, and disambiguation selection.
- Press events retain those one-shot outcomes.
- Up/Down and k/j disambiguation navigation remain repeatable.
- Delegated Tag behavior, mouse handling, and semantic projections are
  unchanged.

## Host migration

Hosts routing raw InlineMention events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize mention-specific outcomes from
`Repeat` or `Release` events.
