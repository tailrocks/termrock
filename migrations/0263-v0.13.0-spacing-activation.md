# 0263 — Spacing activation

## Mission

Activate density-driven interior rhythm across Panel, Dialog, Stack, Grid,
and the shared collection density model.

## Visible defaults

Comfortable bordered panels now inset content by two columns and one row when
space permits. Dialogs add leading, middle, and trailing breathing rows at
affordant heights and collapse them before content on small terminals.
`Density::Dashboard` and `PanelVariant::Quiet` remain compact opt-outs.

## Public API changes

- `DialogSpec` adds `preferred_reference_pct` and
  `preferred_pct_of_reference`; 50% resolves against 160 columns, then clamps
  to the host.
- `StackSpec::from_system` and `GridSpec::from_system` consume shared spacing.
- `ListDensity`, `EmptyDensity`, `KvDensity`, and `DataDensity` are removed.
  Pass `style::Density` to the existing builders and state fields:
  `Compact` replaces list compact / empty inline / KV dense / data compact;
  `Comfortable` replaces list comfortable / empty full / KV reading / data
  comfortable. `Dashboard` follows compact behavior.
