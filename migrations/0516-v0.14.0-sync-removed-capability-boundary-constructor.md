# 0516: Synchronize removed CapabilityBoundary constructor

## Boundary

The dead-accessor sweep removed the unused explicit
`CapabilityBoundary::new(CapabilitySet, CapabilityProfile)` constructor. The
generated public API snapshot retained its signature even though the
constructor is no longer available.

## Change

Removed the one stale snapshot entry for the constructor deleted by
`855e4147`.

## Host migration

capability boundary. No compatibility alias or deprecation period is provided.
