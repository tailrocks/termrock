# 0159 — QuickOpen

## Mission

High-performance fuzzy resource opener for files, symbols, sessions, tables,
commands, and arbitrary host providers. Host owns I/O and multi-million
indexes; TermRock owns chrome, provider memory, generation-gated streaming,
previews, query syntax, and JumpMode / fullscreen integration.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `CommandPalette` | **Preserved** — command execution surface (not resource open) |
| `Picker` | **Preserved** — general query+list |
| `FilePicker` | **Preserved** — FS browser dialog |
| `JumpOverlay` / `assign_jump_badges` | **Preserved** — QuickOpen emits `JumpModeRequested` + hit→target helper |
| `OverlayKind::Fullscreen` / command-palette center | **Preserved** — dual open helpers |
| `QuickOpen*` | **Added** (greenfield) |
| Prior QuickOpen | **None** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     QuickOpen, QuickOpenItem, QuickOpenOutcome, QuickOpenProvider, QuickOpenState,
+     example_quick_open_files, example_quick_open_providers, filter_quick_open_items,
+     open_quick_open_overlay, quick_open_jump_targets,
+ };

+ let providers = example_quick_open_providers();
+ let mut state = QuickOpenState::new();
+ state.set_focused(true);
+
+ match state.handle_key(key, &providers, &visible) {
+     QuickOpenOutcome::SearchRequested { request } => {
+         // cancel prior work tagged with older generation; run host search
+         host.search(request);
+     }
+     QuickOpenOutcome::StreamMore { request } => host.search_more(request),
+     QuickOpenOutcome::SearchCancelled { generation } => host.cancel(generation),
+     QuickOpenOutcome::Activated { provider_id, id } => host.open(provider_id, id),
+     QuickOpenOutcome::JumpModeRequested => {
+         let badges: Vec<char> = ('a'..).take(state.hits…); // or assign from paint hits
+         let targets = quick_open_jump_targets(&visible, QuickOpen::hits_from_state(&state), &badges);
+         open_jump_overlay(&mut stack, bounds, Some(focus));
+     }
+     QuickOpenOutcome::Cancelled => dismiss_quick_open_overlay(&mut stack),
+     _ => {}
+ }
+
+ // when host results arrive:
+ if state.apply_results(request.generation, &window, complete, total_hint) {
+     // paint
+ }
+ QuickOpen::new(&providers, &visible, &system).paint(area, buf, &mut state);
```

### Query syntax

- `@files main` / `#symbols paint` — optional provider override + filter
- Per-provider query and cursor restored on tab switch

### Scale

Do **not** pass millions of rows into the widget. Host index returns a window
(default limit 200); use `StreamMore` for incremental fill.

### Stories

- `quick-open/basic`, `symbols`, `fuzzy`, `loading`, `empty`, `narrow`, `ascii`
