# 0389: List one-shot intents reject key repeats

## Boundary

The shared list intent map must distinguish held-key movement from actions that
fire once per physical press.

## Change

`Enter`, Space, and `Esc` now map to `Activate`, `Toggle`, and `Cancel` only on
`Press`; `Repeat` remains valid for vertical and page movement.

## Consumer impact

All widgets consuming `default_list_intent` inherit the corrected phase policy.
Direct `handle_intent` callers remain unchanged and explicitly own invocation
frequency.
