# 0459: MessageThread physical one-shot actions

## Boundary

`MessageThreadState::handle_key` is the raw keyboard adapter for thread-local
search, zoom, tail-follow, copy, and selected-entry actions. Held keys must not
repeat host outcomes or reopen and close search state.

## Change

- Repeat and release events are ignored for search open/commit/cancel, zoom,
  jump-latest, copy, retry, and cancel action chords.
- Press events retain those one-shot outcomes.
- Search text and Backspace remain repeatable.
- Transcript navigation continues through its existing lifecycle-safe adapter.
- Mouse and semantic state methods are unchanged.

## Host migration

Hosts routing raw MessageThread events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize thread-local outcomes from
`Repeat` or `Release` events.
