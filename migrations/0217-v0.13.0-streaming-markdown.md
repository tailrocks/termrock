# 0217 — StreamingMarkdown

## Mission

Streaming-safe Markdown for token-by-token AI output: unfinished paragraphs,
lists, tables, links, and code fences without flicker or full reparse when
avoidable. Preserve scroll anchors and selection while content grows.
Citations/source anchors, partial fence highlighting, tool/status insertions.
Batch updates for latency vs redraw. Adversarial fixtures and performance
budgets.

Research: Glow-quality rendering + agent CLI streaming.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `MarkdownView` / `MarkdownBlock` / `project_markdown` | **Preserved** — paint + projector |
| `SourceAnchor` | **Preserved** — citations |
| `CodeBlock` (fence paint via MarkdownView) | **Preserved** |
| Full CommonMark crate | **Never required** — host may swap projector later |
| Network / tokenizer I/O | **Never TermRock** |
| `StreamingMarkdown*` · stable-prefix algorithm · fixtures | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    StreamingMarkdown, StreamingMarkdownState, StreamPhase, StreamCitation,
    StreamInsertion, streaming_markdown_fixtures,
};

let mut state = StreamingMarkdownState::new();
// coalesce: apply every N deltas or chars
state.coalesce_deltas = 8;
state.coalesce_chars = 256;

for token in stream {
    state.push_delta(token); // may coalesce
}
state.apply_pending(); // force flush
// incomplete fence stays in tail; committed only grows

// paint
StreamingMarkdown::new(&system).paint(area, buf, &mut state);

// MessageThread lines
let lines = state.plain_lines();

// done
state.finish(); // flush tail into committed

// regenerate
state.reset_with(new_full_doc);

// citations / tool insert
state.add_citation(StreamCitation::new("1", "[1]"));
state.add_insertion(StreamInsertion::new("t", "tool", ["ok"]));
```

### Stable-prefix rules

| Rule | Detail |
|------|--------|
| `committed` | Never shrinks on normal deltas |
| Reparse window | `tail` (+ pending), not full doc |
| Width change | Full reparse allowed |
| Hot path | `full_reparse_count` must stay 0 on pure deltas |
