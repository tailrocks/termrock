# 0210 — DependencyGraph constrained dependency viewer

## Mission

Constrained graph viewer for package, service, schema, and task dependencies:
nodes, edges, direction, status, selection, search, filtering, grouping,
details, and alternative list/tree representation. Does **not** promise
arbitrary graph layout quality. Deterministic layered layouts, pan navigation,
ASCII connectors. Falls back to TreeTable-shaped projection when unreadable.
Benchmark moderate real-world graphs.

Research: terminal graph tools, dependency trees, service maps, FTXUI canvases.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Tree` / `TreeTable` | **Preserved** — TreeTable-shaped fallback projection helpers |
| `ObjectInspector` | **Preserved** — `dep_node_to_inspector_fields` |
| FocusGraph (interaction) | **Preserved** — unrelated focus routing |
| Package/service resolution | **Never in TermRock** — host projects nodes/edges |
| `DependencyGraph*` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    DependencyGraph, DependencyGraphState, DepNode, DepEdge, DepNodeKind,
    DepNodeStatus, DependencyGraphView, dep_node_to_inspector_fields,
};

let nodes = [
    DepNode::new("app", "app").kind(DepNodeKind::Package),
    DepNode::new("termrock", "termrock").kind(DepNodeKind::Package),
    DepNode::new("ratatui", "ratatui"),
];
let edges = [
    DepEdge::new("app", "termrock"),
    DepEdge::new("termrock", "ratatui"),
];
let mut state = DependencyGraphState::with_selected("termrock");
DependencyGraph::new(&nodes, &edges, &system).title("crates").render(area, buf, &mut state);

// Auto tree when width ≤ 40 or nodes > 48
// Ctrl+V cycles Graph → Tree → List
```

### Keys

| Key | Action |
|-----|--------|
| j/k · home/end | Select nodes (filtered order) |
| Enter · i | Details |
| e | Select outgoing edge |
| / | Filter |
| Ctrl+V | Cycle view Graph/Tree/List |
| [ ] · Ctrl+hjkl | Pan graph |
| Shift+wheel / wheel | Pan x / y |
