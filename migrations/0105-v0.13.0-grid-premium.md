# 0105 — Grid premium layout

## Mission

Predictable terminal grid for dashboards, forms, settings, and card collections:
fixed / fractional / content / minmax tracks, gaps, spans, responsive templates,
deterministic overflow policy, Studio-debuggable sizes, optional spatial nav
helpers — without making the grid itself interactive.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Grid`, `GridSpec`, `GridItem`, `TrackSize`, `GridAutoFlow`, `GridLayout` | **Preserve** (expanded) |
| `layout_grid`, `auto_flow_items`, `form_grid_template`, `dashboard_grid_template` | **Preserve** |
| `grid_neighbor`, `grid_neighbor_2d`, `grid_reading_neighbor` | **Preserve** |
| `Stack` / `Inline` | **Preserve** — 1D packing |
| `WorkSurface` / `Workspace` | **Preserve** — named panes |
| `VirtualGrid` | **Preserve** — virtualized data grid (different problem) |
| `OverflowPolicy` on `GridSpec` | **Added** (shared with Stack) |
| `TrackSize::content`, `ideal_size`, `max_size` | **Added** |
| `settings_grid_template` | **Added** |
| `layout_grid_into` | **Added** |
| `GridLayout::{column_sizes, row_sizes, debug_summary, hit_regions, register_semantic_group}` | **Added** |
| MinMax residual growth | **Added** |
| Ad hoc 2D packing for settings/dashboard stories | **Migrated** onto templates |

## API sketch

```rust
use termrock::layout::{
    Grid, GridItem, GridSpec, TrackSize, GridAutoFlow, OverflowPolicy,
    layout_grid, layout_grid_into, form_grid_template, dashboard_grid_template,
    settings_grid_template, grid_neighbor_2d, auto_flow_items,
};

// Equal fr columns + auto-flow
let layout = Grid::columns(3)
    .gaps(1, 1)
    .auto_row(TrackSize::Fixed(4))
    .layout_flow(area, 6, GridAutoFlow::Row);

// Spans
let layout = layout_grid(area, &GridSpec::columns_fr(2).rows([
    TrackSize::Fixed(3),
    TrackSize::fr(1),
]), &[
    GridItem::span(0, 0, 2, 1),
    GridItem::cell(0, 1),
    GridItem::cell(1, 1),
]);

// Responsive templates
let form = form_grid_template(width);
let dash = dashboard_grid_template(width, 3, 18, 1);
let settings = settings_grid_template(width, 18, 2); // label | value

// Overflow: keep head tracks
let tight = Grid::from_spec(
    GridSpec::default()
        .overflow(OverflowPolicy::ClipTail)
        .columns([TrackSize::Fixed(10); 3]),
).layout(area, &items);

// Host-measured intrinsic label column
TrackSize::content(measured_label_cols);

// Studio
println!("{}", layout.debug_summary()); // cols=[..] rows=[..] overflowed=…

// Spatial nav (host wires intents; grid is not interactive)
if let Some(next) = grid_neighbor_2d(&items, focus, 1, 0) { /* Right */ }

// Reuse cell buffer capacity
let mut buf = Vec::with_capacity(32);
let layout = layout_grid_into(area, &spec, &items, &mut buf);
```

## Overflow (tracks)

| Policy | Behavior when fixed/minmax sum > axis |
|--------|---------------------------------------|
| `ShrinkFromEnd` (default) | From end: `min(claim, remaining)` |
| `ClipTail` | Keep head; tail → 0 |
| `EqualShare` | Peel cells from end until fit |

Weight (`fr`) tracks take residual after fixed/minmax. MinMax may **grow** toward
`max` when residual remains after fr distribution. `GridLayout::overflowed` is set
when any fixed/minmax track is below its minimum claim.

## Navigation

Grid is **not** interactive by default. Hosts that want keyboard spatial
navigation call `grid_neighbor` / `grid_neighbor_2d` / `grid_reading_neighbor`
from Move intents. Focus ownership stays on host-registered controls.

## vs Stack / WorkSurface / VirtualGrid

| | Grid | Stack | WorkSurface | VirtualGrid |
|--|------|-------|-------------|-------------|
| Axes | 2D tracks | 1D | 1D named | 2D virtual data |
| Spans | yes | no | no | cells |
| Use | forms, dashboards | anatomy | app chrome | large tables |
