# 0451: KeybindingRecorder physical one-shot actions

## Boundary

`KeybindingRecorderState::handle_key` is the raw physical keyboard adapter for
binding capture and recorder controls. A held key must not append duplicate
chords or retrigger recording, commit, cancel, clear, restore, or blur actions.

## Change

- The adapter now accepts only `Press` events.
- `Repeat` and `Release` events are ignored before they can capture a chord,
  change the draft, or transition recorder mode.
- Semantic `handle_intent` and direct state methods remain available for hosts
  that intentionally issue semantic commands.

## Host migration

Hosts routing raw recorder events must pass complete `KeyEvent` values,
including lifecycle kind. Do not synthesize repeated chord captures or
repeated recorder actions from `Repeat` or `Release` events. Use the semantic
intent path for non-physical commands.
