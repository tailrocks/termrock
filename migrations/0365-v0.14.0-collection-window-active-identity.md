# 0365: Virtual collection windows preserve off-window active IDs

## Boundary

A virtualized collection receives only a slice of the full ordering. Replacing
the active ID merely because it is outside that slice breaks stable focus while
the host scrolls or reloads the window.

## Change

`CollectionState::reconcile_window` preserves an existing active ID when the
window is non-empty but does not contain that ID. Roving reconciliation still
runs when the active item is present, and an empty total clears active state.

## Consumer impact

Virtualized hosts retain active identity across window changes. Movement over a
slice whose active item is off-window continues to reconcile when the host
supplies a slice containing the active item.
