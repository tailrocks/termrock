# 0343: DataTable pinned columns own physical edge geometry

## Boundary

`DataTable` supports start-pinned, center, and end-pinned columns while the
center strip scrolls horizontally. Header regions, body regions, and pointer
hit testing must describe the same painted rectangles.

## Change

DataTable now resolves one clipped physical rectangle per projected column.
Start pins anchor to the content origin, end pins anchor to the opposite edge,
and only the unpinned center strip consumes horizontal offset. Header and body
painting consume those shared rectangles, preventing overlap and keeping
resize, sort, selection, and context hit regions on the visible cells.

Horizontal extent is calculated from the unpinned center strip, so pinned
columns do not create false scroll range.

## Consumer impact

No consumer edit is required. Existing `ColumnPin` declarations now render at
their documented edges; host-owned column models and pointer outcomes remain
unchanged.
