# Remove mirrored input and enabled getters

`accepts_input()` and `is_enabled()` no longer expose copies of host-owned
input/enabled flags on widget and pattern state. Keep the boolean in host state
when changing these flags, and call the existing `set_accepts_input` or
`set_enabled` method. These setters remain available.

`FilePreview::new()` and `NumberConstraints::new()` were exact wrappers around
`Default`; construct them with `FilePreview::default()` and
`NumberConstraints::default()` instead.

This does not remove `is_focused()` or other focus APIs. Those remain until
their paired focus-state migration is complete.
