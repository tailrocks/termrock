# 0380: TreeTable Down stops after the last selectable row

## Boundary

TreeTable forward movement must not select an earlier row when the cursor is
on a trailing group or loading row.

## Change

Forward movement now returns `Ignored` when the cursor's insertion point is
after every selectable row. Backward movement retains its recovery to the
last selectable row only when a prior selectable row exists.

## Consumer impact

No consumer edit is required. Down remains at the trailing non-selectable row
until a selectable successor exists.
