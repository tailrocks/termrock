# 0266 — Motion, text, and glyph kit

This additive release introduces deterministic motion math, explicit-canvas
style fading, equal-style cell-run coalescing, grapheme-safe
`text::truncate_cols`, shared block/braille ramps, catalog diamond/status
glyphs, and a one-cell dot-pulse spinner tier.

`style::faded(color, alpha)` keeps its signature but now delegates to the
general RGB blend helper. StatusBar uses `style::fade_style` with its semantic
canvas instead of a private black-only implementation, improving paper themes.

Motion helpers accept caller-owned ticks and never read wall time. Under
`Motion::Reduced` or `Motion::Off`, `effective_alpha` returns the deterministic
fully-visible fallback.

```rust
let alpha = termrock::style::pulse_brightness(tick, 16);
let label = termrock::text::truncate_cols(text, 24, "…");
state.set_glyph_set(SpinnerGlyphSet::DotPulse);
```

Validate with `mise run check` and `mise run gate`.
