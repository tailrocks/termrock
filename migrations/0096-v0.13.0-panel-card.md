# 0096 — Panel anatomy + Card

## Mission

Composable panel chrome with variants, body modes, collapsible/interactive
state, and a raised `Card` composition for tool/dashboard surfaces.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Panel`, `PanelSlots`, `PanelChrome` | **Preserve** (expanded) |
| `Panel::title/subtitle/leading/trailing/footer/emphasis/chrome` | **Preserve** |
| `Panel::inner`, `Widget` render | **Preserve** (now via `paint`) |
| `PanelVariant`, `PanelBody`, `PanelParts`, `PanelState`, `PanelOutcome` | **Added** |
| `Card`, `CardParts` | **Added** |
| `ToolCard` | **Migrated** — paints via `Card` |
| Nested box-of-boxes | **Avoid** — one Panel/Card per region |

## Variants

| Variant | Border | Notes |
|---------|--------|-------|
| `Bordered` | box | default |
| `Quiet` | none | transparent fill |
| `DividerOnly` | top/bottom rules | ASCII `rule()` glyph |
| `Interactive` | box | panel-level focus + Activate |
| `Selected` | box | Selection surface + gutter; **not** focus |

Focus remains `PanelChrome::Focused` / `Role::BorderFocused` — never selected.

## Body modes

`Host` (default) · `Loading` · `Empty` · `Error` — compose `LoadingView` /
`EmptyState` / `ErrorView` with ASCII glyph fallbacks.

## Consumer edits

```rust
use termrock::widgets::{
    Panel, PanelBody, PanelVariant, PanelState, PanelOutcome, Card,
};
use termrock::style::{DesignSystem, PanelChrome};

let system = DesignSystem::default();

// Geometry + paint
let body = Panel::new(&system)
    .title("Inbox")
    .subtitle("unread")
    .variant(PanelVariant::Bordered)
    .body(PanelBody::Empty)
    .body_title("No messages")
    .paint(area, buf, None);

// Collapsible / interactive
let mut state = PanelState::new();
state.set_focused(true);
let panel = Panel::new(&system).title("Section").collapsible(true);
let body = panel.paint(area, buf, Some(&mut state));
let out = state.handle_key(key, true, false);

// Card (raised)
let body = Card::new(&system)
    .title("Latency")
    .description("p99 last hour")
    .footer("dashboard")
    .paint(area, buf, None);
// children into `body` only
```

Existing `Panel::new(&s).title("T").emphasis(PanelChrome::Focused)` still works.
