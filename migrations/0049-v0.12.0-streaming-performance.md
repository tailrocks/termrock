# 0049 — Streaming and large-data performance kits

## Removed surface

None.

## Canonical addition

Module `termrock::perf` (crate root re-exports):

- **Budgets:** `ComponentBudget`, `budgets`, `budget_for`, `check_batch_budget`,
  `check_zero_alloc_steady` — named CI limits (tree 10k @ 250 ms / 0 alloc, …).
- **Follow:** `FollowMode`, `ScrollAnchor`, `NewContentIndicator`,
  `apply_follow_after_append`.
- **Streaming:** `StreamCoalescer`, `StreamBatch`, `DirtyFlags`,
  `UpdatePriority`, `BackpressureSignal`.

Design: `docs/design/streaming-performance.md`.

`tree_hot_path` now asserts via `check_batch_budget("tree_viewport_10k", …)` and
`check_zero_alloc_steady("tree_viewport_10k_alloc", …)`.

### Host loop sketch

```rust
// drain channel into coalescer
while let Ok(delta) = rx.try_recv() {
    coalescer.push_text(&delta, UpdatePriority::Normal);
}
let batch = coalescer.take_for_frame(tick);
if !batch.is_empty() {
    model.apply_text_delta(&batch.text_delta);
    apply_follow_after_append(&mut window, follow, &mut indicator, len, batch.append_count);
}
// paint only if dirty / input / motion
```
