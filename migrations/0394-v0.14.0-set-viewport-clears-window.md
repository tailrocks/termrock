# 0394: Full collection viewport resets virtual-window metadata

## Boundary

Direct `CollectionState` consumers can switch from a virtual projection to a
full projection before the next reconciliation.

## Change

`CollectionState::set_viewport` now clears `window_start` before applying full
projection viewport metadata. Immediate movement no longer preserves an active
ID as if it were outside a virtual window.

## Consumer impact

`set_viewport` remains the full-projection metadata setter. Virtual consumers
must use `set_virtual_window` or `reconcile_window` for window metadata.
