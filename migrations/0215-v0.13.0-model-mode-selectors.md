# 0215 — ModelSelector and AgentModeSelector

## Mission

Compact selectors for model, reasoning effort, agent mode, and execution policy.
Current choice, provider, capabilities, cost/latency/context metadata,
availability, warnings, and recent choices. Separate model selection from mode
selection while allowing composed presentation. Contract to concise status text
in the composer; expand into searchable selection. Show consequential changes
clearly (permissions / cost). Provider data is application-owned.

Research: Amp, OpenCode, Grok Build, model pickers in AI tools.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ModeRibbon` / `WorkbenchMode` | **Preserved** — workbench strip; `modes_to_workbench` bridge |
| `Select` / `SelectOption` | **Preserved** — `models_to_select_options` for host overlays |
| `ModeIndicator` / `ModelIndicator` (PromptComposer) | **Preserved** — `mode_to_indicator` / `model_to_indicator` |
| SegmentedControl | **Preserved** — unrelated view modes |
| Provider SDKs / model catalogs / policy engines | **Never TermRock** |
| `ModelSelector*` · `AgentModeSelector*` · `ComposerSelectors` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    ModelOption, ModelSelector, ModelSelectorState, ModelSelectorOutcome,
    ModelCapability, ModelAvailability, ReasoningEffort,
    AgentModeOption, AgentModeKind, AgentModeSelector, AgentModeSelectorState,
    AgentModePresentation, default_agent_modes, example_model_catalog,
    ComposerSelectors, mode_to_indicator, model_to_indicator,
};

let models = example_model_catalog();
let modes = default_agent_modes();

let mut model_st = ModelSelectorState::with_selected("fast");
let mut mode_st = AgentModeSelectorState::with_selected("edit");

// Compact composer chrome
ComposerSelectors::new(&modes, &models, &system)
    .paint_compact(status_area, buf, &mode_st, &model_st);

// Expand model list (searchable)
model_st.open();
ModelSelector::new(&models, &system).paint(menu_area, buf, &mut model_st);
match model_st.handle_key(key, &models) {
    ModelSelectorOutcome::Confirmed { id, warning } => {
        // host may dialog on warning (cost/deprecation)
        composer.set_model(Some(model_to_indicator(
            models.iter().find(|m| m.id == id).unwrap()
        )));
    }
    _ => {}
}

// Mode menu — FullAuto carries needs_confirm + consequence
mode_st.open_menu();
match mode_st.handle_key(key, &modes) {
    AgentModeSelectorOutcome::ModeChanged {
        id, kind, consequence, needs_confirm
    } => {
        if needs_confirm { /* host confirm dialog */ }
        composer.set_mode(Some(mode_to_indicator(
            modes.iter().find(|m| m.id == id).unwrap()
        )));
    }
    _ => {}
}
```

### Separation

| Control | Owns |
|---------|------|
| ModelSelector | model id, reasoning effort, cost/context meta |
| AgentModeSelector | safety mode, execution policy, permission consequences |

### Stories

- `model-selector/{compact,expanded,empty}`
- `agent-mode-selector/{ribbon,menu,compact}`
- `composer-selectors/strip`
