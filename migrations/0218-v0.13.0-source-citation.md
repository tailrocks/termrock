# 0218 — SourceCitation and CitationList

## Mission

Compact inline citations and expandable source lists for agent output: title,
type, path/URL, range, confidence/provenance, open, preview, copy, unavailable,
and duplicate grouping. Keep raw destinations visible for external or sensitive
sources. Integrate with Markdown anchors and fullscreen previews. Keyboard
navigation without fragmenting reading flow. No-hyperlink and offline states.

Research: research assistants, IDE references, terminal hyperlink capabilities.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Link` / `DestinationDisplay` / OSC helpers | **Preserved** — `citation_link` composition |
| `SourceAnchor` (markdown) | **Preserved** — range + markdown jump |
| `StreamCitation` (StreamingMarkdown) | **Preserved** — bridges `citation_from_stream` / `citation_to_stream` |
| PTY OSC emission | **Never in widget** — host uses Link osc_requests |
| Provider search / fetch | **Never TermRock** |
| `SourceCitation*` · `CitationList*` · `CitationSource` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    CitationSource, SourceCitation, SourceCitationState, SourceCitationOutcome,
    CitationList, CitationListState, CitationListOutcome, example_citations,
    citation_from_stream, group_citations, DestinationDisplay, SourceAnchor,
};

let sources = example_citations();

// Inline [1] in reading flow
let mut ist = SourceCitationState::new();
ist.focused = true;
SourceCitation::new(&sources[0], &system)
    .show_destination(DestinationDisplay::Auto) // external always shows dest
    .offline(false)
    .no_hyperlink(!term_has_osc8)
    .paint(chip_area, buf, &mut ist);

// List under agent answer
let mut list = CitationListState::new();
list.expand();
CitationList::new(&sources, &system).title("Sources").paint(area, buf, &mut list);

match list.handle_key(key, &sources) {
    CitationListOutcome::Citation(SourceCitationOutcome::OpenRequested { destination, external, .. }) => {
        // host open; raw destination always present
    }
    CitationListOutcome::Citation(SourceCitationOutcome::CopyRequested { text, .. }) => { /* clipboard */ }
    _ => {}
}

// StreamingMarkdown bridge
let c = citation_from_stream(&stream_cite, 0);
```

### Keys

| Key | Inline | List |
|-----|--------|------|
| Enter / o | Open (or preview if offline) | Open selected |
| p | Preview | Preview |
| c / Ctrl+C | Copy (includes raw dest) | Copy |
| g | Jump markdown anchor | — |
| j/k | — | Navigate |
| d | — | Expand duplicate group |
| Esc / h | — | Collapse list |
