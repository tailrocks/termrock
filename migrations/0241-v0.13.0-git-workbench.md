# 0241 — GitWorkbench composition block

## Mission

Modern **source-owned Git workflow** composition: repository status, file
tree with git badges, diff review, history timeline, branches, commits,
command output, conflict diagnostics, contextual actions, and keyboard help.
Fullscreen diff promotion, responsive densities, line/hunk/file selection,
staging-like typed outcomes, and **safe destructive confirm** (Cancel default).
**All Git execution stays host-owned** — no `git` process, libgit2, or worktree
mutation inside TermRock.

Research: lazygit, GitUI, delta, IDE source-control panels (references only;
distinct TermRock design).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DiffReview` / `DiffView` / `DiffHunk` / `DiffLine` | **Preserved** — composed for patch |
| `FileTree` / `FileGitStatus` | **Preserved** — status list |
| `CheckpointTimeline` | **Preserved** — commit history projection |
| `TerminalOutput` | **Preserved** — command output pane |
| `DiagnosticView` | **Preserved** — conflict diagnostics |
| `StatusBar` / `KeyboardHelp` | **Preserved** — chrome / help |
| `AgentWorkbench` / `DatabaseWorkbench` | **Preserved** — other domains |
| Local DiffReview/FileTree re-paint | **Forbidden** |
| `std::process` / `git2` / real repo mutation | **Host-owned** |
| `GitWorkbenchState` · `render_git_workbench` | **Added** (`patterns/git_workbench`) |

## Consumer API

```rust
use termrock::patterns::{
    GitWorkbenchState, GitWorkbenchSurfaces, GitWorkbenchDensity, GitWorkbenchOutcome,
    GitRepoStatus, example_git_files, example_git_diff_lines, example_git_hunks,
    example_git_diff_files, example_git_commits, example_conflict_diagnostics,
    example_git_terminal_meta, example_git_terminal_lines, example_git_help_entries,
    render_git_workbench, git_workbench_layout_density,
};

let mut state = GitWorkbenchState::new();
state.repo_status = GitRepoStatus::Dirty;
// state.density = Some(GitWorkbenchDensity::Narrow);
// state.set_fullscreen_diff(true);

let files = example_git_files();
let lines = example_git_diff_lines();
let hunks = example_git_hunks();
let dfiles = example_git_diff_files();
let commits = example_git_commits();
let diags = example_conflict_diagnostics();
let meta = example_git_terminal_meta();
let tlines = example_git_terminal_lines();
let help = example_git_help_entries(&system);

render_git_workbench(buf, area, GitWorkbenchSurfaces {
    system: &system,
    state: &mut state,
    files: &files,
    diff_lines: &lines,
    hunks: &hunks,
    diff_files: &dfiles,
    commits: &commits,
    diagnostics: &diags,
    terminal_meta: &meta,
    terminal_lines: &tlines,
    help_entries: &help,
});

match state.handle_key(key, &files, &hunks, &help, &diags, &tlines, &meta) {
    GitWorkbenchOutcome::StageRequested { units } => { /* host git add */ }
    GitWorkbenchOutcome::UnstageRequested { units } => { /* host git restore --staged */ }
    GitWorkbenchOutcome::DiscardRequested { paths } => { /* after confirm */ }
    GitWorkbenchOutcome::CheckoutRequested { branch } => { /* host checkout */ }
    GitWorkbenchOutcome::CommitRequested { message } => { /* host commit */ }
    GitWorkbenchOutcome::FullscreenDiff { on } => { /* layout already updated */ }
    GitWorkbenchOutcome::OpenHelp => {}
    _ => {}
}
```

### Densities

| Density | Width | Panes |
|---------|-------|-------|
| `Normal` | ≥ 90 | Files · Diff · History · Branches · Output · Status |
| `Narrow` | 48–89 | Files · Diff · Output · Status |
| `Tiny` | < 48 | Files · Diff · Status |
| Fullscreen | flag | Diff · Status |

### Laws

| Law | Detail |
|-----|--------|
| Public only | Composes public widgets; no local paint forks |
| Host Git I/O | Outcomes are requests only |
| Destructive | Confirm phase; **Cancel** default; `y` unbound |
| Density=None | Derives from last paint width; Tab clamps to visible panes |
| Esc | Peels fullscreen / returns to files / root Cancelled |

## Second-pass design review

**Decisions**

1. Pattern peer to Agent/Database workbench — composition, not a Git client.
2. FileTree west + DiffReview center (`show_tree(false)`) — avoid double file trees.
3. CheckpointTimeline for commit history (host projects SHA/subject as checkpoints).
4. Workbench-owned discard/checkout/delete confirm separate from DiffReview decision confirm.
5. Density law mirrors DatabaseWorkbench (`last_area_width` + clamp).

**Rejected**

- Embedding `git2` / spawning `git` inside TermRock.
- Cloning lazygit keybinds 1:1.
- Holding index truth in the workbench (host owns).

**Residual limits**

- Commit message UI is draft string + chord (not full editor surface).
- Branch list is workbench-painted (not a separate public BranchList widget).
- DiffReview multi-unit destructive confirm still surfaces as `Diff(ConfirmRequired)`.
- PTY not required; unit + structural gates cover interaction.
