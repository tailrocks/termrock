# 0185 — List as composable collection view

## Mission

Redesign List from a label-oriented control into a **composable collection
view**: leading, primary, secondary, status, badge, trailing actions, shortcut,
group headers, separators, and custom row bodies. State is CollectionState +
SelectionModel (via Selection) + roving typeahead + scroll/virtualization.
Single / multi / range selection, search strip, density, and formal narrow drop
order. Keys go through semantic intents first; printable chars feed typeahead.

Research: lazygit lists, Yazi, Textual ListView, shadcn command items.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `List::new` / `from_system` / `focused` / `empty_message` | **Preserved** |
| `ListRow::item` / `separator` / builders | **Preserved** + extended |
| `ListState` selection, multi, offset, hover, click | **Preserved** |
| `CollectionState` / `enable_multi_select` | **Preserved** (`enable_multi_select` → Range mode) |
| `default_list_intent` path | **Preserved** + typeahead fallback |
| `RowRole::Item` / `Separator` | **Preserved** |
| `RowRole::GroupHeader` | **Added** |
| `ListRow::{status, actions, custom}` | **Added** |
| `ListDensity` Compact / Comfortable | **Added** |
| `ListSelectionMode` Single / Multi / Range | **Added** |
| Typeahead labels + `/` search strip | **Added** |
| `filter_list_rows` / virtual window / ScrollArea sync | **Added** |
| `LIST_NARROW_DROP_ORDER` | **Added** (documented drop priority) |
| Direct raw KeyCode maps outside intents | **Migrated** — Shift+Space / `/` / typeahead only remain as specialized paths |

`ListRow` struct gained fields: host struct-literals must set
`status` / `actions` / `custom` (prefer builders).

## Consumer edits

```diff
  use termrock::widgets::{List, ListRow, ListState};
+ use termrock::widgets::{ListDensity, ListSelectionMode, filter_list_rows};

  let rows = [
+     ListRow::group_header("g", Line::from("Running")),
      ListRow::item("a", Line::from("Build"))
          .secondary(Line::from("src"))
+         .status(Line::from("ok"))
+         .actions(Line::from("⏎"))
          .shortcut("b"),
+     ListRow::item("c", Line::from("x")).custom(Line::from("full custom line")),
  ];
  let mut state = ListState::new(Some("a"));
+ state.set_selection_mode(ListSelectionMode::Range);
  // Typeahead: printable keys jump by primary label
  // Search: '/' then chars; host may filter:
+ let q = state.search_query().unwrap_or("");
+ let view: Vec<_> = filter_list_rows(&rows, q).into_iter().cloned().collect();

  List::new(&rows, &system)
+     .comfortable() // or .density(ListDensity::Comfortable)
      .empty_message(Line::from("No items"));

  // Virtualized window:
+ state.set_virtual_window(window_start, total_len);
```
