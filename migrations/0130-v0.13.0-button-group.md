# 0130 — ButtonGroup

## Mission

Grouped actions with connected/separated recipes, primary/secondary ordering,
overflow menu, destructive separation, roving focus (per-command identity),
loading/disabled children, and default action submission (Enter).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ActionBar` / `Action` / `ActionBarState` | **Preserved** — simple dialog strips |
| `Toolbar` | **Preserved** — rich command strips |
| `Button` / `ButtonVariant` | **Preserved** — faces painted via Button |
| Dialog `ActionBar` footer | **Preserved** (migrate to ButtonGroup when overflow/default needed) |
| `ButtonGroup`, items, recipes, outcomes | **Added** |

## API sketch

```rust
use termrock::widgets::{
    ButtonGroup, ButtonGroupItem, ButtonGroupState, ButtonGroupOutcome,
};

let items = [
    ButtonGroupItem::new("cancel", "Cancel"),
    ButtonGroupItem::destructive("delete", "Delete"),
    ButtonGroupItem::primary("save", "Save"),
];
let mut state = ButtonGroupState::new();
state.set_surface_focused(true);

ButtonGroup::new(&items, &system)
    .separated() // or .connected()
    .paint(area, buf, &mut state);

match group.handle_key(&mut state, key) {
    ButtonGroupOutcome::Activated { id } => { /* effect */ }
    ButtonGroupOutcome::OverflowOpened => { /* host menu of parts.overflow_ids */ }
    _ => {}
}
```

## Behavior

| Concern | Rule |
|---------|------|
| Enter | Activates **default** (`is_default` / Primary) |
| Space | Activates **roving cursor** |
| Narrow width | Low-priority → overflow `…`; primary kept |
| Destructive | Own variant; never `is_default` |
| Vertical | Explicit `.orientation(Vertical)` — all visible, no overflow |
| Auto-stack | Opt-in via `.stack_below(n)` (default **0** / off) |
| Connected | 1-col `│`/`|` separators between faces |
| Overflow menu | Host paints menu from `parts.overflow_ids`; `activate_overflow` |
