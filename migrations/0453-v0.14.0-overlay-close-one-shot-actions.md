# 0453: Drawer and Popover physical one-shot close actions

## Boundary

The raw keyboard adapters for `DrawerState` and `PopoverState` close overlays
with bare Escape. A held Escape must not emit duplicate close requests.

## Change

- Drawer and Popover bare Escape now require a single `Press` event.
- Release and repeat Escape events are ignored before close state changes.
- Drawer bracket resize keys remain repeatable for held-key resizing.
- Semantic cancel/close intents and overlay-stack dismissal remain unchanged.

## Host migration

Hosts routing raw Drawer or Popover keyboard events must pass complete
`KeyEvent` values, including lifecycle kind. Do not synthesize repeated close
requests from `Repeat` or `Release` events. Use semantic cancel/close intents
for non-physical commands.
