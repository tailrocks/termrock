# 0118 — Badge semantic status indicator

## Mission

Compact status / category indicator with strong semantic discipline: neutral,
info, success, warning, destructive, outline, and count variants; interactive
focus/select only when opted in; quiet paint (no default fill) for dense
tables; no-color glyphs from the semantic catalog; narrow truncation and
large-count clamping.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Badge::new(label, system)` | **Migrated** — richer builder; still valid |
| `Badge::role(Role)` | **Deleted** — use `variant` / convenience methods |
| `Tag` / `Chip` | **Preserve** — removable / toggle chips, not badges |
| `Panel`/`Card`/`ComposedRow` badge slots as `&str` / `Line` | **Preserve** data; paint may compose `Badge` |
| `BadgeVariant`, `BadgeFill`, `BadgeCount`, `BadgeState`, outcomes | **Added** |
| Module | **Split** — `widgets/badge.rs` (was inline in `primitives`) |

## API sketch

```rust
use termrock::widgets::{Badge, BadgeState, BadgeVariant, BadgeFill};

// Static status (table / task)
Badge::new("live", &system).success().paint(area, buf, None);
Badge::new("beta", &system).outline().paint(area, buf, None);
Badge::count(150, &system).paint(area, buf, None); // (99+)

// Optional soft fill (rare — dense views stay quiet by default)
Badge::new("hot", &system).destructive().soft();

// Interactive filter chip-like badge
let mut state = BadgeState::new();
state.set_focused(true);
let b = Badge::new("filter", &system).interactive(true).neutral();
b.paint(area, buf, Some(&mut state));
let out = b.handle_key(&mut state, key); // Activated when Enter
```

## Variants

| Variant | Role / cue |
|---------|------------|
| Neutral | TextMuted |
| Info | Info + info glyph |
| Success | Success + ✓ |
| Warning | Warning + ! |
| Destructive | Danger + error glyph |
| Outline | Border, `⟨…⟩` |
| Count | Muted, `(n)` / `(99+)` |

## Behavior

| Flag | Applies when |
|------|----------------|
| focused / selected | `interactive(true)` only |
| disabled | blocks activation |
| fill Soft | opt-in underlay |
| max_cols | truncation budget |
