## Removed surface

None. Additive public API only. Existing widgets keep their contracts.

  `PromptBox`, `Timeline`, `TokenMeter`, `ThinkingBlock`

## Consumer edits

Prefer TermRock experience widgets over local chrome for:

- agent conversation streams and tool/approval cards
- empty/loading/error surfaces
- jump-mode and command palette shells
- multi-region work surfaces (`WorkSurface` / `layout_agent_shell`)
- density charts

Register Esc layers through `EscCascade` and overlay z-order through `OverlayHost`
instead of ad-hoc stacks.

## Ownership

TermRock owns paint, non-color status glyphs, layout geometry, and semantic
outcomes. Callers own domain text, filtering, permissions policy, tool execution,
and persistence.
