# 0101 — UiContext / UiHost

## Mission

Per-frame coordination object shared by TermRock components without replacing
Ratatui immediate-mode `Frame`/`Buffer` painting.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DesignSystem`, `InteractionScene`, `FocusGraph`, `OverlayStack`, `SemanticScene`, `FrameClock`/`FrameTick` | **Preserve** — UiContext borrows them |
| `Keymap`, `TerminalCapabilities`, `CapabilityBoundary` | **Preserve** — optional on host |
| `termrock::context::{UiHost, UiContext}` | **Added** |
| Lookbook `HostFrame` | **Preserve** (gallery-specific); maps 1:1 to UiHost authorities |
| Mandatory retained widget DOM | **Not added** |

## API

```rust
use termrock::context::{UiHost, UiContext, adapters};
use termrock::style::DesignSystem;

let mut host = UiHost::<MyId, MyLayer>::test_with_design(DesignSystem::phosphor());
// ensure root layer once…
loop {
    let mut ctx = host.begin_frame();
    // paint with Ratatui Frame + ctx.design()
    // register interactive elements on ctx.scene_mut()
    // register semantics on ctx.semantics_mut()
    // Esc: adapters::route_escape(&mut ctx)
}
```

### Testing

```rust
let tick = FrameTick::manual(now, elapsed, delta);
let mut ctx = host.begin_frame_at(tick);
```

### Nested composition

Pass `&mut UiContext` (or only `ctx.design()` / `ctx.scene_mut()`) into children.
No retained tree — children register for the current frame only.
