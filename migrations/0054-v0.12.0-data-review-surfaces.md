# 0054 — Scalable data and review surfaces (Plan 052)

## Additions

| Surface | Notes |
|---------|--------|
| `ScrollArea`, `ScrollAreaState` | Shared scroll grammar |
| `DataTable`, `DataTableState` | Toolbar, stripes, bulk **SelectAllRequested** (no unload scan) |
| `ObjectInspector` | Field projection + activate outcomes |
| `LogStream` | Follow/detach + levels |
| `DiffReview` | Hunk navigation requests |

`data_view` kits (`VirtualWindow`, `ColumnModel`, `SelectionModel`, `LoadState`) remain the model foundation.

## Performance

DataTable/LogStream paint **O(visible)** projected rows only. Ctrl-A emits `SelectAllRequested` without inventing virtual rows.
