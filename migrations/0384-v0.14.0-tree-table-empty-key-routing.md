# 0384: TreeTable routes empty virtual keys

## Boundary

TreeTable key handling must preserve vertical virtual scrolling while a
partial projection is empty.

## Change

`handle_key` now routes recognized vertical and page intents before the
row-indexed action guard. Non-navigation keys still return `Ignored` without
indexing an empty row slice.

## Consumer impact

No consumer edit is required. PageUp, PageDown, Up, and Down work through
empty virtual projections using the existing semantic intent contract.
