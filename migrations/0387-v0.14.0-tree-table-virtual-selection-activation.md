# 0387 — v0.14.0 TreeTable virtual selection and activation identity

## Boundary

Reconciliation preserves a selected ID outside a partial virtual slice and
clamps only the local cursor. A full projection still repairs a removed
selection. Keyboard activation additionally requires the visible cursor ID to
match the selected ID, preventing stale indices from activating another row.

## Consumer impact

No host API changes. Hosts can reproject a virtual window without losing an
off-window selection or activating a row that merely reused its old index.
