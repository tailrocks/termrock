# 0175 — NotificationCenter

## Mission

Persistent history and action surface for application notifications: unread,
grouping, filtering, timestamps, actions, progress, source, dismissal, clear-all.
Persistence is application-owned. Integrates with Toast via `ToastArchive` without
duplicating kind/archive models. Drawer and full-page recipes. High-volume dedup
and accessibility status lines.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `ToastKind`, `ToastPriority`, `ToastArchive`, `ToastArchiveReason` | **Preserved** (shared models) |
| `ToastQueue::drain_missed` / `missed` | **Preserved** (ingest path) |
| `Drawer` / `OverlaySpec::drawer` | **Preserved** (placement for drawer recipe) |
| Prior NotificationCenter widget | **None** (greenfield) |
| `NotificationCenter`, state, filter, recipes, overlay helpers | **Added** |
| Host ad-hoc history lists | **Migrate** → `NotificationCenter` + host store |

## Consumer edits

```diff
+ use termrock::widgets::{
+     NotificationCenter, NotificationCenterState, NotificationItem, NotificationRecipe,
+     NotificationFilter, example_notifications, open_notification_center_overlay,
+     ToastQueue,
+ };

  // Toast → center
  let missed = toast_queue.drain_missed();
+ let mut center = NotificationCenterState::new();
+ center.set_recipe(NotificationRecipe::Drawer); // or FullPage
+ let _ = center.ingest_archives(missed, now_secs);
+ // or: center.ingest_from_toast_queue(&mut toast_queue, now_secs);

  // Host persistence (app-owned):
+ let snapshot = center.items().to_vec();
+ // … save snapshot …
+ center.replace_items(loaded);

+ let _ = center.open();
+ // Overlay optional:
+ let _ = center.open_on_stack(&mut stack, bounds, Some("status"));
+ NotificationCenter::new(&system).paint(area, buf, &mut center);

  // Keys: j/k · enter open · u read · U all-read · x dismiss · c clear · / filter · esc
```
