# 0452: NotificationCenter physical one-shot actions

## Boundary

`NotificationCenterState::handle_key` is the raw physical keyboard adapter
for notification navigation and actions. A held key must not repeat host-facing
activation, dismissal, read-state, filter, clear, action, or close outcomes.

## Change

- Enter, Escape, mark-read, mark-all-read, dismiss, clear, filter, and item
  action shortcuts now require a single `Press` event.
- Repeat remains supported for list navigation, so held arrows continue to
  move through notifications.
- Semantic `handle_intent` remains phase-free and continues to provide
  keymap-friendly navigation, activation, and cancellation.

## Host migration

Hosts routing raw notification-center events must pass complete `KeyEvent`
values, including lifecycle kind. Do not synthesize repeated activation,
dismissal, read-state, filter, clear, item-action, or close outcomes from
`Repeat` or `Release` events.
