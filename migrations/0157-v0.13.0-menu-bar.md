# 0157 — MenuBar

## Mission

Desktop-style top-level menus for command-rich applications: nested cascades,
mnemonics, checked/radio rows, separators, shortcuts, recent items, dynamic
host-owned commands, OverlayStack placement, and narrow CommandPalette
replacement.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Menu` / `MenuItem` / `MenuState` / `MenuOutcome` / `ContextMenu` | **Preserved** — flat popup / context menus |
| Drawer / Popover / Tooltip + helpers in `menu_nav` | **Preserved** |
| `OverlayStack` `Menu` / `ContextMenu` kinds | **Preserved** — MenuBar cascade uses `OverlaySpec::menu` + `with_parent` |
| `CommandPalette` | **Preserved** — narrow replacement target via `PreferCommandPalette` + `flatten_menu_commands` |
| `MenuBar*` hierarchy, cascade state, overlay helpers | **Added** (greenfield) |
| Prior MenuBar widget | **None** |

## Consumer edits

```diff
+ use termrock::widgets::{
+     MenuBar, MenuBarMenu, MenuBarOutcome, MenuBarState, MenuNode,
+     example_app_menus, flatten_menu_commands, open_menu_bar_overlay,
+     dismiss_menu_bar_overlays,
+ };

+ let menus = example_app_menus(); // or host-built MenuBarMenu tree
+ let mut state = MenuBarState::new();
+ state.set_focused(true);
+ state.set_opener_focus_hint(Some("main-pane".into()));
+
+ match state.handle_key(key, &menus) {
+     MenuBarOutcome::Activated { id, command } => host.run(command.as_deref().unwrap_or(id)),
+     MenuBarOutcome::CheckToggled { id, checked } => host.set_check(id, checked),
+     MenuBarOutcome::RadioSelected { id, group } => host.set_radio(&group, id),
+     MenuBarOutcome::PreferCommandPalette => {
+         let cmds = flatten_menu_commands(&menus);
+         host.open_palette(cmds);
+     }
+     MenuBarOutcome::Closed => host.restore_focus(state.opener_focus_hint()),
+     MenuBarOutcome::LayerClosed => { /* keep cascade; Esc peeled one panel */ }
+     _ => {}
+ }
+
+ // paint bar row + optional panels (or place panels via OverlayStack)
+ let bar = Rect::new(0, 0, width, 1);
+ MenuBar::new(&menus, &system).paint_all(bar, bounds, buf, &mut state);
+
+ // OverlayStack cascade (nested dismiss restores opener on root dismiss):
+ open_menu_bar_overlay(&mut stack, bounds, anchor, size, Some(focus_id));
+ open_menu_bar_submenu_overlay(&mut stack, bounds, sub_anchor, size, 1, Some(focus_id));
+ // Esc → top layer only; dismiss_menu_bar_overlays → root + children + focus
```

### Keys (platform-neutral mnemonics)

| Key | Behavior |
|-----|----------|
| Left / Right (closed) | Rove top-level menus |
| Enter / Down / Space (closed) | Open active top menu |
| Up / Down (open) | Rove items (skips disabled / separators) |
| Right / Expand on submenu | Open nested panel |
| Left / Esc | Close one cascade layer |
| Esc at root open | Full close (`Closed`) — restore focus |
| Alt+letter | Open matching top mnemonic (when terminal delivers Alt) |
| Ctrl+Shift+M | Sticky mnemonic mode toggle (portable fallback) |
| Host F10 | Map to `set_mnemonic_mode(true)` — TermRock `KeyCode` has no F-keys |
| Letter while armed / in panel | Activate matching item mnemonic |
| Narrow (`≤40` cols) | Chip → `PreferCommandPalette` |

### Stories

- `menu-bar/basic`, `open`, `nested`, `mnemonic`, `narrow`, `unicode`, `ascii`
