# 0095 — Surface (lowest-level visual ownership)

## Mission

Canonical fill, padding, border, clip, and hit geometry primitive. Recipes cover
canvas through destructive chrome without nested box soup. Compatible with
terminal-default backgrounds and monochrome/no-color.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Surface` widget | **Redesigned** in `widgets/surface.rs` |
| Legacy elevation enum | **Deleted** — use `SurfaceRecipe` directly |
| New `SurfaceRecipe` (12 recipes) | **Added** |
| New `SurfaceFill`, `SurfaceParts`, `SurfacePaintPlan` | **Added** |
| `DesignSystem::surface_recipe` | **Added** |
| `Panel` | **Migrated** — fill via Surface; title border still Panel-owned |
| Ad hoc `Block::bordered` fillless hosts | **Migrate** reps to Surface when fill/hit/clip needed |
| `Role::{Canvas,Surface,Elevated}` | **Preserve** — recipe paint sources |
| Nested Surface-in-Surface patterns | **Avoid** — one Surface per region |

## Recipes

| Recipe | Fill | Border default |
|--------|------|----------------|
| `Canvas` | `Color::Reset` (terminal default) | no |
| `Inset` | `Role::Surface` if non-empty | no |
| `Sunken` | `Role::Sunken` if non-empty | no |
| `Raised` | `Role::Raised` if non-empty | yes `Border` |
| `Overlay` | Elevated | yes `Border` |
| `OverlayFocused` | Elevated | yes `BorderFocused` + bold |
| `OverlayDanger` | Elevated | yes `Danger` + bold |
| `Interactive` | Surface | yes `Border` |
| `Focused` | Surface | yes `BorderFocused` + bold |
| `Selected` | Selection tint | yes `Border` + bold; Collection membership |
| `Warning` | Surface | yes `Warning` + bold structural cue |
| `Destructive` | Surface | yes `Danger` + bold |

Phosphor uses terminal reset plus named ANSI-16 black for its surface ladder;
it never forces RGB. `terminal_native` leaves the ladder empty when the host
must inherit terminal backgrounds. Slate and other palettes may supply explicit
elevation backgrounds.

## Clipping & hit

- `SurfaceParts::{content,clip}` — legal paint rect for children (hosts must not write outside).
- `SurfaceParts::hit` — mouse region (full root for interactive/bordered; content for passive inset).
- Terminals cannot hard-clip; clip is a contract, not a buffer mask.

## Consumer edits

```rust
use termrock::widgets::{Surface, SurfaceRecipe, SurfaceFill, SurfaceParts};
use termrock::style::DesignSystem;

let system = DesignSystem::default();

// Preferred:
let content = Surface::new(&system)
    .recipe(SurfaceRecipe::Focused)
    .paint(area, buf);
// paint children into `content` only

// Geometry without paint:
let parts: SurfaceParts = Surface::new(&system)
    .recipe(SurfaceRecipe::Raised)
    .padding(1, 1)
    .layout(area);
assert!(parts.clip == parts.content);

// Elevation is expressed directly as a recipe; no compatibility enum exists:
Surface::new(&system).recipe(SurfaceRecipe::Raised);

// Terminal-default / no-color:
Surface::new(&system)
    .recipe(SurfaceRecipe::Canvas)
    .fill(SurfaceFill::TerminalDefault);
```

```rust
// Panel: emphasis → SurfaceRecipe (Inset / Focused / Destructive)
let panel = Panel::new(&system).title("T").chrome(PanelChrome::Focused);
// render paints Surface fill then titled border
```
