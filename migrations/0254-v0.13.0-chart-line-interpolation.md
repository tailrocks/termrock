# 0254 — Chart line interpolation (linear / step)

## Mission

Close shadcn **line** chart path variants (`chart-line-linear`, `chart-line-step`):
public X-path interpolation on `Chart` without dual paint APIs.
Matrix: `docs/design/shadcn-line-charts-coverage.md`.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Chart` default nearest columns | **Preserved** — `ChartInterpolation::Nearest` |
| Multi-series / selection / legend / axes | **Preserved** |
| `ChartInterpolation` · `Chart::linear` · `Chart::step` · `interpolation` | **Added** |

## Consumer API

```rust
use termrock::widgets::{Chart, ChartSeries, ChartInterpolation};

let series = [ChartSeries::new("s", &samples)];
// Default nearest
Chart::new(&series, &system).render(area, buf);
// Linear lerp (chart-line-linear)
Chart::new(&series, &system).linear().render(area, buf);
// Step hold (chart-line-step)
Chart::new(&series, &system)
    .interpolation(ChartInterpolation::Step)
    .render(area, buf);
```
