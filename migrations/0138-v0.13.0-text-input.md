# 0138 — TextInput production editor

## Mission

Production single-line editor: grapheme-safe edits, selection, undo/redo, word
movement, horizontal scroll, placeholder, prefix/suffix, clear action,
validation, secret mask, disabled/read-only/loading, host clipboard outcomes,
intent routing, mouse caret placement, Unicode fuzz, long-input hot path.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput::new` / `placeholder` / `validation` / `label` | **Preserved** |
| `TextInputState::new` / `value` / `insert_str` / `clear` / `validity` | **Preserved** |
| `TextInputOutcome::{Ignored,Changed,Submitted,Cancelled}` | **Preserved** |
| `EditAction::{Insert,Backspace,Delete}` | **Preserved** |
| `EditAction::MoveLeft` unit | **Migrated** → `MoveLeft { select }` or `move_left()` |
| `EditAction::MoveRight` / `Home` / `End` | **Migrated** → struct variants / helpers |
| Selection, undo/redo, word moves, clipboard outcomes | **Added** |
| `prefix` / `suffix` / `secret` / `show_clear` / `paint` / `parts` | **Added** |
| `edit_core` word boundaries | **Added** |
| `TextArea` | **Preserved** — multi-line editor |

## Consumer edits

```diff
- state.apply(EditAction::MoveLeft);
+ state.apply(EditAction::move_left());
// or
+ state.apply(EditAction::MoveLeft { select: false });
```

```rust
// Clipboard (host policy)
match state.handle_key(key) {
    TextInputOutcome::ClipboardCopy { text } => host.copy(text),
    TextInputOutcome::ClipboardCut { text } => host.copy(text),
    TextInputOutcome::ClipboardPasteRequest => {
        let _ = state.insert_str(&host.paste());
    }
    TextInputOutcome::Changed => { /* repaint */ }
    _ => {}
}

// Secret + chrome
TextInput::new("Password", &system)
    .secret(true)
    .prefix("🔑")
    .show_clear(true)
    .paint(area, buf, &mut state);
```

## Default key adapter (Emacs-style)

| Chord | Action |
|-------|--------|
| ←→ / Home/End | Move (±Shift select) |
| Ctrl/Alt+←→ | Word move |
| Ctrl+A / C / X / V | Select all / copy / cut / paste request |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | Undo / redo |
| Ctrl+W / Ctrl+Backspace | Kill word backward |
| Enter | Submit if valid |
| Esc | Cancel |

Hosts may replace with keymap packs via `handle_intent` + custom action routing.
