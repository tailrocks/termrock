# 0063 — Agent dual chrome cutover (Break J partial / Prompt + Permission)

## Removed surface

| Removed | Replacement |
|---------|-------------|
| `ApprovalCard`, `ApprovalCardState`, `ApprovalCardOutcome` | `PermissionPrompt`, `PermissionPromptState`, `PermissionOutcome` |
| `ApprovalDecision`, `ApprovalDecisionRegion`, `ApprovalRisk` | `PermissionAction`, `PermissionRisk`, request/provenance model |
| `PromptBox`, `PromptBoxState`, `PromptBoxOutcome` | `PromptComposer`, `PromptComposerState`, `PromptComposerOutcome` |
| `AgentWorkbenchState::approval_open` | `permission_open` |
| `WorkbenchSurfaces::approval` + `PromptBox` fields | `permission` + `PromptComposer` fields |
| `WorkbenchSurfaces::tokens` | `system` (`&DesignSystem`) |
| Lookbook stories `approval-card/*`, `prompt-box/*` | `permission-prompt/*`, `prompt-composer/*` |

**Deferred:** `StreamView` remains public until stream/Transcript sole path (rest of Break J).

## Canonical replacement

```rust
use termrock::patterns::{
    AgentWorkbenchState, WorkbenchSurfaces, render_agent_workbench, default_modes,
};
use termrock::style::DesignSystem;
use termrock::widgets::{
    PermissionPrompt, PermissionPromptState, PermissionRequest, PermissionRisk,
    PromptComposer, PromptComposerState, Transcript, TranscriptState, /* … */
};

let system = DesignSystem::default();
let mut workbench = AgentWorkbenchState::new();
let mut prompt_state = PromptComposerState::new();
let mut permission_state = PermissionPromptState::new();
let _ = permission_state.enqueue(
    PermissionRequest::new("r1", "bash", "workspace")
        .risk(PermissionRisk::High)
        .command("cargo test"),
);

// Paint
render_agent_workbench(buf, area, WorkbenchSurfaces {
    system: &system,
    state: &mut workbench,
    tasks: &tasks,
    modes: &modes,
    transcript: &transcript,
    transcript_state: &mut tstate,
    prompt: &PromptComposer::new(&system),
    prompt_state: &mut prompt_state,
    status_slots: &slots,
    status_state: &mut sstate,
    permission: Some((&PermissionPrompt::new(&system), &mut permission_state)),
    question: None,
});

// Keys (permission layer wins when open)
let _ = workbench.handle_key(key, &tasks, &mut prompt_state, Some(&mut permission_state));

// Esc peels scene layer; also route Esc into permission to cancel queue
let _ = workbench.handle_escape();
```

Intent-friendly permission navigation:

```rust
use termrock::interaction::{UiIntent, default_permission_intent};
if let Some(intent) = default_permission_intent(key) {
    let _ = permission_state.handle_intent(intent);
}
```

## Consumer edits

1. Replace every `ApprovalCard*` import with `PermissionPrompt*` + `PermissionRequest` builder.
2. Replace every `PromptBox*` import with `PromptComposer*`.
3. Rename workbench `approval` / `tokens` / `approval_open` as above.
4. Remove lookbook/story references to deleted story ids.
5. Do **not** reintroduce `y`→Allow shortcuts — PermissionPrompt never grants on `y`.

## What becomes simpler

One fail-safe trust law, one agent prompt law, one workbench seed path.

## New constraints

- Agent demos and patterns must not import deleted types (policy tests enforce workbench + `agent.rs`).
- Permission Esc cancels without decide; scene peel does not grant.
