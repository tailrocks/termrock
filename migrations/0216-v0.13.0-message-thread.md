# 0216 — MessageThread

## Mission

Virtualized conversation and activity transcript for long-running agent
sessions: user, assistant, system, tool, status, compact event, and error
entries; stable anchors; grouping; timestamps; actors; actions; selection; copy;
and search. Preserve reading position while streaming; new-content indicator
when not following tail. Collapsed tool/activity entries and semantic zoom.
Virtualize long sessions; compact old content without losing checkpoints. Avoid
chat-bubble web imitation (editorial project-to-lines over Transcript).

Research: Amp, OpenCode, Grok Build, Claude Code, editorial Markdown TUIs.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Transcript` / `TranscriptState` / `TranscriptBlock` / `TranscriptKind` | **Preserved** — virtualization substrate |
| `AgentWorkbench` center pane | **Preserved** — may still paint `Transcript` directly; MessageThread is preferred pack |
| ThinkingBlock / ToolCard paint | **Preserved** — host may project into lines; not nested in viewport v1 |
| Nested StatefulWidgets in thread | **Out of scope v1** (AD-1) |
| Network / agent run I/O | **Never TermRock** |
| `MessageThread*` · projection helpers · compact | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    MessageEntry, MessageKind, MessageThread, MessageThreadState, MessageThreadOutcome,
    MessageZoom, MessageActor, example_message_session, compact_entries,
};

let mut entries = example_message_session();
let mut state = MessageThreadState::new();
state.set_focused(true);
state.on_entries_len(entries.len()); // stream append accounting

// paint (project-to-lines over Transcript)
MessageThread::new(&entries, &system).paint(area, buf, &mut state);

// keys
let proj = state.projection(&entries);
let mut ptrs = Vec::new();
let blocks = proj.blocks(&mut ptrs);
match state.handle_key(key, &entries, &blocks) {
    MessageThreadOutcome::Activated { id } => {
        state.set_expanded(&id, true); // unfold tool
    }
    MessageThreadOutcome::CopyRequested { id } => { /* host clipboard */ }
    MessageThreadOutcome::JumpLatest => {}
    MessageThreadOutcome::ActionRequested { id, action } => { /* retry/cancel */ }
    _ => {}
}

// streaming: append entry, then
entries.push(MessageEntry::assistant("a9", "delta…"));
state.on_entries_len(entries.len()); // unread if not following

// compact old without losing checkpoints
entries = compact_entries(&entries, 200);
```

### Keys

| Key | Action |
|-----|--------|
| j/k · page | Select / scroll (Transcript) |
| Enter | Activate (expand / host detail) |
| Ctrl+F | Fold toggle |
| Ctrl+Z | Cycle zoom Compact→Summary→Full |
| Ctrl+N | Jump latest when unread |
| / | Search filter |
| r / x | Retry / cancel on tool/error |
| Ctrl+C | Copy selected |
