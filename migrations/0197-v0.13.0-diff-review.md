# 0197 — DiffReview interactive patch review

## Mission

Interactive review behavior on top of DiffView: file tree, hunk and line-range
selection, comments, approve/reject/apply decisions, staging-like actions,
external editor, and review summary. Version-control / plan / agent policy stays
consumer-owned. Comments and selection key by stable ids across mode/resize.
Safe destructive language + undo for session review ops.

Research: GitHub reviews, lazygit staging, Grok Build plan review, agent diff
approval.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DiffView` / `DiffLine` / `DiffHunk` | **Preserved** — paint + nav substrate |
| `DiffReviewState.view` | **Preserved** — embeds `DiffViewState` |
| Hunk cursor / Enter activate | **Preserved** |
| `DiffReview` thin veneer only | **Migrated** — full workbench chrome |
| `DiffReviewOutcome` view-forward only | **Extended** — decisions, comments, confirm, undo, editor |
| `DiffDecision`, `DiffReviewUnit`, `DiffComment*` | **Added** |
| `DiffReviewFileRow`, `DiffReviewRegion`, summary | **Added** |
| `diff_review_bench` | **Added** |
| VCS/git/apply execution | **Never in TermRock** — request outcomes only |
| Space → DiffView mode Toggle | **Migrated** — Space selects hunk; `v` cycles view mode |

## Consumer API sketch

```rust
use termrock::widgets::{
    DiffLine, DiffHunk, DiffReview, DiffReviewState, DiffReviewFileRow,
    DiffDecision, DiffReviewUnit, DiffComment, DiffCommentAnchor,
};

let files = [
    DiffReviewFileRow::new("a.rs", "src/a.rs").stats(3, 1),
];
let mut state = DiffReviewState::new();
// a approve · r reject (confirm if multi) · t stage · x apply · c comment
// Space select hunk · e editor · u undo · Tab region · v view mode
let out = state.handle_key_lines(key, &lines, &hunks, &files);
// Host: match StageRequested / ApplyRequested / ExternalEditorRequested …

DiffReview::new(&lines, &system)
    .hunks(&hunks)
    .files(&files)
    .title("PR #12")
    .render(area, buf, &mut state);
```

### Keys

| Key | Action |
|-----|--------|
| Tab / S-Tab | Focus file tree · diff · comments · summary |
| Space | Toggle hunk selection |
| S-Space | Toggle line selection |
| a / r | Approve / reject (bulk reject confirms) |
| t / T | Stage / unstage request |
| x | Apply request |
| c | Comment draft · Enter commits · Esc cancels |
| e | External editor request |
| u / C-z | Undo · U redo |
| v | Diff view mode cycle (Auto/Split/Unified) |
| n/p j/k | Hunk / line nav (DiffView) |
| Enter | Activate hunk or confirm banner |
