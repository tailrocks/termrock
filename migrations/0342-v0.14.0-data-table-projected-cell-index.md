# 0342: DataTable projected cells keep source-column identity

## Boundary

`DataTable` responsive layout may drop visible columns when the available
width is too small. The resolved paint list stores source declaration indexes;
body cells must use those same indexes when reading the host's row projection.

## Change

The body painter now reads `cells[col_idx]`, not `cells[paint_ord]`. A dropped
middle column therefore no longer shifts every later cell's displayed value.
The hit region and cursor ordinals remain visible-column ordinals for keyboard
and pointer navigation.

## Consumer impact

No consumer edit is required. Existing row projections remain in declaration
order, including values for columns omitted by responsive painting.
