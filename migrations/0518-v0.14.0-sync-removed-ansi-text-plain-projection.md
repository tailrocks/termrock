# 0518: Synchronize removed AnsiText plain projection

## Boundary

The dead-accessor sweep removed the unused `AnsiText::plain` projection. The
generated public API snapshot retained three duplicate signatures even though
the projection is no longer available.

## Change

Removed all three stale snapshot entries for `AnsiText::plain` deleted by
`855e4147`.

## Host migration

Use the supported `AnsiText::lines` data and its `AnsiLine::plain` fields when
plain text extraction is needed at the host boundary. No compatibility alias
or deprecation period is provided.
