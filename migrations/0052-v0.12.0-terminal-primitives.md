# 0052 — Terminal-native primitives, content, and feedback (Plan 050)

## Removed surface

None removed. New public primitives land beside existing feedback views.

## Canonical replacements / additions

| Surface | Module |
|---------|--------|
| `Button`, `IconButton`, `ActivationState`, `ActivationOutcome` | `termrock::widgets` |
| `Badge`, `Tag`, `Chip`, `Kbd`, `Separator`/`SeparatorLine`, `Spinner` | `termrock::widgets` |
| `Heading`, `Paragraph`, `Surface`, `Section`, `Callout`, `Alert` | `termrock::widgets` |

Existing `EmptyState` / `LoadingView` / `ErrorView` / `Skeleton` / `Progress` remain; new surfaces compose DesignTokens recipes and typed outcomes.

## Consumer edits

```rust
use termrock::style::DesignTokens;
use termrock::widgets::{Button, ButtonState, ActivationOutcome};

let tokens = DesignTokens::default();
let mut state = ButtonState::new();
state.activation.set_focused(true);
Button::new("Save", &tokens).render(area, buf, &mut state);
```

## Ownership

TermRock owns activation law, chrome recipes, non-color glyphs. Consumers own labels, domain effects on `Activated`.

## Validation

```bash
cargo test -p termrock --lib primitives content
```
