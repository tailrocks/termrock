# 0347: DataTable edit mode owns semantic intents

## Boundary

While an inline edit is active, navigation and row actions must not bypass
the edit lifecycle. Submit and cancel are the only semantic intents that may
complete that lifecycle.

## Change

`DataTableState::handle_intent` now routes Submit through the same typed commit
path as Enter, Cancel through the draft-clearing cancel path, and ignores
movement, activation, selection, expansion, and unrelated intents while
editing. Invalid loading states cancel the edit instead of operating on stale
rows.

## Consumer impact

Consumers may send `UiIntent::Submit` or `UiIntent::Cancel` directly while an
edit is active. Other semantic intents return `Ignored` until the edit ends.
