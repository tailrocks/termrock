# 0408 — v0.14.0 remove legacy layout and input aliases

## Breaking change

Remote commit `6d29e86e` removes obsolete public layout and input aliases.
Migrate callers to the canonical APIs; no compatibility shims remain.

## Center dialog layout

`CenterSpec::dialog(width, height)` and `Center::dialog(width, height)` were
removed. Build the safe-margin layout explicitly with either canonical
constructor:

```rust
let spec = CenterSpec::new(width, height).safe_margin(true);
let center = Center::new(width, height).safe_margin(true);
```

Named recipes `Center::onboarding` and `Center::failure` remain available.

## Keyboard labels

`Kbd::from_chord_buf` was removed. It previously wrote into a caller-owned
`String` and returned a borrowed `Keycap` label. Use `Kbd::from_chord` for one
chord, `Kbd::from_chord_fmt` when supplying a chord format, and
`Kbd::sequence` for multiple chords. These constructors own their formatted
label; add `.keycap()` when the old Keycap appearance is required.

## Diff review mouse input

`DiffReviewState::handle_mouse` was removed. Call
`handle_mouse_lines(event, lines, hunks, files)` and provide the complete
visible line and file context.

## Documentation cleanup

Dead AnsiText legacy-performer comments were removed. Skeleton documentation
now describes `SkeletonLayout::lines` and `Skeleton::new` as canonical
staggered-line constructors; these wording cleanups require no code migration.
