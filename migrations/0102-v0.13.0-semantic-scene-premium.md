# 0102 — SemanticScene premium discovery APIs

## Mission

Lightweight semantic tree rebuilt every frame for hit-testing, focus navigation
aids, jump mode, help, Studio inspection, portable snapshots, and AI-readable UI
state — without owning focus (InteractionScene remains sole input authority).

## API sketch

```rust
use termrock::interaction::{SemanticScene, SemanticNode, SemanticRole, SemanticState};

let mut scene = SemanticScene::<&str, AppAction>::new();
scene.begin_frame();
scene.reserve(visible_len); // virtualized window only

scene.register(
    SemanticNode::content("list", list_area)
        .role(SemanticRole::List)
        .label("Files"),
)?;
scene.register_child(
    "list",
    SemanticNode::control("row0", row_area)
        .role(SemanticRole::ListItem)
        .label("a.rs")
        .state(SemanticState { selected: true, ..Default::default() })
        .actions(vec![AppAction::Open]),
)?;

// Hit / focus aids
let hit = scene.hit_test_focusable(pos);
let next = scene.focus_neighbor(Some(&"row0"), true, true);

// Jump mode
use termrock::widgets::assign_jump_badges_from_semantics;
let targets = assign_jump_badges_from_semantics(&scene);

// FocusGraph projection
for node in scene.to_focus_nodes() {
    focus_graph.register(node);
}

// Portable snapshot (remote / AI)
let text = scene.snapshot_with(|a| format!("{a:?}")).to_text();
let parsed = SemanticSnapshot::from_text(&text);
```

## Virtualized lists

Register **only visible rows** (`Virtualizer` / viewport), never `logical_len`.
Use `reserve(visible)` + `register_many`.
