# 0340 — One line-cell scrollbar painter

**Version:** `v0.14.0`  
**Kind:** breaking API + behavioral

Line-cell scrolling now has one authoritative painter:
`paint_overflow_scrollbar`. The legacy `paint_list_scrollbar` and
`paint_scrolled_region` entry points are removed; update hosts to call the
overflow painter directly and pass its focus state.

`gutter_column` centralizes the reserved final-column geometry. It returns the
one-column gutter for any content area, while callers remain responsible for
choosing the content rectangle and its vertical inset.

This removes the old subcell-rounded list painter from line widgets. Their
track and thumb now use the same full-cell geometry and canonical roles as
panel, picker, list, tree, text-area, table, and select scrolling.
