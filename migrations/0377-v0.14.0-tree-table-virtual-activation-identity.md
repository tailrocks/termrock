# 0377: TreeTable activation requires selected identity

## Boundary

TreeTable must not activate a visible row through a stale cursor index after a
virtual projection preserves a selected ID outside the current slice.

## Change

`Activate`, `Submit`, and `Open` now require the cursor row's ID to equal the
selected ID in addition to the row being selectable.

## Consumer impact

No consumer edit is required. Activation waits until the selected row is
projected instead of dispatching the wrong visible row.
