# 0196 — DiffView professional unified/split renderer

## Mission

High-quality read-only unified and side-by-side diff renderer: files, hunks,
line numbers, syntax spans, additions/deletions/context, whitespace markers,
word-level changes, folding, search, navigation. Narrow terminals force
unified. Large diffs virtualize with file/hunk anchors. Semantic roles +
no-color prefixes. Migrate and improve the previous DiffView; DiffReview
becomes a thin review veneer over the same model.

Research: delta, lazygit, GitUI, review tools, TermRock DiffView/DiffReview.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `DiffKind::{Context,Added,Removed}` | **Preserved** + **extended** (`FileHeader`, `HunkHeader`, `Meta`) |
| `DiffLine` | **Migrated** — builders + id, line nos, words, syntax, ws, file/hunk ids |
| `DiffState` | **Migrated** — type alias of `DiffViewState` |
| `DiffView` | **Redesigned** — unified/split, search, fold, anchors, chip chrome |
| `DiffHunk` | **Moved** to `widgets/diff.rs` (left `review`); builder API |
| `DiffReview` / `DiffReviewState` | **Migrated** — wraps `DiffView` / `DiffViewState` |
| `DiffReviewOutcome` | **Extended** — maps from `DiffViewOutcome` |
| `(text, Role)` DiffReview lines | **Deleted** — use `DiffLine` |
| Struct-literal `DiffLine { text, kind }` | **Migrated** — `DiffLine::new` / `::added` / `::removed` |
| `diff_bench` | **Added** |

## Consumer API sketch

```rust
use termrock::widgets::{
    DiffKind, DiffLine, DiffHunk, DiffMode, DiffView, DiffViewState,
    DiffWordKind, DiffWordSpan, diff_bench,
};

let words = [
    DiffWordSpan::new(DiffWordKind::Equal, "x = "),
    DiffWordSpan::new(DiffWordKind::Insert, "2"),
];
let lines = [
    DiffLine::file_header("f", "diff --git a/a.rs b/a.rs").file_id("a.rs"),
    DiffLine::hunk_header("h0", "@@ -1,1 +1,1 @@").hunk_id("h0"),
    DiffLine::removed("r1", "x = 1;").old_no(1).hunk_id("h0"),
    DiffLine::added("a1", "x = 2;").new_no(1).hunk_id("h0").words(&words),
];
let hunks = [DiffHunk::new(1, 3, "@@ -1,1 +1,1 @@").id("h0")];
let mut state = DiffViewState::new(); // Auto mode → split when wide
state.mode = DiffMode::Unified; // or Split / Auto
// n/p hunks, s mode, / search, z fold, l line-nos, w word-diff, . whitespace

DiffView::new(&lines, &system)
    .hunks(&hunks)
    .title("a.rs")
    .focused(true)
    .render(area, buf, &mut state);

// Review veneer (activate/stage):
// DiffReview::new(&lines, &system).hunks(&hunks).render(area, buf, &mut DiffReviewState::new());
```

### Keys

| Key | Action |
|-----|--------|
| j/k ↑↓ | Cursor / scroll |
| n/p | Next / previous hunk |
| Home/End | First / last hunk |
| Enter | Activate hunk (review) |
| s / Space | Cycle mode Auto→Split→Unified |
| / | Search |
| z | Fold current hunk |
| l | Toggle line numbers |
| w | Toggle word-diff paint |
| . | Toggle whitespace markers |
| h/← → | Horizontal scroll (unified) |
