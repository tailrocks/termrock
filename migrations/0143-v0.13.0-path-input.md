# 0143 — PathInput filesystem-aware field

## Mission

Path entry for setup flows and future FilePicker: completion hooks, tilde/env
presentation helpers, host-projected existence/type/risk status, base/relative
context, history, browse action — **without** coupling TermRock to a concrete
filesystem implementation or async runtime.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` | **Preserved** — path buffer composition |
| `SearchInput` history/clear patterns | **Preserved** (parallel design) |
| FilePicker | **Not yet** — will compose PathInput (P2) |
| Pure helpers `normalize_separators`, `join_path`, `expand_tilde`, … | **Added** |
| `PathInput*` / `PathFsStatus` / `PathRisk` / `PathExpect` / `PathStyle` | **Added** |

## Consumer edits

```rust
use termrock::widgets::{
    PathExpect, PathFsStatus, PathInput, PathInputOutcome, PathInputState, PathRisk, PathStyle,
};

let mut state = PathInputState::new()
    .with_style(PathStyle::Unix) // or PathStyle::native()
    .with_expect(PathExpect::Directory)
    .with_base("/workspace")
    .with_home("/home/user")
    .with_path("~/proj");
state.set_focused(true);

match state.handle_key(key) {
    PathInputOutcome::Changed => {
        // host: schedule async metadata lookup
        state.set_fs_status(PathFsStatus::Pending);
    }
    PathInputOutcome::LookupRequested { path }
    | PathInputOutcome::CompletionRequested { raw: path, .. } => {
        let _ = path;
        // host: std::fs / remote FS / sandbox — then:
        // state.set_fs_status(PathFsStatus::Directory);
        // state.set_risk(PathRisk::Normal);
    }
    PathInputOutcome::BrowseRequested => {
        // host: open FilePicker, then state.set_path(picked)
    }
    PathInputOutcome::Submitted { path } => {
        let resolved = state.resolved_against_base();
        let _ = (path, resolved);
    }
    _ => {}
}

// After host FS probe:
state.set_fs_status(PathFsStatus::File);
// Overwrite / system target:
state.set_risk(PathRisk::Destructive);

// Completion candidate from host:
state.apply_completion("main.rs");

PathInput::new(&system)
    .label("Install path")
    .show_browse(true)
    .ascii(true);
```

### Ownership boundary

| Concern | Owner |
|---------|--------|
| Typing, history, browse/complete *signals* | PathInput |
| `std::fs`, network FS, sandbox, permissions | Host |
| Existence / type / destructive risk | Host projection |
| Env var values / home directory string | Host injects |

### Keys

| Chord | Action |
|-------|--------|
| Tab | `CompletionRequested` |
| Ctrl+O / browse glyph | `BrowseRequested` |
| Enter | `Submitted` + history |
| Esc | `Cancelled` |
| Up/Down (empty or Alt) | history |
