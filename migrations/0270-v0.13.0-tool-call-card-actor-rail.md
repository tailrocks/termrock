# ToolCallCard actor rail and compact row

`ToolCallCard` now uses the shared tool-actor rail. Compact cards paint a
single-line disclosure, tool diamond, strong verb, and muted parenthetical
details. Expanded cards continue the rail and place output on the semantic
sunken surface. Running cards can animate their rail and dot pulse from a
host-owned deterministic tick.

## Consumer edits

Pass the same paint tick used by other active surfaces:

```rust
ToolCallCard::new(&call, &system)
    .tick(frame_tick)
    .paint(area, buffer, &mut state);
```

Remove consumer-owned tool diamonds, running pulses, accent gutters, and
output backgrounds. `ToolCallCard` now owns that chrome. Reduced-motion and
motion-off systems render a static running marker identical across ticks.
