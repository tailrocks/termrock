# 0402 — v0.14.0 EmptyState uses one stateful paint path

## Breaking change

`EmptyState::paint(area, buffer, &mut EmptyStateState)` is now the only paint
entry. The passive 2-argument paint, `paint_with_state`, stateless `Widget`
implementations, and dead `EmptyKind::title_role` API are removed. Paint and
measurement share one row projection across explanation, example, context,
actions, and the shortcut footer.

## Consumer impact

Retain the action-focus state and pass it to paint on every frame:

```rust
let mut state = EmptyStateState::new();
empty.paint(area, frame.buffer_mut(), &mut state);
```

The focused action now receives the selection marker and bold treatment from
the shared paint path.
