# 0140 — PasswordInput secure secret entry

## Mission

Secure single-line secret field derived from TextInput editing: masking, reveal
policy, paste controls, strength/status hooks, confirmation pairing, and
redaction from semantic scene, Debug, paint (when masked), and outcome payloads.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `TextInput` / `TextInputState` | **Preserved** — PasswordInput composes editor internally |
| `TextInput::secret` / `secret_mask` | **Preserved** — paint-only mask for demos; prefer PasswordInput for credentials |
| `PasswordInput` / `PasswordInputState` | **Added** |
| `RevealPolicy` / `ClipboardPolicy` / `PasswordStrengthHint` | **Added** |
| `PasswordConfirmState` | **Added** — password + confirm pair |
| `PasswordInputOutcome` | **Added** — never embeds secret string |
| `TextInputState::secure_clear` | **Added** — overwrite buffer + drop undo/redo snapshots |
| Lookbook `text-input/secret` | **Preserved** — demos paint mask only |
| Lookbook `password-input/*` | **Added** |

## Consumer edits

```diff
- // Prefer PasswordInput for real secrets
- let mut state = TextInputState::new("");
- TextInput::new("Password", &system).secret(true)
+ let mut state = PasswordInputState::new()
+     .with_reveal_policy(RevealPolicy::Explicit)
+     .with_clipboard_policy(ClipboardPolicy::PasteOnly);
+ state.set_focused(true);
+ match state.handle_key(key) {
+     PasswordInputOutcome::Submitted => {
+         let secret = state.take_secret(); // host owns; do not log
+     }
+     PasswordInputOutcome::ClipboardPasteRequest => {
+         let _ = state.insert_str(&host.paste());
+     }
+     PasswordInputOutcome::ClipboardDenied => { /* toast optional */ }
+     _ => {}
+ }
+ PasswordInput::new("Password", &system)
+     .placeholder("••••")
+     .strength(PasswordStrengthHint::Weak);
```

### Clipboard policy

| Policy | Copy/Cut outcome | Paste |
|--------|------------------|-------|
| `DenyAll` | `ClipboardDenied` | denied |
| `PasteOnly` (default) | `ClipboardDenied` | `ClipboardPasteRequest` |
| `AllowHostCopy` | `ClipboardCopyAllowed` (host calls `secret()`) | paste ok |

Outcomes never carry secret bytes. Hosts that copy must deliberately call
`secret()` after `ClipboardCopyAllowed`.

### Reveal policy

| Policy | Behavior |
|--------|----------|
| `Never` (default) | always masked |
| `Explicit` | Alt+R or reveal glyph toggle |
| `Hold` | Alt+H press/release |
