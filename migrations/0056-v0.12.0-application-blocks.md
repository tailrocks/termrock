# 0056 — Application block collection (Plan 053)

## Additions

| Block state | Outcomes |
|-------------|----------|
| `OpsDashboardState` | region focus, table/log bubbles, retry/time-range **requests** |
| `ResourceBrowserState` | sidebar + `LoadRequested` with selection generation |
| `SettingsShellState` | save/reset/discard/search **requests** |
| `FormWizardState` | step nav, `BlockedInvalid`, `SubmitRequested` |

Layout helpers `layout_ops_dashboard` / `layout_resource_browser` remain for geometry. Blocks own chrome state only; domain effects never execute inside TermRock.

## Registry

Package blocks via `termrock-cli` using public APIs only (see migration 0055).

## Validation

```bash
cargo test -p termrock --lib blocks
```
