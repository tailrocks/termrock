# 0189 — DataTable interactive / virtualized redesign

## Mission

Category-leading interactive DataTable for professional developer tools: sort,
filter/search, column resize/visibility/pin/reorder hooks, grouping, row/cell/
range selection, inline edit, copy, context actions, sticky header + pin strips,
remote/partial load, unknown totals, and million-row logical datasets via
consumer projection. Keyboard nav modes and pointer resize/selection are
precise. Responsive column priorities and fullscreen promotion. VisiData-like
stories and serious window/paint tests.

Research: VisiData, Textual DataTable, DB clients, k9s, btop, spreadsheets.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `data_view` kits (`VirtualWindow`, `ColumnModel`, `SelectionModel`, `LoadState`, `SortSpec`, `FilterSpec`, `CopyPayload`, `ExpandState`, `GroupHeader`, `bench`) | **Preserved** + extended |
| `DataTable::new` / `toolbar` / `focused` / projected `[(RowId, &[&str])]` | **Preserved** |
| `DataTableState::{selection, window, cursor_*, load, density, expand, sort, filter, striped, ascii, colorless, accepts_input}` | **Preserved** |
| `DataTableOutcome` core variants (Scrolled, CursorMoved, Sort*, Filter, Activate, Toggle, SelectAll, Copy, Expand, Context, EditStarted, Retry, Toolbar) | **Preserved** |
| `col_window: VirtualWindow` | **Migrated** → `h_offset` + resolved paint widths |
| `handle_mouse(event, rows)` | **Migrated** → `handle_mouse(event, rows, columns: &mut ColumnModel)` (resize applies overrides) |
| Columnar join-string paint | **Migrated** → true multi-column layout + `│` + pin strips |
| `DataTableNavMode` Cell\|Row\|Range | **Added** |
| `DataTableHeaderRegion` / `DataTableCellRegion` | **Added** |
| Outcomes: `ColumnResized`, `ColumnVisibility`, `ColumnReorderRequested`, `EditCommitted`, `EditCancelled`, `FullscreenRequested`, `NavModeChanged`, `SelectionChanged`, `GroupToggled` | **Added** |
| `ColumnModel::{set_width_override, move_column, resolve_paint_widths, effective_width, index_of}` | **Added** |
| `DataColumn::{sortable, editable}` builders | **Added** |
| `DataTable::{groups, fullscreen_hint}` | **Added** |
| `Table` (display) | **Preserved** — not folded into DataTable |

## Consumer edits

```diff
  let mut state = DataTableState::new();
  state.set_logical_rows(1_000_000);
  let (start, end) = state.window.visible_range();
  let rows = source.project(start, end); // ONLY this slice

- state.handle_mouse(event, &row_ids);
+ state.handle_mouse(event, &row_ids, &mut columns);

  // Apply host-owned mutations from outcomes:
  match outcome {
+     DataTableOutcome::ColumnResized { column, width } => {
+         columns.set_width_override(&column, width);
+     }
+     DataTableOutcome::ColumnReorderRequested { from, to } => {
+         columns.move_column(from, to);
+     }
+     DataTableOutcome::EditCommitted { row, column, text } => { /* domain write */ }
+     DataTableOutcome::FullscreenRequested => { /* host promote */ }
+     DataTableOutcome::NavModeChanged(mode) => { /* optional chrome */ }
      DataTableOutcome::SelectAllRequested => {
          state.selection.select_all_rows(&row_ids); // visible only
      }
      _ => {}
  }

  DataTable::new(&system, &columns, &rows)
+     .groups(&group_headers)
+     .fullscreen_hint(true)
      .focused(scene_owns)
      .render(area, buf, &mut state);
```

### Keys (defaults)

| Key | Behavior |
|-----|----------|
| ↑/↓ j/k | Row cursor / scroll window |
| ←/→ h/l | Cell column or h-scroll (`Row` mode: h-scroll only) |
| Shift+arrows | Range extend or expand detail |
| Space | Toggle multi-select row |
| Enter | Activate / commit edit |
| Esc | Cancel edit / clear selection |
| Ctrl+A | SelectAllRequested (visible) |
| s | SortSpec on cursor column |
| / | FilterChanged |
| c | Copy shape |
| e | EditStarted |
| x | ContextMenu |
| [ ] | Resize cursor column (−/+) |
| , . | Reorder request left/right |
| \ | Cycle nav mode Cell→Row→Range |
| Ctrl+F | FullscreenRequested |
