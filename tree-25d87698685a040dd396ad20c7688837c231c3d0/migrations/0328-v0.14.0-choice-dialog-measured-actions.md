# 0328 — ChoiceDialog measures actions before stacking

**Version:** `v0.14.0`
**Kind:** behavioral

`ChoiceDialog` now keeps actions horizontal whenever their rendered labels,
cursor chrome, and configured gaps fit its actual inner content width. It
stacks actions vertically only when that measured row would clip.

Previously a generic dialog breakpoint also considered outer height and could
stack short action rows despite ample horizontal space. This made spacious but
short dialogs harder to scan and spent scarce vertical space unnecessarily.

No consumer edit is required. Callers keep using the same `ChoiceDialog` and
`Action` APIs; custom labels and Unicode display widths participate in the fit
decision automatically.
