This preview mounts one persistent Rust state machine. Focus it, use the current actions shown by the runtime, inspect the typed outcome, and use **Reset** for fresh state.

## Try it

- `type recipient`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `Enter/comma add`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `paste values`: Focus the editable field, then type or paste Unicode text; the draft remains visible.
- `←→ choose token`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.
- `Delete remove`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `Alt+←→ reorder`: Dispatch this action to the mounted Rust state machine and inspect its visible typed result.
- `click`: Activate the focused or pointed target; inspect the changed cells and typed outcome below the terminal.

Every accepted action reaches the same mounted Rust value. The status line shows the latest typed outcome; **Reset** creates a fresh instance.

## Usage

The Code view above and this source excerpt use the exact paint setup registered for `token-field/basic`. Interaction state is long-lived in the catalog interactor; the host only forwards backend-neutral events.

```rust
use ratatui::prelude::*;
use termrock::{input::*, interaction::*, runtime::*, style::*, widgets::*};

// Exact paint setup used by the shared catalog story.
fn token_field_basic_story(frame: &mut Frame<'_>, area: Rect, system: &DesignSystem) {
    let mut state = TokenFieldState::new();
    state.set_focused(true);
    let _ = state.push_token(FieldToken::new("1".into(), "alice@ex.com"));
    let _ = state.push_token(FieldToken::new("2".into(), "bob@ex.com"));
    let _ = TokenField::new(system)
        .label("To")
        .placeholder("Add recipient…")
        .ascii(true)
        .paint(area, frame.buffer_mut(), &mut state);
}
```

## Migrated handbook guidance

# TokenField

**Purpose.** Recipients, filters, tags, file mentions, command arguments — an
owned token collection with a draft input. Hosts own async completion menus.


## vs TokenStrip

| | TokenStrip | TokenField |
|--|------------|------------|
| Data | borrowed projection | owned tokens + draft |
| Input | none | free-text commit |
| Focus | roving on chips | draft ↔ tokens one surface |

## Focus model

One host Tab stop for the field. Inside:

- **Draft** — type; Left at caret start moves to last token
- **Token** — Left/Right; optional remove part without Tab
- Empty draft **Backspace** removes previous token
- **Alt+Left/Right** reorders focused token

## Example

```rust
use termrock::style::DesignSystem;
use termrock::widgets::{FieldToken, TokenField, TokenFieldState};

let system = DesignSystem::default();
let mut state = TokenFieldState::new();
state.set_focused(true);
let _ = state.push_token(FieldToken::new("1".into(), "alice@ex.com"));
// comma / Enter commits draft; Tab → CompletionRequested
let _ = TokenField::new(&system).label("To");
```
