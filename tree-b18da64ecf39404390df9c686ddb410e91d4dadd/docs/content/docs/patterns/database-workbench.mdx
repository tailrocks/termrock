## Workflow

- `Tab cycle panes`: move visible focus, selection, pane, or hierarchy state for the next action.
- `type SQL`: focus the real field and edit its persistent Unicode-safe draft.
- `Ctrl+Enter run`: invoke the focused public state-machine action and inspect its typed request.
- `Ctrl+P palette`: forward this normalized action to the mounted public pattern state.
- `Ctrl+H history`: forward this normalized action to the mounted public pattern state.
- `Esc close layer`: peel or cancel the current transient layer and preserve underlying state.

Accepted actions update the same persistent pattern instance in web docs and native Lookbook. Typed requests appear in the status line; the fixtures never authenticate, connect, execute, persist, or mutate external state.

## Ownership

TermRock owns composition, focus geometry, responsive layout, and reusable state transitions. The consuming application owns records, commands, persistence, secrets, authorization, and side effects.
