# 0037 — DesignSystem quiet phosphor hierarchy

## Canonical addition

```rust
use termrock::{DesignSystem, DesignTokens};
use termrock::widgets::List;

let system = DesignSystem::phosphor(); // SelectionChrome::Gutter by default
let list = List::new(&rows, system.theme()).tokens(&system.tokens);
```

List paint prefers `DesignTokens::list_row_recipe` when `.tokens(...)` is set:
quiet gutter selection, phosphor accent for intent, not full-row fill by default.

## Validation

```bash
cargo test -p termrock list --all-features --locked
```
