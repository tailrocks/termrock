# 0236 — AgentWorkbench elevated composition block

## Mission

North-star **application block** composed only from **public** TermRock APIs
and registry components — not a monolithic framework requirement. Source-owned
composition for agent hosts (Grok Build, Amp, OpenCode, Claude Code, Posting,
Zellij, Glow as experience references; clone none).

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `AgentWorkbenchState` + `render_agent_workbench` | **Elevated** — sole scene authority |
| `agent_workbench_layout` / `sync_workbench_scene` | **Preserved**, density-aware |
| `WorkbenchSurfaces` | **Migrated** — elevated optional slots |
| `WorkbenchKeyOutcome` | **Migrated** — Task/Activity wrap elevated outcomes |
| `PromptBox` / `ApprovalCard` workbench path | **Deleted** (already cut over to Composer + PermissionPrompt) |
| Local visual substitutes in pattern | **Forbidden** — fix framework if missing |
| `WorkbenchDensity`, fixtures, modal rects | **Added** |

## Consumer API

```rust
use termrock::patterns::{
    AgentWorkbenchState, WorkbenchDensity, WorkbenchSurfaces, WorkbenchKeyOutcome,
    agent_workbench_layout, agent_workbench_layout_density, default_modes,
    example_workbench_tasks, example_workbench_activities, render_agent_workbench,
    sync_workbench_scene, dialog_modal_rect, diff_modal_rect, permission_modal_rect,
};

let mut workbench = AgentWorkbenchState::new();
// optional: workbench.density = Some(WorkbenchDensity::Narrow);
// optional: workbench.ascii = true; workbench.colorless = true;

render_agent_workbench(buf, area, WorkbenchSurfaces {
    system: &system,
    state: &mut workbench,
    task_models: Some(&tasks),       // preferred TaskRail
    tasks: &[],                      // legacy List fallback
    modes: &default_modes("build"),
    transcript: &transcript,
    transcript_state: &mut tstate,
    activities: Some(&activities),
    prompt: &prompt,
    prompt_state: &mut pstate,       // draft NEVER cleared by overlays
    status_slots: &slots,
    status_state: &mut sstate,
    permission: Some((&perm, &mut perm_state)),
    question: Some(&flow),
    plan: Some(&plan_w),
    diff: Some(&diff_w),
    session: Some(&session_w),
    working: Some(&working_w),
});

// Key routing: overlay → focused pane; one-layer Esc
let out = workbench.handle_key(
    key, &mut pstate, &mut tstate, &blocks,
    Some(&mut perm_state),
    Some(&tasks), None,
    Some(&activities), Some(&hunks),
);
```

### Layout densities

| Density | Width (default) | Panes |
|---------|-----------------|-------|
| `Normal` | ≥ 72 | TaskRail · Transcript · Activity · Working · Prompt · Status |
| `Narrow` | 40–71 | Transcript · Activity · Prompt · Status |
| `Tiny` | < 40 | Transcript · Prompt · Status |

### Laws

| Law | Detail |
|-----|--------|
| Draft | Overlays never clear `PromptComposerState` |
| Esc | One dismissible layer peels; no bulk grant / no submit |
| Focus | Tab cycles TaskRail → Transcript → Activity → Prompt when no overlay |
| Public only | Pattern imports only public widgets + layout/scene |
| Host owns I/O | Outcomes are requests; no process / network / secrets |

### Stories

- `agent-workbench/{basic,tool-running,permission,plan,diff,session,multi-agent,narrow,tiny,ascii,no-color}`

## Breaking edits

1. `WorkbenchSurfaces` requires new fields: `task_models`, `activities`, `plan`,
   `diff`, `session`, `working` (all `Option` — pass `None` if unused).
2. `handle_key` gains `activities` and `diff_hunks` parameters.
3. `WorkbenchKeyOutcome::Task` is now `Task(TaskRailOutcome)` (was
   `Outcome<String>`).
4. `WorkbenchKeyOutcome::Activity` is now `Activity(ActivityShelfOutcome)`.
5. Command layer kind is `LayerKind::Menu` (no `Palette` variant).
