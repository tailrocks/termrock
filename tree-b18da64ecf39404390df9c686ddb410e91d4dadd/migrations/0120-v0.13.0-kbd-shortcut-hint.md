# 0120 — Kbd and ShortcutHint

## Mission

Canonical keyboard chord and shortcut display: platform-aware modifiers,
sequences, alternatives, and semantic commands; derive display from the active
[`Keymap`] rather than hardcoded labels; compact footer, keycap, and inline-doc
forms; ASCII/no-color and narrow contraction; shared by menus, dialogs, help,
and toolbars.

## Preserve / migrate / split / delete

| Surface | Fate |
|---------|------|
| `Kbd::new(label, system)` | **Preserved** (label is now `Into<Cow>`) |
| `Kbd::from_chord(chord, buf, system)` | **Migrated** → `Kbd::from_chord(chord, system)` (owned) or `from_chord_buf` / `kbd_from_chord` |
| `chord_glyph` | **Preserved** — legacy static table for HintSpan / tests |
| `HintBar` / `Hint` / `HintSpan` | **Preserved** — still compose string chords; prefer ShortcutHint for new code |
| `Keymap::glyph_for` / `push_spans_for` / `hint_spans` | **Preserved** |
| `format_chord` / `format_sequence` / `format_alternatives` / `format_binding` | **Added** |
| `ShortcutHint`, `ChordFormat`, `Platform`, `ModifierStyle`, `KbdVariant`, `ShortcutForm` | **Added** |
| Module | **Split** → `widgets/kbd.rs` |

## API sketch

```rust
use termrock::widgets::{
    Kbd, ShortcutHint, ChordFormat, ModifierStyle, Platform,
    format_chord, format_alternatives,
};
use termrock::keymap::{KeyChord, Keymap};

// Chord paint
Kbd::from_chord(KeyChord::ctrl(KeyCode::Char('s')), &system)
    .keycap()
    .paint(area, buf);

// Sequence / alternatives
Kbd::sequence(&[KeyChord::plain(KeyCode::Char('g')); 2], &system);
Kbd::alternatives(&[KeyChord::ctrl(KeyCode::Char('s')), KeyChord::plain(KeyCode::Char('s'))], &system);

// From keymap — never hardcode labels
let k = Kbd::for_action(&map, Action::Save, &system);
let h = ShortcutHint::for_action(&map, Action::Save, &system)?
    .footer(); // or .inline_doc() / .keycap()
h.paint(area, buf);

// Platform-aware formatting
format_chord(
    KeyChord::ctrl(KeyCode::Char('c')),
    ChordFormat::docs().platform(Platform::Mac).modifiers(ModifierStyle::Symbols),
);
```

## Forms

| Widget | Form | Layout |
|--------|------|--------|
| Kbd | Compact | bare chord |
| Kbd | Keycap | `[ chord ]` |
| Kbd | Inline | docs-oriented |
| ShortcutHint | Footer | `C-s Save` |
| ShortcutHint | InlineDoc | `Save  C-s` |
| ShortcutHint | Keycap | `[C-s] Save` |

## Contraction

ShortcutHint drops the **command** before the chord when width is tight
(`shows_command`). ASCII forces arrow names (`Up` not `↑`).
